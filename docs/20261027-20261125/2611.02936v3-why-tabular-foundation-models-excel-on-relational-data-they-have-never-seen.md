## 摘要
给定一个存储异构表格信息的关系数据库（RDB），我们如何预测某个感兴趣目标列中的缺失值（或未来值）？在企业场景中，候选目标数量众多，因此最好避免每遇到一个新的预测任务就从零开始学习一个新模型。基于上下文学习（ICL）和 RDB 特定预训练的冻结基础模型（FM）提供了一种可行方案，但理想设计在很大程度上仍未确定。或许出乎意料的是，近期初步证据表明，现有单表基础模型（即 TFM）在与合适的无参数关系编码器结合后，即使完全未接触 RDB 预训练或任何类型的关系数据，在实践中也能颇具竞争力。在本工作中，我们首先通过更多样化的实验从经验上证实这一现象。随后转向我们的主要贡献，即揭示多种互补解释，说明 TFM 为何表现得如此有效。这些解释最终依赖于一种内在协同效应：无参数编码器将关系效应映射为固定长度嵌入，而这些嵌入大致模拟了 TFM 最初设计所面向的分布；由此，理想的单表性质得以迁移到关系场景中（例如收敛的后验预测分布）。总体而言，我们的分析为改进 RDB 基础模型开辟了新路径，尤其是在我们优先考虑可解释性以及其不可避免地将集成到智能体系统中的情况下。

## Abstract
Given a relational database (RDB) storing heterogeneous tabular information, how can we predict missing (or future) values in some target column of interest? As candidate targets are numerous in enterprise settings, it is preferable to avoid learning a new model from scratch each time there is a new prediction task. Frozen foundation models (FMs) based on in-context learning (ICL) and RDB-specific pre-training provide a viable solution, but the ideal design still remains largely unresolved. Perhaps unexpectedly, preliminary evidence has recently shown that existing single-table FMs (aka TFMs), when combined with suitable parameter-free relational encoders, can be quite competitive in practice despite zero exposure to RDB pre-training or relational data of any kind. In this work we first empirically confirm this phenomenon with a more diverse array of experiments. We then turn to our main contribution, namely, surfacing multiple complementary explanations for why TFMs behave so effectively. These explanations ultimately hinge on innate synergies whereby parameter-free encoders map relational effects to fixed-length embeddings that loosely mimic distributions for which TFMs were originally designed; in so doing, desirable single-table properties transfer to relational settings (e.g., convergent posterior predictive distributions). Collectively, our analysis forges new pathways for improving RDB FMs, particularly when we prioritize interpretability and inevitable integration within agentic systems.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：关系数据库（RDB）由多张相互关联的异构表构成，是企业与电商场景的核心数据载体。单个 RDB 中往往存在大量可预测目标（如客户留存、用户流失、点击率等），若每个新任务都从零训练模型，成本高昂且不可扩展。
- **理想方案**：构建冻结的 RDB 基础模型（FM），使其能够跨未见过的 RDB 与任务直接做零样本/少样本预测。
- **现有路线**：包括 LLM 直接消化序列化 RDB、基于上下文学习（ICL）的专用 Transformer、RDB 特定预训练模型（如 KumoRFM、RT-J 等）。
- **反常现象**：近期初步证据显示，**单表基础模型（TFM）**（如 TabPFN）搭配**无参数关系编码器**，在完全未接触任何 RDB 预训练或关系数据的情况下，竟能在关系数据上取得有竞争力的表现。
- **论文定位**：本文并非提出新模型，而是（1）用更广泛的实验确认该现象；（2）给出**多种互补的理论解释**，说明为何 TFM 在 RDB 上如此有效，并为可解释、易融入智能体系统的 RDB FM 设计提供新思路。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体流程
- 将 RDB 建模为异构图 G（表为节点类型、行为节点、PK-FK 为边）。
- 对每个目标行 x 采样 H-hop 子图 G_H(x)，经无参数编码器 g_pf 映射为定长嵌入 z。
- TFM 以 {z_i, y_i} 作为 ICL 样本，对测试点 z_test 做后验预测。

### 2.2 核心解释一：单表与 RDB 的“连续谱”
- 通过引入延续参数 τ∈[0,1]，构造标签生成函数：
  y = ψ[(1−τ)f₁(x, ε₁) + τf₂(G_H(x)\x, ε₂)]
- τ=0 退化为纯单表，τ=1 完全依赖关系效应；二者之间形成连续谱。
- 单表与 RDB 之间没有明确分界线，因此 TFM 天然适合覆盖该谱系。

### 2.3 核心解释二：局部性与无偏估计的必要条件
- 定义“持续 RDB 生成过程”（Definition 5.1），要求预测器满足方差消失与偏差趋零。
- **Proposition 5.2**：若 RDB FM 要在广泛分布族上获得无偏估计，则解码器 q_θ 应仅依赖嵌入接近 z_test 的 ICL 样本（局部性）。
- **均匀采样**优于随机游走采样：均匀采样可在无先验知识时覆盖 z_test 邻域，并近似 IID，从而复用 TFM 的单表先验。
- 通过后验预测分布（PPD）论证：
  p_ppd(y_test|z_test, S_n) = ∫q(y_test|z_test)dμ(q|S_n) → p̂(y_test|z_test) ≈ p_gt
  即均匀采样 + 单表先验可使 PPD 收敛到真实分布。

### 2.4 核心解释三：无参数编码器的表达能力
- 以交互项 y_i = max_{j∈R_i}[a_j ∧ b_j] 为案例，反驳“无参数编码器无法处理交互项”的观点。
- 三点反驳：
  1. 所有有损编码都会产生反例，关键在反例在真实 RDB 中的相对频率；
  2. 任意交互项数量随列数二次增长，参数化编码器也无法穷尽；
  3. TFM 可在压缩表示之间建模交互，且足够多的聚合可实现无损压缩（Kolmogorov-Arnold 表示定理）。

### 2.5 核心解释四：与智能体系统的三阶段协同
- **阶段 1（符号/智能体）**：基于领域知识筛选潜在有用特征（如“黄金特征”）。
- **阶段 2（编码器）**：无参数 g_pf 保持列对齐、不混合特征，将黄金特征原样传递。
- **阶段 3（解码器）**：TFM 以数据驱动方式在 ICL 样本中判断特征相关性。
- 无参数编码器使三阶段互补且可解释（SQL 聚合可被智能体直接审查）。

## 6. 主要结论与发现

1. **TFM 竞争力确认**：在 6 个 benchmark 上，TFM-based 方法（RDBLearn、TabPFN-Rel-OSS）在 RDB FM 中取得最佳平均排名，甚至超过部分逐任务监督模型。
2. **连续谱视角**：单表与 RDB 之间无明确界限；TFM 天然覆盖从 τ=0 到 τ=1 的整个谱系，且在 τ 增大时性能下降最慢（表 1）。
3. **局部性与均匀采样**：Proposition 5.2 表明无偏 RDB FM 需局部性；均匀采样比随机游走更符合该条件，且样本效率更高（表 2：RDBLearn 均匀采样用 7816 个唯一标签达 AUROC 75.0，优于 RT-J 8K 采样的 73）。
4. **表达能力无忧**：无参数编码器在交互项任务上与 KumoRFM-2 竞争力相当，且对表宽增加更稳定；参数化编码器并无明确优势。
5. **智能体协同**：TFM + 无参数编码器天然支持三阶段分工；单次 agent 提示即可使 RDBLearn 平均 AUROC 从 0.7602 提升至 0.7841，与 SOTA 多智能体系统 RelAgent（GPT-5.2，0.7838）持平，且无需逐任务训练。
6. **RDB 特定预训练的困境**：随机游走采样破坏 IID 假设，使 PPD 不再收敛；RDB 特定先验设计更难、更易错配，且无法通过增大 n 补偿。
