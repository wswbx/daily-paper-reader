## 摘要
大语言模型（LLMs）可以帮助从数据中发现数学方程，但大多数LLM引导的符号回归方法仅关注单一最优方程，而未量化对替代函数形式的不确定性。这具有挑战性，因为不同方程可能对观测数据拟合得相似，却产生显著不同的外推结果。我们在LLM-SRBench数据集上的实验表明，标准共形区间能够达到名义上的分布内覆盖，但在外推下经常失效。为应对这一挑战，我们提出LLM-SR-UQ框架，该框架保留相互竞争的方程结构，并利用它们之间的分歧来刻画关于潜在函数形式的不确定性。我们将标准固定宽度共形方法扩展为量化结构区间，该区间度量候选方程之间的分歧，并识别预测区间应在何处加宽。大量实验表明，我们的框架通过纳入结构分歧显著提高了覆盖达成率，同时保持了分布内覆盖。当应用于其他符号回归方法时，我们的方法也表现出良好的泛化性。

## Abstract
Large language models (LLMs) can help discover mathematical equations from data, but most LLM-guided symbolic regression methods focus on a single best equation without quantifying uncertainty over alternative functional forms. This is challenging because distinct equations can fit the observed data similarly while producing substantially different extrapolations. Our experiments on the LLM-SRBench dataset show that standard conformal intervals achieve nominal in-distribution coverage but frequently fail under extrapolation. To tackle this challenge, we introduce LLM-SR-UQ, a framework that retains competing equation structures and uses their disagreement to characterize uncertainty about the underlying functional form. We extend the standard fixed-width conformal approach to quantify structural intervals, which measure disagreement among candidate equations and identify where prediction intervals should widen. Extensive experiments show our framework substantially improves coverage attainment by incorporating structural disagreement while preserving in-distribution coverage. Our approach also shows good generalizability when it is applied to other symbolic-regression methods.

# 《知晓方程何时出错：外推场景下LLM引导符号回归的结构不确定性》论文总结

## 1. 核心问题与研究动机

- **背景**：LLM 引导的符号回归（如 LLM-SR）能够从数据中发现可解释的闭式方程，但现有方法普遍只输出**单一最优方程**，不量化“函数形式本身是否正确”的不确定性。
- **核心矛盾**：不同的方程结构可以在观测数据范围内拟合得几乎一样好，却在外推（extrapolation）时给出**截然不同的预测**。一旦搜索过程中丢弃了竞争方程，这种结构歧义就无法再被事后校准所捕捉。
- **现有方法的不足**：
  - 经典符号回归虽已有贝叶斯模型选择、集成、SINDy 系综等方法刻画结构不确定性，但多输出项包含概率或模型分数，而非具有覆盖目标的预测区间。
  - 标准保形预测（split conformal）在分布内（ID）能达到名义覆盖，但其**可交换性假设在外推下不成立**，实验显示 OOD 覆盖经常严重失效。
  - 现有基准主要评估点预测精度与符号恢复，不评估预测区间是否校准。
- **论文目标**：在 LLM 引导符号回归中同时给出点预测与**反映函数形式歧义的、输入依赖的预测区间**，并系统评估其在 ID 与外推（OOD）下的覆盖表现。

## 2. 方法论：LLM-SR-UQ 框架

### 2.1 核心思想
保留多个相互竞争的候选方程结构，用它们之间的**预测分歧**作为结构不确定性的经验度量，再通过保形校准把这种分歧转化为具有覆盖意义的预测区间。区间在候选方程分歧大的输入处加宽，在分歧小处收窄。

### 2.2 四阶段流程

- **Stage A（提出结构）**：LLM 每轮生成 K=8 个带自由系数（c0, c1, …）的方程结构。A1 起附带固定格式的搜索诊断摘要（领先方程、拟合误差、不可辨识系数、未使用变量、残差模式等）；A2/A3 额外加入 critic 指导。proposer 不直接接触数值训练数据。
- **Stage B（拟合、评分与保留）**：
  - 在 D_fit 上用非线性最小二乘拟合系数，计算 RSS 与噪声方差估计。
  - 用 BIC 近似对数贝叶斯证据：BIC_k = n·log σ̂²_k + d_k·log n，log Z_k ≈ −BIC_k/2。
  - 综合得分 ℓ_k = log Z_k − λ·d_k（λ=0.05）。
  - 保留至多 B=24 个高分且结构不重复的候选；**温度控制权重** w_k ∝ exp(ℓ_k/τ)，通过二分法调节 τ 使 Kish 有效模型数 B_eff = (Σw_k²)⁻¹ 达到 0.35B ≈ 8.4，避免权重几乎全部塌缩到单一方程。
- **Stage C（可选 critic）**：每 5 次 LLM 调用中有 1 次分配给 critic。critic 读取数值诊断（残差趋势、弱系数、重复结构族、停滞标志；A3 还读取 D_cal-EXT 上无标签的结构分歧与区间增长信息），输出禁令、指令与最多 3 条方程编辑。**critic 只影响后续提议，不修改保留缓冲区**；所有编辑需通过格式与证据引用校验。
- **Stage D（预测与结构区间）**：
  - 点预测用未加温权重做贝叶斯模型平均：ŷ(x) = Σ_k w̃_k M_k(x; θ̂_k)。
  - 结构散布（加温权重）：σ²_S(x) = Σ_k w_k (M_k(x; θ̂_k) − ŷ(x))²，并加一个极小噪声项保证正值。
  - 在 D_cal-ID 上计算归一化非一致性分数 s_i = |y_i − ŷ(x_i)| / σ_S(x_i)，取 ⌈(m+1)(1−α)⌉ 分位数 q̂_α。
  - 最终区间：C(x) = [ŷ(x) − q̂_α·σ_S(x), ŷ(x) + q̂_α·σ_S(x)]。
  - 对照基线 split conformal 使用同一预测器但常数尺度，从而**隔离“结构分歧”本身的贡献**。

### 2.3 消融阶梯（A0–A3）
- A0：仅问题描述；A1：加入规则化机械诊断；A2：加入 LLM critic；A3：critic 额外获得无标签外推分歧信息。所有配置统一 125 次 LLM 调用预算（A2/A3 中 24 次给 critic、101 次给 proposer）。

- **数据划分**：训练数据 80% 为 D_fit（n=3200），20% 为 D_cal-ID（m=800）；另有仅用于 critic 的无标签外推探测区 D_cal-EXT；最终在 D_test（插值）与 D_OOD（外推）上评估。

- **对比方法**：

## 6. 主要结论与发现

- **标准保形区间在外推下系统性失效**：ID 覆盖约 0.90，但 OOD 覆盖常远低于名义值（如 A1 split 仅 0.627，Ensemble-SINDy split 仅 0.365）。
- **结构区间显著提升 OOD 覆盖达成率**（同一预测器下）：
  - A0：0.58 → 0.83；A1：0.53 → 0.92。
  - LLM-SR top-24：0.53 → 0.86；Ensemble-SINDy：0.26 → 0.62。
  - ID 覆盖保持在约 0.90，点预测 NMSE 不变。
- **改进可跨搜索方法迁移**：结构区间不依赖具体搜索算法，在 LLM-SR 与 Ensemble-SINDy 上同样有效。
- **机械反馈（A1）是主要收益来源**：相比 A0，A1 显著降低 ID/OOD NMSE，提高搜索多样性（重复结构族比例 31%→22%，探索到 774 个不同结构族），并达到最高 OOD 达成率 0.92。
- **LLM critic 未带来额外收益**：A2/A3 的 OOD 达成率为 0.82–0.88，均不及 A1；critic 使方程更简单（系数数 8.3→6.7–7.4），但损失部分 ID 精度；校准感知 critic 反而使区间更宽。
- **结构分歧的增益不依赖证据权重是否退化**：在未加温权重几乎为点质量的 86 个 A0 问题上，结构区间仍把达成率从 0.58 提升到 0.86；温度目标在 B_eff=2–24 范围内结果平坦，说明方法对超参数不敏感。
- **重要警示**：即使点预测准确，外推区间也可能极宽（附录案例中 OOD 平均宽度约为 ID 的 1900 倍），说明“覆盖达标”必须与区间锐度联合解读；且结构区间**不保证 OOD 覆盖**，仅为经验改进。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量与总时长，难以评估方法的大规模可行性与碳成本。
- **外推覆盖无理论保证**：结构区间仅继承可交换性下的边际覆盖保证；OOD 下的改进是经验性的，在更强分布偏移下可能失效（作者亦明确承认）。
- **实验覆盖有限**：
  - 仅使用 LSR-Synth 子集，排除 LSR-Transform；
  - 主要结果基于**单一搜索种子**，种子复现仅在 20 个开发问题上进行；

- **区间锐度问题**：个别案例 OOD 区间极宽（约 1900 倍），虽然覆盖达标，但实际可用性受限；锐度指标只在覆盖达标子集上计算，跨方法可比性有限。
- **critic 结论的边界**：critic 的零效果是在固定 125 次调用预算下得到的，作者也指出这刻画的是“整体配置”而非 critic 的孤立效应；更强模型或不同预算下结论可能不同。
- **结构分歧度量的解释性**：加温权重并非校准的贝叶斯后验，σ_S 是经验性分歧度量；论文也指出低 top-family 权重不一定代表函数多样性（可能存在“同一函数的多种写法”），这一测量局限未被量化。
- **应用限制**：方法依赖 LLM 能提出足够多样的候选结构；若搜索从未探索到正确结构族（如附录案例中 sigmoidal 形式从未被提出），结构区间只能反映“已见候选间的不一致”，无法弥补搜索覆盖的盲区。
