## 摘要
对信号交叉口交通延误的可信估计对现代交通系统至关重要，因为它可支持面向拥堵缓解的主动交通控制。现有解析方法往往依赖理想化假设，这限制了其在复杂交通条件下的准确性；而数据驱动方法虽可能取得较强的估计性能，但通常缺乏透明的结构，从而降低其实际应用中的可信度。为解决这些局限，我们提出 CoSyDelay，一种认知符号回归（SR）框架，用于自动推导显式且物理一致的经验延误估计表达式（DEEs）。具体而言，CoSyDelay 将交叉口层面的延误估计分解为转向车流层面的子问题，从而降低符号搜索的复杂度。在 DEE 学习过程中，CoSyDelay 从交通变量中构建领域知识引导的符号输入。采用大语言模型（LLMs）作为符号搜索算子，迭代生成并细化候选表达式结构，随后利用进口道层面的延误标签校准其特定于转向车流的系数。复合适应度函数从估计准确性以及是否符合指定交通延误原则两方面联合评估学习得到的 DEEs。在多个信号交叉口上的实验结果表明，所得表达式在保持物理一致性的同时取得了有竞争力的估计性能，从而支持可信的延误估计。源代码和数据集可在 https://github.com/ForrestXie9/CoSyDelay 获取。

## Abstract
Trustworthy estimation of traffic delays at signalized intersections is critical for modern transportation systems, as it supports proactive traffic control for congestion mitigation. Existing analytical methods often rely on idealized assumptions that limit their accuracy under complex traffic conditions, whereas data-driven methods may achieve strong estimation performance but usually lack transparent structures, which reduces confidence in their practical application. To address these limitations, we propose CoSyDelay, a cognitive symbolic regression (SR) framework for automatically deriving explicit and physically consistent empirical delay estimation expressions (DEEs). Specifically, CoSyDelay decomposes intersection-level delay estimation into turning-movement-level subproblems, thereby reducing the complexity of the symbolic search. During DEE learning, CoSyDelay constructs domain-informed symbolic inputs from traffic variables. Large language models (LLMs) are employed as symbolic search operators to iteratively generate and refine candidate expression structures, whose movement-specific coefficients are subsequently calibrated using approach-level delay labels. A composite fitness function evaluates the learned DEEs jointly in terms of estimation accuracy and compliance with specified traffic-delay principles. Experimental results on multiple signalized intersections demonstrate that the resulting expressions achieve competitive estimation performance while maintaining physical consistency, thereby supporting trustworthy delay estimation. Source code and datasets are available at https://github.com/ForrestXie9/CoSyDelay.

## 2. 方法论

### 2.1 核心思想
将交叉口级延误估计**分解为转向车流级子问题**，以领域知识构造符号输入，用 **LLM 作为符号搜索算子**迭代生成/精炼表达式结构，并以**复合适应度**（估计精度 + 交通延误原理合规性）驱动搜索，最后按流量加权聚合到进口道与交叉口级。

### 2.2 关键技术细节

- **问题定义**：转向车流特征 $x_i=(q_i, g^{eff}_i, C_i)$，学习映射 $f(\cdot)$ 得到转向级延误估计 $\hat d_i$。
- **步骤 0 — 特征变换（领域知识引导）**：
  - 将原始输入转为 $x'=(y,\lambda,C)$，其中流量比 $y=q_i/s_i$（$s_i=s_0 L_i$，$s_0=1800$ veh/h/lane）、绿信比 $\lambda=g^{eff}_i/C_i$、周期 $C$。
  - 这三个变量是交通理论中延误估计的经典输入，且不增加输入变量个数。
- **步骤 1 — LLM 表达式骨架初始化**：
  - 用初始化 Prompt 让 LLM 生成 $P$ 个候选表达式结构，含符号系数 $a_1,\dots,a_k$（不赋固定数值）。
  - 每个转向有独立系数向量 $a_{i,j}$，但**系数校准以进口道级延误标签监督**（转向级标签不需要）。
- **步骤 2 — 系数校准**：
  - 对每个候选结构，最小化“进口道延误标签”与“转向估计按流量加权聚合值”之间的差异，联合校准所有转向的系数（L-BFGS-B，约束 $a>0$）。
- **步骤 3 — 复合适应度评估**：
  - **精度分** $\text{Score}_{acc}$：各有效进口道 $R^2$ 的均值（负值截断为 0）。
  - **物理分** $\text{Score}_{phys}$：二元值，仅当**所有转向**均通过全部 7 条延误原理时为 1。
  - 总适应度 $\text{Fitness}_{overall}=\text{Score}_{acc}+\text{Score}_{phys}\in[0,2]$。
- **7 条交通延误原理及自动检查**（表 III）：
  1. 必须包含 $y,\lambda,C$；
  2. 对流量比单调不减（$\partial f/\partial y\ge0$）；
  3. 对绿信比单调不增（$\partial f/\partial\lambda\le0$）；
  4. 单位一致性（对 $C$ 一阶齐次）；
  5. 低流量极限有限且非负；
  6. 非负性（实数、有限、非负）；
  7. 零绿灯极限 $+\infty$。
  - 数值检查在 $D=[0.001,2.0]\times[0.02,0.95]\times[30,240]$ 上用固定拉丁超立方采样加边界组合进行。
- **步骤 4 — 种群更新与终止**：
  - 采用标准 $(\mu+\lambda)$ 全局父子选择，保留适应度最高的 $P$ 个结构；$G=10$ 代后终止。
- **步骤 5 — LLM 再生（Regeneration）**：
  - 将父代表达式、训练集精度结果、**逐原理违规反馈**（而非仅总分）填入再生 Prompt，让 LLM 生成变体；失败/重复候选会将原因返回 LLM 重试，5 次失败则重新初始化。
- **输出与多粒度聚合**：
  - 以验证集适应度选择最优结构，结构固定后在训练+验证集上重拟合转向系数。
  - 转向级估计按流量加权聚合为进口道级（式 7）与交叉口级（式 8）延误；总流量为零时报告 N/A。
- **典型学得表达式（I1）**：
  $$\hat d=a_1 C\, y^{a_2}\left(\frac1\lambda-1\right)^{a_3}\exp\left(a_4\frac{y}{\lambda}\right)$$
  其中 $a_1C$ 为时间尺度，$y^{a_2}$ 为需求响应，$(1/\lambda-1)^{a_3}$ 为非绿灯/绿灯时间比效应，$\exp(a_4 y/\lambda)$ 为饱和度非线性增长项。

- **计算开销报告不完整**：论文给出单次运行的平均 API 调用次数、累计 API 延迟与系数校准时间，但未系统报告总训练时长、总算力开销与不同规模下的扩展性。

## 8. 可借鉴的研究范式

- **“分解—知识输入—符号搜索—原理约束”四段式流程**：将高维交叉口级问题分解为转向级子问题，用领域知识构造低维符号输入，再以复合适应度约束搜索，适合其他交通状态估计/性能指标建模任务。
- **LLM 作为符号搜索算子而非端到端预测器**：让 LLM 生成和精炼表达式骨架，数值系数交由确定性优化校准，可在保持可解释性的同时利用 LLM 的结构先验。
- **逐原理违规反馈优于单一总分**：将具体违反哪条原理、在哪些采样点违反反馈给 LLM，有助于下一轮生成针对性修正，这一提示设计可迁移到其他“物理一致符号回归”任务。
- **多粒度聚合与标签监督解耦**：用进口道级标签校准转向级系数，降低了对细粒度标签的依赖，为标签粒度粗于建模粒度的场景提供了思路。
- **统一预算与多次随机运行**：符号搜索方法统一 wall-clock 预算并包含 API 等待，配合 20 次独立运行与非参数检验，为 LLM 参与搜索的实验公平性提供了可参考范式。

## 9. 总体评价

CoSyDelay 的核心贡献不在于提出某个全新延误公式，而在于构建了一套**可自动推导显式、物理一致延误表达式**的方法框架，并在精度、可解释性与原理合规性之间取得较好平衡。其实验矩阵较完整，主对比、消融、敏感性与泛化实验相互支撑，统计检验与预算控制较规范。主要不足在于 LLM 依赖带来的成本与复现问题、7 条原理的覆盖有限、部分对比设置存在未区分细节，以及实地多场景验证仍可加强。总体而言，该工作对“知识引导符号回归 + LLM 结构搜索”在交通工程中的应用具有较强示范意义。
