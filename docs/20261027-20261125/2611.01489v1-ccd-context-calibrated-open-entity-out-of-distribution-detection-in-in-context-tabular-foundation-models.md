## 摘要
上下文表格基础模型（TFM），如 TabPFN，基于带标签的上下文进行预测且不更新参数，正越来越多地用于 Web 应用中的分布外（OOD）检测，这些应用的测试行来自该上下文中不存在的实体。此类应用需要开放实体 OOD 检测：新实体不能被误判为未知类，而未知类仍必须被检出。现有检测器在此设置下失效，而实体划分差距掩盖了这种失效：随机划分也会将测试实体放入上下文中。该失效源于每个 TFM 分数都反映了某一行对上下文的不熟悉程度。这会产生一种实体优先于类别的偏差：新实体中属于已知类的行看起来比熟悉的行更具 OOD 性，有时甚至比未知类更具 OOD 性。具体而言，与上下文 TFM 搭配最广泛使用的两种 OOD 分数面临实体-类别权衡：TFM 的预测置信度会漏检未知类，而测试行到上下文的距离则会标记出新实体。为解决该问题，我们将一组实体排除在上下文之外，并用剩余上下文对其打分，从而将其转化为已知类的新实体，并告诉我们此类行应如何打分。为衡量对新实体的检测，我们构建了 NEO-Tab（New-Entity OOD detection on Tables），包含 14 个分组表和时间表，其上所有测试行均来自新实体。随后，我们提出上下文校准检测（CCD），它利用分布内数据上的这些分组留出交换，以新实体参考来校准三个距离和置信度。CCD 根据灵敏度和锐度对其加权，保持模型冻结且不使用 OOD 数据。在 NEO-Tab 上，CCD 在我们报告的每个指标上均优于 16 个现有检测器，并且其领先优势在三个 TFM 主干上依然保持。

## Abstract
In-context tabular foundation models (TFMs), such as TabPFN, predict from a labelled context without updating their parameters and are increasingly used for out-of-distribution (OOD) detection in Web applications, whose test rows come from entities absent from that context. Such applications need open-entity OOD detection: a new entity must not be mistaken for an unknown class, and an unknown class must still be caught. Existing detectors fail in this setting, and an entity-split gap hides the failure: random splits also place the test entities in the context. The failure arises because every TFM score reflects how unfamiliar a row is to the context. This produces an entity-over-class bias: known-class rows of new entities look more OOD than familiar ones, sometimes more than unknown classes. Specifically, the two OOD scores most widely used with in-context TFMs face an entity-class trade-off: the TFM's predictive confidence misses unknown classes, whereas the distance of a test row to the context flags new entities. To address this problem, we hold a group of entities out of the context and score them with the remaining context, which turns them into new entities of known classes and tells us how such rows should score. To measure detection on new entities, we build NEO-Tab (New-Entity OOD detection on Tables), 14 grouped and temporal tables on which all test rows come from new entities. We then propose Context-Calibrated Detection (CCD), which uses these group-out swaps on in-distribution data to calibrate three distances and the confidence against new-entity references. CCD weights them by their sensitivity and sharpness, keeps the model frozen and uses no OOD data. On NEO-Tab, CCD outperforms 16 existing detectors on every metric we report, and its lead holds on three TFM backbones.
