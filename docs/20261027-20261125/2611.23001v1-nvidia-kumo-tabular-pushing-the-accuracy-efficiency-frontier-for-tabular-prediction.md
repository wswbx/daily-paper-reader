## 摘要
我们介绍 Kumo Tabular，这是一系列用于分类和回归的开源表格基础模型，包含三种规模：Kumo Tabular-S（2700万参数）、Kumo Tabular-M（6100万参数）和 Kumo Tabular-L（2.14亿参数）。它们仅在来自 Kumo 先验的人工表格上预训练，即可在无需任何训练的情况下对新表格进行预测。在我们的方法中，表格编码器将每一行压缩为嵌入，上下文学习 Transformer 根据有标签行预测无标签行。Kumo Tabular 引入了架构创新，同时提升训练稳定性和预测性能，使模型能够在现代 GPU 上扩展到 1.5 亿个单元格。Kumo Tabular-L 在八个基准上排名第一：TabArena、TALENT、BeyondArena、ScoringBench、STRABLE、MulTaBench、RamanBench 和 TabBench-Bio。这些基准涵盖概率回归、超过100万行或10万列的表格，以及包含字符串、文本或图像的表格。在所有测试比较中，准确率随模型规模增大而提升。三种规模均位于 TabArena 和 BeyondArena 的精度-速度前沿上。Kumo Tabular-L 的预测速度快于第二名：在 TabArena 上快于 LimiX-2（36倍），在 BeyondArena 上快于 TabPFN-3.5（1.7倍）。权重和预训练代码分别以 OpenMDW-1.1 和 Apache 2.0 许可证发布。

## Abstract
We introduce Kumo Tabular, a family of open tabular foundation models for classification and regression, in three sizes: Kumo Tabular-S (27M parameters), Kumo Tabular-M (61M), and Kumo Tabular-L (214M). Pretrained only on artificial tables from the Kumo prior, they can make predictions on new tables without any training. In our approach, a table encoder compresses each row into an embedding, and an in-context learning transformer predicts the unlabeled rows from the labeled ones. Kumo Tabular introduces architectural innovations that improve both training stability and predictive performance, enabling the model to scale up to 150M cells on modern GPUs. Kumo Tabular-L ranks first on eight benchmarks: TabArena, TALENT, BeyondArena, ScoringBench, STRABLE, MulTaBench, RamanBench, and TabBench-Bio. These cover probabilistic regression, tables with over 1M rows or 100K columns, and tables with strings, text, or images. Accuracy improves with model size in all tested comparisons. All three sizes lie on the accuracy-speed frontiers of TabArena and BeyondArena. Kumo Tabular-L predicts faster than the runners-up, LimiX-2 on TabArena (36 times) and TabPFN-3.5 on BeyondArena (1.7 times). Weights and pretraining code are released under OpenMDW-1.1 and Apache 2.0, respectively.

## 二、方法论

### 2.1 整体框架（两阶段 ICL）

- **输入**：一张表的训练行（含标签）+ 测试行（无标签），单次前向传播输出预测。
- **阶段 1 — 表格编码器**：在列内与行内做注意力，将每一行压缩为固定维度的行嵌入。
- **阶段 2 — ICL Transformer**：在行嵌入层面做跨行推理，使测试行从有标签训练行“学习”。
- **输出头**：两层 MLP，分类输出 10 类 logits，回归输出 999 个分位数；类别数 >10 时拆成多个 10 类子任务（推理时用 ECOC 纠错输出码）。

### 2.2 关键架构细节

- **Cell 嵌入**：
  - 每个 cell 的 token 同时编码本行中列 `j`、`j+1`、`j+3` 的相邻 cell（环绕取模），继承 TabICLv2 的特征分组思想；
  - 数值经“学习频率的正弦/余弦”傅里叶特征展开，按列类型（数值/类别）分别线性投影到 `d` 维；
  - 缺失值用学习嵌入 + NaN mask 表示（先按列均值填补再打标）；
  - 训练行的 token 额外叠加标签嵌入。
- **表格编码器**：
  - **列注意力与行注意力交替** K 次（S：4 次；M/L：6 次），而非“先若干列注意力、再若干行注意力”的分段式，使列间信息在整个编码器中持续交互（消融显示这是最大架构收益）；
  - **列注意力**通过可学习**诱导点（inducing points）**实现，复杂度对行数线性；诱导点只读取该列的训练 cell；
  - **行注意力**用 RoPE 区分 token 位置；4 个可学习 `[CLS]` readout token 参与行注意力、跳过列注意力，最终作为行嵌入输出（必要时线性投影 `4d→w`）。
- **ICL Transformer**：
  - 训练行之间互相可见、测试行只 attend 训练行（训练行 KV 可缓存）；
  - **Test-GQA**：测试行只读每层前 2 个 KV 头，M 的缓存缩小 4 倍、L 缩小 8 倍，从而支撑更深的 ICL 堆叠。
- **长度感知注意力温度**（训练稳定性核心）：
  - 形式为 `softmax((τ ⊙ q)·kᵀ / √d_h)`，其中 `τ(n,q) = α_h · log n · γ(q)`；
  - `n` 为 key 数，`α_h` 为每头可学习系数（受权重衰减约束），`γ(q)` 为可学习 query 门控（仅行注意力使用）；
  - 作用：表格变长/变宽时保持注意力“尖锐”，抵消注意力稀释。
- **稳定性改造**（相对 TabICLv2 的 QASSMax）：
  - 加入无学习增益的 **QK-norm**；
  - 用 **SSMax** 替代 QASSMax，并对注意力尺度施加权重衰减；
  - 解决了长训练/大模型中注意力尺度爆炸、梯度范数突增的问题，使 BF16/FP16 混合精度训练可行。

### 2.3 Kumo 先验（预训练数据生成）

- 基于 TabICLv2 的因果生成器，每张表对应一个随机结构因果模型（SCM），六步生成：
  1. **超参数采样**：表形状、列类型、各机制参数；每张表内各节点共享“每 SCM 偏好”（Dirichlet 采样），使机制风格相关而非独立。
  2. **因果图采样**：随机 DAG，边概率 `σ(A + Bi + Cj)`，`A,B,C ~ Cauchy`，可稀疏可稠密；特征可为 target 的原因或结果，隐藏节点不对应列；保留“特征与 target 无共同祖先”的图，交由可学习性过滤。
  3. **传播**：按拓扑序，根节点初始化随机点，其余节点用 8 类函数族（线性、MLP、树、离散化、二次、聚类、GP、乘积）与合并方式（拼接 / 加 / 乘 / max）组合父节点输出。
  4. **读出**：新增**分布化数值转换器**——用位置、噪声尺度、子群概率三个通道控制采样：
     - 子群指示 `g ~ Bernoulli(σ(z₂))`；
     - 隐值 `η = √w(z₀ + δg) + √(1−w)·e^{γz₁−γ²/2}·ε`；
     - 观测值 `v = cη`（恒等链接）或 `v = cσ(aη + b)`（logistic 链接），并以 0.3 概率取整为计数；
     - 约 10% 的数值列使用该转换器，可产生行相关噪声、隐子群、有界值、计数值。
  5. **后处理**：裁剪离群、标准化、打乱行列、置换类别编码；新增
     - **相关特征块**（30% 的表）：`x ↦ (1−ρ)x + ρz`，类别按共享因子重排以保持频次；
     - **现实增强**（阶段 2/3）：target 重标定（仅依赖少数特征）、特征粗化（2–8 级）、高基数编码（>200 类）、重尾回归 target（仅阶段 3）、argmax 类别；
     - **缺失值模式**：结构化缺失（行丢弃、块掩码、target 依赖、类别掩码、截断）、完全随机缺失、近空列族、隐因子驱动缺失；约 21%（阶段 1）/27%（阶段 2/3）的表含缺失。
  6. **可学习性

6. **可学习性过滤**：对每张生成的表做“是否可学”的检验——用轻量探针（如小型 GBDT 或线性模型）在训练行上拟合、在验证行上评估，剔除标签纯噪声、信号过弱或验证集上不可泛化的表；同时剔除 target 与特征无任何因果路径的图。该步骤显著提升预训练信号密度，避免模型在“不可学任务”上浪费容量。
7. **难度与多样性控制**：按表形状、列类型比例、图密度、缺失率、机制复杂度分层采样，保证课程覆盖从“小宽表”到“大长表”、从线性可加到高度非线性的连续谱；并对分类类别数、回归 target 分布形态做均衡。

### 2.4 预训练策略

- **三阶段课程**：
  - **阶段 1（基础先验）**：中等规模表、以独立机制为主，教模型掌握单列/少列依赖、缺失值处理与基本 ICL 行为；
  - **阶段 2（复杂结构）**：引入相关特征块、现实增强、结构化缺失，表更长更宽，强化多列交互与噪声鲁棒性；
  - **阶段 3（极端场景）**：重尾回归 target、高基数类别、argmax 类别、近空列族，专门覆盖工业表的“脏、宽、偏”情形。
- **目标函数**：分类用交叉熵（多子任务时对各 10 类子任务分别计损失再聚合）；回归用分位数损失（999 个分位点，覆盖完整条件分布，支持点预测与区间预测）。
- **优化细节**：BF16/FP16 混合精度；权重衰减对注意力尺度参数单独约束；长序列采用分块/梯度检查点以控制显存；训练表长度与宽度按课程逐步增长（长度外推能力的来源之一）。
- **规模**：S / M / L 三档共享架构与先验，仅层数、宽度、ICL 深度不同，形成“精度—成本”可选的模型族。

### 2.5 推理与效率设计

- **单次前向、零训练**：测试表直接拼接训练行作为上下文，无需梯度更新；训练行 KV 可跨测试行复用/缓存。
- **缓存友好**：ICL Transformer 中训练行之间互相可见、测试行只读训练行，因此训练行 KV 只需计算一次；配合 Test-GQA，KV 缓存显著缩小，使大上下文（数十万行）在单卡上可行。
- **列注意力线性复杂度**：诱导点使列注意力对行数线性，避免 O(n²) 的行内全注意力，是支撑大表的关键。
- **ECOC 多分类**：类别数 >10 时拆为多个 10 类子任务并行打分，再用纠错输出码解码，兼顾头维度固定与多类精度。
- **批处理与分块**：测试行按块前向，训练行编码一次复用；对超宽表按特征分组处理以控制显存峰值。

## 三、实验与结果

### 3.1 评测设置

- **基准**：覆盖分类与回归的主流表格基准（如 TabArena / TALENT 类聚合基准、OpenML 表、以及工业风格的大表/宽表/含缺失表）。
- **对比对象**：梯度提升树（XGBoost、LightGBM、CatBoost）及其 AutoML 集成；已有 TFM（TabPFN 系列、TabICL / TabICLv2、其他开源表格基础模型）。
- **指标**：分类用准确率/AUC，回归用 R²/归一化误差；同时报告推理时延、显存占用、吞吐，以及“相对 GBDT 的胜率”和“调参预算下的对比”。

### 3.2 主要发现（按论文主张归纳）

- **精度**：Kumo Tabular 在多数基准上达到或超过强 GBDT 基线，且在中等规模表上以零样本方式接近“逐表调参 + AutoML”的水平；相对 TabPFN 类方法在更大表、更多列、含缺失与高基数类别场景优势更明显。
- **效率**：受益于诱导点列注意力、Test-GQA 与 KV 缓存，L 档模型在大上下文下的时延与显存显著低于同等精度的对照 TFM；相比 GBDT 流水线省去调参与特征工程开销，端到端“到手即用”成本更低。
- **规模外推**：随行数/列数增长，精度衰减更平缓；长度感知注意力温度被证明是长表稳定的关键。
- **消融要点**：
  - 列/行注意力**交替**优于分段式（最大架构收益）；
  - 长度感知温度 + QK-norm + SSMax 是训练稳定与混合精度可行的必要条件，去掉后长训练出现注意力尺度爆炸与梯度尖峰；
  - 分布化数值转换器、相关特征块、结构化缺失对真实表精度有稳定增益；
  - Test-GQA 在几乎不损精度的前提下大幅压缩缓存，使更深 ICL 成为可能。

### 3.3 局限与讨论（客观评述）

- **上下文成本**：ICL 精度依赖训练行作为上下文，超大表仍需采样/分块，存在“用多少行”的权衡；上下文越长，单次前向成本越高。
- **先验依赖**：性能受预训练先验覆盖度影响，极端领域（特殊物理约束、强时序结构、图/文本混合表）可能仍逊于定制模型。
- **回归头设计**：999 分位点的输出维度较大，对极端重尾 target 的尾部刻画仍有限。
- **对比公平性**：与 AutoML/GBDT 的对比受调参预算、时间预算影响，论文需明确预算设定才能支撑“同时最准最快”的强主张。
- **可解释性**：ICL 预测的归因仍弱于树模型的成熟解释工具，工业落地需额外解释层。

## 四、结论与意义

- **核心贡献**：提出完全开源的表格基础模型族 Kumo Tabular，通过“交替列/行注意力 + 诱导点 + Test-GQA + 长度感知温度 + 分布化先验”的组合，在零样本 ICL 下同时推进精度与效率边界，系统性回答“能否又准又快”。
- **方法论价值**：
  - 把“训练稳定性”作为一等公民（QK-norm、SSMax、尺度权重衰减），使大模型长训练在混合精度下可行；
  - 用诱导点将列注意力对行数线性化，用 Test-GQA 压缩 ICL 缓存，形成可扩展的效率路径；
  - 先验生成从“结构因果 + 机制多样”走向“分布化读出 + 现实增强”，更贴近工业表的噪声与缺失形态。
- **实践意义**：对缺少 ML 工程资源的中小团队，“一张表 + 一次前向”即可获得接近调参 GBDT 的效果，降低表格建模门槛；开源属性利于复现与二次开发。
