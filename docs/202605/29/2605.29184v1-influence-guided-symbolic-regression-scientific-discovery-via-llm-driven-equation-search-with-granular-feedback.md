## 摘要
大型语言模型为科学发现提供了有前景的途径，但其在符号回归中的应用常受限于低效的搜索策略和粗糙的反馈信号。当前方法通常使用标量度量（如全局均方误差）引导LLM，这无法识别所提出方程中哪些成分驱动性能或导致错误。我们提出影响引导的符号回归（IGSR），该方法将方程发现建模为一个迭代的两步过程，结合多样化项生成与严格选择：LLM为线性模型生成候选基函数ψ_j(x)，随后使用细粒度影响分数Δ_j进行评估。这些分数量化了每项对泛化准确率的边际贡献，从而能够进行影响引导的剪枝过程，系统地优化模型结构。将该机制集成到蒙特卡洛树搜索中，可以在导航组合搜索空间的同时平衡对新函数形式的探索与高影响成分的利用。我们在多个基准测试上展示了IGSR的有效性，包括LLM-SRBench、药代动力学PKPD模型、流行病学模拟以及真实世界基因组数据。值得注意的是，我们使用高维生物数据集在案例研究中验证了该框架的真正发现能力：IGSR识别出DNA甲基化与RNA聚合酶II暂停之间的新型关系，该假设随后通过湿实验得到了支持。

## Abstract
Large Language Models (LLMs) offer a promising avenue for scientific discovery, yet their application to symbolic regression is often constrained by inefficient search strategies and coarse feedback signals. Current methods typically guide LLMs using scalar metrics (e.g., global Mean Squared Error), which fail to identify which components of a proposed equation are driving performance or causing error. We introduce \textit{Influence-Guided Symbolic Regression} (IGSR), a method that frames equation discovery as an iterative two-step process combining diverse term generation with rigorous selection: an LLM generates candidate basis functions $ψ_j(\mathbf{x})$ for a linear model, which are then evaluated using granular influence scores $Δ_j$. These scores quantify each term's marginal contribution to generalization accuracy, enabling an influence-guided pruning process that systematically refines the model structure. Integrating this mechanism into a Monte Carlo Tree Search (MCTS) enables navigating the combinatorial search space while balancing exploration of novel functional forms with exploitation of high-influence components. We demonstrate IGSR's effectiveness on a diverse suite of benchmarks, including LLM-SRBench, pharmacological PKPD models, an epidemiological simulation, and real-world genomic data. Notably, we validate the framework's capacity for genuine discovery in a case study using a high-dimensional biological dataset, in which IGSR identified a novel relationship between DNA methylation and RNA Polymerase II pausing; a hypothesis that was subsequently supported via wet-lab experimentation.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- 将方程发现建模为**迭代的“提出-剪枝”循环**（propose-and-prune cycle）。
- LLM（“Propose” Agent）根据问题描述、当前项集合、历史决策等上下文，生成候选基函数 \(\psi_j(\mathbf{x})\)。
- 这些基函数被组合成一个线性模型 \(f(\mathbf{x}) = \sum_j w_j \psi_j(\mathbf{x})\)，用普通最小二乘法（OLS）拟合权重 \(w_j\)。
- **细粒度反馈**：在验证集上计算每项的影响力分数 \(\Delta_j\)，定义为将该项删除（置 \(w_j=0\)）后验证MSE的增加量。\(\Delta_j\) 直接量化了该项对泛化精度的边际贡献。
- **确定性剪枝**（默认）：按 \(\Delta_j\) 降序保留前 \(K\) 个项（\(K=6\)），避免LLM在剪枝阶段产生幻觉。
- 也可使用**代理剪枝**（IGSR-Agent）：第二个LLM根据 \(\Delta_j\) 和语义推理进行取舍。

### 2.2 搜索策略
- 将“提出-剪枝”循环嵌入**蒙特卡洛树搜索**（MCTS）中。每个节点代表一个方程状态，边代表由一次“提出-剪枝”循环产生的转换。
- MCTS使用UCT（Upper Confidence Bound for Trees）平衡探索与开发。
- 每个节点的即时奖励 = -验证MSE，直接反向传播（启发式MCTS，默认无深度rollout）。
- 默认预算：30次节点扩展，每节点5个后继，探索常数 \(c=\sqrt{2}\)。

### 2.3 关键算法流程
```text
1. 初始化根节点（空方程状态）。
2. 循环直到总扩展数达到预算：
   - 用UCT选择叶子节点。
   - 从该节点生成多个子节点（通过LLM提出新项，拟合线性模型，计算Δ_j，剪枝保留top-K项）。
   - 计算子节点的验证MSE作为奖励，反向传播更新树中节点统计。
3. 输出整个搜索过程中验证MSE最低的方程。
```

## 5. 实验数量与充分性

- **主要基准**：在6个数据集上，IGSR和IGSR-Agent各运行25个随机种子，95%置信区间报告。与10种以上基线方法对比。
- **LLM-SRBench**：128个问题×5种子，GPT-4o-mini LLM，固定300k token预算。
- **消融研究**：
  - 影响力反馈 vs 基本反馈（标量MSE）的对比。
  - MCTS vs 无MCTS（仅线性迭代）的对比。
  - 确定性剪枝 vs 代理剪枝的对比。
  - MCTS rollout深度的探究（0,1,2）。
  - 提出项数量（1,3,5,10,20）的影响。
  - 提示变化（默认 vs 简化）的影响。
  - LLM敏感性：使用9种不同LLM（含开源模型）。
  - 干扰特征鲁棒性：添加5~150个无关特征。
  - 合成模型基准：5种具有新结构（三角函数、除法、交互项）的模型。
  - 外推泛化：跨生物重复的RNA聚合酶数据集。
  - 嵌套验证分析：分离影响力计算与MCTS奖励的验证集。
  - 影响力分数变体对比（no-refit vs refit-aware）。
- **稳定性分析**：25个种子上方程结构的Jaccard相似度分析。
- **因果发现验证**：湿实验验证DNA甲基化假设（10种子重复、独立生物重复、随机100特征子集）。

**评价**：实验非常充分且客观。覆盖多种科学领域（生物、医学、流行病学、基因组学）、多种模型范式（白盒/黑盒/AFE/神经符号）、多种搜索机制。消融实验系统性地剖析了每个组件的贡献。统计报告规范（均值±95% CI，种子数足够）。LLM-SRBench确保了公平计算预算。案例研究提供了真实的科学发现验证。

## 6. 论文的主要结论与发现

- **性能优势**：在6种生物/临床基准上，IGSR在可解释模型中排名第一（平均排名1.17），显著优于SINDy、GPLearn、PySR及所有LLM基线。
- **LLM-SRBench**：IGSR在ID和OOD预测性能上均取得最佳平均排名，象征恢复指标也领先。
- **消融证实**：影响力反馈和MCTS两者都不可或缺。移除任一都会导致MSE大幅上升（从0.000787升至0.293或0.626）。
- **稳定性**：在已知真值（肺癌PKPD）的25个种子上，核心机制项（4个主要项）被≥80%种子恢复，交叉种子间Jaccard相似度均值0.65。
- **计算效率**：随特征数从10增至263，运行时间仅增加约25%（亚线性扩展），峰值内存<3GB。
- **真正科学发现**：IGSR在高维RNA聚合酶暂停数据中提出“DNA甲基化抑制转录暂停”的新假设，后续湿实验（5-azacytidine处理）证实该假设（暂停频率和强度显著增加，Wilcoxon p<10⁻³³）。

## 7. 优点

- **细粒度反馈创新**：引入每项影响力分数 \(\Delta_j\)，从根本上改善LLM的搜索指导，从全局标量转向结构感知，是核心概念贡献。
- **解耦生成与选择**：LLM负责创造性提出候选项，数据驱动的影响力分数负责严格筛选，有效避免LLM幻觉和无效搜索。
- **高效的搜索集成**：MCTS与“提出-剪枝”循环巧妙结合，平衡探索-利用，收敛速度快于传统遗传编程。
- **鲁棒性与可扩展性**：对干扰特征、不同LLM骨干、提示变化均表现稳定；在263维特征空间仍保持低内存和亚线性时间。
- **完整的科学发现循环**：从数据→模型→假设→湿实验验证，展示了AI从“预测”到“发现”的跃升，是论文的重要亮点。
- **透明度与可复现性**：开源代码、默认超参数、详细附录（含完整提示模板、消融设置），便于复现与扩展。

## 8. 不足与局限

- **LLM先验依赖**：发现能力受限于LLM的预训练分布；若所需函数形式完全不在LLM知识范围内，系统可能无法提出。
- **模型结构限制**：假设目标形式为 \(f(\mathbf{x}) = \sum w_j \psi_j(\mathbf{x})\)，无法直接发现深度嵌套的非线性动力系统（如全连接神经网络）。IGSR-TLO变体部分缓解但仍有局限。
- **优化目标单一**：当前仅优化验证MSE，未显式纳入稀疏性惩罚或复杂度权衡。作者承认未来可考虑多目标优化帕累托前沿。
- **计算成本**：尽管运行时间可接受，但LLM API调用仍是主要开销（每运行约1.87美元、约27万token）。对于需要大量种子或超大规模问题的场景成本可能较高。
- **湿实验验证的局限性**：案例研究中的湿实验只验证了DNA甲基化暂停抑制这一特定假设，方法在其他领域的发现能力尚需更多独立验证。
- **实验覆盖**：虽然基准数据集多样，但主要集中于生物医学领域（PKPD、流行病、基因组）。在物理、化学、材料等更广泛领域的表现仍需进一步测试（LLM-SRBench已有部分覆盖，但象征恢复指标在材料科学中较低）。
- **偏见风险**：LLM可能引入训练语料中的偏见，需要用户在敏感领域谨慎解读被发现的方程（特别是医疗/政策相关）。作者强调应视其为候选假设而非已验证的因果定律。
