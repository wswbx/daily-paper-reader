## 摘要
许多化学工程系统受跨运行机制切换的机制支配，因此数据驱动的依赖于运行机制的控制方程的发现对于预测建模、优化和控制至关重要。我们提出了用于数据驱动的依赖于运行机制的控制方程发现的符号决策树方法。该方法同时学习可解释的分裂条件以划分输入域，以及描述每个运行机制的局部控制方程。为了提高可处理性，分裂条件和控制方程均使用基函数参数化，从而产生一个混合整数优化学习问题。我们使用所提出的方法学习混合动力模型以及聚合物熔体零剪切粘度的本构方程。与学习单个全局模型或使用现有决策树模型的方法相比，符号决策树识别出物理上可解释的运行机制和局部控制方程，同时提高了预测准确性。该框架为发现化学工程系统中依赖于运行机制的模型提供了一种可解释且可推广的途径。

## Abstract
Many chemical engineering systems are governed by mechanisms that switch across operating regimes, making the data-driven discovery of regime-dependent governing equations essential for predictive modeling, optimization, and control. We propose symbolic decision trees for the data-driven discovery of regime-dependent governing equations. The method simultaneously learns interpretable splitting conditions to partition the input domain and local governing equations that describe each regime. To improve tractability, both the splitting conditions and governing equations are parametrized using basis functions, resulting in a mixed-integer optimization learning problem. We use the proposed approach to learn hybrid dynamical models and a constitutive equation for the zero-shear viscosity of polymer melts. Symbolic decision trees identify physically interpretable regimes and local governing equations while improving predictive accuracy relative to approaches that learn a single global model or use existing decision tree models. This framework provides an interpretable and generalizable route for discovering regime-dependent models in chemical engineering systems.

## 1. 核心问题与整体含义（研究动机和背景）
许多化学工程系统（如反应器、聚合物材料）的行为依赖于运行机制的切换，例如流动机制变化、生化网络激活/去激活、模型预测控制（MPC）定律随约束条件变化。传统的模型发现方法（如稀疏回归、符号回归、混合建模）只能学习单个全局模型，无法同时识别不同机制的逻辑划分和各区间的局部方程。现有应对方法存在不足：深度学习缺乏可解释性；两步聚类法将分区和模型学习分离，导致分区不是针对模型准确性优化的；遗传编程虽然通用但计算昂贵且无法保证最优性。

因此，本文提出一种**符号决策树（Symbolic Decision Tree）**框架，能够同时学习可解释的分裂条件（划分输入域）和局部控制方程（描述每个机制），将问题转化为混合整数线性规划（MILP），从而获得可解释、可泛化的机制依赖模型。

## 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：使用决策树表示分段模型。每个内部节点包含一个非线性分裂条件（基函数线性组合），每个叶节点包含一个局部非线性方程（基函数线性组合）。通过二元变量控制节点类型、数据分配、特征选择等，形成MILP。
- **技术细节**：
  - **树结构约束**：定义二元变量 $d_n$ 表示节点 $n$ 是否为分支节点；强制根节点为分支节点，叶节点不可有子节点。
  - **数据分配**：二元变量 $z_{in}$ 表示数据点 $i$ 是否分配到节点 $n$；约束确保每个数据点只被分配到一个叶节点，且只能分配到分支节点的子孙节点。
  - **分裂逻辑**：分裂条件为 $\sum_k a_{nk}\phi_k(x) < b_n$ 或 $\ge b_n$，基函数 $\phi_k$ 预先定义。引入二元变量 $\omega_{nk}$ 控制特征选择，并限制非分支节点特征系数为零。
  - **路由约束**：若数据点分配到叶节点，则必须满足该路径上所有分裂条件，采用大M法线性化。
  - **输出计算**：叶节点预测值为 $\hat{y}_{in} = \sum_k c_{kn}\phi_k(x_i)$，整体预测 $y_i^{\text{pred}} = \sum_n z_{in}\hat{y}_{in}$，通过线性化处理双线性项。
  - **复杂度控制**：设置最大特征数 $N_B$（分裂）和 $N_F$（叶节点）。
  - **学习目标**：最小化三个目标之和——预测误差（MAE）、树复杂度（分支节点数）、系数绝对值之和。通过权重 $\lambda_c, \lambda_m$ 平衡。
- **求解**：使用Gurobi等MILP求解器，可扩展到分类任务。

## 7. 优点
- **同时性和可解释性**：首次将分裂条件和局部方程一起学习，且使用基函数保持可解释性。

- **通用性**：可扩展至分类任务，适用于化工、材料、控制等领域。
- **正则化控制**：通过树复杂度项和系数范数项防止过拟合。
