## 摘要
基于大语言模型（LLM）的用户模拟可支持界面设计、无障碍研究和交互式智能体评估，但标准的计算机使用智能体针对任务完成进行优化，而非复现人类感知、推理和行动的方式。我们提出 COGENT（COGnitive agENT），一种用于模拟用户与桌面界面交互的模块化认知架构。COGENT 借鉴 Norman 的行动周期和 ACT-R 等成熟认知理论，通过将模拟过程分解为具有显式感知、记忆、用户状态、意图和动作选择表示的认知模块，实现可解释、可干预且模块化的用户模拟。我们首先展示六项可干预性演示，每项演示追踪对记忆、用户属性或处理模块的一次单独编辑如何沿认知流水线传播并产生行为变化。我们在 AgentNetBench、A11y-CUA 和 SENSE-42 三个基准上评估 COGENT 的行为保真度和归因保真度，发现其在复现记录的人类行为方面相较计算机使用基线取得统计显著更高的保真度提升，并恢复了人类自我报告心理状态之间的关系结构。这些演示和评估共同表明，COGENT 有助于实现更忠实、可解释、可干预且模块化的基于 LLM 的认知模拟。

## Abstract
LLM-based user simulation can support interface design, accessibility research, and interactive-agent evaluation, but standard computer-use agents are optimized for task completion rather than reproducing how people perceive, reason, and act. We introduce COGENT (COGnitive agENT), a modular cognitive architecture for simulating user interaction with desktop interfaces. COGENT draws on established cognitive theories, such as Norman's action cycle and ACT-R, to enable explainable, intervenable, and modular user simulation by decomposing the simulation process into cognitive modules with explicit representations of perception, memory, user state, intentions, and action selection. We begin by presenting six intervenability demonstrations, each tracing how a single edit to memory, a user attribute, or a processing module propagates through the cognitive pipeline to produce a behavioral change. We evaluate COGENT's behavioral and attributional fidelity across three benchmarks -- AgentNetBench, A11y-CUA, and SENSE-42 -- finding that it achieves statistically significant fidelity gains over computer-use baselines in reproducing recorded human behavior and recovers the relational structure among human self-reported psychological states. Together, these demos and evaluations demonstrate COGENT's utility toward more faithful, explainable, intervenable, and modular LLM-based cognitive simulations.

# COGENT 论文结构化总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：基于 LLM 的用户模拟被广泛用于界面设计、无障碍研究、交互式智能体评估，商业平台（Aaru、Simile、Viewpoints.ai 等）与学术工作（合成问卷受访者、经济主体、社交智能体）都在用 LLM 模拟人。
- **核心问题**：标准计算机使用智能体（CUA）为**任务完成**优化，而非复现人**如何**感知、推理、行动。人可以通过不同路径达成同一结果（有人凭记忆走捷径、有人搜索可见控件、有人失败后求助），这些选择取决于注意、知识、解释与状态变化——而 CUA 把"路线"留作未建模。
- **关键论点**：
  - 到达目标 ≠ 像用户一样行为；对界面研究和认知科学而言，**路线本身就是研究对象**。
  - 提示词式 persona 无机制可研究：让模型"表现出沮丧"只会产生报告沮丧的文本，没有任何东西把报告与行为连接起来（引 Goldenberg & Gross 对情绪的功能性定义）。
  - 单体提示词没有可干预的位置、没有可检查的中间表示、无法把行为变化归因到特定假设。
  - **结论：用户模拟需要的是架构，而不是更长的 persona。**
- **整体含义**：提出 COGENT（COGnitive agENT），将模拟过程分解为带显式表示（感知、记忆、用户状态、意图、动作选择）的认知模块，追求**可解释、可干预、模块化**的用户模拟。

## 2. 方法论：核心思想与关键技术细节

### 2.1 设计原则
- **可解释性**：下游模块以可追踪方式使用上游产物，把模型假设与行为连接。
- **可干预性**：可编辑记忆、配置属性、替换处理模块，并检查后果。
- **模块化**：由具有声明接口的可复用组件组装用户（借鉴 Concordia 等组件化生成式模拟系统）。

### 2.2 理论来源
- **ACT-R**：专门化过程通过显式表示（缓冲区）交换信息 → 动机是分离"注意、记忆、解释、选择、执行"并给它们显式交互表示。
- **Norman 行动周期**：意图形成 → 动作指定与执行 → 感知、解释、评估后果 → 组织五模块的循环结构。

### 2.3 五模块处理循环
1. **Observation**：捕获界面截图（每周期一帧不可变图像）。
2. **Cognition**：
   - *Perception*：识别被注意到的区域与线索，产生主观视觉工作区（含掩码图像、P# 区域、O# 状态线索）。
   - *Retrieval*：依据感知证据与用户上下文激活长时记忆条目（必须指向已存在条目；空存储则无召回）。
   - *Comprehension*：整合主观感知、回忆、近期经验，构建**情境模型**（situation model），并解释上一动作的效果。
3. **Control**：
   - *Monitor*：依据主观证据判断会话目标是否完成。
   - *Appraise*：依据评价理论（Scherer）更新动态状态（特质固定、状态可变）。
   - *Executive*：维持/修正中间意图，或选择休息、求助（ask_help）、放弃（give_up）等元动作。
4. **Action Reasoning**：从三类来源生成候选——**回忆的可执行程序、被注意到的界面控件、试探性探索**；每个候选保留来源、支持证据与预期结果；选择后提交一个原子动作意图。
5. **Execution**：grounding 组件在原截图上定位已选指称（仅限定位，不得改变操作与载荷），随后由（可替换的）运动组件派发鼠标/键盘输入；下一次观察提供反馈。

### 2.4 三个共享存储（跨周期连续性）
- **Memory**：长时事实、程序、经验摘要 + 有界工作记忆（受工作记忆容量理论启发）。
- **Situation model**：用户对"正在发生什么"的当前解释（可与可观察显示相区分）。
- **User attributes**：稳定特质 + 动态状态，每项含"含义 + 取值"。

### 2.5 信息边界（关键技术细节）
- 每个过程只接收"前序阶段输出 + 为其角色声明的共享存储信息"。
- 下游模块中**仅 Execution 可见原始截图**，且只用于定位已选指称；程序化检查拒绝改变操作与载荷。
- 该边界使干预的下游路径可追踪，同时把"选择什么"与"物理上如何落地"分离。
- 实现上通过**类型化记录（typed records）+ LLM 支撑的操作**落地；检索为空、无动态状态时的评价、单候选选择、键盘操作等会跳过模型调用。

### 2.6 评价指标（公式文字说明）
- **Jensen–Shannon 距离**：对池化后的智能体/人类八类动作计数归一化后计算 JS 距离，衡量动作类型分布相似性。
- **序列距离**：对智能体与人类序列的公共前缀计算归一化 Levenshtein 距离 `d_seq = Lev(x_{1:L}, y_{1:L}) / L`（L 为两者较短长度）。
- **人类归一化差距 HNG**：`HNG_{a,t} = D^{AH}_{a,t} / (D^{HH}_t + 1e-6)`，即以任务内人类—人类平均分歧为尺度归一化；值为 1 表示与人类间分歧相当。
- **属性关系**：21 对属性相关性的秩一致性（Spearman ρs）、幅度误差（MAE）、属性标签置换检验。

## 6. 主要结论与发现

### 6.1 行为保真度
- **AgentNetBench**：精确动作一致率 **59.8%**（CUA 52.2%、CUA-USER 53.7%）；动作类型准确率 **84.1%**（79.0%、80.9%）；池化 JS 距离 **0.0445**（0.1252、0.1210）。四项增益均统计显著（配对增益 +6.04 点，95% CI [2.99, 9.20]）。
- **A11y-CUA**：池化 JS 距离 **0.272**（CUA 0.370、CUA-USER 0.418、CUA-User-CB 0.389），全部显著更低；序列距离 **0.511**（0.595、0.612）显著更低；但 **CUA-User-CB 的序列距离 0.532 与 COGENT 无显著差异**；HNG 归一化后差异**不显著**（均值均 >1，即智能体—人类分歧仍远大于人类—人类分歧）。
- **替代动作子集**："任一可行动作"准确率三者接近（61.0/61.0/57.3），与"记录的人类选择"一致率 COGENT 32.0% vs CUA 18.0%，但置信区间均跨零，**结论不确定**。

### 6.2 归因保真度（SENSE-42）
- 21 对属性关系的**排序**与人类高度一致：**ρs = 0.860**（置换检验 p = 0.000397），任务均值层面 ρs = 0.830。
- 但**幅度未校准**：相关系数 MAE = 0.397。
- **属性—行为关联失败**：时间需求—模态切换在人类为 β = −0.135（显著），智能体为 +0.078（方向相反）；努力—单位决策数人类 +0.110（显著），智能体 +0.137（同向但不显著）。即"属性如何共变"比"属性如何关联行为"更容易复现。

### 6.3 模块编辑（附录 D）
- **界面候选受限**：精确率降至 53.11%（−4.21 点，pH = .010），类型准确率 −5.36 点，且无效输出率上升 7.24 点——损失主要来自**预测可靠性**而非保真度。
- **移除滞后反馈评估**：精确率降至 53.63%（−3.69 点，pH = .010）；223 个丢失的精确匹配中 106 个是**人类停止决策**。
- 全屏视觉访问、无记忆、目标级控制：**均无显著变化**。

## 7. 优点（方法与实验设计亮点）

- **架构层面的可干预性**：把记忆、属性、处理模块暴露为三个独立干预点，并用类型化记录把"一次编辑"与"行为差异"连接，这是提示词 persona 无法提供的。
- **理论落地清晰**：ACT-R 的缓冲区思想 + Norman 行动周期被具体化为五模块、三存储、明确接口，附录 A 详述理论动机与信息边界。
- **干预演示设计精巧**：六组配对覆盖三类干预，并保留"执行坐标落在 Browser 命中框"这类**模型叙述与执行行为不一致**的证据，说明作者以实际执行结果而非模型文本为准。
- **多层面保真度评估**：下一步预测（固定状态）、实时轨迹（含自身后果）、内部状态关系三层互补；区分"与记录人类选择一致"和"与任一可行动作一致"。
- **诚实的负面结果**：明确报告 HNG 不显著、属性幅度未校准、属性—行为关联失败，并讨论其含义。
- **统计规范**：配对任务 bootstrap、Holm 校正、分层重采样、置换检验、敏感性分析（适配器错误、前 11 块截断）。

## 8. 不足与局限

### 8.1 实验覆盖
- **单一模型家族**（GPT-5.4），未验证跨模型/跨提示的稳健性。
- **任务与人群有限**：A11y-CUA
