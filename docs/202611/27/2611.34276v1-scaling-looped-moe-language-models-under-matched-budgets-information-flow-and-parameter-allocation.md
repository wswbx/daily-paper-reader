## 摘要
循环 Transformer 将计算深度与参数数量解耦，已有研究表明增加计算可带来有前景的性能提升。然而，在严格的等参数和等 FLOP 约束下配置这些模型的系统性设计原则仍然匮乏。我们通过改进循环模型中的信息流并系统研究循环参数配置，为该方向做出贡献。具体而言，我们通过门控内循环状态更新和跨阶段残差连接来改进这一信息流。在此设计基础上，受控研究确定了一种配置：单次通过的 Core 深度为总展开深度的 25%-35%，并将节省的参数重新分配到每层额外的路由专家中，从而在零额外计算的情况下提升性能，同时保持与现有训练基础设施的兼容性。在 1T 预训练 token 后评估，我们的 69B MLA 和 51B KDA 混合专家模型在四个基准上分别平均优于预算匹配的非循环基线 1.16 和 2.29 个百分点。在具有 200B token 训练预算的通用骨干网络上进行的进一步复现实验表明，我们的方法相比其他循环方法实现了更低的困惑度。这些复现实验的代码可在 https://github.com/lxi01766/Scaling-Looped-MoE-Language-Models-under-Matched-Budgets-Information-Flow-and-Parameter-Allocation 获取。

## Abstract
Looped Transformers decouple computational depth from parameter count, and prior studies have demonstrated promising performance gains with increased computation. However, systematic design principles for configuring these models under strict iso-parameter and iso-FLOP constraints remain scarce. We contribute to this direction by improving information flow in looped models and systematically studying loop parameter configurations. Specifically, we refine this information flow via gated inner-loop state updates and a cross-stage residual connection. Building on this design, controlled studies identify a configuration combining a single-pass Core depth of 25%-35% of the total unrolled depth with reallocating saved parameters into extra routed experts per layer, improving performance at zero extra compute while preserving compatibility with existing training infrastructure. Evaluated after 1T pre-training tokens, our 69B MLA and 51B KDA Mixture-of-Experts models outperform budget-matched non-recurrent baselines by an average of 1.16 and 2.29 percentage points across four benchmarks, respectively. Further reproduction experiments on a common backbone with a 200B-token training budget show that our method achieves lower perplexity than other looped methods. Code for these reproduction experiments is available at https://github.com/lxi01766/Scaling-Looped-MoE-Language-Models-under-Matched-Budgets-Information-Flow-and-Parameter-Allocation.

## 1. 核心问题与研究动机

- **背景**：循环 Transformer（Looped Transformer）通过复用权重共享层，将"计算深度"与"参数量"解耦，是一种与常规参数扩展正交的深度扩展范式。已有工作（Huginn、Parcae、SMELT、SenseNova-Loop 等）表明增加循环计算可提升推理与算法归纳能力。
- **核心问题**：现有研究虽展示了循环架构的潜力，但在**严格的等参数（iso-parameter）与等 FLOP（iso-FLOP）约束**下，如何系统配置循环模型仍缺乏可复用的设计准则。作者将其拆解为两个子问题：
  - **循环内部信息流**：权重共享下，内循环状态更新与跨阶段表示传递应如何设计，才能实现有效的迭代精炼？
  - **循环配置与跨架构通用性**：等预算下循环结构如何划分、参数如何分配，且同一循环设计能否迁移到不同注意力骨干？
- **整体含义**：论文试图从"信息流设计"和"参数分配"两个耦合维度，为预算受限下循环式大模型提供可操作、可迁移的设计原则，而非仅报告单一模型的性能点。

## 2. 方法论

### 2.1 基础架构
- 沿用 **Prelude–Core–Coda 三阶段拓扑**：Prelude $P$ 提取初始表示，共享 Core $F_\omega$ 迭代 $R$ 次，Coda $C$ 映射到下一词预测。
- 前向流程：$e=P(\text{Embed}(x))$，$h_t=F_\omega(M(h_{t-1},e))$，$z=C(h_R)$，其中 $P,C$ 只执行一次，$F_\omega$ 参数 $\omega$ 跨 $R$ 次复用。

### 2.2 内循环状态更新（改进信息流）
- **直接首迭代输入**：对 Prelude 输出做 RMSNorm 得 $\tilde e=N_E(e)$，第一次迭代直接输入 Core：$h_1=F_\omega(\tilde e)$。相比 Huginn/Parcae 用高斯噪声初始化 $h_0$，避免了"同一保留系数既要抑制噪声又要保留语义轨迹"的优化冲突。
- **边界归一化**：对 $t\ge2$，先做迭代级 RMSNorm $N_{t-1}$ 对齐循环状态尺度，再与固定输入融合。
- **通道级门控融合**：$u_t=\alpha\odot N_{t-1}(h_{t-1})+\Delta\odot B(\tilde e)$，$h_t=F_\omega(u_t)$，其中 $B$ 为可学习投影。
- **保留/注入解耦参数化**：$\alpha=\exp(-\exp(\theta))$，$\Delta=\text{softplus}(b)$，$\theta,b$ 为独立可学习向量。
  - 与 Parcae 的 $\alpha=\exp(-\Delta\odot\exp(a))$ 相比：Parcae 中 $\partial\alpha_i/\partial\Delta_i<0$，注入增大会压制保留，产生梯度耦合；本文令 $\partial\alpha/\partial b=0$，二者可联合优化而不纠缠（本质是 $\theta=a+\log\Delta$ 的双射重参数化）。

### 2.3 跨阶段残差连接
- 边界归一化与门控融合虽稳定了尺度，却切断了 Prelude→Coda 的直接残差通路，迫使终态 $h_R$ 同时承担"多步精炼"和"保留低层表示"双重职责。
- 引入**无额外参数**的跨阶段残差：$z=C(e+h_R)$，将未归一化的 Prelude 输出直接加到最终循环状态，恢复直达梯度路径。

### 2.4 循环配置与参数分配原则
- 定义总展开深度 $D_{\text{total}}=L_{\text{pre}}+R\cdot L_{\text{core}}+L_{\text{coda}}$，Core 深度比 $\rho=L_{\text{core}}/D_{\text{total}}$。
- **原则一（循环 Core 配置）**：$R=2$，单次 Core 深度取总展开深度的 **25%–35%**，在"计算复用"与"独立边界层容量"间取得平衡。
- **原则二（参数到专家的再分配）**：将权重共享节省的参数转为**每层额外路由专家**（uniform layer-wise expert-pool expansion），保持隐维、注意力配置、单专家 FFN 宽度与激活专家数不变，实现零额外计算下的容量恢复，并兼容现有 kernel 实现。

## 6. 主要结论与发现

- **信息流设计有效**：门控内循环更新 + 跨阶段残差在消融中均带来稳定增益；去掉跨阶段残差验证损失从 1.8020 升至 1.8327，加性融合与拼接+随机初始化分别升至 1.8047、1.8101。
- **配置规律**：$R=2$ 优于更多循环次数（如 3+3 边界层时，$R$ 从 2 增至 7 使 $\rho$ 从 35% 降至 10%，loss 从 1.5603 升至 1.5684）；$\rho$ 从 5%→25%→35% 时 loss 从 1.5759 降至 1.5618/1.5603，但 45%

时 loss 回升（约 1.5620+ 量级），呈现"先降后升"的倒 U 形，支持 25%–35% 的推荐区间；循环次数继续增大（如 $R=7$）或 Core 过深都会稀释共享层的复用收益并挤压边界层容量。

- **参数恢复的必要性**：等参数约束下直接把权重共享省下的参数"还回去"并非最优；将其转为每层额外专家（Ours）在 20 个验证集上平均损失为三者最低，与 Depth–Width 重分配聚合差距仅 0.0007、任务级互有胜负，但无需改动隐维/注意力/专家宽度、可直接复用现有 MoE kernel，工程可落地性最好；Attn–FFN 重分配则明显落后。
- **恢复前后对比**：图 4 显示，未做恢复时循环模型随 $\rho$ 增大持续落后于非循环参考；加入专家池扩展后，各 $\rho$ 点的损失曲线整体下移并贴近甚至追平非循环基线，说明"共享省参数 + 专家补容量"是等预算下可行的组合范式。
- **主实验（1T token）**：69B MLA（4.37B 激活）与 51B KDA（3.24B 激活）在 MMLU/CMMLU/C-Eval/BBH 上均优于严格等参数、等 FLOP 的非循环配对基线，表明该循环设计在数十 B 级 MoE 上仍成立，而非仅在小模型上有效。
- **与 Parcae/SMELT 对比**：在 200B token、两检查点、两指标下，本文完整循环公式（首迭代直入 + 解耦门控 + 跨阶段残差）整体优于复现适配的 Parcae 与 SMELT，说明增益来自信息流设计的组合而非单一技巧。
- **跨骨干通用性**：同一循环配置在 MLA、KDA、GQA 与 mHC 四类骨干上均取得正收益；mHC+Loop 相对 mHC 非循环基线有提升，但该对比总参数不等（11.9B vs 14.5B），只能作为"架构兼容性"证据。
- **总体命题**：在等参数/等 FLOP 预算下，"少而深的共享 Core（$R=2$、$\rho\approx25\%$–35%）+ 解耦门控信息流 + 跨阶段残差 + 专家池扩容"构成一套可复用的循环式大模型配置准则。

- **对比公平性的细节**：Parcae/SMELT 为适配复现版，非原配置；mHC 对比未做参数恢复；恢复策略对比的性能差距在噪声量级，选择依据偏工程兼容性。这些都被作者部分承认，但削弱了"全面占优"的表述强度。
