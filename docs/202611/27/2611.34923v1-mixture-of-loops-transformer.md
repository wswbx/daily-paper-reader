## 摘要
循环 Transformer 通过在不同循环间复用共享层来提升表达能力，但代价是效率下降。要推进其表达能力与效率的前沿，需要重新思考连接相邻循环的核心机制：在 Transformer 的循环之间应传递什么？我们提出循环混合 Transformer（Mixture-of-Loops Transformer，MoLT），其循环混合注意力（Mixture-of-Loops Attention，MoLA）使用键和值（KV）作为记忆，以便跨深度和循环进行选择性复用。在循环残差方案下，MoLT-R 保留残差流，并跨循环读取局部 KV 以提升表达能力。在循环 KV 方案下，MoLT-KV 则从嵌入重新开始，并读取当前循环的局部 KV 以及更早位置上的前序循环记忆 KV，以提升效率。MoLT-KV 消除了同位置跨循环依赖，并结合用于并行训练的 loop forcing，解锁了超越训练循环范围的单次遍历循环混合（Mixture-of-Loops，MoL）解码。为平衡效率与质量，我们引入 U 形 MoLT（U-MoLT），它将记忆构建与预测读出分离，并在不改变预测的情况下跳过未使用的解码器遍历。在 400B token 预训练中，U-MoLT 在 700M/1.5B 稠密模型和 3B MoE 模型上均优于 OLMo3；在 700M 模型上实现 1.7 倍的验证交叉熵（CE）token 效率，同时将 3B MoE 的 10 领域困惑度改善 0.75，并将 10 任务准确率提升 2.1 个百分点。在 Qwen3.5-0.8B-Base 的 100B token 持续预训练中，我们的 U-MoLT 适配版本在全部 11 个领域上相较匹配基线降低了 CE，平均 token 效率为 1.4 倍。在推理时，采用 MoL-Hybrid-2 的 U-MoLT 在 S 规模（约 113M）模型上以 996.6 对 1,000.6 ms 的延迟与非循环 OLMo3 相当。代码见 https://github.com/hustvl/MoLT

## Abstract
Looped Transformers boost expressivity by reusing shared layers across loops, yet at the cost of efficiency. Pushing their expressivity-efficiency frontier requires rethinking the core mechanism connecting adjacent loops: What should be passed as a Transformer loops? We introduce Mixture-of-Loops Transformer (MoLT), whose Mixture-of-Loops Attention (MoLA) uses keys and values (KV) as memory for selective reuse across depths and loops. Under loop residual, MoLT-R retains the residual stream and reads local KV across loops for expressivity. Under loop KV, MoLT-KV instead restarts from embeddings and reads current-loop local KV with preceding-loop memory KV at earlier positions for efficiency. MoLT-KV eliminates same-position cross-loop dependence and, paired with loop forcing for parallel training, unlocks single-traversal Mixture-of-Loops (MoL) decoding beyond the training loop horizon. To balance efficiency and quality, we introduce U-shaped MoLT (U-MoLT), which separates memory construction from prediction readout and skips unused decoder traversals without changing predictions. In 400B-token pretraining, U-MoLT outperforms OLMo3 across 700M/1.5B dense and 3B MoE models, achieving 1.7x validation cross-entropy (CE) token efficiency at 700M while improving 3B MoE 10-domain perplexity by 0.75 and 10-task accuracy by 2.1 percentage points. In 100B-token continued pretraining of Qwen3.5-0.8B-Base, our U-MoLT adaptation lowers CE on all 11 domains over the matched baseline with 1.4x mean token efficiency. At inference, U-MoLT with MoL-Hybrid-2 matches non-looped OLMo3 latency at 996.6 vs. 1,000.6 ms on S-size (~113M) models. Code is available at https://github.com/hustvl/MoLT

# 《Mixture-of-Loops Transformer》论文结构化总结

## 1. 核心问题与整体含义

- **研究背景**：循环 Transformer（Looped Transformer）通过跨循环复用共享层参数来提升表达力，已成为前沿架构设计的重要方向（如 Universal Transformer、LoopLM 等）。但其代价是推理效率下降。
- **核心问题**：推进表达力—效率的前沿，需要重新思考连接相邻循环的核心机制——**循环之间到底应该传递什么？**
- **现有范式的瓶颈**：标准答案是"循环残差"（loop residual），即把每个循环的输出直接传入下一个循环。这一选择同时制约表达力与效率：
  - **表达力瓶颈**：反复把计算压缩进单一残差流，会造成跨层、跨循环的信息稀释与表征退化。
  - **效率瓶颈**：每个 token 依赖自身在前一循环的输出，推理必须逐循环串行执行。
- **论文主张**：不应仅依赖残差流，而应把计算出的**键值（KV）作为记忆**，在深度与循环间进行选择性复用。由此提出 **Mixture-of-Loops Transformer（MoLT）** 家族，并给出 MoLT-R、MoLT-KV、U-MoLT 三种变体，分别面向表达力、效率与二者平衡。

## 2. 方法论

### 2.1 核心思想：Mixture-of-Loops Attention（MoLA）

- MoLA 让每一层同时关注**序列 KV**（沿 token 位置）与**深度 KV**（同一 token 位置、不同层/不同循环的局部 KV），二者在**同一个 softmax 分布**中联合归一化（沿用 MoDA 的联合序列—深度归一化）。
- 查询来自当前层输入，键值来源由反馈接口决定；无额外的循环门控，查询权重决定各来源贡献。
- 关键技术细节：逐头仿射 RMS QK 归一化 + RoPE；深度 KV 保留写入者原有的归一化与旋转，读取者直接复用。

### 2.2 三种架构变体

**（a）MoLT-R：循环残差 + MoLA（偏表达力）**

- 保留残差流：循环 r 的初始状态为循环 r−1 的归一化输出 $z^{r-1}_t$（首循环为嵌入 $e(x_t)$）。
- 序列 KV：当前层输入 $X^{r,\ell}_j$（$j \le t$）的局部 KV。
- 深度 KV：当前循环更早层（$0 \le k < \ell$）的局部 KV，加上**前序循环全部层**的局部 KV（同 token 位置）。
- 更新式：$\hat X = X + \text{MoLA}(X, S_X, D^{<\ell}_{cur} \sqcup D_{prev})$，再经 FFN 与 Norm 输出 $z^r$。

**（b）MoLT-KV：循环 KV（偏效率）**

- **嵌入重启**：每个循环都从 $e(x_t)$ 重新开始，不携带前序残差状态。
- **严格前缀记忆 KV**：序列来源是前序循环归一化输出 $z^{r-1}_j$ 经逐层记忆投影得到的 KV，且仅限 $j < t$（排除对角线）。
- 深度 KV：仅当前循环内 $0 \le k \le \ell$ 的局部 KV（含自身 KV），为当前 token 提供同位置注意力路径。
- **关键性质**：嵌入重启 + 严格前缀掩码消除了**同位置跨循环依赖**，使每个反馈循环退化为沿 token 位置的严格三角递推 $z^r_t = F_t(x_t, z^{r-1}_{<t})$。

**（c）U-MoLT：记忆构建与预测读出分离（平衡效率与质量）**

- 受 YOCO / Universal YOCO / DeepSeek CED 启发，将循环 KV 栈作为 **MoLT Encoder**（$L_E$ 层），另设**因果、仅交叉的 MoLT Decoder**（$L_D$ 层）。
- 解码器从原始编码器输出 $Y^{r,0} = X^{r,L_E}$ 出发，通过**逐层独立的解码器 KV 投影**读取归一化编码器输出 $z^r$（$j \le t$）；反馈仅由编码器决定，解码器不参与循环反馈。
- 预测头接收解码器最终输出（U-MoLT）或循环原始输出（普通 MoLT）。

### 2.3 训练：Loop Forcing

- 多循环目标：对每个循环的下一 token 交叉熵加权求和 $L = \sum_{r=1}^{N} \alpha_r L_r$，$\alpha_r = w_r / \sum w_k$。
- **Loop forcing**：类比 teacher forcing，每个反馈循环从**前序循环的严格前缀记忆 KV** 并行训练，而非顺序解码的前缀，把训练从 T 个串行步骤降为 N 个并行 pass；支持开放或截断的跨循环梯度。
- 三项设计支撑记忆源迁移：共享读出监督（对齐 $z^1$ 与 $z^2$）、嵌入重启（锚定残差流）、输出与 QK 归一化（有界激活与 logits）。

### 2.4 推理：三种解码调度

- **Fixed-loop 解码**：每个 token 顺序执行 N 个循环，保留 N 份序列 KV 缓存。
- **Mixture-of-Loops（MoL）解码**：从空缓存逐 token 单次遍历共享栈，读取已缓存前缀记忆 KV + 当前循环局部 KV，并追加新记忆 KV；**首次实现超越训练循环视野的单次遍历循环解码**。
- **MoL-Hybrid 解码**：用 1 或 2 循环**并行 prefill** 初始化提示记忆 KV，随后每步单次遍历解码；兼顾并行 prefill 与低解码成本。
- 理论保证（附录 B）：Proposition 1 证明有限前缀稳定化（位置 t 在 $r \ge t+2$ 后收敛）；Corollary 1 证明空缓存 MoL 解码与任意 $r \ge t+2$ 展开等价；Corollary 2 给出 MoL-Hybrid 的提示条件稳定化；Proposition 2 证明 U-MoLT 可省略未使用的解码器遍历而不改变预测。
- 成本分析：等分 $L_E = L_D = L/2$ 时，MoL-Hybrid-2 的 U-MoLT 在 prefill 块深度、二次 prefill 注意力、每步解码遍历数、持久 KV 存储四项主导成本上均与无循环 L 层 Transformer 相当。
