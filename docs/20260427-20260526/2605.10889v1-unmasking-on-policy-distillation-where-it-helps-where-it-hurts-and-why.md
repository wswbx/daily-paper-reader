## 摘要
通策略蒸馏为训练推理模型提供了密集的逐令牌监督；然而，目前尚不清楚该信号在哪些条件下有益，在哪些条件下有害。应该使用哪个教师模型，在自蒸馏的情况下，哪个特定的上下文应作为监督信号？最佳选择是否因令牌而异？目前，解决这些问题通常需要代价高昂的训练过程，其聚合性能指标掩盖了单个令牌层面的动态。我们引入了一种无训练的诊断框架，以最高分辨率运行：每个令牌、每个问题、每个教师。我们推导出理想的每节点梯度，定义为最大化学生成功概率的参数更新。然后，我们开发了一种可扩展的目标 rollout 算法，以高效估计该梯度，即使对于长链中间思维也适用。梯度对齐分数定义为该理想梯度与任何给定蒸馏梯度之间的余弦相似度，量化了特定配置逼近理想信号的程度。在一系列自蒸馏设置和外部教师模型中，我们观察到在错误的 rollout 上，蒸馏指导与理想的对齐程度远高于正确的 rollout，而在正确 rollout 上学生已经表现良好，教师的信号往往变得嘈杂。此外，我们发现最佳蒸馏上下文同时依赖于学生模型的容量和目标任务，并且没有出现普遍有效的单一配置。这些发现激励了在蒸馏中使用逐任务、逐令牌的诊断分析。

## Abstract
On-policy distillation offers dense, per-token supervision for training reasoning models; however, it remains unclear under which conditions this signal is beneficial and under which it is detrimental. Which teacher model should be used, and in the case of self-distillation, which specific context should serve as the supervisory signal? Does the optimal choice vary from one token to the next? At present, addressing these questions typically requires costly training runs whose aggregate performance metrics obscure the dynamics at the level of individual tokens. We introduce a training-free diagnostic framework that operates at the highest resolution: per token, per question, and per teacher. We derive an ideal per-node gradient defined as the parameter update that maximally increases the student's probability of success. We then develop a scalable targeted-rollout algorithm to estimate this gradient efficiently, even for long chains of intermediate thoughts. The gradient alignment score, defined as the cosine similarity between this ideal gradient and any given distillation gradient, quantifies the extent to which a particular configuration approximates the ideal signal. Across a range of self-distillation settings and external teacher models, we observe that distillation guidance exhibits substantially higher alignment with the ideal on incorrect rollouts than on correct ones, where the student already performs well and the teacher's signal tends to become noisy. Furthermore, we find that the optimal distillation context depends jointly on the student model's capacity and the target task, and that no single universally effective configuration emerges. These findings motivate the use of per-task, per-token diagnostic analyses for distillation.

# 论文总结：Unmasking On-Policy Distillation: Where It Helps, Where It Hurts, and Why

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：通策略蒸馏（On-policy Distillation, OPD）已成为当前推理模型（如 Qwen3、MiMo、GLM-5）后训练的核心技术，通过教师模型在每个 token 上提供密集的监督信号以补充稀疏的外部奖励。然而，实践中面临一系列未解决的选择问题：教师应选用更大的外部模型还是自身（自蒸馏）？上下文应包含完整的推理轨迹还是精简摘要？不同问题甚至不同 token 之间最优选择是否变化？这些问题目前只能通过昂贵训练实验回答，且聚合性能指标掩盖了逐 token 的动态。
- **整体含义**：论文旨在建立一种无需训练的、高细粒度诊断框架，能够从每个 token、每个问题、每个教师配置的层面评估蒸馏信号的质量，从而揭示 OPD 在不同条件下的有效性和局限性。

## 2. 方法论

### 核心思想
- 定义**理想每节点梯度**：在每个 token 位置（节点 u），目标是最大化学生对此节点后成功概率的期望：`L_ideal(u) = Σ_k P_k^θ * P_k^succ`，其梯度为 `∂L_ideal/∂z_j = P_j^θ (P_j^succ - P̄_succ)`，其中 `P_j^succ` 是选择 token j 后成功的经验概率，`P̄_succ` 是期望成功率。
- **蒸馏梯度的统一形式**：分析了多种主流蒸馏目标（GKD、单样本 GKD 估计器、MiniLLM、Dr. GRPO）的梯度，发现它们都具有相同局部结构：`∂L/∂z_j = P_j^θ (f_j - f̄)`，其中 f_j 因方法而异（Dr. GRPO 中 f_j = P_j^succ；GKD 中 f_j = ±(log P_j^θ - log P_j^te)）。
- **梯度对齐分数（Gradient Alignment Score）**：定义为理想梯度与蒸馏梯度（如 GKD）之间的余弦相似度，范围 [-1, 1]。正值表示蒸馏梯度指向成功方向，负值表示有害，接近零表示无关（如风格差异）。

### 关键技术细节
- **生成树与经验成功概率**：通过学生模型生成 G 条 rollout，构建前缀树，每个节点统计各 token 的访问次数和后续成功比例，从而估计 `P_k^succ`。
- **Targeted-Rollout 算法**：解决稀疏性问题，对访问不足的 token 进行针对性补充采样。通过**指数深度窗口**（如 token 1–50, 51–150, 151–350…）分配预算，优先采样教师-学生差异大的 token（如 GKD 梯度模长、概率差），每个重要 token 补充至至少 100 次访问。
- **高效性**：生成树和成功概率估计与教师无关，可共享：一次 rollout 生成（Phase 1）后，每个教师只需一次前向传播（Phase 2）计算对齐分数，总计算量约为独立运行的 1/7。

## 3. 实验设计

### 数据集与任务场景
- **BoolQ**（阅读理解，短推理链，约 200 token）
- **MMLU**（多选知识，中等长度推理链）
- **AIME 2025**（数学竞赛，长推理链，约 5K–30K token）作为案例研究

### 模型
- 学生：Qwen3-0.6B、Qwen3-1.7B
- 教师配置（共 8 种）：
  - **自蒸馏**（学生自身作为教师，但上下文不同）：Self-1C（一条正确解答）、Self-Sum-1C（32B 模型摘要）、Self-1C1W（正确+错误解答）、Self-Sum-1C1W（两者摘要）、Self-1C (32B)（32B 生成正确解答）
  - **外部教师**（更大模型，相同 prompt）：Qwen3-4B、Qwen3-8B、Qwen3-14B

### 对比方法
- 未直接对比其他蒸馏算法，而是对比不同教师/上下文配置下梯度对齐分数的差异。
- 通过 oracle 分析（过滤掉负对齐的 token）评估选择性蒸馏的最大潜力。

### 评估指标
- 梯度对齐（平均余弦相似度）、教师优势（teacher advantage）、成功概率范围加权余弦、正对齐决策点比例、并行路径相关性

论文明确提到：

- 节点显著性要求：≥20 次访问（BoolQ/MMLU）或 ≥40 次（AIME）才纳入计算。

## 5. 实验数量与充分性

- **实验数量**：覆盖 2 个学生模型、8 种教师配置、2 个主要数据集 + 4 个 AIME 问题（案例）。BoolQ 和 MMLU 分别约 88K 和 49K 决策点（节点数），统计量丰富。
- **充分性**：
  - 完成了正确的 vs 错误路径对比、教师排名、消融（上下文、是否包含错误示例）、Oracle 分析（选择性蒸馏上限）。
  - 在 AIME 上验证了结论的迁移性（长序列）。
  - 进行了多种指标的稳定性检查（平均余弦、加权余弦、正对齐比例），多数结论一致。
- **客观性与公平性**：训练框架无训练，仅基于经验成功概率，避免训练偏差。教师配置均在同一生成树上评估，公平。不足：仅使用 Qwen3 系列模型，未覆盖其他架构（如 Llama、Mistral）；仅评估 GKD 梯度，未覆盖所有蒸馏方法（如 MiniLLM 虽推导但未实验）。

## 6. 主要结论与发现

1. **蒸馏在错误路径上更可靠**：在所有设置下，错误 rollout 上的梯度对齐显著高于正确 rollout（如 Qwen3-0.6B BoolQ：正确路径平均余弦 0.011 vs 错误 0.044）。教师信号在学生已成功的路径上变得嘈杂甚至有害。
2. **教师与上下文的选择取决于学生容量**：
   - 对小模型（0.6B），自蒸馏（尤其是正确仅示例）远超外部教师（因为难以理解外部推理风格）；对较大模型（1.7B），外部教师（Qwen3-8B）在 BoolQ 上优于自蒸馏。
   - 包含错误示例（1C1W）在简单任务（BoolQ/MMLU）上总是有害；但在硬数学（AIME）上反而最佳（提供对比信号）。
3. **无通用最佳配置**：最优教师随问题难度、学生容量变化，例如摘要帮助 1.7B 但有害 0.6B；外部教师对 1.7B BoolQ 好但对 MMLU 不好。
4. **分歧度可弱预测对齐**：学生-教师分布散度（KL/JS/L2）与对齐正相关，余弦相似度负相关，但频率绝对值很小（|ρ| < 0.05），仅可作为廉价必要非充分过滤。
5. **Oracle 分析**：若仅使用对齐>0 的 token（约 50% 节点），信号强度可提升 10–15 倍，且所有路径受益。

## 7. 优点

- **细粒度诊断**：首次实现逐 token 的蒸馏质量评估，解决了聚合指标隐藏的异质性。
- **无训练高效性**：无需昂贵训练，仅需学生 rollout 和教师前向传播，且树结构可复用。
- **理论统一框架**：揭示多种蒸馏目标共享相同的梯度结构，并建立与奖励模型（Dr. GRPO）的联系。
- **可扩展性**：targeted-rollout 算法使得该方法适用于长序列（AIME 30K token）。
- **实践指导价值**：为选择教师、上下文提供机制性解释（“可理解性”假说），并可指导设计更高效的蒸馏策略（如加权错误路径）。

## 8. 不足与局限

- **模型覆盖有限**：仅使用 Qwen3 系列（0.6B/1.7B/4B/8B/14B），未测试其他品牌模型，通用性受限。
- **方法覆盖有限**：实际仅用 GKD 梯度作为蒸馏信号进行对齐计算；虽然推导了 MiniLLM 的单样本估计器，但未在实验中对比，可能遗漏某些方法的特性。
- **评估指标单一**：对齐分数本身依赖经验成功概率估计，对于长序列或低采样次数节点，估计噪声较大（如 AIME 需要更严格阈值）。
- **计算成本仍较高**：每个问题需数万至数十万 rollout，72 A100-days 总量不低；论文明确表示更适合作为离线评估工具而非在线训练信号。
- **应用限制**：诊断框架要求学生 rollout 和教师前向，无法在 zero-shot 场景直接应用；也未探讨如何将诊断结果自动整合进训练 pipeline。
- **解释性局限**：对“可理解性”的假设（学生难以吸收风格差异大的教师信号）缺乏直接验证，仅从实验结果推断。
