## 摘要
基于LLM的SystemVerilog断言（SVA）生成常被报道接近饱和，最强专用模型在NL2SVA-Human上达到约76%的准确率。我们表明这一整体数字掩盖了时间差距：整体表现强劲的模型在有限延迟和活性规范上仍会崩溃为少数蕴含模板。核心问题在于主流方法（NL/SVA对的监督微调）优化的是词元级模仿，而非定义SVA正确性的属性等价。我们提出奖励加权在线策略蒸馏（RWOPD），这是一种在线策略蒸馏方法，对学生模型输出进行采样，用开放的SymbiYosys+Z3属性等价检查器（PEC）评分，并对验证器可通过的输出应用来自冻结的14B教师模型的验证器奖励加权前向KL梯度。这使得每个响应词元的监督保持密集，同时将选择与损失权重均基于属性等价行为。RWOPD将CodeV-SVA-14B蒸馏为Qwen2.5-Coder-7B-Instruct学生模型，该模型在NL2SVA-Human和NL2SVA-Machine上的pass@1、pass@5和pass@10均达到新最优，超越了先前的专用SOTA模型和671B通用基线。

## Abstract
LLM-based generation of SystemVerilog Assertions (SVA) is often reported as nearing saturation, with the strongest specialized model reaching ${\sim}76\%$ accuracy on NL2SVA-Human. We show that this aggregate hides a temporal gap: models that appear strong overall still collapse to a few implication templates on bounded-delay and liveness specifications. The core issue is that the dominant recipe, supervised fine-tuning on NL/SVA pairs, optimizes token-level mimicry rather than the \emph{property equivalence} that defines SVA correctness. We introduce \emph{Reward-Weighted On-Policy Distillation} (RWOPD), an on-policy distillation method that samples student rollouts, scores them with an open SymbiYosys+Z3 Property-Equivalence Checker (PEC), and applies a verifier-reward-weighted forward-KL gradient from a frozen 14B teacher on verifier-passable rollouts. This keeps the supervision dense at every response token while grounding both selection and loss weight in property-equivalent behavior. RWOPD distills CodeV-SVA-14B into a Qwen2.5-Coder-7B-Instruct student that sets a new state of the art on NL2SVA-Human and NL2SVA-Machine across pass@1, pass@5, and pass@10, surpassing both specialized prior SOTA models and 671B general-purpose baselines.

# 论文总结：Reward-Weighted On-Policy Distillation with an Open Property-Equivalence Verifier for NL-to-SVA Generation

## 1. 核心问题与整体含义（研究动机和背景）

- **问题识别**：当前最先进的 NL-to-SVA 生成模型（如 CodeV-SVA-14B）在总体准确率（~76% on NL2SVA-Human）上看似饱和，但这一聚合指标掩盖了“时间差距”（temporal gap）。模型在 bounded-delay、ranged-delay 和 liveness 规格上会崩溃为少数几种蕴含模板（template collapse），即生成的 SVA 语法上合理但语义不匹配。
- **根本原因**：主流训练范式——监督微调（SFT）优化的是 token 级别的模仿（token-level mimicry），而不是 SVA 真正需要的“属性等价性”（property equivalence）。两个 SVA 可以语法差异很大但等价，也可以仅差一个时间算子而语义相反；SFT 无法直接优化语义正确性。
- **含义**：需要将训练目标从 token 匹配转向基于验证器反馈的语义正确性，直接优化模型生成的断言是否与参考规范等价。

## 2. 方法论：核心思想、关键技术细节

### 核心思想：Reward-Weighted On-Policy Distillation (RWOPD)

- **整体框架**：基于在线策略蒸馏（On-Policy Distillation, OPD），但加入一个由属性等价检查器（PEC）提供的奖励信号，对学生的 rollouts 进行筛选和加权，再施加教师模型的密集前向 KL 梯度。
- **关键步骤**：
  1. **学生采样**：当前学生（7B+LoRA）从每个 prompt 采样 K 个 rollouts（温度 T，top-p=0.95）。
  2. **验证器筛选**：使用开放 SymbiYosys+Z3 属性等价检查器（PEC）将每个 rollout 与参考 SVA 对比，得到五种判决：EQUIVALENT, IMPLIES_REF_TO_LM, IMPLIES_LM_TO_REF, NOT_EQUIVALENT, UNSUPPORTED。仅保留 EQUIVALENT 或单向蕴含的 rollout。
  3. **奖励加权**：对保留的 rollout 赋予权重 w(y)（EQUIV: 1.0, IMPLIES_REF→LM: 0.6, IMPLIES_LM→REF: 0.4）。
  4. **密集蒸馏**：在保留且加权的 rollouts 上，计算教师（冻结的 CodeV-SVA-14B）与学生之间关于响应 token 的前向 KL 散度，并对权重进行归一化。
- **关键公式**：\( L_{RWOPD}(p) = \frac{\sum_{y \in S(p)} w(y) L_{OPD}(y)}{\sum_{y \in S(p)} w(y)} \)，其中 \( L_{OPD}(y) \) 是截断的前向 KL，\( S(p) \) 是 verifier-passable 的 rollouts 集合。
- **教师-学生词汇对齐**：截断至共享词汇表 Vmin=151,643。
- **Curriculum SFT 种子**：为防模板崩溃，采用三层分级课程（C1, C2, C3），每阶段包含先前阶段的回放（replay），并使用操作符 token 加权交叉熵（α=3），提高时间操作符的学习权重。

### 开放 PEC 验证器

- **实现**：基于 Yosys/SymbiYosys 和 Z3，对每个 SVA 对进行两个有界模型检查（BMC），产生五个判决。对 liveness 操作符返回 UNSUPPORTED，保证声音性（soundness）。
- **用途**：训练时作为筛选器和奖励信号，评估时仍使用 JasperGold 作为完整 oracle。

### 对比基线：稀疏 RL 方法

- 使用相同 PEC 奖励的 GRPO/IPO 作为基线，但奖励是稀疏的（每 rollout 一个标量），且需要大量超参数调优（7 种 GRPO 配置、2 种 IPO 配置），所有结果均未超过 SFT 基线。

## 6. 主要结论与发现

1. **RWOPD 达到新 SOTA**：7B+LoRA 学生模型在 NL2SVA-Human 和 NL2SVA-Machine 上以 pass@1/5/10 全面超越先前专用 SOTA（CodeV-SVA-14B）和 671B 通用模型（DeepSeek-R1, GPT-5）。
2. **增益集中在时间非平凡类**：在 NL2SVA-Machine 上，C2 提升 7.5pp，C3 提升 11.5pp，而 C1 已饱和。
3. **验证器更适合作为奖励形状过滤器而非稀疏奖励**：GRPO/IPO 无论如何调优均未超过 SFT 基线，而 RWOPD 利用了密集教师 KL，显著优于仅过滤（RS-SFT）和稀疏 RL。
4. **开放 PEC 的声音性**：在 C1/C2 片段上，开放 PEC 的 EQUIVALENT 判决与 JasperGold 零冲突（144/144 一致）。
5. **训练稳定性**：RWOPD 选择步骤 150 的 checkpoint，验证集轨迹单调上升，峰值区域宽，结果对步骤选择不敏感。

## 7. 优点

- **方法创新**：巧妙地将验证器奖励与在线策略蒸馏结合，利用验证器进行语义筛选和加权，同时保留教师模型的密集 token 级监督，解决了稀疏奖励信号不足的问题。
- **开源工具链**：开发了开放 SymbiYosys+Z3 PEC，为训练提供可重复、声音的验证信号，降低了对外部商业工具（JasperGold）的依赖。
- **实验严谨性**：进行了大量消融和对照实验，包括与不同 RL 变体的比较，并公开了训练动态、bootstrap 置信区间和 oracle 一致性检查。
- **揭示隐藏问题**：提出了 Temporal Complexity Level (TCL) 诊断，揭示了现有基准的“模板崩溃”现象，推动领域关注语义正确性而非语法匹配。
- **可复现性**：提供了详细超参数、代码截图（附录）、管道时间预算，承诺释放代码。

## 8. 不足与局限

- **C3 学习间接**：开放 PEC 在 liveness 上 abstain，因此 C3 的改进主要来自课程 SFT 种子 + 过滤保护，而非直接蒸馏，机制较为间接。
- **开放 PEC 声音性验证规模小**：仅验证了 SFT-50% greedy 输出的 20 个 EQUIVALENT 判决，样本量有限，虽从构造保证了声音性，但更广泛验证仍有必要。
- **依赖商业工具最终评估**：headline pass@k 仍需 JasperGold，无许可证的社区无法完整复现评估。
- **统计显著性有限**：bootstrap 置信区间在相邻方法间有重叠，点估计排序稳健但差异可能不显著于噪声。
- **RL 探索范围有限**：仅测试了 GRPO 和 IPO，未包括 reward-weighted regression、PPO 等变体，负结论的范围有限。
- **LoRA 容量可能受限**：使用 r=16 LoRA，可能限制了模型学习复杂语义区分的能力（如 GRPO 无法在训练上积累提升），更大适配器或全微调可能改变结论。
- **多种子敏感性未验证**：仅报告了一个种子，缺少多次运行的稳定性分析。
