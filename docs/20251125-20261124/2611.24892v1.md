## 摘要
用户模拟器为评估交互式智能体提供了一种可扩展的方式，但如何评估其质量仍研究不足。特别是，现有用户模拟器评估框架能否可靠地检测模拟用户行为中有意义的失败尚不清楚。这种不确定性使得模拟器评估难以解读。为了理解高基准分数能告诉我们关于模拟器质量的什么信息，我们对指标本身进行（元）评估。为了具体实施这种元评估，我们故意扰动模拟回放以诱发失败，如改变目标、省略约束、过早停止和接受有缺陷的工作，然后测试指标是否会惩罚这些失败。来自三项先前研究的评估方法仅检测到10种扰动中的5-6种；它们的组合分数甚至更倾向于被指示接受有缺陷工作的群体，而非未修改的对照组。受这些差距的启发，我们提出了一种新的评估套件，它结合了用户模拟器用于评估智能体的效用以及两项对真实用户的保真度度量：群体级保真度评估集体交互模式，而轨迹级保真度评估个体用户目标、约束和人设的保持情况。在相同的检测标准下，我们的评估套件检测到所有10种扰动。在351个真实多轮会话中评估六个用户模拟器，这些会话涉及来自23种语言的348名不同用户与智能体合作创建和优化全栈Web应用、游戏、设计资产和自动化工作流等制品，我们发现群体级度量可能遗漏模拟用户追求错误目标、忽略约束或行为不符合人设的情况，这凸显了在全面粒度上评估保真度的必要性。

## Abstract
User simulators offer a scalable way to evaluate interactive agents, but how to assess their quality remains underexplored. In particular, it is unclear whether existing user simulator evaluation frameworks reliably detect meaningful failures in simulated user behavior. This uncertainty makes it difficult to interpret simulator evaluation. To understand what a high benchmark score tells us about simulator quality, we (meta-)evaluate the metrics themselves. To instantiate this meta-evaluation, we deliberately perturb simulated replays to induce failures such as altered goals, omitted constraints, premature stopping, and acceptance of broken work, then test whether the metrics penalize these failures. Evaluation methods from three prior studies detect only 5-6 of the 10 perturbations; their combined scores even favor populations instructed to accept broken work over unmodified controls. Motivated by these gaps, we propose a new evaluation suite that combines utility of user simulators for evaluating agents and two measures of fidelity to real users: population-level fidelity assesses collective interaction patterns, while trace-level fidelity assesses the preservation of individual users' goals, constraints, and persona. Under the same detection criterion, our evaluation suite detects all 10 perturbations. Evaluating six user simulators on 351 real multi-turn sessions in which 348 distinct users across 23 languages and agents work together to create and refine artifacts such as full-stack web apps, games, design assets, and automated workflows, we find that population-level measures can miss when a simulated user pursues the wrong goal, ignores a constraint, or behaves out of character, highlighting the need to assess fidelity at comprehensive granularities.

## 1. 核心问题与整体含义

- **研究背景**：LLM 智能体通过多轮交互帮助用户写代码、做文档、生成制品（全栈 Web 应用、游戏、设计资产、自动化工作流等）。评估这类交互式智能体需要"用户"参与反馈，但招募真实用户成本高、难以复现，因此**用户模拟器（User Simulator）** 被广泛用于离线评估与训练。
- **核心问题**：用户模拟器本身的质量如何评估？现有评估框架（SimulatorArena、VISTA、SWE-Together、Sim2Real 等）给出的高分，是否真的意味着模拟器能可靠地替代真实用户？
- **关键洞察**：现有评估指标可能"高分低能"——模拟用户可能语言自然、听起来像人，却在**批准破损的制品、忽略关键需求、追求错误目标**。论文因此对评估指标本身做**元评估（meta-evaluation）**，检验它们能否检测出有意义的失败。
- **整体含义**：论文主张用户模拟器评估应同时覆盖三个层次——**下游评估效用（能否正确区分智能体）**、**群体级保真度（集体行为模式是否像真实用户）**、**轨迹级保真度（单个回放是否保持原用户的目标、约束与人设）**。

## 2. 方法论

### 2.1 核心思想：基于扰动的元评估

- 借鉴"criteria-targeted perturbation testing"（Sai et al., 2021），**故意扰动模拟器的设置**，生成"控制回放 vs 扰动回放"配对，检验评估指标是否对扰动给出更低分数（敏感性），以及在阈值筛选下能否区分控制与扰动样本（过滤能力）。
- 扰动作用于模拟器的**生成条件**（profile、响应指令、轮次预算），而非静态文本编辑，因此交互会自然演化。

### 2.2 回放设置

- 从真实会话中提取**会话 profile**（目标、约束、偏好、人设、停止条件），模拟器据此在新交互中代表原用户。
- 交互在持久沙箱中进行，模拟器接收 profile、发展中的对话、工作区证据（文本文件内容、元数据、工具错误摘要），生成反馈或停止；上限 30 个用户轮次。
- 控制回放与扰动回放共享源会话、开场请求、初始文件与指定智能体，但各自使用全新智能体实例与独立工作区。

### 2.3 十种扰动（按三层原则组织）

| 层次 | 扰动 | 操作 |
|---|---|---|
| L1 下游效用 | Agent favoritism | 指示模拟用户偏袒某智能体，淡化错误、接受不完美输出 |
| L1 | Profile extraction artifact | 把对原智能体的不满固化为持久用户特质，导致持续挑剔 |
| L2 群体保真 | Approve broken work | 指示接受有缺陷/缺需求的交付物并继续 |
| L2 | Premature stop | 将轮次预算截断为真实用户轮数的一半（2–15 轮） |
| L2 | Front-loading | 把本应逐步浮现的需求与验收标准前置到前 2 条消息 |
| L3 轨迹保真 | Adversarial goal | 用貌似合理的替代目标替换原目标与交付物 |
| L3 | All constraints removed | 清空 profile 中的硬约束（开场请求仍保留） |
| L3 | Persona swap | 替换写作风格（简洁小写/官僚/正式冗长） |
| L3 | Co-debugger | 让模拟用户充当调试协作者，诊断问题、提补丁 |
| L3 | Language switch | 英语用户改用中文回放，其他语言用户改用英语 |

### 2.4 元评估协议（关键公式）

- **敏感性（轨迹级）**：对配对样本 $i$，定义分数下降 $d_{i,m,p} = s_m(x_i^C) - s_m(x_i^p)$，均值 $\bar d_{m,p}$；配对胜率 $W_{m,p} = \frac{1}{|I|}\sum h(d_{i,m,p})$，其中 $h(d)$ 对 $d>0$ 记 1、$d=0$ 记 0.5、$d<0$ 记 0。
- **敏感性（群体级）**：重复 $B=200$ 轮，每轮采样 100 个会话，计算 $D_{b,m,p} = S_m(X_b^C) - S_m(X_b^p)$；要求 $D$ 的 **2.5 百分位 > 0** 才算检测到。
- **检测判定**：一个评估套件中**任一**组成指标在任一层级满足标准即算检测到该扰动（每个扰动只计一次）。
- **过滤分析**：用 AUROC 衡量分数区分控制/真实用户组与扰动组的能力；并报告在允许 5%/10% 扰动样本通过时，控制回放或真实用户轨迹的**保留率**。

### 2.5 新评估套件（bench-v0）

- **L1 下游排序一致性**：用 Claude Sonnet 4.6 将用户轮次标注为 accept / extend / correct / redirect / reject（及 stop），计算满意度
  $s(x) = N_{accept} + N_{stop} - N_{correct} - N_{reject}$，
  按智能体聚合后排序，与参考排序比较 Kendall's τ；L1 分数为排序一致性 $S_{order}=100\max(0,\tau)$ 与标准化分差一致性 $S_{gap}=100\max(0, 1 - MAE_z/(2/\sqrt{\pi}))$ 的平均。
- **L2 群体级行为保真**：四个指标族取算术平均——
  1. **动作分布**：LLM 将用户轮次分为 10 类对话行为（REFINE、REPORT_BUG、ADD_SUBTASK 等），$S_{act}=100\sum_a \min(p_a^{sim}, p_a^{real})$；
  2. **交互动态**：每轮词数、每会话用户轮数、词汇多样性（MATTR-50）、提问率、代码率，$S_{dyn}=\frac{100}{5}\sum_k \min(r_k, 1/r_k)$；
  3. **结果敏感性**：比较智能体出错后用户负面反应的概率提升 $\Delta_q$，$S_{out}=100(1-|\Delta_{sim}-\Delta_{real}|/2)$；
  4. **信息溯源**：比较用户来源信息点占比的比值比，$S_{prov}=100\min(OR, OR^{-1})$。
- **L3 轨迹级保真**：三个指标族取平均——**意图保持**（无重大漂移的回放比例）、**约束保持**（对话中保留或工作区满足的硬约束比例）、**人设一致性**（风格相似度 + 判断标准符合率 $C = N_{enacted}/(N_{enacted}+N_{violated})$）。
- **总分**：L1、L2、L3 的**几何平均**，同时分别报告三层分数。

## 6. 主要结论与发现

- **现有套件检测覆盖不足**：10 种扰动中，SimulatorArena 检出 6/10、VISTA 5/10、SWE-Together 6/10，而新套件 **10/10**。
- **共同盲区**：三个外部套件**均未检测到 agent favoritism**，尽管该扰动会改变智能体分数与排名；组合分数甚至**偏好接受破损工作的扰动群体**（如 VISTA 在 approve-broken-work 上 AUROC 低至 0.01）。
- **过滤能力差距显著**：agent favoritism 过滤中，新套件在 5% 扰动存活阈值下保留 **98%** 控制群体，最佳外部基准（Sim2Real）仅 10%；approve-broken-work 中动作分布保留 100% vs 最佳外部 26%；轨迹级人设分数保留 **68%** 真实用户轨迹 vs 最佳外部 28%。
- **群体级指标会漏检个体失败**：群体级度量可能遗漏模拟用户追求错误目标、忽略约束或行为失真；例如 VISTA 的 goal consistency 与 SWE-Together 的 intent recall 对"改变频道主题"的目标替换给出满分 1.00，而新套件的意图判断识别为重大漂移。
- **截断悖论**：premature stop 反而可能**提高** L2 分数，因为控制回放比真实用户会话更长，截断使长度更接近真实参考——说明单一群体统计可能奖励错误行为。
- **六个模拟器各有短板**：Sonnet 5 总分最高（70）且 L2 最高（87）；Terra L3 最高（84）；SimulatorArena L1 最高（57，τ=0.67）；**没有任何模拟器在三个层级上全面领先**，凸显多层评估的必要性。

## 7. 优点

- **元评估视角新颖且必要**：把评估指标本身作为研究对象，用受控扰动检验其有效性，比单纯"与人类判断一致"更能揭示指标的具体盲区。
- **扰动设计系统化**：10 种扰动有文献依据、实证观察与常识缺陷三重来源，且按三层原则组织，便于诊断"哪一层失效"。
- **三层评估框架互补性强**：L1 检验工具效用、L2 检验集体行为、L3 检验个体保真，避免单一聚合分数掩盖失败模式；作者明确强调"层级分数是指标而非校准概率"。
- **实验严谨**：配对设计、bootstrap 置信区间、群体重采样、对基线取最佳指标、真实用户参照阈值等多重保障；同时报告敏感性与过滤两种互补视角。
- **数据贡献**：351 个真实多轮会话（348 用户、23 语言）为后续研究提供资源；附录含丰富定性案例（目标漂移、约束放松、人设失真、过度协助等），可读性强。
- **诚实报告局限**：明确指出 premature stop 的反直觉结果、轨迹级过滤判别力有限（AUROC 0.62）等。

## 8. 不足与局限

- **算力与成本未报告**：无法评估方法的计算开销与可复现性；大量 LLM 判断器调用可能带来显著成本与延迟。
- **判断器依赖与偏差风险**：L1/L2/L3 大量依赖 Claude Sonnet 4.6 作为判断器，存在自偏好、提示敏感性与评分噪声风险；论文未系统报告判断器的可靠性（如与人类标注的一致性）。
- **人类研究偏弱**：配对识别准确率仅 0.56、一致率 0.51，说明扰动对人也难以辨别，"检测到"标准的生态效度存疑；且人类研究规模与设计细节披露有限。
- **扰动覆盖有限**：10 种扰动虽系统，但仍是人工设计的离散集合，可能遗漏其他真实失败模式（如多用户协作、长程记忆衰减、工具调用幻觉等）；语言切换仅涉及中英。
- **参考排序的外部性**：L1 参考排序由同一判断器从真实会话导出，与模拟回放的评分共享判断器，存在循环性风险；论文称参考构建"不属于框架贡献"，但实际应用中参考质量直接影响 L1 有效性。
- **轨迹级过滤判别力有限**：控制 vs 扰动 AUROC 仅 0.62，严格阈值下控制回放保留率低（5% FPR 时仅 10%），实际筛选可能损失大量合格样本。
- **应用范围限制**：聚焦"制品生产型"工作区任务（代码、Web 应用、设计资产），对纯对话、客服、具身等场景的泛化性未验证；模拟器骨干与智能体集合有限（9 个智能体）。
- **部分指标定义敏感**：如约束覆盖采用"对话提及或工作区满足"的宽松或逻辑，可能高估保持率；群体级指标在样本量小时（n=10）敏感性明显下降。
