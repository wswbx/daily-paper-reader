## 摘要
本工作提出了一种机器学习-符号回归（ML-SR）策略，以开发一个物理可解释的公式，用于预测假设性金属有机框架（hMOFs）中的低压CO2吸附容量。在1000个样本的小数据集上训练了四个机器学习模型，并通过SHAP和特征重要性分析确定了五个关键描述符——最大腔径、孔隙限制直径、空隙率、重力比表面积和氢原子数。然后采用符号回归推导出一个简洁的吸附公式，Q=aA，其中a表示吸附基线（mmol/g），A是一个无量纲吸附数，包含四个结构描述符。我们将A解释为吸附结合力与扩散驱动力之间的比率，揭示了孔隙拓扑和表面化学如何共同影响吸附。对137,652个hMOFs的综合数据集的验证表明，该公式对62,448个结构实现了超过70%的预测准确性，确认了在明确的结构和操作范围内的强适用性。与传统黑箱机器学习模型不同，所提出的物理引导表达式能够实现高效预测，并提供对吸附机制的更清晰见解。

## Abstract
This work presents a machine learning-symbolic regression (ML-SR) strategy to develop a physically interpretable formula for predicting low pressure CO2 adsorption capacity in hypothetical metal-organic frameworks (hMOFs). Four ML models were trained on a small dataset of 1,000 samples, and five key descriptors-largest cavity diameter, pore limiting diameter, void fraction, gravimetric surface area, and number of hydrogen atoms-were identified through SHAP and feature importance analyses. Symbolic regression was then employed to derive a concise adsorption formula, Q=aA, where a represents an adsorption baseline (mmol/g) and A is a dimensionless adsorption number incorporating four structural descriptors. We interpret A as the ratio between an adsorption binding force and a diffusion driving force, revealing how pore topology and surface chemistry jointly influence adsorption. Validation against a comprehensive dataset of 137,652 hMOFs demonstrates that this formula achieves over 70% prediction accuracy for 62,448 structures, confirming strong applicability within defined structural and operational ranges. Unlike conventional black box ML models, the proposed physics-guided expression enables efficient prediction and provides clearer insight into adsorption mechanisms.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 整体流程（四步策略）
1. **小样本训练ML模型**：从MOFX-DB数据库中随机抽样1000个hMOF样本，训练四种ML模型。
2. **特征分析与筛选**：通过SHAP和特征重要性分析，从22个结构/化学描述符中确定关键描述符。
3. **符号回归生成公式**：使用符号回归（gplearn）在筛选出的5个描述符上，生成大量候选表达式，并利用Pareto前沿筛选高性能公式。
4. **大规模验证与物理分析**：将公式在137,652个hMOFs上验证，并对公式的物理意义进行单因素/双因素分析。

### 2.2 关键描述符
通过SHAP和特征重要性分析，五个最关键描述符为：
- X₀ = 最大腔径（LCD，单位Å，除以10缩放）
- X₁ = 孔径限制直径（PLD，单位Å，除以10缩放）
- X₂ = 空隙率（无量纲）
- X₃ = 重力比表面积（Sa，单位m²/g，除以1000缩放）
- X₄ = 氢原子数（无量纲）

其中，论文选择H作为化学相关描述符（而非F、Br等），因为H在所有MOF中更普遍，并且C–H基团可与CO₂形成氢键和偶极相互作用。

### 2.3 符号回归过程
- **实现工具**：PySR/gplearn，使用遗传编程，算子包括+、−、×、÷、√、ln、|x|、−x、1/x。
- **适应度函数**：Pearson相关系数r（最大化），同时控制公式复杂度（公式长度）。
- **搜索规模**：共进行超过2,984,000,000次演化评估，获得14,920个原始公式，去重后得到2,641个唯一候选表达式。
- **公式筛选标准**：
  1. |r| > 0.75，公式长度 < 16；
  2. 尽量靠近Pareto前沿（最大化r、最小化复杂度）；
  3. 根据物理可解释性逐条人工审查——加法/减法涉及的描述符必须具有相同量纲，否则舍弃（如X₂、X₃、X₄与X₀、X₁量纲不同，不能直接加减）。
- **PLD被排除的原因**：(1) PLD在所有描述符中非线性最强，与符号回归搜索的简单线性结构不匹配；(2) 含PLD的公式多数不在Pareto前沿附近；(3) 含PLD的候选公式物理意义难以解释。

### 2.4 最终公式
在8个高绩效候选公式中，论文最终选定：
**Q = a * (X₂·X₃·X₄^(1/4)) / [X₀·(1 + X₃²)]**

其中：
- a = 3.3 mmol/g（吸附基线常数，与0.5 bar、298 K条件下的基线CO₂吸附能力对应；论文推测其可能取决于气体种类、温度和压力，但暂为假设）。
- 定义无量纲吸附数（Adsorption Number）：
**A = (X₂·X₃·X₄^(1/4)) / [X₀·(1 + X₃²)]**

### 2.5 物理意义解释
- **吸附结合力**（分子）：(X₂·X₃·X₄^(1/4))——体现表面化学（H原子数）与物理结构（空隙率、比表面积）的协同耦合作用；X₄^(1/4)为幂律函数，使增长速率随变量增大而减缓。
- **扩散驱动力**（分母）：X₀·(1 + X₃²)——与孔道拓扑结构（LCD）和比表面积相关，体现分子可及性、跃迁势垒和晶内迁移率；常数“1”可能是与气体扩散系数相关的物理因子（推测）。
- **A = 吸附结合力 / 扩散驱动力**。A越大，吸附能力越强；扩散驱动力增大（限制效应减弱）会降低A，而更强的吸附结合力会提高A。
- A被类比为流体力学中的雷诺数、努塞尔数等无量纲数，用于跨尺度、跨体系的吸附过程比较。

## 6. 论文的主要结论与发现

1. **关键描述符的确定**：在22个描述符中，最大腔径、孔径限制直径、空隙率、重力比表面积和氢原子数是决定低压CO₂吸附的关键因素。低压下化学相互作用（尤其是H相关的C–H…O₂C相互作用）的重要性突出。
2. **成功推导出简洁物理公式**：Q = a·(X₂·X₃·X₄^(1/4)) / [X₀·(1 + X₃²)]，其中a = 3.3 mmol/g。该公式在62,448个hMOFs（约占总体的45%）上实现绝对相对误差<30%，对这些结构的线性回归R²达到0.907；对78,039个结构（AER<40%）R²为0.844；全数据集R²为0.596。
3. **无量纲吸附数A的提出**：A = 吸附结合力 / 扩散驱动力，可作为评估MOF吸附性能的广义无量纲特征数。
4. **物理机制揭示**：
   - 空隙率和氢原子数与A正相关；
   - 最大腔径与A负相关（过大孔削弱限制效应）；
   - 比表面积与A存在最优匹配范围（约1000 m²/g附近）。
5. **对实验设计的指导意义**：公式可用于量化预测MOF功能化改造（如引入-NH₂）后吸附容量的变化，辅助MOF结构优化与高通量筛选。
6. **对研究范式的贡献**：ML-SR策略可作为“黑箱ML”之外的补充路径，为材料科学提供可解释、可迁移的数学模型。

- **与多准则统计互补**：结合Pearson、Spearman和距离相关三种统计度量，全面评估特征间线性和非线性关系。

## 8. 不足与局限

- **预测精度有限**：与引入新描述符的高性能ML模型相比，该公式的总体R²（0.596）较低，仅对约45%的MOFs达到AER<30%，说明公式适用范围有限。
- **化学多样性不足**：MOFX-DB中的金属中心/无机节点种类有限，公式可能无法推广到含富金属化学的MOFs。
- **柔性骨架局限**：对ZIF-8、UiO-66等动态/柔性框架MOFs预测偏差大（ZIF-8准确率仅31.93%），因为公式仅基于静态晶格描述符，未包含“呼吸效应”。
- **公式选择存在主观性**：论文承认人类在解释和选择符号回归公式中的参与不可避免引入主观性和偶然性。例如，R²略高的公式a₃因无法解释“空隙率−比表面积”项而被弃用。
- **吸附基线a的物理起源不确定**：a=3.3 mmol/g仅为经验值，论文推测其与气体种类、温度和压力有关，但缺乏充分验证。
- **特征使用的简化**：符号回归仅使用5个描述符，忽略了其他可能对低压吸附有贡献的化学特征（如金属位点、卤素等），且PLD（孔径限制直径）虽为关键描述符却未进入最终公式。
- **数据噪声**：MOFX-DB的GCMC模拟可能存在统计不确定性，虽然论文通过两阶段验证加以缓解，但并未完全消除。
- **缺乏与传统ML模型在完全一致条件下的同数据集公平对比**：未在相同的137,652样本上复现文献中的新描述符模型，只能做宏观对比。
