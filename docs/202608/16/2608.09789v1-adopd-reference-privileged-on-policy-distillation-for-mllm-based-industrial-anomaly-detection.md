## 摘要
工业异常检测（IAD）要求识别与正常视觉模式之间的细粒度偏差。多模态大语言模型（MLLMs）可以通过在推理时将查询图像与参考图像进行比较来提高识别准确率，但这些收益依赖于额外的检索和处理。我们探究参考比较的收益是否可以内化到模型参数中。训练期间对参考图像的访问允许一个参考感知的教师模型来监督一个仅使用查询图像的学生模型。然而，教师模型可能倾向于基于查询线索或语言先验而非有效视觉信息来产生看似合理的响应。我们提出了ADOPD，一种参考特权策略蒸馏框架。教师模型在匹配和不匹配的参考图像下评估学生生成的rollouts。匹配参考下的教师-学生对数似然比定义了token级的学习方向，指定了学生应该学习的内容。两种参考视图之间的似然差距估计了参考特定支持度，并校准了序列级权重。ADOPD在MMAD基准的零样本推理下达到了77.31%的平均准确率，比Qwen3-VL-4B骨干网络提升了6.14个百分点，并优于其单样本设置2.64个百分点。实验表明，ADOPD从参考比较中学习了一种细粒度的异常检查策略。项目将在https://github.com/withTai/ADOPD提供。

## Abstract
Industrial anomaly detection (IAD) requires identifying fine-grained deviations from normal visual patterns. Multimodal large language models (MLLMs) can improve recognition accuracy by comparing query images with references at inference time, but these benefits rely on additional retrieval and processing. We investigate whether the benefits of reference comparison can instead be internalized in the model parameters. Access to references during training allows a reference-aware teacher to supervise a query-only student. However, the teacher may favor plausible responses based on query cues or language priors rather than valid visual information. We propose ADOPD, a reference-privileged on-policy distillation framework. The teacher evaluates student-generated rollouts under matched and mismatched references. The matched-reference teacher-to-student log-ratio defines the token-level learning direction, specifying what the student should learn. The likelihood gap between the two reference views estimates reference-specific support and calibrates the sequence-level weight. ADOPD achieves 77.31% average accuracy on the MMAD benchmark under zero-shot inference, improving the Qwen3-VL-4B backbone by 6.14 points and outperforming its one-shot setting by 2.64 points. Experiments show that ADOPD learns a fine-grained anomaly inspection strategy from reference comparison. The project will be available at https://github.com/withTai/ADOPD.

## 2. 论文提出的方法论

### 核心思想

ADOPD 的核心是**分离"学什么"（token 级学习方向）与"学多强"（序列级更新强度）**：

- 学生模型（仅查询图像）先采样 rollouts，形成由自身状态诱导的训练轨迹；
- 冻结的教师模型在**匹配参考**与**不匹配参考**两种不对称视角下重放同一个 rollout；
- 匹配参考下的教师-学生对数概率比定义 token 级学习方向（即蒸馏方向）；
- 匹配与不匹配参考下的教师似然差距定义序列级权重（即更新力度）；
- 最终通过策略梯度目标函数更新学生策略。

### 关键技术细节

1. **参考特权在线策略蒸馏**：
   - 学生从查询图像+问题的 prompt x 中采样 G 个 rollouts：y_g ∼ π_S(·|x)；
   - 在生成步骤 t，教师和学生均在同一学生生成的 prefix 上计算下一个 token 的概率：p_g^S(t) 和 p_g^T(t; r)；
   - 匹配参考下的 token 级优势定义为：A_g^t = sg[log p_g^T(t; r_mat) − log p_g^S(t)]，它决定"学什么"——当教师分配给某个 token 的概率高于学生时为正反馈，反之则为负反馈。

2. **对比参考加权**：
   - 计算每个 rollout 的对比参考支持得分（序列平均匹配/不匹配参考的教师对数似然差）：s_g = (1/T_g) Σ_t [log p_g^T(t; r_mat) − log p_g^T(t; r_mis)]；
   - 将 s_g 在同一 prompt 的 G 个 rollouts 内做组相对标准化，加单位偏移后裁剪：w_g = s_g[1 + clip((s_g − μ)/σ, −ε_w, ε_w)]；
   - 权重 w_g 是 detached 且非负的，因此只调节学习幅度、不改变学习方向。

3. **校准优化目标**：
   - 将序列级权重广播到每个 token 形成校准优势：Â_g^t = w_g · A_g^t；
   - 最终目标函数为：L_ADOPD = −(1/G) Σ_g (1/T_g) Σ_t Â_g^t log π_S(y_g^t | x, y_{<t}^g)。

4. **匹配与不匹配参考的定义**：匹配参考是指与查询异常状态语义一致的局部区域参考；不匹配参考则刻意打破这种有效查询-参考关系（如来自相反异常状态的区域证据）。二者不对称、不可互换。

### 与现有方法的区别

- 与 off-policy SFT 蒸馏不同，ADOPD 在学生自己诱导的状态上评估教师反馈，避免了暴露偏差；
- 与朴素参考特权 OPD 不同，ADOPD 增加了对比参考加权机制，解决教师"支持是否真正源于参考比较"的信任问题。

## 6. 论文的主要结论与发现

1. ADOPD 在 MMAD 零样本推理下达到 **77.31%** 平均准确率，较 Qwen3-VL-4B 基线提升 **6.14 个百分点**；超过该骨干的 one-shot 参考条件推理 **2.64 个百分点**，同时无需推理时参考检索开销。
2. ADOPD 以 4B 学生超越最强领域专用模型 Reason-IAD（8B）0.60 个百分点；
3. 提升主要集中在**比较敏感的异常识别任务**上：异常判别提升 12.72 点、缺陷定位提升 2.49 点、缺陷分析提升 0.28 点；而在缺陷分类/描述和物体分类/分析上不如最强竞争者——表明 ADOPD 学到的是参考比较塑造的异常检查策略而非泛化的语义推理能力。
4. 对比参考加权（calibration）是有效的：未加权的参考特权 OPD 仅达 74.95%，低于 SFT 的 75.70%；加权后的 ADOPD 达 77.31%，说明仅靠在线采样并不保证更强的知识迁移，需要参考对比加权来补足。
5. 区域裁剪参考优于全图参考，表明**局部异常相关的特权监督**比提供整张参考图更有效；不匹配参考比随机裁剪提供更强的校准信号。
6. 定性分析表明 ADOPD 的梯度归因更集中在缺陷区域（细划痕、孤立斑点、局部结构损伤），与基线的扩散式注意力形成对比，但在纹理密集样例上仍比 GT mask 更广。

## 7. 优点

- **思想创新**：首次将"参考比较"从推理期输入转化为训练期特权信息，通过在线策略蒸馏内化到模型参数中，实现了零样本推理下的参考比较能力；
- **方法论设计巧妙**：匹配/不匹配参考的不对称干预分别提供"方向信号"与"信任信号"，分离了"学什么"和"学多强"，逻辑清晰且形式化表达完整；
- **对比加权机制具有普适性**：匹配-不匹配似然差距作为一种无需答案标注（verifier-free）的参考特异度代理指标，不依赖额外奖励模型；
- **训练高效**：仅用 6K 训练记录和 60 个优化步骤即取得显著提升，数据效率突出；
- **评估指标全面**：不仅报告准确率，还报告召回率、精确率与 F1（更贴合工业场景对漏检的关注）；从多个维度（数据集、子任务、训练范式、参考粒度、模型配置）进行系统分析；
- **写作清晰**：从预备知识（OPD 推导）到方法细节（算法 1）再到实验验证，结构完整，便于复现。

## 8. 不足与局限

- **对特权数据标注的依赖**：训练需要配对图像（正常/异常同实例同视角）和缺陷区域标注，这在真实工业场景中获取成本较高；论文也承认"较弱的、自动构建的特权参考"是未来方向；
- **性能提升不均衡**：ADOPD 在异常判别（+12.72 点）和定位（+2.49 点）上提升显著，但在缺陷分类、描述和物体分类/分析上弱于最强竞争者，说明参考比较带来的收益并非全面；
- **定位精度仍有限**：论文明确承认归因图在纹理密集样例上比 GT mask 更宽，ADOPD 不是像素级分割模型的替代品，而是一种"与定位相关的推理"改进；
- **缺少统计显著性验证**：未提供多次独立运行的标准差或显著性检验，无法确认结果差异的统计稳定性；
- **算力细节不够透明**：GPU 确切数量、训练时长、能耗等未披露，影响可复现性和资源评估；
- **教师偏差风险**：匹配参考下的教师反馈仍可能包含语言先验或查询线索的偏差，对比加权机制只能作为缓解手段而非完全消除；
- **评估范围有限**：仅在 MMAD 的 4 个数据集上评估，未涵盖更多新兴工业异常数据集或真实产线场景，跨域泛化能力证据不足。
