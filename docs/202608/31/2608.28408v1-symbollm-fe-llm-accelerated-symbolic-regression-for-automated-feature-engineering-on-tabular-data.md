## 摘要
表格数据是机器学习中的核心数据格式，但常因特征信息量不足而缺乏高性能建模所需的判别能力。自动化特征工程（AutoFE）通过自动化特征生成和选择克服了这一问题，确保了模型性能和操作效率。然而，传统的AutoFE通常依赖盲目的数学变换，导致生成的特征可解释性较差，而基于大语言模型（LLM）的AutoFE面临着需要高成本的多轮迭代来生成高效用特征以有效提升模型性能的挑战，并且还存在偏差和幻觉的固有风险。在本文中，我们将符号回归与LLM相结合用于特征工程（SymboLLM-FE），以解决这些挑战。我们通过符号回归提取与目标强相关的数学表达公式，这些公式可以提升模型性能，然后利用具有丰富先验知识的LLM对其进行优化，以确保可解释性。在六个真实世界数据集和四个Kaggle比赛中的实验结果表明，SymboLLM-FE优于现有的AutoFE。SymboLLM-FE还通过采用基于统计先验的LLM优化机制和个位数次LLM调用，解决了可解释性差和迭代次数多的双重挑战。

## Abstract
Tabular data, as a core data format in machine learning, often lacks the discriminative power needed for high-performance modeling due to insufficient feature informativeness. Automated Feature Engineering (AutoFE) overcomes this by automating feature generation and selection, ensuring both model performance and operational efficiency. However, traditional AutoFE often yield features with poor interpretability because they rely on blind mathematical transformations, while large language models (LLM)-based AutoFE faces challenges in requiring costly multi-round iterations to generate high-utility features to effectively enhance model performance, compounded by inherent risks of bias and hallucination. In this paper, we combine symbolic regression with LLMs for feature engineering (SymboLLM-FE) to solve these challenges. We extract mathematically expressive formulas strongly correlated with the target via symbolic regression, which can enhance model performance, then refine them by LLMs with rich prior knowledge to ensure interpretability. Empirical results on six real-world datasets and four Kaggle competitions demonstrate that SymboLLM-FE outperforms existing AutoFE. SymboLLM-FE also addresses the dual challenges of poor interpretability and numerous iterations by employing a statistical prior-grounded LLM refinement mechanism and single-digit LLM calls.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **总体框架（SymboLLM-FE）**：两阶段协作流程，包括“符号回归的公式构造”和“基于 LLM 的特征生成”两个阶段。

### 2.1 阶段一：公式构造（Formula Construction by Symbolic Regression）

- **特征子集采样**：
  - 为避免对所有 \(2^n-1\) 个非空特征子集都运行符号回归（指数复杂度），论文提出基于 **Spearman 相关系数** 的特征排序 + **扩展滑动窗口**（expanding-sliding window）策略。
  - 先计算每个特征与目标变量的 Spearman 相关系数，按相关性单调升序排序，得到有序特征序列 \(C'\)。
  - 窗口初始大小 \(k = \lfloor n/2 \rfloor\)，先进入“扩展阶段”（\(k\) 从 \(\lfloor n/2 \rfloor\) 逐步增至 \(n\)），再在固定 \(k\) 下让窗口右移，生成多个连续特征子集。
  - 该策略将搜索空间从指数级 \(O(2^n)\) 降为多项式级 \(O(n^2)\)，具体子集数量上界为：
    - \(n\) 为偶数：\((n+2)(n+4)/8\)
    - \(n\) 为奇数：\((n+3)(n+5)/8\)
- **公式生成**：
  - 对每个生成的子集 \(S_i\) 训练一个符号回归模型（采用遗传编程，gplearn），产出从该子集到目标的数学表达式 \(\tau_i\)（例如 `add(mul(c1,c2),c3)`）。
  - 最终构造一个公式库 \(R = \{(S_i, P_f(S_i), \tau_i)\}_{i=1}^{|S|}\)，包含特征子集、符号回归模型性能、对应公式三元组。
- **符号回归细节**（附录 A）：
  - 使用 gplearn 库，遗传编程，执行群体初始化、适应度评估、交叉/变异、迭代进化。
  - 适应度函数加入**简约惩罚**（parsimony pressure）：\(\tilde{E}(T_i)=E(T_i)+\Omega\cdot size(T_i)\)，以控制表达式复杂度、防止过拟合。
  - 算子库共 14 种（add, sub, mul, div, sqrt, inv, neg, abs, max, min, sin, cos, tan, log），均带保护机制（如除零返回固定值）以保证数值稳定性。
  - 超参数固定：种群规模 20000，代数 120，早停阈值 \(10^{-4}\)，锦标赛规模 100，交叉概率 0.9。

### 2.2 阶段二：基于 LLM 的特征生成（Feature Generation via LLMs）

- **LLM 引导的代码生成**：将公式库 \(R\) 中每个公式 \(\tau\) 转化为自然语言描述，连同数据集背景信息和代码生成提示词一起送入 LLM，通过链式思维（Chain-of-Thought）生成可执行的 Python pandas 特征工程代码。
- **下游预测器验证**：执行生成的代码，得到新特征集 \(C_{new}\)，与原始特征合并成 \(C_{final}\)，训练下游预测器并评估性能。
- **迭代精炼**：将预测器性能、使用的特征及其生成代码反馈给 LLM，进行多轮优化。但论文强调使用统计先验约束 LLM 的操作空间，实际只需约 **4 次 API 调用**即可达到较好效果。
- **特征控制与去冗余**：
  - 动态剪枝：通过下游模型反馈丢弃对验证性能有损的特征。
  - LLM 作为语义过滤器：识别符号回归公式与原始特征之间的数学等价关系，去除多重共线性。
  - 在符号回归阶段使用简约惩罚（Occam's razor），并严格限制 LLM 只在经过统计验证的候选子空间内操作，从而抑制幻觉和噪声。

## 7. 优点

- **思路新颖**：将符号回归与 LLM 有效结合，形成“SLR 负责数学模式发现，LLM 负责语义精炼”的分工模式，避开了传统方法可解释性差和纯 LLM 方法高成本/幻觉的双重困境。
- **搜索空间优化严谨**：使用 Spearman 排序 + 扩展滑动窗口，在不损失特征表示能力的前提下将复杂度从指数级降至多项式级，并给出了数学上界。
- **高效迭代**：通过统计先验锚定 LLM 操作，将 API 调用次数压缩到个位数，在实际应用中具有极强实用性。

- **负面风险控制**：通过约束 LLM 在符号回归已验证的公式库上进行解释、合并和去冗余，从架构上抑制幻觉和偏差，同时设计了错误处理流程（错误回传 LLM 自动修复代码）。
