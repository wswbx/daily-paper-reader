## 摘要
与图像和文本不同，将迁移学习应用于表格数据具有挑战性，因为不同领域之间的特征类型、结构和语义存在异质性。现有方法假设数据表间存在共享特征以实现领域间的知识迁移，这在实际中并不现实。本文引入广义上下文学习，以消除跨领域共享特征的需求。由变压器投影权重（针对key、value和query）捕获的广义上下文提供了基于规则的泛化，而非传统上从变压器激活中学习的领域特定上下文。源领域中key的投影权重与目标领域中query的权重交互，以实现数据无关的跨域注意力迁移学习（CATTLE）。我们在十对不相交的源-目标数据集上的实验表明，CATTLE能够从单一源数据集学习广义上下文，并且在排名和统计上优于九种最先进的基线方法，包括使用大规模预训练模型的机器学习、深度学习和迁移学习方法。CATTLE取得了最佳平均排名（2.9），并相比基线方法平均AUROC提升了3.7%。CATTLE源代码可在 https://tinyurl.com/pr5s8ywn 获取。

## Abstract
Unlike images and text, applying transfer learning to tabular data is challenging due to heterogeneity in feature types, structures, and semantics across disparate domains. Existing methods assume shared features across data tables to enable knowledge transfer between domains, which is unrealistic in practice. \mds{This paper introduces generalized context learning to remove the requirement of shared features across domains. The generalized context captured by transformer projection weights for $key$, $value$, and $query$ provides rule-based generalization rather than the domain-specific context conventionally learned from transformer activations. Projection weights for $key$ from the source domain interact with the weight for $query$ in the target domain to achieve Cross-domain Attention Transfer Learning (CATTLE) in a data-agnostic manner. Our experiments on ten pairs of disjoint source-target data sets show that CATTLE can learn generalized context from a single source data set and is rank-wise and statistically superior to nine state-of-the-art baselines, including machine learning, deep learning, and transfer learning methods using large-scale pre-trained models. CATTLE achieves the best average rank (2.9) and delivers a 3.7% average AUROC gain over the baseline methods.} The CATTLE source code is available at https://tinyurl.com/pr5s8ywn.

- **研究动机与背景**：与图像和文本数据不同，表格数据在不同领域之间呈现出显著的特征异构性——不同领域数据集的特征类型（数值型、类别型等）、结构及语义均有较大差异。例如，银行交易数据与电子健康记录几乎不存在任何共享特征。这使得传统迁移学习假设——“源域与目标域存在共享特征或特征重叠”——在真实场景中往往不成立。
- **核心问题**：如何在源域与目标域特征空间**完全不相交（disjoint）**的情况下，实现表格数据的有效知识迁移？这是开发大型表格基础模型所面临的根本性挑战。
- **整体含义**：论文提出一种**数据无关（data-agnostic）**的迁移学习范式，通过Transformer投影权重而非传统激活值来获取广义上下文，使知识迁移不再依赖于源域和目标域的特征重叠，打破了表格数据跨域迁移的瓶颈。

## 2. 论文提出的方法论

- **核心思想**：区别于传统的基于数据表示（key、value、query激活值）的域特定上下文学习，论文提出从Transformer的投影权重矩阵（\(W_q\)、\(W_k\)、\(W_v\)）中学习**广义上下文（generalized context）**。这种上下文代表“如何学习数据”的规则级泛化知识，独立于任何特定领域。
- **关键技术细节**：
  - **预训练阶段**：使用源数据集预训练gFTT（Gated Feature Tokenizer Transformer），支持两种预训练方式：
    - **自监督预训练**：随机掩码部分特征值（掩码比例35%），通过重建被掩码的数值型特征（MSE损失，式5）和类别型特征（余弦相似度损失，式4）进行学习，总损失为式6。
    - **监督预训练**：以源数据标签为目标，使用交叉熵损失训练。
  - **权重转移机制**：将预训练gFTT模型**最高层**（知识最综合层）的\(W_k\)和\(W_v\)权重复制到目标gFTT模型的**最底层两层**，并在目标域微调期间**保持冻结**，以保留广义上下文。
  - **跨域注意力的实现**：目标域微调时，目标域的query投影权重（\(W_{tq}\)）与源域预训练的key权重（\(W_{sk}\)）产生交互——目标数据的query表示与由预训练权重投影的key表示之间的缩放点积（式2），即形成跨域注意力。
  - **数据表示**：类别特征的特征名+类别值通过预训练BERT获取嵌入并拼接；数值特征则用特征名的嵌入乘以数值。
- **算法流程**（Algorithm 1）：源域预训练gFTT → 提取最高层注意力权重 → 替换目标gFTT最低两层的key-value权重并冻结 → 目标域带标签数据进行微调得到CATTLE模型。

## 6. 论文的主要结论与发现

- **CATTLE（自监督预训练）在AUROC和ACC上均获得最佳平均排名**：AUROC平均排名2.9（σ=2.4），ACC平均排名2.4（σ=1.5），优于所有基线方法。

- **跨注意力在权重层面而非激活层面确实有效**，且提供的数据无关广义上下文不受源域特定知识干扰——换用不同源数据集对同一目标域的性能影响很小（最大AUROC差距仅0.018）。
- **单一源数据集即足以学习广义上下文**，无需大规模多源数据预训练；这一发现对现实中难以获得大规模标注表格数据的场景具有重要价值。
- **自监督预训练优于监督预训练**，支持了无标签数据预训练的实用性和必要性。
- 在小样本目标数据集（如540个样本的Cylinder Bands）上，CATTLE自监督版本也优于XGBoost等传统强基线，表明其在有限样本表格学习中的潜力。

## 7. 优点

- **方法层面**：首次提出“广义上下文”（generalized context）概念，从Transformer投影权重而非激活值中提取跨域知识，这是概念和方法上的创新；彻底摆脱了对共享特征空间的依赖，使**不相交表格数据**的迁移学习成为可能。
- **数据效率**：仅需单一源数据集即可实现有效迁移，不依赖大规模多源预训练，大幅降低了迁移学习的应用门槛。
- **实用性**：自监督预训练避免了人工标注的需求，适合标注成本高昂的表格数据应用场景。
- **实验设计**：系统地对比了传统机器学习、深度学习、迁移学习三类基线，并进行了多角度消融实验和统计检验，证据链较完整。

## 8. 不足与局限

- **理论基础薄弱**：选择最高层注意力权重进行迁移、以及“权重提供规则泛化而激活提供域特定上下文”的假设，主要依据经验观察和引用文献（Chan et al., 2022），缺乏严格的数学或理论证明。
- **实验覆盖有限**：仅使用10对源-目标数据集，且全部来自OpenML，未涵盖更广泛的实际应用场景（如真实银行、医疗机构的私有数据），外部效度有待验证。
- **对比公平性问题**：与CM2（2000数据集预训练）和XTab（52数据集预训练）相比，CATTLE使用专门为每对任务定制的源域预训练模型，这种“任务导向预训练”与“通用预训练”的对比可能不完全对等。此外，CATTLE利用了BERT的预训练语义知识，而部分基线（如匿名化编码）未获得同等的外部知识支持。
- **对语义的依赖**：CATTLE高度依赖特征名称和类别值的语义信息（通过BERT编码），这意味着其对非英文表格、匿名化数据或特征名称无意义的场景可能失效。
- **结果呈现存在问题**：Table 3和Table 4中基线方法名称出现错位和混乱（如某些单元格显示多个来源），虽然核心结果仍可辨认，但影响论文的可信度和可复现性。
- **可解释性不足**：跨多头注意力层中知识的具体分布机制尚未被阐明，论文作者也承认这是未来工作的重要方向。
