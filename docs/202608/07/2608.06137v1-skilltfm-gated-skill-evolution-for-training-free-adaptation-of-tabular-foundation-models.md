## 摘要
表格数据在现实应用中无处不在，对于科学、工业、金融、医疗和公共服务中的数据驱动预测与决策至关重要。表格基础模型（TFMs）已成为通用表格学习的一种有前景的范式，能在不同数据集间提供可复用的预测器，并显著减少对特定任务训练、调优和模型开发的需求。然而，其实际部署仍受分布偏移、异质特征语义以及难以在无需昂贵微调或额外标注数据的情况下捕获的任务特定模式所制约。为此，我们提出SkillTFM，一种免训练系统，将TFM的适应从参数更新转变为智能体技能的门控演化。SkillTFM的核心是一个可验证且可扩展的技能库，它结合了边界证据识别与门控技能演化：前者刻画任务结构和基座模型的失效模式，而后者在显式验证下检索并扩展可复用技能。在模拟边界场景和真实电价预测中，SkillTFM将AUC提升了0.128–0.142，并将非线性边界AUC从0.699提升至0.898。此外，跨TFM骨干网络的实验验证了SkillTFM的有效性与通用性。

## Abstract
Tabular data are ubiquitous in real-world applications and are crucial for data-driven prediction and decision-making across science, industry, finance, healthcare, and public services. Tabular foundation models (TFMs) have emerged as a promising paradigm for general-purpose tabular learning, offering reusable predictors across diverse datasets and substantially reducing the need for task-specific training, tuning, and model development. However, their practical deployment remains constrained by distribution shifts, heterogeneous feature semantics, and task-specific patterns that are difficult to capture without costly fine-tuning or additional labeled data.   To this end, we propose SkillTFM, a training-free system that shifts TFM adaptation from parameter updates to the gated evolution of agentic skills. The core of SkillTFM is a verifiable and extensible skill bank that couples boundary evidence identification with gated skill evolution: the former characterizes task structure and base-model failure patterns, whereas the latter retrieves and extends reusable skills subject to explicit validation. Across simulated boundary settings and real-world electricity-price forecasting, SkillTFM improves AUC by 0.128--0.142, raises nonlinear-boundary AUC from 0.699 to 0.898. Furthermore, experiments across TFM backbones demonstrate the effectiveness and generality of SkillTFM.

## 一、核心问题与研究动机

论文聚焦于**表格基础模型（Tabular Foundation Models, TFMs）在实际部署中的适应性问题**。尽管TFM（如TabPFN、TabICL、TabDPT等）通过任务上下文即可作为通用预测器，免去了逐数据集训练，但其在以下现实条件下仍会出现系统性边界失效：

- **分布偏移**：训练上下文与部署数据分布不一致。
- **异质特征语义**：特征含义随任务变化，结构不稳定。
- **非线性结构与缺失模式**：超出模型已覆盖的结构条件。
- **系统误差与不稳定依赖**：局部区域的持续过预测或幅度低估。

现有应对方式（微调、固定预处理、规则修复、校准）往往将"修复"当作默认动作，即使在基座模型已可靠的区域也会干预，缺乏对"当前任务是否值得修复"和"修复是否安全"的判断。**核心矛盾**在于：如何在不更新参数、不依赖额外标注的前提下，判断边界失效是否可修复，并以可控、可验证的方式扩展TFM的能力边界。

## 二、方法论：SkillTFM

### 2.1 核心思想

SkillTFM将TFM的适应问题重新定义为**"基于证据的边界扩展决策"**——将适应从参数更新转变为**门控外部技能状态（gated external skill state）**的演化。系统决定当前任务是落入"基座模型可靠"、"可修复的边界失效"还是"证据不足需回退"三类状态之一。若证据支持且有已验证技能，则执行修复；否则回退到基座模型输出。

### 2.2 技能状态结构

技能状态形式化为：

```
S = (E, O, R, G, F, B, P)
```

- **E**：证据提取规则
- **O**：修复技能库
- **R**：排名规则
- **G**：风险守卫
- **F**：回退规则
- **B**：被拒绝路径约束
- **P**：原则记忆

### 2.3 证据条件化的边界扩展（运行时）

1. **证据提取**：`zT = E(T, M)`，从任务和基座模型行为中提取可观测信号，包括：
   - 特征分布变化
   - 标签-特征关系
   - 预测偏差
   - 趋势/周期性
   - 缺失模式
   - 扰动敏感性
   - 运行时**不使用当前测试标签**。

2. **技能激活**：候选修复集为满足适用条件且不触发禁忌条件的技能：
   ```
   C(zT, S) = {o ∈ O : zT ∈ required(o), zT ∉ contraindicated(o)}
   ```

3. **排序元组**：每个候选按可审计的元组排序：
   ```
   q(o, zT; S) = (rsup, rhist, −rrisk, −rmem, −cost)
   ```
   分别对应证据支持度、历史可靠性、执行风险、记忆约束相似度、干预成本。

4. **运行时证书（gating policy）**：按序扫描候选，仅当**证据充分 AND 风险可接受 AND 记忆不阻断**时执行首个通过证书的修复；若无候选通过，则**回退**到基座预测。

### 2.4 验证门控的技能演化

执行痕迹（execution trace）不直接改变部署状态；候选编辑须通过**晋升门（promotion gate）**才能成为已验证更新：

- **改进度量**（选择任务上）：
  ```
  Gsel(ΔS) = (1/|Tsel|) Σ [U(T, St⊕ΔS) − U(T, St)]
  ```

- **危害率**（守卫任务上）：
  ```
  Hsel(ΔS) = (1/|Tguard|) Σ 1[U(T, St⊕ΔS) < U(T, St) − δ]
  ```

- **晋升条件**：改进达阈值 ∧ 危害率低于限制 ∧ 回归审查通过 ∧ 编辑格式合法：
  ```
  Promote(ΔS) = 1{Gsel ≥ ε, Hsel ≤ α, RegressionPass = 1, SchemaPass = 1}
  ```

- 被拒绝的编辑存入技能记忆，成为未来提议的约束；系统保留回滚快照。

## 三、实验设计

### 3.1 基座模型

以 **TabPFN、TabICL、TabDPT、LimiX** 四个TFM作为基座预测器，SkillTFM以外部技能状态进行免训练适应，不修改任何参数。

### 3.2 评估场景与Benchmark

- **受控边界套件（Controlled Boundary Suite）**：覆盖7种边界族——不稳定依赖、分布偏移、缺失性、不平衡、标签噪声、高维干扰、非线性边界。每种边界有明确的构造机制、可观测证据和目标压力（见表5）。
- **三种评估机制**：
  1. **Held-out**：学习过的单一边界类型的新任务。
  2. **Mixed**：多边界因素混合任务。
  3. **Generator/severity transfer**：以不同生成器或参数重新生成已学习边界类型。

## 六、主要结论与发现

1. **免训练适应可行且有效**：SkillTFM在三种边界转移机制下提升AUC 0.128–0.142，零观测危害。
2. **技能演化创造新能力**：从未支持的非线性边界AUC 0.699→0.898（+0.199），证明验证门控演化能扩展技能库。
3. **选择性干预是核心机制**：整体回退率约42%–48%，在C4高可靠区域回退率高达98.8%，表明系统不会盲目修复。
4. **跨模型与跨优化器可移植**：同一技能状态对4种TFM均提升AUC 0.139–0.148；外部LLM仅作提议者，无法直接修改部署状态。
5. **真实场景有效**：电价预测MAE从53.02降至25.16（-52.5%），修改仅38.2%预测点，覆盖83.4%的大误差点，零危害。

## 七、优点

- **范式创新**：首次将"技能学习"引入TFM免训练适应，将修复视为证据条件化的动作而非默认行为。
- **可验证与安全**：晋升门（改进/危害率/回归/格式四重检查）+运行时证书+回退机制，使系统在扩展边界同时保持可审计性和零危害保证。
- **可扩展与可插拔**：技能状态独立于具体TFM骨干和LLM优化器，具备跨模型/跨优化器迁移能力。
- **问题定位精准**：指出TFM边界失效不是全局开关，而是依赖局部数据模式、误差趋势和修复风险；分层分析（C1–C4）和真实场景可视化有力地支撑了这一论点。
- **实验设计严谨**：评估标签仅用于分组、目标标签在开发阶段不可见、边界套件构造可控，消融实验分离了各组件的独立贡献。

## 八、不足与局限

1. **缺乏外部基线对比**：仅与自身消融变体比较，未与现有方法（如数据预处理、分布鲁棒性方法、校准、选择性预测等）直接对比，削弱了相对优势的说服力。
