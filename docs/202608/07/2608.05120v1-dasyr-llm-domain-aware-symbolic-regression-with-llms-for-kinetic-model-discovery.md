## 摘要
动力学模型发现是化学工程中的一个核心挑战，因为准确的速率表达式对于理解和控制化学与生物过程至关重要。符号回归（SR）已成为识别可解释动力学模型的一种强大的数据驱动方法，但通常在没有领域知识的情况下运行，常常探索物理化学上不合理的模型。大语言模型（LLM）为将领域专业知识注入这一搜索过程提供了有前景的途径。在此，我们引入了一个LLM引导的SR框架，将LLM模块嵌入迭代SR算法中，用于自动化动力学模型发现。LLM在每次迭代中承担两个角色：（1）对最佳SR候选模型进行定性物理化学批评；（2）在SR生成模型和内置化学知识的指导下提出新的候选速率表达式。我们在四个复杂度递进的硅内案例研究中评估了该框架，涵盖多相催化和生物过程系统。结果表明，与最先进的SR框架相比，LLM引导框架将识别真实模型的迭代次数减少了41.7%–79.3%，且LLM在超过一半的引导运行中直接提出了正确的模型结构。在实际应用中，每次迭代通常需要新的湿实验，这转化为实验工作量的显著减少。两种方法在独立验证集上的预测性能相当，所有案例研究中R²>0.98。消融研究表明，SR组件和LLM规模都对这一性能有所贡献，而减小规模的LLM在很大程度上保持了发现效率。这些发现表明，LLM可以有效地将领域知识注入科学模型发现，为全自动、领域感知的动力学建模流程铺平了道路。

## Abstract
Kinetic model discovery is a central challenge in chemical engineering, as accurate rate expressions are essential for understanding and controlling chemical and biological processes. Symbolic regression (SR) has emerged as a powerful data-driven approach for identifying interpretable kinetic models, but usually operates without domain knowledge, often exploring physicochemically implausible models. Large language models (LLMs) offer a promising avenue for injecting domain expertise into this search. Here, we introduce an LLM-guided SR framework, embedding an LLM module within an iterative SR algorithm for automated kinetic model discovery. The LLM performs two roles at each iteration: (1) a qualitative physicochemical critique of the best SR candidates, and (2) the proposal of new candidate rate expressions guided by the SR-generated models and embedded chemical knowledge. Our framework is evaluated on four in silico case studies of increasing complexity, spanning heterogeneous catalysis and bioprocess systems. Results show the LLM-guided framework reduces iterations to identify the ground-truth model by $41.7-79.3\%$ versus a state-of-the-art SR framework, with the LLM directly proposing the correct model structure in over half of the guided runs. In practical settings, where each iteration typically requires a new wet-lab experiment, this translates into a substantial reduction in experimental effort. Predictive performance on an independent validation set is equivalent between both approaches, with $R^2>0.98$ in all case studies. Ablation studies indicate that both the SR component and the LLM scale contribute to this performance, with a reduced-size LLM largely retaining discovery efficiency. These findings demonstrate that LLMs can effectively inject domain knowledge into scientific model discovery, paving the way toward fully automated, domain-aware kinetic modelling pipelines.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 整体框架（DASyR-LLM）

- 以 **ADoK-S**（强形式化版本，先通过 SR 拟合浓度轨迹再求导得到速率估计）为底层 SR 骨干，嵌入一个 **LLM 模块**，构成九步迭代循环：
  1. 从真实系统/合成模型生成浓度数据；
  2. 对浓度数据执行 SR，拟合各物种的浓度轨迹 h(t)；
  3. 基于 AIC 选择每个物种的最佳浓度模型；
  4. 对 h(t) 解析求导得到速率估计 ḣ(t)；
  5. 以 ḣ(t) 为回归目标、浓度为输入执行 SR，得到候选速率表达式；
  6. 对 SR 生成的速率模型进行参数精炼（ODE 积分 + 非线性最小二乘）；
  7. **LLM 模块**：批判 top-k<sub>SR</sub>（=5）最佳 SR 候选的物理化学合理性，并基于批判结果提出 n<sub>gen</sub>（=3）个新候选速率表达式（3 个并行 LLM 实例，最多 9 个新候选/轮）；
  8. 对所有候选（SR + LLM 提出）计算 AIC 并排序；若找到真实模型则停止；
  9. **MBDoE**：基于排名前二模型的预测轨迹差异最大化（Hunter-Reiner 准则）设计新的初始条件，生成新实验并入数据集，循环迭代直至收敛或预算耗尽（12 轮）。

### 2.2 关键技术细节

- **两阶段 SR 策略**：先从浓度数据拟合可微的轨迹模型，再对导数做速率定律 SR。这避免了在遗传编程搜索中直接做 ODE 参数估计（计算上不可行），同时提高导数估计稳定性。
- **参数估计**：对 LLM 提出的候选模型仅给结构、无初始参数，需先随机初始化再精炼；采用 L-BFGS-B + 20 次多起点优化（multistart），取 SSE 最低解。
- **模型选择**：基于 NLL 的 AIC，NLL 中每个物种独立估计测量方差（对角加权）。
- **LLM 提示设计**：两个任务分别使用结构化提示——步骤 1 提示包含全局反应、物种名、top-5 候选表达式及其 AIC/NLL、少量示例（few-shot）；步骤 2 输入步骤 1 的批判文本，要求提出机理可解释的、与原候选结构不同的新表达式。作者刻意采用自由文本而非 JSON 结构化输出，以保留推理灵活性（代价是需人工解析）。
- **LLM 配置**：Qwen3-14B，开启 thinking 模式，temperature=0.6、top-p=0.95、top-k=20。

### 2.3 算法流程（文字版）

```
输入：初始数据集 D（2 个实验×30 点/实验）、实验预算 nB=12、kSR=5、nLLM=3、ngen=3
循环（直到识别真实模型或达到预算）：
  ① 对 D 执行 SR → 候选浓度模型 → AIC 选优
  ② 对浓度模型求导 → 速率估计
  ③ 对速率估计执行 SR → 候选速率表达式 → ODE 积分精炼参数

  ⑤ 计算所有候选的 AIC → 若真实模型被识别则终止
  ⑥ 取 top-2 模型，用 MBDoE 设计新实验初始条件 → 生成新数据并入 D

```

## 6. 主要结论与发现

1. **迭代效率显著提升**：LLM 引导框架将识别真实模型（或等价近似）所需的迭代次数平均减少 **41.7%–79.3%**（甲苯加氢脱烷基 50.0%、N₂O 分解 73.7%、异构化 41.7%、细菌蛋白生产 79.3%）。每次迭代对应一个新 MBDoE 实验，直接转化为湿实验成本的节省。
2. **LLM 直接贡献明显**：16 次 LLM 引导运行中，9 次最终模型由 LLM 直接提出（超过一半），7 次 LLM 将搜索引导至正确函数形式后由 SR 恢复。
3. **预测精度未受损**：两种方法在独立验证集上的 R² 均 >0.98，分布相近，说明迭代效率提升不以牺牲模型质量为代价。
4. **领域知识价值最大化场景**：改进幅度最大的案例（N₂O 分解、细菌生产）恰是纯数据驱动搜索最困难的系统，表明 LLM 领域知识在结构不易被数据驱动的场景中价值最大。
5. **消融结论**：去掉 SR 后，无数据访问的 LLM-Only 变体收敛可靠性下降（2 次运行中 1 次未在预算内收敛、另 1 次需 6 轮），表明 SR 提供的"数据锚定"候选结构对 LLM 推理至关重要；LLM 规模从 14B 降至 8B 后仍能全部收敛（2–5 轮），说明框架收益并非大模型专属。
6. **可解释性附加收益**：LLM 在每轮提供机理层面的定性批评估，可过滤物化上不合理的候选（如生物量增长速率为正依赖于产物浓度这类结构）。

## 8. 缺点与局限性

- **合成数据验证，缺乏湿实验闭环**：全部案例均为 in silico 合成系统，虽可精确控制噪声与真值，但未能证明框架在真实实验数据（如不确定的测量系统误差、模型缺失、批次效应）下的鲁棒性。真实化学/生物体系的噪声明晰度远低于合成数据，LLM 的“领域知识”也可能与实际系统不符。
- **消融实验覆盖不足**：LLM-Only 与缩减模型消融仅在细菌蛋白生产一个案例上开展，且重复次数少（各 2 次与 4 次），统计功效不足。作者虽承认这一点，但仍无法排除框架收益在催化系统中对 LLM 分量敏感度不同的可能。
- **LLM 提示与输出解析依赖人工**：框架刻意采用自由文本输出以保留推理灵活性，但步骤 7 的批判与生成结果需要人工读取并转化为符号表达式，这阻碍了完全自动化闭环的实现（论文未给出自动解析方案）。在实际大规模实验筛选场景中，人工介入成本可能抵消部分效率收益。
- **计算开销集中于 LLM 推理**：每轮 LLM 推理耗时 322–998 秒，且随轮次增长有上升趋势（上下文累积），在 14B 模型下总体墙钟时间约是纯 SR 基线的 1.5–2 倍以上。尽管迭代次数减少，但单位迭代的成本显著增加；若模型更大则成本更高，可能削弱“实验预算节省”的实际意义（尤其是湿实验成本远高于计算成本时除外）。
- **模型选择（AIC）对候选池质量的依赖**：LLM 提出新候选后，AIC 排序仍以数据拟合为主导。若 LLM 提出结构与真实模型完全不同的“可解释”表达式，且某些随机初始条件下数据拟合不差，则 AIC 可能给予误导性支持，导致算法进入错误搜索方向（作者未分析此类失败案例）。
- **LLM 可能生成“看似合理但物化上无效”的候选**：论文未量化 LLM 候选的被拒绝率（即无法通过参数估计或显著低于 SR 候选的比例）。自由文本生成模式意味着大规模运行时缺少自动过滤机制，非物理表达式可能增加后续参数估计负担。
- **实验设计（MBDoE）仅考虑 top-2 模型差异**：对多候选情形，仅用前两名设计新实验可能忽略其他有潜力的结构，导致搜索早熟。这与作者选择的简单策略有关，但论文未探讨更鲁棒的设计准则（如加权贝叶斯 D-optimal）。
- **通用性与提示敏感性**：LLM 的表现可能高度依赖提示中 few-shot 示例的选择、任务表述甚至模型自身版本，论文未做提示敏感性分析。不同领域用户可能需要重新设计提示才能获得类似收益，框架推广存在隐性工程成本。

## 9. 对学术研究与工业实践的意义

- **推动 AI-for-Science 的方法论融合**：该工作展示了一个“数据驱动搜索 + 领域知识批判 + 主动实验设计”的闭环范式，不局限于动力学建模，可迁移到材料配方、生态模型、药物代谢等需要从稀疏数据中发现结构化机制的领域，为 LLM 参与科学发现提供了可复制的架构参考。
- **挑战“唯数据论”的 SR 范式**：通过证明 LLM 的定性先验能显著压缩符号搜索空间，论文动摇了“最可靠的发现必须完全依赖无偏统计拟合”的传统观念，为“小而精”的数据集场景（如药物合成、稀有材料）带来效率提升希望。
- **填补自动化实验设计中的“机理知识注入”空白**：现有的 MBDoE 方法通常在给定候选模型集合内优化质量，而 DASyR-LLM 将 LLM 作为“新候选生成器”打破模型池边界，使主动学习不再受限于预先定义的假设空间，这对闭环自动实验室具有直接的工程意义。
- **对成本敏感科研场景的启示**：如果湿实验成本极高而 LLM 推理成本较低，即使迭代次数减少 40%–80%，也能显著降低总实验预算。该方法支持在不更改后端 SR/ODE 基础设施的条件下替换或升级 LLM 版本，便于实际团队采纳。
- **凸显模型可信性评估的重要性**：论文同时报告拟合统计、参数置信区间、验证集外推性能与迭代收敛情况，为后续工作如何严谨评估“AI 发现科学规律”提供了良好的评估模板。

## 10. 未来方向（论文隐含与合理推测）

- **自动化 LLM 输出解析**：使用结构化生成（有约束解码）或专用解析器，消除人工介入，实现端到端全自动闭环。
- **跨案例多任务迁移**：将同一 LLM 在多种体系上的批判经验作为“元知识”，提升对新体系的初始候选质量，减少必要迭代轮数。
- **替代 AIC 的鲁棒模型选择**：引入贝叶斯模型平均或 LLM 对候选物理合理性打分来辅助排序，降低错误方向风险。
- **与更先进 LLM 结合**：将 14B 骨干替换为更大模型（如 70B 级）或许能进一步提升生成候选的物化正确率，但需权衡推理延迟。
- **扩展到真实实验室验证**：在封闭式自动化平台（如液体处理机器人）上集成该框架，以真实催化/生物实验检验其在噪声、缺失数据及测量误差条件下的实用性。
- **结合时序不确定性**：当前 MBDoE 基于浓度预测均值差异，未来可引入异构方差或模型参数不确定性，提高实验设计效率。

**总体评价**：DASyR-LLM 提出了一个新颖、模块化且具有实际可用价值的 LLM 引导符号回归框架，在多个合成动力学系统上取得了显著的迭代效率提升，同时保持高精度与可解释性。其局限在于验证环境偏理想化、消融覆盖不足以及人工解析依赖，但作为概念验证与未来 AI 自动化科学发现的基础，无疑是一个坚实且有启发性的工作。
