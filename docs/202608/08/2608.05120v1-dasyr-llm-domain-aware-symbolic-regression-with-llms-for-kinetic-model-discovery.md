## 摘要
动力学模型发现是化学工程中的一个核心挑战，因为准确的速率表达式对于理解和控制化学及生物过程至关重要。符号回归（SR）已成为识别可解释动力学模型的一种强大数据驱动方法，但通常在没有领域知识的情况下运行，常常探索物理化学上不合理的模型。大型语言模型（LLM）为将领域专业知识注入这一搜索提供了一条有前景的途径。在此，我们引入了一个LLM引导的SR框架，将LLM模块嵌入迭代SR算法中，用于自动化动力学模型发现。在每个迭代中，LLM扮演两个角色：（1）对最佳SR候选模型进行定性物理化学批评；（2）在SR生成的模型和内置化学知识的指导下，提出新的候选速率表达式。我们的框架在四个复杂度递增的计算机模拟案例研究上进行了评估，涵盖多相催化和生物过程系统。结果表明，与最先进的SR框架相比，LLM引导框架将识别真实模型的迭代次数减少了41.7%至79.3%，并且在超过一半的引导运行中，LLM直接提出了正确的模型结构。在实际应用中，每次迭代通常需要新的湿实验，这转化为实验工作量的显著减少。两种方法在独立验证集上的预测性能相当，所有案例研究的R²>0.98。消融研究表明，SR组件和LLM规模都对这一性能有所贡献，而缩小规模的LLM在很大程度上保持了发现效率。这些发现表明，LLM可以有效地将领域知识注入科学模型发现中，为完全自动化、领域感知的动力学建模流程铺平了道路。

## Abstract
Kinetic model discovery is a central challenge in chemical engineering, as accurate rate expressions are essential for understanding and controlling chemical and biological processes. Symbolic regression (SR) has emerged as a powerful data-driven approach for identifying interpretable kinetic models, but usually operates without domain knowledge, often exploring physicochemically implausible models. Large language models (LLMs) offer a promising avenue for injecting domain expertise into this search. Here, we introduce an LLM-guided SR framework, embedding an LLM module within an iterative SR algorithm for automated kinetic model discovery. The LLM performs two roles at each iteration: (1) a qualitative physicochemical critique of the best SR candidates, and (2) the proposal of new candidate rate expressions guided by the SR-generated models and embedded chemical knowledge. Our framework is evaluated on four in silico case studies of increasing complexity, spanning heterogeneous catalysis and bioprocess systems. Results show the LLM-guided framework reduces iterations to identify the ground-truth model by $41.7-79.3\%$ versus a state-of-the-art SR framework, with the LLM directly proposing the correct model structure in over half of the guided runs. In practical settings, where each iteration typically requires a new wet-lab experiment, this translates into a substantial reduction in experimental effort. Predictive performance on an independent validation set is equivalent between both approaches, with $R^2>0.98$ in all case studies. Ablation studies indicate that both the SR component and the LLM scale contribute to this performance, with a reduced-size LLM largely retaining discovery efficiency. These findings demonstrate that LLMs can effectively inject domain knowledge into scientific model discovery, paving the way toward fully automated, domain-aware kinetic modelling pipelines.

## 2. 提出的方法论

### 2.1 整体框架架构

DASyR-LLM建立在ADoK-S（一个结合SR、参数估计、AIC模型选择和MBDoE的迭代发现框架）之上，整个流程共9个步骤：

1. **生成浓度数据**：由已知的ground-truth系统模拟合成数据（加入高斯噪声 σ=0.1）。
2. **对浓度数据做SR**：用PySRRegressor对每个物种拟合解析轨迹模型 h(t)，从Pareto前沿中经AIC选出最优。
3. **选择浓度模型**（按AIC）。
4. **估计速率**：对 h(t) 用numdifftools求数值导数，得到速率估计 ˙h(t)。
5. **对估计的导数做SR**：以 ˙h(t) 为回归目标、测量浓度为输入，发现候选速率表达式。
6. **参数估计**：对SR生成的速率模型，用PySR内部参数作为初值，通过ODE积分（L-BFGS-B + 20个随机起点多起点策略）最小化SSE来精炼参数。
7. **LLM模块**（核心创新）：
   - **任务1（模型批判）**：LLM接收top-kSR（kSR=5）SR候选模型的结构、参数值、NLL和AIC，从反应机理、参数量级、化学合理性等方面进行定性评估。
   - **任务2（模型提出）**：基于批判结果，LLM提出 ngen=3 个新候选速率表达式，且要求结构上与现有候选不同、可机理解释。
   - 每个LLM执行 nLLM=3 次并行，最多产生 3×3=9 个新候选；所有新候选进入参数估计和AIC排序。
8. **模型选择（AIC）**：对所有候选（SR + LLM提出）计算AIC并排序；若识别到ground-truth模型则终止，否则选出AIC最低的两个模型进入MBDoE。
9. **MBDoE**：通过最大化两个竞争模型预测轨迹的差异（Hunter-Reiner准则），优化新实验的初始条件 C0，生成新数据并入数据集。

循环迭代直至找到ground-truth模型或用完实验预算（nB=12次迭代，即11次额外实验）。

### 2.2 关键算法/公式要素

- **动态系统模型**：˙C(t) = f(C(t))，C(t0)=C0。
- **参数估计**：最小化 SSE(m)，采用ODE积分预测轨迹（即预测值来自模型积分而非直接拟合测量点），再以AIC做模型选择（AIC = 2·NLL + 2d，NLL按各物种独立方差计算）。
- **MBDoE目标函数**：C0^(new) = argmax ∫‖ˆCm1(τ; C0, θm1) − ˆCm2(τ; C0, θm2)‖² dτ。
- **提示词设计**：LLM模块使用两个独立的结构化提示（Step 1批判+Step 2提出），每个提示包含全局反应、物种名、候选表达式+性能指标，并配有一个one-shot示例；输出为自由文本，由人工解析为符号表达式。

- **合计**：40次完整流程实验，加1个独立验证集（120条件/案例）。

### 5.2 充分性与公平性评价

- **充分性较好**：主实验每个案例有4次独立重复，覆盖随机性；消融设计能分离SR组件、LLM规模等因素的贡献；验证集覆盖插值、边界、外推，评估较为全面。
- **公平性问题**：LLM-Only有数据变体给LLM提供了完整原始浓度-时间数据，而主框架中LLM只接触符号候选和拟合统计量——作者也承认该设置"偏向上限场景"，不可直接对比。
- **局限性**：消融仅在单一案例（细菌生产）上进行，结论的**泛化性有限**；基准案例仅4个，规模偏小；所有数据均为合成数据，未在真实湿实验数据上验证。

## 6. 主要结论与发现

- **迭代效率大幅提升**：LLM引导框架收敛所需的平均迭代次数较Baseline SR减少41.7%–79.3%（甲苯加氢脱烷基50.0%、N2O分解73.7%、异构化41.7%、细菌生产79.3%）。由于每次迭代对应一次新实验，这直接转化为实验资源的大幅节约。
- **LLM直接提出正确模型**：16次LLM引导运行中，**9次最终模型由LLM直接提出**；7次LLM将搜索引向正确结构后被SR恢复。在N2O分解案例中，Baseline SR有2/4次在预算内未收敛，而LLM引导全部收敛。
- **预测性能相当**：独立验证集上所有案例R²均>0.98，两种方法表现分布相似，说明迭代减少**不以牺牲模型预测精度为代价**。
- **参数显著性**：部分收敛模型含单个不显著项，去除后即为ground-truth，说明LLM引导能收敛到正确函数形式；个别案例（Run 32）存在显著但数值很小的偏移项。
- **消融结论**：
  - 移除SR（LLM-Only）后，收敛可靠性下降（无数据变体有一半运行未收敛），说明**SR提供的数据锚定的候选结构对LLM推理很重要**；
  - 当LLM直接获得原始数据时，可在迭代1即提出正确结构，但这是额外信息；
  - Qwen3-8B在4/4次运行中均收敛（2–5次迭代），说明**框架对LLM规模具有鲁棒性**，但基于单一案例，需更多验证。

## 7. 优点

- **创新性角色设计**：LLM既做**定性批判**又做**候选生成**，两种角色互补，且都与MBDoE闭环结合——这在以往LLM辅助科学发现工作中未见。
- **领域知识显式注入**：LLM能依据反应类型、参数量级、机理合理性等对SR候选做出物理化学判断，过滤统计上拟合好但机理上不合理的表达式（如细菌案例中LLM明确拒绝引入负增长阈值的SR候选，转向Monod型结构）。
- **模块化与可移植性**：LLM模块仅作用于参数估计的输出和模型选择的输入，不改动底层SR和实验设计，可适配不同SR骨干和不同LLM。
- **可解释性增强**：每一轮LLM的批判和提案都提供机理说明，形成可审计的"发现日志"（代码库中已开源）。
- **统计严谨性**：对最终模型提供参数置信区间和显著性检验，识别了接近真实模型的表达式中的非显著项。
- **实用价值明确**：以迭代数减少等价实验数节约，贴合湿实验环境下实验成本主导的现实约束。

## 8. 不足与局限

- **计算开销较高**：LLM推理和新增候选的参数估计使每迭代时间显著高于Baseline；只有在实验成本远超计算成本时，该权衡才划算。
- **需要人工介入**：LLM输出为自由文本，需人工解析为符号式，尚未实现端到端自动化。
- **参数估计不保证全局最优**：多起点L-BFGS-B仍有陷入局部最优风险，尤其是LLM提出的候选缺乏内嵌参数初值时，可能因初始化不佳被AIC错误淘汰。
- **合成数据假设理想**：假设所有物种都可直接测量、误差为0均值高斯噪声、无系统性偏差或缺失数据，这些在真实湿实验中不一定成立。
- **案例覆盖有限**：4个案例（3个经典文献案例+1个生物过程）规模小，且未涉及大型反应网络、PDE系统或其他非动力学领域。
- **预训练暴露风险**：大部分案例来自经典教材/文献，LLM可能在预训练中见过相关内容；虽然作者论证了消融实验表明非单纯记忆，但无法完全排除。（Qwen3作为开源模型，其训练数据是否包含这些文献无法确认。）
- **模型选择无明确停止准则**：研究中未采用AIC差异阈值等早期停止策略，在真实应用（未知ground-truth）中如何判断"已收敛"仍是一个开放问题。
- **机制判断存在主观性**：所谓"物理化学合理性"评估依赖LLM的内部知识，缺乏可量化的机理评分函数，不同LLM或不同提示可能导致不同判断。
