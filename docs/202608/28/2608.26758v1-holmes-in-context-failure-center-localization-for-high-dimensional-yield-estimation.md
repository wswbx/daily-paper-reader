## 摘要
高sigma良率估计中的重要性采样需要从严重不平衡的样本集中定位失效中心。现有的代理辅助方法依赖于迭代的基于梯度的训练，在极端类别不平衡下是不适定的；模型误差会传播到估计器中，导致高维下的精度崩溃。我们将失效中心定位重新表述为少样本二元分类：一个预拟合的表格基础模型在单次前向传播中执行无梯度的上下文推理，从而消除了不适定的训练循环。HOLMES（通过流形估计与采样的高sigma最优定位）结合了一种基于SVD的各向异性提议分布，该分布捕获失效流形的局部几何，并采用命中率驱动的自适应混合方案，在常规自适应崩溃的情况下稳定重要性权重。在跨越$D = 108$到$D = 1{,}152$的6T SRAM基准测试中，全维度基线在某个维度上出现精度崩溃，最强基线的相对误差达到25.8%；另外在最大的两个维度上评估了PCA+MNIS。HOLMES在所有五个配置中相对误差保持在5.9%以内，相对于蒙特卡洛方法具有高达$58.8\times$的加速。代码可在 https://github.com/IceLab-JCIE/ICE006-Yield-Holmes 获取。

## Abstract
Importance sampling for high-sigma yield estimation requires locating the failure center from a severely imbalanced sample set. Existing surrogate-assisted methods rely on iterative gradient-based training, ill-posed under extreme class imbalance; model errors propagate into the estimator, causing accuracy collapse in high dimensions. We recast failure-center localization as few-shot binary classification: a prior-fitted tabular foundation model performs gradient-free in-context inference in a single forward pass, eliminating the ill-posed training loop. \textbf{HOLMES} (High-sigma Optimal Localization via Manifold Estimation and Sampling) pairs this with an SVD-based anisotropic proposal that captures the local geometry of the failure manifold, and a hit-rate-driven adaptive mixing scheme that stabilizes importance weights where conventional adaptation collapses. On 6T SRAM benchmarks spanning $D = 108$ to $D = 1{,}152$, full-dimensional baselines exhibit accuracy collapse at some dimension, with the strongest baseline reaching 25.8\% relative error; PCA+MNIS is additionally evaluated at the two largest dimensions. HOLMES remains within 5.9\% across all five configurations with up to $58.8\times$ speedup over Monte Carlo. The code is available on \href{https://github.com/IceLab-JCIE/ICE006-Yield-Holmes}

## 2. 方法论

### 2.1 核心思想
- 失效中心定位只需要找到“失效/通过”的决策边界，而无需拟合全局电路响应模型，因此本质上是分类问题。
- 使用预训练的TabPFN（表格基础模型）在给定带标签上下文集的情况下，通过单次前向传播输出后验失效概率，无需任何参数更新或梯度训练，天然适应小样本和极端类别不平衡。

- 初始化数据集 $D$（从先验采样）和 $q=p$；
- 每轮迭代：若维度超限则特征选择 → 构建上下文集 → TabPFN输出概率 → 计算得分 → 选top-$m$ → SVD构造提议 → 从混合分布采样并SPICE评估 → 更新数据集与 $\alpha$；

## 6. 主要结论与发现

- HOLMES在所有五个配置上相对误差保持在**5.9%以内**（最低0.1%），而所有全维度基线均在某个维度出现精度崩溃（峰值误差24.5%~100%）。
- 相比蒙特卡洛，HOLMES取得 **58.8×加速**（在 $D=108$），且在高维下仍保持7.7~21.3倍加速。
- 固定 $\tau=0.1$ 的稳健性测试表明无需特殊调度即可得到稳定估计，CV不超过3.6%。
- 分类器替换实验证实TabPFN是决定性因素：替换为常规分类器后误差升至28.7%~73.8%，而TabPFN仅0.1%。
- 消融实验表明SVD提议和命中率自适应都不可或缺：移除SVD在 $D=864$ 误差增至11.88%，移除自适应在 $D=108$ 误差增至40.95%。
- HOLMES避免了“假收敛”（FOM稳定但估计错误）和“不收敛”两类传统方法的失效模式。

## 7. 优点

- **问题重构巧妙**：将失效中心定位从回归/参数拟合转化为少样本分类，降低了问题难度并提高了对极端不平衡的鲁棒性。
- **免训练、免梯度**：利用TabPFN的上下文推理，无训练循环，避免了梯度方法在高维不平衡下的不适定问题。
- **几何自适应提议**：SVD各向异性提议能够捕捉失效流形的局部几何，且维度越高优势越明显。
- **稳定自适应机制**：命中率驱动的混合更新替代ESS，避免了高维下权重退化。
- **实验验证充分**：在多个维度、多种基线、消融和替换分析下验证了各组件的必要性，证明方法有效且可解释。
- **工程实用性**：所需SPICE调用数（1700~13000）远低于MC，模型计算开销占比极低，具备实际应用潜力。

## 8. 不足与局限

- **假设单一失效区域**：当前方法假设存在一个主导失效中心，未覆盖多失效区域（well-separated failure modes）的电路，作者也将其列为未来方向。
- **依赖TabPFN的输入限制**：特征选择步骤可能丢失高阶交互信息；当 $D$ 极大且有效特征维度超过 $D_{\max}$ 时，性能可能下降。
- **特征选择基于线性互信息**：仅考虑单特征与标签的相关性，无法捕捉特征间联合效应。
- **实验场景有限**：仅针对6T SRAM读延迟失效，未推广到其他电路类型（如写延迟、漏电等）或更先进的工艺节点。
