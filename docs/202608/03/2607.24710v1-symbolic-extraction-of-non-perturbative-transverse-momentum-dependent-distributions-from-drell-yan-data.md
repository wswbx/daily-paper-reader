## 摘要
我们提出了一种对非极化夸克非微扰横向动量依赖（TMD）部分子分布函数的解析参数化，该函数通过神经网络拟合与符号回归相结合从Drell-Yan数据中提取。一个因子化神经网络直接在固定靶、Tevatron、RHIC和LHC实验的截面数据上以次次次领头对数精度进行训练，随后对每个网络分量应用符号回归以发现紧凑的解析表达式。最终公式从表达式复杂度和实验χ²构成的Pareto前沿中选出，得到一个具有9个自由数值常数的闭合形式非微扰函数，在482个数据点上达到χ²/ndf=1.040。即使在偏向于零的稀疏先验下，一个非平凡的x-b_T交叉项仍被保留，表明纵向动量分数与横向动量之间存在轻微但真实的关联。这项工作表明，符号回归是连接灵活机器学习拟合与可解释解析TMD参数化的可行工具，并为数据驱动的非微扰QCD特定特征发现开辟了系统路径。

## Abstract
We present an analytical parametrization of the non-perturbative transverse-momentum-dependent (TMD) parton distribution function of unpolarized quarks, extracted from Drell-Yan data using a combination of neural-network fitting and symbolic regression. A factorized neural network is trained directly against experimental cross-section data from fixed-target, Tevatron, RHIC, and LHC experiments at next-to-next-to-next-to-leading logarithmic accuracy, and symbolic regression is subsequently applied to each network component to discover compact analytical expressions. The final formula is selected from a Pareto front in the space of expression complexity and experimental $χ^2$, yielding a closed-form non-perturbative function with 9 free numerical constants that achieves $χ^2/\mathrm{ndf}=1.040$ over 482 data points. A non-trivial $x$-$b_T$ cross term is retained even under a sparsity prior that biases it toward zero, indicating a mild but genuine correlation between the longitudinal momentum fraction and the transverse momentum. This work demonstrates that symbolic regression is a viable tool for bridging flexible machine-learning fits and interpretable analytical TMD parametrizations, and opens a systematic path toward data-driven discovery of specific features of non-perturbative QCD.

# 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 采用因子化神经网络对 f_NP 进行参数化，再对训练好的网络每个分量分别做符号回归，最后在“表达式复杂度–实验 χ²”构成的 Pareto 前沿上选择最终解析式。
- 所有参数量化精度为 N³LL（次次次领头对数精度），理论截面基于 TMD 因子化公式与 b* 演化和 Ogata 正交等标准处理。

### 参数化结构
- 非微扰函数写成：

  `f_NP(x, b_T; ζ) = exp[-g₂²(b_T) b_T² ln(ζ/Q₀²)] · R(x, b_T)`，其中 Q₀² = 1 GeV²。

- 形状函数进一步分解为：

  `R(x, b_T) = exp[h_x(x) h_b(b_T) + h_xb(x, b_T)]`，其中 h_xb 为 x–b_T 交叉项。

- 该分解是出于物理直观和符号回归可行性考虑：直接对二维函数做符号回归复杂度太高，分解为两个一维函数加一个小交叉项可降低搜索难度。

### 神经网络设计
- 所有网络均为浅层 MLP，tanh 激活：
  - h_x：单隐层、8 个神经元；
  - h_b：单隐层、8 个神经元，通过“输出减去 b_T=0 处输出”强制 h_b(0)=0；
  - g₂：单隐层、4 个神经元，输出经过 softplus 保证正值；
  - h_xb：单隐层、4 个神经元，同样通过输出差强制 h_xb(x,0)=0，并施加 L1 稀疏惩罚（λ=1e-4）和容量限制，防止交叉项吸收本属于主干的信号。
- 硬物理边界（b_T>10 或 x≥1 时 R=0）在评估时用掩码强制。

### 训练与损失
- 使用预计算的“卷积骨架”HDF5 文件保存所有数据点的正交权重、相空间因子、动量分数、演化尺度等，训练时只计算 f_NP 与权重乘积之和，避免重复计算积分。
- 实验协方差矩阵（含关联系统误差）经 Cholesky 分解后计算 χ²。
- 损失函数由三部分构成：
  1. 子集平衡的 χ² 损失（按 59 个实验子集分别归一化，并用 λ_bal=5 驱动子集 χ² 向均值靠拢）；
  2. h_xb 权重上的 L1 稀疏惩罚；
  3. 其余形状网络（h_x, h_b, g₂）的 L2 权重衰减。
- 训练最多 100,000 epochs，梯度裁剪阈值为 1.0，使用 Adam 类优化，g₂ 与形状网络采用不同的学习率；最终 checkpoint 根据“最差数据子集 χ² 最小化”的 minimax 准则选定。

### 符号回归与 Pareto 选择
- 对训练好的 h_x、h_b、h_xb、g₂ 在稠密网格上评估，调用 PySR 分别进行符号回归，每个分量产生一组复杂度–MSE 的 Pareto 候选。
- 将四个分量的帕累托候选全部组合成完整的 f_NP，再通过卷积骨架计算每个组合的实验 χ²，以“总复杂度（节点数之和）–实验 χ²/ndf”构成联合 Pareto 前沿。
- 最终选择复杂度 31 的候选：它满足全局 χ²/ndf≈1.040，且最差子集 χ² 已进入平台期（再增加 23 个复杂度单位只改善 0.09）。

# 6. 主要结果与关键发现

### 符号回归得到的最终解析式
- 论文在 Pareto 前沿上选出总复杂度 31 的表达式，并给出每个分量的具体闭式形式。  
- 整体非微扰因子具有“指数型二次项 × 修正因子”的结构，其中 h_b 是关于 b_T 的多项式/有理式组合，h_x 是 x 的多项式组合，g₂ 为常数或极低阶函数，h_xb 则以较稀疏的形式耦合 x 与 b_T。  
- 与常用的 Gaussian 形式（即 h_b 仅含 b_T² 项）相比，最终公式额外包含高次项与交叉项，表明实验数据在 N³LL 精度下更偏好有结构的偏离纯高斯行为；其偏离幅度大致在 10%–20% 量级。

### 实验 χ² 表现
- 全局 χ²/ndf ≈ 1.040，与 MAPNN 的拟合质量相当，但模型参数量从神经网络的上百个连续权重压缩为约 10 个解析参数，且表达式完全透明、可直接移植到其他理论框架。  
- 最差子集的 χ² 也已进入平台区：从复杂度 8 到 31 时下降明显，但从 31 到 54 仅改善 0.09，因此选 31 为最终复杂度满足“简洁性-拟合质量”折中。

### 与 MAPNN 的对比
- 在代表性观测区间（ATLAS 13 TeV, 66<Q<116 GeV 与 E605, 10.5<Q<11.5 GeV）中，两者对横截面的预言几乎重合，误差带宽度相似；拉值分布也没有系统性偏离。  
- 这说明：符号回归并不会牺牲拟合能力，反而能以更紧凑的形式复现神经网络的表达力；符号回归发现的公式在物理上更易于理解和后续应用。

# 7. 讨论与局限性

### 关于符号回归本身的局限
- 符号回归得到的表达式并非唯一，且搜索引擎倾向于生成由幂次、指数、对数等基本函数构成的组合；不同种子可能产生不同但等效的公式。论文通过 Pareto 前沿和实验 χ² 双重筛选来缓解这一问题，但仍无法保证找到的是“全局最优”解析形式。  
- 表达式的可解释性仍有限：例如 h_b 中出现的 b_T⁴ 等项缺乏直观的物理图像，更多是数据驱动的有效参数化，而非从 QCD 推导出的严格结果。

### 与理论框架的耦合
- 所有结论均基于 N³LL 的 TMD 因子化、b* 演化方案和设定的 Q₀²=1 GeV² 约定；若更换演化方案（如 ζ 势表述、不同 b* 形式），符号回归得到的公式结构可能改变。因此，其结果应视为“在特定理论框架下的有效参数化”，而非普适的非微扰函数唯一形式。

### 实验数据覆盖的制约
- 数据集中在 Drell-Yan 类过程，覆盖了 x≤0.1 的主体区域和中等的 Q；对极小 x（海夸克饱和区域）和极大 x（接近 1）的约束很弱，导致外推区域的不确定性很大。文中也明确强调了这一点，并建议未来纳入 SIDIS 和 e+e- 湮灭数据以扩大敏感区间。

### 计算与复现方面的保留
- 论文未公布最终符号回归表达式的完整系数数值表，也未给出训练与符号回归的详细超参数扫描和随机种子清单，这为复现和后续应用带来一定困难。  
- 虽然所有网络结构和损失函数均有描述，但“最差子集最小化”的 checkpoint 选择机制、L1 惩罚强度等关键细节说明得较简略。

# 8. 结论与展望

- **核心结论**：本文提出了一种将神经网络拟合与符号回归相结合、从 Drell-Yan 全球数据中自动提取非微扰 TMD 函数解析表达式的完整流程。在 N³LL 精度下，它找到了一个复杂度 31 的闭式公式，其全局 χ² 与 MAPNN 相当，但可解释性和可移植性显著提升。
- **方法论意义**：证明了机器学习不仅可用于“黑箱预测”，也能在物理约束和实验精度的驱动下“发现”紧凑的数学规律；该流程适用于其他非微扰函数（如 PDF、FF、GPD）的提取，具有较好的通用性。
- **未来方向**：
  - 将更多过程（SIDIS、e+e-）和更多可观测（向量的角分布等）纳入拟合，增强对 x–b_T 关联的约束；

  - 将所得解析式嵌入蒙特卡洛事件生成器和 QCD 工具包，检验其在实际应用场景中的数值稳定性与预测能力。
