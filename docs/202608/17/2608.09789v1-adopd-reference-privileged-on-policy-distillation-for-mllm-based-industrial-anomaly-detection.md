## 摘要
工业异常检测（IAD）需要识别与正常视觉模式的细粒度偏差。多模态大语言模型（MLLMs）可以通过在推理时将查询图像与参考图像进行比较来提高识别准确性，但这些优势依赖于额外的检索和处理。我们研究了参考比较的优势是否可以内化到模型参数中。在训练期间访问参考图像使得一个参考感知教师能够监督一个仅使用查询图像的学生模型。然而，教师可能倾向于基于查询线索或语言先验的看似合理的响应，而非有效的视觉信息。我们提出了ADOPD，一种参考特权在线蒸馏框架。教师评估在匹配和不匹配参考下学生生成的输出。匹配参考下的教师与学生输出的对数比率定义了token级别的学习方向，指明了学生应该学习的内容。两种参考视图之间的似然差距估计了参考特定的支持度，并校准了序列级别的权重。ADOPD在MMAD基准的零样本推理下达到了77.31%的平均准确率，比Qwen3-VL-4B主干网络提高了6.14个百分点，并比其单样本设置高出2.64个百分点。实验表明，ADOPD从参考比较中学习了一种细粒度的异常检查策略。该项目将在https://github.com/withTai/ADOPD 提供。

## Abstract
Industrial anomaly detection (IAD) requires identifying fine-grained deviations from normal visual patterns. Multimodal large language models (MLLMs) can improve recognition accuracy by comparing query images with references at inference time, but these benefits rely on additional retrieval and processing. We investigate whether the benefits of reference comparison can instead be internalized in the model parameters. Access to references during training allows a reference-aware teacher to supervise a query-only student. However, the teacher may favor plausible responses based on query cues or language priors rather than valid visual information. We propose ADOPD, a reference-privileged on-policy distillation framework. The teacher evaluates student-generated rollouts under matched and mismatched references. The matched-reference teacher-to-student log-ratio defines the token-level learning direction, specifying what the student should learn. The likelihood gap between the two reference views estimates reference-specific support and calibrates the sequence-level weight. ADOPD achieves 77.31% average accuracy on the MMAD benchmark under zero-shot inference, improving the Qwen3-VL-4B backbone by 6.14 points and outperforming its one-shot setting by 2.64 points. Experiments show that ADOPD learns a fine-grained anomaly inspection strategy from reference comparison. The project will be available at https://github.com/withTai/ADOPD.

# ADOPD：基于MLLM的工业异常检测中的参考特权在线蒸馏

## 1. 核心问题与整体含义（研究动机与背景）

工业异常检测（IAD）需要识别与正常视觉模式之间的细粒度偏差，在自动化制造和质量控制中具有基础性地位。近年来，多模态大语言模型（MLLMs）因其结合视觉感知与灵活语言推理的能力，为IAD提供了开放集识别和可解释推理的可能。然而，MLLM的开放域表征难以捕捉细粒度的局部偏差和产品特定的异常模式。

**关键观察**：研究者发现，类似人类检查员将产品与标准模板比对的做法，参考条件化推理（reference-conditioned inference）——即在推理时为模型提供一张正常参考图像——能够显著提升MLLM在IAD任务上的表现。但这种方式需要为每个查询额外检索和处理参考图像，带来了计算开销。

**核心问题**：能否将参考比较的优势内化到模型参数中，使得模型在**零样本推理**（无参考图像输入）时也能获得参考比较带来的收益？

**方法定位**：论文将训练时访问参考信息天然地建模为特权信息（privileged information）设置——教师模型在训练时能同时观察查询和参考证据，而学生模型只能观察查询图像。由此，参考比较不再作为部署时的输入，而是作为训练时的监督信号被"摊销"进模型参数中。

## 2. 方法论：ADOPD框架

### 2.1 核心思想

ADOPD的核心洞见是**将"学什么"（what to learn）与"学多强"（how strongly to learn it）分离**：

- **Token级学习方向**：由匹配参考下的教师-学生对数概率比率定义；
- **序列级更新强度**：由匹配/不匹配参考视图间的教师似然差距校准。

### 2.2 技术细节与算法流程

**（1）参考特权在线蒸馏（Reference-Privileged On-Policy Distillation）**

- 学生策略πS从仅查询提示x中采样G条rollout（轨迹）：$y_g \sim \pi_S(\cdot|x)$；
- 对于每条rollout中的每个token，冻结教师πT在同一学生生成前缀下，以匹配参考$r_{mat}$为条件计算token级优势：
  $$A^g_t = \text{sg}[\log p^T_g(t; r_{mat}) - \log p^S_g(t)]$$
- 这一定义与标准OPD的区别在于：教师获得了参考这一特权条件，而学生没有。

**（2）对比参考加权（Contrastive Reference Weighting）**

为防止教师仅凭查询图像线索或语言先验作出响应，ADOPD引入**不匹配参考**作为对照：

- 不匹配参考来自**相反异常状态**的区域证据，刻意破坏有效的查询-参考关系；
- 定义对比参考支持得分（contrastive reference support score）：
  $$s_g = \frac{1}{T_g}\sum_{t=1}^{T_g}[\log p^T_g(t; r_{mat}) - \log p^T_g(t; r_{mis})]$$
  该得分度量轨迹在有效参考关系被保留时是否被优先支持；
- 对同一提示的G条rollout进行组内相对校准，计算参考权重：
  $$w_g = s_g \left[1 + \text{clip}\left(\frac{s_g - \mu}{\sigma}, -\epsilon_w, \epsilon_w\right)\right]$$
  其中$\mu$和$\sigma$是$\{s_g\}$的均值和标准差；权重被detach且非负，只调整学习幅度而不改变匹配参考定义的更新方向。

**（3）校准优化目标**

- 将序列级权重广播到每个token，得到支持校准的token优势：$\hat{A}^g_t = w_g A^g_t$；
- 最终优化目标为：
  $$\mathcal{L}_{ADOPD} = -\frac{1}{G}\sum_{g=1}^{G}\frac{1}{T_g}\sum_{t=1}^{T_g}\hat{A}^g_t \log \pi_S(y^g_t | x, y^g_{<t})$$

### 2.3 与其他范式的对比

- **SFT（Off-Policy蒸馏）**：在固定教师生成的目标上训练学生，存在暴露偏差（exposure bias）；
- **Reference-Privileged OPD（无校准）**：在教师评估学生生成前缀上做策略梯度，但不确定教师支持是否真正基于参考比较；
- **ADOPD**：通过"匹配/不匹配"参考的**不对称干预**，同时提供学习方向和该方向的可信度。

## 6. 主要结论与发现

1. **ADOPD在零样本推理下达到77.31%的平均准确率**，将Qwen3-VL-4B主干提升6.14个百分点，并**超过该骨干的one-shot设置2.64个百分点**——说明参考比较的优势可以被完全内化到模型参数中，无需在推理时提供参考图像；
2. ADOPD超越了IAD专用模型Reason-IAD（76.71%）0.60个百分点，且使用了更小的4B主干（vs 8B）；
3. 性能提升**集中在比较敏感的异常识别任务**：异常判别（88.44%，较最佳竞争方法高12.72点）、缺陷定位（+2.49点）、缺陷分析（+0.28点）；而在缺陷分类、描述和物体分类上未超过最佳竞争者——说明ADOPD学到的是参考比较带来的细粒度检查策略，而非通用语义能力的提升；
4. ADOPD显著提高了**召回率**（94.27%，较one-shot基线高23.95点）和F1（92.32%，+14.08点），意味着更少的漏检，代价是精确率下降3.93点——表明ADOPD倾向于更敏感地发现潜在缺陷；
5. 对比参考加权（contrapositive reference weighting）是关键组件：校准后的ADOPD（77.31%）优于无校准的OPD（74.95%）和不匹配参考的替代方案（随机裁剪为75.80%、无对照为75.09%）。

## 7. 优点

1. **问题定义清晰且新颖**：将推理时参考比较"内化到参数"这一想法明确建模为特权信息下的在线蒸馏问题，区别于以往蒸馏和RL后训练方法；
2. **方法论上"方向-幅度"分离**的设计非常优雅：匹配参考定义token级梯度方向，不匹配参考作为对照组校准序列级权重，这一双参考非对称干预机制既有理论动机、又有直观解释力；
3. **在线（on-policy）蒸馏避免了SFT的暴露偏差**：学生在自己生成的轨迹上获得教师反馈，训练分布与推理分布一致；
4. **无需额外验证器或奖励模型**：对比参考支持得分是一种验证器自由的代理信号，不依赖人工标注答案，拓展了训练信号的来源；
5. **显著的实证收益**：在多个数据集和子任务上一致改善，特别是召回率和F1的大幅提升对工业检测中"减少漏检"的实际需求具有重要意义；
6. **消融设计系统全面**：每个设计决策都有对应实验验证，结论可信度高。

## 8. 不足与局限

1. **对配对数据和标注的依赖**：训练需要异常图像与正常图像的配对以及缺陷标注（边界框/分割掩码）来构造匹配和不匹配参考，这在实际工业场景中获取成本高；论文也承认"当前对配对图像和缺陷标注的依赖"是局限，未来需要更弱或自动构造的特权参考；
2. **验证范围的局限**：
   - 仅在一个benchmark（MMAD）上评估；
   - 仅在一个主干（Qwen3-VL-4B）上做了完整训练实验，其他容量的学生或主干作为主结果的证据尚不充分；
   - 训练数据仅来自Real-IAD一个来源，跨域泛化能力未充分验证；
3. **精确率下降**：ADOPD在提高召回率的同时精确率较one-shot基线下降3.93个百分点（90.8% vs 94.8%），可能意味着更多的误报，在某些高精度要求的工业场景中这可能是一个实际障碍；
4. **无统计显著性报告**：未提供多次运行的标准差或显著性检验，结果可能存在偶然性；
5. **计算成本未完全透明**：论文报告了训练步数、batch size等超参数，但未报告GPU数量、训练时长、教师推理开销等，第三方复现时难以预估所需资源；
6. **定性分析的主观性**：梯度归因图（图4）的定性比较缺乏量化指标（如归因与GT掩码的IoU），结论的说服力有限；论文也承认ADOPD的定位相关推理改进不能替代专用像素级分割模型；
