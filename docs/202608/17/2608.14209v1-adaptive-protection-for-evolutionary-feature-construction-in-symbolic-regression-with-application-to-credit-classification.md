## 摘要
进化特征构建在符号回归中展现出强大潜力，能够自动发现输入特征的信息性变换，从而增强简单的基础学习器。然而，现有方法往往缺乏明确的机制来保留进化过程中发现的重要构建特征，当遗传算子扰乱有效特征时，宝贵的遗传物质可能会丢失。本文引入了一种自适应保护机制，利用特征重要性度量在进化过程中选择性保留构建特征。该机制对更重要的构建特征提供更强的保护，同时仍允许较不重要的特征被修改，并从更重要的特征中整合有用的构建块。我们使用多种特征重要性计算方法评估了该方法，并证明了其在不同基础学习器上的鲁棒性。在98个回归基准数据集上的实验结果表明，所提出的机制相较于基线方法持续提高了解决方案质量，而在两个信用分类数据集上的实验表明，该方法也能有效扩展到符号回归之外，提升搜索有效性。

## Abstract
Evolutionary feature construction has shown strong promise in symbolic regression by automatically discovering informative transformations of input features that enhance a simple base learner. However, existing approaches often lack explicit mechanisms to preserve important constructed features discovered during evolution, and valuable genetic material can be lost when genetic operators disrupt effective features. This paper introduces an adaptive protection mechanism that leverages feature importance metrics to selectively preserve constructed features during evolution. The mechanism provides stronger protection for more important constructed features while still allowing less important features to be modified and to incorporate useful building blocks from more important features. We evaluate the approach using multiple feature importance calculation methods and demonstrate its robustness across different base learners. Experimental results on 98 regression benchmark datasets show that the proposed mechanism consistently improves solution quality over baseline approaches, and experiments on two credit classification datasets demonstrate that the method also extends effectively to improve search effectiveness beyond symbolic regression.

### 1. 核心问题与整体含义（研究动机与背景）

进化特征构建（Evolutionary Feature Construction）是符号回归（Symbolic Regression）中的一类重要方法，其核心思想是利用遗传规划（GP）自动演化出对输入特征的有效数学变换，再利用这些变换后的构造特征训练简单的基础学习器（如线性回归、决策树），从而提升预测性能。

然而，现有方法普遍存在一个关键缺陷：**在进化过程中，缺乏对已发现的重要构造特征的显式保护机制**。遗传操作（交叉、变异）在生成新特征组合的同时，容易破坏当前种群中具有高价值的特征变换。一旦一个性能优异的构造特征被无意破坏，即使后代中引入了其他有用的特征，整体解决方案的质量仍可能显著退化。这与遗传算法中“积木块（building block）”理论所强调的“保护有价值的子结构”相矛盾。

为应对这一挑战，本文提出了**自适应保护机制（Adaptive Protection Mechanism, APM）**——一个基于特征重要性度量的通用框架，能够在任意遗传算子之外添加一层保护逻辑，按重要性对构造特征进行差异化保留，从而在“探索新特征”和“利用已有优良特征”之间取得更好的平衡。

### 2. 方法论：核心思想、关键技术细节与算法流程

**核心思想**：构造特征越重要，在遗传操作后越倾向于恢复到其原始状态；越不重要的特征，则越有可能被继续修改或替换。该机制本质上是一种“更细粒度的精英主义”——不再限于保留整个个体，而是精确保留个体内部最有价值的构建块。

**整体工作流**（7个阶段）：

1. **种群初始化**：使用 Ramped Half-and-Half 方法生成 N 个个体，每个个体包含 k 棵特征构造树。
2. **解决方案评估**：分别以岭回归、随机决策树或逻辑回归作为基础学习器训练模型，以 R² 、AUC 或交叉验证分数作为适应度。
3. **重要性计算**：对每个构造特征计算其重要性 I，作为保护力度的依据。
4. **父本选择**：使用 ε-lexicase 选择策略。
5. **后代生成**：对父本执行子树交叉和子树变异，可对单个个体中的多棵树分别施加。
6. **自适应保护**：保存遗传操作前的原始树；遗传操作后，按“保护分数”决定哪些树需要恢复。
7. **精英主义**：保留当前最优个体，并维护一个规模为100的档案集用于最终预测。

**自适应保护机制的核心步骤**（Algorithm 1）：

- 在遗传操作前保存所有树的原始状态；
- 执行交叉/变异得到修改后的树；
- 计算归一化重要性：Ĩⱼ = |Iⱼ| / Σₖ|Iₖ|；
- 对每棵树计算保护分数：sⱼ = m_protect · Ĩⱼ（m_protect 为保护系数，默认取5）；
- 采样均匀随机数 u，若 u < sⱼ 则将该树恢复到原始状态。

保护系数为0时保护失效；系数越大，高重要性树恢复概率越高。该机制与具体遗传算子无关，可兼容传统算子、语义算子、基于 LLM 的交叉等。

**特征重要性计算方法**（三种）：

- **内置系数（Built-In）**：线性模型取系数绝对值 |βⱼ|；决策树按分裂节点的加权不纯度下降量求和。
- **SHAP值**：基于博弈论 Shapley 值，线性模型下取平均绝对 SHAP：I = (1/n)Σ|βⱼ(xᵢⱼ − E[Xⱼ])|。
- **边际贡献（Marginal Contribution）**：计算去除特征前后模型 R² 之差：I = R²_full − R²₋ⱼ（需额外重新拟合一次模型）。

### 6. 主要结论与发现

1. **保护机制显著有效（RQ1）**：在98个回归数据集上，内置系数APM在56个数据集上胜过无保护基线，SHAP-APM胜60个，边际贡献APM胜58个，各配置平均仅1–6个数据集的败绩。保护机制使后代特征重要性更接近父代，保持了搜索的局部性，避免了解决方案质量的严重退化。
2. **“保护”优于“减少操作”（RQ2）**：简单的低交叉/变异率虽然减少了破坏概率，但也削弱了探索能力；而APM允许全面应用遗传操作，再通过保护机制有选择地保留关键特征，效果显著更优。
3. **内置系数的性价比最高（RQ3）**：三种重要性度量在预测精度上相差不大，但内置系数零额外开销、最简单实用；边际贡献因需额外重拟合模型，计算开销大，且在特征高度相关时可能低估真实重要特征；SHAP介于两者之间。
4. **对不同基础学习器鲁棒（RQ4）**：当基础学习器从岭回归换为随机决策树（使用不纯度下降作为重要性度量）时，保护机制仍然生效并稳定胜过基线。
5. **可迁移到分类任务（RQ5）**：在两个信用分类数据集上，APM在训练AUC上优于无保护和低操作率基线；测试AUC上与无保护基线持平，在Australian数据集上优于低操作率基线，但增益相对有限。

### 8. 不足与局限

- **保护粒度停留在完整特征层面**：目前保护对象是整棵构造特征树，无法区分一个树中真正关键的子树或子结构；作者明确指出该局限，并将“动态识别与保护有用子结构”作为未来方向。
