## 摘要
电力系统故障期间准确的相量估计具有挑战性，因为故障电流包含衰减的直流偏移、谐波、噪声以及可能的频率偏差。这些失真会显著降低基于离散傅里叶变换的传统估计器的性能，尤其在故障发生后的第一个周期内。本文提出了SymbolicPhasor，一种动态深度符号回归框架，用于估计失真故障电流信号的基波分量。该方法通过重叠移动窗口处理信号，学习每个窗口内完整波形的可解释解析表达式，然后将重建信号投影到标称正弦和余弦基上，以恢复瞬时基波幅值和相位。通过嵌入对应于标称、三次和五次谐波频率的符号标记，所提方法被引导向具有物理意义的表达式，同时保持数据驱动的灵活性。该方法在单一衰减直流、多重衰减直流和偏离标称频率条件下进行了评估。结果表明，其重建精度持续较高，决定系数达到0.985，证明所提框架能够在实际保护继电和测量应用中于一个周期内恢复基波分量。

## Abstract
Accurate phasor estimation during power system faults is challenging because fault currents contain decaying DC offsets, harmonics, noise, and possible frequency deviations. These distortions can significantly degrade conventional discrete Fourier transform-based estimators, especially during the first cycle after fault inception. This paper presents SymbolicPhasor, a dynamic deep symbolic regression framework for estimating the fundamental component of distorted fault current signals. The method processes the signal through overlapping moving windows, learns interpretable analytical expressions for the full waveform within each window, and then projects the reconstructed signal onto nominal sine and cosine bases to recover the instantaneous fundamental magnitude and phase. By embedding symbolic tokens corresponding to the nominal, third-, and fifth-order harmonic frequencies, the proposed approach is guided toward physically meaningful expressions while preserving data-driven flexibility. The method is evaluated under single decaying-DC, multiple decaying-DC, and off-nominal frequency conditions. Results show consistently high reconstruction accuracy, with coefficient of determination values reaching 0.985, demonstrating that the proposed framework can recover the fundamental component within one cycle for practical protective relaying and measurement applications.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：电力系统发生故障时，故障电流中通常包含衰减直流偏移（DCO）、奇次谐波、噪声以及可能的频率偏差。这些非基波分量会严重干扰传统的离散傅里叶变换（DFT）相量估计算法，尤其在故障发生后的第一个周期内，估计误差可达 15%，可能导致保护装置误动或拒动。
- **现有方法局限**：已有 DCO 抑制方法分为四类——DFT 前处理、DFT 后处理、最小二乘（LS）和人工智能（AI）方法。它们各有不足：
  - 预处理方法常需一个完整周期数据，延迟较大，且对小时间常数、噪声敏感；
  - 后处理方法依赖系统参数（如 X/R 比），有时需要额外电压信号；
  - LS 方法受限于预设模型和泰勒展开阶数；
  - AI 方法需要大量离线和在线训练数据，泛化能力有限，且难以解释。
- **研究意义**：论文提出 SymbolicPhasor，利用深度符号回归（DSR）在故障后一个周期内恢复基波分量，兼具可解释性、数据驱动灵活性和实用保护应用潜力。

## 2. 方法论：核心思想、技术与算法流程

### 2.1 核心思想
- 不直接对基波进行强制拟合，而是先在每个滑动窗口内用符号回归学习故障电流完整波形的解析表达式（包含基波、DCO、谐波等），再将重建信号投影到名义频率的正弦/余弦基上，从而提取瞬时基波幅值和相位。
- 通过嵌入与基频、三次、五次谐波对应的符号 token（如 `w377(t)=377t`），引导搜索空间向物理上合理的表达式收敛，保持可解释性。

### 2.2 故障电流信号模型
- 信号为分段函数：故障前仅含基波；故障后包含：
  - 基波分量（幅值跳变）；
  - 单个或多个衰减 DC 偏移（`Adc * exp(-(t-tf)/τdc)`）；
  - 三次和五次谐波；
  - 高斯白噪声。

### 2.3 动态窗口策略
- 将信号划分为重叠移动窗口：窗口长度 = 一个周期（200 个采样点 @12kHz），步长 = 1/4 周期。
- 这样可保证部分窗口自然跨越故障时刻，同时覆盖故障前和故障后数据。
- 对重叠窗口的局部估计采用加权平均合并，得到全时段的动态估计。

### 2.4 符号回归重建
- 每个窗口内，符号回归模型仅以时间 `t` 为输入，学习表达式 `f^(m)(t)`。
- 二元算子集：`{+, -, ×}`；
- 一元算子集：`{sin, exp, w377, w1131, w1885}`，其中 `w377=377t`、`w1131=1131t`、`w1885=1885t` 分别对应基波、三次谐波、五次谐波的角频率标记。
- 最终学到近似形式：
  ```
  i^(t) ≈ α1 sin(377t + β1) + α3 sin(1131t + β3)
          + α5 sin(1885t + β5) + αdc exp(βdc t)
  ```

### 2.5 基波提取
- 对重建信号 `i^(m)(t)`，在最小二乘意义下投影到 `sin(ωt)` 和 `cos(ωt)`，得到系数 `a_sin` 和 `b_cos`。
- 幅值：`A = sqrt(a_sin² + b_cos²)`；
- 相位：`φ = atan2(b_cos, a_sin)`；
- 从而得到局部基波波形，再用重叠窗口平均合并。

### 2.6 性能指标
- **决定系数 R²**：衡量重建波形与真实基波的整体拟合精度；
- **幅值过冲 MO**：衡量估计幅值轨迹中的瞬态过冲程度。
