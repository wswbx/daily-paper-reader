## 摘要
CLI代理是语言模型最接近具身环境的设置：模型发出命令，终端执行它们，返回的流——stdout、错误、文件、日志和追踪——记录了后果。我们认为这个流是一种监督信号，但标准的代理强化学习丢弃了它：GRPO风格的训练使用稀疏的结果级奖励更新动作标记，而忽略了回滚中已经存在的环境响应。失败的回滚尽管包含了关于环境如何响应的丰富证据，但提供的策略梯度信号很少。我们引入了ECHO（环境交叉熵混合目标），这是一种混合目标，将标准的基于动作标记的策略梯度损失与辅助损失相结合，该辅助损失训练策略预测由其自身动作产生的环境观测标记。ECHO重复使用与GRPO相同的前向传播，不需要额外的回滚，并将终端反馈转化为所有回滚的密集监督。ECHO在TerminalBench-2.0上将GRPO的pass@1翻倍：Qwen3-8B从2.70%提升到5.17%，Qwen3-14B从5.17%提升到10.79%。ECHO还产生了能更好预测终端动态的策略，即使是在它们未生成的轨迹上：在保留的回滚中，它显著降低了环境标记的交叉熵，而仅使用GRPO几乎不变。从基础Qwen3-8B开始，ECHO在没有专家演示的情况下，在保留的终端任务上达到了专家SFT后GRPO的性能，并在TerminalBench-2.0上恢复了大约一半的专家SFT初始化优势。在某些设置中，仅环境预测损失就能实现无验证器的自我改进，使策略通过仅从环境交互中学习来改进未见过的OOD任务。这些结果表明，环境观测不仅仅是未来行动的上下文，更是每个回滚中已经存在的密集、在线策略监督信号。

## Abstract
CLI agents are the closest thing language models have to an embodied setting: the model emits commands, the terminal executes them, and the returned stream -- stdout, errors, files, logs, and traces -- records the consequences. We argue that this stream is a supervision signal, but standard agent RL discards it: GRPO-style training updates action tokens with sparse outcome-level rewards while ignoring environment responses already in the rollout. Failed rollouts provide little policy-gradient signal despite containing rich evidence about how the environment responds. We introduce ECHO (Environment Cross-entropy Hybrid Objective), a hybrid objective that combines the standard policy-gradient loss on action tokens with an auxiliary loss that trains the policy to predict environment observation tokens resulting from its own actions. ECHO reuses the same forward pass as GRPO, requires no additional rollouts, and turns terminal feedback into dense supervision for all rollouts. ECHO doubles GRPO pass@1 on TerminalBench-2.0: Qwen3-8B improves from 2.70% to 5.17%, and Qwen3-14B from 5.17% to 10.79%. ECHO also produces policies that better predict terminal dynamics, even on trajectories they did not generate: across held-out rollouts, it sharply reduces environment-token cross-entropy while GRPO alone barely changes it. From base Qwen3-8B, ECHO matches expert-SFT-then-GRPO performance on held-out terminal tasks without expert demonstrations, and recovers roughly half of the expert-SFT initialization benefit on TerminalBench-2.0. In some settings, the environment prediction loss alone enables verifier-free self-improvement, allowing policies to improve on unseen OOD tasks by learning only from environment interactions. Together, these results suggest that environment observations are not merely context for future actions, but a dense, on-policy supervision signal already present in every rollout.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：在命令行界面（CLI）智能体（terminal agent）的强化学习训练中，标准的GRPO（Group Relative Policy Optimization）只对动作标记（action tokens）施加策略梯度损失，而完全忽略回滚（rollout）中包含的终端环境反馈（标准输出、错误日志、文件内容等）。这使得大部分失败回滚几乎没有策略梯度信号，尽管其中包含了丰富的环境响应信息。
- **整体含义**：作者认为环境观测流（environment observation stream）是一种天然的、密集的在线监督信号，但现有RL方法将其丢弃。如果能够利用这些反馈作为额外的训练目标，可以使智能体更好地理解终端动态、提高任务成功率，甚至在无验证器（verifier）的情况下实现自我改进。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：在GRPO基础上，增加一个环境预测辅助损失（Environment-Prediction Loss），直接对终端输出的观测标记（observation tokens）施加交叉熵损失，迫使策略模型学会预测自己动作所导致的环境响应。
- **关键技术细节**：
  - **混合目标函数**：\( \mathcal{L}_{\text{ECHO}}(\theta) = \mathcal{L}_{\text{GRPO}}(\theta; A) + \lambda \mathcal{L}_{\text{Env}}(\theta; O') \)，其中 \( A \) 是动作标记位置，\( O' \) 是环境观测标记位置（排除警告前缀），\( \lambda \) 是权重（实验中取0.05）。
  - **无需额外前向传播**：与GRPO共享同一前向过程，只通过不同的掩码（mask）收集logits，因此不增加回滚次数或前向计算量。
  - **在线策略（on-policy）**：训练目标是当前策略自身回滚产生的环境反馈，随着策略改进，环境响应也变化，形成自演进的课程。
  - **环境标记选择**：只对真正的终端输出（command_output部分）施加损失，排除低熵的警告标记，因为警告标记在约60步内就会过拟合，不再提供有用梯度。
  - **算法流程**：前向计算得到全序列logits → 分别计算动作标记上的GRPO损失和观测标记上的交叉熵损失 → 合并反向传播。

## 3. 实验设计

- **数据集/场景**：
  - 训练集：8870个终端任务，来自Endless Terminals（1977个）和OpenThoughts-Agent-v1-RL（723个），再经扩充和GPT-5筛选保留至少一次成功解决的任务。其中8770个用于训练，100个作为内部保留验证集（val100）。
  - 评估基准：
    - **val100**：100个内部保留任务。
    - **ITD** (Internal-Dev)：71个任务，涵盖数据处理、系统操作、开发工具。
    - **TBLite** (OpenThoughts-TBLite)：100个任务，针对小模型性能校准。
    - **TB2** (TerminalBench-2.0)：89个任务，使用Terminus-2 harness（更严格的标准）。
    - **PyTerm**：928个合成终端任务，侧重Python脚本生成（仅用于无验证器适应实验）。
- **对比方法**：
  - 基线：Base模型（不用RL）、仅GRPO训练、专家SFT初始化后GRPO、未使用专家SFT的ECHO。
  - 三种初始策略：Qwen3-8B Base、OpenThinker-Agent-v1-SFT（OT-SFT，在~15k专家演示上SFT后的Qwen3-8B）、Qwen3-14B Base。

## 4. 资源与算力

- **GPU型号与数量**：8块B200 GPU。
- **训练步数与时间**：每个模型训练500 GRPO步，每步16个回滚（n=16），批量大小16，学习率1e-6。单次运行约24-48小时（wall-clock time）。

## 6. 主要结论与发现

- **ECHO一致提升任务成功率**：在TerminalBench-2.0上pass@1几乎翻倍：Qwen3-8B从2.70%提升到5.17%，Qwen3-14B从5.17%提升到10.79%。内部评测（val100、ITD、TBLite）上也均有提升。
- **ECHO真正学习了终端动态**：在离线轨迹上，ECHO显著降低了环境标记交叉熵，而GRPO几乎不改变。表明策略学会了预测终端响应，且能泛化到其他智能体产生的轨迹。
- **减少对专家演示的依赖**：从基础Qwen3-8B开始，ECHO在内部评测上完全匹配专家SFT后GRPO的性能，在TB2上恢复约一半差距，无需任何专家演示。
- **训练/推理效率提升**：8B模型达到GRPO峰值性能所需步数减少1.5-2.3倍；推理时超时率降低55%（8B），完成令牌减少30%。
- **无验证器自我改进可行**：仅用环境预测损失在干净轨迹上继续训练，可使PyTerm提升10pp，ITD提升5.2pp，且不损害同分布性能。

## 7. 优点

- **方法简洁高效**：只改变损失掩码，共享前向计算，无额外回滚或教师模型，计算开销极小。
- **直觉清晰、可解释**：预测环境响应自然蕴含世界模型学习，与“好的预测意味着理解”一致。
- **实验充分，证据链完整**：从任务性能到环境预测能力，再到训练/推理效率和专家演示依赖，多角度验证有效性。
- **实际价值突出**：显著提升小模型性能，降低对昂贵专家数据的需求，并提供无验证器在线适应能力。

## 8. 不足与局限

- **适用范围有限**：仅验证于CLI终端环境，能否推广到其他交互环境（如GUI、网络、数据库）未探索。
- **模型族局限**：仅测试了Qwen3系列，未在Llama、GPT等模型上验证。
- **评测试集规模小**：TerminalBench-2.0仅89个任务，内部评测集也较小；统计显著性依赖Wilson区间，但样本量有限。
- **专家SFT间隙恢复不完整**：在TB2上仅恢复50%的SFT增益，表明ECHO不能完全替代高层次策略知识。
- **无验证器适应有特定条件**：仅在干净工具调用轨迹上有效，且依赖任务反馈的“动作链接性”（action-linkedness），并非通用。
- **奖励信号限制**：依然使用二元稀疏奖励（0/1），未结合过程奖励。ECHO与更先进的RL稳定技术（如clip-higher、过滤无效轨迹）兼容性未详细讨论。
- **潜在过拟合风险**：环境预测损失可能使模型过度拟合回滚中的噪声模式，论文未讨论过拟合问题或正则化策略。
