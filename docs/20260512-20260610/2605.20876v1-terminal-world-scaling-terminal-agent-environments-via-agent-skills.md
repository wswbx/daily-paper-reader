## 摘要
终端智能体赋予大型语言模型直接在命令行环境中执行任务的能力，但其进展受到高质量训练数据稀缺的瓶颈限制。现有方法从部分来源（如人工定义的种子或GitHub仓库）引导，先实例化一个组件，再补全其余部分，导致任务局限于狭隘的种子分布、环境与任务语义不匹配，以及无引导探索产生的低效轨迹。为解决这些问题，我们引入了Terminal-World，一个全自动流水线，以智能体技能作为核心合成原语，该原语联合编码了要完成什么、何时应用（前置条件和环境状态）以及如何执行，使得任务指令、环境和教师轨迹能够共同推导。为进一步扩展合成空间，Terminal-World将技能组合成技能团队和技能图，用于多角色和跨领域的任务合成。利用该流水线，我们构建了5,723个训练环境，并训练了Terminal-World-8B/14B/32B模型，在6个基准测试中评估，Terminal-World系列始终优于终端智能体基线。值得注意的是，使用相同的教师模型且仅用1.2%的训练数据，Terminal-World-32B在Terminal-Bench 2.0上以+4.5 Pass@1（31.5）超越了Nemotron-Terminal-32B，并达到了43.8 Pass@3。

## Abstract
Terminal agents extend Large Language Models with the ability to execute tasks directly in command-line environments, but their progress is bottlenecked by the scarcity of high-quality training data. Existing approaches bootstrap from partial sources such as human-defined seeds or GitHub repositories to instantiate one component and then complete the rest, producing tasks confined to narrow seed distributions, environments misaligned with task semantics, and inefficient trajectories from unguided exploration. To address these limitations, we introduce Terminal-World, a fully automated pipeline that uses agent skills as the central synthesis primitive, which jointly encode what to accomplish, when to apply (preconditions and environment state), and how to execute, enabling task instructions, environments, and teacher trajectories to be co-derived. To further broaden the synthesis space, Terminal-World composes skills into skill teams and skill graphs for multi-role and cross-domain task synthesis. Using this pipeline, we construct 5,723 training environments and train Terminal-World-8B/14B/32B, evaluated across 6 benchmarks where the Terminal-World series consistently outperforms terminal-agent baselines. Notably, using the same teacher model and only 1.2% of the training data, Terminal-World-32B surpasses Nemotron-Terminal-32B on Terminal-Bench 2.0 by +4.5 Pass@1 (31.5) and achieves 43.8 Pass@3.

# Terminal-World 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：基于LLM的终端智能体（terminal agent）直接在命令行环境中执行任务，具有广泛的通用性和自主性，但受限于高质量训练数据的稀缺。现有的数据合成方法从局部来源（人工定义的种子、GitHub仓库）引导，只实例化一个组件再补全其余部分，导致三大局限：**任务分布狭窄**（仅覆盖种子分布）、**环境与任务语义错位**（环境事后适配，配置脆弱或松散对齐）、**轨迹低效**（缺乏指导，教师模型产生冗余探索和次优路径）。
- **整体含义**：作者发现开源生态中已有的“智能体技能”（agent skill）（如ClawHub、SkillMP中的技能）天然编码了“做什么”、“何时做”、“如何做”三个方面，可以作为联合合成任务指令、可执行环境和教师轨迹的统一原语。从而提出**Terminal-World**全自动流水线，以技能为中心解决上述三大局限，实现高质量、低成本、可扩展的终端智能体训练数据合成。

## 2. 方法论

### 核心思想
利用真实世界中的agent skill作为合成原语，每个skill统一描述：
- 要完成什么（what）
- 当何时应用（前置条件与环境状态，when）
- 如何执行（how）

通过解码这三个方面，协同生成任务指令（I）、环境蓝图（E，含初始文件、设置步骤）、验证标准（V）和执行指南（G），进而构造可执行沙箱并收集高效教师轨迹。

### 关键技术细节

#### （1）Agent Skill Collection
- 从ClawHub和SkillMP收集10,000个技能，经三层过滤：
  - **规则过滤**：移除终端无关技能（剩余8,520个）
  - **LLM过滤**：对终端适用性和内容丰富性打分（1-3），保留双项最高分（3,025个）
  - **流行度过滤**：按下载量排序取前1,000个，覆盖12大类63子类
- **扩展**：利用SkillNet分类技能间的4种关系（Compose with, Depends on, Similar to, Belong to），将同一子类内的Compose with关系形成**技能团队**（76个，多角色工作流，深度扩展）；跨子类的Depends on关系形成**技能图**（237个，端到端流水线，广度扩展）。所有团队和图扁平化为skill.md格式，与单技能共同作为合成原语S。

#### （2）Task Generation
- 将每个原语S与从FinePersonas采样的用户画像U配对（无关配对跳过）。
- 使用LLM（DeepSeek-V3.2）合成四元组 (I, E, V, G)：
  - I = 任务指令
  - E = 环境蓝图（初始文件描述 + 自然语言设置步骤）
  - V = 评价标准（可转化为pytest断言）
  - G = 技能衍生执行指南（用于引导轨迹收集）
- 过滤：LLM-as-a-Judge对5个维度（指令质量、封闭可解性、蓝图完整性、指南质量、评价标准质量）评分，要求每维≥4分方可保留。

#### （3）Environment Building
采用统一的生成-验证-修复（GVR）机制构建沙箱三个组件：
- **初始文件**：根据文件生成模式（llm_direct / local_tool / remote_fetch）路由到不同代理，文件验证代理检查内部正确性和跨文件一致性。
- **设置脚本**：环境构建代理将自然语言步骤转换为shell命令；环境验证代理生成诊断探测脚本测试包、服务、运行时状态，失败则修复。
- **pytest验证器**：验证器生成代理根据评价标准V生成pytest脚本；验证器检查可执行性和可靠性（测试在初始状态必须失败），失败则修复。
最多修复3次，成功后进入下一阶段。

#### （4）Trajectory Collection
- 教师模型：DeepSeek-V3.2配合Terminus2脚手架。
- 每步：教师根据指令I、指南G和历史轨迹H产生动作A，接收观察O。
- 成功后运行验证器标注结果，保留成功和失败轨迹（失败轨迹包含大量正确中间步骤）。
- **关键设计**：指南G仅在轨迹收集时使用，SFT训练前从输入中移除，让学生模型从验证过的终端交互本身学习。

## 6. 主要结论与发现

1. **高效性**：Terminal-World系列在所有三个规模（8B/14B/32B）上均优于现有终端智能体基线。32B模型以仅5.7K训练数据（Nemotron-Terminal的1.2%）达到Terminal-Bench 2.0 Pass@1 31.5，超越Nemotron-Terminal-32B的27.0（+4.5）。
2. **泛化性**：仅使用终端风格轨迹训练，但在AIME、DABench、TableBench、BIRD等非终端任务上匹配或超越Nemotron-Terminal（其包含大量辅助数据），说明技能引导轨迹具有可转移能力。
3. **行为优势**：Terminal-World-32B执行步数和命令数更少、命令失败率更低，说明学习到了更简洁的目标导向策略。
4. **指南重要性**：指南移除显著降低性能（-2.2 Pass@1），说明保留指南会干扰自主计划；失败轨迹包含正确中间步骤，不应整体抑制。
5. **多样性与低成本**：用户画像有效扩展技能使用场景（场景簇从74增至153），完整pipeline成本仅$0.17/轨迹。

## 7. 优点

- **全自动协同合成**：以agent skill为原语，一次性对齐任务语义、环境约束和执行过程，解决了以往方法中各组件分离导致的不一致问题。
- **高样本效率**：仅需极少量数据即可达到甚至超越使用大量数据训练的模型，证明了数据和方法的优质性。
- **可扩展性**：通过技能团队和技能图在深度（多角色）和广度（跨领域）上扩展，能覆盖更复杂的工作流。
- **实用性强**：支持任意文件类型（104种），包含设置脚本和pytest验证器，环境真实可执行，具有真实世界终端工作的多样性。
- **成本低廉**：全流程$999.59，平均每样例$0.17，使得其他团队容易复现和扩展。
- **系统消融与深入分析**：不仅报告总指标，还深入分析行为、错误模式、难度、质量、裁判一致性，为后续研究提供丰富洞察。

## 8. 不足与局限

- **技能覆盖可能仍有盲区**：虽然扩展到1,000+技能，但真实终端任务种类无穷，可能在某些小众或新兴领域（如特定工业工具、硬件交互）覆盖不足。
- **依赖教师模型能力**：教师轨迹使用DeepSeek-V3.2生成，其能力上限限制了轨迹质量；若教师模型本身难以解决某些任务，则无法产生有效示范。虽然教师探索后仍可能产生失败轨迹，但成功轨迹质量依赖教师。
