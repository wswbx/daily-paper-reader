## 摘要
基于大语言模型（LLM）的进化程序搜索已成为自动化科学发现的有效范式。然而，当前方法在根本上受到三大瓶颈的制约：结构盲目的父代选择、稀疏的完整程序评估奖励，以及在搜索过程中无法适应的静态变异算子。我们提出了GAE（图增强进化），该框架通过紧密耦合的三支柱架构解决了这些局限。首先，关系图神经网络（GNN）将程序解析为类型化计算图，生成结构感知的嵌入表示。其次，基于强化学习优化的元控制器利用这些嵌入，以有导向策略替代盲目的进化采样，根据奖励历史动态选择最优父代和变异方向。第三，在线GRPO微调循环利用组归一化评估奖励在测试时持续更新LLM变异算子，直接使模型的生成分布与高适应度结构编辑对齐。我们在一个具有挑战性的科学发现任务——复杂非线性振荡系统的符号回归上评估了GAE。通过将随机搜索转变为有导向的自我改进轨迹，GAE高效发现了封闭形式的物理方程，始终达到或超越静态LLM驱动的基线，并在分布外性能上取得了最先进成果。

## Abstract
Evolutionary program search guided by Large Language Models (LLMs) has emerged as a powerful paradigm for automated scientific discovery. However, current approaches are fundamentally constrained by three bottlenecks: structurally blind parent selection, sparse whole-program evaluation rewards, and static mutation operators that fail to adapt during search. We present GAE (Graph-Augmented Evolution), a framework that resolves these limitations through a tightly coupled, three-pillar architecture. First, a relational graph neural network (GNN) parses programs into typed computation graphs, producing structure-aware embeddings. Second, an RL-optimized meta-controller leverages these embeddings to replace blind evolutionary sampling with a directed policy, dynamically selecting optimal parents and mutation directions based on reward history. Third, an online GRPO fine-tuning loop continuously updates the LLM mutation operator at test-time using group-normalized evaluation rewards, directly aligning the model's generation distribution with high-fitness structural edits. We evaluate GAE on a challenging scientific discovery task: symbolic regression for complex nonlinear oscillator systems. By transforming stochastic search into a directed, self-improving trajectory, GAE efficiently discovers closed-form physical equations, consistently matching or outperforming static LLM-driven baselines and achieving state-of-the-art out-of-distribution performance.

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体框架：GAE（Graph-Augmented Evolution）

GAE 在 OpenEvolve 框架基础上，引入三个紧密耦合的组件，所有组件共享一个关系图神经网络（GNN）编码器：

- **GNN 编码器**：将每个程序解析为类型化计算图（基于抽象语法树 AST），通过 L 层关系消息传递生成结构嵌入 \(z \in \mathbb{R}^d\)（d=128）。预训练后，每 K 代（K=3）在线微调，以滑动窗口的最近程序-奖励对回归预测适应度。
- **离散 SAC 元控制器**：以父程序嵌入 \(z_\alpha\) 为状态，输出一个离散动作（共 2700 种，包括变异类型、目标节点 ID、参数索引），指导 LLM 进行结构变异。训练使用三部分奖励：
  - 任务分数：\(r_{\text{task}} = \text{clip}(R(\beta), r_{\min}, r_{\max})\)
  - 新颖性：\(r_{\text{nov}} = 1 - \min_{p \in P} \cos(z_\beta, z_p)\)
  - 复杂度惩罚：\(r_{\text{cx}} = \max(0, (N(\beta)-20)/20)\)
- **GRPO 在线微调**：每代用 G=8 个孩子组成的小组，计算孩子与父代奖励之差 \(R^{\text{grp}}_g = R_g - R_\alpha\)，然后用 PPO-clip 目标更新 LLM 权重，使生成分布偏向高适应度结构编辑。KL 惩罚系数 \(\beta_{kl}=0.1\)，截断 \(\epsilon=0.2\)。

### 2.2 关键公式与算法流程

- 关系图卷积：\(h_i^{(\ell+1)} = \text{LayerNorm}\left( \text{GELU}\left( W_{\text{self}} h_i^{(\ell)} + \sum_{r=1}^{|E|} \frac{1}{|N_r(i)|} \sum_{j \in N_r(i)} W_r h_j^{(\ell)} \right) \right)\)
- GRPO 损失：\(\mathcal{L}_{\text{GRPO}} = -\frac{1}{G}\sum_g \min\left( \rho_g \hat{A}_g, \text{clip}(\rho_g, 1\pm\epsilon) \hat{A}_g \right) + \beta_{\text{kl}} D_{\text{KL}}(\pi_{\theta_{\text{LLM}}} \| \pi_{\text{ref}})\)
- 整体算法：每代从精英库均匀采样一个父代 → GNN 编码 → SAC 选择动作 → LLM 生成 G 个孩子 → 评估 → GRPO 更新 LLM → SAC 用最佳孩子更新 → 插入精英库 → 每 K 代微调 GNN。

### 2.3 三者解耦性

SAC、GRPO、GNN 优化互不相干的参数集，各自以不同时间尺度运行，禁用任一个会退化为更简单的基线（如均匀变异提示、冻结 LLM、陈旧嵌入）。
