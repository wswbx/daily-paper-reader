# Towards Automated Confidence Bound Provers and Searchers 

## My Phan Erik Learned-Miller ∗

## July 14, 2026 

Abstract 

In this work we lay the groundwork for automating the process of finding and proving the validity of lower confidence bounds of the mean. Our key finding is based on the observation that finding an optimal confidence bound under certain conditions can be formulated as an optimization problem. We use this observation to show that any valid confidence bound (such as Hoeffding’s) must be a relaxation of a certain optimization problem. To automatically find and prove confidence bounds, we need to automate the process of defining and finding such a relaxation. We define a family of relaxations parameterized by a function called the order function. This family of relaxations can approximate any other target relaxation such as Hoeffding’s by using the target as the order function. When the order function is linear (such as the sample mean in the case of Hoeffding’s), our relaxation is a linear-size mixed-integer linear program.

## 4.3 Anderson’s Bound as the Order Function 

Anderson’s bound [Anderson, 1969] is a linear function of the sorted sample and is a valid bound proven to be tighter than Hoeffding’s for any sample. Therefore the constraint T (yi) ≥ T (x) is a linear constraint. Anderson’s upper bound of the mean of distribution on ( −∞ , 1] is derived by derived a lower bound of the CDF F using the property P(F (X) ≥ y) = 1 − P(F (X) < y ) ≥ 1 − P(F (X) ≤ y) ≥

1 − y = P(U ≥ y). Since it’s not always true that P(F (X) ≥ y) ≤ P(U ≥ y), we cannot derive a lower bound of the mean by finding an upper bound of the CDF. Therefore, we derive a lower bound of the mean of X ≥ 0 by finding an Anderson’s upper bound of the mean of 1 − X ≤ 1. The valid bound in [Phan et al., 2021] is strictly tighter than Anderson’s bound when applied to applied to the set of all distributions with support on [0 , 1]. Therefore the T -optimal bound with Anderson’s as the order function will be strictly tighter than Anderson’s bound when applied to applied to the set of all distributions with support on [0 , 1]. # E Related Works 

[Phan et al., 2021] is the only previous work we are aware of that can be used implicitly to automate the relaxation for many order functions T for non-parametric confidence bounds, as proposed by our work. Phan et al. [2021] do not explicitly present the result as automating the relaxation, but it can be used as such. The bound in [Phan et al., 2021] is valid for many order functions T but does not have the guarantee to be arbitrarily close to the T -optimal bound as ours partially has (Section 3.5), and therefore can be strictly looser than the T -optimal bound. We discuss previous works that try to find to solve Definition 2.1 on a case-by-case basis. It can be done by finding an upper bound of: 

PG(T (X) ≥ T (x)) . (211) Below we discuss the results regarding the upper bound of Eq. 211 for some specific functions T

(Section E.1), and the results regarding finding a good function T that will result in tight bounds for Definition 2.1 (Section E.2). 

## E.1 Results for Some Order Functions T

Let F be the set of all distributions on [0 , 1] and T be the sample mean. When X are i.i.d. samples, Luczak et al. [2016] find a tight upper bound when T (x) ≤ 1/n . When X are independent (and not necessarily identical) samples with the same mean, Bentkus [2004] finds an upper bound for any x such that T (x) > 0. When X are i.i.d. samples, Bentkus [2001] provides a tighter bound than [Bentkus, 2004] for the special case when E[Xi] = 1 /2. Let F be the set of all distributions on [0 , 1] and T be a linear function. When X are independent (and not necessarily identical) samples with the same mean, Pinelis [2006] also provides an upper bound of the tail bound in Eq. 211 for the special case when μ(G) = 1 /2. Anderson’s bound [Anderson, 1969] is a linear function of the order statistics of the samples, so if we prove a generalization of the result in [Luczak et al., 2016] that involves a linear function of the order statistics of the samples instead of the sum, we can use Anderson’s bound as function 

T and have a bound for F[0 ,∞) that is better than or equal to Anderson for any sample. Phan et al. [2021] also provide an upper bound for any T , which leads to results proven to be better than or equal to Anderson’s when the support is [0 , 1] and equal to Anderson’s when the support is [0 , ∞). Anderson’s bound is shown to be tighter than Hoeffding’s for any sample [Learned-Miller and Thomas, 2019]. 

## E.2 Evaluating the Performance of the Order Function T

When the set of distributions F is a family of distribution with unknown parameter θ such that the family of probability density functions or probability mass functions {g(t|θ) : θ ∈ Θ} has a monotone likelihood ratio and T is a sufficient statistic for θ, then Karlin-Rubin theorem states that the test that use T is a uniformly most powerful (UMP) test [Casella and Berger, 2002].
