## 摘要
从数据中符号性地发现控制方程不仅受到算法设计和数据量的限制，还受到吸引子几何的限制：长期动力学允许恢复的内容。通过在Lorenz-84系统内进行设计（其中一个强迫参数驱动定常点、极限环和混沌状态，而控制方程和候选库保持不变），我们表明一个单一数值——不变测度矩矩阵的最小特征值λ_min(M)——为稀疏回归（SINDy）和进化符号回归（PySR）设定了可辨识性上限。λ_min(M)源自伯克霍夫遍历定理，并通过在任何运行前的短参考轨迹获得，它衡量吸引子覆盖函数空间的充分程度：当该值消失时，任何算法（无论是稀疏还是组合）都无法恢复；随着该值增大，两种算法均有改善。混沌通过扩散吸引子提高λ_min(M)，但也扩大吸引子并放大噪声；由于噪声以线性方式进入SINDy的回归瓶颈，而以超线性方式进入PySR的判别通道，相同的转变可能使两种方法朝相反方向移动，因此更深的混沌并非总是更好。来自该框架的无参数机制性分数无需重新拟合即可转移到留出的Lorenz-96系统，确认了机制而非曲线拟合；从方程中读取的一个标准可预测何时增加混沌不会改善条件。我们还引入了Soft F1，一种系数加权的结构度量，可解决二值成功和预测分数无法识别的性能差异。因而，发现的第一个问题不是选择哪种算法，而是吸引子允许什么。

## Abstract
Symbolic discovery of governing equations from data is limited not only by algorithm design and data volume, but by the geometry of the attractor: what the long-run dynamics allow to be recovered. Using a within-system design on Lorenz-84, where one forcing parameter drives fixed-point, limit-cycle, and chaotic regimes while the governing equations and library stay fixed, we show that a single number, $λ_{\min}(M)$, the smallest eigenvalue of the invariant-measure moment matrix, sets the identifiability ceiling for both sparse regression (SINDy) and evolutionary symbolic regression (PySR). Derived from the Birkhoff ergodic theorem and obtained from a short reference trajectory before any run, $λ_{\min}(M)$ measures how fully the attractor covers function space: where it vanishes, recovery is impossible for any algorithm, sparse or combinatorial alike; as it grows, both algorithms improve. Chaos raises $λ_{\min}(M)$ by spreading the attractor, but also enlarges it and amplifies noise; because noise enters SINDy's regression bottleneck linearly and PySR's discrimination channel superlinearly, the same transition can push the two methods in opposite directions, so deeper chaos is not uniformly better. Parameter-free mechanistic scores from this framework transfer without refitting to a held-out Lorenz-96 system, confirming mechanism rather than curve-fitting; a criterion read from the equations predicts when added chaos will not improve conditioning. We also introduce Soft F1, a coefficient-weighted structural metric that resolves performance differences invisible to binary-success and predictive scores. The first question of discovery is then not which algorithm, but what the attractor permits.

- **核心问题**：系统发现的首要问题不是“选哪种算法”，而是“该吸引子允许恢复什么？”——即长期动力学如何决定从数据中恢复控制方程的固有上限。
- **整体贡献**：作者证明了一个可计算的标量——不变测度矩矩阵的最小特征值 $\lambda_{\min}(M)$——同时决定了稀疏回归和进化搜索的下限机制。当其为零时，所有算法均无法恢复任何项；当其为正时，设定噪声和正则化的容忍上限。混沌可提高覆盖面，但也放大噪声，导致不同算法对同一转变可能反向响应。

### 2. 方法论

- **核心思想**：基于 Birkhoff 遍历定理，长时间轨迹的时间平均 Gram 矩阵收敛到吸引子上的不变测度矩矩阵 $M = \int \Phi(x)\Phi(x)^\top d\mu(x)$。$M$ 的最小特征值 $\lambda_{\min}(M)$ 刻画吸引子在函数空间中的覆盖程度。
- **SINDy 的机制模型**：
  - 使用 STLSQ 交替岭回归与硬阈值。
  - 失败模式分为假负（正态项被过度收缩至阈值下）和假正（噪声通过病态条件放大致无关项超过阈值）。
  - 威胁比定义为 $T_{FN} = \frac{\lambda}{w_{\min} \|\xi_{gt}\|}$，$T_{FP} = \frac{\kappa_{\text{eff}} \rho_{EIV} \sigma_\varepsilon}{\lambda}$。
  - 最终分数 $F_{SINDy} = \max(T_{FN}, T_{FP})$，当任一威胁 > 1 时恢复失败。
- **PySR 的机制模型**：
  - 两个独立瓶颈：条件瓶颈（$\sigma_{\min,\text{partial}}$，即不能由错误项组合再现的真实项信号）和信噪比判别瓶颈（$Q_{noise}$，辨别项与噪声之比）。
  - 分数 $F_{PySR} = \sqrt[4]{\sigma_{\min,\text{partial}}} \cdot Q_{noise}^{1/2}$（经验选择，但对敏感性低）。
- **Soft F1 指标**：系数权重的调和平均，对系数偏差指数衰减，解决二元成功率和预测误差对部分恢复的不敏感问题。

### 3. 实验设计

- **系统**：主实验使用 Lorenz-84（L84），通过单一强制参数 $F$ 遍历 8 个动力学状态：1 个固定点（R0）、2 个极限环（R1 低幅，R2 高幅）、5 个混沌状态（R3–R7 按最大 Lyapunov 指数排序）。
- **零参数留出验证**：Lorenz-96（5 维环状模型）用作独立验证，所有机制分数直接迁移，不重新拟合。
- **三个实验场景**：
  - **数据匮乏**：无噪声，使用精确导数，训练样本量 N 从 20 到 10,000 共 17 个对数间隔值。
  - **噪声敏感性**：固定 N=5,000，加入高斯噪声（$\eta=0-20\%$），导数估计使用有限差分（FD）或 Savitzky-Golay 平滑（SG）。

- **对比算法**：SINDy（稀疏回归，pySINDy）和 PySR（进化符号回归）。
- **评价指标**：主要使用 Soft F1，辅助分析 R² 和结构 F1。

### 6. 主要结论与发现

- 动力学状态的可辨识性排序为**不动点 < 极限环 < 混沌**，在所有实验条件下稳定出现。
- 该排序的机制是吸引子对函数空间的覆盖程度，由 $\lambda_{\min}(M)$ 直接衡量：消失时所有算法失败，较大时设置噪声和正则化的容忍上限。
- 混沌通过扩散吸引子提升 $\lambda_{\min}(M)$，但也扩大吸引子振幅、放大噪声；噪声进入 SINDy 线性地、进入 PySR 超线性地（指数 $n_{nc}=3$），因此更深的混沌可能导致 PySR 变差（如高噪声下大极限环可超越混沌）。
- Soft F1 指标暴露了二元成功率和预测误差无法区分的部分恢复差异（如系数精度差异、错误项但高 R² 的情况）。
- 机制性指标 $F_{SINDy}$ 和 $F_{PySR}$ 无参数拟合，成功迁移至 L96 和 jerk 系统，且部分相关性分析排除噪声水平为唯一驱动因子。

### 7. 优点

- **系统内设计**：固定方程、库、协议，只变动力学状态，严格隔离变量，之前研究无法做到。
- **可计算预诊断工具**：$\lambda_{\min}(M)$ 可在运行任何发现算法之前从短参考轨迹计算，无需掌握真实方程。
- **机理模型**：为 SINDy 和 PySR 分别构建了基于数学原理（Birkhoff 定理、岭回归、误差变量）的失效模型，参数自由，可迁移。
- **Soft F1 指标**：填补了结构 F1（忽略系数精度）和预测 R²（忽略结构正确性）之间的空白，适用于部分恢复的常见情况。
- **实验验证深度**：覆盖数据量、噪声、先验三大条件，包含留出验证、超参数控制、部分相关消融、非多项式系统验证。

### 8. 不足与局限

- **状态观测假设**：模型假定全部系统状态可测；部分观测场景（如延迟嵌入）需要额外研究，未涉及。
- **机制指标的事后性**：$F_{SINDy}$ 需知道哪些库项是真项，故只能诊断已完成运行，不能作为运行前筛选。
- **独立性假设**：PySR 的双通道（条件与信噪比）在模型中当作独立，未证明在相关噪声下成立。
- **库与运算符集限制**：仅使用 3 次多项式库（SINDy）和 {+, -, ×}（PySR），缺乏对非多项式函数、高阶项或嵌套结构的系统性覆盖。
- **混沌内趋势统计弱**：对于 L84，混沌内 $\lambda_{\min}(M)$ 随 $\lambda_1$ 变化的符号不确定（p=0.39），仅靠 5 个状态不足以定论。

- **外部验证范围较窄**：虽然包括 L96 和 jerk 系统，但均属于低维常微分方程，未测试高维动力学、时空系统或随机系统。
