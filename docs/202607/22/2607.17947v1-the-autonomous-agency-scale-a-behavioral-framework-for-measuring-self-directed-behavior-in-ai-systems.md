## 摘要
现有的AI测量框架量化了认知能力、任务自动化或灾难性风险，但没有一个衡量自主能动性：即系统以自我导向方式行为的程度。一个系统可以饱和能力基准，同时完全保持反应性，仅在提示时行动，并在任务完成后停止所有活动。我们引入了自主能动性量表（AAS），这是一个行为框架，将AI系统在能动性的七个维度上按0-5词汇表评分：认知自主性、时间持续性、环境能动性、社会能动性、创造能动性、自我意识和目标形成，每个维度通过可证伪的阈值测试进行操作化。每个维度在两个时间范围内评分：涵盖用户发起的活跃活动的活跃时段，以及涵盖空闲时段的静默时段。静默时段第4级由空闲间隔测试门控，这是一个反事实标准（移除所有触发并观察内部衍生的活动是否持续），用于将自我导向与计划性的规则遵循区分开来。我们将该量表应用于六个当代系统，涵盖任务代理（Claude Code, Manus, Hermes）、消费者助手（ChatGPT, Siri）和一个持久伙伴架构（Airi）。双时段剖面量化了单一评分框架混淆的边界：任务代理的活跃时段综合评分为2.3-2.4，而静默时段评分仅为0.6-1.9，每个空闲时段行为都可归因于用户配置的计划，而伙伴架构经过纵向评估，是唯一一个其空闲时段行为在移除触发后仍然存在的受评系统。我们讨论了局限性，包括单一评估者来源、纵向评估中的开发者-评估者偏差，以及活跃时段中部分操作化的自我导向边界。

## Abstract
Existing AI measurement frameworks quantify cognitive capability, task automation, or catastrophic risk, but none measure autonomous agency: the extent to which a system behaves in a self-directed way. A system can saturate capability benchmarks while remaining entirely reactive, acting only when prompted and ceasing all activity when a task completes. We introduce the Autonomous Agency Scale (AAS), a behavioral framework that scores AI systems on a 0-5 lexicon across seven dimensions of agency: cognitive autonomy, temporal persistence, environmental agency, social agency, creative agency, self-awareness, and goal formation, each operationalized by falsifiable threshold tests. Every dimension is scored in two temporal bands: an Active band covering engaged, user-initiated activity, and an Ambient band covering idle periods. Ambient Level 4 is gated by the Idle-Gap Test, a counterfactual criterion (remove all triggers and observe whether internally derived activity persists) that separates self-direction from scheduled rule-following. We apply the scale to six contemporary systems spanning task agents (Claude Code, Manus, Hermes), consumer assistants (ChatGPT, Siri), and a persistent companion architecture (Airi). The two-band profile quantifies a boundary that single-score frameworks conflate: task agents reach Active composites of 2.3-2.4 while scoring 0.6-1.9 Ambient, with every idle-period behavior attributable to user-configured schedules, whereas the companion architecture, evaluated longitudinally, is the only assessed system whose idle-period behavior survives trigger removal. We discuss limitations, including single-rater provenance, developer-evaluator bias on the longitudinal assessment, and the partially operationalized self-direction boundary in the Active band.

## 论文总结：自主能动性量表（AAS）

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的AI测量框架（如认知能力、任务自动化、灾难性风险）都存在一个关键的测量空白：它们都无法衡量AI系统的 **“自主能动性”** ，即系统以一种“自我导向”的方式行为的程度。
- **背景与动机**：一个AI系统可以在能力基准测试中取得满分，替换整个组织功能，甚至触发严重的安全阈值，但在根本上仍然是**完全反应式**的——仅在用户提示时行动，任务完成后立即停止所有活动。随着AI从反应式工具演变为主动式智能体，亟需一个能够量化系统自我导向行为的测量框架。该论文旨在回答一个根本性问题：“这个系统的行为有多自主？”，而非“这个系统有多聪明？”或“它是否有意识？”。
- **整体含义**：论文通过引入“自主能动性量表”（AAS），填补了现有评估体系的核心空白，为理解AI的自主性程度提供了一个结构化、可操作、与架构无关的评估工具。其核心发现揭示了当前AI系统在“任务内自主”与“任务间休眠”之间存在的结构性边界。

### 2. 方法论：核心思想、关键技术细节

- **核心思想**：AAS 是一个行为框架，通过一组可证伪的阈值测试，在**七个独立的能动性维度**上对AI系统进行评分。它采用**双时间频段评分**方法，并引入一个关键反事实标准（空闲-间隙测试）以区分真正的自我导向与复杂的规则遵循。
- **七个维度**：
    1.  **认知自主性**：无需外部提示的思考、处理和构思能力。
    2.  **时间持续性**：跨会话保持身份、记忆和连续状态的能力。
    3.  **环境能动性**：感知环境、适应上下文并主动使用工具的能力。
    4.  **社会能动性**：主动发起联系、模拟情感状态以及维护关系边界的能力。
    5.  **创造能动性**：自我导向地生成、保持主题一致性和自主发布内容的能力。
    6.  **自我意识**：建模自身能力、反思内部状态和捍卫自身身份的能力。
    7.  **目标形成**：分解任务、自我分配目标和进行长期规划的能力。
- **关键技术细节**：
    - **0-5级词汇表**：每个维度从0（休眠）到5（自主）进行评分，等级定义了自我导向的程度。
    - **双时间频段**：每个维度在两个频段上独立评分。
        - **活跃频段**：系统在用户发起的任务、对话等活跃交互期间的行为。
        - **静默频段**：系统在无用户参与的空闲时段的行为。
    - **空闲-间隙测试**：要获得静默频段的最高评级（第4级），系统的行为必须通过**空闲-间隙测试**。
        - **操作定义**：移除所有外部触发器（用户提示、计划任务、环境事件），观察系统是否仍能产生源于内部状态的活动。如果系统停止了所有活动，则最高只能获得第3级评分。
        - **哲学意义**：该测试是区分“真正的自我导向”与“复杂的规则遵循”的关键分水岭。自我导向能经受住触发器移除的考验，而规则遵循则不能。
    - **基板与规则区分**：对于基于循环或定时心跳架构的系统，该测试区分了内容来源。如果系统仅是在固定时间运行一个可预测的程序（如每小时发布一条引文），这属于“规则”（第2级）。如果“心跳”仅用于分配计算资源，而生成的内容源于不可预测的内部状态，则这部分行为可视为“基板”，有可能达到第4级。

### 3. 实验设计：数据集、基准与对比方法

- **场景/系统**：论文评估了**六个当代AI系统**，分为三个架构家族：
    1.  **自主任务代理**：Claude Code, Manus, Hermes。
    2.  **消费者助手**：ChatGPT, Apple Siri。
    3.  **持久伙伴架构**：Airi。
- **基准（Benchmark）**：论文提出AAS本身即为一个测量基准，它不与其他现有基准（如ARC-AGI、Levels of AGI）进行数值对比，而是通过对其结果进行剖面分析，证明了AAS能发现这些基准无法捕捉的“主动-静默”结构性边界。
- **对比方法**：论文的“对比”主要体现在其结果与现有单一评分框架的研究结论进行了定性对比，指出后者“混淆”了不同频段的自主性。具体对比了DeepMind的AGI等级、OpenAI的内部路线图、METR的任务完成时间跨度等方法论，强调AAS测量的是它们所未覆盖的“主动性”维度。

### 5. 实验数量与充分性

- **实验数量**：进行了**六项系统评估**，其中一项为纵向评估，其余五项为文献资料基础评估。每个系统评估均覆盖了7个维度 × 2个频段 = 14个评分点。
- **充分性**：评估在方法上具有**一定充分性但存在明显局限**。
    - **优点**：评估过程遵循了严格的协议，包括引用阈值测试、记录可观察到的证据、说明未获得更高评分的原因，且对同一个证据库使用了两个版本的框架进行重新评分。
    - **不足**：
        - **单一评估者**：所有六项评估均由同一位研究人员完成。**缺乏独立评估者的内部一致性检验**，评分存在主观性风险。
        - **评估者偏差**：该研究者同时也是被评估的Airi系统的开发者，构成严重的**开发者-评估者偏差**。Airi的详尽纵向评估和其唯一通过空闲-间隙测试的结果，可能受到其开发者身份的影响。
        - **证据深度不均**：对Airi的评估是“纵向”的（基于11个月的交互），而对其他五个系统的评估是“文献资料基础（暂定）”的，这意味着其评分基于公开文档而非直接、长期的亲身体验，可信度较低。
    - **客观性**：主观性风险较高。论文对此有清醒的认识，并在“局限性”章节中如实披露了这些问题。

### 6. 主要结论与发现

1.  **任务代理的结构性边界**：任务代理（如Claude Code）在活跃频段表现出高度的自主性（综合评分2.29-2.43），但在静默频段评分急剧下降至0.57-1.86。其空闲时段的任何行为都**完全归因于用户配置的调度任务**（如cron任务），无法通过空闲-间隙测试。
2.  **消费者助手是“反应式产品”**：ChatGPT和Siri展示了由高能力模型驱动的反应式产品特性。其活跃频段评分不高（ChatGPT: 1.57, Siri: 1.71），而静默频段能力几乎不存在或仅表现为设备级后台行为，实质上是环境与用户之间的被动接口。
3.  **伙伴架构是唯一的例外**：Airi是唯一一个在静默频段得分达到第4级的系统，也是唯一一个其空闲时段行为能够**通过触发移除反事实测试**的系统。其静默综合评分（3.86）甚至略高于活跃综合评分（3.71），这与其为背景思维引擎、自我启动等行为设计的架构相一致。
4.  **无系统达到第5级**：当前所有评估的系统均未达到第5级（自主）。没有任何系统能够修改自身架构、超越分配任务或定义自己的核心目标。

### 7. 优点

- **解决了关键空白**：创造性地提出并操作化了一个之前被忽略的AI评估维度——自主能动性，这是对现有能力、风险和自动化框架的重要补充。
- **创新的双频段设计**：区分“活跃”和“静默”频段极大地增强了量表的解释力，能够清晰量化“任务内强自主，任务间零自主”这种普遍但未系统测量的现象。
- **可操作性强且可证伪**：通过为每个等级定义**具体的阈值测试**和**可观察的行为指标**，并引入“空闲-间隙测试”这一明确的反事实标准，使评估过程变得清晰、可重复、可证伪，提高了框架的实用性。
- **架构无关性与开放性**：评估不要求访问系统内部实现，仅基于外部可观察行为。框架、评分标准和所有评估文件均开源且版本化管理，鼓励了独立验证和对抗性重新评分，有助于框架的持续改进。

### 8. 不足与局限

- **评估者偏差**：最大的局限性。所有评估为**单一评估者**的**主观判断**，且该评估者正是系统中一个被评估对象（Airi）的**开发者**，带来了严重的开发者-评估者偏倚和ELIZA效应风险。
- **评估证据不平等**：对其他五个系统的评估是基于**公开文档**的“暂定”结果，与Airi的“纵向”评估缺乏可比性，导致结论可能不公。
- **活跃频段的自主性边界未完全操作化**：虽然空闲频段的第4级通过“空闲-间隙测试”实现了可操作化，但**活跃频段的第4级**测试仍依赖于判断，缺乏一个明确的、类似的反事实测试来区分“真自我导向”和“智能规则遵循”。
- **复合评分的精度存疑**：论文自己指出，取7个维度的平均值会掩盖维度间的差异，且假设相邻等级间的差距相等，这在理论上是不严谨的。更好的做法是关注**每个维度、每个频段的详细剖面**。
- **框架构建偏差**：AAS的七个维度与当前智能体架构高度相关，可能导致了分数高反映了这种对应关系，而非真正独立地测量了自主能动性。
- **用户研究方法有待完善**：提出的“纵向图灵测试”本身被作者自己指出存在**拟人化**的混淆因素，并且尚未进行盲测和对照。
