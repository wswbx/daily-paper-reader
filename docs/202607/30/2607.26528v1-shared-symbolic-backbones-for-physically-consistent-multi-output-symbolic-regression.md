## 摘要
符号回归提供解析表达式，但通常一次只应用于一个输出。这在过程系统中存在局限性，因为状态变量通常通过共享的物理参数相互耦合。独立的符号回归可能得到准确的单个方程，但难以作为一个整体模型进行解释。我们提出了一种用于耦合多输出系统的神经进化符号回归方法。该方法搜索一个共享符号骨架：一组潜在的符号单元，这些单元被一次性发现，并通过稀疏的加法或乘法读取方式被多个输出重用。离散模型结构通过突变和交叉进行进化，而连续参数通过梯度下降调整并遗传给后代。该方法在一组已知真实解的基准测试以及水热液化产率案例上进行了评估。结果表明，耦合并不是降低预测误差的通用途径。其主要贡献在于，当物理共享因子嵌入潜在表达式且从数据中弱可辨识时，强制实现并诊断跨输出一致性。这种情况出现在Langmuir-Hinshelwood和位点覆盖分母中，独立的PySR无法弥合一致性差距或恢复相同的共享形式。相反，当每个输出已经可辨识时（如Van de Vusse基准测试），独立的符号回归与耦合模型相当或更优。所提出的框架并非通用预测器，而是一种结构化的共享机制提取器。当目标结构稀疏、共享、弱可辨识或受闭合约束时，其价值最高。

## Abstract
Symbolic regression provides analytical expressions, but it is usually applied one output at a time. This is limiting in process systems, where state variables are often coupled through shared physical parameters. Independent symbolic regression can give accurate individual equations that are difficult to interpret as one model. We present a neuro-evolutionary symbolic regression method for coupled multi-output systems. The method searches for a shared symbolic backbone: a set of latent symbolic units that is discovered once and reused by several outputs through sparse additive or multiplicative read-outs. The discrete model structure is evolved by mutation and crossover, whereas the continuous parameters are tuned by gradient descent and inherited by the offspring. The method is assessed on a set of benchmarks with known ground truth and on a hydrothermal liquefaction yield case. The results show that coupling is not a general route to lower prediction error. Its main contribution is the enforcement and diagnosis of cross-output consistency when a physically shared factor is embedded in a latent expression and is weakly identifiable from the data. This occurs for Langmuir-Hinshelwood and site-coverage denominators, for which independent PySR does not close the consistency gap or recover the same shared form. Conversely, when each output is already identifiable, as in the Van de Vusse benchmark, independent symbolic regression matches or improves the coupled model. The proposed framework, rather than a general purpose predictor, is a structured shared-mechanism extractor. Its value is highest when the target structure is sparse, shared, weakly identifiable or constrained by closure.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题来源**：过程系统中的状态变量（如反应速率、产物收率）通常通过共享的物理参数（如阿伦尼乌斯因子、吸附分母、抑制项）相互耦合。传统的符号回归（Symbolic Regression, SR）一次只处理一个输出，对每个输出独立拟合。
- **独立拟合的弊端**：各自准确的方程放在一起可能不协调——例如两个本应共享温度依赖性的速率被赋予不同的表观活化能；分别拟合的收率相关性在联合评估时可能违反质量守恒（closure violation）。这导致模型虽然每个输出误差很小，却无法构成一个单一的、物理一致的过程模型。
- **核心动机**：工程上需要的不是黑箱拟合，而是一组紧凑的方程，其中共享的物理因子被表示一次、一致地使用，并且可读、可简化、可对照机理知识。
- **整体含义**：本文提出并测试了一种**共享骨架（shared-backbone）**的多输出符号回归方法（MO-SB-NESR），旨在**强制跨输出物理一致性**，而不仅仅追求预测误差最小化。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 搜索一组**可重用的潜在符号单元（latent units）**，形成一个“共享符号骨架”（shared symbolic backbone）。
- 每个输出通过稀疏的加法或乘法读出头（read-out）从这组潜变量中选择并组合，从而实现因子共享。
- 离散结构（算子、输入掩码、读出头连接、输出模式）通过进化搜索（遗传编程）优化，连续参数通过梯度下降（Adam）调整，并采用**拉马克式继承**（后代继承亲本的调优参数）。

### 2.2 架构三组件
1. **特征库（Feature Bank）**：对原始输入进行变换，形成可配置的原始特征集，如 `x, 1/x, log x` 等。
2. **符号骨架（Symbolic Backbone）**：由 `H` 个潜变量单元组成，每个单元具有离散操作 `σ_h`、二进制输入掩码 `s_h` 以及连续参数 `(w_h, b_h)`。公式：
   \[
   z_h = \sigma_h\left(w_h^\top (s_h \odot \phi(x)) + b_h\right), \quad \sigma_h \in O = \{\exp, (\cdot)^2, \text{id}, 1/(\cdot), \log(1+\cdot), \sin, \sqrt{\cdot}\}
   \]
3. **读出头（Read-outs）**：每个输出 `o` 有一个二进制模式（乘/加）和读出头掩码行 `M_o`（长度 H）。
   - 乘法（幂律速率形式）：\( y_o = k_o \prod_{h} z_h^{e_{oh} M_{oh}} \)
   - 加法（物种平衡形式）：\( y_o = \kappa_o + \sum_h c_{oh} M_{oh} z_h \)
   - **共享是字面意义的共享**：同一个潜变量被多个输出引用，输出特定的指数/系数允许参数差异。

### 2.3 神经进化训练流程
- 初始化包含 `P` 个个体的种群，每个个体拥有随机骨架。
- 每代：评估适应度 → 选择 → 繁殖（突变和交叉）。
- 突变：翻转算子、输入掩码位、读出头边、输出模式。
- 交叉：交换整个潜变量单元。
- 适应度函数：
  \[
  F = \log L + \lambda_{\text{row}} \sum_{o,h} M_{oh} + \lambda_{\text{lat}} |\{h: \exists o, M_{oh}=1\}| + \lambda_{\text{in}} \sum_{h \text{ active}} \|s_h\|_1
  \]
  其中 `L` 是归一化均方误差（NMSE），后三项分别惩罚连接数、使用的潜变量数、每个潜变量使用的输入数，以实现稀疏性。
- 最终模型选择：在验证集上绘制误差 vs 复杂度，取在可容忍误差内最简单的模型。

### 2.4 三维先验协议
为了审计注入的领域知识，设计三种模式：
- **无约束（unconstrained）**：无先验，完全盲搜。
- **软播种（soft）**：将先验单元种子植入初始种群，但进化可保留或丢弃。
- **硬冻结（hard）**：先验单元的操作和输入被冻结，仅拟合常数。
- 通过比较三臂结果诊断：all-agree（盲搜即可恢复）、soft-recovers（需种子）、hard-only（数据不支持）、disagree（先验与数据冲突）。

## 6. 主要结论与发现

1. **耦合≠更低的预测误差**：耦合的主要优势不是提高预测精度，而是**强制跨输出一致性**。
2. **适用条件**：当共享物理因子嵌入于潜变量表达式且**每个输出单独看时弱可识别**（如弱可识别的分母），耦合才有优势。典型例子：Langmuir-Hinshelwood分母（B2）和甲醇/RWGS位点覆盖分母（B7）。
3. **不适用条件**：当每个输出已经可识别时（B1, B5, B6），独立PySR匹配或更好，耦合反而增加复杂度。
4. **关键区分**：非可分离性（non-separability）本身不是充分条件；核心是**每输出弱可识别**（per-output non-identifiability）。
5. **先验协议的诊断能力**：通过三臂协议可区分盲搜可恢复、需种子、硬约束/不可恢复等情形，审计知识注入的有效性。
6. **HTL应用示例**：所提方法在真实数据上提取出主导温度驱动因子（高温增加油和气，减少焦和液相）并满足质量守恒，尽管解释方差有限。验证了方法作为“结构化共享机制提取器”的价值。

## 7. 优点
