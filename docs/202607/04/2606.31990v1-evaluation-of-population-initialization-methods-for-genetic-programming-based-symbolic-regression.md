## 摘要
我们分析了优化基于遗传编程（GP）的符号回归（SR）初始种群对解的精度和复杂度的影响。我们比较了三种成熟的随机初始化方法，以及使用基于多目标进化算法NSGA-II的GP/SR实现从穷举符号回归（ESR）中初始化的小优化解。我们在12个不同复杂度的合成问题和1个真实数据集上比较了每种初始化方法找到的最终帕累托前沿。我们发现初始化方法在精度或模型复杂度上没有显著差异。ESR初始化的初始优势在仅几代后便消失。我们的结果表明，在初始种群多样性相似的情况下，基于GP的符号回归中初始化方法对最终帕累托前沿的影响可忽略不计。

## Abstract
We analyze the effect of optimizing the initial population of genetic programming (GP) for symbolic regression (SR) on the accuracy and complexity of solutions. We compare three well-established random initialization methods as well as initialization with small optimized solutions from exhaustive symbolic regression (ESR) using a GP/SR implementation which is based on the multi-objective evolutionary algorithm NSGA-II. We compare the final Pareto fronts found with each initialization method on twelve synthetic problems of varying complexity and one real-world dataset. We find no significant differences in accuracy or model complexity among the initialization methods. The initial advantage of initialization with ESR disappears after only a few generations. Our results show that, given similar diversity in the initial population, the effect of the initialization method in GP-based symbolic regression on the final Pareto front is negligible.

-   **关键技术细节**：
    -   **算法基准**：使用基于**NSGA-II**（多目标进化算法）的**Operon**（PyOperon）GP框架。优化两个目标：**归一化均方误差（NMSE）**和**模型复杂度**（长度）。
    -   **初始化方法**：
        1.  **随机初始化**：包括`Grow`方法、`PTC-2`（概率树创建器）和`BTC`（平衡树创建器）。
        2.  **ESR初始化**：先运行穷举符号回归（ESR），在小型搜索空间（复杂度≤10）中找到所有代数上唯一的最优模型集合。然后从ESR结果中选取模型（每个复杂度级别选取250个），直接作为GP的初始种群。为了与GP的初始大小分布匹配，ESR在不同最大复杂度（3, 5, 7, 9）下运行。
    -   **参数优化**：所有模型在进化过程中使用**Levenberg-Marquardt (LM)** 算法进行数值参数优化，最多15次迭代。
    -   **控制变量**：为了公平比较，GP的所有其他超参数（如种群大小1000，代数500，选择、交叉、变异率等）在所有初始化方法中都保持一致，唯一的变量是初始种群的生成方式。

## 6. 主要结论与发现

1.  **初始化方法影响可忽略**：在12个合成问题和1个真实世界问题上，无论是随机初始化（Grow、PTC-2、BTC）还是ESR初始化，在经过完整进化过程（500代）后，**最终帕累托前沿在精度和模型复杂度上均无显著差异**。
2.  **ESR的初始优势短暂**：ESR初始化在进化初期（最初几代）确实提供了一个明显的优势（更低的误差），但这种优势**在10到20代内迅速消失**。GP能够利用随机初始化自行产生与ESR初始化所得模型质量相当的解。
3.  **特殊情况**：只有一个简单的合成问题（Problem 1），ESR的初始模型与真实方程非常接近，此时ESR初始化显著提升了最终结果。这说明，当真实解的复杂度很低，并且ESR能精确捕获其结构时，初始化才有效。
4.  **随机方法无差异**：三种随机初始化方法（Grow, PTC-2, BTC）在所有实验上的性能也基本相同。Grow方法虽然产生了略微更低和波动更大的多样性，但这并未影响最终结果。
5.  **实践建议**：根据研究结果，作者建议在GP/SR中默认使用**BTC或PTC-2**进行随机初始化，因为它们计算成本极低，且能提供与更复杂（且昂贵）的ESR初始化完全等效的结果。

-   **多维度比较**：不仅比较了最终性能，还分析了**初始多样性**和**进化动态过程**，深入解释了观察到的现象（为何初始优势会消失）。
-   **理论与实践结合**：论文不仅进行了理论分析，还通过一个真实世界的Nikuradse数据集验证了结论的普适性，增强了研究的说服力。
-   **明确的实践指导**：结论直接、清晰、可操作，为实际应用GP/SR的研究者和工程师提供了简单有效的初始化建议。

## 8. 不足与局限

-   **搜索空间限制**：ESR的主要限制在于其只能搜索**低复杂度**（≤10）的模型。本研究中，ESR提供的模型与真值（复杂度和误差）相差较远。因此，论文的结论可能不适用于能产生高复杂度、接近真值模型的更强初始化方法。
-   **单变量函数限制**：所有问题均为**单变量**回归问题。在多维空间和交互作用更复杂的场景下，不同初始化方法的表现可能存在差异。但由于ESR无法处理高维问题，因此无法直接验证。
-   **问题集偏向性**：虽然包括了12个合成问题和1个真实问题，但问题集可能仍不能完全覆盖GP/SR在实际应用中遇到的各种困难（如大规模噪声、缺失数据、高度非线性）。尤其是真实问题只有一个，结论的普适性有待在更多真实场景中验证。
-   **GP配置固定**：研究仅使用了Operon框架和固定的GP超参数。不同的GP实现、选择策略、变异算子或种群规模可能改变初始化方法的影响。结论对其他进化算法（如遗传算法）的通用性未知。
-   **计算成本不对称**：虽然结论说“影响不大”，但ESR初始化（耗时2小时）比随机初始化（耗时5秒）昂贵得多。文章强调的是“影响可忽略”，而非“成本效益比”。对于实时或大规模应用，ESR的计算开销是不可接受的。
