## 摘要
无监督强化学习旨在无外在奖励的情况下预训练可扩展的、以技能为条件的策略，作为下游控制任务的基础。尽管近期取得了进展，但我们认为当前的离策略无监督强化学习方法受到两个关键且被忽视的瓶颈的限制：（1）非平稳的技能语义，（2）脆弱的泛化能力。为应对这些挑战，我们提出了GenDa（通用数据高效智能体），一个用于鲁棒无监督强化学习的统一框架。首先，我们引入了一种技能重标记机制，以缓解非平稳性并显著提高预训练的数据效率。其次，我们提出了互补信息瓶颈，鼓励学到的技能策略关注以自我为中心的特征，并增强对下游任务分布变化的鲁棒性。通过多种实验，我们证明GenDa显著提升了无监督强化学习的可扩展性，具有优越的泛化能力和数据效率。我们的代码和视频可在https://ihatebroccoli.github.io/official-GenDa获取。

## Abstract
Unsupervised Reinforcement Learning (URL) aims to pre-train scalable, skill-conditioned policies without extrinsic rewards, serving as a foundation for downstream control tasks. Despite recent progress, we argue that current off-policy URL methods are limited by two critical, overlooked bottlenecks: (1) non-stationary skill semantics and (2) brittle generalization. To address these challenges, we propose GenDa (Generalizable Data-efficient Agent), a unified framework for robust unsupervised reinforcement learning. First, we introduce a skill relabeling mechanism to mitigate non-stationarity and significantly improve data efficiency for pre-training. Second, we propose a Complementary Information Bottleneck (CIB), encouraging the learned skill policy to focus on ego-centric features and become robust to distribution shifts for downstream tasks. Through various experiments, we demonstrate that GenDa significantly enhances the scalability of URL with superior generalizability and data efficiency. Our code and videos are available at https://ihatebroccoli.github.io/official-GenDa.

- **研究动机**：无监督强化学习（URL）旨在无需外在奖励信号的情况下，预训练可扩展的、以技能为条件的策略，为下游控制任务提供基础。当前最先进的离策略URL方法受限于两个被忽视的关键瓶颈：
  - **非平稳技能语义（Semantic Drift）**：在离策略设置中，同一技能标签`z`对应的轨迹会随着表示函数`ϕ`的演化而变化，导致缓冲中存储的`(τ, z)`对语义过时，注入高方差噪声，严重损害数据效率。
  - **泛化脆弱性（Brittle Generalization）**：现有策略直接以包含全局上下文信息（如绝对坐标、背景）的完整状态为输入，导致技能执行与全局环境纠缠，在分布偏移（如初始位置变化、视觉背景变化）下行为不一致，限制了技能在多样化下游任务中的复用。
- **整体含义**：解决这两个瓶颈是提升URL可扩展性、使其成为真正通用控制基础的关键。本文提出GenDa框架，同时缓解语义漂移和增强泛化鲁棒性。

## 2. 方法论：核心思想、关键技术细节与算法流程
### 核心思想
- 通过**技能重标记（Skill Relabeling）** 动态对齐缓冲中的历史经验与当前表示空间，消除非平稳性。
- 通过**互补信息瓶颈（Complementary Information Bottleneck, CIB）** 迫使技能政策关注与技能执行直接相关的局部具身特征，而非全局上下文，提升泛化能力。

### 关键技术细节
1. **技能重标记（Relabeling for Skill Representation）**
   - **z-step（重标记）**：对于每条轨迹`τ = (s0, s1, ..., sT)`，用当前表示函数`ϕ`的EMA版本计算方向向量：  
     `z_relab = unit(ϕ_tgt(sT) - ϕ_tgt(s0))`，  
     其中`unit(x) = x / max(||x||, ε)`。替代原始固定的`z_roll`。
   - **ϕ-step（优化）**：使用重标记后的`z_relab`作为目标，最大化式(3)的基目标`L_base`。
   - **防止坍缩**：引入均匀性正则化项`L_unif`（式5），最小化重标记技能向量之间的余弦相似度的对数、和，鼓励`H(z_relab)`最大化，避免表示坍缩。
   - **最终表示损失**：`L_ϕ = L_base + β L_unif`，β=1.0。
2. **策略重标记（Relabeling for Skill Policy）**
   - 利用内在奖励函数`r(ϕ, z) = (ϕ(s')-ϕ(s))^T z`，对同一轨迹内的每步转移，不同时间跨度`c`生成多目标`z_c`，与`z_relab`和原始`z_roll`混合，丰富离策略奖励信号。
3. **互补信息瓶颈（CIB）**
   - 训练编码器`q_ψ(ℓ|s)`，最大化式(9)的变分信息瓶颈目标：  
     `J_CIB = I(ℓ; s) - I(ℓ; ϕ(s))`。  
     解码器`p_ω(ŝ | ℓ, ϕ(s))`可利用ϕ中的信息重建s，迫使ℓ保留ϕ未捕获的互补信息（如局部具身特征）。
   - 技能策略输入由原始状态`s`替换为ℓ：`π(a|s,z) → π(a|ℓ,z)`，训练、收集、部署时一致使用CIB，实现全局上下文鲁棒性。
4. **算法流程（Algorithm 1）**：  
   初始化策略π、表示ϕ、EMA目标ϕ_tgt、CIB编码器q_ψ、拉格朗日乘子λ、重放缓冲B。  
   - 每轮：采样技能z，通过π(a|ℓ,z)收集轨迹存入B。  
   - 每步梯度更新：从B采样批次→重标记z→更新ϕ和λ→混合原始、重标记、c步标签→用SAC更新π→更新CIB→更新EMA。
