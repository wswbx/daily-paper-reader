## 摘要
Bash脚本是系统管理和DevOps自动化的基石，其代码质量直接影响系统稳定性与安全性。在使用大语言模型（LLM）进行自动化Bash脚本生成时，存在两个相互关联的缺陷：不可审计的“黑箱”推理以及生成代码中严重的鲁棒性漏洞。为解决这两个问题，我们提出BashCoder-R1，一种用于鲁棒且可解释的Bash脚本生成的新型框架。我们的流程结合了：（1）持续预训练（CPT），使模型专门化于Bash范式；（2）在经专家验证的推理与代码样本上进行长链思维监督微调（L-CoT SFT），以模拟主动风险意识思维；（3）鲁棒性感知的组相对策略优化（R-GRPO），一个强化学习阶段，优化针对语法正确性、鲁棒性（通过shellcheck）和格式正确性的加权奖励。我们在BashBench（一个包含952个真实世界任务的新基准，其中773个单行任务、179个多行任务）上进行评估。对于单行/多行任务，BashCoder-R1实现了SyntaxPass（100.00%/94.97%）、RobustWarnRate（4.01%/16.47%）、RobustPass（95.99%/79.33%）、FuncRate（93.01%/93.85%）和FullRate（90.04%/73.18%），在FullRate上分别比最强基线DeepSeek-V3.2（推理版）高出37.82%和20.18%。在功能性、鲁棒性和清晰度方面的人工评估进一步证实了BashCoder-R1获得了最高质量评级。

## Abstract
Bash scripts are the cornerstone of system administration and DevOps automation, where code quality directly impacts system stability and security. In automated Bash script generation using Large Language Models (LLMs), two interconnected failures emerge: unauditable "black box" reasoning and critical robustness vulnerabilities in generated code. To address both, we propose BashCoder-R1, a novel framework for robust and explainable Bash script generation. Our pipeline combines: (1) Continual Pre-training (CPT) to specialize the model on Bash paradigms; (2) Long Chain-of-Thought Supervised Fine-Tuning (L-CoT SFT) on expert-validated reasoning-and-code samples to emulate proactive risk-aware thinking; and (3) Robustness-Aware Group Relative Policy Optimization (R-GRPO), a reinforcement learning phase optimizing a weighted reward for syntax correctness, robustness (via shellcheck), and format correctness. We evaluate on BashBench, a new benchmark of 952 real-world tasks (773 single-line, 179 multi-line). BashCoder-R1 achieves SyntaxPass (100.00%/94.97%), RobustWarnRate (4.01%/16.47%), RobustPass (95.99%/79.33%), FuncRate (93.01%/93.85%), and FullRate (90.04%/73.18%) for single-line/multi-line tasks, outperforming the strongest baseline DeepSeek-V3.2 (Reasoning) by 37.82% and 20.18% in FullRate. Human evaluation on Functionality, Robustness, and Clarity further confirms BashCoder-R1 achieves the highest quality ratings.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：构建一个三阶段训练流水线（CPT → L-CoT SFT → R-GRPO），使模型不仅生成功能正确的 Bash 代码，还能先输出显式推理链（`<think>...</think>`），并在强化学习阶段直接优化鲁棒性。
- **关键技术细节**：
    1. **持续预训练（CPT）**：在 976,524 条 Bash 脚本及通用文本（809.79M tokens）上继续预训练，专注于语法和结构模式，采用标准语言建模损失：
        $$L_{\text{CPT}} = -\frac{1}{N} \sum_{i=1}^N \sum_{j=1}^{T_i} \log P(x_{i,j} \mid x_{i,<j})$$
        训练 2 epochs，学习率 $1\times10^{-5}$，batch size 64，截断长度 2048。
    2. **长思维链监督微调（L-CoT SFT）**：在 12,334 个经过专家验证的样本（7,005 单行 + 5,329 多行）上进行监督学习，样本格式为 `<instruction, <think>推理链</think>, <answer>代码</answer>`。损失函数：
        $$L_{\text{SFT}} = -\frac{1}{M} \sum_{k=1}^M \sum_{l=1}^{L_k} \log P(y_{k,l} \mid I_k, y_{k,<l})$$
        训练 3 epochs，学习率 $1\times10^{-5}$，batch size 8，最大序列长度 8192。
    3. **鲁棒性感知的组相对策略优化（R-GRPO）**：在 1,824 个高复杂度样本（812 单行 + 1,012 多行）上进行强化学习。每组生成 G=8 个输出，计算三个自动奖励：
        - 语法检查 $R_{\text{syntax}}$（`bash -n` 通过为 1，否则 0）
        - 鲁棒性检查 $R_{\text{robustness}}$（`shellcheck` 无警告为 1，否则 0）
        - 格式合规 $R_{\text{format}}$（包含合理 `<think>` 和 `<answer>` 为 1，否则 0）
        总奖励 $R = 0.3 \cdot R_{\text{syntax}} + 0.5 \cdot R_{\text{robustness}} + 0.2 \cdot R_{\text{format}}$
        策略更新使用带 clip 和 KL 散度惩罚的 GRPO 目标：
        $$J_{\text{R-GRPO}}(\theta) = -\mathbb{E}\left[ \frac{1}{G} \sum_{i=1}^G \sum_{t} \min\left( r_t(\theta)\hat{A}_{i,t}, \operatorname{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_{i,t} \right) \right] + \lambda D_{KL}(\pi_\theta \| \pi_{\text{ref}})$$
        训练 5 epochs，学习率 $3\times10^{-7}$。

- **推理阶段**：使用贪心解码（温度 T=0）以确保确定性和可复现性。
