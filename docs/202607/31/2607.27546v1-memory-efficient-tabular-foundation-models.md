## 摘要
表格基础模型，如TabPFN，近年来因其在上下文表格机器学习任务中的性能而受到广泛关注，其性能往往超过经典基线。然而，这些模型的实际部署考虑受到的关注较少。在本文中，我们研究了这些模型的内存需求。我们证明，采用模型压缩方法可以实现高达7.6倍的内存缩减，同时保持相似的性能水平，将部署需求降低近87%。我们的工作为寻求在实际环境中高效部署这些模型的从业者提供了见解。

## Abstract
Tabular Foundation Models, such as TabPFN, have received a large amount of recent attention due to their performance on in-context tabular machine learning tasks, which often exceeds classical baselines. However, practical deployment considerations of these models has received less attention. In this paper we investigate the memory requirements for these models. We demonstrate that employing model compression approaches can enable memory reductions of up to 7.6 with similar levels of performance, reducing deployment requirements by nearly 87%. Our work provides insight to practitioners seeking efficient deployment of these models in practical settings.

## 方法论：核心技术思想与流程

- **核心思想**：采用后训练量化（Post-Training Quantization，PTQ）技术，将模型权重从 FP32 精度降为 INT4 精度，以减小部署时的模型存量和内存占用，同时尽量保持模型原有的预测能力。
- **三种量化方法**：
  - **K-Means 量化**（Han et al., 2016）：基于经典向量量化理论，将权重聚类为码本（codebook），并以码本索引代替原始权重，配合 INT4 位打包（bit-packing）方案，进一步压缩模型文件体积。
  - **AWQ（Activation-aware Weight Quantization，激活感知量化）**（Lin et al., 2024）：通过分析激活值分布，识别对模型性能至关重要的权重通道，在量化时给予更高精度保护，减少精度损失。
  - **GPTQ（Generalized Post-Training Quantization）**（Frantar et al., 2022）：基于逐层误差补偿的二次规划方法，通过校准数据逐步更新权重，使量化误差最小化。
- **校准流程适配**：对于源自大语言模型的 GPTQ 和 AWQ，论文将其校准流程适配至 TabPFN 的上下文学习场景，以 `(x_train, y_train; x_test)` 元组作为校准输入。
- **推理流程说明**：量化后的模型在推理时需要先反量化（dequantization）回浮点精度，因此该方法主要改善的是存储和部署带宽需求，而非运行时内存占用。
- **评估口径**：模型内存以 BZIP2 压缩后大小为基准，模拟实际部署流水线中的传输与存储场景。

- **评估模型**：
  - 表格基础模型：**TabPFN-v2.5** 和 **TabPFN-v2.6** 两个版本，分别应用 K-Means INT4、AWQ INT4 和 GPTQ INT4 三种量化方法。
  - 经典基线：XGBoost、CatBoost、LightGBM、KNN、Random Forest，每种方法均评估了默认配置和超参数调优（RandomisedSearchCV，3 折交叉验证）两种变体。
- **评估指标**：Accuracy、ROC-AUC、模型内存占用（MB）、压缩比；以及基于两两比较的 ELO 评分和胜率分析。
- **主要对比逻辑**：
  - 量化后的 TabPFN 对比 FP32 原始版本（精度损失）；
  - 量化后的 TabPFN 对比经典基线（精度优势是否保留）；

- **辅助实验（Ablations）**：

## 主要结论与发现

- **INT4 量化可显著降低部署内存**：三种 INT4 方法在 TabPFN-v2.5 和 v2.6 上均实现了 6.06×–7.65× 的压缩，同时精度损失极小（≤ 0.005）。
- **K-Means INT4 综合表现最佳**：在两种模型版本上均取得最高压缩比（7.65× 和 7.56×）和最小精度损失（0.001），同时优于 GPTQ 和 AWQ。
- **量化不会削弱 TFM 相对经典方法的优势**：所有量化变体的平均精度均高于最强的经典基线（LightGBM tuned: 0.864），在数据集级 ELO 排名和胜率分析中也保持明显领先。
- **INT4 是精度-内存的最佳平衡点**：位宽消融显示，2-bit 仅能恢复约 90% 基线精度，1-bit 则接近随机性能；4-bit 可恢复超过 99% 的精度，且仅需 5.4 MB 存储。
- **量化带来的性能方差极小**：30 个数据集上的标准差在量化前后基本一致，表明量化不会引发数据集依赖性的性能不稳定。
- **推理内存与速度基本不受影响**：由于 TabPFN 推理开销主要由注意力激活（activations）而非权重驱动，权重量化对推理峰值内存（变化 < 2%）和速度（±10% 以内）影响不大，这指向激活量化作为未来工作方向。

## 不足与局限

- **仅关注后训练量化**：未探索量化感知训练（Quantization-Aware Training, QAT），后者在更低精度下可能获得更好的性能（但需访问训练管线）。
