## 摘要
矩阵补全支撑着从表格插补到因果推断等一系列问题，然而现有的表格基础模型将其视为逐项预测，对每个目标重复上下文，并丢弃了矩阵的二维结构。我们提出 MatrixFormer，一个预训练的、矩阵原生的 Transformer，能在单次前向传播中为每个缺失项预测完整分布。MatrixFormer 完全在合成低秩矩阵和潜在因子矩阵上、在不同缺失模式下训练。在零样本应用且使用相同模型权重的情况下，MatrixFormer 在因果推断面板数据任务、语言模型基准分数补全、表格插补和推荐系统矩阵补全上取得了有竞争力的性能。这些结果使 MatrixFormer 成为矩阵补全的通用基础模型。

## Abstract
Matrix completion underlies problems from tabular imputation to causal inference, yet existing tabular foundation models treat it as entry-by-entry prediction, repeating context for every target and discarding the matrix's two-dimensional structure. We introduce MatrixFormer, a pre-trained matrix-native transformer that predicts a full distribution for every missing entry in a single forward pass. MatrixFormer is trained entirely on synthetic low-rank and latent-factor matrices under diverse missingness patterns. Applied zero-shot and with the same model weights, MatrixFormer achieves competitive performance on causal inference panel-data tasks, language-model benchmark-score completion, tabular imputation, and recommendation systems matrix completion. These results position MatrixFormer as a general-purpose foundation model for matrix completion.

# MatrixFormer 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **问题定位**：矩阵补全（matrix completion）是表格插补、推荐系统、因果推断（面板数据反事实预测）、语言模型基准分数补全等一系列任务的共同底层问题。观测条目同时携带行结构与列结构信息。
- **现有方法的局限**：
  - 传统方法（低秩分解、链式方程插补 MICE/ICE、MissForest、HyperImpute 等）需要针对每个新矩阵从观测条目重新估计参数，无法复用计算。
  - 表格基础模型（如 TabPFN 系列、TabImpute）虽通过合成预训练把部分计算"预置"进模型，但采用**逐项（entry-wise）表示**：把一个 $R\times C$ 矩阵展开成 $RC$ 个监督样本，每个样本重复携带行/列上下文。这导致：
    1. 内存与运行时间随矩阵规模急剧膨胀；
    2. 矩阵的**二维结构被丢弃**，行列结构在表示层面不再区分。
- **整体含义**：作者提出 MatrixFormer——一个**矩阵原生（matrix-native）**的预训练 Transformer 基础模型，把矩阵当作二维网格直接建模，单次前向即可为所有缺失项输出完整预测分布，并声称可零样本、同一套权重跨领域通用。

## 2. 方法论

### 2.1 核心思想
- 将部分观测矩阵 $X\in(\mathbb{R}\cup\{\text{NaN}\})^{R\times C}$ 及其缺失掩码 $M$ 直接表示为 $R\times C$ 的**单元格 token 网格**，用交替轴向注意力（alternating axial attention）沿行、列两个自然轴传播信息，避免逐项展开的上下文重复。
- 单次前向并行预测所有缺失项，每个缺失项输出一个**完整分布**（而非仅点估计）。
- 完全在**合成矩阵**上预训练，部署时权重固定、零样本使用。

### 2.2 关键技术细节

**（1）单元格表示（式 1）**
- 观测单元初始表示 $E^{(0)}_{rc}=(1-M_{rc})f_{val}(\tilde X_{rc})+M_{rc}m_{mask}+e_{miss}(M_{rc})$。
- 观测值经共享 MLP $f_{val}$ 嵌入；缺失值使用可学习 mask 向量 $m_{mask}$（类似 BERT 的 masked-token）；再加一个按观测状态查表的嵌入 $e_{miss}$ 作为偏置。

**（2）CLS 边框**
- 在网格外分别添加 $K_c$ 列 row-CLS token 与 $K_r$ 行 column-CLS token（$K_r=K_c=12$），把 Transformer 的特殊聚合 token 思想推广到两个矩阵轴；这些 token 参与注意力但不是预测目标。

**（3）交替轴向注意力（式 2–4）**
- 每个 block 依次做：**特征注意力**（在每行内跨列，捕捉同一数据点的其他变量）→ **数据点注意力**（在每列内跨行，捕捉同一变量跨样本的结构）→ **FFN**。
- 均采用 pre-norm RMSNorm + 残差，残差以可学习标量增益 $\gamma_i$ 缩放（ReZero 风格）；FFN 用 SwiGLU。
- 位置编码用 **RoPE**，沿被注意的轴施加（特征注意力用列位置，数据点注意力用行位置）。
- 规模：$L=8$ 个 block，宽度 $d=768$，16 个注意力头（头维 48），FFN 宽度 1536，共 **78M 参数**。

**（4）解码器与 bar 分布（式 5–6）**
- 共享解码 MLP $f_{dec}:\mathbb{R}^d\to\mathbb{R}^O$（$O=5000$ 个固定 bin），输出经 softmax 得到 bin 概率 $q(z)$，构造 **bar distribution**；两端 bin 换成半正态尾部使支撑为 $\mathbb{R}$。
- 点插补取预测均值 $\hat X_{rc}=\sum_k q_k(z_{rc})\nu_k$（$\nu_k$ 为 bin 中点，两端为尾部均值）。
- 保留完整分布使同一解码器可同时支持似然损失与 CDF 对齐损失。

**（5）计算复杂度**
- 朴素稠密注意力为 $O(R^2C^2)$；轴向分解后为 $O(RC^2+CR^2)=O(RC(R+C))$，显著降低注意力开销并保持行列结构区分。

### 2.3 合成预训练

**三阶段训练**（同架构，逐阶段续训）：
1. **Base 阶段**：小规模潜因子矩阵（rank 1–11，10–50 行 × 5–50 列，40% MCAR），17k 更新。
2. **Main 阶段**：多样化数据与目标，128k 更新。
3. **Size-extension 阶段**：把矩阵逐步放大到最多 2000 行 × 1000 列，5k 更新（类比 LLM 的上下文长度扩展）。

**数据先验（式 8–10）**：四个等概率矩阵族
- 低秩族（rank 2–16，$\alpha\sim U(0.2,2)$）；
- 慢尾 / 陡尾谱族（rank 2–min(160,R,C)，$\alpha$ 分别 $\sim U(0,0.5)$、$U(1,2.5)$）；
- 潜因子族（rank 1–min(11,R,C)，因子行分布为高斯/Laplace/Student-t/spike-and-slab/中心化 Dirichlet）。
- 谱系数由"快衰减头部 + 幂律尾部 + 终端 taper"混合生成（式 9），奇异向量几何在四种构造（高斯、相干、平滑、含偏移）中随机选择。
- 缺失机制：固定 40% MCAR 或混合核（MCAR/MAR/MNAR + 结构化模式，名义缺失率 5%–75%）；75% 的 episode 额外抽稀部分行/列以模拟稀疏支撑（如新用户）。每个族配两种掩码 → 8 个等权组件。

**目标函数（式 11）**
- $L(\theta)=\mathbb{E}\big[\frac{1}{|S|}\sum_{(r,c)\in S}\big(-\log p_{\theta,rc}(y_{rc})+2\rho(\mu_{\theta,rc}-\bar\mu_{rc})+0.05\,\ell_{CDF}(z_{rc},y_{rc})\big)\big]$
- 三项分别为：真值监督的负对数似然、**向两个冻结教师模型均值蒸馏**的 Huber 点损失（阈值 1）、真值监督的 CDF 排序概率分数（RPS，bin 中点阈值）。
- 教师仅训练时使用，推理仍是单模型单次前向。

**优化**：AdamW（weight decay 0.02，梯度裁剪 0.5），FP32 参数 + BF16 计算；主阶段 batch 为 2 个矩阵，学习率 600 步 warmup 至 $10^{-5}$ 后余弦衰减至 5%；用固定合成验证集选最优 checkpoint。

### 2.4 观测误差集成（MatrixFormer，式 12）
- MatrixFormer = 通用专家 MatrixFormer-Impute 与推荐专用专家 MatrixFormer-RecSys 的**输入相关凸混合**。
- 对每个输入矩阵，用**观测单元**上的归一化平方重建误差拟合单一权重 $w^\star$（两模型最小二乘解析解，裁剪到 $[0,1]$），同一权重用于所有缺失单元。
- 注意：权重拟合使用的是观测条目（in-sample 证据），作者在独立隐藏条目上评估该混合。
