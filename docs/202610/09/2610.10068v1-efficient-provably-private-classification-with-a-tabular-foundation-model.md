## 摘要
表格数据支撑着医学、金融、政府和科学领域的预测与决策，但往往包含敏感的个人层面信息，因此需要在保持隐私的同时进行准确预测。传统隐私学习提供形式化隐私保证，但需要缓慢的、针对特定数据集的优化，在强隐私下会遭受显著的效用损失，并且常常难以正确应用。表格基础模型能够快速适应新数据集，但现有模型缺乏形式化隐私保证，且极易受到成员推断攻击，限制了其在敏感数据上的使用。在此，我们提出 PrivTab，一种易于使用的、用于差分隐私分类的表格基础模型，其架构内嵌了隐私机制。PrivTab 在模拟数据集上预训练，利用上下文学习将敏感行转换为紧凑的、可证明私密的摘要——有效学习如何在隐私约束下学习。在中等至强隐私下，PrivTab 优于隐私线性与神经网络基线，表现出可忽略的成员泄露，在强隐私下仍保持校准良好的预测，并将数据集拟合时间减少 10,000 倍，仅需单次前向传播。通过结合形式化隐私、速度和易用性，PrivTab 将近期 AI 进展带入因敏感个人层面数据而受限的应用中。

## Abstract
Tabular data underpin prediction and decision-making in medicine, finance, government and science, but often contain sensitive individual-level information, creating a need for accurate prediction while preserving privacy. Traditional private learning provides formal privacy guarantees, but requires slow dataset-specific optimisation, suffers substantial utility loss under strong privacy, and is often difficult to apply correctly. Tabular foundation models adapt rapidly to new datasets, but existing models lack formal privacy guarantees, and are highly vulnerable to membership-inference attacks, limiting their use on sensitive data. Here we introduce PrivTab, an easy to use tabular foundation model for differentially private classification that embeds a privacy mechanism within its architecture. Pretrained on simulated datasets, PrivTab uses in-context learning to transform sensitive rows into compact, provably private summaries---effectively learning how to learn under privacy. PrivTab outperforms private linear and neural-network baselines under moderate-to-strong privacy, shows negligible membership leakage, maintains well-calibrated predictions under strong privacy, and reduces dataset fitting time by 10,000 times, requiring only a single forward pass. By combining formal privacy, speed, and easy of use, PrivTab brings recent advances in AI to applications where sensitive individual-level data have limited their adoption.

## 2. 方法论

### 2.1 核心思想

- 将**隐私机制嵌入基础模型架构中敏感信息进入的位置**：在上下文数据集到摘要的转换环节引入差分隐私（DP），将敏感上下文压缩为紧凑的、可证明私有的摘要（private summary）。
- 摘要一旦生成，所有下游预测均为 DP 的**后处理**，不再消耗隐私预算，可无限次存储和查询。
- 在数百万模拟任务上以**隐私感知目标**预训练，模型学会在隐私噪声下进行预测，而非仅在部署时被动加入噪声。

### 2.2 关键技术细节

**（1）整体架构（基于 LBANP）**
- 参数量约 9.3M，其中私有摘要模块 8.9M，预测模块 0.4M。
- 行嵌入：将每行特征与标签嵌入拼接，映射到 256 维 token；查询行使用专门的未知标签标记。
- 私有摘要模块：初始化 128 个可学习伪 token（pseudo-tokens），经 **3 层主层**（每层先 DP-MHCA 再 MHSA）+ **2 层后处理 MHSA**，返回 5 个摘要状态。
- 预测模块：查询 token 通过标准 MHCA 与摘要交互，最后经 MLP 输出类别 logits。

**（2）DP-MHCA（差分隐私多头交叉注意力）**
- 用**有界 tanh 注意力**替代 softmax：$g(q,k) = \tanh(\langle q,k\rangle/\sqrt{d_h})$，值向量归一化使 $\|v_j\|_2 \leq 1$，每个加和项仅依赖一行，且范数有界。
- 注意力输出加高斯噪声 $\xi_i \sim \mathcal{N}(0, \sigma^2 I)$，可选后噪声归一化（缩放至最大范数 $G=512$），该归一化为后处理，不影响隐私。
- 灵敏度上界：$\Delta_2 \leq 2\sqrt{Hm}$，**与上下文大小 $n_c$ 无关**。

**（3）隐私保证（GDP 参数化）**
- 噪声标准差：$\sigma = \dfrac{2\sqrt{Hm L_{\text{main}}}}{\mu}$
- 每层满足 $\mu/\sqrt{L_{\text{main}}}$-GDP，经 GDP 自适应组合后整体满足 $\mu$-GDP。
- 替换-一（replace-one / substitute）邻接关系，报告为高斯差分隐私（GDP），可通过 $\delta(\varepsilon) = \Phi(-\varepsilon\mu + \mu/2) - e^{\varepsilon}\Phi(-\varepsilon\mu - \mu/2)$ 转换为 $(\varepsilon,\delta)$-DP。
- 组合公式：$\mu_{\text{total}}^2 = \sum_i \mu_i^2$。

**（4）噪声感知预训练目标**
- 目标为在噪声摘要条件下的交叉熵：$\mathcal{L}_{\text{priv}} = \mathbb{E}_{\tau}\left[-\sum_{(x,y)\in D_t}\log q_\psi(y|x,\tilde{S})\right]$
- 理论上等价于最小化噪声感知后验预测分布 $p_\phi(\cdot|x,\tilde{S})$ 与预测分布之间的 KL 散度（Theorem S2.1）。
- 训练课程：隐私级别 $\mu$ 对数均匀采样，初期从低噪声（$\mu_{\min}=64$）逐步降到 0.16；上下文规模先小（100–2048）后大（1024–8192）。
- 两个模型变体：小上下文（<4096 行）与大上下文（≥4096 行），推理时按上下文大小路由。

**（5）私有预处理（可选扩展）**
- 使用公开描述（LLM 推断）确定裁剪区间 $[a_k, b_k]$，释放加噪的上下文和与平方和（各分配 $\mu_{\text{prep}}/2$），计算噪声均值与方差，再对上下文和查询行做标准化。
- 总隐私预算按 $\mu_{\text{total}} = \sqrt{\mu_{\text{prep}}^2 + \mu_{\text{pred}}^2}$ 组合。

**（6）验证与审计**
- **形式化验证**：Lean 4 证明灵敏度界与自适应 GDP 组合。
- **实现检查**：自动化测试确认 DP-MHCA 前所有变换逐行独立。
- **经验审计**：梯度优化搜索最坏相邻数据集，用最优似然比检验比较实际输出与理论 trade-off 曲线。

## 3. 实验设计

### 3.1 数据集与场景

- **主基准**：33 个 TabArena 分类数据集（行数 ≤100,000，特征 ≤120），涵盖二分类与多分类。

- **DP-LR**：差分隐私逻辑回归。

- 非私有逻辑回归作为性能参照；TabPFN v3 与 TabICL v2 作为成员推断攻击对比。

## 6. 主要结论与发现

- **预测性能**：PrivTab 在**中等至强隐私**下 AUC 与 log loss 均优于 DP-LR 和 DP-MLP；强噪声下 log loss 优势最显著（表明嵌入式隐私机制有助于保持可靠的不确定性估计）。弱隐私下 DP-MLP 逐渐追平甚至反超。
- **聚合 Elo**：PrivTab 在所有隐私级别上的聚合 Elo 最高（1166.5），DP-MLP 为 1097.5，DP-LR 为 1000。
- **数据集规模趋势**：PrivTab 相对 DP-MLP 的优势在小数据集上最大，随数据集增大而减小（Spearman $\rho=-0.57$ 至 $-0.66$）；相对 DP-LR 的优势则随数据集增大而增加（$\rho=+0.27$ 至 $+0.49$）。
- **拟合效率**：PrivTab 中位拟合时间约 10 ms，比基线快**四个数量级以上**；全基准仅需 30 GPU 秒 vs 基线的 400/130 GPU 小时。
- **成员隐私**：PrivTab 的记录级成员推断 AUC 接近 0.5（完美隐私），最脆弱记录的攻击准确率远低于 TabPFN v3 和 TabICL v2（后者接近 100%）。
- **私有预处理**：使用 LLM 从公开描述推断裁剪区间可实现端到端私有预处理，在 5 个数据集上 PrivTab 仍取得最高 Elo（1161.5）。
- **消融结论**：噪声感知预训练至关重要（Elo 1440 vs 1188）；3 层私有层、单头 DP-MHCA、tanh 交互函数、上下文尺度归一化与双模型组合均为最优配置。

- **噪声感知训练**：模型在预训练时即接触隐私噪声，学习在噪声下预测，显著优于部署时被动加噪。
