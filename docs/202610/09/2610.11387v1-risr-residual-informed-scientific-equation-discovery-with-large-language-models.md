## 摘要
符号回归将结构搜索与数值拟合相结合，但聚合拟合分数并不能描述剩余误差如何随输入变化。我们提出 RISR，一种残差信息引导的方法，利用这些误差模式来指导公式发现，并学习哪些修正值得拟合。一个残差编码器将对齐的输入、目标、当前预测和残差压缩为连续 token，用以条件化语言模型以提出公式。在后续精炼中，一个双视图关系编码器使用加性残差和正则化乘性残差来预测候选修正的拟合后效用。我们在 LLM-SRBench 的科学任务上评估 RISR。RISR 在 1% 和 0.1% 逐点相对误差容限下分别达到 63.57% 和 38.50% 的 ID 准确率。相应的 OOD 准确率为 56.07% 和 38.24%。RISR 在使用相同骨干模型的情况下优于所报告的基线。结果表明，我们的残差信息引导方法能够改进数值方程恢复。

## Abstract
Symbolic regression combines structural search with numerical fitting, but aggregate fit scores do not describe how the remaining error varies across inputs. We introduce RISR, a residual-informed method that uses these error patterns to guide formula discovery and learn which corrections are worth fitting. A residual encoder compresses aligned inputs, targets, current predictions, and residuals into continuous tokens that condition a language model to propose formulas. For subsequent refinement, a dual-view relational encoder uses additive and regularized multiplicative residuals to predict the post-fit utility of candidate corrections. We evaluate RISR on scientific tasks from the LLM-SRBench. RISR achieves 63.57% and 38.50% ID accuracy at the 1% and 0.1% pointwise relative-error tolerances, respectively. The corresponding OOD accuracies are 56.07% and 38.24%. RISR outperforms the reported baselines using the same backbone. The results show that our residual-informed approach can improve numerical equation recovery.

## 1. 核心问题与研究动机

- **背景**：符号回归（Symbolic Regression, SR）旨在从观测数据中恢复显式的数学表达式，兼具可解释性与科学价值。其本质是一个**离散结构搜索**与**连续系数拟合**紧密耦合的问题：某个结构项是否有用，取决于其拟合后的系数以及它与方程其余部分的组合方式。
- **核心痛点**：现有方法（稀疏辨识、神经策略搜索、进化算法、LLM 引导搜索等）普遍使用**聚合拟合分数**（如 MSE、NMSE）来排序候选方程，但这类标量分数**无法刻画残差如何随输入变化**。
- **具体后果**：整体损失相近的两个方程，其误差在输入空间中的分布（非线性模式、变量交互、局部偏差）可能截然不同，因而需要完全不同的修正方向；聚合分数丢失了误差的位置与变量依赖信息，无法为下一步"改哪里、怎么改"提供细粒度指导。
- **论文含义**：作者主张把**逐点残差（pointwise residual）** 作为一等公民，既用于条件化 LLM 的公式生成，也用于学习"哪种修正值得拟合"的决策，从而把数值反馈从"打分"升级为"指导"。

## 2. 方法论

### 2.1 总体框架：两阶段流水线

RISR 分两个阶段：
- **Stage A — 残差信息引导的公式搜索**：用残差编码器把数值状态压成连续 token 条件化冻结的 LLM，结合可学习的结构编辑生成器，搜索并拟合出初始方程 $p_0$（64 个外层候选槽位）。
- **Stage B — 残差引导的精炼**：对 $p_0$ 先做全系数标定，再用双视图关系编码器 + 效用头对修正动作排序，最多进行 **4 次**修正拟合尝试，**不再调用 LLM**。

### 2.2 Stage A：搜索残差编码器与结构编辑

- **输入对齐元组**：$(x_i,\ y_i,\ p(x_i),\ r_i=y_i-p(x_i))$，即输入、目标、当前预测、残差四通道对齐。
- **双路径编码**：
  - **点注意力路径**：逐行 MLP（11→256→256）+ 两个 8 头自注意力块；16 个可学习 query 通过交叉注意力聚合有效点，输出 16×256。
  - **谱场路径**：显式特征提升，每点 122 维特征（24 个坐标通道 + 21 个坐标对乘积×残差 + 72 个正余弦通道 + 5 个观测通道）；6 个**可学习对数频率**（非 FFT）；7 个残差中心做高斯加权区域池化。
  - **融合与投影**：逐 token 学习式 sigmoid 门控融合两路，投影器 256→2048→2048 映射到 LLM 嵌入空间，得到 **16 个连续 token** 替换一个占位符嵌入。
- **LLM 冻结**：以 Qwen3-Coder-30B-A3B-Instruct 为骨干，编码器与投影器从零训练，LLM 参数不动、不加 LoRA。
- **可学习结构编辑生成器**：自带的残差编码器 + AST 程序编码器（节点类型、变量、常数、父子关系、深度），通过交叉注意力预测 **add / replace / delete / stop** 四类编辑及目标节点、函数族、变量支撑与连续参数。
- **坐标裁剪**：编码器最多 6 个坐标槽（按与残差的相关性打分筛选），但方程签名与数值拟合保留全部原始变量。

### 2.3 Stage B：双视图残差编码与修正效用预测

- **两种修正模式的动机**：
  - 加性更新 $p+h$ → 需要 $h(x_i)\approx r_i$，直接用残差 $r$。
  - 乘性更新 $p(1+h)$ → 需要 $p_i h(x_i)\approx r_i$，理论上应使用 $r_i/p_i$，但 $p_i$ 近零时不稳。
- **正则化乘性信号**（核心公式）：

$$u_i=\frac{p_i r_i}{p_i^2+\lambda^2},\qquad \lambda=0.05\cdot\max\{\mathrm{RMS}(p),10^{-8}\}$$

  当 $|p_i|$ 远大于 $\lambda$ 时 $u_i$ 近似分数修正 $r_i/p_i$，在零点附近抑制不稳定比值。
- **变量表示**：每个变量构造 **140 维统计特征**（14 种坐标变换 × 7 种信号 + 矩统计），其中 14 种变换包括 $z,z^2,z^3,|z|,\log(1+z^2),e^{-z^2}$ 与 4 个频率的正余弦对；另有 **9 个有向边特征**（$z_jz_k,\ z_j^2z_k,\ z_jz_k^2$ 与信号的相关）以及每视图 **64 个算子乘积相关**。
- **关系注意力**：两视图**共享**嵌入网络与两个 4 头关系注意力块，边特征同时贡献注意力偏置与 value；变量表示与全局池化上下文拼接后经 384→128 融合为 $h_j$（支持最多 8 个变量，掩码处理 padding）。
- **动作空间**：8 个算子族

$$\Phi=\{z,\ z^2,\ z^3,\ \sin z,\ \tanh z,\ \exp z,\ \log(1+z^2),\ (1+z^2)^{-1}\}$$

  动作 = {加性/乘性} × {1 或 2 个变量} × {每变量一个算子}；维度 $d$ 下共 $16\big(d+2\binom{d}{2}\big)$ 个有效动作（$d=8$ 时为 3712 个）。
- **共享效用头** $Q_\theta(D,p,a)$：将变量表示与算子嵌入组成 query，乘积动作对称组合并附加两视图的乘积相关，预测**拟合后效用**（编码器 + query + 效用头共约 **389,297** 个可训练参数）。

### 2.4 系数拟合与自适应接受

- **拟合目标**（加权相对平方误差）：

$$L_S(f)=\frac{1}{|S|}\sum_{i\in S}\left(\frac{f(x_i)-y_i}{s_{i,S}}\right)^2,\quad s_{i,S}=\max\{|y_i|,\ 0.01\,\mathrm{RMS}(y_S),\ \epsilon_{64}\}$$

- **变量投影（Variable Projection）**：修正形式为 $h_a(x)=\alpha\prod_{j\in J}\phi_{k_j}(b_j z_j+c_j)+\beta$；对每一组非线性参数 $(b_j,c_j)$ 用加权最小二乘解析求出线性参数 $\alpha,\beta$（加性设计列 $(g_a,1)$，乘性设计列 $(p g_a,p)$），非线性参数用 3 个确定性起点 + 信赖域反射最小二乘求解，单动作总时限 15 秒。
- **自适应动作选择**：冻结的打分器每次选最高分的未尝试动作；若训练相对平方误差**下降超过 0.1%** 则接受，否则回退；每次接受后刷新残差视图与动作排序；被拒动作也计入 4 次预算；训练 NMSE ≤ $10^{-12}$ 时提前停止。
- **关键约束**：所有接受决策只基于训练集，不使用测试观测；精炼阶段不调用 LLM。

### 2.5 合成数据与离线训练

- **搜索残差编码器**：6,000 训练 / 768 验证，目标公式由随机变换的初等函数组合成乘积、平滑机制切换或条件门控响应，当前方程故意缺项或用仿射近似；训练目标为冻结 LLM 上目标公式 token 的交叉熵（AdamW，1 epoch，750 步，encoder lr $2\times10^{-5}$，projector lr $10^{-4}$）。
- **结构编辑生成器**：先做 50,000/5,000 的残差预训练，再用 20,000/2,000 的编辑监督（增/删/替/停标签 + 拟合增益 + 复杂度变化）。
- **精炼配对数据**：8,192 训练对 / 1,024 验证对 + 3 个各 1,024 对的测试集（新观测云、留出乘积动作、8 变量输入），合计 24,576 个状态、**196,608 个动作效用标签**。
- **效用标签构造**：256 个观测分为 192 个拟合行 F 与 64 个效用行 H；在 F 上拟合并按 0.1% 阈值接受，在 H 上测量效用：

$$U(p,a)=\mathrm{clip}_{[-3,3]}\left[\log_{10}\frac{L_H(p)+\varepsilon}{L_H(p'_a)+\varepsilon}\right]$$

- **训练损失**：$L=L_{\text{value}}+0.5\,L_{\text{rank}}+0.5\,L_{\Delta}$，其中 $L_{\text{rank}}$ 学习同一状态内动作排序，$L_{\Delta}$ 匹配同一动作在两个配对状态上的效用差（即"动作效用随当前方程变化"的监督）。
