## 摘要
核函数编码了广泛机器学习模型的归纳偏置，然而自动化核函数设计面临一个根本性困境。由基核和算子构成的固定文法保证了有效性，但将搜索限制在这些构建块可表达的结构内。相反，无限制的程序消除了这一限制，但不再保证有效性。在我们的压力测试中，在随机输入上通过数值检查的 LLM 生成核函数中，有 22-58% 在不同尺度或维度上评估时失败。我们提出 Kernel Autoresearch（Kernaut），它将核函数设计视为开放式模型发现。编码智能体将核函数编写为程序，而构造契约确保每个被接受的核函数都是有效的。一个质量-多样性存档保留具有不同行为的高性能核函数，新颖性筛选引导智能体转向功能上新颖的候选。我们的实验表明，所发现的核函数编码了可复用的归纳偏置，能够泛化到未见任务。在留出的黑箱优化族上，一个发现的核函数优于在同一批回合上训练的元学习深度核。此外，从十个酶动力学速率定律中发现的核函数在五个未见机制上实现了比调优的 ARD 和深度核基线更低的误差。所发现的核函数也是人类研究者可改进的可解释程序：其中一个经人类改进的版本进一步将留出预测误差降低 5.7%，将优化遗憾降低 7.8%。

## Abstract
Kernels encode the inductive bias of a wide range of machine learning models, yet automated kernel design faces a fundamental dilemma. A fixed grammar of base kernels and operators guarantees validity but limits the search to structures expressible by those building blocks. Conversely, unrestricted programs remove this limitation but no longer guarantee validity. In our stress tests, 22-58% of LLM-generated kernels that pass numerical checks on random inputs fail when evaluated at different scales or dimensions. We propose Kernel Autoresearch (Kernaut), which treats kernel design as open-ended model discovery. Coding agents write kernels as programs, while construction contracts ensure that every accepted kernel is valid. A quality-diversity archive retains high-performing kernels with distinct behaviors, and novelty screening steers agents toward functionally new candidates. Our experiments demonstrate that the discovered kernels encode reusable inductive biases that generalize to unseen tasks. On held-out black-box optimization families, a discovered kernel outperforms a meta-learned deep kernel trained on the same episodes. Furthermore, kernels discovered from ten enzyme-kinetic rate laws achieve lower error than tuned ARD and deep kernel baselines on five unseen mechanisms. The discovered kernels are also interpretable programs that human researchers can refine: a human-refined version of one further reduces the held-out predictive error by 5.7% and optimization regret by 7.8%.

## 1. 核心问题与研究动机

- **背景**：核函数决定了高斯过程、核岭回归、SVM 等一大类模型的归纳偏置，但自动化核设计长期陷入两难。
- **两难困境**：
  - **固定文法路线**（基核 + 固定算子，如 CKS、BO 搜索、神经组合、CAKE）：由构造保证有效性，但搜索空间被限制在已有构件能表达的结构内。
  - **无限制程序路线**（让 LLM 直接写 `kernel_matrix`）：打破限制，但任意程序不保证是对称、正半定（PSD）的合法核（Rice, 1953 的不可判定性）。
- **关键实证**：论文的压力测试显示，在随机输入上通过数值检查（Cholesky/特征值）的 LLM 生成核中，有 **22–58%** 在改变输入尺度、维度或批处理方式后失效；即使要求先给出 PSD 证明，仍有约 8/37 的程序失败（多为实现错误）。
- **整体含义**：将核设计重新表述为**开放式模型发现（open-ended model discovery）**——允许智能体写出超越固定文法的核程序，同时用可信机制保证每个被接受的核在数学上有效，并让发现的核具备可迁移、可解释、可人工改进的归纳偏置。

## 2. 方法论：Kernaut 框架

### 2.1 核心思想
- 智能体**只写核的“组件”**（点函数、特征、频谱、输入变换），由**可信解释器（trusted interpreter）** 用 PSD 保持规则组装成完整 Gram 矩阵。
- 组件接口 + 组装规则 = **构造契约（construction contracts）**。

### 2.2 四类构造契约（Definition 2）
- **Feature map**：φθ: X→Rᵐ，κθ(x,y)=φθ(x)ᵀφθ(y)。
- **Spectral**：频率 ωⱼ 与原始权重 rⱼ，κθ(x,y)=Σⱼ wⱼcos(ωⱼᵀ(x−y))，其中 wⱼ=rⱼ²/M ≥ 0（由 Bochner 定理保证）。
- **Pullback**：输入变换 Tθ，κθ(x,y)=k₀(Tθ(x),Tθ(y))，k₀ 为可信库核（RBF、Matérn、RQ 等）。
- **Closure**：以库核或已接受核为叶子，用和、积、非负标量乘法组合（Schur 积定理保持 PSD）。

### 2.3 有效性保证（Proposition 1）
- 只要组件返回**有限输出**且**维度正确**，每个契约产生的矩阵都对称 PSD。
- 额外要求**纯度（purity）**：输出只依赖输入与参数，不依赖批内其他点、随机性或历史调用；满足纯度后组装函数才是定义在整个域上的合法核。
- **Proposition 2**：特征契约在紧集上可一致逼近任意连续 PSD 核（表达能力不受限），但不保证高效综合。

### 2.4 验收阶梯（Acceptance Checks）
- **T0 可执行**：沙箱执行、输出形状正确。
- **T1 经验 PSD**：采样输入上的特征值与对称性数值测试。
- **T2 契约认证**：契约组装 + 纯度 + 5 类蜕变关系（确定性、置换、子集、扩展、重复点）。
- **只有 T2 程序能进入存档**；源码静态检查拒绝批依赖、随机性、持久状态。

### 2.5 质量-多样性存档与新颖性筛选
- 采用 **MAP-Elites**：每个候选占据一个单元 c(κ)=(niche, growth, novelty band)。
- **核指纹**：在维度 d∈{2,5,8} 的 16 个固定点上计算中心化、单位归一化的 Gram 矩阵；用最小平均指纹距离 d_nov 衡量与参考核的相似度。
- **新颖性惩罚** Ω_nov 为软惩罚（τ_nov=0.08，λ_nov=0.1，γ=5），预测提升越大惩罚越小。
- 调度器优先填充空 niche；以 p_new=0.35 概率写新根，否则修订父代精英，并采样 k_insp=3 个灵感。

### 2.6 算法流程（Algorithm 1–3）
- **Algorithm 1（Campaign）**：预算 B 次 run，每次选 niche → 选 parent/root → 采样灵感 → 运行一次 agent session → 若通过 T2 则加入存档并更新 cell elite → 最后用验证 CRPS 选择冻结程序。
- **Algorithm 2（Session）**：工具调用序列 propose_formulation → stage_candidate → verify_staged_candidate → optimize_parameters（Halton 序列，最多 64 次）→ submit_staged_candidate → evaluate_candidate。
- **Algorithm 3（Selection）**：仅按验证 CRPS 排序冻结程序，测试集在选定后才打开。
