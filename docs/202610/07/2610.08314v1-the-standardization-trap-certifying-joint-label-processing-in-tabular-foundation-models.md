## 摘要
线性回归与核平滑为上下文学习提供了易于处理的解释：在这两者中，特征决定了分配给每个上下文标签的权重。然而，这种固定权重解释是否能够描述预训练的表格基础模型（TFM）仍不清楚。使用导数来检验这一解释会陷入标准化陷阱：公开的 TFM 软件包在模型看到标签之前会先对标签进行标准化，而普通导数还反映了标准化标签集合之外的行为，从而使得即使模型做出的每一个预测都与某个固定权重映射一致，模型仍可能显得是非线性的。我们提出两种仅依赖于标准化标签处预测的证书，它们能够拒绝两种不同的解释：固定权重预测，以及相互独立的非线性标签变换之和。在我们评估的五个公开 TFM 上，我们的证书表明，改变一个上下文标签会改变其他标签对预测的影响，我们将这种行为称为联合处理。我们进一步发现，联合处理随训练而出现，并且注意力分数承载了所测得的大部分交互。总之，这些发现促使我们提出能够解释上下文标签如何改变单个样本影响的 TFM 解释。

## Abstract
Linear regression and kernel smoothing offer tractable explanations of in-context learning: in both, the features determine the weight assigned to each context label. However, whether this fixed-weight account describes pretrained tabular foundation models (TFMs) remains unclear. Testing this account using derivatives runs into a standardization trap: public TFM packages standardize the labels before the model sees them, yet ordinary derivatives also reflect behavior outside the set of standardized labels, making a model appear nonlinear even when every prediction it makes agrees with a fixed-weight map. We propose two certificates that depend only on predictions at standardized labels and can reject two distinct explanations: fixed-weight prediction and sums of independent nonlinear label transformations. Across the five public TFMs that we evaluate, our certificates show that changing one context label alters how other labels influence the prediction, a behavior we call joint processing. We further find that joint processing emerges with training and that attention scores carry most of the measured interaction. Together, these findings motivate TFM explanations that account for how context labels change the influence of individual examples.

# 《标准化陷阱：认证表格基础模型中的联合标签处理》论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：线性回归与核平滑为上下文学习（in-context learning）提供了可解释的固定权重框架：特征决定每个上下文标签的权重，标签只提供被组合的数值。改变标签会改变预测，但权重不变。
- **核心问题**：这种固定权重解释是否适用于预训练的表格基础模型（TFM）？即：TFM 中一个上下文标签是否只贡献自己的值，还是也会改变其他标签被赋予的权重？
- **关键障碍——标准化陷阱（Standardization Trap）**：
  - 公开 TFM 包在模型看到标签前会先标准化标签，使进入网络的标签被限制在“标准化流形” M 上（均值为 0、平方范数固定为 r²）。
  - 普通导数（如 Hessian）不仅描述流形上的行为，还反映流形外的行为。可以构造一个函数，在 M 上与固定权重映射完全一致（预测完全相同），但其 Hessian 非零（如加入 ∝(∥ỹ∥²−r²) 的项）。
  - 因此直接用二阶导数检验会把固定权重模型误判为非线性，这就是“标准化陷阱”。
- **整体含义**：需要仅依赖标准化标签上预测的检验方法，才能可靠区分三种标签处理方式：
  1. **固定权重预测**：权重不依赖标签；
  2. **独立非线性标签变换之和**：每个标签只改变自身影响；
  3. **联合处理（joint processing）**：一个标签改变其他标签的影响。

## 2. 方法论

### 2.1 核心思想

- 只使用网络在标准化流形 M 上的预测值来构造统计量，去除流形外行为带来的假象。
- 通过切线投影和两次“去除”操作，分别得到两个证书：
  - **A_T**：排除固定权重预测；
  - **X_sep**：排除“独立非线性标签变换之和”，从而认证联合处理。

### 2.2 关键技术细节与公式流程

1. **设定与标准化**：
   - 上下文特征 X、标签 y，查询 x*，预测 ŷ = f(x*, X, y)。
   - 网络内部接收标准化标签 ỹ_i = (y_i − ȳ)/s_y，内部预测 ŷ_int = g(ỹ)。
   - 标准化流形：M = {ỹ ∈ ℝⁿ : 1ᵀỹ = 0, ∥ỹ∥² = r²}。

2. **切线投影**：
   - 切线方向需保持均值和范数（一阶），投影矩阵：
     P_T = I − 11ᵀ/n − ỹỹᵀ/r²。
   - 切线曲率：P_T H P_T，其中 H = ∇²_ỹ g(ỹ)。

3. **第一证书 A_T（排除固定权重）**：
   - 引理 1：任何在 M 上与仿射函数一致的函数，其切线曲率必为各向同性形式 λ(ỹ)P_T。
   - 定义去除各向同性部分后的张量：
     T = P_T H P_T − [tr(P_T H P_T)/(n−2)] P_T，
     A_T = ∥T∥_F。
   - 固定权重映射（在 M 上仿射）必有 A_T = 0；A_T ≠ 0 排除固定权重。

4. **第二证书 X_sep（认证联合处理）**：
   - 引理 2：若 g 在 M 上与“仿射 + 逐标签可分离变换” b + aᵀỹ + Σ_k φ_k(ỹ_k) 一致，则 T 属于空间
     S = {P_T D P_T − [tr(P_T D P_T)/(n−2)] P_T : D 为对角矩阵}。
   - 定义 X_sep = ∥T − P_S T∥_F，其中 P_S 是到 S 的正交投影。
   - X_sep = 0 对固定权重和可分离变换均成立；X_sep ≠ 0 认证联合处理。
   - 投影系数通过 Gram 矩阵 G 和 Moore–Penrose 伪逆求解：Gc = β，P_S T = Σ_k c_k B_k。

5. **归一化份额**：
   - Ā_T = A_T² / ∥P_T H P_T∥_F²，X̄_sep = X_sep² / A_T²，均在 [0,1] 内。

6. **一阶修正检验（附录）**：
   - 原始排列统计量 Δ_perm 也会陷入标准化陷阱。
   - 修正后的交集投影位移 Δ⊥_perm 和最小二乘残差 LS 对 M 上仿射的映射为零。

## 6. 主要结论与发现

1. **所有五个 TFM 均显示联合处理**：
   - Ā_T 在全部 20 个 setting 中非零，平均 98.5%，排除固定权重；
   - X̄_sep 平均约 63%，范围 23%–92%，排除“独立非线性标签变换之和”；
   - 即改变一个上下文标签会改变其他标签的影响力。

2. **联合处理随训练出现**：
   - 随机初始化副本也有非线性（Ā_T 非零），但 X̄_sep 最多 3.4%，训练模型每个查询至少 29.5%；
   - 匹配注意力熵的控制也无法弥补差距。

3. **注意力分数承载大部分交互**：
   - 阻断导数通过注意力分数（前向值不变）后：
     - X_sep 平均下降 85%（TabDPT 75% 至 TabPFN-V2.6 95%）；
     - A_T 平均下降 81%；
     - 完整曲率算子中由被阻断路径贡献的部分达 0.93–1.00。

4. **固定权重仍是有效近似**：
   - 在任务保持的标签分布下，固定权重代理的中位 held-out R² 为 0.72；
   - 但精确检验上所有模型均拒绝固定权重。

5. **默认预测也非仿射**：
   - 完整预测（多 estimator 组合）在固定矩路径上的四阶差分远超校准下限。

6. **受控模型补充**：
   - LayerNorm 不是交互的必要条件；
   - 存在不使用标签依赖注意力分数、仍能有效处理非线性标签的替代架构（score-blocked 模型）。

## 7. 优点

- **理论严谨性**：清晰识别并形式化“标准化陷阱”，证明固定权重映射可产生非零 Hessian，避免错误结论。
- **证书的可证伪性**：两个统计量分别对应两个可拒绝的零假设，且仅依赖流形 M 上的预测，具有扩展不变性。
- **校准充分**：在已知行为的构造映射上验证统计量，数值上确认浮点误差范围内的零值。
- **多角度证据链**：从精确 Hessian、一阶统计量、探针估计、前向二阶差分到随机副本和注意力干预，交叉验证结论。
- **机制定位**：通过 stop-gradient 干预将交互定位到注意力分数路径，为后续机理解释提供方向。
- **诚实的局限性讨论**：明确指出证书单侧、无法区分具体机制、未证明交互提升精度等。

## 8. 不足与局限

- **证书是单侧的**：A_T = 0 或 X_sep = 0 不能证明模型属于对应类别，只能拒绝。
- **无法区分具体机制**：联合处理可能来自任务推断、局部重加权或表示依赖，证书不能区分。
- **未证明交互提升预测精度**：导数检验只证明存在，不证明必要性；注意力阻断不改变前向预测。
- **注意力干预的局限**：只阻断导数路径，前向计算不变；不能验证“冻结注意力分数”的前向干预模型。
- **预训练重叠风险**：TabDPT 的预训练数据列表未公开，无法排除数据集重叠对结果的影响。
- **规模与覆盖有限**：主实验 4 个数据集、n = 256；上下文规模趋势仅少量模型和数据集；受控模型规模小。
- **算力未报告**：无法评估计算成本与可复现性。
- **固定权重代理的协议敏感性**：TabDPT 的排列拟合 R² 在不同协议下差异巨大，说明近似质量依赖标签分布假设。
