## 摘要
使用上下文学习的表格基础模型最近在预测性表格任务上超越了梯度提升树。然而，近期的机制性研究见解表明，这些模型中的参数在很大程度上是冗余的。我们提出 LoopICL，一种循环式 Transformer，其核心设计将参数数量与计算深度解耦。LoopICL 仅由一个块组成，通过两个耦合流处理数据：一个单元流捕获每个单元的特征表示，一个行流捕获上下文样本表示，二者通过列内注意力和跨列注意力联合细化。在预训练期间，我们改变循环次数，使该块在测试时能够展开为不同迭代次数，并使用学习到的退出门自动退出。在其标准设置下，LoopICL 在相同计算成本（FLOPs）下，在 TabArena 和 TALENT 上与 TabICLv2 表现相当，同时使用的参数减少近 90%。此外，其循环设计使用户还能在推理成本与性能之间进行权衡，提供了一种资源感知的 TFM。

## Abstract
Tabular foundation models using in-context learning have recently surpassed gradient-boosted trees on predictive tabular tasks. However, recent mechanistic insights suggest that parameters in these models are largely redundant. We introduce LoopICL, a looped transformer whose core design decouples parameter count from computational depth. LoopICL consists of a single block, processing data through two coupled streams: a cell stream capturing per-cell feature representations and a row stream capturing in-context example representations, jointly refined through within-column and cross-column attention. During pre-training, we vary loop counts, allowing the block to be unrolled for a varying number of iterations at test-time and use a learned exit-gate to automatically exit. In its standard setting, LoopICL performs competitively with TabICLv2 on TabArena and TALENT at the same computational cost (FLOPs), while using nearly 90% fewer parameters. Furthermore, its recurrent design enables users to also trade off inference cost and performance, providing a resource-aware TFM.

- **整体含义**：论文提出 LoopICL，用单个共享 Transformer 块反复循环，挑战“扩大参数”趋势，转向“扩大循环预算”。其目标是在相同 FLOPs 下，以近 90% 更少参数达到与大型固定深度 TFM 竞争的性能，并提供推理成本与性能可调的资源感知模型。

## 2. 方法论

### 2.1 核心思想

- LoopICL 由一个共享 Transformer 块组成，在预训练时变化循环次数 \(L\)，测试时可展开为不同迭代次数。
- 模型通过两个耦合流处理数据：
  - **Cell stream**：\(R \times C \times E\)，捕获每个单元格的特征表示，\(E=128\)。
  - **Row stream**：\(R \times D\)，捕获每个上下文样本的表示，\(D=4E=512\)。
- 每一轮循环中，cell stream 先建模局部特征交互，再读出到 row stream；row stream 通过 ICL 注意力精炼，更新后的 cell stream 保留到下一轮。

### 2.2 输入编码与分布条件

- 原始特征按列标准化，缺失值用列均值填充。
- 使用 cyclic feature grouping，每个特征与其 \(G-1\) 个循环移位邻居拼接，\(G=3\)，投影为 \(E\) 维 cell embedding。
- 类别标签通过正交初始化嵌入矩阵注入，并在每个循环步骤重新注入。
- **分布编码**引入三种信号：
  - 边际直方图：32 bins 自适应分位软对数直方图 + 4 个分布矩。
  - 判别直方图：分类任务中每类对数直方图残差（类减边际）。
  - Fourier 分位编码：每个单元格在列内的经验秩，8 个频率，并带 OOD 标志。
- 所有条件 MLP 输出层零初始化，使其初始不激活，随后逐渐学习依赖程度。

### 2.3 循环块

- 每轮应用一个共享 axial block，权重在所有 \(L\) 轮中绑定。
- 对 cell stream：
  1. 标签重注入。
  2. **列内注意力**：ISAB，每列独立处理行，\(K=128\) 个诱导点，8 头，头维 16。
  3. **跨列注意力**：每行内对列做带 RoPE 的自注意力，8 头，头维 16；再用 4 个 CLS token 读出到 row stream。
- row stream 更新：
  - 零初始化标签注入。
  - 因果掩码 ICL 注意力，8 头，头维 64，测试行可关注训练行。
- 所有子块使用 sandwich normalization（pre/post RMSNorm）。
- 注意力中加入 query-conditioned softmax scaling，含 \(n_{\text{ref}}=512\)，防止长序列输出增长导致不稳定。

### 2.4 残差缩放

- 每轮更新：  
  \[
  x \leftarrow x + \alpha(\tilde{x} - x)
  \]
- \(\alpha \in (0,1]\) 控制更新幅度。
- 研究三种方案：
  - \(\alpha=1\)：无缩放。
  - \(\alpha=1/\sqrt{L}\)：较温和深度归一化。
  - \(\alpha=1/L\)：线性深度归一化，鼓励在预算内均匀分配计算。
- \(\alpha=1/L\) 可使模型在超过预训练循环数时仍稳定外推，并实现预算感知计算。

### 2.5 解码器与早退

- 解码器为 attention-based retrieval decoder，具有目标排列等变性。
- 测试行表示作为 query，训练行表示作为 key，按 one-hot 标签加权累积每类注意力质量，多头平均后得到类别概率。
- **Early-exit gate**：
  - 轻量 MLP，少于 20K 参数。
  - 输入 43 维特征：压缩状态、状态变化、循环深度正弦编码、最近三次门输出、数据集大小正弦编码。
  - 输出退出概率 \(\lambda_t\)。
  - 累积退出概率 \(F_t = 1-\prod_{s=1}^t(1-\lambda_s)\)，当 \(F_t > q\) 时停止，默认 \(q=0.5\)。
  - 门只用训练集表示，不使用测试集信息。
- 测试时使用 \(N=8\) 个集成成员，每个成员使用不同特征顺序、类别排列、预处理，并独立早退。

### 2.6 预训练流程

- **Stage 1**：500K 步，batch size 64，合成数据 2–100 特征、最多 10 类、最多 1024 行，训练/测试划分比例均匀采样于 \([0.3,0.9]\)，全量 BPTT。优化器 Muon，lr \(8\times10^{-4}\)，momentum 0.9，warmup 5000，cosine decay，梯度裁剪 1.0，权重衰减 0.01。
- **Stage 2**：30K 步长上下文继续预训练，1–2000 特征、最多 100,000 行，特征×行预算 \(10^6\)。使用 TBPTT，窗口 \(k=5\)，只反传最后 5 轮。lr \(10^{-4}\)。
- **Stage 3**：4K 步训练早退门，冻结 backbone，最大 16 轮，是预训练上限的两倍。
- 循环次数 \(L\) 从 log-normal Poisson 分布采样，\(\gamma \sim \text{LogNormal}(\mu,0.5^2)\)，\(L \sim 1+\text{Poisson}(\gamma)\)，裁剪到 \([1,8]\)，预训练平均约 5.32 轮。
