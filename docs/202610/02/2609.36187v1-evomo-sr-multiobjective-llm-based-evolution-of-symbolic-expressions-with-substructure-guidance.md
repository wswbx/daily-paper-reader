## 摘要
符号回归（SR）是一种数据驱动的科学发现方法，用于在数据中搜索可解释的解析关系。近年来，大语言模型（LLM）也对科学发现产生了重大影响，使该过程各个阶段的自动化成为可能。基于这些原因，利用LLM内嵌的科学知识和编程能力来解决SR任务的可能性已经出现，与传统方法相比展现出有前景的性能。我们提出EvoMO-SR，一种新颖的LLM驱动的SR框架，其中LLM生成方程骨架，其系数由外部优化器单独拟合。该框架包括多目标生存选择，通过平衡准确性和复杂度来控制膨胀，以及子结构引导机制，利用候选可复用构建块对表达式进行变异。在LSR-Synth的八个域内和域外设置中的七个上，EvoMO-SR使用小型LLM模型，即Llama-3.1-8B-Instruct，取得了最佳准确性。我们还通过两个基于规范化子树重叠和项匹配的符号准确性指标评估了结构恢复，表明我们的方法具有更大的概率恢复出高精度的符号结构。

## Abstract
Symbolic Regression (SR) is a data-driven method for scientific discovery which searches for interpretable analytical relationships within data. Recently, Large Language Models (LLMs) have also had a significant impact on scientific discovery, enabling the automation of various stages of the process. For these reasons, the possibility of harnessing the embedded scientific knowledge and programming capabilities of LLMs to solve SR tasks has emerged, showing promising performance compared with traditional methods. We propose EvoMO-SR, a novel LLM-driven SR framework in which the LLM generates equation skeletons, with their coefficients fitted separately by an external optimizer. The framework includes a multi-objective survival selection which controls bloating by balancing accuracy and complexity, and a substructure guidance mechanism which mutates expressions with candidate reusable building blocks. EvoMO-SR achieves the best accuracy in seven of the eight in-domain and out-of-domain settings for LSR-Synth, using a small LLM model, i.e., Llama-3.1-8B-Instruct. We also evaluated structural recovery through two symbolic accuracy metrics based on canonicalized subtree overlap and term matching, showing that our method has a greater probability of recovering highly accurate symbolic structures.

## 1. 核心问题与整体含义（研究动机与背景）

- **符号回归（Symbolic Regression, SR）** 旨在从数据中自动发现可解释的解析关系（方程），相比黑箱模型具有更强的可解释性，是数据驱动科学发现的重要工具。
- 传统 SR 主要依赖**遗传编程（GP）**（如 PySR、GPGomea、Operon）和**深度学习方法**（如 DSR、uDSR），但长期面临三大痛点：搜索效率低、**表达式膨胀（bloating）**、以及结构恢复困难。
- 近年来 **LLM** 因其内嵌的科学知识与编程能力，被引入 SR 任务。代表性工作 LLM-SR 让 LLM 生成方程骨架、外部优化器拟合系数；LaSR 则用 LLM 生成自然语言概念来增强 GP 搜索。
- 但已有 LLM 方法存在不足：
  - LLM-SR 缺少**显式的种群进化与父子生存选择**，仅靠经验缓冲区采样；
  - LaSR 的知识以**自然语言概念**形式存储，而非显式数学构件；
  - 多数方法对**表达式膨胀**缺乏系统性的多目标控制。
- **EvoMO-SR 的核心动机**：将 LLM 嵌入显式的、基于种群的多目标进化循环中，同时引入**可复用子结构档案**来引导变异，从而在保持小模型（Llama-3.1-8B-Instruct）条件下实现更高精度与更好结构恢复。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
- LLM 负责生成**方程骨架**（Python 代码形式的符号表达式），系数由外部优化器 **L-BFGS-B** 单独拟合；
- 整个搜索在**显式进化循环**中进行，结合**多目标生存选择**与**子结构引导变异**。

### 2.2 关键组件与流程

**(1) 问题形式化**
- 给定数据集 \(D=\{(x_i,y_i)\}_{i=1}^n\)，学习符号结构 \(\phi(\cdot;\hat\Theta)\) 与参数 \(\hat\Theta\)，使 \(\hat f(x)=\phi(x;\hat\Theta)\approx y\)。
- LLM 生成候选骨架集合 \(\Phi=\{\phi_j\}_{j=1}^M\)，参数由优化器独立估计。

**(2) 初始化**
- 初始提示 \(P_{init}=\{role+task,\ context,\ format\}\) 拼接而成；
- 上下文包含变量的物理含义等数据集特定信息；
- LLM 输出除方程外还包括**文字解释**（说明为何提出该结构、增删改了哪些项），用于增强后续提示并提升可解释性。

**(3) 进化循环**
- 父代选择：默认 **random with replacement**（也可用锦标赛、轮盘赌）；
- 变异：每次随机从预定义变异提示中选择一个：
  - “Refine the current expression while preserving useful terms.”
  - “Propose a new expression completely different from the current one.”
- 循环提示 \(P_{loop}=P_{init}\cup\{I_j,\ mutation\}\)，其中 \(I_j\) 为被选个体的方程、描述与适应度。

**(4) 多目标生存选择**
- 目标为两个相互冲突的指标：
  - **精度**：NMSE \(=\frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}\)；
  - **复杂度**：Python AST 节点数。
- 使用 **非支配排序 + 拥挤距离（NSGA-II 风格）** 构建新种群，逐前沿选取直至填满；
- **精英保留（elitism=True）**：父代与子代共同参与生存选择；
- 维护 **Pareto 档案**记录全程最优权衡解。

**(5) 子结构引导机制**
- 每代结束后，扫描子代个体，提取其相对于父代**新增的可加子树（substructure）**；
- 子结构需满足：非平凡（非常数/单变量）、复杂度受控、经 SymPy 规范化去重；
- 维护容量为 10 的**动态定长档案**，新子结构若优于当前最差者则替换（依据其所属个体的 NMSE）；
- 以概率 \(p_{sub}=0.5\) 在变异提示中随机注入一个档案子结构，指示 LLM 在变异中使用它。

**(6) 符号准确率指标**
- **SA_AST**：规范化（运算符统一、交换律排序、常数占位符化）后 AST 子树签名的 Jaccard 相似度；
- **SA_Term**：规范化后可加项签名的 Jaccard 相似度，剔除变量无关的乘法系数；
- SA_Term 对多余项惩罚更轻，更关注是否恢复正确子结构。

## 3. 实验设计：数据集、Benchmark 与对比方法

### 3.1 数据集

## 6. 主要结论与发现

- **数值精度**：在 LSR-Synth 的 8 个域/划分比较中，EvoMO-SR 在 **7 个取得最低聚合 NMSE**（包括全部 4 个 OOD 设置），仅 Physics ID 略逊于 LLM-SR。
- 相对 LLM-SR，OOD NMSE 降低倍数约为：**物理 14×、化学 53×、生物 37×、材料科学 2.4×10³**。
- **统计显著性**：化学、生物、材料科学的 ID/OOD 均显著（p<0.05）；物理 OOD 显著；物理 ID 不显著（p=0.885）。总体 129 题中，EvoMO-SR 在 ID 赢 95 题、OOD 赢 107 题。
- **符号准确率**：
  - 所有方法的 SA 值整体偏低；
  - SA_AST 上 GPGomea 在部分域最强，EvoMO-SR 在右尾（τ≈0.35 以上）占优；
  - SA_Term 上 EvoMO-SR 在 τ≥0.3 后最强，说明其更可能**恢复高相似度的符号结构**。
- **随机函数数据集**：EvoMO-SR 在 P1–P4 上 NMSE ID/OOD 全面优于 LLM-SR；P1 达到 SA_Term=1.0。
- **消融结论**：
  - 多目标选择显著降低表达式复杂度；
  - 子结构引导对**更大模型**（GPT-5.4-nano、DeepSeek-v4-Flash）增益更明显；
  - LLM 变异明显优于 GP 变异或混合变异；
  - 子结构引导的单独效果不一致，与多目标选择存在**交互作用**。
- **行为差异**：LLM-SR 有时会“走捷径”使用 `gradient` 等非传统算子拟合加速度，而 EvoMO-SR 未出现此类行为。

## 7. 优点（方法与实验设计亮点）

- **架构清晰**：将 LLM 明确嵌入显式种群进化循环，与 LLM-SR 的“经验缓冲区采样”形成互补思路；
- **多目标生存选择**：显式平衡精度与复杂度，有效抑制 bloating，提升可解释性；
- **子结构档案机制**：将进化中产生的可复用数学构件显式归档并注入变异提示，是较新颖的知识复用方式；
- **双符号准确率指标**：SA_AST 与 SA_Term 互补，兼顾严格性与宽容度，避免了单一指标的片面性；
- **小模型大效果**：仅用 Llama-3.1-8B-Instruct 即超越多个基线，说明方法本身设计有效而非依赖大模型；
- **实验严谨**：统一骨干、统一优化器、多次运行取均值、Wilcoxon+Holm 校正、全面消融；
- **附带可解释性**：LLM 输出的文字描述被保留并用于后续提示，便于追踪决策过程。

## 8. 不足与局限

- **符号准确率整体偏低**：即使 EvoMO-SR 在部分场景更优，SA_AST/SA_Term 的绝对值仍较低，距离真正恢复真实方程仍有较大差距；
- **子结构贡献难以归因**：档案中的子结构与“所属个体的整体表现”绑定，无法隔离单个子结构的独立贡献；
- **算力信息缺失**：未报告 GPU 型号/数量，仅以运行时间与 token 数间接反映成本，且 API 调用成本较高（1,000 次/run）；
- **部分场景未达显著**：Physics ID 与 oscillator 的 NMSE 对比未达统计显著；
- **提示工程依赖**：方法对提示设计较敏感，论文未系统评估提示变体的影响；
- **OOD 与真实数据覆盖有限**：OOD 主要通过时间/温度外推或单维度外推构造，与真实科学外推场景仍有差距；
- **可复现性**：代码以匿名仓库形式提供，但 LLM API 版本与随机性可能影响复现；
