## 摘要
表格基础模型（TFMs）日益流行，因为它们无需任务特定训练或大量调参，就能通过上下文学习在新数据集上给出强预测。然而，已发布的 TFMs 在预训练先验、架构和目标上同时存在差异，掩盖了各自的归纳偏置。因此，我们考察一个具体能力：无关特征抑制。在合成任务和真实数据集上，加入空特征会使行令牌模型 TabDPT 的预测性能下降显著更大，而单元格令牌交替轴模型 TabPFN v2 及其他 TFMs 则相对稳定。这一差距促使我们追问：架构是否有助于无关特征抑制？由于已发布的 TFMs 仍受其他设计选择的混杂影响，我们在相同的稀疏到稠密线性先验下训练精简的行令牌和交替轴 Transformer。精确贝叶斯分析表明，稀疏预测需要上下文相关的特征门控，而稠密端点只需要均匀特征加权。与这一区分一致，交替轴模型在稀疏任务上显著更接近贝叶斯最优预测器，而在稠密任务上架构差距变得可忽略；几乎所有的稀疏差距都来自线性系数估计误差。最后，在受控模型和冻结的 TabPFN v2 中，我们考察了对特征注意力输出进行干预对线性系数的影响，发现了任务依赖的、通过特征索引路径对计算进行选择性路由的证据。总之，这些结果支持架构-先验对齐：保留可寻址的特征轴为任务自适应的相关性推断提供了归纳偏置。代码见 https://github.com/Tianqi-Zhao/ArchitecturePriorTFMs。

## Abstract
Tabular foundation models (TFMs) are increasingly popular because they deliver strong predictions on new datasets through in-context learning, without task-specific training or extensive tuning. Yet released TFMs differ simultaneously in their pretraining priors, architectures, and objectives, obscuring their respective inductive biases. We therefore examine one concrete capability: irrelevant-feature suppression. Across synthetic tasks and real-world datasets, adding null features causes substantially greater predictive degradation in the row-token model TabDPT, whereas the cell-token alternating-axis model TabPFN v2 and other TFMs remain comparatively stable. This gap motivates us to ask whether architecture contributes to irrelevant-feature suppression. Because released TFMs remain confounded by other design choices, we train streamlined row-token and alternating-axis transformers under identical sparse-to-dense linear priors. Exact Bayes analysis shows that sparse prediction requires context-dependent feature gating, whereas the dense endpoint requires only uniform feature weighting. Consistent with this distinction, the alternating-axis model is substantially closer to the Bayesian optimal predictor on sparse tasks, while the architecture gap becomes negligible on dense tasks; almost all of the sparse gap arises from linear coefficient-estimation error. Finally, in both the controlled model and frozen TabPFN v2, we examine the effect of interventions on the feature-attention outputs on the linear coefficients, finding evidence of task-dependent selective routing of computation through feature-indexed pathways. Together, these results support architecture-prior alignment: preserving an addressable feature axis provides an inductive bias for task-adaptive relevance inference. Code is available at https://github.com/Tianqi-Zhao/ArchitecturePriorTFMs.

# 论文总结：表格基础模型中的架构与稀疏先验对齐

## 1. 核心问题与整体含义

- **研究背景**：表格基础模型（Tabular Foundation Models, TFMs）通过上下文学习（in-context learning）在新数据集上无需任务特定训练即可给出强预测，近年来发展迅速。然而，已发布 TFM 在**预训练先验、架构和目标**上同时变化，导致性能差异无法归因于单一设计选择，架构的归纳偏置被混淆。
- **核心问题**：论文聚焦一个具体能力——**无关特征抑制（irrelevant-feature suppression）**，追问：在匹配的任务先验下，架构本身是否影响这一能力？
- **关键观察**：在合成 Friedman 任务与 42 个 OpenML 回归数据集上，注入空特征（null features）后，行令牌模型 **TabDPT** 的预测性能退化远大于单元格令牌交替轴模型 **TabPFN v2** 及其他 TFM（TabICL v2、TabPFN v3、v2.5）。例如在 ρ=7 时，TabDPT 在 Friedman 与 OpenML 上的中位 R² 下降分别为 0.0370 与 0.0713，而 TabPFN v2 仅为 0.0008 与 0.0014，差距超过 46 倍与 50 倍。
- **整体含义**：论文主张**架构-先验对齐（architecture–prior alignment）**，而非对表格架构做普适排名——保留可寻址的特征轴为任务自适应的相关性推断提供归纳偏置，但当最优规则对所有坐标均匀加权时，这一优势几乎消失。

## 2. 方法论

### 2.1 核心思想
- 构造**匹配的稀疏到稠密线性先验族**，使贝叶斯最优预测器有闭式解，从而在受控条件下比较两种架构（行令牌 vs. 交替轴）对稀疏/稠密先验的逼近能力。

### 2.2 关键技术细节

- **匹配先验族**：固定设计回归 y = Xβ + ε，ε ~ N(0, σ²Iₙ)，XᵀX = nI_d。对 k ∈ [d]，先验 P_k 从所有大小为 k 的支持集 S_k 中均匀抽取支持 S，β_S | S ~ N(0, (v²/k)I_k)，β_{S^c} = 0。该缩放使 E[ββᵀ] = (v²/d)I_d 对所有 k 不变，仅改变支持结构而非信号能量。
- **后验预测均值**：充分统计量 c = Xᵀy/n，贝叶斯系数映射为
  **η*_k(c) = E[β|D] = λ_k q_k(c) ⊙ c**
  其中 q_{k,j}(c) = P(j ∈ S | c) 为后验包含概率，λ_k = nv²/(nv² + kσ²) 为收缩因子。
- **稠密 vs. 稀疏的计算差异**：
  - 稠密端点（k = d）：q_d(c) = 1_d，η*_d(c) = λ_d c，即**均匀收缩**，可等价实现为线性核回归 (λ_d/n)Σᵢ⟨x,xᵢ⟩yᵢ。
  - 稀疏情形（k < d）：后验包含概率 q_k(c) 对 c 非线性（指数归一化），需要**上下文相关的特征门控**。
- **定理 1（响应仿射壁垒）**：任何形如 f(D,x) = a(X,x) + b(X,x)ᵀy 的响应仿射预测器，其唯一最小二乘最优解为 λ_d xᵀc，等于稠密贝叶斯解；但在每个 k < d 的稀疏先验下，该仿射类与 f*_k 之间存在严格正的下确界逼近误差。线性核回归是理想化单层行令牌注意力的对应实现，故该壁垒暗示行令牌架构在稀疏任务上的局限。
- **交替轴可实现性（命题 3）**：理想化交替轴网络可用三层注意力（特征–观测–特征）与 O(k) 个残差通道逼近任意 k 的稀疏贝叶斯预测器。k=1 时，直接构造为：特征轴注意力以 logits ∝ c²_j、values = λ₁c_j x_j 做 softmax 加权；一般 k 通过 Newton 恒等式从 O(k) 个池化幂和中恢复初等对称多项式，再经最终逐点映射输出。
- **预测误差分解（引理 2）**：将预测误差分解为**系数误差**、**截距误差**与**非线性残差**三部分，用于定位架构差距来源。
- **特征消息干预**：在特征注意力输出处对源特征 j 的消息乘以 (1−δ)（δ=0.1），分别作用于上下文行或查询行，重跑下游网络并重新拟合线性系数，测量**系数响应 Ĵ^(ℓ)_{rj}**、**特异性 P^(ℓ)_j**（自身系数响应占比）与**敏感度 w^(ℓ)_j**（单位衰减下自身系数响应/|c_j|）。

## 3. 实验设计

### 3.1 数据集与场景
- **合成数据**：7 种 Friedman 配置（样本量 N ∈ {250, 500, 1000, 2000}，噪声 σ ∈ {0.5, 1, 2, 4}），共 350 个任务设置，5 个相关特征。
- **真实数据**：42 个 OpenML 回归数据集（如 Grid Stability、California Housing、Superconductivity 等），最大 1000 行，约 80/20 上下文/查询划分。
- **空特征构造**：合成任务追加 i.i.d. 均匀空列；真实数据追加整行置换的原始列副本，空特征比例 ρ ∈ {0, 0.2, 0.4, 1, 2, 4, 7}，采用嵌套前缀保证配对可比。每个任务做 5 次独立构造重复。

### 3.2 Benchmark 与对比方法
- **生产模型对比**：TabDPT v1.2（禁用检索）、TabPFN v2、TabPFN v2.5、TabICL v2、TabPFN v3；另复现 TabDPT v1.0–v1.3 四个版本。
- **受控实验**：在相同先验 P_k 下训练精简行令牌模型（5 层，约 39.4 万参数）与交替轴模型（3 层，约 35.6 万参数），d ∈ {10, 20}，k ∈ {1, d/2, d}，各 32,000 个测试任务，3 个训练种子。
- **评估指标**：R² 下降、归一化空特征偏移（置换单个查询特征）、归一化 PDP 变化、任务归一化贝叶斯逼近误差、系数/截距/残差分解误差。

## 6. 主要结论与发现

1. **已发布 TFM 对空特征的鲁棒性差异显著**：TabDPT 对空特征的预测退化与功能依赖均远大于 TabPFN v2，且该现象在 TabDPT v1.0–v1.3 各版本中持续存在（v1.3 有所缓解但仍远超 TabPFN v2）。
2. **架构在匹配先验下确有贡献**：稀疏任务中交替轴模型显著更接近贝叶斯最优，d=10、k=1 时误差差距约 0.34，d=20 时约 0.627；稠密端点差距近乎消失。
3. **稀疏差距主要来自系数估计误差**：在 d=10、k=1 和 k=5 时，系数误差差异分别解释 98.4% 与 97.5% 的预测误差差距；d=20 时分别为 99.7% 与 98.0%。
4. **特征注意力支持选择性计算路由**：衰减活跃特征消息主要改变其自身系数（高特异性），且该效应具有任务依赖性（活跃源特异性高于非活跃源）与层间异质性（末层查询消息敏感度最高，分别达上下文中位数的 15.5 倍与 8.9 倍）。
5. **该机制在冻结 TabPFN v2 中同样存在**：说明选择性路由并非受控模型的训练伪影。
6. **总体结论**：支持架构-先验对齐，而非架构普适优劣；可寻址特征轴为稀疏任务自适应提供归纳偏置。

## 7. 优点

- **实验设计精巧**：通过匹配先验族将架构从预训练先验中干净地隔离出来，并利用闭式贝叶斯目标提供精确参照，是 TFM 架构研究的方法论贡献。
- **理论分析严谨**：响应仿射壁垒定理严格刻画了行令牌类架构在稀疏先验下的表达局限，交替轴构造性证明给出可实现性上界。
- **误差分解清晰**：将预测误差分解为系数、截距、非线性三部分，精准定位架构差距来源，避免笼统的端到端比较。
- **干预诊断优于注意力权重解读**：通过消息衰减 + 系数响应 + 特异性/敏感度指标，避免"注意力即解释"的常见陷阱，并明确区分功能依赖与内部机制。
- **结论表述克制**：反复强调架构-先验对齐的条件性结论，而非宣称某一架构普遍更优，并诚实讨论 tokenization 等识别限制。

## 8. 不足与局限

- **理论假设较强**：精确贝叶斯分析假设高斯查询、正交上下文列、已知支持大小 k、线性响应；相关性特征、支持大小不确定性与非线性近似均未覆盖。
- **生产模型对比为观察性**：已发布 TFM 在预训练数据、预处理、规模、特征上限与集成方式上均不同，无法将差异严格归因于架构。
- **受控对比仍有固有差异**：深度、token 数量与计算成本无法完全匹配，架构优势可能部分来自这些因素而非纯粹的轴结构。
- **机制定位不完整**：干预实验只能说明特征消息对系数有特征对齐的因果影响，**无法确定相关性在何处被推断**，也无法证明非活跃源影响降低就是注意力内部的抑制。
- **Tokenization 限制**：TabPFN v2 每个源 token 含两个原始特征，只能做组级归因，无法延伸到原始特征级；结论基于单一 estimator 配置，未扩展到完整生产集成。
- **泛化性有限**：未验证模型容量、训练算力、特征顺序、检查点选择等优化层面因素对架构优势的影响；相关性特征下对角度量不再完备。
- **算力报告不完整**：未披露 GPU 数量与训练总时长，可复现性受限。
- **代码与数据可得性**：论文声明代码已开源（GitHub），但 OpenML 数据集需自行获取，且生产实验的具体
