## 摘要
LLM智能体越来越多地检索外部精选的技能库——即在决策时检索的程序性指令——以提升在长周期交互任务中的表现。现有技能库通常被视为与模型无关，在不同容量和行为的骨干网络上重复使用相同的技能表述。然而，我们在多个模型规模上的受控实验表明，技能有效性强烈依赖于模型：一个对某个骨干网络有益的技能可能会损害另一个骨干网络。受此观察启发，我们提出了MASA（模型感知技能对齐）框架，该框架在不修改智能体权重的情况下，使技能适应每个目标骨干网络。MASA分两个阶段运行：(1) 一个分层技能进化流水线，利用爬山法和UCB驱动的树搜索，在环境反馈和模型能力轮廓的引导下，迭代地重写通用和任务特定技能；(2) 一个轻量级的、以模型为条件的技能重写器，在进化轨迹上训练，以单次前向传播复现该适应过程。在三个交互环境和四个骨干网络上的实验表明，MASA consistently实现了最佳总体性能，比最强基线高出高达25.8个点。学习到的重写器进一步泛化到未见过的任务和环境，无需额外搜索，以极低的推理成本持续超越更大的教师LLM。

## Abstract
LLM agents increasingly retrieve externally curated skills-procedural instructions retrieved at decision time-to improve performance on long-horizon interactive tasks. Existing skill libraries are typically treated as model-agnostic, reusing the same skill formulations across backbones with substantially different capacities and behaviors. However, our controlled experiments across multiple model scales show that skill effectiveness is strongly model-dependent: a skill that benefits one backbone can harm another. Motivated by this observation, we propose MASA Model-Aware Skill Alignment, a framework that adapts skills to each target backbone without modifying agent weights. MASA operates in two stages: (1) a hierarchical skill evolution pipeline that iteratively rewrites general and task-specific skills using hill climbing and UCB-driven tree search, guided by environment feedback and model capability profiles; and (2) a lightweight model-conditioned skill rewriter trained on evolution trajectories to reproduce the adaptation in a single forward pass. Experiments across three interactive environments and four backbones show that MASA consistently achieves the best overall performance, with gains of up to 25.8 points over the strongest baseline. The learned rewriter further generalizes to unseen tasks and environments without additional search, consistently outperforming a much larger teacher LLM at a fraction of the inference cost.

### 一、论文的核心问题与整体含义（研究动机和背景）

*   **核心问题**：当前为LLM Agent设计的技能库（Skill Library）通常是“模型无关”（model-agnostic）的，即为一个模型优化的技能库会被直接复用在其他模型上。论文通过实验证明，技能的有效性**高度依赖于目标模型的特性**（如参数量、架构、训练方式等）。一个对模型A有益的技能，可能对模型B有害。因此，研究的关键挑战是：**如何让技能库的表述形式与目标模型的能力和偏好对齐？**

*   **研究背景**：LLM Agent常通过从外部库中检索“技能”（一种程序化指令）来提升在长周期交互任务中的表现。现有工作通常构建一个共享技能库并在不同LLM骨干网络上复用。但实际部署中，由于硬件、成本等限制，系统需要适配各种规模的模型，这暴露了“一刀切”技能库的局限性。论文首次系统地揭示了技能与模型之间“对齐”的重要性。

### 二、论文提出的方法论：核心思想、关键技术细节与流程

*   **核心思想**：MASA (Model-Aware Skill Alignment) 框架的核心思想是将技能表述形式与目标模型的能力进行对齐，在不修改Agent权重的情况下，为每个模型“定制”其最优的技能库。它将技能对齐视为一个**受环境反馈驱动的分层搜索问题**，并通过**轻量级重写器**来实现高效的部署。

*   **关键技术细节与流程**：
    1.  **预备观察**：通过控制变量实验（仅改变技能粒度的文本表述），发现最优技能粒度因模型而异，且性能与粒度的关系是非单调的，不能通过简单的启发式规则确定。
    2.  **问题形式化**：
        *   目标是为每个目标模型 F 搜索其最优技能库 **S⋆F**，使得在评估任务集上的期望奖励最大化。
        *   奖励函数 R 平衡了任务完成率（SR）和技能引起的“空转率”（NHR），即 `R = SR - λ·NHR`。
    3.  **分层模型条件技能进化**：
        *   **阶段一：通用技能进化（爬山算法）**。用于优化跨任务策略的通用技能。每次迭代包含：**展开**（用当前技能评估模型）→ **分析**（教师LLM分析失败轨迹并生成结构化归因）→ **重写**（教师LLM根据模型卡和失败归因重写技能）→ **接受/拒绝**（仅当新技能集产生更高奖励时才接受）。
        *   **阶段二：任务特定技能进化（UCB树搜索）**。用于优化每个任务类型下的特定技能。为每个任务类型独立维护一个树，每个节点代表一个候选技能集。过程包括：**选择**（用UCB1公式选择最有潜力的叶节点）→ **扩展**（评估并产生新节点）→ **评估**（计算新节点的平均奖励）→ **反向传播**（更新路径上的访问计数和值估计）。
        *   **关键输入**：一个结构化的**模型卡**，包含架构、训练数据和能力强弱项，作为技能重写的条件信号。
        *   **教师模型**：使用更强的教师LLM（如DeepSeek-V4-Pro）来驱动重写过程。

    4.  **模型条件技能重写器**：
        *   **目标**：*摊销*上述搜索过程的高昂计算成本，实现单次前向传播即可完成技能适配。
        *   **训练**：使用一个轻量级模型（Qwen3-4B），通过监督微调（SFT）来学习从输入（模型卡+输入技能集+任务描述）到输出（进化后的最优技能集）的映射。
        *   **训练数据**：从进化过程产生的轨迹中采样，涵盖不同质量的输入技能（如搜索中间状态、跨模型转移、单次教师重写、增强变体），以提升重写器的鲁棒性。
        *   **推理**：在部署时，重写器无需与环境交互，一步生成适配的技能。

### 三、实验设计：数据集/场景、Benchmark与对比方法

*   **环境与数据集**：

    2.  **WebShop**：模拟在线购物的环境，需要根据用户要求进行商品搜索、比较和购买。
    3.  **搜索增强QA**：涉及信息检索和答案合成的任务，包括单跳（NQ, TriviaQA, PopQA）和多跳（HotpotQA, 2Wiki, MuSiQue, Bamboogle）基准。

*   **骨干模型（Backbone/Baselines）**：使用Qwen3系列的四个不同规模的模型作为目标Agent：**4B, 8B, 14B, 32B**。教师模型为**DeepSeek-V4-Pro**。

    3.  **DS-Adapter**：使用教师LLM（DeepSeek-V4）进行一次性的、针对模型的重写，不进行迭代搜索。

### 六、论文的主要结论与发现

1.  **技能效果是模型依赖的**：同一技能对不同模型的影响差异巨大，甚至可能产生反作用。这挑战了“一刀切”技能库的假设。
2.  **MASA方法有效**：提出的模型感知技能对齐框架MASA在三个环境、四种模型上全面超越了所有基线方法，最高提升达到25.8个百分点。
3.  **重写器展现强泛化能力**：轻量级的MASA重写器能够成功地泛化到未见过的任务和环境，在单次前向传播中就能产生有效的技能适配，甚至超越了更大、更昂贵的教师LLM，展示了极佳的实用性和成本效益。
4.  **技能对齐需考虑任务类型**：在同一模型内部，不同任务类型对相同技能的反应也不同，因此技能对齐需要在全局和任务级别共同进行。

### 七、优点：方法或实验设计上的亮点

### 八、不足与局限

1.  **实验范围有限**：主要结论基于Qwen3系列模型（和Gemma3的补充实验）。将方法扩展到更多模型家族（如Llama、GPT系列，特别是闭源模型）和更广泛的环境，是验证其通用性的必要步骤。
2.  **依赖自动奖励信号**：搜索阶段和重写器训练都严重依赖于环境提供的自动成功/失败信号（如任务完成标志）。对于缺乏此类内建奖励的开源任务或真实世界应用，需要设计外部评估器或依赖人工标注，这增加了应用难度。
3.  **潜在偏见和安全风险**：进化过程中使用的教师模型和轨迹可能继承或放大偏差、不安全或低效的策略。在部署前对进化后的技能库进行审查是必要的。
4.  **计算成本未完全透明**：虽然重写器本身很轻量，但进化搜索阶段的计算成本（GPU算力、时间）并未明确报告，这部分成本对于资源有限的团队可能较高。
