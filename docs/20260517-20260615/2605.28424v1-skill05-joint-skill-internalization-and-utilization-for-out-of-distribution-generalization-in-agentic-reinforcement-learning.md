## 摘要
将显式技能融入大语言模型已成为一种有前景的范式，使自主智能体能够解决复杂任务。智能体技能可内在分为用于广泛认知迁移的通用技能和用于动态执行的任务特定技能。然而，现有基于技能的强化学习方法通常强制在完全外化（导致高昂的上下文开销）与完全内化（存在过拟合和知识冲突风险）之间做出刻板选择。为解决这一困境，我们提出Skill0.5，一种新颖的智能体强化学习框架，通过结合通用技能内化与任务特定技能利用，明确区分技能处理方式。在动态的、难度感知路由器的驱动下，Skill0.5将任务分流到不同的精通层级以应用定制优化策略：它通过特权蒸馏内化通用技能，为困难任务构建认知基础，同时对简单任务使用诊断探测来惩罚捷径并强制特定技能利用。在ALFWorld和WebShop上的实验表明，Skill0.5优于基于记忆和基于技能的强化学习基线，在分布内和分布外场景中均带来性能提升。

## Abstract
Equipping large language models with explicit skills has emerged as a promising paradigm for enabling autonomous agents to solve complex tasks. Agent skills can be inherently divided into general skills for broad cognitive transfer and task-specific skills for dynamic execution. However, existing skill-based reinforcement learning (RL) methods typically force a rigid choice between full externalization, which incurs prohibitive context overhead, and full internalization, which risks overfitting and knowledge conflicts. To address this dilemma, we propose Skill0.5, a novel agentic RL framework that explicitly differentiates skill treatments by combining general skill internalization with task-specific skill utilization. Driven by a dynamic, difficulty-aware router, Skill0.5 streams tasks into distinct mastery tiers to apply tailored optimization strategies: it internalizes general skills via privileged distillation to build a cognitive foundation for hard tasks, while using diagnostic probing on easy tasks to penalize shortcuts and enforce specific skill utilization. Experiments on ALFWorld and WebShop demonstrate that Skill0.5 outperforms both memory-based and skill-based RL baselines, yielding performance improvements across both in-distribution and out-of-distribution scenarios.

- **研究背景**：大语言模型（LLM）作为自主智能体解决复杂任务时，显式技能（skill）成为一种重要范式。技能可分为通用技能（general skills，如元推理、错误恢复）和任务特定技能（task-specific skills，如细粒度执行规则）。
- **现有困境**：当前基于技能的强化学习方法面临两种极端选择：
  - **完全外化（full externalization）**：将全部技能放入prompt，导致上下文过长，影响ICL能力，尤其在长程任务中。
  - **完全内化（full internalization）**：将技能全部融入模型参数，但受模型容量限制，易出现过拟合和知识冲突，导致执行幻觉。
- **核心问题**：在真实部署中，技能库动态扩展，智能体常面对未见过的分布外（OOD）任务和技能。现有方法统一处理两类技能，无法兼顾上下文效率与泛化适应性。
- **整体含义**：需要区分对待通用技能（应内化为认知基础）和任务特定技能（应动态外化利用），以平衡开销与泛化能力。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 提出**Skill0.5**框架，联合优化通用技能内化与任务特定技能利用。
- 通过**难度感知路由器**根据实时掌握程度将任务分为三个层级（hard/medium/easy），每个层级应用不同的优化目标。

### 2.2 关键技术细节

#### 阶段一：难度感知路由（Phase-1）
- 对每个任务 \( x_i \)，使用标准prompt（仅含检索到的特定技能）采样G条轨迹，计算经验通过率 \( p_i \)。
- 定义动态阈值 \( \eta_t \) 为滑动窗口内平均通过率。
- 路由规则：
  - \( p_i = 0 \) → **Hard**
  - \( 0 < p_i \leq \eta_t \) → **Medium**
  - \( p_i > \eta_t \) → **Easy**

#### 阶段二：层级定制优化（Phase-2）
- **Hard任务**：通过**特权蒸馏内部化通用技能**。使用特权prompt（含通用技能+特定技能）让教师模型生成成功轨迹，然后通过token级Jensen-Shannon散度（JSD）让学生模型（仅有标准prompt）模仿教师，从而内化通用技能。
- **Medium任务**：应用**标准GRPO**，直接复用Phase-1轨迹，通过组内优势归一化（intra-group advantage）优化策略。
- **Easy任务**：采用**反捷径利用（Anti-Shortcut Utilization）**。引入无技能prompt（ablated specific skills）采样诊断轨迹，计算利用增益 \( u_i = p_i - p_i^{\text{none}} \)。然后构造任务级利用优势 \( A_{u_i} \)，与轨迹级优势叠加，抑制跳过特定技能的捷径行为。

#### 整体优化目标
\[
\mathcal{L} = \mathcal{L}_{\text{hard}} + \mathcal{L}_{\text{medium}} + \mathcal{L}_{\text{easy}}
\]
三个损失互斥，每个任务仅触发一种。

### 2.3 算法流程（文字说明）
1. 每个训练步，采样一批ID训练任务。
2. 对每个任务，用标准prompt采样G条轨迹，计算通过率 \( p_i \)。
3. 根据滑动平均阈值 \( \eta_t \) 将任务分配到Hard/Medium/Easy。
4. Hard任务：用特权prompt重采样成功轨迹，计算JSD损失加入总损失。
5. Medium任务：对Phase-1轨迹计算标准GRPO损失。
6. Easy任务：无技能prompt采样诊断轨迹，计算利用优势，加权到GRPO损失。
7. 更新策略参数。
