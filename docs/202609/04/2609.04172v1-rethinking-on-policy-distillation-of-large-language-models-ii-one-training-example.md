## 摘要
在线策略蒸馏（OPD）结合了学生生成的样本与教师提供的密集词级监督。现有工作主要研究其算法行为，而训练数据的作用尚不明确。我们在数据最小极限下通过使用单个查询进行训练来考察这一作用。单次OPD在数百步内持续改进，并在任务领域和模型家族中恢复了全数据OPD的大部分收益。我们通过训练期间访问的状态以及学生与教师对齐的速率来解释这一结果。我们测量了\emph{状态覆盖率}，即全数据OPD访问的状态中，由查询集的生成轨迹所达到的比例。单个查询已达到\(71.5\%\)，其中大部分在前100步内实现。添加语义不同的查询会同时提高覆盖率和验证准确率，直到16个查询达到\(98.9\%\)并匹配全数据训练。然而，无论OPD是在一个查询还是整个数据集上训练，对齐速度都以相似的速度减慢，即使是固定的状态集也需要数百步才能吸收。因此，OPD是数据过剩但算法饥饿的。其生成轨迹迅速暴露了广泛的监督，而学生吸收这些监督的速度却越来越慢。状态覆盖率结果扩展到多教师OPD，其中每个领域16个语义多样的查询匹配全数据MOPD。作为进一步的压力测试，内容稀疏的模板和领域外的WildChat查询也接近真实查询基线。因此，任务内容和诱导的状态覆盖率可以分离。我们希望这些发现将未来的工作引向OPD的步骤效率，并促使重新审视其在前沿后训练中近期成功背后的数据和机制。

## Abstract
On-policy distillation (OPD) combines student-generated rollouts with dense token-level supervision from a teacher. Existing work has mainly studied its algorithmic behavior, leaving the role of training data unclear. We examine this role at the data-minimal limit by training on a single query. One-shot OPD keeps improving for hundreds of steps and recovers most of full-data OPD's gain across task domains and model families. We explain this result through the states visited during training and the rate at which the student aligns with the teacher. We measure \emph{state coverage}, the fraction of the states full-data OPD visits that a query set's rollouts reach. A single query already reaches \(71.5\%\), most of it within the first 100 steps. Adding semantically distinct queries raises coverage and validation accuracy together, until 16 queries reach \(98.9\%\) and match full-data training. Yet alignment slows at a similar pace whether OPD trains on one query or the whole dataset, and even a fixed set of states takes hundreds of steps to absorb. OPD is therefore data-overfed but algorithm-starved. Its rollouts quickly expose broad supervision, while the student absorbs that supervision increasingly slowly. The state-coverage result extends to multi-teacher OPD, where 16 semantically diverse queries per domain match full-data MOPD. As a further stress test, content-light templates and off-domain WildChat queries also approach the real-query baseline. Task content and induced state coverage can therefore come apart. We hope these findings direct future work toward the step efficiency of OPD, and prompt a re-examination of the data and the mechanisms behind its recent successes in frontier post-training.

## 1. 核心问题与整体含义

- **研究背景**：在线策略蒸馏（On-Policy Distillation, OPD）已成为 Qwen3、DeepSeek-V4、GLM-5、Kimi K3 等前沿模型后训练中的标配技术，其特点在于：学生模型自采样轨迹，同时教师模型在每个访问到的前缀（state）提供密集的逐 token 分布监督。
- **现有空白**：已有研究 OPD 的工作几乎全部从“算法行为/训练动力学”角度切入（如 Li et al. 2026、Fu et al. 2026、Cai et al. 2026 等），但**训练数据本身如何影响 OPD，以及数据与算法如何交互，此前未被系统研究过**。
- **研究问题**：将数据量降到最低（single query），为什么一个训练样例就足以让 OPD 持续学习数百步并带来显著提升？
- **核心结论**（一句话概括）：
  > **OPD 处于"数据过喂、算法饥饿"（data-overfed but algorithm-starved）的状态**——极少量的查询已经提供了足够广泛的监督状态，真正限制训练收益的是学生模型吸收这些监督的速度。

- 这一发现颠覆了传统“多少条数据才够用”的问题框架，将 OPD 数据设计的重要对象从**问题数量/难度**转向**查询所诱导的状态覆盖区域**。

## 2. 方法论

### 2.1 OPD 形式化
- 目标函数：在访问到的状态上最小化逐 token KL 散度。  
  `L_OPD(θ) = E_{x~D, y~π_θ} Σ_i KL( π_θ(·|s_i) ∥ π_T(·|s_i) )`
- 实际训练中使用两种优势估计器：
  1. **采样 token advantage**：`A_i = log π_T(y_i|s) − log π_θ(y_i|s)`（单 token 估计，用于多数实验）
  2. **Top-k advantage**：覆盖学生最高概率的 k 个 token，降低方差（数学实验 k=16）

### 2.2 关键分析概念
- **State（状态）**：自回归上下文前缀 `s_i = (x, y_<i)`，是 OPD 监督真正作用的单位。
- **状态覆盖率（State Coverage）**：将一个 full-data OPD 全程采样的 states 作为参照空间，做 PCA 降维 + K-means 聚类（K=200），然后度量某个数据集/设置能到达其中多少比例的语义簇。
- **吸收率（Absorption Rate）**：`v_t = (d_t − d_{t+1}) / d_t`，即一步更新能够消除的剩余教师-学生距离的比例，用来衡量算法吸收监督的速度。
- **Gap recovery / Full-data recovery**：分别以教师分数或 full-data OPD 分数为基准，计算学生提升量与差距的比值。

### 2.3 数据与算法两个视角的分析框架
- **数据侧**：为什么单 query 收益大？→ 单条 query 的 rollouts 已经能覆盖 full-data state space 的 71.5%。
- **算法侧**：为什么能持续学几百步？→ 不是因为数据持续供给，而是因为**学生每一步只能吸收剩余差距的一个越来越小的比例**；即使固定 states 集合不变，也需要数百步才能消化。

## 6. 主要结论与发现

1. **One-Shot OPD 效果显著且稳健**：
   - 数学领域单 query 训练大约可恢复 full-data OPD 增益的 **69%（step 300）到 87%（按 full-data recovery 计）**；
   - 在 code、instruction following、agentic 工具使用中，分别恢复了教师-学生差距的 73%、66%、64%；
   - 效果同样出现在 Llama 3.2-3B、OLMo-7B 等其他模型家族上。

2. **单 query 已经覆盖绝大多数状态**：
   - 一条 query 在前 100 步内就能覆盖 full-data 状态空间的 **65.9%**，300 步达到 **71.5%**；
   - 16 个语义多样 query 覆盖率提升到 **98.9%**，在验证准确率上达到甚至轻微优于 full-data OPD。

3. **数据多样性的本质是状态多样性**：
   - 同一聚类内的 16 条 query 到达覆盖率仅约 76.8%、验证准确率接近 4-shot 水平，说明是否带来新状态才是关键；
   - query 的调度顺序影响很小。

4. **算法侧限制是"吸收慢，且越来越慢"**：
   - 无论 1-shot 还是 17k full-data，吸收率都以相似速度下降；验证中每步只吸收约剩余距离的一个递减比例；
   - 固定 states 集合的 off-policy 复用也要花数百步才能完全消化——**训练长度不是由新鲜状态的供给决定的**。

5. **效率瓶颈在算法而非数据**：
   - 结论 "OPD is data-overfed but algorithm-starved"；
   - 学习率只是把时间轴缩放，不改变学习曲线的形状。

6. **机制可推广到 MOPD**：
   - 每个领域 16 个语义多样 query 的 MOPD（数学、代码、指令跟随三老师）能达到甚至超过 full-data MOPD 的收益（平均恢复 101% 的 full-data gain）。

7. **输入的语义内容不是必须的**：
   - content-light 的模板和 WildChat 领域外 prompt 也能接近真实 query 的表现；
   - 只要输入能把学生带到"教师能提供监督的状态"，就可以构成有效的 OPD 数据。

8. **与 one-shot RLVR 的差异**：
   - RLVR 依赖可验证结果且轨迹结果分歧衰减快，单 query 信号先强后弱；
   - OPD 因 teacher token-level 监督持续存在于所有状态，300–1000 步内持续产出收益，验证增益约为相同设定 RLVR 的 2 倍以上。

---

## 7. 优点

- **刻画了全新视角**：将 OPD 数据分析从“查询数量”下沉到“状态覆盖率”，提出 data-overfed / algorithm-starved 的可记忆核心洞见。
- **极简实验哲学**：one-shot 设计与循环强调“数据量→0 时算法本质仍然成立”，用非常小的实验成本揭示高信号问题。
- **测量设计细致**：state coverage 的定义给出可复现流程；对聚类数 K、state 提取位置、参照集构造均有大量 robustness checks（附录表 4/5、图 16），分析严谨。
- **多处善用对照拆解混淆**：例如 off-policy distinct trajectories 消融控制 on-policy 带来的 states 变化；16-cluster vs 1-cluster queries 分离多样性与数量；固定 state 的 off-policy 复用拆开“供给新状态”与“消化旧状态”。
- **跨域跨模型的结论验证**：涵盖数学、代码、指令跟随、工具调用和不同学生-教师对，增强了结论一般性。
- **对领域热点有直接回应**：在线蒸馏在 Qwen3、DeepSeek-V4、GLM-5 等前沿模型的 post-training 中被使用，本文对这些系统的数据/训练效率有实际参考价值。

## 8. 不足与局限

- **论文自身列出的局限**：
  1. state coverage 依赖 full-data reference，并假设各 cluster 均等重要——不能独立于 full-data run 预测某个 query 的价值；
  2. 没有说明吸收率为什么会下降，只描述了该现象；
  3. MOPD 只覆盖 3 个 domain、每个 domain 一个教师，扩展到更多教师时的表现未知。

- **实验规模与尺度限制**：模型规模仅覆盖约

**实验规模与尺度限制**：模型规模仅覆盖约 1.5B–7B 的中小规模参数区间，未涉及 30B、70B 或更大的模型；若考虑更大模型上采样成本与分布变化，one-shot 的覆盖率数值与吸收率曲线可能需要重新校准，结论的规模外推性尚未得到验证。

- **训练长度与衰减外推不足**：多数实验止步于 300 步，最长对比实验到 1000 步；吸收率下降曲线是否在更长训练（数千步）后趋近于零，以及 one-shot 相对 full-data 的长期差距是否会重新拉大，论文没有给出充分证据。

- **评价指标相对单一**：虽然覆盖多个任务域，但每个域所用评测基准数量有限（如代码仅 LiveCodeBench、指令仅 Multi-IF），在单一基准上得出的恢复比例可能有噪声；同时报告多为 avg@n 的聚合指标，缺少对学生分布变化（如多样性坍塌）的细粒度刻画。

- **状态覆盖率度量的粒度局限**：聚类基于教师 hidden states 的语义表征，cluster 内仍有大量状态分布差异未被体现；对"覆盖率 71.5%"这样的绝对数字应视作参考性代理指标，而非精确的统计量。

- **对劣势估计器与超参数的敏感性交代不够完整**：论文承认 Section 3（top-k advantage）与 Section 4/5（sampled-token advantage）之间的数值不完全可比；此外响应长度、温度、采样数量等只做了部分消融，状态覆盖与这些超参数联合作用的交互分析仍显薄弱。

- **缺少工程层面的失败案例讨论**：论文聚焦于 one-shot 为什么有效，但对什么条件下 one-shot 会失败（如教师过弱、学生过强、领域分布极度分散等边界情况）未给出系统的反例分析，边界条件的刻画不够完整。

## 9. 对本领域研究的意义与启示

1. **对 OPD 数据设计的范式转移**：本研究提示社区，在 OPD 中无需再执著于收集大规模、高难度的提问数据集；更值得关注的是**如何用最少查询撬动覆盖最广状态空间的轨迹**。这直接影响了主动学习、查询构造（query synthesis）在蒸馏中的角色定位。

2. **将优化焦点移向算法侧**："data-overfed but algorithm-starved"的表述向算法研究者发出明确信号——与其继续增大 batch、增加 query 数，不如致力于设计吸收更快、样本效率更高的蒸馏损失或更新规则。

3. **对大规模在线蒸馏系统（Qwen3、DeepSeek-V4 等）的工程启示**：如果训练中遇到收益递减，未必需要立即扩容数据管道；可先检查状态覆盖率是否已饱和，再考虑是否为算法吸收能力所限。

4. **one-shot 作为诊断工具**：本文给出了一种廉价的"冒烟测试"思路——用单条查询即可大致判断一个 OPD 配置（学生-教师对、采样参数、学习率）是否有潜力。若 one-shot 都学不动，则 full-data 很难指望有本质改观。

5. **重新审视 state 在训练中的地位**：以往数据筛选以 query 为粒度，本文通过状态覆盖率将分析单元从 query 前移至 prefix/state，为后续"状态级数据选择""前缀级重加权"等更精细的蒸馏数据策略打开了空间。

## 10. 关键术语与定义速查

| 术语 | 定义/含义 |
|---|---|
| OPD | On-Policy Distillation，学生自采样轨迹、教师逐 token 提供分布监督的蒸馏范式 |
| One-Shot OPD | 仅使用 1 条 query 的 OPD 训练，本文的核心实验设置 |
| State | 自回归上下文前缀 (x, y_<i)，OPD 监督施加的最小单位 |
| State Coverage | 一条/一组 query 的轨迹所到达状态语义簇占 full-data 状态簇集合的比例 |
| Absorption Rate | v_t = (d_t − d_{t+1})/d_t，单步更新消除剩余教师-学生距离的比例 |
| Gap Recovery | (M_t − M_0)/(M_T − M_0)，相对教师基准的增益恢复比例 |
| Full-Data Recovery | 相对 full-data OPD 最终分数的增益恢复比例 |
| MOPD | Multi-teacher On-Policy Distillation，多教师扩展版本 |
| Multi-IF / BFCL v3 / LiveCodeBench | 分别用于指令跟随、工具调用、代码生成的评测基准 |
| RLVR | Reinforcement Learning with Verifiable Rewards，基于可验证奖励的强化学习（与 OPD 对照） |
| Content-light training | 只含模板/系统提示、不携带实质语义内容的查询压力测试 |

## 11. 总结

本论文以极简的 one-shot 实验设计，系统性地回答了"在线策略蒸馏中数据到底起什么作用"这一问题。作者通过状态覆盖率分析发现，单条查询即可覆盖 full-data 训练状态空间的七成以上，而真正限制训练收益进一步增长的是学生模型逐 token 吸收教师监督的速率呈递减趋势。由此提出"OPD 处于数据过喂、算法饥饿"的核心论断，并将数据设计焦点从问题数量转移到状态覆盖。作者进一步在数学、代码、指令跟随、工具调用四个领域和多个模型家族上验证了这一结论的稳健性，并通过多教师蒸馏、内容轻量输入、与 RLVR 对照等实验加固了机制的普适性。该工作对大规模在线蒸馏系统的数据效率改进和后续算法研究提供了明确的方向性启示。

尽管论文在模型规模、训练步数与覆盖率度量粒度上存在一定局限，其问题意识之敏锐、实验设计之简约克制、分析框架之清晰，均使其成为 OPD 数据科学研究中一篇具有较高参考价值的作品。
