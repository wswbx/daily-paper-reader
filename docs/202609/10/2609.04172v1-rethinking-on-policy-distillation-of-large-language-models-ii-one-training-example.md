## 摘要
在线策略蒸馏（OPD）将学生模型生成的 rollout 与教师模型提供的密集 token 级监督相结合。现有工作主要研究其算法行为，而训练数据的作用仍不清楚。我们通过在单个查询上训练，在数据极简极限下考察这一作用。单样本 OPD 在数百步内持续提升，并在多个任务领域和模型族上恢复了全数据 OPD 的大部分增益。我们通过训练过程中访问的状态以及学生与教师对齐的速率来解释这一结果。我们测量了状态覆盖，即一个查询集的 rollout 所到达的状态占全数据 OPD 所访问状态的比例。单个查询已达到 71.5%，其中大部分在前 100 步内达到。添加语义上不同的查询会同时提高覆盖率和验证准确率，直到 16 个查询达到 98.9% 并匹配全数据训练。然而，无论 OPD 是在一个查询还是整个数据集上训练，对齐都以相似的速度变慢，甚至固定的一组状态也需要数百步才能吸收。因此，OPD 是数据过饱而算法匮乏。其 rollout 很快暴露出广泛的监督，而学生吸收这些监督的速度越来越慢。状态覆盖结果可扩展到多教师 OPD，其中每个领域 16 个语义多样的查询即可匹配全数据 MOPD。作为进一步的压力测试，内容轻量的模板和域外 WildChat 查询也接近真实查询基线。因此，任务内容与诱导出的状态覆盖可能分离。我们希望这些发现将未来工作引向 OPD 的步效率，并促使人们重新审视其近期在前沿后训练中成功背后的数据和机制。

## Abstract
On-policy distillation (OPD) combines student-generated rollouts with dense token-level supervision from a teacher. Existing work has mainly studied its algorithmic behavior, leaving the role of training data unclear. We examine this role at the data-minimal limit by training on a single query. One-shot OPD keeps improving for hundreds of steps and recovers most of full-data OPD's gain across task domains and model families. We explain this result through the states visited during training and the rate at which the student aligns with the teacher. We measure \emph{state coverage}, the fraction of the states full-data OPD visits that a query set's rollouts reach. A single query already reaches \(71.5\%\), most of it within the first 100 steps. Adding semantically distinct queries raises coverage and validation accuracy together, until 16 queries reach \(98.9\%\) and match full-data training. Yet alignment slows at a similar pace whether OPD trains on one query or the whole dataset, and even a fixed set of states takes hundreds of steps to absorb. OPD is therefore data-overfed but algorithm-starved. Its rollouts quickly expose broad supervision, while the student absorbs that supervision increasingly slowly. The state-coverage result extends to multi-teacher OPD, where 16 semantically diverse queries per domain match full-data MOPD. As a further stress test, content-light templates and off-domain WildChat queries also approach the real-query baseline. Task content and induced state coverage can therefore come apart. We hope these findings direct future work toward the step efficiency of OPD, and prompt a re-examination of the data and the mechanisms behind its recent successes in frontier post-training.

## 1. 核心问题与研究动机

- **背景**：在线策略蒸馏（On-Policy Distillation, OPD）已成为前沿 LLM 后训练的标准组件（Qwen3、MiMo、GLM-5、DeepSeek-V4、Kimi K3 等均使用）。其特点是学生采样自身 rollout，教师在每个访问到的前缀上提供**密集的 token 级分布监督**，区别于 RLVR 仅有的结果级标量奖励。
- **研究缺口**：已有工作几乎全部从**算法视角**解释 OPD 为何有效（目标函数、更新几何、成败条件等），但**训练数据的作用**从未被系统研究——数据与算法如何交互尚不清楚。
- **核心问题**：受 one-shot RLVR 启发，作者把数据压到极限（仅用**一个 query** 训练），追问：**为什么 OPD 在单样本上能持续学习数百步并大幅提升？**
- **整体含义**：论文给出的答案是 **OPD 是“数据过供、算法饥饿”（data-overfed but algorithm-starved）**——单条 query 的 rollout 很快就能暴露足够广的监督信号，而学生吸收这些监督的速度却越来越慢，成为真正的瓶颈。这一发现将数据设计的焦点从“收集多少问题”转向“输入诱导出哪些状态”。

## 2. 方法论

- **核心思想**：把 query 的作用还原为它诱导的**状态（state）**——即自回归前缀 \(s=(x, y_{<i})\)。OPD 在每个访问状态上都有教师监督，因此一条 query 配合 64 条 rollout 即可产生数万个受监督状态，query 数量会严重低估监督量。
- **OPD 目标**：最小化访问状态上的逐 token KL：
  \[
  \mathcal{L}_{\text{OPD}}=\mathbb{E}_{x\sim D,\,y\sim\pi_\theta}\Big[\sum_i \mathrm{KL}(\pi_\theta(\cdot|s_i)\|\pi_T(\cdot|s_i))\Big]
  \]
  实践中用两种优势估计：(i) 采样 token 优势 \(A_i^{\text{OPD}}=\log\pi_T(y_i|s)-\log\pi_\theta(y_i|s)\)；(ii) top-\(k\) 优势，在学生最可能的 \(k\) 个 token 上按学生概率加权求和（数学实验用 \(k=16\)，其余用采样 token 形式）。
- **状态覆盖（State Coverage）**——数据侧的核心度量：
  - 用**教师最后一层隐藏向量** \(h_T(s)\) 作为状态的表示；
  - 以全数据 OPD 整个训练过程访问的状态为参考空间，PCA 降维后 K-means 聚成 \(K=200\) 个簇；
  - 覆盖率 \(\mathrm{Cov}(S)=\frac{1}{K}|\{c(s):s\in S\}|\)，即某设置 rollout 到达的簇比例。只记录“是否到达”，不记录访问频次。
- **吸收率（Absorption Rate）**——算法侧的核心度量：
  - 距离 \(d_t=\frac{1}{|T_t|}\sum_i|\log\pi_T(y_i|s_i)-\log\pi_\theta(y_i|s_i)|\)（取绝对值避免正负抵消）；
  - 吸收率 \(v_t=(d_t-d_{t+1})/d_t\)，即一次更新吸收了多少剩余师生差距；
  - 因梯度裁剪在前期起作用，从 step 30 起测量，并用几何窗口 \([t/1.4,1.4t]\) 估计 \(v_t\) 以降噪。
- **辅助对齐指标**：top-\(k\) token 重叠率、overlap-token advantage（共享高概率 token 上的加权对数概率差）、绝对熵差。
- **收益归一化**：gap recovery \(=\frac{M_t-M_0}{M_T-M_0}\)，full-data recovery \(=\frac{M_t-M_0}{M_F-M_0}\)，便于跨领域比较。

## 6. 主要结论与发现

- **单样本即可恢复大部分增益**：one-shot OPD 在数学上 step 300 恢复 69% 师生差距、87% 全数据增益；step 1000 仍恢复 72% 全数据增益，且曲线长期与全数据接近（约 3 分带内）。代码/IF/工具调用分别恢复 73%/66%/64% 的师生差距。
- **对 query 与 rollout 属性不敏感**：易/中/难 query 效果相当，**学生从未解出的 hard query 与总是解出的 easy query 一样有效**；缩短响应长度、降低采样温度均不破坏增益。
- **数据侧：一条 query 覆盖 71.5% 状态**，其中 65.9% 在前 100 步达到，之后新增簇急剧递减；语义多样的 16 条 query 达 98.9%，并追平全数据 OPD。控制实验表明**多样性而非数量**是关键（16 条来自 16 个簇 vs 同一簇差异显著；调度顺序几乎无影响）。
- **算法侧：吸收率持续下降且与数据量无关**：1/4/16/full-data 四种设置在 300 步内都吸收了约 78%–84% 的 step-30 距离，衰减速度相近；即使**固定同一组状态**（off-policy）训练，仍需约 200 步才收敛。学习率只压缩步轴、不改变衰减形状。
- **结论定性**：OPD 的瓶颈不是数据供给，而是**每步吸收监督的效率**；run 的长度由优化器而非训练集决定。
- **MOPD 可迁移**：每领域 16 条语义多样 query 即匹配全数据 MOPD（101% 恢复），full-data MOPD 本身也接近三个独立 full-data OPD。
- **输入内容可与状态覆盖分离**：空模板、仅含系统提示的模板、域外 WildChat 输入都能接近真实 query 基线（数学中 WildChat 约差 1 分），但完全关闭思考块的模板会崩溃；说明输入的核心作用是**启动学生推理并诱导可被教师监督的状态**。
- **与 one-shot RLVR 对比**：同一条 query 下，OPD 在 1000 步内验证增益是 RLVR 的两倍以上；RLVR 受限于结果变化（query 被解出后优势消失），OPD 的 token 级信号在 query 解出后仍持续存在。

## 7. 优点

- **极端受控的实验范式**：把数据压到单条 query，干净地分离“数据作用”与“算法作用”，是数据效率研究中的有力设计。
- **提出可量化的新概念**：state coverage 把“数据价值”从问题数量转向诱导状态空间，为数据选择提供可操作视角；吸收率则量化了算法吸收监督的速度。
- **因果性消融扎实**：通过固定状态、同数量不同多样性、调度顺序、学习率等控制，排除了“训练好只是因为顺路访问了更多状态”等替代解释。
- **跨领域、跨模型族验证**：结论不局限于 Qwen 系或数学任务，外部效度较好。
- **与 RLVR 的直接对照**：在同一 query 上做 head-to-head，清晰揭示两类目标在信号来源与上限上的差异。
- **实践启示明确**：数据设计应从“收集问题”转向“选择能诱导互补状态的输入与教师”，并指向提升步效率的后续方向（如信任域内多 epoch 复用、按剩余教师信号加权 token）。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号/数量/训练时长，影响可复现性与成本评估。
- **状态覆盖是相对且语义级的代理指标**：以全数据 OPD 参考空间为基准，只回答“覆盖了该空间的多少”，不反映自身覆盖质量；所有簇等权，忽略访问频次与簇内剩余教师信号强度；构造依赖 \(K\)、参考集与状态位置。

- **“数据过供”结论的边界条件**：该论断建立在教师能在学生访问的状态上提供可靠密集监督这一前提上。当师生能力差距过大、教师本身在特定状态上不可靠（如长尾推理、幻觉状态），或教师信号与任务目标不一致时，单 query 的监督质量会下降，“数据过供、算法饥饿”的二分可能不再成立。论文未系统探讨教师质量对结论的调制作用。
- **超参敏感性未穷尽**：仅做了学习率（0.5×/1×/2×）与采样温度的消融，未系统探索 batch size、梯度累积、KL 惩罚系数、top-\(k\) 取值等对吸收率曲线形状与状态覆盖速率的影响，因此“run 长度由优化器决定”这一结论的超参稳健性仍有余地。
- **吸收率定义的构造性局限**：以平均绝对对数概率差作为师生距离，忽略了分布形状（如多峰、熵结构）的差异；几何窗口 \([t/1.4,1.4t]\) 估计 \(v_t\) 虽降噪，却引入额外超参，可能掩盖非单调、阶段性或局部回升的吸收模式；从 step 30 起测也回避了早期梯度裁剪主导阶段，使“吸收率”无法刻画训练全程。
- **缺乏机制性/理论刻画**：论文以实证为主，未给出吸收率衰减的理论解释（如与优化景观曲率、教师信号方差、参数更新范数的关系），“算法饥饿”目前更接近描述性标签而非可预测的机制模型，难以据此事前估计某设置的收敛步数。
- **实践建议尚未验证**：论文指向的提升步效率方向（信任域内多 epoch 复用、按剩余教师信号加权 token、状态级数据选择）多属推断性建议，本文并未给出对应实验，实际增益与副作用未知。
- **评测与统计披露**：部分 benchmark（如 AIME 2025 avg@16）样本量小、方差大，论文未普遍报告多次运行的置信区间或显著性检验，个别 1–3 分差距的解读需谨慎。

## 9. 总体评价与启示

本文的价值不在于提出新算法，而在于用**极简数据设定**重新框定了 OPD 的研究问题：把“需要多少数据”转化为“一条输入能诱导多少可监督状态”与“优化器每步能吸收多少教师信号”两个可测量维度。其核心贡献有三：一是**概念贡献**，提出 state coverage 与 absorption rate 两个互补度量，为数据侧与算法侧提供了统一的诊断语言；二是**实证贡献**，通过跨领域、跨模型族的受控实验证明单 query 即可恢复大部分增益，且多样性而非数量是关键；三是**方向贡献**，将数据设计重心从“问题收集”转向“状态诱导”，并指出步效率是下一阶段的主要瓶颈。

对实践的启示可概括为：在 OPD 数据预算有限时，优先选择能诱导互补推理状态的少量输入，而非堆叠大量相似问题；在训练监控中，除验证指标外应关注吸收率曲线的形状，以判断瓶颈究竟在数据还是优化；当任务状态空间显著增大（长程 agentic、多轮对话）时，需重新评估单 query 设定的适用边界。

总体而言，这是一篇**问题意识清晰、实验设计严谨、结论有冲击力但边界也较明确**的工作。它更像一份高质量的“诊断报告”而非“解决方案”：它令人信服地指出 OPD 的瓶颈所在，却把“如何提升吸收率”这一真正的难题留给了后续研究。
