## 摘要
符号回归（SR）旨在从数据中寻找简洁且可解释的数学表达式，以用于科学方程发现。现有符号回归基准在评估成本与基准有效性之间面临权衡。对大规模任务池进行重复评估成本高昂，而紧凑基准缺乏系统性证据来表明其保留了任务多样性与算法区分能力。SymbolicArena 提供了一个用于基准蒸馏与动态评估的统一基础设施。该框架标准化了 664 个具有可执行真值表达式的异构任务，并将完整任务集（Full Task Set）蒸馏为 Core50，一个经过验证的包含 50 个任务的基准。蒸馏过程在显式平衡约束下保留了任务覆盖范围与算法区分度。SymbolicArena 对异构符号回归算法应用统一的执行协议，并产生可比较的输出与搜索轨迹。多轴评估刻画数值质量、符号质量与搜索行为。Core50 将评估工作量减少 92.5%，并与完整任务集评估保持一致性。实验表明，SymbolicArena 比替代选择器实现了 72.6% 至 86.7% 更低的近似误差，进一步支持其对完整任务集的保真度。评估揭示了当前符号回归方法在数值拟合与符号恢复之间存在显著差距，表明可靠的方程恢复仍是一个开放挑战。

## Abstract
Symbolic regression (SR) seeks concise and interpretable mathematical expressions from data for scientific equation discovery. Existing SR benchmarks face a tradeoff between evaluation cost and benchmark validity. Repeated evaluation of large task pools is expensive, and compact benchmarks lack systematic evidence of preserved task diversity and algorithm discriminability. SymbolicArena provides a unified infrastructure for benchmark distillation and dynamic evaluation. The framework standardizes 664 heterogeneous tasks with executable ground truth expressions and distills the Full Task Set into Core50, a validated benchmark of 50 tasks. The distillation process preserves task coverage and algorithm discrimination under explicit balance constraints. SymbolicArena applies a unified execution protocol to heterogeneous SR algorithms and produces comparable outputs and search trajectories. Multi Axis Evaluation characterizes numerical quality, symbolic quality, and search behavior. Core50 reduces evaluation workload by 92.5% and maintains agreement with Full Task Set evaluations. Experiments show that SymbolicArena achieves 72.6% to 86.7% lower approximation error than alternative selectors, further supporting its fidelity to the Full Task Set. Evaluation reveals a substantial gap between numerical fitting and symbolic recovery across current SR methods, suggesting that reliable equation recovery remains an open challenge.

## 一、核心问题与研究动机

- **符号回归（SR）的目标**：从观测数据中恢复简洁、可解释的数学表达式，服务于科学方程发现与符号建模。
- **现有基准的两难困境**：
  - 大型基准任务池（如 SRBench 252 任务、SRSD 240 任务、LLM-SRBench 240 任务）覆盖广，但重复评估成本高昂。
  - 紧凑基准虽能降低评估开销，却缺乏系统性证据证明其保留了任务多样性与算法区分能力。
- **评估协议碎片化**：不同基准在任务构建、执行流程、诊断维度上各自为政，难以跨范式比较异构 SR 算法（演化搜索、神经策略搜索、Transformer、LLM 辅助搜索等）。
- **核心诉求**：需要一套统一基础设施，既能蒸馏出经过验证的紧凑基准，又能标准化异构算法的执行与多维度评估。
- **论文整体含义**：SymbolicArena 将紧凑基准构建形式化为"蒸馏问题"，同时提供统一执行协议与多轴评估，试图在评估成本与基准有效性之间取得平衡。

## 二、方法论

### 2.1 核心思想

将紧凑 SR 基准构建视为**子集选择/蒸馏问题**：从 664 个可执行任务中选出 50 个，使其在聚合得分与算法区分度上逼近完整任务集。整体流程分为**基准蒸馏**与**统一评估**两阶段。

### 2.2 关键技术流程

**（1）Full Task Set 构建（664 任务）**
- 初始候选池超 800 个任务，来源包括 SRSD、LLM-SRBench、SRBench 1.0/2025、Keijzer、Korns、Vladislavleva、Nguyen。
- 准入条件：真值公式可解析可执行、变量/常量/算子一致、训练/ID/OOD 划分可复现、元数据完整。
- 统一 schema：特征顺序、目标信息、固定数据划分、真值表达式、结构元数据、语义重复组标识。
- 公式复杂度按 Python AST 中 BinOp/UnaryOp/Compare 节点计数划分：Simple（≤5，284个）、Moderate（6–8，188个）、Complex（≥9，192个）。

**（2）校准集挖掘（200 任务）**
- 以 PySR 与 LLM-SR 为初始探针，各任务运行一次。
- 分歧度 $G_i = \frac{|g_i^{id}| + |g_i^{ood}|}{2}$，其中 $g$ 为两探针的对数 NMSE 差。
- 组成：140 个高分歧任务 + 20 个单侧可解任务 + 40 个中等分歧任务。

**（3）四探针选择**
- 定义校准可用性 $H_\alpha(a;\tau) = \alpha q(a) + (1-\alpha)[1-b_\tau(a)]$，$\alpha=0.5$、$\tau=100$，$q$ 为有限结果率，$b$ 为数值爆炸率。
- 枚举 495 个四算法子集，在覆盖至少 3 个主要范式的约束下最大化平均可用性。
- 唯一最优：$A_4 = \{\text{DSO}, \text{PyOperon}, \text{iMCTS}, \text{uDSR}\}$，覆盖神经策略搜索、演化搜索、结构化搜索。

**（4）Core50 构建**
- 四探针在 664 任务上各跑 3 个种子，记录 ID/OOD NMSE、输出有效性、种子波动。
- 任务信息量：$\text{Info}_i = \text{Disc}_i \cdot \text{Stab}_i$，其中 Disc 综合探针间方差与熵，Stab 基于构建不稳定性。
- 目标函数：$J(S) = 0.45\,\text{Coverage}(S) + 0.35\,\text{MeanInfo}(S) + 0.20\,\text{Balance}(S)$
- 覆盖率：$\text{Coverage}(S) = 0.6\,\text{StructuralCoverage} + 0.4\,\text{ResponseCoverage}$
- 可行性约束：恰好 50 任务、每个语义重复组/基名至多 1 个、每子组至多 6 个、族配额（$\beta=0.6$ 平滑）、难度分布（4–10 easy / 14–24 medium / 12–22 hard / 3–6 extreme）、至多 8 个受限配额任务等。
- 优化：贪心初始化 + 可行单任务交换，冻结最优子集为 Core50。

**（5）统一执行协议**
- 通用适配器接口（fit/predict/get_optimal_equation），Conda 隔离环境 + 子进程隔离 + 超时控制。
- 输入仅含训练集、特征名、目标信息；ID/OOD 测试集与真值表达式仅用于评估。
- 每分钟记录一个检查点，保存算法原生规则选出的当前最优表达式及搜索轨迹。

**（6）多轴评估（六轴，[0,1] 尺度）**
- **ID/OOD**：数值质量，$\phi(x) = \frac{\ell_{max} - r(x)}{\ell_{max} - \ell_{min}}$，$r(x)=\text{clip}(\log_{10}\max(x,\epsilon), -12, 2)$。
- **SYM**：符号保真度，等价则 1，否则 $0.5(S_{tree}F_vF_o)^{1/3}$。
- **MIN**：最小性，$\min(1, C_{ref}/C_{pred})$。
- **EFF**：搜索效率，$\frac{1}{T}\sum_t q(t)/q^*$，$q^*$ 为该次运行观测最大值。
- **STAB**：稳定性，$(NVC)^{1/3}$，综合数值一致性、有效运行比例、结构一致性。
- 符号后处理使用 Opus 5 做表达式简化与等价/结构判定，结果在指标聚合前冻结。

## 三、实验设计

- **基准规模**：Full Task Set 664 任务 → Core50 50 任务（工作量降低 92.5%）。
- **评估算法**：15 个代表性 SR 算法，覆盖 6 类范式：
  - 结构化搜索：iMCTS、QLattice、JAXSR
  - 演化搜索：PySR、PyOperon、gplearn、SymbolFit
  - 神经策略搜索：uDSR、DSO
  - 混合搜索：FePySR、RAG-SR
  - Transformer：E2ESR、TPSR
  - LLM 辅助：DrSR、LLM-SR
- **验证算法**：FePySR、SymbolFit、JAXSR 被排除在基准构建之外，仅用于保真度验证。
- **对比基线选择器（6 个）**：uniform random-50、family-stratified random-50、metadata-diverse-50、response-space K-medoids-50、top-information-50、difficulty-balanced-50。
- **评估条件**：clean + 1% + 5% 训练标签噪声；ID 与 OOD 两个分布；每算法 3 个随机种子（520/521/522），PySR 与 LLM-SR 使用种子 1314。
- **保真度度量**：聚合 MAE、NMAE、Spearman/Kendall 秩相关、逐对顺序一致率。
- **敏感性分析**：探针选择的 1000 次家族分层 bootstrap、$\alpha\in[0.3,0.7]$、$\tau\in\{10,30,100,300,1000\}$、成员移除替换实验；Core50 权重的单参数与联合扰动（5000 个权重向量）。

## 六、主要结论与发现

1. **基准蒸馏有效**：Core50 相比 6 个替代选择器，将聚合得分 MAE 降低 72.6%–86.7%（MAE=0.1388），且在结构-响应联合空间中覆盖任务总体主要区域。
2. **保真度高**：9 个算法（含 3 个未参与构建的验证算法）在 Full Task Set 与 Core50 上 ID ρ=0.9833、OOD ρ=0.9667，OOD 排序完全保留，ID 仅一对顺序变化。
3. **无算法全面占优**：iMCTS 领先 ID/OOD，FePySR 领先 SYM/MIN，JAXSR 领先 EFF/STAB，PySR 在四个轴上排第二，体现能力专精化。
4. **数值拟合 ≠ 符号恢复**：强数值精度不保证符号保真（如 iMCTS 数值第一但 SYM 仅 42.15；Nguyen-9 案例 NMSE≈1e-15 却被判 not_equivalent，SYM=0.4886）。
5. **搜索行为独立于解质量**：EFF/STAB 与最终数值质量相关性极弱（EFF-ID ρ=−0.08，STAB-ID ρ=−0.17），高 EFF 可能只是"早达低峰"，高 STAB 仅表示可重复性。
6. **噪声鲁棒性差异大**：iMCTS 在噪声下仍保持最高 OOD，DSO 绝对下降最小；高 clean OOD 性能不必然对应小退化。
7. **轴间结构**：ID-OOD 高度相关（0.98），SYM-MIN 强相关（0.82），数值与符号中等相关（0.57–0.64），支持保留多轴独立评估。

## 七、优点

- **系统化的基准蒸馏框架**：将紧凑基准构建形式化为带显式约束的优化问题，目标函数兼顾覆盖率、任务信息量与分布平衡，并给出可复现的冻结流程。
- **严谨的保真度验证**：使用独立于构建流程的 3 个验证算法，避免"自证"；同时报告聚合 MAE、秩相关与逐对顺序一致率。
- **统一执行协议**：通过通用 wrapper、环境隔离、子进程超时控制、分钟级轨迹记录，使异构算法可比且可复现。
- **多轴评估设计**：将数值质量、符号质量、搜索行为解耦，揭示单一数值指标无法反映的能力差异，并给出明确的公式定义与 bootstrap 区间。
- **充分的敏感性与不确定性分析**：探针选择、权重扰动、噪声鲁棒性均有量化结果，且给出任务核心稳定集（37 任务在全部 5000 次权重采样中被选中）。
- **信息隔离与可审计性**：LLM 搜索模型无法访问真值或测试目标；Opus 5 仅在评估侧后处理，判定结果冻结并保留哈希，具备审计追溯能力。
- **可复现承诺**：固定任务清单、数据划分、随机种子、预算、算法配置与评估协议。

## 八、不足与局限

- **基准覆盖边界继承**：Core50 继承 Full Task Set 的覆盖边界，未包含的科学领域与算子族不在验证范围内；新任务族或差异较大的搜索范式需重新验证保真度。
- **保真度仅对当前任务分布与所代表范式有效**：Core50 由四个探针响应蒸馏而来，超出该算法范式集合的结论外推需谨慎。
- **无算法专属超参调优**：仅使用官方默认/推荐配置加最小适配，绝对分数与相对排名可能随专门调优改变；结果仅代表标准化配置下的表现。
- **STAB 结构一致性判定存在审计不一致**：clean/1%/5% 噪声下分别有 3/2/3 个算法-任务组出现不一致的成对符号判定，限制 STAB 结构分量的解释。
- **符号等价判定依赖 LLM**：Opus 5 的判定被视为评估证据而非形式化数学证明，存在模型判定偏差风险；虽有冻结与审计机制，但不等价判定仍可能受模型局限影响。
- **算力信息不透明**：未报告 GPU 型号/数量/总时长，难以评估复现成本与环境要求。
- **任务难度依赖静态元数据**：复杂度由 AST 算子计数定义，函数调用（sin、exp）不计权重，辅助实现逻辑会干扰计数，属描述性元数据而非经验难度。
- **部分选择器未做重复抽样**：metadata-diverse、K-medoids、top-information、difficulty-balanced 仅报告单次点估计，未给随机性区间（尽管它们本质上是确定性的）。
- **应用限制**：主要面向 SR 学术评测场景，对工业级大规模方程发现或需要严格形式化验证的场景支持有限。
