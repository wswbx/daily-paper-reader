## 摘要
尽管符号回归（SR）已在科学领域成功用于发现新方程，但其在金融估值中的应用受到若干限制。自然科学提供的是客观正确的关系，而金融估值则构成一类独特的符号发现问题：它允许多种有效视角，在非平稳市场条件下运行，并涉及带噪的连续表现信号。在这项工作中，我们提出多智能体基本面分析与符号自适应学习（MUFASA），一个用于金融领域符号发现的分层多智能体框架。MUFASA 引入了：（1）通过代表不同估值视角的专门智能体进行解耦方程发现；（2）一个元协调器，对市场上下文信息进行层级推理；（3）一种记忆机制，对统计性能摘要（如准确率、稳定性和尾部风险）进行推理，以在噪声反馈下指导学习。在来自多个国家的数据集上的实验表明，与经典金融方法、金融大语言模型和 SR 方法相比，MUFASA 在估值任务上取得了最先进的性能，同时产生可解释的方程，我们将其与社区共享。我们还公开了跨进化迭代的蒸馏学习结果以及依赖上下文的策略权重，这可能为未来金融基本面分析研究提供有用见解。

## Abstract
While symbolic regression (SR) has been successfully used in science to discover new equations, its use in financial valuation is hindered by several limitations. Whereas the natural sciences provide objectively correct relationships, financial valuation constitutes a distinct class of symbolic discovery problems, as it admits multiple valid perspectives, operates under non-stationary market conditions, and involves noisy, continuous performance signals. In this work, we propose Multi-Agent Fundamental Analysis with Symbolic Adaptive learning (MUFASA), a hierarchical multi-agent framework for symbolic discovery in finance. MUFASA introduces (1) disentangled equation discovery via specialized agents representing distinct valuation perspectives, (2) a meta-coordinator that performs hierarchical-level reasoning over market context information, and (3) a memory mechanism that reasons over statistical performance summaries (e.g., accuracy, stability, and tail risk) to guide learning under noisy feedback. Experiments across datasets from multiple countries show that MUFASA achieves state-of-the-art performance on the valuation task compared to classical finance methods, financial large language models, and SR approaches, while simultaneously producing interpretable equations, which we share with the community. We also make publicly available the distilled learnings across evolution iterations and context-dependent strategy weights, which might offer useful insights for future research on financial fundamental analysis.

## 1. 核心问题与整体含义

- **研究背景**：符号回归（Symbolic Regression, SR）在自然科学中已成功用于从数据中发现数学方程，并借助大语言模型（LLM）进一步提升假设生成与搜索效率。然而，这些方法默认存在一个稳定、客观的“真值方程”，与金融估值的本质不符。
- **核心问题**：金融基本面估值构成一类**独特的符号发现问题**，其与自然科学的差异体现在三个层面：
  - **多重有效视角**：金融估值不存在唯一真值方程，盈利、现金流、成长、资产、质量等不同估值哲学可同时提供合理解释；现有搜索单一方程的 SR/Agent 方法会限制表达力与泛化性。
  - **非平稳环境**：财务信号与收益的关系随市场状态（牛/熊）和公司行业而变化，相同动作在不同迭代中产生不同结果，奖励信号被环境不稳定所混淆。
  - **噪声、连续反馈**：候选表达式通过带噪的连续性能信号（如 MAPE）评估，而非二值正确/错误信号；现有基于成败二值信号蒸馏经验的 agent 记忆容易将成功归因于虚假模式。
- **整体含义**：上述三类挑战在自演化循环的各个阶段相互叠加，使金融符号发现整体难度递增。论文旨在提出一个能够同时应对多视角、非平稳与噪声反馈的分层多智能体框架，在提升估值预测精度的同时产出可解释、经济上有依据的符号表达式。

## 2. 方法论

### 2.1 核心思想

MUFASA（Multi-Agent Fundamental Analysis with Symbolic Adaptive learning）是一个**分层多智能体符号发现框架**，包含三个关键设计：

1. **解耦式方程发现**：用一组专门智能体分别代表不同估值视角（如现金流、盈利、成长、资产、质量），各自在受限假设空间内搜索表达式，鼓励多样性并保持视角内可解释性。
2. **层级级推理**：引入元协调器智能体，基于市场上下文（行业、市场状态）动态加权各专家智能体的输出，实现跨环境自适应组合。
3. **统计性能记忆**：每个智能体维护结构化记忆，记录历史方程及其统计性能摘要（准确率、稳定性、尾部风险、复杂度、偏差、排名、校准），并从中蒸馏学习经验以指导后续假设生成。

### 2.2 问题形式化

- 给定公司宇宙与会计信息数据库 \(X_t\)，目标为每家公司 \(i\) 产生估值，并与前瞻股价 \(y_{i,t+1}\) 比较。
- 需识别可解释的符号关系 \(\tilde{f}\)，且解释变量 \(x_{i,t} \subseteq X_t\) **并非先验给定**，必须在发现过程中从数据库中识别。
- 金融关系具有**上下文依赖性**，定义上下文变量 \(C(i,t) = (s(i), r(t))\)，其中 \(s(i)\) 为公司行业，\(r(t)\) 为市场状态。
- 目标：发现解释变量 \(\hat{x}_{i,t}\) 与上下文依赖的符号表达式 \(\tilde{f}_{C(i,t)}\)，使得 \(\tilde{f}_{C(i,t)}(\hat{x}_{i,t}) \approx y_{i,t+1}\)，同时满足样本外泛化性与可解释性。

### 2.3 解耦式符号发现

- **视角分解**：定义一组估值哲学 \(a\)，每种哲学对候选方程施加归纳偏置（偏好变量与结构模式），防止表达式多样性坍缩。
- **假设生成**：每个视角 \(a\) 使用 LLM \(\pi_\theta\) 迭代生成候选表达式 \(\tilde{f}^{(a)} \sim \pi_\theta(\cdot \mid p^{(a)})\)；提示 \(p^{(a)}\) 编码投资哲学 \(a\) 与累积学习 \(Z^{(a)}\)。
- **工具使用——数据检索**：智能体先通过语义检索获取候选变量名与描述，再选择并检索对应数据；若检索失败（不可用或覆盖不足），接收结构化反馈并调整假设。
- **工具使用——代码评估**：候选表达式表示为可执行程序，直接计算预测值 \(\hat{y}^{(a)}_{i,t+1} = \tilde{f}^{(a)}(x^{(a)}_{i,t})\)；若执行失败（语法错误、非法操作、非有限输出），接收结构化反馈并修正。
- **假设优化与评估**：
  - 将表达式中的标量乘数/参数视为连续变量，用**差分进化**（Differential Evolution）优化，解耦结构发现与参数拟合。
  - 适应度定义为预测误差：\(L^{(a)} = \text{MAPE}(\hat{y}^{(a)}_{i,t+1}, y_{i,t+1})\)。

### 2.4 层级级推理（元协调器）

- 元协调器智能体 \(\pi_\phi\) 针对每个上下文 \(C(i,t)\) 产生权重向量，表示各专家智能体在该上下文下的相对重要性。
- 提示 \(p^{\text{meta}}\) 包含当前上下文、各智能体性能 \(L^{(a)}\) 与累积学习 \(Z^{\text{meta}}\)；元协调器选择智能体子集，并通过 **SLSQP 约束优化**计算权重向量 \(\tilde{w}_{C(i,t)}\)。
- 聚合估值：\(\hat{y}_{i,t+1} = \tilde{w}_{C(i,t)}^\top \cdot \hat{y}_{i,t+1}\)。
- 元协调器质量评估：\(L^{\text{meta}} = \text{MAPE}(\hat{y}_{i,t+1}, y_{i,t+1})\)，支持在非平稳反馈下持续自适应。

### 2.5 统计性能记忆

- 不同于仅存储标量损失或二值成败，记忆记录每个假设及其**统计行为摘要**，包括：
  - **准确率**：Mean MAPE、Median MAPE；
  - **稳定性**：标准差、IQR、变异系数；
  - **尾部风险**：p90/p95 误差、最差十分位均值；
  - **复杂度**：变量+算子数量、预测覆盖率；
  - **偏差**：平均符号百分比误差（MSPE）；
  - **排名**：Spearman 秩相关；
  - **校准**：按实际价格四分位的符号百分比误差。
- 从记忆中蒸馏学习 \(Z^{(a)}\)，捕获重复评估中显现的统计规律（如方差、尾部行为），使智能体能在噪声监督下识别稳健候选并改进搜索策略。

### 2.6 算法流程（文字说明）

- **哲学智能体训练**（Algorithm 1）：初始化种子方程 → 迭代：生成假设 → 数据检索（失败则反馈）→ 代码评估（失败则反馈）→ 系数优化 → 计算 MAPE → 更新记忆与学习。
- **元协调器训练**（Algorithm 2）：对每个上下文初始化权重 → 迭代：生成权重假设 → 代码评估聚合预测 → 计算 MAPE → 更新元记忆与学习。
