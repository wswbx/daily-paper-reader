## 摘要
数学表达式及其所产生的数值行为是同一底层函数的两种视角，将二者联系起来是科学发现的核心。符号回归（SR）直接依赖于这一联系：它搜索能够重现给定行为的表达式。近期的多模态模型通过将符号表达式及其数值行为嵌入到共享表示空间中来学习这一联系。我们表明，该嵌入空间仅在全局层面是对齐的：完整表达式对应完整行为，但表达式中各个部分的贡献并未被表示。这一粒度差距使模型无法判断对表达式的局部编辑如何改变其行为，而这正是符号回归的核心操作。我们提出一种组合式对齐方法以弥合这一差距：结构位置编码将表达式的子结构暴露给编码器，而多粒度对比目标则将每个子表达式锚定于其所产生的行为，再将这种锚定传播至完整表达式。由此得到的表示缩小了符号嵌入与数值嵌入之间的大部分模态差距，能够可靠地区分原始对齐方法无法区分的局部编辑效果，并可迁移至外部符号回归语料库。

## Abstract
Mathematical expressions and the numerical behavior they produce are two views of the same underlying function, and connecting them is central to scientific discovery. Symbolic Regression (SR) relies on this connection directly: it searches for an expression that reproduces a given behavior. Recent multi-modal models learn this connection by embedding symbolic expressions and their numerical behavior in a shared representation space. We show that this embedding space is only globally aligned: complete expressions correspond to complete behaviors, but the contribution of individual parts of an expression is not represented. This granularity gap leaves the model unable to tell how a local edit to an expression changes its behavior, the central operation in SR. We introduce a compositional alignment method that closes this gap: a structural positional encoding exposes the substructure of an expression to the encoder, and a multi-granularity contrastive objective grounds each subexpression in the behavior it produces before propagating this grounding to the full expression. The resulting representations close much of the modality gap between symbolic and numerical embeddings, reliably distinguish the effects of local edits that the original alignment cannot, and transfer to external SR corpora.

# SNIP++ 论文中文总结

## 1. 核心问题与研究动机

- **背景**：符号回归（SR）的目标是从数值观测中恢复出数学表达式，其本质是连接同一函数的两种视角——**离散的符号形式**（由算子与变量按树结构组成）与**连续的数值行为**（在有限输入点上的观测值）。
- **现有方法**：SNIP（Meidani et al. 2024）借鉴 CLIP，用双向 InfoNCE 对比学习将表达式与其数值行为嵌入同一共享空间，支持符号→数值与数值→符号两个方向的检索。
- **核心问题——粒度差距（Granularity Gap）**：
  - SNIP 将表达式序列化为前缀 token 序列，仅使用**顺序位置编码**与**整体池化表示**，因此父-子关系与子树归属对编码器不可见。
  - 监督信号只作用于**完整表达式层面**，无法表示表达式内部各组成部分（子树）的功能贡献。
  - 结果是模型无法判断"对表达式的局部编辑如何改变其行为"——而这恰是 SR 的核心操作。
- **整体含义**：作者主张，一个真正有用的共享空间应按**函数语义**组织符号形式：对等价重写保持不变，对改变行为的局部编辑保持敏感。这需要**细粒度、组合式**的功能接地，而非仅全局对齐。

## 2. 方法论

### 核心思想
在 SNIP 基础上做两项互补改造：(1) 用**树结构位置编码**让编码器感知表达式的组合结构；(2) 用**多粒度对比目标**将每个子树锚定到其产生的数值行为，并把这种接地传播到完整表达式。

### 关键技术细节

- **树结构位置编码（Tree PE）**：
  - 对每个节点记录从该节点到根的最近 L 步分支选择（第一子 / 第二子，用 (1,0)/(0,1) 表示；一元算子用第一子分支；填充为 (0,0)）。
  - 使用 C 个通道，通道 c 中第 k 层关系权重为 ρᶜᵏ，其中 ρc = tanh(θc) ∈ (−1,1)，保证更远祖先关系权重衰减；初始化 θc = artanh(0.5)，即 ρc = 0.5。
  - 各通道表示拼接得到 rv ∈ R^{2CL}，且令 2CL = d_model；实验中 L=64、C=4。
  - 输入嵌入变为 h⁽⁰⁾ᵢ = ei + qi + r_{v(i)}，即在 token 嵌入与顺序位置嵌入之上叠加结构编码。
  - **仅新增 4 个可学习标量参数**，不改变数值编码器、分词器、池化与投影头。

- **多粒度子树对齐（Local Objective）**：
  - 对每个训练表达式采样一个非平凡子树 s⁰，并生成 K 个受控扰动变体 s¹…sᴷ（三类编辑：一元算子替换、变量替换、二元算子替换）。
  - 对每个变体构造三种表示：
    - 上下文化符号表示 c（在父表达式中池化子树 span）；
    - 独立符号表示 o（子树单独编码）；
    - 数值表示 p（子树在共享输入上的输出）。
  - 局部损失 L_local = C_τs(C, P) + C_τs(O, P)，其中 C_τ 为双向对比损失，τs = 0.1。
  - 原始与扰动子树**对称处理**：每个扰动既是原件的难负例，也是自身数值行为的正例。

- **完整表达式对齐（Global Objective）**：
  - 将每个扰动子树拼接回父表达式得到 f_ik，构造完整表达式符号表示 gS 与数值表示 gV。
  - L⁺_global = C_τg(GS⁺, GV⁺)，τg = 1；上标 + 表示在原 SNIP 全局目标上扩展了扰动父表达式对。

- **最终目标**：L_full = L⁺_global + L_local，单阶段联合梯度下降优化；推理时冻结编码器，用法与 SNIP 完全一致。

## 3. 实验设计

### 数据与场景
- **训练数据**：在线使用 SNIP 表达式生成器生成（非固定语料），最大输入维度 10。
- **全局对齐评测**：100,000 个留出（held-out）表达式-行为对。
- **细粒度判别评测**：128 个留出表达式（过滤后 127 个），每个生成六类受控编辑变体。
  - **训练中出现过的三类**：一元算子替换、变量替换、二元算子替换。
  - **留出的三类**：树重塑（结合律重排）、操作数重排（a−b→b−a）、完整子树重写。
- **域外泛化**：三个外部 SR 语料库 Feynman、Classic、Strogatz 及其并集（有效过滤后完整表达式分别为 81/35/13/129）。
- **功能几何探针**（4 组）：
  - 连续功能变化（sin(cx) 族中 c 从 0.5 到 5）；
  - 保行为 vs 改行为编辑的相似度对比；
  - 等价代数重写 vs 近邻错误替代（七类恒等式族）；
  - 与 Taylor 截断近似的跨模态相似度。

### Benchmark 与对比方法
- **基准**：SNIP（在相同条件下重新训练）。
- **度量指标**：
  - 全局对齐：Recall@10、nDCG@10（f→y 与 y→f 双向）；
  - 模态差距：ℓ2 归一化后符号与数值嵌入质心的欧氏距离；
  - 细粒度判别：正确配对的**百分位排名**（0.5 为随机，1 为完美）；
  - 消融：nDCG@10、模态差距、表达式级与子树级百分位排名。
- **消融阶段**：S0=SNIP → S1=+Tree PE → S2=+上下文化子树对齐 → S3=+独立子树对齐 → S4=+对称扰动子树监督 → S5=+扰动父表达式传播（即完整 SNIP++）。

- **模型规模**：符号与数值编码器各 8 层 Transformer，d_model=512，FFN=2048，16 注意力头，共享 512 维潜空间；SNIP 约 67.2M 参数，SNIP++ 仅额外增加 4 个标量。
- **评测资源**：单张 H100-80GB、8 个 CPU 核心、64GB 内存；全部使用冻结编码器。

- **实验规模概览**：

  - **优点**：消融设计细致，能逐项归因各组件贡献；评测覆盖全局→局部→子树三个粒度；域外迁移覆盖三个独立策展的 SR 基准；使用 bootstrap 置信区间与配对比较。

## 6. 主要结论与发现

- **全局对齐大幅提升**：
  - f→y 的 nDCG@10 从 47.8% → **87.3%**，y→f 从 31.3% → **82.6%**；Recall@10 同趋势。
  - 方向间不平衡从 16.5 个百分点缩小到 **4.7** 个百分点。
- **模态差距显著缩小**：质心距离从约 **1.2 → 0.3**；PCA 显示 SNIP 第一主成分主导模态分离（35.0%），SNIP++ 前两主成分仅 6.5%/5.9%，方差分布更均匀，且 99% 方差所需维度从 91 降至 48。
- **细粒度判别显著改善**：平均百分位排名 f→y 从 .48 → **.73**，y→f 从 .69 → **.79**；12 个"编辑类型×方向"设置中 11 个优于 SNIP（唯一反例为 y→f 下的完整子树重写）。
- **子树级判别更强**：上下文化子树平均百分位 f→y 从 .47 → **.87**，y→f 从 .61 → **.92**，12 个设置全部显著更优。
- **域外迁移有效**：Feynman/Classic/Strogatz/并集上，全局对齐平均百分位 .79（SNIP 为 .47），表达式级细粒度 .69（SNIP 为 .48），且在所有语料与方向上均稳定高于随机。
- **功能几何更合理**：sin(5x) 与 sin(0.5x) 的相似度从 .94 降至 .06；保行为编辑保持接近、改行为编辑被分离；等价重写平均百分位 .72 → .90；与 Taylor 近似的跨模态相似度均值 .24 → .45。
- **消融结论**：仅加 Tree PE（S1）几乎无改善，说明**结构信息本身不足，需行为监督**；S2（上下文化子树对齐）带来最大跃升；S3 恢复逆向全局对齐；S4/S5 进一步平衡双向并传播到表达式层。

## 7. 优点

- **问题定位精准**：明确指出现有跨模态对齐的"粒度差距"，并从理论上拆解为三项需求（组件接地、功能敏感性、上下文相关贡献），方法与之逐项对应。
- **方法轻量且通用**：仅新增 4 个标量参数，不改变骨干架构、分词与池化，可即插即用地替换 SNIP 的对齐模块。
- **监督设计巧妙**：
  - 子树在"父上下文中"与"独立"两种视图下双重锚定，直接缓解数值→符号方向的多义性；
  - 对称处理扰动（既是难负例又是正例），充分利用编辑信息；
  - 从子树到父表达式的监督传播，使局部信号影响全局表示。
- **评测体系完整且克制**：明确使用冻结编码器隔离解码器/搜索偏差；评测粒度由粗到细递进；同时报告全局指标、模态差距与百分位排名。
- **泛化验证充分**：留出编辑族、外部语料、多种功能几何探针，均显示改进不局限于训练分布。
- **可解释性提升**：方差谱更平坦、模态交错更充分，为下游候选比较、搜索引导提供更合理的语义几何。

## 8. 不足与局限

- **未嵌入端到端 SR 系统**：论文聚焦表示质量本身，未验证其对完整生成/搜索流程（如符号搜索、解码器）的实际收益，作者亦将此列为未来工作。
- **评测样本规模有限**：细粒度判别仅 127 个目标表达式；Strogatz 仅 13 个，外部语料统计功效受限。
- **单一训练种子**：未报告多随机种子结果，超参数搜索范围较小，稳健性证据不足。
- **训练-评测分布同源风险**：主要评测表达式来自 SNIP 生成器（仅用不同随机种子），同分布性能可能被高估。
- **存在个别反例**：y→f 方向下完整子树重写的百分位排名未优于 SNIP，说明该类编辑的逆向对齐仍有改进空间。
- **应用限制**：方法依赖表达式树结构与可解析的子树采样；对含隐式约束、非树形结构或不可评估子式的场景适用性未讨论；训练需生成受控扰动，可能引入编辑族先验偏差。
- **可复现性细节**：PCA 图仅展示 800 对样本的可视化；部分阈值（如方差 ≥ 1e-10、float32 精确比较判等）可能影响"数值可区分"判定。
- **任务范围**：仅针对符号-数值两模态对齐，未与更广的多模态/代码表示方法（如 E-Graph、语义等价嵌入）做直接对比。
