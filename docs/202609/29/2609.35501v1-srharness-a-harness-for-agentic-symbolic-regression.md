## 摘要
近期的智能体符号回归方法日益依赖大语言模型来在长搜索轨迹中分析数据、选择科学操作并细化假设。在此类系统中，性能不仅取决于底层模型和搜索策略，还取决于支持科学搜索的运行时基础设施。我们提出 SRHarness，一种面向智能体符号回归的领域专用支撑框架，其构建围绕三种机制：可组合的科学操作，为原始量、变换量和候选衍生量提供统一接口；持久化的科学状态，保留已评估的假设并暴露紧凑的面向模型的视图；以及轨迹生命周期管理，协调延续、分支、重启和终止。在 LLM-SRBench 上，在匹配的 LLM 骨干模型下，SRHarness 持续提升数值泛化能力和符号恢复能力。使用 DeepSeek-v4-flash-0731 时，它在 LSR-Transform 上达到 93.69% 的符号准确率，而 SR-Scientist 为 62.16%；在移除科学描述和变量语义的匿名化变体上，它仍保持 72.97% 的准确率，而 SR-Scientist 为 39.64%。在相同的 DeepSeek-v4-flash-0731 骨干模型下，SRHarness 也显著优于 Codex（72.97% 对 20.72%），并达到与使用 GPT-5.5 的 Codex 相当的性能，而仅向 Codex 提供相同的科学工具并不能复现这一优势。这些结果表明，有效的智能体符号回归不仅取决于模型或工具，还取决于用于组织科学操作、累积假设和长时程搜索的结构化运行时支持。

## Abstract
Recent agentic symbolic regression approaches increasingly rely on large language models to analyze data, select scientific operations, and refine hypotheses over long search trajectories. In such systems, performance depends not only on the underlying model and search strategy, but also on the runtime infrastructure that supports scientific search. We introduce SRHarness, a domain-specific harness for agentic symbolic regression built around three mechanisms: composable scientific actions that provide a common interface over raw, transformed, and candidate-derived quantities; persistent scientific state that retains evaluated hypotheses and exposes compact model-facing views; and trajectory lifecycle management that coordinates continuation, branching, restart, and termination. On LLM-SRBench, SRHarness consistently improves both numerical generalization and symbolic recovery under matched LLM backbones. With DeepSeek-v4-flash-0731, it achieves 93.69% symbolic accuracy on LSR-Transform, compared with 62.16% for SR-Scientist, and retains 72.97% accuracy on an anonymized variant that removes scientific descriptions and variable semantics, versus 39.64% for SR-Scientist. Under the same DeepSeek-v4-flash-0731 backbone, SRHarness also substantially outperforms Codex (72.97% vs. 20.72%) and reaches performance comparable to Codex with GPT-5.5, while simply providing Codex with the same scientific tools does not reproduce this advantage. These results show that effective agentic symbolic regression depends not only on models or tools, but also on structured runtime support for organizing scientific actions, accumulated hypotheses, and long-horizon search.

## 1. 核心问题与整体含义
- **研究动机**：符号回归（SR）旨在从数据中发现可解释的数学表达式。近年方法从传统遗传编程发展到 LLM 引导、再到智能体式 SR：LLM 不再只是候选方程生成器，而是作为控制器，在长搜索轨迹中自主选择科学操作、分析中间证据并迭代假设。
- **核心问题**：此类智能体 SR 的性能不仅取决于底层 LLM 和搜索策略，还高度依赖支撑长时程科学搜索的**运行时基础设施**，即 agent harness。现有系统通常把工具、状态管理、轨迹管理等机制嵌入各自搜索策略中，导致跨系统比较时容易混淆“搜索策略差异”与“运行时支撑差异”。
- **整体含义**：论文主张 harness 应成为智能体符号回归的**一等组件**。SRHarness 试图提供可复用的领域专用运行时支撑，而不规定具体搜索策略，从而分离模型能力、搜索逻辑与执行支撑三层。

## 2. 方法论
- **核心思想**：围绕三个机制构建 SRHarness：可组合科学动作、持久科学状态、轨迹生命周期管理。
- **可组合科学动作**：
  - 将动作抽象为 \(r = A(q; \kappa)\)。其中 \(q\) 是智能体指定的科学量与选项，\(\kappa\) 是 harness 管理的持久执行上下文，如数据绑定、训练/验证划分、运行时配置。
  - 动作输入支持**表达式视图**，可作用于原始变量、变换量（如 \(\log x_i\)、\(x_i/x_j\)）或候选衍生量（如当前方程的残差 \(y-f(x)\)），无需物化新数据集。
  - 候选生成动作遵循统一的“候选—证据”契约，记录表达式、评估、复杂度、诊断证据与来源；harness 统一做有效性与评估语义检查后再准入状态。
  - 每个动作区分机器可读结果与返回给模型的紧凑观察，避免完整执行记录塞满对话上下文。
- **持久科学状态**：
  - 维护结构化科学状态 \(S_t\)，保存已评估候选及其数值评估、复杂度、证据和来源。
  - 状态跨对话轨迹持久：分支不再继续或对话重启时，已准入候选仍保留。
  - 模型看到的不是全量状态，而是有界投影 \(v_t = P_\rho(S_t)\)。实现中包括**拟合—复杂度 Pareto 视图**和 **Top-k 历史候选视图**。
- **轨迹生命周期管理**：
  - 支持继续、分支、重启、终止，并记录对话前驱、重启来源、跨分支信息传递等 provenance。
  - 参考实现采用 **R×C×L×K 调度器**：\(R\) 为重启轮数，\(C\) 为独立对话分支数，\(L\) 为细化深度，\(K\) 为局部响应采样数。
  - 算法流程：划分训练/验证集；每轮重启用 Top-k 状态初始化新对话；每个分支内最多细化 \(L\) 步；每步可采样 \(K\) 个响应，执行动作并评估准入；选最佳响应继续，其余样本中的诊断证据可合并；记录中间结果，完美拟合则提前返回，最终返回最佳候选。

## 3. 实验设计
- **Benchmark**：LLM-SRBench。论文称共 240 题，包含：
  - **LSR-Synth**：128 题，覆盖物理、化学、生物、材料科学，评估 ID 与 OOD 数值泛化。
