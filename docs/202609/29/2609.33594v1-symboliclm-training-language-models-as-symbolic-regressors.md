## 摘要
大语言模型（LLMs）在科学推理中已展现出颇具前景的能力，但科学发现最终要求直接从观测数据中推导出精确规律，即符号回归（SR）。由于概率式文本生成与 SR 对精确结构的要求之间存在差距，这给 LLMs 带来了挑战。现有方法依赖复杂的外部脚手架，不仅计算开销高昂，还将符号推理与模型本身割裂开来。为解决这一局限，我们提出通过专门的数值符号监督和物理监督，直接赋予 LLMs 符号回归能力。我们提出 PhysSymbArena，这是一个大规模基准，包含超过 160,000 个方程和 18 亿 token 的带物理描述的数值符号数据，可用于系统化训练与评估。基于 PhysSymbArena，我们开发了 SymbolicLM，通过数学与物理监督增强 LLMs 的符号回归能力。在推理阶段，我们进一步提出 SymbolicSGA，一种利用定量反馈迭代改进生成方程的细化框架。在多个符号回归基准上的实验表明，SymbolicLM 在保持有竞争力的数值拟合性能的同时，显著提升了结构恢复能力。这些结果表明，符号回归可以作为 LLMs 的一种内在能力被显式学习。

## Abstract
Large Language Models (LLMs) have shown promising capabilities in scientific reasoning, yet scientific discovery ultimately requires deriving precise laws directly from observational data, known as Symbolic Regression (SR). This poses a challenge for LLMs due to the gap between probabilistic text generation and the exact structural requirements of SR. Existing approaches rely on complex external scaffolds, which are computationally expensive and separate symbolic reasoning from the model itself. To address this limitation, we propose to directly equip LLMs with symbolic regression capabilities through dedicated numerical-symbolic and physical supervision. We introduce PhysSymbArena, a large-scale benchmark containing over 160,000 equations and 1.8B tokens of numerical-symbolic data with physical descriptions, enabling systematic training and evaluation. Based on PhysSymbArena, we develop SymbolicLM, which enhances the symbolic regression ability of LLMs through mathematical and physical supervision. During inference, we further introduce SymbolicSGA, a refinement framework that leverages quantitative feedback to iteratively improve generated equations. Experiments on multiple symbolic regression benchmarks show that SymbolicLM substantially improves structural recovery while maintaining competitive numerical fitting performance. These results demonstrate that symbolic regression can be explicitly learned as an intrinsic capability of LLMs.

## 1. 核心问题与整体含义

- **研究动机**：LLM 在科学问答、文献理解、数学推理等任务上表现突出，但真正的科学发现要求从观测数据中直接推导出精确的形式化定律，即符号回归（Symbolic Regression, SR）。

- **论文主张**：不应把符号回归完全外包给外部搜索，而应直接向 LLM 注入符号理解与从原始观测数据归纳规律的能力，使其将符号回归作为内在能力来学习。

### 2.3 SymbolicLM 训练流程

- **指令微调（SFT）**：
  - 输入提示由指令 \(I\) 和结构化数值观测 \(V_i\) 构成，表达式用前缀表示，如 `[add mul 2 sin x 3]`。
  - 使用标准 token 级交叉熵损失，建立“数值观测 → 符号表达式”的映射。
- **强化微调（RFT）与物理—符号奖励**：
  - 使用 GRPO，每个提示采样 \(G=8\) 个候选表达式，组内归一化奖励计算相对优势。
  - 设计五类奖励：
    - **解析有效性奖励**：SymPy 可解析得 1，否则 0。
    - **量纲一致性奖励**：满足量纲约束得 1，否则 0。
    - **结构相似性奖励**：将常数替换为占位符得到骨架，比较算子、非线性函数、变量、常数、结构序列、复杂度等六个特征，使用 Jaccard 或归一化相似度加权求和。
    - **符号等价奖励**：预测骨架与真实骨架完全一致得 1，否则 0。

- **推理阶段 SymbolicSGA**：
  - 改编自 SGA 的 ReAct 式框架，保留“利用”和“探索”两个分支。
  - 利用分支：在最佳父公式上做局部结构变异，如修改变量名或替换一元/二元项。

## 3. 实验设计

- **数据集 / 基准**：
  - **PhysSymbArena**：论文自建，160,000+ 方程，用于训练与评测。
  - **SRBench-Feynman**：119 个 Feynman 物理方程，评估已建立物理问题上的方程发现。
  - **LLM-SRBench-Transform**：变换后的符号回归任务，评估超出直接方程匹配的泛化能力。
- **对比方法**：
  - 传统 SR：AFP、AFP-FE、GP-GOMEA、GPLearn、PySR。
  - 神经符号回归：DSR、E2E、SNIP、TPSR。
  - LLM-based SR：LLM-SR、SGA。
  - 通用 LLM：Qwen3-8B、DeepSeek-V4-flash、Gemini-3.8-flash、GPT-5.5。
- **评价指标**：
  - \(R^2\)：决定系数，越高越好。
  - NMSE：归一化均方误差，越低越好。
  - Acc\(_\tau\)：最坏相对误差在容差 \(\tau\) 内的准确率，反映精确结构恢复。
- **主要实验结果**：
  - PhysSymbArena 上，SymbolicLM(SFT) 达到 \(R^2=0.7581\)、Acc=0.4375；加入 RL 后 Acc 提升至 0.4648；再叠加 SymbolicSGA 后 \(R^2=0.9056\)、Acc=0.5508。
  - SRBench-Feynman 上，SymbolicLM + SymbolicSGA 达到 \(R^2=0.9569\)、NMSE=0.0430、Acc=0.6470。
  - LLM-SRBench-Transform 上，达到 \(R^2=0.9481\)、NMSE=0.0519、Acc=0.4144。
- **消融实验**：
  - SymbolicSGA 对比原 SGA：\(R^2\) 从 0.9539 升至 0.9569，NMSE 从 0.0461 降至 0.0431，Acc 从 0.6218 升至 0.6471。
  - 物理信息消融：无物理信息时 \(R^2=0.7678\)、Acc=0.4297；有物理信息时 \(R^2=0.7582\)、Acc=0.4375。物理信息未提升数值拟合，但提升符号恢复准确率。

## 6. 主要结论与发现

- 符号回归可以通过专门的数值—符号与物理监督，被显式地学习和增强为 LLM 的内在能力。
- SFT 能显著提升通用 LLM 的符号回归表现；GRPO 结合物理—符号奖励进一步提升结构恢复准确率。
- SymbolicSGA 在推理阶段利用定量反馈迭代精炼候选结构，能有效纠正结构错误，显著提升精确符号恢复。
- 物理信息主要提供语义与结构指导，提升符号恢复准确率，但不一定直接改善数值拟合。
- 从 PhysSymbArena 学到的能力可泛化到 SRBench-Feynman 与 LLM-SRBench-Transform 等外部基准。
- SymbolicSGA 优于原始 SGA 的细化策略，更适合符号回归任务。
