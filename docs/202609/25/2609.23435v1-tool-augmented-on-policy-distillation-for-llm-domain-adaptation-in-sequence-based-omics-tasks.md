## 摘要
多组学序列包含复杂的生物学模式，但解析其机制以实现自动化科学发现仍具挑战性。当大语言模型（LLM）解读这些序列时，评估其预测与科学推理至关重要。然而，现有面向多组学序列任务的基准依赖分类和回归指标，忽视了模型是否掌握其背后的生物学证据。我们提出OmicsBench，这是首个面向多组学序列的推理基准，包含跨越DNA调控、RNA加工和蛋白质功能的六个任务中的1,160个经专家验证的问题。OmicsBench要求提供可追溯的证据链，并使用与领域专家共同制定的实例特定评分标准进行评估。对17个LLM的评估揭示了一种反向关系：尽管科学LLM在序列分类准确率上优于通用LLM，但它们未能提供有效证据来支持其预测。一种可能的解释是捷径学习：专用模型可能依赖统计模式，而非科学发现所需的生物学机制。受此发现启发，我们提出工具增强同策略蒸馏（TA-OPD），一种使序列预测与基于证据的生物学推理对齐的后训练方法。在涵盖0.8B至27B参数的五个Qwen3.5模型上，TA-OPD持续增强生物学证据基础，同时在大多数任务上提升预测性能。这些增益在不同模型规模上持续存在，表明更强的序列推理并非仅源于模型容量的增加，而是可通过证据感知训练得到提升。OmicsBench与TA-OPD共同为诊断多组学LLM中的推理失败提供了框架，并为构建其预测能更好地植根于具有生物学意义证据的模型指明了路径。

## Abstract
Multi-omics sequences contain complex biological patterns, yet deciphering their mechanisms for automated scientific discovery remains challenging. As large language models (LLMs) interpret these sequences, evaluating both predictions and scientific reasoning is critical. However, existing benchmarks for multi-omics sequence tasks rely on classification and regression metrics, neglecting whether models grasp the underlying biological evidence. We introduce OmicsBench, the first reasoning benchmark for multi-omics sequences, comprising 1,160 expert-validated questions across six tasks spanning DNA regulation, RNA processing, and protein function. OmicsBench requires traceable evidence chains, evaluated using instance-specific rubrics developed with domain experts. Evaluating 17 LLMs reveals an inverse relationship: while scientific LLMs outperform general-purpose LLMs in sequence classification accuracy, they fail to provide valid evidence to support their predictions. One plausible interpretation is shortcut learning: specialized models may rely on statistical patterns rather than the biological mechanisms needed for scientific discovery. Motivated by this finding, we introduce tool-augmented on-policy distillation (TA-OPD), a post-training method to align sequence prediction with evidence-grounded biological reasoning. Across five Qwen3.5 models spanning 0.8B to 27B parameters, TA-OPD consistently strengthens biological evidence grounding while improving predictive performance on most tasks. These gains persist across model scales, indicating that stronger sequence reasoning does not arise solely from increased model capacity, but can be improved through evidence-aware training. Together, OmicsBench and TA-OPD provide a framework for diagnosing reasoning failures in multi-omics LLMs and a path toward models whose predictions are better grounded in biologically meaningful evidence.

## 2. 方法论

### 2.1 OmicsBench：首个多组学序列推理基准

- **任务体系**：对齐分子生物学中心法则，分三大类共六个任务（N=1,160）：
  - DNA 调控：表观标记预测（EMP, 197）、启动子检测（Prom, 219）、转录因子结合位点预测（TFBS, 216）
  - RNA 加工：RNA 修饰预测（Mod, 101）、非编码 RNA 分类（ncRNA, 215）
  - 蛋白功能：酶功能预测（EC, 212）
- **构建流程（四阶段）**：
  1. **数据过滤**：以 Biology-Instructions（34,033 测试样本）为源，用余弦相似度 + coreset selection 保留代表性序列，再分层采样平衡标签，得 5,537 候选。
  2. **智能体合成**：Bio-Agent（Claude-Sonnet-4.5）调用领域工具（BLAST 同源检索、ViennaRNA 结构预测、JASPAR motif 扫描、PubMed API 文献检索）生成长文本推理链；Verifier Agent 执行"标签一致性 + 逻辑连贯性"双重校验，约 1,512 题通过。
  3. **专家验证**：3 位领域专家独立评审（科学准确性、证据相关性、推理完整性），多数通过者保留，最终 1,160 题。
  4. **评分标准构建**：遵循 "Define–Decompose–Scale–Verify" 工作流。

### 2.2 评估框架：Rubric Recall（RR）

- **分层评分结构**：
  - 任务级维度 $D_{\text{task}}$：专家为每类任务定义的通用评估"清单"（如 EC 的维度含同源证据、活性位点 motif、催化残基、底物特异性、反应化学）。
  - 实例级评分标准 $R_q = \{r_1, ..., r_k\}$，每条 $r = (d, E)$，其中 $d$ 为维度，$E$ 为从标准答案中抽取的原子证据单元集合（如"位置 −30 的 TATA box"、"BLAST E-value < 10⁻¹⁰"）。
- **公式**：
  $$\text{Rubric Recall}(q) = \frac{1}{|R_q|}\sum_{r \in R_q} \mathbb{1}(r \text{ is satisfied by } \hat{y}_q)$$
  某条 rubric 被判为"满足"当且仅当其中**至少一个**原子证据单元在模型输出中被还原。
- **评判协议**：LLM judge 依据三条标准判定证据还原——(1) 精确实体匹配（如 PDB ID 的字母数字对齐）；(2) 语义等价（接受保留生物学准确性的表述变体）；(3) 上下文有效性（证据须主动支持结论，而非误归因或幻觉），并校验定量约束（如"78% identity"满足"≥75%"阈值）。
- **抗刷分设计**：评分按维度数平均而非证据计数，避免堆砌文本；对抗性关键词注入测试显示，约 1,000 token 的术语堆砌模板响应在六个任务上得分均低于 1.2%。
- **数据规模**：1,160 题共 3,745 条 rubric 维度（约 3.2 条/题），由 11,392 个具体证据项支撑（约 3.0 个证据/维度）。

### 2.3 TA-OPD：工具增强同策略蒸馏

- **核心思想**：让 LLM 在不使用工具推理的前提下，从"会用工具的智能体"那里学习证据落地的推理能力。
- **技术谱系与设计**：
  - **OPD**：强外部教师逐 token 监督学生（仅最终答案不够）。
  - **OPSD**：教师与学生同源初始化（同一模型两份副本），教师独享 ground-truth 答案等特权信息，无需更大模型。
  - **TA-OPD**：在 OPSD 基础上，特权信息改为由工具增强的生物医学智能体（Biomni + DeepSeek-V4-Flash）分析同一序列后产出的**答案与支持证据**。教师冻结，仅更新学生权重。
- **训练信号**：对每个 token 计算"教师 log 概率 − 学生 log 概率"作为蒸馏信号，学生按自身策略生成响应后接受逐 token 引导，从而同时训练解释与预测。
- **数据门控**：采用"答案-标签一致性"门控，仅当智能体最终预测与真实标签一致时才纳入训练；解释允许含噪。采用固定种子的重采样缓解任务内标签不平衡。
- **优化细节**：采样 token 的 k=1 log-ratio 估计器 + 策略梯度优化 + AdamW；3% warm-up 后常数学习率 2×10⁻⁶，权重衰减 0.01；prompt 上限 8,192 token，响应上限 16,384 token。
- **训练集**：TA-OPD-10K 含 10,069 条记录（8,686 唯一输入），分布为 EMP 2,152 / Prom 1,784 / TFBS 1,670 / Mod 1,346 / ncRNA 1,678 / EC 1,439；已排除与 OmicsBench 评测输入完全相同的样本。

- **充分性评价**：
  - **优点**：模型覆盖面广（专有/开源/科学三类），任务覆盖中心法则三阶段，同时报告预测与推理两类指标，跨规模验证提升了结论可信度；去极值 + 多种子统计较为规范。
  - **不足**：**缺少消融实验**——未单独拆解 TA-OPD 中"工具证据""标签一致性门控""特权信息类型"等组件的贡献；未与朴素 SFT、标准 OPD、纯 OPSD 做同等条件下的受控对比；训练数据仅来自单一来源（Biology-Instructions）与单一智能体（Biomni + DeepSeek-V4-Flash）；评测任务仅 6 个、模型上限 27B。总体而言实验设计**客观性与公平性较好**（统一 prompt、统一 judge、统一种子协议），但**覆盖面与因果归因强度有限**。

## 6. 主要结论与发现

- **"推理退化"现象**：科学 LLM 预测强但证据弱；科学 LLM 平均响应仅 47 token，通用 LLM 为 857 token。家族内预测-推理相关性：通用模型 r=0.26（正相关），科学模型 r=−0.29（负相关）。科学 LLM 预测得分约为通用的 1.5 倍（12.11 vs 7.94），推理质量却仅约 0.2 倍（3.01% vs 13.76%）。
- **通用模型在 RR 上占优**：Grok-4 平均召回最高（21.10%），其次 Qwen3-Max（18.53%）、Gemini-3-Pro（16.17%）；六个任务的最高 RR 均由通用模型取得。
- **多组学能力高度不均衡**：无任何模型在六个 RR 列全部进入前三；DNA

DNA 调控类任务（EMP/Prom/TFBS）的 RR 普遍高于 RNA 与蛋白类任务，蛋白 EC 与 RNA 修饰 Mod 的 RR 最低，说明模型在需要跨模态（结构、化学反应、修饰化学）推理的任务上证据还原能力最弱；没有任何单一模型能在全部六项任务上同时领先。

- **TA-OPD 的改进效果**：
  - **推理显著提升**：在全部 5 个 Qwen3.5 规模上，TA-OPD 后 RR 均大幅上升，且增益随规模扩大而增大；小模型（0.8B）经蒸馏后 RR 可超过同家族大模型基线，说明"证据感知训练"可在一定程度上弥补参数量的不足。
  - **预测不退化、部分提升**：预测指标（MCC/AUC/Accuracy/Fmax）在多数任务上保持或小幅上升，未出现"重推理轻预测"的权衡，验证了同策略蒸馏在同时优化两类目标上的有效性。
  - **跨规模增益高度线性**：不同规模模型获得的 RR 增益与基线能力之间 Pearson r=0.99、Spearman ρ=1.00，表明 TA-OPD 的收益具有可预测的规模化行为。
- **核心论点得到支撑**：序列推理能力并非仅由模型规模决定，而是可以通过"工具增强的证据示范 + 同策略蒸馏"这类数据/训练侧手段显著改善；通用 LLM 在推理维度上反而优于科学专用模型，暗示当前科学模型的训练范式（纯监督映射）存在系统性偏差。

## 7. 可能的不足与局限

- **因果归因不够精细**：如前所述，缺少对 TA-OPD 各组件（工具证据、答案一致性门控、同源教师初始化、特权信息类型）的消融，无法确定增益主要来自"证据示范"还是"逐 token 蒸馏"本身。
- **评测规模有限**：OmicsBench 仅 1,160 题、6 个任务，每题 rubric 维度约 3.2 条，粒度较粗；RR 采用"至少一个原子证据被还原即满足"的宽松判定，可能高估模型的完整推理能力，也难以区分"部分还原"与"完全还原"。
- **评判依赖单一 LLM judge**：全部评分统一由 DeepSeek-V3.2 完成，未报告 judge 与人类专家的一致性（如 Cohen's κ）或多 judge 交叉验证，存在 judge 偏差与自洽性风险。
- **数据来源单一**：训练集仅源自 Biology-Instructions，且证据由单一智能体（Biomni + DeepSeek-V4-Flash）生成，分布与风格可能受限；虽然排除了与评测输入完全相同的样本，但同源数据仍可能带来潜在泄漏或风格过拟合。
- **模型规模上限有限**：TA-OPD 验证最高到 27B，虽引入 397B 作为外部参照，但未在超大模型上执行蒸馏实验，规模化结论的外推需谨慎。
- **长文本与算力成本**：prompt 8,192 + 响应 16,384 token 的配置，加上多工具调用与专家标注，整体成本较高，论文自述"成本高昂"却未给出量化，限制了方法的可复现性与可扩展性讨论。
- **评测任务偏静态**：所有任务为"给定序列 → 预测 + 解释"，未涉及交互式、多轮或需主动实验设计的科学发现场景，与论文引言中"自动化科学发现"的宏大目标之间仍存在距离。

## 8. 对领域的启示与未来方向

- **评测范式层面**：论文主张从"结果导向"转向"证据导向"评测，RR 与 OmicsBench 提供了一种可操作的模板——用任务级维度 + 实例级原子证据构建评分清单，并以抗刷分设计（按维度平均、对抗性关键词注入）保证度量有效性。这一思路可迁移到其他科学领域（化学、材料、临床）的 LLM 评测。
- **训练范式层面**：TA-OPD 展示了一条"不依赖更大模型、不依赖人工长链标注"的路线——用工具增强智能体充当教师，把"如何用证据支撑结论"的隐式能力蒸馏给学生。这对数据稀缺、标注昂贵的科学领域尤为重要。
- **模型设计层面**："推理退化"提示科学专用模型的微调目标可能过度偏向分类精度，牺牲了可解释性；未来科学 LLM 的训练应显式纳入证据落地目标，或在评测中把推理质量作为一等指标。
- **待解问题**：如何在推理与预测之间取得更优权衡；如何把工具使用能力真正内化到无工具推理的学生模型中；如何将证据导向训练扩展到多轮交互与实验设计；以及如何建立人类专家与 LLM judge 一致性的可靠校准机制。

## 9. 总体评价

论文以"发现问题（推理退化）→ 构建诊断工具（OmicsBench + RR）→ 提出改进方案（TA-OPD）"的完整闭环，回应了科学 LLM 在组学序列任务中"会答不会讲理"的痛点。其贡献在于：首次系统量化了科学模型预测强、推理弱的现象；提出可复用的证据导向评测框架；并验证了工具增强同策略蒸馏在提升推理能力上的有效性及可预测的规模化行为。主要短板在于消融不足、评测规模与 judge 可靠性有限、数据来源单一，使得方法增益的精确归因与结论外推仍需后续工作补强。总体而言，这是一项问题意识清晰、方法设计自洽、实验较为规范的工作，为可解释、证据可落地的科学 LLM 提供了有价值的路线图。
