## 摘要
符号回归（SR）旨在从数据中寻找简洁且可解释的数学表达式，以用于科学方程发现。现有符号回归基准在评估成本与基准有效性之间面临权衡。对大规模任务池进行重复评估成本高昂，而紧凑基准缺乏任务多样性与算法区分能力得以保留的系统性证据。SymbolicArena 为基准蒸馏与动态评估提供了统一基础设施。该框架标准化了 664 个具有可执行真实表达式的异构任务，并将完整任务集蒸馏为 Core50，一个经过验证的包含 50 个任务的基准。蒸馏过程在显式平衡约束下保留了任务覆盖度和算法区分度。SymbolicArena 对异构符号回归算法应用统一执行协议，并生成可比较的输出和搜索轨迹。多轴评估刻画数值质量、符号质量和搜索行为。Core50 将评估工作量减少 92.5%，并与完整任务集评估保持一致。实验表明，SymbolicArena 相比替代选择器实现了 72.6% 至 86.7% 的近似误差降低，进一步支持其对完整任务集的保真度。评估揭示了当前符号回归方法在数值拟合与符号恢复之间存在显著差距，表明可靠的方程恢复仍是一个开放挑战。

## Abstract
Symbolic regression (SR) seeks concise and interpretable mathematical expressions from data for scientific equation discovery. Existing SR benchmarks face a tradeoff between evaluation cost and benchmark validity. Repeated evaluation of large task pools is expensive, and compact benchmarks lack systematic evidence of preserved task diversity and algorithm discriminability. SymbolicArena provides a unified infrastructure for benchmark distillation and dynamic evaluation. The framework standardizes 664 heterogeneous tasks with executable ground truth expressions and distills the Full Task Set into Core50, a validated benchmark of 50 tasks. The distillation process preserves task coverage and algorithm discrimination under explicit balance constraints. SymbolicArena applies a unified execution protocol to heterogeneous SR algorithms and produces comparable outputs and search trajectories. Multi Axis Evaluation characterizes numerical quality, symbolic quality, and search behavior. Core50 reduces evaluation workload by 92.5% and maintains agreement with Full Task Set evaluations. Experiments show that SymbolicArena achieves 72.6% to 86.7% lower approximation error than alternative selectors, further supporting its fidelity to the Full Task Set. Evaluation reveals a substantial gap between numerical fitting and symbolic recovery across current SR methods, suggesting that reliable equation recovery remains an open challenge.

## 2. 方法论

### 核心思想
将紧凑 SR 基准构造视为**子集选择/蒸馏问题**，以任务结构属性 + 算法响应信号为输入，在覆盖度、信息量、分布平衡三重约束下选出代表性任务子集；同时以统一协议执行异构算法，并进行多轴评估。

### 关键流程（四阶段）

- **① 全任务集构建（Full Task Set, 664 任务）**
  - 从 800+ 候选任务（SRSD、LLM-SRBench、SRBench 1.0/2025、Keijzer、Korns、Nguyen、Vladislavleva）中筛选，准入条件包括：真值公式可解析可执行、变量/常量/算子一致、固定 train/ID/OOD 划分可用、元数据完整。
  - 统一 schema 记录：身份溯源、变量与目标、真值表达式（原始 + 归一化）、数据划分、结构元数据、语义去重组。
  - 复杂度按 Python AST 算子数定义：$C_i = N_{BinOp} + N_{UnaryOp} + N_{Compare}$，划分 Simple（≤5）、Moderate（6–8）、Complex（≥9）。

- **② 校准集挖掘（Calibration Set, 200 任务）**
  - 以 PySR 与 LLM-SR 为初始探针，用 ID/OOD 对数 NMSE 差值定义分歧分数 $G_i = \frac{|g^{id}_i| + |g^{ood}_i|}{2}$。
  - 含三组：高分歧 140、单侧可解 20、中等分歧 40，保证极端与中间区域均有覆盖。

- **③ 四探针选择**
  - 在 12 个候选算法中，以"校准可用性" $H_\alpha(a;\tau) = \alpha q(a) + (1-\alpha)[1-b_\tau(a)]$ 为目标（有限结果率 + 抗数值爆炸率，默认 α=0.5, τ=100）。
  - 约束覆盖至少 3 个主要范式，枚举全部 $\binom{12}{4}=495$ 个子集，唯一最优解为 $A_4 = \{\text{DSO, PyOperon, iMCTS, uDSR}\}$，覆盖神经策略搜索、进化搜索、结构化搜索。

- **④ Core50 蒸馏**
  - 四探针在 664 任务 × 3 随机种子上评估，计算任务信息量：
    $$\text{Info}_i = \text{Disc}_i \cdot \text{Stab}_i$$
    其中区分度由探针间中位误差方差与有效输出熵构成，稳定性由种子间 IQR 与有效比例构成。
  - 优化目标：
    $$J(S) = 0.45\,\text{Coverage}(S) + 0.35\,\text{MeanInfo}(S) + 0.20\,\text{Balance}(S)$$
    $$\text{Coverage}(S) = 0.6\,\text{StructuralCoverage} + 0.4\,\text{ResponseCoverage}$$
  - 硬约束：恰好 50 任务、每语义重复组/每 basename 至多 1 个、每子组至多 6 个、难度配额（4–10 easy、14–24 medium、12–22 hard、3–6 extreme）、失败模式上限、每家族配额 $t_f = n(\beta n_f/N + (1-\beta)/F)$，β=0.6。
  - 求解：贪心初始化 + 可行单任务交换，冻结最优子集为 Core50。

### 统一执行协议
- 每个算法用统一 wrapper 封装（fit / predict / get_optimal_equation），Conda 隔离环境 + 子进程沙箱 + 超时控制。
- 运行记录：算法、任务、种子、预算；每分钟快照记录原生最优表达式及其 ID/OOD 指标；测试集不参与候选选择。
- 形式化评测：50 任务 × 3 种子（520/521/522）× 180 分钟预算。

### 多轴评估（六轴，[0,1] 尺度）
- **数值质量**：ID、OOD，通过裁剪对数误差映射 $\phi(x) = \frac{\ell_{max} - r(x)}{\ell_{max} - \ell_{min}}$（$\ell_{min}=-12, \ell_{max}=2$）。
- **符号质量**：SYM（等价判断 + 树相似度/变量/算子 F1 的几何组合）、MIN（$m_{MIN} = \min(1, C_{ref}/C_{pred})$）。
- **搜索行为**：EFF（检查点质量积分归一化到单次运行峰值）、STAB（数值一致性 × 有效比例 × 结构一致性的几何平均）。
- 符号后处理由 Opus 5 完成（简化、等价判断、结构判断），处理结果在指标聚合前冻结。

## 6. 主要结论与发现

- **Core50 高效且保真**：
  - 评测工作量降低 **92.5%**；
  - 聚合分数 MAE 仅 **0.1388**，相比 6 个替代选择器降低 **72.6%–86.7%**；
  - 9 算法跨规模秩相关：ID **ρ = 0.9833**、OOD **ρ = 0.9667**；3 个验证算法的 OOD 排序完全保持，ID 仅一对换序。
- **保真度来源于覆盖 + 信息量的协同**：仅优化信息量（top-information）或仅优化难度平衡（difficulty-balanced）反而产生更大 MAE；仅匹配来源比例也不够。
- **无算法在所有维度占优**：iMCTS 领先 ID/OOD，FePySR 领先 SYM/MIN，JAXSR 领先 EFF/STAB，PySR 在数值与符号四项均居第二；各算法呈现明显的"能力特化"。
- **数值拟合 ≠ 符号恢复**：iMCTS 数值领先但 SYM 仅 42.15；Nguyen-9 案例中 NMSE 低至 4.54×10⁻¹⁵，仍被判定为 not_equivalent（mSYM=0.4886）。
- **搜索行为 ≠ 解的质量**：JAXSR 的 EFF/STAB 接近满分但 ID/OOD 中等；高 EFF 可能只是早期达到的有限峰值，高 STAB 只代表可重复性。
- **轴间相关性结构支持多维评估**：ID-OOD 强相关（0.98），SYM-MIN 强相关（0.82），但 EFF/STAB 与数值质量几乎不相关（−0.08/−0.06）。
- **噪声鲁棒性差异显著**：iMCTS 在噪声下仍保持最高 OOD，但绝对下降大（Δ5%≈−32.6）；DSO、gplearn 下降极小（≈−1）。

## 7. 优点

- **问题建模清晰**：将紧凑基准构造显式形式化为带约束的子集选择/蒸馏优化问题，给出可复现的目标函数与约束体系。
- **构建过程可审计**：探针选择、校准集挖掘、Core50 选择均有完整的敏感性分析（重采样、规则扰动、成员移除、权重扰动），并报告稳定的核心任务集（5000 次采样中 37 个任务被全选）。
- **统一执行协议**：隔离环境 + 子进程沙箱 + 统一 wrapper，解决了异构 SR 算法（进化/神经/Transformer/LLM）难以公平比较的问题。
- **多轴评估体系**：突破"只看最终误差"的局限，将数值质量、符号质量、搜索行为分离，并用相关性分析实证其非冗余性。
- **LLM 使用有信息隔离设计**：搜索用 LLM 与评估用 LLM 严格分离，搜索模型无法访问真值与测试集；对 SRSD 干扰变量采用语义角色掩码，防止信息泄漏。
- **可复现性强**：固定任务清单、数据划分、种子、预算、配置，符号判断冻结并保留哈希与提示版本，声明材料包含清单、脚本、配置。
- **验证算法独立于构建**：FePySR/SymbolFit/JAXSR 排除在构建之外，提供额外的保真度证据。

- **案例研究的代表性**：Nguyen-9 数值-符号差距案例虽具说明力，但属于单点轶事证据；论文未系统统计"低 NMSE 但 not_equivalent"在 Core50 上的发生频率，因而"数值拟合 ≠ 符号恢复"更多是定性揭示而非量化定律。

- **时间预算的单一性**：形式化评测固定 180 分钟预算，未报告不同预算下的排名稳定性。对于收敛速度差异大的算法（如 LLM 辅助搜索 vs. 进化搜索），固定预算可能系统性偏袒某一类范式。

- **缺少与既有紧凑基准的直接对照**：论文主要对比的是"从同一全任务集蒸馏出的替代选择器"，而非与 SRSD、SRBench 等既有基准本身的规模-保真度权衡做横向比较，因此"Core50 优于现有紧凑基准"这一主张的证据链相对间接。

## 9. 总体评价与启示

- **定位**：SymbolicArena 的贡献主要在于**基础设施与评测方法学**，而非提出新的 SR 算法。其价值在于把"紧凑基准该怎么做"从经验性拼凑提升为可复现、可审计、带约束的优化问题，并配套统一执行协议与多轴指标。

- **方法学亮点**：以"探针响应信号"驱动任务选择（而非仅靠静态元数据），使被选任务天然具备算法区分度；用"覆盖度 + 信息量 + 平衡"三目标的加权组合避免单一维度退化；用敏感性分析量化核心任务集的稳定性（5000 次采样中 37 任务恒被选中），这在基准类论文中较为少见。

- **核心实证发现的意义**：
  - "数值拟合 ≠ 符号恢复"呼应了 SR 领域长期存在的隐忧——高精度插值未必等价于正确结构发现，提示未来评测与算法设计都应把符号等价性置于与数值误差同等重要的位置。
  - "搜索行为 ≠ 解的质量"（EFF/STAB 与 ID/OOD 近乎不相关）说明搜索过程指标不应被当作性能代理，而应作为诊断工具使用。
  - "无算法全维占优、能力特化明显"则支持按应用需求（追求精度 / 追求可解释 / 追求稳定复现）选择算法，而非追求单一排行榜。

- **对后续工作的启示**：
  - 需要**跨分布的外部验证**——在新领域、新算子族上重做保真度检验，才能确认 Core50 的可迁移性。
  - 需要**更形式化的符号等价判定**——降低对 LLM 判断的依赖，或至少给出判断一致性度量与冲突消解规则。
  - 需要**预算敏感性研究**——报告不同时间/评估预算下的排名稳定性，避免固定预算带来的范式偏袒。
  - 需要**更完整的成本披露**——包括硬件配置、总机时与能耗，以便社区评估基准的可持续性。

- **一句话结论**：SymbolicArena/Core50 在"评测成本—基准保真度"这一两难上给出了一个工程上扎实、方法上可审计的解法，并通过多轴画像暴露了 SR 领域数值与符号能力脱节的关键缺口；但其外部有效性、符号判定的形式化程度与成本透明度仍是需要后续补齐的短板。
