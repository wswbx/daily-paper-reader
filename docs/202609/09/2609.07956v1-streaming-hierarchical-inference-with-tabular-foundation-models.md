## 摘要
表格基础模型（TFM）近期通过上下文学习展现了强大的预测性能，但受限于通信开销和延迟，其在高吞吐量数据流中的部署仍具挑战性。我们提出了一种名为HINT的层次化推理框架，将基于边缘的检索与基于云的TFM推理相结合。该框架维护一个基于图、滑动窗口之上的近似最近邻记忆，以提供本地预测和不确定性估计，从而允许高置信度样本在本地处理，而将不确定实例及其检索到的上下文选择性卸载至云端托管的TFM。该框架提供卸载阈值和邻域检索策略，可通过调整以平衡预测性能与通信成本。实验表明，HINT能持续识别出有利的权衡方案。

## Abstract
Tabular Foundation Models (TFMs) have recently demonstrated strong predictive performance through in-context learning, but their deployment in high-throughput data streams remains challenging due to communication overhead and latency. We propose \textit{HINT}, a hierarchical inference framework that combines edge-based retrieval with cloud-based TFM inference. A graph-based approximate nearest neighbor memory maintained over a sliding window provides local predictions and uncertainty estimates, allowing confident samples to be processed locally while uncertain instances are selectively offloaded, together with their retrieved context, to a cloud-hosted TFM. The framework exposes an offloading threshold and a neighborhood retrieval policy that can be varied to balance predictive performance and communication cost. Experiments show \textit{HINT} consistently identifies favorable trade-offs.

- **研究背景**：表格基础模型（TFM，尤其是TabPFN）通过上下文学习（in-context learning）无需微调即可完成分类，开辟了流式持续学习的新方向。但TFM属于CloudML类别，推理依赖云端服务器，在高吞吐量、实时性要求高的IoT数据流场景中，面临严重的通信开销与延迟瓶颈。
- **核心矛盾**：
  - 流式学习需要实时处理，而TFM的单次推理需要将标签集（上下文）连同查询样本一起传输到云端；
  - 传统增量决策树（IDT）等方法可以在边缘运行，但表征能力有限，无法捕捉复杂依赖。
- **核心问题**：能否构建一种机制，让大多数简单样本在边缘低成本处理，仅将困难样本有选择性地卸载至云端TFM，从而在预测性能与通信成本之间取得可调平衡？
- **整体含义**：该工作属于从“模型压缩”（模型侧）转向“数据选择与通信压缩”（数据侧）的范式转变——核心不在于让模型变小，而在于减少推理所需传输的信息量。

### 2. 方法论：核心思想、关键技术细节

#### 核心思想：分层推断（Hierarchical Inference）
HINT构建了边缘-云两级推断流水线：
- **边缘端**：维护一个基于图结构的、滑动窗口上的近似最近邻（ANN）记忆库，通过kNN加权投票做本地预测，同时给出置信度估计。
- **云端**：当本地置信度低于阈值θ时，将该样本及其检索到的k个邻居上下文一起卸载至云端的TabPFN进行上下文学习推理。

#### 关键技术细节

**（1）图结构：SWINN（Sliding Window NN-graph）**
- 基于NN-Descent初始化，维护一个有向加权图 Gt = (Vt, Et)，每个顶点对应窗口Wt中的一个实例；
- 每个顶点最多K条出边，权重为用户指定的距离度量；
- 滑窗操作：
  - **初始化**：缓冲L个实例，达到窗口上限后用随机出边建图并迭代细化；
  - **插入**：在图内执行K-NN搜索，将新顶点连接至其K个近邻，更新反向邻域；
  - **删除**：滑窗满时移除最旧顶点及其关联边，对受影响邻域执行局部修复与细化；
- 三个核心算子：
  - **Search**：贪心最佳优先遍历，用min-heap存候选项、max-heap存当前K近邻；
  - **Refinement**：基于“邻居的邻居可能是邻居”，在总邻域内做连接操作替换边；
  - **Pruning**：基于三角形规则移除冗余最长边，控制内存并保持可达性。

**（2）本地预测与置信度**
- 类j的加权支持度：sj(x) = Σ 1(yi=j)·w(x,xi) / Σ w(x,xi)，w(x,xi) = d(x,xi)⁻¹；
- 预测标签 ŷ(x) = argmax_j sj(x)；
- 置信度 p(x) = s_ŷ(x)(x) ∈ [0,1]。

**（3）卸载决策与上下文调度**
- **卸载规则**：当 p(x) < θ 时卸载至云端TFM，否则本地接受预测；
- **邻域大小策略**：k(t) ∈ {5, 10, 20, 40} 按调度变化，维护两种并行kNN模型（固定k_min=3 和调度k(t)），在线选择累计精度更高者做本地预测；
- **成本函数**（通信-误差代理）：
  - Cost_i(t) = β(1+k_t) + η_i（若卸载且服务器判错） 或 γ_i（若本地处理且本地判错）；
  - β控制通信成本与预测误差的相对权重；
  - 作者声明该成本是简化代理，不包含实际网络延迟、传输能量等部署相关因素。

### 6. 主要结论与发现

- 在θ=0.7时，HI在5/6数据集上优于ARF，且仅在16%～54%的样本卸载率下即达到该效果；
- 与纯本地推测相比，HI在所有数据集上都大幅提升了准确率（最显著的是在POSTURE上，ARF退化为多数类预测BAC为0.285，而HI的平均BAC提升至0.555）；
- HI在所有数据集上均形成相对清晰的Pareto前沿，准确率先快速上升，随后在中等成本区饱和——仅需适度卸载即可获得接近全卸载的准确率，无需全部卸载；
- 成本灵敏度β系统性地控制Pareto前沿的形状与位置：
  - 低β → 倾向更多卸载；高β → 偏好低成本低准确率的策略；
- 当β≥0.27时，HI的总通信-误差成本可低于全卸载，最大可实现约35%的成本降低；
- k(t)的影响取决于记忆窗口大小：窗口较小且通信成本高（β=0.5）时更大的k(t)没有收益；窗口较大且通信成本低（β=0.1）时更大的k(t)提供额外精度收益，且有助于让云端TFM更有效地利用传输的上下文；
- 总体而言：分层推理能够以少量通信换取接近上界的预测性能，较之传统流式方法（ARF）也有显著优势。在所选代价-精度折衷区间内，存在一个“甜点区”，在中高θ值下实现接近上界的精度并大幅降低通信量。

### 7. 优点

- **方法设计简洁而灵活**：在边缘侧使用带滑动窗口的图ANN结构，将“局部预测器”与“上下文选择器”合二为一，避免额外的模型训练；仅通过两个标量参数（θ和k(t)）即可控制通信-精度权衡；
