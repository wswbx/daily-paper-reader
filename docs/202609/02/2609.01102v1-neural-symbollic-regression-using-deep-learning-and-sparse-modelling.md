## 摘要
符号回归（SR）旨在发现能够表示数据内在关系的简洁数学表达式，其可解释性和科学理解性超越了黑盒模型。然而，遗传编程等传统方法面临可扩展性挑战且对噪声高度敏感，而SINDy等稀疏回归技术则严重依赖预定义的特征库。本文提出了一种神经符号回归（NSR）框架，将神经网络视为符号发现的函数预处理器。我们的方法采用解耦流水线：神经网络首先在交互感知的非线性特征空间中学习目标函数的平滑、抗噪近似。然后应用LASSO提取稀疏、可解释的闭式表达式。为提升预测精度和符号保真度，我们结合Ray Tune和ASHA调度进行分布式超参数优化。在Nguyen基准测试集上的实验表明，我们的方法在RMSE、噪声鲁棒性和分布外泛化方面始终优于SINDy和未调优的神经基线。消融研究证实了特征交互、神经网络深度和调优策略的重要性。总体而言，本研究提出了一种可扩展且可理解的神经符号框架，为科学机器学习中神经逼近与稀疏方程发现之间建立了坚实桥梁。

## Abstract
Symbolic Regression (SR) seeks to find succinct mathematical expressions that represent the fundamental relationships within data, providing interpretability and scientific understanding that exceeds that of black-box models. Nevertheless, traditional methods like Genetic Programming face challenges with scalability and are highly sensitive to noise, while sparse regression techniques such as SINDy rely significantly on predetermined feature libraries. In this work, we present a Neural Symbolic Regression (NSR) framework that treats neural networks as functional preconditioners for symbolic discovery. Our approach uses a decoupled pipeline: a neural network first learns a smooth, noise-robust approximation of the target function in an interaction- aware nonlinear feature space. LASSO is then applied to extract sparse, interpretable closed-form expressions. To improve predictive accuracy and symbolic fidelity by integrating distributed hyperparameter optimization with Ray Tune and ASHA scheduling. Experiments on the Nguyen benchmark suite show that our approach consistently outperforms SINDy and non-tuned neural baselines in RMSE, noise robustness, and out-of-distribution generalization. Ablation studies confirm the significance of feature interactions, neural depth, and tuning strategies. In general, this study presents a scalable and understandable neural-symbolic framework, creating a solid link between neural approximation and the discovery of sparse equations for scientific machine learning.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：如何从数据中自动发现可解释的符号表达式，同时兼顾精度、可扩展性和抗噪能力。
- **已有方法的不足**：
  - **遗传编程（GP, Koza）**：表达能力强，但收敛慢、易出现代码膨胀、计算代价高，且对噪声高度敏感，难以扩展到高维/大规模数据。
  - **稀疏回归（如SINDy）**：将符号发现转化为特征库上的稀疏回归问题，规避了组合爆炸，但其有效性严重依赖预先人工设计的特征库是否完整覆盖目标函数的基底。
  - **端到端神经符号方法（DSR、神经SR）**：将函数逼近和符号搜索耦合在同一优化过程中，虽然灵活，但训练不稳定、计算开销大、可解释性难以保证。
- **本文的重新定位**：不把神经网络当作直接生成符号公式的工具，而是将其视为**“函数预处理器”**（functional preconditioner）——先用神经网络获得平滑、抗噪的函数近似，再通过稀疏回归从中提取符号表达式。两个阶段严格解耦，从而在可解释性、噪声鲁棒性和扩展性之间取得更好的平衡。

## 2. 提出的方法论：核心思想、关键技术细节与流程

**核心思想**：
> 既然噪声会干扰符号结构的可辨识性，那么先用神经网络把观测“清洗”成适合稀疏恢复的表示，再在表示空间中用 LASSO 找出简洁的闭式公式。神经网络的职责是平滑，不是生成符号。

**技术细节**：

1. **非线性特征库构建**
   - 基础函数集合：F = {id, sin, cos, exp, log(1+x), x², x³, tanh}。
   - 主特征库：将 F 应用于每一输入维度。
   - 二阶交互项：加入跨维度成对乘积 {fₚ(xₐ)·f_q(x_b) | a≠b}，使库能够表达特征间的交叉影响。
   - 总维度规模：O(kd + k²·C⁽d,₂⁾)，并用 Joblib 并行构建。

2. **神经网络逼近**
   - 输入为完整特征矩阵 Φ_full(X)，网络结构为 MLP（宽度 H ∈ {32,64,128}，深度 L ∈ {1,2,3}）。
   - 激活函数用 ReLU/GELU，配合 dropout 和权重衰减；采用 AdamW 优化器。
   - 训练目标含 L2 正则：L = MSE(fθ(Φ(x)), y) + α‖θ‖₂²。
   - 支持 CUDA 与 Apple MPS 后端加速。

3. **LASSO 稀疏符号提取**
   - 训练后的神经网络输出/中间表示被用作目标变量，然后对特征库做稀疏回归：β* = argmin ‖Φ_full(X)β − y‖₂² + λ‖β‖₁。
   - 非零系数的项即视为构成符号表达式的活跃元素；用 SymPy 将这些项重建成解析表达式。
   - 该方法依据压缩感知理论：若 Φ_full 满足 RIP 条件，稀疏系数可被精确恢复。

4. **超参数优化**
   - 用 Ray Tune + ASHA 调度器（从早停前 20 个并行 trial 中筛除劣势 trial：若 mᵢ < γ·median(m) 则淘汰/晋升）。
   - 搜索空间覆盖：学习率 η ~ LogUniform(10⁻⁴, 10⁻²)、宽度 {32,64,128}、深度 {1,2,3}、λ ∈ {10⁻⁴, 10⁻³, 10⁻²}、批大小 {32,64,128}。
   - 目标是优化验证集 RMSE。

**算法流程（NSR 流水线）**：
1) 输入——给定数据 (X, y)；
2) 构建原始非线性特征 Φ(X)；
3) 添加成对交互特征 Φ⁽²⁾(X)，合并成完整库 Φ_full；
4) 在 Φ_full 上训练 MLP 作为平滑逼近器；
5) 用 LASSO 提取稀疏系数 β；
6) 用 SymPy 将活跃项还原为解析表达式 f*(x)。

## 6. 论文的主要结论与发现

- **NSR 在多数 Nguyen 基准上一致优于 SINDy 和未调优神经网络基线**，体现了解耦神经-符号流水线的优势。
- **符号恢复质量良好**：例（Nguyen-3）真实函数为 f(x) = x⁵+x⁴+x³+x²+x，NSR 提取结果为 1.002x⁵ + 0.998x⁴ + 1.001x³ + 1.000x² + 0.999x，结构上几乎与真值一致。
- **噪声鲁棒性显著提升**：在 σ 增大过程中，NSR 的 RMSE 增大更缓慢，优于 SINDy（得益于神经网络的平滑作用）。
- **OOD 泛化能力更强**：在 [−2,2] 测试域上，NSR 仍能保持较好的预测一致性，而 SINDy 出现明显偏离。即神经网络学到的潜在映射捕捉了本质函数形式，而不仅是记忆训练样本。
- **Ray Tune + ASHA 的超参优化是必要的**：调优后模型收敛更快、最终损失更低、符号更简洁，消融中无调优参数时 RMSE 从 0.004 升至 0.019、活跃项数升至 7（产生了冗余）。
- **每个模块都承担独立角色**：去掉交互项（RMSE 0.037）、减小特征库（0.142）、变浅网络（0.081）都会明显降低精度，验证了完整设计的必要性。

## 7. 优点

- **思想层面的清晰性**：把神经网络定为“函数预处理器”而不是“符号生成器”，重新定义了神经符号回归中神经网络应当扮演的角色；解耦流水线在不牺牲可解释性的前提下提高噪声鲁棒性和符号可辨识性。
- **支持交互项的特征库设计**：在传统 SINDy 多项式库中引入“基础函数×基础函数”的二阶交互，能表达跨维度耦合关系，扩展了特征库的表达力同时保持稀疏兼容性；每个模块在整个流水线里的作用都有相应消融验证。
- **符号恢复与精度兼顾**：得出的是闭式解析解而非黑箱模型，配以 SymPy 自动重建表达式，在目标变量可微分/可测量的科学场景中实施性强。
- **利用成熟工程工具**（Ray Tune、ASHA、Joblib、GPU/MPS），直接将超参数搜索融入符号回归流程，为可复现性提供了现成的实现框架。
- **复杂度分析较为全面**：对比了 GP、SINDy、NSR 的时间和空间复杂度，承认并系统评估了特征库增长所造成的瓶颈。

## 8. 不足与局限

- **特征库的过强依赖**：符号表达能力仍受限于预定义基础函数，若目标函数中包含库外基底（如特殊函数或复合构造）则无法被 LASSO 以线性项的形式恢复；二阶交互使库的维度 O(k²d²) 迅速膨胀，在高维场景中内存消耗和组织难度非常高。
- **数值一致性与可复现性不足**：主对比结果中 Nguyễn-3 在正文与表格之间显著不一致，Nguyen-6/7 指标缺失；OOD 实验只覆盖一个函数，难以形成稳健断言；未报告多次运行的误差区间，难以判断差异的统计显著性。
- **基线设置有待更公平**：SINDy 没有像 NSR 那样经过调优和交叉验证，PySR 也只是单次报告，未进行充分对照；神经网络的“光滑性假设”对不连续或分段函数场景未必有效。
- **LASSO 偏差问题**：LASSO 会对强相关特征产生压缩偏置，特征库内部结构存在线性相关性会导致估计系数失真，文中未处理特征之间相互依赖的退化问题。
- **训练开销增加**：调优后的 NSR 运行时间为 SINDy 的约 35 倍（42.7s vs 1.2s，按照文末数值），同时仍然只对低维合成基准做了验证，尚未在真实噪声场景或高维系统上做过测试。
- **缺乏与最新神经符号方法（如 DSR、AI Feynman）的直接对比**：即使提及这些方法，并未给出横比数字，与最先进方法（State-of-the-art）的对比说服力有待加强。
