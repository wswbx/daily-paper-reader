## 摘要
当每一张表都定义一个新的监督任务时，表格基础模型应当学习什么可复用的计算？我们提出原位表示精炼：支持集标签引导对当前 episode 表示的更新，而这些更新在不改变模型参数的情况下迁移到未标注查询。一个正则化的留一目标导出支持集校正及其查询扩展。主导项将基于注意力的读取与状态相关缩放分离开来，从而启发了 RefineICL：一种注意力门控、无 FFN 的上下文堆叠，并带有选择性低秩特征交互与类型化记忆。RefineICL-L24 在 AMLB29 上达到 0.93836 的 OVR-AUC 和 0.87173 的准确率。一种基准信息驱动的继续训练在 38 个数据集的 TabArena 快照上达到 1644.8 Elo，在相同评估下比 TabPFN-3 高 31.4 Elo。在 TabZilla 的两个视图上，它还在全部四项报告指标上优于 TabPFN-v3。在匹配的 100K 更新深度网格中，扩展的 FFN 没有带来一致的验证收益，并且在 L8 时多使用 60.2% 的峰值推理内存。内部干预表明，支持集表示不仅仅是静态的标签来源：在保持查询输出不变的情况下，移除一个中间支持集更新，会使所有 72 个测试 episode 的最终查询交叉熵增加。综合起来，推导与干预共同解释了注意力门控更新如何在上下文中构建任务特定的预测器。

## Abstract
What reusable computation should a tabular foundation model learn when every table defines a new supervised task? We develop in-situ representation refinement: support labels guide updates to the episode's representations, and these updates transfer to unlabeled queries without changing model parameters. A regularized leave-one-out objective yields a support correction and its query extension. The leading term separates attention-based reading from state-dependent scaling, motivating RefineICL: an attention-gated, FFN-free contextual stack with selected low-rank feature interaction and typed memory. RefineICL-L24 reaches 0.93836 OVR-AUC and 0.87173 accuracy on AMLB29. A benchmark-informed continuation reaches 1644.8 Elo on the 38-dataset TabArena snapshot, 31.4 Elo above TabPFN-3 under the same evaluation. It also improves all four reported metrics over TabPFN-v3 on both TabZilla views. In a matched 100K-update depth grid, an expanded FFN gives no consistent validation benefit and uses 60.2% more peak inference memory at L8. Internal interventions show that support representations are more than a static source of labels: removing one intermediate support update, while preserving the query output, increases final query cross-entropy in all 72 tested episodes. Together, the derivation and interventions explain how attention-gated updates can construct a task-specific predictor in context.

## 1. 核心问题与整体含义

- **核心问题**：表格基础模型（Tabular Foundation Model）将监督学习转化为一次前向计算——把带标签的行作为上下文，由预训练网络预测剩余行。但每一张新表都定义了一个新的监督任务，因此一个更基础的问题是：**什么样的可复用计算，能把一张带标签的表转化为其对应的预测器？**
- **现有视角的不足**：在语言建模中，Transformer 的 FFN 可被视为参数化的键值记忆；但表格 episode 的任务信息来源不同——特征含义、类别身份、决策边界都可能变化，任务监督由支持集（support）行提供。已有的"上下文学习即优化"视角虽表明 Transformer 能模拟梯度下降或闭式预测器更新，但多局限于受限设定。
- **整体含义**：论文主张，参数应编码"跨表恢复预测器的过程"，而上下文定义当前表的预测器。作者提出**原位表示精炼**（in-situ representation refinement）：支持集标签引导对当前 episode 表示的更新，这些更新在不改变模型参数的情况下迁移到未标注查询。这为理解表格 ICL 提供了一种建设性的、可实验检验的解释。

## 2. 方法论

### 2.1 核心思想

- 不假设参数空间中存在一个优化器，而是**推导带标签样本如何重塑当前 episode 的表示**。
- 在支持集表示上定义一个**类别分离目标**（留一监督邻域目标），对其进行正则化局部优化，得到支持集校正，再通过核扩展迁移到查询。

### 2.2 关键技术细节与公式流程（文字说明）

1. **留一目标（类别分离）**：
   - 设支持集状态 $Z = [z_1,\dots,z_n]$，相似度 $\kappa(z_i,z_j)=\exp(\tau z_i^\top z_j)$。
   - 对每个支持行 $i$，用其他行（排除自身）的归一化相似度加权，计算其正确类邻居质量 $q_i(Z)$。
   - 目标函数 $J(Z) = -\frac{1}{n}\sum_i \log q_i(Z)$，即正确类邻居质量的对数负值；要求每类至少两个支持样本。

2. **支持集更新方向**：梯度下降方向 $F = -\nabla_Z J(Z) = [f_1,\dots,f_n]$，其中 $f_i$ 由支持标签、邻域误差和当前表示共同决定，并非 $y_i$ 的固定编码——它随 episode 表示变化而变化。

3. **命题 1（降低目标的支持更新）**：
   - 设 $K$ 为支持 Gram 矩阵（加对角项 $\epsilon I_n$），$\alpha>0$ 为正则化强度，$\beta$ 为平滑常数。
   - 正则化局部目标的解为 $U^* = F K(\beta K + \alpha I_n)^{-1}$，且 $J(Z+U^*)-J(Z) \le -\frac{1}{2}\langle F,U^*\rangle \le 0$，即该校正局部降低 episode 目标。

4. **查询扩展（核迁移）**：
   - 对查询状态 $z_q$，定义 $k_q$，平滑核扩展为 $u(z_q) = F(\beta K+\alpha I_n)^{-1}k_q$。
   - 当 $\beta\|K\|_2/\alpha$ 较小时，主导项为 $u(z_q)\approx \frac{1}{\alpha}\sum_i \kappa(z_q,z_i) f_i$。
   - 进一步可写成 $u(z_q)\approx \frac{s(z_q)}{\alpha} r(z_q)$，其中 $s(z_q)=\sum_j\kappa(z_q,z_j)$ 为总相似度，$r(z_q)=\sum_i a_i(z_q) f_i$ 为注意力形式（系数 $a_i$ 非负且和为 1，等价于以 $\log\kappa$ 为 logits 的 softmax 注意力）。
   - **关键分离**：注意力读取决定"读什么"，查询相关的尺度 $s(z_q)/\alpha$ 决定"以多强施加"。

5. **RefineICL 网络实现**：
   - 每个上下文块实现 $h_{\ell+1}=h_\ell + W_{o,\ell}[\mathrm{Norm}(A_\ell(\bar h_\ell)) \odot \mathrm{SiLU}(W_{g,\ell}\bar h_\ell)]$，即注意力读出与向量门控（SiLU）逐元素相乘后投影、残差相加。
   - **三大设计后果**：(a) 更新支持状态（校正 $f_i$ 依赖当前邻域）；(b) 分离读取与缩放（注意力归一化相对相似度，门控控制校正强度）；(c) 以乘积作为非线性更新，**无需独立的扩展 FFN**。
   - **表格特征处理**：类型化编码器分别表示数值、类别身份与缺失；两轮特征图打分，仅保留每个特征最强的 16 个邻居做低秩特征交互（FI，秩 32/64）；三块行编码器 + RowCLS 压缩为固定宽度行状态；类型化记忆在压缩前存储特征状态，并在相对深度 1/3 与 2/3 处以八头门控读回，更新 RMS 限制为当前行状态 RMS 的 0.25。
   - 模型尺寸：L12（深度 12、宽度 2048）与 L24（深度 24、宽度 1024），特征嵌入维度 256。

## 6. 主要结论与发现

- **预测性能**：
  - RefineICL-L24 在 AMLB29 上达 0.93836 OVR-AUC、0.87173 准确率，优于 L12（+1.51 / +0.84 点）与 TabPFN-v3（+0.30 / +0.22 点）。
  - TabArena 快照上达 **1644.8 Elo**，比 TabPFN-3 高 31.4 Elo（相同评估下）。
  - TabZilla 两个视图上**全部四项指标**（准确率、F1、AUC、log loss）均优于 TabPFN-v3。
  - 159.5M 参数仅为 TabFM 1.639B 的 9.7%。

- **FFN 的作用**：
  - 匹配 100K 更新深度网格中，扩展 FFN **无一致验证收益**（L2、L4 使 CE 变差，L8 略有改善）。
  - L8 时 FFN 带来 1.11 点边界规则准确率增益，但**峰值推理内存增加 60.2%**（202.97 → 325.12 MiB）。

- **支持集表示是动态的**：
  - 在保持块 12 查询输出不变、仅跳过其支持更新的干预下，**72/72 episode** 的最终查询交叉熵增加，平均 +0.0510，准确率下降 1.44 点。
  - 学习到的支持更新降低留一目标（每块平均 −0.0204），而行置换更新（+0.0258）与标签打乱（+0.6312）均使其上升。

- **深度、宽度与证据规模**：
  - 块 12–24 将查询"正确类 vs. 最近错误原型"余弦间隔提高 0.0509，最近原型准确率提高 2.77 点。
  - 更宽的规则（更多 RBF 本征模）使用更多表示维度：秩 32 投影损失从 B=4 的 1.04 点升至 B=64 的 8.66 点。
  - 支持行从 128 增至 1024 时，L24–L12 差距从 0.24 扩大到 4.25 点。

- **查询特定性与标签选择性**：
  - 在 1024 行下，置换注意力输出、门控、配对更新分别使准确率下降 52.28、34.27、56.89 点——校正必须送达其对应查询。
  - 仅改变支持标签（线性/XOR/径向/波），匹配规则准确率平均 0.985，非匹配仅 0.515——标签选择当前预测器。

## 7. 优点

- **理论与架构的紧密联系**：从留一监督目标推导出支持校正与查询扩展，主导项自然分离"读取"与"缩放"，直接为注意力 + 门控 + 残差块提供构造性依据，而非事后附会。
- **FFN-free 设计的实证支持**：通过匹配深度 × FFN 网格与内存测量，定量说明省略扩展 FFN 的可行性与内存优势，而非仅凭参数量宣称。
- **机制性干预设计精巧**：
  - 保持查询输出不变、仅替换支持输出，干净地隔离了支持更新的因果贡献。
  - 查询置换实验同时保留向量集合与配对关系，区分"内容错误"与"接收者错误"。
  - 行置换与标签打乱作为对照，排除状态幅度与随机性解释。
- **评估严谨性**：
  - 重叠基准视图不合并，配对数据集级 W/T/L 分析，bootstrap 保留配对结构。
  - 明确记录 checkpoint SHA-256、协议 ID、成员预算，区分"四成员对比"与"原生默认"。
- **效率与容量意识**：明确区分参数存储比较与匹配算力比较，避免过度解读。

## 8. 不足与局限

- **机制证据主要来自合成任务**：核心干预（RBF episode、边界规则、稀疏规则）均在合成分类上完成，真实表格恢复面板范围较窄且为事后设计。
- **单训练种子**：匹配 FFN 网格与部分配对区间基于单一种子，未量化训练方差，结论的统计稳健性受限。
- **checkpoint 差异混杂**：L12 与 L24 在深度、宽度、训练历史上不同，深度相关结论无法完全归因于深度本身。
- **短程恢复不能替代完整训练**：组件删除后的 250 步恢复只测量训练模型的依赖性与部分补偿，不代表从零训练的架构必要性。
- **TabArena 结果存在开发暴露偏差**：L24 continuation 由该基准诊断信息指导，属于开发暴露比较，且使用固定 38 数据集、fold-0 快照与异构参考预算。
- **缺少回归任务**：论文明确
