## 摘要
基于模型与数据驱动范式的集成，通过结合解析冗余关系（即基于模型诊断中用作诊断指标的输入-输出关系）的可解释性与学习技术的适应性，为故障诊断提供了一个强大的框架。DT4X 是最近的一种诊断算法，它使用符号回归生成多变量关系，利用解析冗余关系的一些性质，并将其用作决策树中的分裂函数。然而，其符号回归过程在每个节点仅优化两个选定类别之间的分离，常常使其余类别碎片化，并降低可解释性和诊断性能。本文介绍了 DT4X+，它是 DT4X 的增强版本，修改了训练集的构建和符号回归损失，使得表达式在分离目标类别的同时保持非目标类别的一致性。由此得到的关系与 ARR 性质完全一致，并带来信息更丰富的分裂、更强的鲁棒性以及在动态系统数据集上的更好性能。在若干基准系统上进行的实验证明了这种增强公式的优势。

## Abstract
The integration of model-based and data-driven paradigms provides a powerful framework for fault diagnosis by combining the interpretability of analytical redundancy relations, i.e., input-output relations that are used as diagnosis indicators in model-based diagnosis, with the adaptability of learning techniques. DT4X is a recent diagnosis algorithm that uses symbolic regression to generate multivariate relations leveraging some properties of analytical redundancy relations and uses them as split functions in a decision tree. However, its symbolic regression procedure optimizes only the separation between two selected classes at each node, often fragmenting the remaining classes and degrading both interpretability and diagnosis performance. This paper introduces DT4X+, an enhanced version of DT4X that modifies the construction of training sets and the symbolic-regression loss so that expressions separate the target classes while preserving the coherence of non-target classes. The resulting relations become fully consistent with ARR properties and lead to more informative splits, improved robustness, and better performance on dynamic-system datasets. Experiments conducted on several benchmark systems demonstrate the benefits of this enhanced formulation.

## 1. 核心问题与整体含义

- **研究背景**：故障诊断中，模型驱动方法可借助解析冗余关系（ARR）提供可解释的故障指示器；数据驱动方法适应性强，但神经网络等黑箱模型可解释性差。决策树因结构透明而受到关注，但传统单变量树难以表达模型诊断中常见的多变量关系。
- **现有方法 DT4X**：DT4X 使用符号回归生成多变量数学表达式，并将其作为决策树分裂函数，使数据驱动学习与 ARR 概念相连接。理想 ARR 对正常类为零，对故障类为零或非零，且在同一类内保持一致。
- **关键缺陷**：DT4X 在每个节点只优化两个目标类别的分离，不考虑非目标类别。这会导致非目标类被任意割裂到左右子节点，违背 ARR “同一类行为一致”的性质，降低可解释性，并迫使树在更深层用更多关系补偿。
- **本文含义**：论文提出 DT4X+，通过修改训练集构建和符号回归损失，使生成的关系在分离目标类的同时保持非目标类一致性，从而得到更接近 ARR、对各类敏感度更明确的“完全有效故障指示器”。

## 2. 方法论：DT4X+ 的核心思想与关键技术

- **核心思想**：在符号回归训练中纳入当前节点所有类别，并在损失函数中惩罚非目标类被分裂到两个分支的碎片化现象。
- **训练集构建改进**：
  - 原 DT4X 只对目标类对 \((c_1,c_2)\) 采样并平衡；若涉及非正常类，会加入正常样本以强制 ARR 结构。
  - DT4X+ 在此基础上，额外加入当前节点中所有非目标类样本，并保持其原始比例，使符号分类器能观察到候选表达式对非目标类的影响。
- **损失函数改进**：
  - 总损失：\(Loss_{DT4X+}=L_{target}+L_{frag}\)。
  - \(L_{target}\)：与 DT4X 相同的 log loss，用于目标类对判别。
  - \(L_{frag}\)：对每个非目标类计算归一化 Gini 不纯度：  
    \[
    L_{frag}=\sum_{k\in nt}4\cdot p_{left,k}\cdot p_{right,k}\cdot w_k
    \]
    其中 \(p_{left,k}\)、\(p_{right,k}\) 是类 \(k\) 样本进入左右分支的比例，\(w_k\) 是类 \(k\) 的样本频率权重。某类完全进入单侧时为 0，均匀分裂时为 1。
- **损失作用机制**：
  - 由于 gplearn 对概率做裁剪，log loss 中错误样本贡献约 \(15\log(10)\approx34.54\)，正确样本贡献可忽略。
  - 因此 \(L_{target}<1\) 对应目标类分离准确率约高于 0.97；此时 \(L_{frag}\) 才显著影响总损失，保证先分离目标类，再抑制非目标类碎片化。
- **算法流程**：
  - DT4X+ 修改 DT4X 的 `balance` 和损失计算部分；类别对选择、递归建树、停止准则等仍沿用 DT4X。
  - 节点内部若找到合适表达式则分裂，否则成为多数类叶子；最终内部节点表达式充当故障指示器，叶子对应故障类别。
