## 摘要
符号回归（SR）中的一个基本挑战是如何从观测数据中高效恢复复杂的数学表达式。尽管该问题是NP难的，但许多具有实际意义的表达式自然地分解为非线性特征模块的组合，将结构复杂性集中到少量可复用组件中。本文提出FePySR，一个两阶段框架，通过在方程搜索之前提取有效特征来缩减SR搜索空间。FePySR首先使用异质神经网络将观测数据约束到一组候选表达式，然后利用PySR在该精炼的表达式空间内进行结构优化。在五个标准基准测试中，FePySR通过获得更高的方程恢复率超越了最先进的方法。在一组75个高度复杂的合成方程上，FePySR恢复了36个方程，同时在其余未恢复的案例中产生了显著更小的均方误差，并且相比PySR减少了计算时间。FePySR的第一阶段在选定的top特征数量变化以及观测数据噪声水平增加的情况下保持一致的性能。应用于控制生物系统的常微分方程时，FePySR在100次测试中成功识别了24个控制方程，而PySR未能恢复任何方程。综上所述，FePySR是一个可推广的框架，可以增强SR求解器，实现跨科学领域符号表达式的高效可靠恢复。

## Abstract
A fundamental challenge in symbolic regression (SR) is efficiently recovering complex mathematical expressions from observational data. Although this problem is NP-hard, many expressions of practical interest decompose naturally into combinations of nonlinear feature modules, concentrating structural complexity into a small number of reusable components. Here, we introduce FePySR, a two-stage framework that reduces the SR search space by extracting valid features prior to equation search. FePySR first employs a heterogeneous neural network to constrain observational data to a set of candidate expressions, then performs structural optimization within this refined expression space using PySR. Across five standard benchmarks, FePySR outperforms state-of-the-art methods by achieving higher equation recovery rates. On a set of 75 highly complex synthesized equations, FePySR recovers 36 equations, while producing substantially smaller mean squared errors on the remaining unrecovered cases, with reduced computation time compared to PySR. FePySR's first stage also maintains consistent performance under varying numbers of selected top features and increasing levels of noise in the observational data. Applied to ordinary differential equations governing biological systems, FePySR successfully identifies governing equations in 24 out of 100 tests where PySR recovers none. Taken together, FePySR is a generalizable framework that can enhance the SR solvers, enabling the efficient and reliable recovery of symbolic expressions across scientific domains.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：符号回归（Symbolic Regression，SR）是从观测数据中恢复出简洁、可解释的数学表达式，但是该问题已被证明是 NP 难的。主要困难来自两个组合搜索：特征选择（识别有效特征）和结构优化（在巨大操作符空间中找到最优公式）。随着输入维度和表达式复杂性的增长，搜索空间呈指数爆炸，现有方法难以高效处理。
- **整体含义**：许多实际感兴趣的表达式虽然整体复杂，但可以自然地分解为少量可复用的非线性特征模块（如 `e^x`、`sin(x)` 等）。因此，**如果在进行完整符号搜索之前先提取出这些有效特征，就能大幅降低搜索空间的深度和广度**，从而提升 SR 的效率和恢复率。这一思路属于“简化搜索空间”的范式，与 AI Feynman 的维度约简策略互补。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 提出两阶段框架 **FePySR**：
  1. **第一阶段（特征提取）**：使用一个称为 **特征映射网络（Feature Mapping Network, FMN）** 的异构神经网络，从原始数据中提取出高度表达性的非线性特征（如 `x^2`, `sin(x)`, `e^x` 等）。
  2. **第二阶段（结构搜索）**：将原始变量与提取到的特征拼接成增强表示，再交给现有的 SR 求解器 **PySR**（基于遗传编程）在精简后的表达式空间中进行结构优化。

### 关键技术细节
- **FMN 架构**：
  - 采用密集连接（dense connectivity）的多层异构激活单元（Heterogeneous Activation Units, HAUs）。每个 HAU 使用一个预定义的数学原语作为激活函数，例如 `(·)^2`, `sin(·)`, `cos(·)`, `exp(·)`, `+`, `×`。
  - 信息流：第 i 层的输出 = 该层所有 HAUs 的输出与第 i-1 层输出的拼接（类似残差连接）。
  - 与 EQL 不同，FMN 不直接生成完整公式，而是通过训练学习到一组“候选特征”。
- **损失函数**：`L = L2 + L_sparse + L_contrast`
  - `L2`：预测值与真值之间的平方误差。
  - `L_sparse`：对权重施加 L1 稀疏正则（`λ₁=0.08`），抑制无关特征。
  - `L_contrast`：对比损失（`λ₂=0.001`），惩罚对称二元算子（如 `+`, `×`）两分支权重的余弦相似度，防止功能坍缩（如 `x+x` 退化为 `2x`）。
- **训练稳定性措施**：
  - **梯度归一化**：每个 HAU 的梯度进行单位归一化，避免不同算子（如 `exp`, `log`）产生不同量级的梯度导致训练失衡。
  - **指数叠加抑制**：为阻止连续指数运算造成数值溢出，引入掩码机制，禁止一个指数 HAUs 的输入直接来自前一个指数 HAUs 的输出。
- **特征提取过程（算法 1）**：
  1. 训练 FMN 至损失收敛（如 100 个 epoch）。
  2. 逐层提取：对每个 HAU，选取其输入中 **绝对值最大的权重** 对应的特征，然后应用该 HAU 的数学原语得到新特征。
  3. 重复上述步骤至最后一层，得到候选特征集。
  4. 进行多次独立训练（如 16 次），合并所有候选特征，用 SymPy 化简为最简规范形式，统计频率排序，选取 top K 个特征（默认 K=4）。
- **第二阶段**：将 top K 特征与原始输入拼接，输入 PySR 进行符号搜索。
