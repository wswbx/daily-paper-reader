## 摘要
星系的光度函数、恒星质量函数以及晕的质量函数是天体物理学中的基本量，也是多种天体物理和宇宙学分析的关键输入。它们通常通过“目测”选择的拟合函数进行参数化，以匹配观测或模拟数据。我们应用符号回归——特别是穷举符号回归（ESR）算法——来自动搜索最优的LF、SMF和HMF函数形式。ESR使用描述长度（一种近似贝叶斯证据的度量，平衡准确性与复杂性）对所有复杂度不超过用户定义算子基集所允许最大值的函数进行评分。我们发现了许多在LF和SMF上优于谢希特函数和双谢希特函数，以及在HMF上优于普雷斯-谢希特和沃伦/廷克函数的函数。通过额外对函数的推断和积分特性施加“物理性检查”，我们根据准确性、简洁性以及在数据范围之外的行为确定了最优的低复杂度函数形式。除了提供可直接替代文献中LF、SMF和HMF拟合函数的函数，并识别出各拟合良好的函数中的稳健行为外，我们还提出了一种框架，利用符号回归自动发现任何天体物理数据集的最优函数。

## Abstract
The galaxy luminosity and stellar mass function (LF, SMF), and halo mass function (HMF), are fundamental quantities in astrophysics and crucial inputs to a range of astrophysical and cosmological analyses. They are typically parametrised by fitting functions that have been chosen "by eye" to match observed or simulated data. We apply symbolic regression -- specifically the Exhaustive Symbolic Regression (ESR) algorithm -- to automate the search for optimal LF, SMF and HMF functional forms. ESR scores all functions up to a maximum complexity composed of a user-defined basis set of operators using the description length, an approximation to the Bayesian evidence that balances accuracy with complexity. We find many functions outperforming the Schechter and double Schechter functions for the LF and SMF, and that outperform the Press--Schechter and Warren/Tinker functions for the HMF. By additionally imposing "physicality checks" on functions' extrapolation and integration properties, we identify the optimal, low-complexity functional forms in terms of accuracy, simplicity and behaviour beyond the data range. As well as providing drop-in replacements for literature LF, SMF and HMF fitting functions, and identifying robust behaviour across well-fitting functions, we present a framework with which symbolic regression may be used to automate the discovery of optimal functions for any astrophysical dataset.

## 1. 论文的核心问题与整体含义（研究动机和背景）
星系的光度函数（LF）、恒星质量函数（SMF）以及暗晕质量函数（HMF）是天体物理学中的基础量，广泛应用于星系形成、宇宙学参数约束、星系-晕连接等研究。然而，这些函数的参数化形式长期以来依赖于“目测”和经验选择，例如 LF 和 SMF 常用的 Schechter 函数、双 Schechter 函数，以及 HMF 的 Press–Schechter、Warren 和 Tinker 拟合公式。这些传统形式是否最优、能否被更简洁或更准确的函数替代，并未得到系统性验证。本文旨在利用**穷举符号回归（Exhaustive Symbolic Regression, ESR）** 自动化搜索最优的低复杂度函数形式，从而为 LF、SMF 和 HMF 提供更优的匹配函数，并建立一套通用的函数发现框架。

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：将函数拟合问题转化为一个**在函数空间中的穷举搜索**问题，对每个候选函数使用**最小描述长度（Minimum Description Length, MDL）** 进行评分，MDL 近似于贝叶斯证据，平衡了拟合精度（似然）和函数复杂度（结构复杂度 + 参数复杂度）。最终选出描述长度最小的函数。
- **关键技术细节**：
  - 算子基集：包括变量 \(x\)、数值参数 \(\theta\)，以及一元算子（exp, ln, inv）和二元算子（+, -, ×, /, pow）。函数复杂度定义为算子、变量和参数的总数。
  - ESR 流程：从复杂度 3 开始，逐步增加到 10（受计算可行性限制），在每个复杂度下生成所有可能的函数，并进行简化和去重（利用符号恒等式），然后对每个函数进行 BFGS 参数优化，计算其描述长度。
  - 描述长度公式：\(\text{DL} = -\ln(\hat{L}) + k\ln(n) + \sum_j \ln(c_j) - \frac{p}{2}\ln(3) + \sum_i \left[\frac{1}{2}\ln(\hat{I}_{ii}) + \ln(|\hat{\theta}_i|)\right]\)，其中 \(\hat{L}\) 是最大似然值，\(k\) 是函数复杂度，\(n\) 是唯一算子数，\(c_j\) 是简化产生的常数，\(p\) 是自由参数数，\(\hat{I}_{ii}\) 是费雪信息矩阵对角线元，\(\hat{\theta}_i\) 是最大似然参数值。
  - 物理性检查：除 MDL 排名外，还对函数进行外推行为检查，包括：渐近行为（\(x\to\infty\)时趋于0，\(x\to0+\)时有界非负）、单调性（针对 LF/SMF）、积分收敛性（总质量/亮度密度不超过物理上限，HMF 的累积质量分数 ≤1）。通过这些检查的函数才被认为是“物理合理”的备选。

## 5. 实验数量与充分性
- **实验数量**：
  - LF/SMF：对 Sérsic 和 cmodel 两种测光各做了一组 ESR 搜索（复杂度 3\~10），并分别与 Schechter、双 Schechter、Bernardi 进行对比。
  - HMF：对 10 个 Quijote 实现进行 ESR 搜索，然后选出前 200 个函数在所有 100 个实现上重新拟合和排名。此外还做了扩展质量范围（包含更低质量晕，约 19 粒子）的敏感性分析。
- **充分性与公平性**：
  - 充分：穷举搜索至复杂度 10，覆盖了简单的候选函数；不同实现的 HMF 分析检验了函数对初始条件相位的稳健性。
  - 公平：所有对比函数（Schechter、Bernardi、Press–Schechter、Warren、Tinker）都在相同数据上重新优化参数并计算 DL，因此排名是公平的。但对 HMF 的 Warren 和 Tinker 函数，由于复杂度 >10，未纳入 ESR 排名，仅单独比较 DL。

## 6. 论文的主要结论与发现
- **LF**：最佳 ESR 函数为 \(\phi_{\text{LF}}(x) = e^{\alpha(\ln(\beta + \gamma x))^\delta}\)（Sérsic 测光）或 \(\phi_{\text{LF}}(x) = (\alpha + e^{\beta x^\gamma})^\delta\)（cmodel 测光），均优于 Schechter 函数（DL 改进 >500），且通过物理性检查。函数在亮端呈超指数衰减（指数约 0.3\~0.5）。
- **SMF**：最佳 ESR 函数为 \(\phi_{\text{SMF}}(x) = (\alpha + e^{\beta x^\gamma})^\delta\)（与 cmodel LF 形式相同），优于 Schechter（DL 改进 >1000），但仍不如 Bernardi 的 7 参数函数（DL 差距约 200）。这表明 SMF 可能需要更复杂的结构（如双成分）。
- **HMF**：最佳 ESR 函数为 \(f(\sigma) = \theta_0 / (\theta_1 + e^{\sigma \theta_2 + \sigma})\)（复杂度 10，3 参数），在所有 100 个 Quijote 实现中 98 次排名第一。该函数在 HMF 上优于 Warren 和 Tinker（DL 改进约 2200\~3100）。另外还发现了一类保持 Press–Schechter 式 \(1/\sigma\) 行为的函数 \(f(\sigma) = \alpha e^{-\beta \sigma^\gamma} / \sigma\)，可作为理论优先的备选。
- **共同特征**：所有最优函数在亮/高质端都表现出比简单指数更快的超指数衰减；SMF 需要更复杂的双成分结构；HMF 的大 \(\sigma\) 外推（低质量端）被 ESR 强制切断，但作者指出这更可能是 DL 对简洁性的偏好，而非真实物理，应与 zoom 模拟结果对比。

## 7. 优点
- **首创性**：首次将穷举符号回归系统应用于 LF、SMF 和 HMF 的函数形式发现，取代了传统的手工试错方法。
- **自动化与客观性**：使用 MDL 指标统一衡量精度与复杂度，无需人为设定正则化权重，结果可重复。
- **物理性检查**：除了统计拟合，还增加了对渐近行为和积分物理性的检查，确保函数在数据范围外不会出现明显不合理的行为。
- **稳健性分析**：对 100 个不同初始条件的 Quijote 实现分别拟合，证明了排名高度一致（图 6），验证了函数形式对宇宙方差不敏感。
- **可扩展框架**：本文建立的 ESR 流程可推广到其他天体物理函数拟合问题（如 HI 质量函数、重子质量函数等）。

## 8. 不足与局限
- **运算范围受限**：ESR 只能搜索复杂度 ≤10 的函数，可能遗漏更优但更复杂的函数（尤其对 SMF，Bernardi 函数复杂度 >10 表现更好）。
- **数据覆盖有限**：
  - LF/SMF 仅使用 SDSS 一个样本，且只到 \(M_\star \sim 10^{8.5} M_\odot\)，更深的 GAMA 数据（\(M_\star \sim 10^{7.5} M_\odot\)）可能偏好不同的函数（如上升的低质量端）。
  - HMF 仅使用 Quijote 单一宇宙学，未检验函数在不同宇宙学下的通用性（所谓的“普适性”）。
- **外推不可靠**：ESR 函数在低质量/低光度端通常为常数或趋零，这与实际观测（如 GAMA 看到的下降）或 zoom 模拟（f(σ) 继续上升）不一致。作者明确指出这是 DL 偏好简洁性的结果，而非数据驱动。
- **似然假设的简化和检查**：
  - 假设 bin 间相互独立（泊松似然），但 HMF 的 bin 间相关性分析显示约 58% 的 bin 对相关 >0.1，尽管对函数排名影响不大，但参数不确定度可能被低估。
  - 使用费雪信息矩阵的对角近似，而非全行列式，导致参数复杂度项有一定偏差，但检查发现对排名无实质影响。
- **未考虑的潜在偏差**：
  - LF/SMF 基于 Bernardi 的测光和恒星质量转换，不同测光方法（Sérsic vs. cmodel）已被证实会导致系统差异，本文通过同时分析两种测光部分缓解了此问题，但未探索更广泛的光度/质量模型。
  - 未考虑星族合成模型和初始质量函数的不确定性，这些会影响 SMF 的形状。
- **低质量晕的偏差**：扩展至更低质量（~19 粒子）后，函数排名显著变化，ESR 可能过度拟合了噪声，说明这些 bins 可能受到分辨率效应影响，使用时需谨慎。
