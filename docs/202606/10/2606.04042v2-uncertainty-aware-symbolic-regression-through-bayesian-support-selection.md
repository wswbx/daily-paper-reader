## 摘要
可靠独立筛选与稀疏化算子（SISSO）框架是一种强大的符号回归方法，用于从大规模非线性特征空间中提取紧凑且可解释的描述符。然而，标准SISSO是确定性的：它返回单一描述符和点预测，而不量化描述符选择、回归系数或预测中的不确定性。本文引入了一种概率扩展，其中可靠独立筛选（SIS）阶段保持确定性以保持可扩展性，而稀疏化算子（SO）阶段被重新表述为对SIS筛选后的支持空间进行贝叶斯推理。由此产生的确定性SIS/贝叶斯SO框架为竞争性描述符支持提供了后验概率、特征包含概率、贝叶斯模型平均预测以及预测可信区间，同时在最大后验极限下恢复了标准SISSO的确定性SO描述符。应用于X₂YZ Heusler合金磁矩数据集时，该方法在五折交叉验证均方根误差上略有改进，且95%预测区间的经验覆盖接近标称值。更重要的是，后验暴露了具有竞争性且物理相关的符号描述符族，这些在确定性分析中会显得人为唯一。这些结果表明，确定性SIS/贝叶斯SO可以作为SISSO的不确定性感知诊断扩展：一种在小数据材料回归问题中评估描述符置信度、稳定性和非唯一性的工具。

## Abstract
The Sure Independence Screening and Sparsifying Operator (SISSO) framework is a powerful symbolic-regression method for extracting compact and interpretable descriptors from large nonlinear feature spaces. However, standard SISSO is deterministic: it returns a single descriptor and point prediction, without quantifying uncertainty in descriptor selection, regression coefficients, or predictions. Here we introduce a probabilistic extension in which the sure independence screening (SIS) stage is kept deterministic to preserve scalability, while the sparsifying operator (SO) stage is reformulated as Bayesian inference over the SIS-screened support space. The resulting deterministic-SIS/Bayesian-SO framework yields posterior probabilities for competing descriptor supports, feature-inclusion probabilities, Bayesian-model-averaged predictions, and predictive credible intervals, while recovering the deterministic SO descriptor of standard SISSO in the maximum-a-posteriori limit. Applied to an $X_2YZ$ Heusler-alloy magnetic-moment dataset, the approach gives modest improvements in five-fold cross-validation RMSE and near-nominal empirical coverage of the 95$\%$ predictive intervals. More importantly, the posterior exposes competing, physically related symbolic descriptor families that would appear artificially unique in a deterministic analysis. These results suggest that deterministic-SIS/Bayesian-SO can be used as an uncertainty-aware diagnostic extension of SISSO: a tool for assessing descriptor confidence, stability, and non-uniqueness in small-data materials regression problems.

- **核心问题**：标准 SISSO（Sure Independence Screening and Sparsifying Operator）符号回归方法是确定性的，只能输出单一描述符和点预测，无法量化描述符选择、回归系数和预测的不确定性。在小数据材料科学问题中，多个高相关符号描述符可能近似等价，确定性选择会掩盖这种竞争关系，导致人为的“唯一”结论。
- **研究动机**：在保持 SISSO 可扩展性的前提下，引入不确定性量化，使描述符选择具有概率意义，提供后验支持概率、特征包含概率、贝叶斯模型平均预测以及预测可信区间，从而作为诊断工具评估描述符的稳定性与置信度。
- **整体含义**：确定性-SIS/贝叶斯-SO 框架是 SISSO 的保守扩展，保留了确定性筛选的计算效率，同时将稀疏化步骤变为贝叶斯推断，在不损害预测精度的前提下揭示了数据中的描述符非唯一性。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：保持 SIS 阶段为确定性（保证可扩展性），仅将 SO 阶段重构为对 SIS 筛选后的支持空间的贝叶斯推断。
- **关键技术细节**：
  - **确定性 SIS 阶段**：根据相关性等指标对 M 个符号特征排序，保留前 K 个特征（K ≪ M），得到缩减的设计矩阵 Φ_I ∈ ℝ^(N×K)。
  - **贝叶斯 SO 阶段**：对每个候选支持 γ ⊂ {1,…,K}（|γ| = d），使用高斯线性模型 y = Φ_I^(γ) β_γ + ε, ε ~ N(0, σ²I)，赋予系数高斯先验 β_γ ~ N(0, τ²I)。积分掉系数得到边际似然 p(y|γ)，再结合支持先验 p(γ) 得到后验支持概率 p(γ|D_I) ∝ p(y|γ) p(γ)。
  - 后验输出：MAP 描述符、特征包含概率 PIP(k) = Σ_{γ∋k} p(γ|D_I)、贝叶斯模型平均预测 p(y*|x*, D_I) = Σ_γ p(γ|D_I) p(y*|x*, γ, D_I) 及预测可信区间。
- **支持先验设计**（三种示例）：
  1. **均匀先验**：所有大小为 d 的支持等概率，作为通用默认选择。
  2. **相关-多样性先验**：鼓励高 SIS 分数且特征间低相关性的支持（λ_SIS, λ_corr 调节）。
  3. **Slater–Pauling 启发先验**（仅用于 d=2）：以电子计数（N_v = 2N_X + N_Y + N_Z）为骨干，鼓励一个特征对齐 N_v、另一个对齐残差的组合，同时惩罚内部相关性，用于组织解释性后验。
- **实现细节**：对每个支持，特征列和目标进行均值中心化；σ² 固定为全数据标准 SISSO 的 RMSE 平方（d=2:0.2652, d=3:0.1694）；τ² 固定为目标方差除以 d（4.7158/d）。未进行方差标准化，未使用 Zellner g 先验。

## 3. 实验设计：使用的数据集、基准、对比方法
- **数据集**：X₂YZ 全 Heusler 合金磁矩数据集，共 88 个化合物（38 Co 基、32 Fe 基、18 Ni 基）。每个位点（X、Y、Z）使用 6 个元素描述符（第一电离能、电负性、共价半径、价电子数、原子体积、d 电子数），共 18 个主特征（Z 的 Nd 为零被移除）。
- **基准**：标准 SISSO（确定性 SIS + 确定性 ℓ0 SO），在相同符号特征库（运算符 +、-、*、/、^-1、^2，最大复杂度 5，库大小 2.425×10⁸）和相同 SIS 筛选设置下运行。
- **对比方法**：贝叶斯-SO 使用三种先验（均匀、相关-多样性、Slater–Pauling）与标准确定性 SO 比较。描述符维度 d=2 和 d=3 分别实验。采用五折交叉验证（同一折划分）。
