## 摘要
元强化学习通过从相关任务中提取共享结构实现快速适应，但现有的端到端方法通常将任务推断与特定具身的控制耦合在一起。这种耦合可能掩盖非参数任务语义，降低样本效率，并限制跨智能体重用。我们提出了一种元知识重用框架，该框架在动力学简化的智能体上学习任务级知识，并将其迁移到异构智能体。该框架使用贝叶斯非参数先验来组织潜在任务模式，并使用高层策略生成任务级幅度指导。为了桥接可重用的任务知识与不同具身，我们引入了语义-幅度接口和轻量级时间适配器，将冻结的元知识转换为时间对齐的子目标，供具身特定的低级控制器使用。在多个运动智能体上的实验表明，与最近的最先进基线相比，我们的框架将最后一步跟踪误差降低了94.75%-99.79%，并且在使用其交互数据约23.8%的情况下实现了相当的部署性能。

## Abstract
Meta-reinforcement learning enables fast adaptation by extracting shared structure from related tasks, but existing end-to-end methods often couple task inference with embodiment-specific control. This coupling can obscure non-parametric task semantics, reduce sample efficiency, and limit cross-agent reuse. We propose a meta-knowledge reutilization framework that learns task-level knowledge on a dynamics-simplified agent and transfers it to heterogeneous agents. The framework uses a Bayesian non-parametric prior to organize latent task modes and a high-level policy to generate task-level magnitude guidance. To bridge reusable task knowledge with different embodiments, we introduce a semantic-magnitude interface and a lightweight temporal adaptor, which convert frozen meta-knowledge into temporally aligned subgoals for embodiment-specific low-level controllers. Experiments on multiple locomotion agents show that our framework reduces final-step tracking error by 94.75% -- 99.79% compared with recent state-of-the-art baselines and achieves comparable deployment performance with about 23.8% of their interaction data.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：在一个**动力学简化智能体**（基于质量-阻尼模型的质量点抽象）上，使用**贝叶斯非参数先验（Dirichlet Process Mixture Model, DPMM）** 正则化潜在任务空间，学习可复用的任务级元知识（任务推断模块+高层策略）。随后通过**语义-幅度对齐接口（SMAI）** 和**轻量级步幅预测器（stride predictor）**，将冻结的元知识转换为时间对齐的子目标，供异构具身的低层控制器执行。

- **关键技术细节**：
  1. **元知识获取**：
     - 简化智能体（仅保留位置、速度等任务相关变量，去掉高维关节/接触动力学）。
     - 使用 VAE 编码器 $q_\phi(z|c_t)$ 从最近历史窗口 $c_t$ 推断潜在变量 $z_t$，解码器 $p_\xi$ 同时预测下一状态、奖励和任务置信度。
     - 在潜在空间施加 DPMM 先验（通过 stick-breaking 构建），使用变分推理（Memorized VB）自适应组织任务模式数量，无需提前指定。
     - 训练高层策略 $\pi_{\text{high}}(a^{\text{high}}|s_t, z_t)$ 生成抽象动作，并利用 stop-gradient 保持任务推断模块与策略优化分离。
  2. **解耦的低层策略训练**：
     - 为每个目标具身独立训练低层控制器 $\pi_{\text{low}}^{(i)}(a_t^{(i)}|s_t^{(i)}, g_t)$，其中 $g_t$ 为通过 SMAI 生成的任务级幅度信号。
     - 设计课程学习，逐步增加目标幅度、切换频率、回合长度和初始状态多样性，使低层策略先获得稳定运动能力，再学会跟随变化的子目标。
  3. **元知识重用**：
     - 冻结已训练的元知识模块（推断器+高层策略）。
     - 目标具身通过状态映射函数 $R^{(i)}$ 提取抽象状态，推断潜在变量 $z_t$，高层策略生成残余更新得到标量幅度 $m_t$，结合任务置信度得到 SMAI 子目标 $g_t = m_t \cdot b_t$。
     - 步幅预测器 $P^{(i)}_\zeta$ 在线估计当前子目标应保持的执行步数 $k_t$，适应不同具身的响应延迟。
     - 低层策略按 $k_t$ 步固定子目标执行，形成闭环。

- **公式要点**：
  - 任务推断损失：$\mathcal{L}_I = \mathcal{L}_{\text{rec}} + \beta_{\text{KL}} \sum_k \rho_{tk} D_{\text{KL}}(q_\phi\|p_{\theta_k})$
  - 高层策略更新：$\mathcal{L}_\pi^{\text{high}} = \mathbb{E}[\eta \log \pi_{\text{high}} - \min_j Q_{\chi_j}]$（with stop-gradient on $z_t$）
  - 低层奖励：$r_{\text{low}}^{(i)} = - \| \Phi_{u_t}^{(i)}(s_t^{(i)}) - m_t \|_2^2 - \lambda_a \|a_t^{(i)}\|_2^2$

### 7. 优点

- **解耦框架新颖**：首次在 Meta-RL 中明确将任务级元知识与具身特定控制分开学习，从根本上避免端到端耦合带来的低效和可转移性差问题。
- **贝叶斯非参数先验**：DPMM 自动适应任务模式数量，无需预先指定，更符合真实任务分布的非参数特性。
- **实用的接口设计**：SMAI 将语义通道与标量幅度结合，简洁统一；步幅预测器轻量在线适应不同具身时间尺度，设计巧妙。
- **课程学习**：为低层策略设计的渐进式训练（幅度、切换频率、长度、初始化）有效解决了复杂具身早期不稳定问题。
- **实验设计全面**：覆盖多种具身、多种任务，包含定性与定量分析、消融研究，且与多个强基线进行全面对比，结论可信度高。
