## 摘要
用于LLM智能体的技能自我进化方法旨在将执行轨迹转化为可复用的技能文档，但当前流程通常从每个任务的一条轨迹中学习，在检查候选技能补丁之前就进行合并，并在推理前加载完整的技能语料库。我们提出SkillCAT，一个无需训练的框架，将这一过程分解为三个阶段。对比因果提取（CCE）为每个任务采样多条轨迹，并比较同一任务的成功/失败对，以识别解释结果差异的证据。评估增强进化（AAE）在源任务副本上重放每个候选补丁，仅保留那些能改进或保持任务结果的补丁，然后进行分层技能补丁合并。拓扑感知任务执行（TTE）将进化后的技能编译成一个可路由的子技能拓扑，因此推理时仅加载与任务相关的能力节点。我们在常见的智能体基准测试上评估SkillCAT，包括SpreadsheetBench、WikiTableQuestions和DocVQA，并进一步测试跨模型和分布外泛化。在这些设置中，SkillCAT将基线平均得分提高了高达40.40%，展示了无需模型训练的可靠技能进化。

## Abstract
Skill self-evolution methods for LLM agents aim to turn execution trajectories into reusable skill documents, but current pipelines typically learn from one trajectory per task, merge candidate skill patches before checking them, and load the full skill corpus before inference. We propose SkillCAT, a training-free framework that separates this process into three stages. Contrastive Causal Extraction (CCE) samples multiple trajectories for each task and compares same-task success/failure pairs to identify evidence that explains outcome differences. Assessment-Augmented Evolution (AAE) replays each candidate patch on source-task clones and keeps only patches that improve or preserve task outcomes before hierarchical skill patch merging. Topology-Aware Task Execution (TTE) compiles the evolved skills into a routable sub-skill topology, so inference loads only the capability nodes relevant to the task. We evaluate SkillCAT on common agent benchmarks, including SpreadsheetBench, WikiTableQuestions, and DocVQA, and further test cross-model and out-of-distribution generalization. Across these settings, SkillCAT raises the average score over baselines by up to 40.40%, demonstrating reliable skill evolution without model training.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：LLM智能体依赖外部技能文档完成复杂任务，现有工作将执行轨迹自动提炼为可复用技能（技能自我进化）。但主流方法（如顺序更新、Trace2Skill）存在三个关键缺陷：
  - 单轨迹偏差（Single‑Trace Bias）：仅从单条轨迹学习，成功可能源于偶然，失败无法定位根因。
  - 未经验证合并（Unvalidated Merging）：候选技能补丁直接合并，并未先在源头任务上验证，导致低质量或有害规则进入语料库。
  - 推理上下文过载（Context Overload）：合并后的技能持续膨胀，推理时加载全部内容增加提示长度并引入无关规则，干扰规划。
- **核心问题**：如何在不进行模型训练的前提下，从多轨迹中可靠提取因果技能、验证并过滤补丁、以及按需加载上下文，从而提升智能体的任务表现和泛化能力。
- **整体含义**：提出SkillCAT，一种无需训练的三阶段框架，将技能生命周期拆解为对比式因果提取、评估增强进化、拓扑感知执行，实现了更高效、更可靠的技能自我进化。

## 2. 论文提出的方法论：核心思想与关键技术细节

### 核心思想
将技能进化分解为三个独立可观察的阶段：证据提取（只聚焦因果分歧点）、补丁验证（源任务重放评分后选择）、推理部署（按拓扑路由最小相关技能）。三个阶段均不更新模型权重。

### 关键技术细节

#### 2.1 对比因果提取（CCE）
- **多种子采样**：对每个任务 \(x_i\) 用 \(K\) 个随机种子运行智能体，收集多条轨迹及其结果 \(y_{i,z} \in \{0,1\}\)。
- **对比对构建**：当同一任务同时包含成功和失败轨迹时，随机各取一条构成对比对 \((\tau_i^+, \tau_i^-)\)。
- **因果分水岭定位**：找出成功与失败动作序列首次不同的时间步 \(w_i = \min\{t : \alpha_t^+ \neq \alpha_t^-\}\)。
- **证据提取**：仅围绕分水岭提取候选经验记录 \(r_i = \mathcal{E}(\tau_i^+, \tau_i^-, w_i)\)，包含本地证据、失败原因和可编辑教训。
- **回退机制**：若任务全成功或全失败，可启用单轨迹提取器 \(\mathcal{E}_1\) 或跳过该任务。

#### 2.2 评估增强进化（AAE）
- **源任务重放**：对每个候选补丁 \(p_j\)，在关联的源任务克隆上临时应用该补丁，记录基线结果 \(y_j\) 和重放结果 \(\hat{y}_j\)。
- **评分校准**：根据状态转移定义分数 \(a_j\)：
  - (0→1)=3.0（最佳，修复失败）
  - (1→1)=2.0（保持成功）
  - (0→0)=1.0（未改善）
  - (1→0)=0.0（恶化，拒绝）
- **阈值筛选**：仅保留 \(a_j \geq \theta\)（默认 \(\theta=2.0\)）的补丁。
- **分层合并**：按分数层级从低到高逐级合并，最终技能 \(S^* = S^{(L)}\)，合并算子复用Trace2Skill。

#### 2.3 拓扑感知任务执行（TTE）
- **拓扑构建**：离线分析 \(S^*\) 的Markdown层级，一级内容为核心技能 \(S^\circ\)，二级为可路由节点集合 \(V\)，抽取元数据（标题、关键词、摘要、依赖）。
- **LLM路由**：给定任务描述 \(c\) 和预算 \(k\)，LLM路由器 \(\rho\) 从拓扑摘要 \(\Sigma\) 中选择最多 \(k\) 个相关节点。
- **确定性扩展**：运行时空验证节点ID、添加确定性锚点、展开依赖边、包含基础节点，得到最终节点集 \(V_c\)。
- **技能装配**：拼接 \(S_c = S^\circ \oplus \bigoplus_{v \in V_c} B_v\)，不修改规则文本。

### 算法流程（文字说明）
1. 输入：演化任务集 \(X\)、种子集 \(Z\)、基础技能 \(S_0\)、阈值 \(\theta\)、路由预算 \(k\)。
2. Stage 1（CCE）：对每个任务运行多种子收集轨迹，如果成功失败混合则提取对比证据；否则回退或跳过。存入记录集 \(R\)。
3. Stage 2（AAE）：将 \(R\) 转换为候选补丁，每个补丁在源任务克隆上重放打分，保留 \(a_j \geq \theta\) 的补丁，按分数分层合并得到 \(S^*\)。
4. Stage 3（TTE）：编译 \(S^*\) 为拓扑 \((S^\circ, V)\)。对每个测试任务，LLM路由选节点，确定性扩展，装配 \(S_c\)，智能体执行。

## 6. 论文的主要结论与发现

1. **SkillCAT显著提升性能**：在Qwen3.5-35B‑A3B同模型Skill Deepening中，Vrf达到55.50%，比Trace2Skill+Combined高出25.83百分点；平均得分提升最高40.40%。
2. **各模块均不可或缺**：消融显示移除任一模块性能下降，特别是移除AAE后效果低于基线（-3.67%），表明源任务验证防止了有害合并。
3. **CCE的种子数存在最优平衡**：5种子达到最佳Vrf（55.50%），更多种子反而下降且大幅增加采样时间。
4. **AAE分数校准有效**：重放转移分数与下游性能单调对应（F→S最佳，S→F最差），验证了该打分作为筛选指标的可靠性。
5. **TTE减少上下文并保持/提升性能**：LLM图路由器在top_k=7时实现41.6%上下文缩减，同时达到55.50% Vrf，优于无TTE的46.50%。
6. **跨模型泛化可行但依赖用户模型**：gemma-4-31B-it受益明显（+22~31.5 Vrf），gpt-5.4-mini提升有限，暗示技能表述可能需要适应不同LLM。

## 7. 优点

- **新颖的三阶段分离设计**：精准定位现有方法的三个痛点，并分别提出针对性解决方案，逻辑清晰且模块化。
- **无需模型训练**：所有操作基于LLM推理和规则合并，避免了微调成本和过拟合风险，可快速适配新模型。
- **对比因果提取**：通过同任务成败对比定位因果分水岭，相较于单轨迹总结显著提升证据质量。
- **源任务重放验证**：引入轻量级评估机制，以简单分数排序即可过滤无效补丁，避免了盲目合并风险。
- **拓扑感知路由**：编译技能拓扑并利用LLM进行轻量路由，在保持技能完整性的同时大幅减少推理上下文，降低令牌消耗。
- **强泛化能力**：在分布外（WikiTQ）和多模态（DocVQA）任务上均有显著提升，且技能可被不同模型复用。
- **实验验证充分**：包含主表、消融、参数扫描、路由对比等多维度分析，各个设计的贡献均得到量化。

## 8. 不足与局限

- **任务覆盖有限**：仅测试了电子表格和文档VQA两类任务，在代码生成、网页交互、机器人控制等更广泛场景中的有效性未验证。
- **初始技能依赖**：Deepening场景从Human-Written初始化，Creation从较弱的Parametric初始化，但初始技能的偏差如何影响演化上限未探讨。
- **种子数选择的经验性**：5种子最优来自SpreadsheetBench实验，可能对其他任务适用性不同，需要更多跨任务校准。
- **LLM路由额外成本**：TTE依赖LLM进行路由选择，虽然减轻了提示长度，但引入了一次额外推理调用，且路由质量受限于LLM本身理解。
- **跨模型泛化欠均衡**：部分模型（如gpt-5.4-mini）提升微小，技能表述的通用性或需进一步适配不同系列模型。
- **未评估负面影响**：未分析演化中可能引入的安全风险、偏见放大或错误传播；技能合并可能产生意料之外的规则冲突。
- **计算资源细节缺失**：虽然是无训练框架，但多种子并行采样和重放仍消耗大量推理资源，论文未报告具体GPU型号、数量及总耗时，难以复现完整成本。
- **与更多基线对比不足**：未与Reflexion、Self‑Refine、AutoSkill等迭代类方法直接比较，说服力局限于Trace2Skill系列。
