## 摘要
在大语言模型中，策略内蒸馏（OPD）正在从全轨迹KL监督转向更具选择性的训练范式。最近的OPD方法越来越关注选择从哪些轨迹中学习、哪些token信息量最大以及哪些监督信号最可靠。受此趋势启发，我们重新思考OPD的优化粒度，并提出\fireicon\ FiRe-OPD（先过滤，再重加权），它在轨迹和token两个层面联合调整监督信号。具体来说，FiRe-OPD首先过滤轨迹以移除低质量rollout样本，然后在保留的轨迹内应用软重加权以强调信息性token。与硬token选择相比，FiRe-OPD利用软加权机制有效减轻信息损失并增强优化稳定性，从而实现更细粒度的OPD优化。我们在强到弱、单教师和多教师设置中验证了FiRe-OPD的有效性，并展示了其相对于近期token级OPD方法的优越性（例如在强到弱设置中AIME 2024上提升+6.25，在多教师设置中Miner上提升+18.81）。我们的代码可在https://github.com/YuYingLi0/FiRe-OPD获取。

## Abstract
On-Policy distillation (OPD) in large language models is shifting from full-trace KL supervision toward more selective training paradigms. Recent OPD methods increasingly focus on selecting which trajectories to learn from, which tokens are most informative, and which supervision signals are most reliable. Motivated by this trend, we rethink optimization granularity of OPD and propose \fireicon\ FiRe-OPD (Filter, then Reweight), which jointly adjusts supervision signals at both trajectory and token levels. In details, FiRe-OPD first filters trajectories to remove low-quality rollout samples, and then applies soft reweighting within the retained trajectories to emphasize informative tokens. Compared with hard token selection, FiRe-OPD leverages a soft-weighting mechanism to effectively mitigate information loss and enhance optimization stability, thereby achieving finer-grained OPD optimization. We validate the effectiveness of FiRe-OPD across strong-to-weak, single-teacher, and multi-teacher settings, and demonstrate its superiority over recent token-level OPD methods ( (e.g., +6.25 on AIME 2024 in strong-to-weak, +18.81 on Miner in multi-teacher). Our code is available at https://github.com/YuYingLi0/FiRe-OPD.

## 1. 核心问题与整体含义（研究动机与背景）

在线策略蒸馏（On-Policy Distillation, OPD）是大语言模型后训练中一种有效的知识迁移范式——学生模型基于自身生成的轨迹，接收教师模型的密集 token 级监督。但标准 OPD 对所有轨迹和所有 token 施加均匀的 KL 散度监督，忽视了不同轨迹和不同 token 在学习价值上的巨大差异。近期工作开始探索选择性训练，但存在两大局限：
- **粒度孤立**：现有方法要么在轨迹级要么在 token 级操作，未能联合建模两个粒度并利用其互补性。
- **硬选择策略**：大多数 token 级方法采用硬丢弃（hard selection），永久丢失了可能仍有部分学习价值的信号，导致优化不稳定和噪声累积。

论文提出 **FiRe-OPD**（Filter, then Reweight），通过**轨迹级过滤**和**token 级软重加权**实现细粒度、自适应、稳定的在线策略蒸馏。

## 2. 方法论：核心思想与关键技术细节

### 整体架构
FiRe-OPD 包含两个级联阶段：
1. **轨迹级过滤**：基于教师模型对学生生成轨迹的对数概率（归一化），筛除低质量轨迹。
2. **token 级软重加权**：在保留的轨迹内，结合教师置信度和学生困惑度，连续地分配重要性权重，再归一化后用于策略梯度。

### 关键技术细节

#### 轨迹级过滤
- **信号定义**：使用教师模型在整个学生生成轨迹上的平均对数概率作为轨迹质量指标：
  \[
  s(y) = \frac{1}{T}\sum_{t=1}^T \log \pi_T(y_t|x, y_{<t})
  \]
  该值低意味着教师与学生在该路径上的分布差异大，教师监督不可靠。
- **操作**：在一个 batch 内，按 \(s(y)\) 排序，丢弃底部 \(p\%\) 的轨迹（默认 \(p=20\%\)）。仅保留的轨迹进入下一阶段。

#### Token 级软重加权
- **教师置信度** \(c^T_t\)：基于教师分布熵的归一化倒数（低熵 = 高置信）。
- **学生困惑度** \(c^S_t\)：基于学生分布熵的归一化值（高熵 = 高困惑 = 需要指导）。
- **组合权重**：\(w_t = (1 + \alpha \cdot c^T_t) \times (1 + \beta \cdot c^S_t)\)，默认 \(\alpha = \beta = 1.0\)。
- **归一化**：在每个轨迹内，对权重归一化以保持梯度量级稳定：
  \[
  \tilde{a}_t = \frac{w_t}{\frac{1}{T}\sum_{t'} w_{t'}} \cdot a_t
  \]
  其中 \(a_t\) 是标准 OPD 的 token 级优势（教师学生 log 概率差）。
- **最终损失**：使用 PPO 风格的 clip 目标，但以归一化后的 \(\tilde{a}_t\) 替换 \(a_t\)。

### 与现有方法的区别
- 对比 EOPD（仅用教师熵）、TIP（仅用学生熵+硬选择）、ExOPD（全局奖励缩放）等，FiRe-OPD 同时考虑教师和学生信号，且采用软加权而非硬丢弃，避免了信息永久丢失。

1. **FiRe-OPD 在所有三个蒸馏场景下一致优于标准 OPD 和现有改进方法**，特别是在强→弱和多教师场景获得显著提升（AIME24 +6.25, MinervaMAT +18.81）。
2. **轨迹级硬过滤 + token 级软加权是最优组合**（消融表6）：低质量轨迹应完全移除，而 token 则应连续加权而非硬丢弃。

4. **软加权机制自动识别推理转折点**（案例研究）：如"Therefore"So"等推理连接词获得高权重，数值计算词权重低，体现了对推理策略选择点的聚焦。

## 7. 优点
- **多粒度联合优化**：首次将轨迹级和 token 级同时纳入统一框架，互补优化。
- **软加权保留信息**：避免硬选择导致的信息永久丢失，优化更平滑稳定。
- **无需外部奖励**：完全基于教师和学生的内在信号（对数概率、熵），不依赖外部验证器或奖励模型，实用性强。
- **超参数鲁棒**：学生困惑度权重 \(\beta\) 在较大范围内（0.25∼5.0）表现稳定，便于实际应用。
- **可视化分析深入**：通过 token 权重分布和词例分析，揭示了模型关注的推理策略点，提供了可解释性。

## 8. 不足与局限
- **独立 token 假设**：当前方法将每个 token 独立处理，未考虑前缀错误对后续 token 信号的影响（即错误积累问题）。论文自身提及“prefix-aware weighting”可能进一步改善。
- **粒度选择有限**：仅考虑了 token 级和轨迹级，忽略了中间粒度如 step 级或 chunk 级（更契合 chain-of-thought 结构）。这是论文明确指出的未来方向。
- **单教师场景提升较小**：在教师学生同架构时，提升不如强→弱场景显著，可能意味着该方法对分布差异较大的情况更有效。
- **实验覆盖可扩展**：仅验证了 Qwen3 系列 4B/30B；更大的模型（如 70B 或 MoE）尚未测试。代码任务只采用了一组多教师数据，未在通用代码蒸馏场景单独对比。
- **超参数依赖性**：轨迹过滤百分位 \(p\) 和教师置信度权重 \(\alpha\) 仍需调参（最佳值 \(p=20\%\), \(\alpha\geq1\)），不过论文展示了在合理范围内的稳定性。
- **公平性考量**：多教师场景只对比了 ExOPD 和 OPD，缺少与其他近期多教师 OPD 方法的对比（如 Uni-OPD 虽在引言提及但实验未包括）。
