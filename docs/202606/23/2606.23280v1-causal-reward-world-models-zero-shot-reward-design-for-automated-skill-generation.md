## 摘要
自动奖励设计（ARD）旨在通过语言驱动的奖励函数合成来替代强化学习中的手动奖励工程。然而，现有基于大语言模型（LLMs）的方法本质上仍然是相关性驱动的，依赖迭代的环境反馈来为每个特定任务优化奖励假设。这种范式不仅导致推理效率低下，而且使得LLMs容易受到语义上看似合理但因果虚假的奖励组件的影响，从而导致优化无效。为了解决这些局限性，我们提出了因果奖励世界模型（CRWM），该模型通过在多任务交互数据上进行离线预训练，显式地建模候选奖励组件与任务目标物理变量之间的因果拓扑关系。基于从粗到细的预训练策略，我们引入了一个联合优化模块，该模块将显式机制解耦与置信度感知的软融合相结合，利用微观层面的轨迹来细化粗粒度结构先验，从而构建一个稳健且可解释的因果骨架。在推理过程中，LLMs利用CRWM作为与任务无关的因果先验来约束奖励生成，从而实现零样本奖励函数设计。我们的工作为ARD问题开辟了一种新的白盒范式。在复杂连续控制基准上的大量实验表明，CRWM无需反馈驱动的奖励细化即可生成可执行的奖励函数，显著降低了获取新机器人技能的设计延迟，同时匹配或超越了最先进的性能，并进一步展现出在未见任务和多种机器人形态上的强泛化能力。

## Abstract
Automated Reward Design (ARD) aims to replace manual reward engineering in reinforcement learning with language-driven reward function synthesis. However, existing approaches based on large language models (LLMs) remain inherently correlation-driven, relying on iterative environmental feedback to refine reward hypotheses for each specific task. This paradigm not only results in inefficient reasoning but also makes LLMs susceptible to semantically plausible yet causally spurious reward components, leading to ineffective optimization. To address these limitations, we propose the Causal Reward World Model (CRWM), which explicitly models the causal topological relationships between candidate reward components and task-targeted physical variables through offline pre-training on multi-task interaction data. Based on a coarse-to-fine pre-training strategy, we introduce a joint optimization module that integrates Explicit Mechanism Decoupling with Confidence-Aware Soft Fusion to refine coarse structural priors using micro-level trajectories, thereby constructing a robust and interpretable causal skeleton. During inference, LLMs leverage CRWM as a task-irrelevant causal prior to constrain the reward generation, enabling zero-shot reward function design. Our work opens up a new white-box paradigm for the ARD problem. Extensive experiments on complex continuous control benchmarks demonstrate that CRWM generates executable reward functions without feedback-driven reward refinement, significantly reducing the design latency for acquiring new robotic skills while matching or surpassing state-of-the-art performance, and further exhibits strong generalization capabilities across unseen tasks and diverse robotic embodiments.

- **研究动机**：在基于强化学习的机器人技能获取中，奖励函数设计一直是核心挑战。传统方法依赖人工手动设计，易出错且耗时。近年来，大语言模型（LLM）驱动的自动化奖励设计（ARD）方法出现，通过语义推理生成可执行的奖励函数。然而，现有LLM-based ARD方法本质上是**相关性驱动**的，它们依赖迭代的环境反馈（试错）来优化奖励假设，导致两个严重问题：
  - **优化崩溃（Optimization Collapse）**：LLM引入了与任务语义相关但实际上因果虚假的奖励组件（如引入物体速度作为提升任务奖励，产生高频梯度噪声）。
  - **规范博弈（Specification Gaming）**：智能体利用虚假相关信号获得高奖励但未完成真实目标（如保持剪刀微开累积奖励）。
- **背景**：这些问题的根源在于LLM缺乏对奖励组件与任务目标之间**因果结构**的理解，现有方法未利用跨任务的奖励关系。理论上，同一动力学系统内不同任务的奖励组件共享因果结构，且因果结构是可识别的。
- **整体含义**：迫切需要一种能够显式建模因果拓扑、从多任务数据中学习共享因果先验的方法，从而实现零样本（zero-shot）奖励生成，消除对迭代环境反馈的依赖。

## 2. 方法论

### 2.1 核心思想
- 提出**因果奖励世界模型（CRWM）**，作为奖励设计的“因果核”（causal kernel）。CRWM通过离线多任务交互数据预训练，建模候选奖励组件与任务目标物理变量之间的**因果拓扑关系**。在推理时，LLM利用CRWM作为与任务无关的因果先验，进行零样本奖励函数生成，无需任务特定的反馈驱动细化。

### 2.2 关键技术细节
- **层次化数据收集（Hierarchical Data Collection）**：
  - 利用现有ARD框架（Eureka、URDP）提取各任务的k个物理含义奖励组件，通过“任务特定名称归一化”和“全局原子奖励组件池”将语义等价组件映射为d个共享结构变量V = {v1,...,vd}（如物体位置、速度、接触力等）。
  - 均匀采样N个权重向量ω(n)形成不同奖励函数，训练策略，作为对奖励组件权重的**干预操作**（do-operation）。
  - 收集两个层次的数据：
    - **宏观数据集 Dmacro**：记录N种权重配置下的最终适应度分数F(n)（任务成功率）。
    - **微观数据集 Dmicro**：记录每步结构变量的密集轨迹 st（维度d）。
- **结构先验提取（Structural Prior Extraction）**：
  - 使用预训练因果基础模型**LimiX**，从Dmacro估计因果效应矩阵 Mraw ∈ R^{d×d}，得到粗粒度结构先验 ⟨Mprior, Mconf⟩，其中Mconf编码归一化的效应幅度作为置信度。
  - 该先验作为后续细化初始值。
- **联合优化模块（Joint Optimization Module）**：
  - 解决两个问题：（1）单一静态拓扑混淆持久因果与状态依赖的瞬态交互；（2）粗先验可能包含结构幻觉和偏倚效应。
  - 提出**显式机制解耦（EMD）**：
    - 将瞬时拓扑 Minst(st-1) 分解为**可学习因果骨架 Minv**（保留用于奖励生成）和**状态依赖瞬态分量 Mtrans(st-1; θ)**（由MLP参数化）。
    - Minst(st-1) = Minv ⊙ (1_{d×d} + Mtrans(st-1; θ)) （Hadamard积）。
  - **置信度感知软融合（Confidence-Aware Soft Fusion）**：
    - 损失函数 L_soft = γ ||Mconf ⊙ (Minv - Mprior)||_F^2，对高置信度边施加强正则化，低置信度边更灵活。
  - 统一优化目标：
    - min_{Minv,θ} E_{(st-1,st)~Dmicro} [L_MSE(st, Minst(st-1)st-1)] + λ h(Minv) + L_soft
    - 其中h(Minv)是DAGMA无环正则化（-log det(αI - Minv⊙Minv) + d log α），确保因果骨架为有向无环图。
    - 使用**增广拉格朗日方法（ALM）**求解。
  - 收敛后得到优化骨架 M*_inv 作为最终CRWM。
- **因果自动奖励设计（Causal-ARD）**：
  - 对M*_inv的绝对因果效应值进行一维2-means聚类，自动确定阈值τ，提取活跃因果边。
  - 序列化为**因果拓扑提示**（source, target, causal effect三元组）。
  - LLM在系统指令中接收该提示，进行**因果剪枝**（Causal Pruning）：仅包含存在到score节点的因果路径的奖励组件，虚假相关项系数置零。
  - 最终的奖励函数通过一次生成（single pass）获得，无需环境反馈迭代。

### 2.3 算法流程（文字说明）
1. 收集离线干预数据集 D_off = {Dmacro, Dmicro}。
2. 用因果基础模型从Dmacro提取结构先验 Mprior, Mconf。
3. 初始化可学习骨架 Minv 和瞬态参数 θ。
4. 循环直到收敛：
   - 从Dmicro采样过渡对 (st-1, st)。
   - 构建瞬时拓扑 Minst(st-1) = Minv ⊙ (1 + Mtrans(st-1; θ))。
   - 计算重构损失、无环正则化、软融合损失，联合更新。
5. 提取收敛的 M*_inv。
6. 通过聚类设定阈值，提取活跃因果边，构建因果拓扑提示。
7. LLM基于任务描述、观测空间和因果拓扑提示，生成零样本奖励函数代码。

### 5.2 充分性评价
- **充分性**：实验覆盖了零样本性能、消融各组件、跨域泛化、实机验证、超参数敏感性，以及替代模型对比。20个Dexterity任务较全面，14/6划分合理。ManiSkill2验证了跨机器人形态和物理引擎泛化。实机实验进行了奖励对齐验证。
- **公平性**：所有LLM驱动方法使用相同底层LLM（deepseek-v3），因果基础模型LimiX统一。对比方法使用官方或已发表配置。评估指标明确。但注意：实验数据全部来自单一因果基础模型LimiX，虽然做了替代对比（AVICI），但仅图S-3显示结果相似，未提供更多细节。另外，所有实验在相同硬件条件下运行，但未报告随机种子或多次运行的标准差（仅在图中显示单点结果）。

## 6. 主要结论与发现
1. **因果先验显著提升零样本LLM奖励生成**：ZS-LLM在未见任务上SR极低（如<0.01），而CRWM引导的奖励达到0.85-0.96，说明语义推理不足，因果结构关键。
2. **达到或超越迭代SOTA方法**：在6个未见灵巧任务上，CRWM的零样本性能（ESI=0）与URDP（1-4次ESI）持平或更好，超过Eureka（4次ESI）。
3. **跨域泛化有效**：在ManiSkill2三个任务上，CRWM零样本SR为0.64-0.89，优于ZS-LLM，与迭代方法可比或更好。
4. **实机对齐准确**：CRWM引导的奖励在实机轨迹上AUC达94.5-99.6%，远高于ZS-LLM的47.9-62.5%。
5. **消融验证各组件必要性**：移除任何组件（先验、EMD、软融合）或替换为LLM推断先验都导致SR大幅下降（平均从0.85降至0.09-0.38），验证了CRWM设计的有效性。
6. **减少了设计延迟**：零样本生成免去每次任务的迭代环境交互，显著降低新技能获取时间。

## 7. 优点

### 7.1 方法论方面
- **因果驱动的白盒范式**：首次将显式因果结构引入奖励设计，可解释性强，可追溯虚假相关来源。
- **从粗到细的预训练策略**：利用因果基础模型获取粗先验，再通过微观轨迹细化，结合置信度软融合，有效处理状态依赖瞬态交互，结构稳健。
- **显式机制解耦**：将持久因果骨架与瞬态分量分离，避免静态拓扑混淆，同时保证无环约束。
- **零样本高效性**：一次离线预训练后，新任务奖励生成无需迭代环境反馈，大幅降低计算开销。
- **跨任务、跨形态泛化**：通过共享原子组件池和因果拓扑，可转移到不同机器人形态和物理环境。

### 7.2 实验方面
- **多层次验证**：仿真（Dexterity 20任务、ManiSkill2 3任务）、实机轨迹对齐、统计失效模式分析，覆盖全面。
- **公平对比**：所有LLM方法使用相同底层模型，基线采用公开成熟方法。
- **充分的消融**：逐个组件移除、替代先验，定量证明各部分贡献。
- **超参数敏感性分析**：给出了干预采样数N和软融合权重γ的影响。

## 8. 不足与局限
1. **预训练成本高**：离线阶段需要大量干预数据采集和策略训练（4200次运行），虽然是一次性，但对于新类别或资源受限场景可能难以承受。
2. **组件池覆盖有限**：CRWM的泛化受限于全局原子奖励组件池。如果目标任务涉及池外物理基元（如流体动力学、可变形物体），无法直接推理。未来需扩展开放词汇变量发现和自动池扩展。
3. **实机实验只做了奖励对齐验证**：仅通过遥操作轨迹检验奖励区分度，未进行完整的策略学习与部署。缺乏双手灵巧操作的sim-to-real验证（因硬件限制），实际部署性能未知。
4. **实验统计规范性不足**：未报告多次运行的标准差或置信区间，也未明确每次运行随机种子。图表中显示单点成功率，可能掩盖随机性。
5. **因果模型依赖**：结构先验提取依赖LimiX（一种预训练因果基础模型），虽然替代实验显示类似结果，但未深入分析不同因果基础模型对结果的影响边界。
6. **任务规模较小**：预训练仅14个灵巧任务，泛化实验只涉及3个ManiSkill2任务，在更广泛多变的机器人操作任务（如移动操作、双臂协作）上尚未验证。
7. **在ManiSkill2上某些任务零样本SR相对较低**（如OpenCabinetDrawer为0.64），虽优于基线，但与迭代方法（URDP 0.80）有差距，说明复杂长程任务可能仍需少量任务适配。
8. **未讨论环境动态变化**：如物体质量、摩擦系数变化等因果结构的稳健性未测试。
