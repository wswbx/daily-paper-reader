## 摘要
在线策略蒸馏（OPD）通过教师提供的密集的词元级监督，提高了标准强化学习的学习效率。在OPD的标准KL目标中，词元级损失被均匀平均，这意味着所有词元的权重相等。然而，我们发现并非所有词元都是平等的：随着学生生成的序列变长，它们偏离教师分布的程度加剧，导致后后位置的监督质量下降。因此，仅使用前30%词元的OPD可以与使用所有词元的OPD表现相当，而仅使用后30%词元的OPD几乎学不到任何东西。在本文中，我们通过约束优化的视角对这一现象提供了原则性的理解。基于这些见解，我们推导出重要性加权在线策略蒸馏（IW-OPD），其中每个词元的权重取决于学生与教师分布之间的累积差异，自然地对早期词元赋予更高权重，而对偏差较大的后期词元赋予较低权重。我们展示了IW-OPD比OPD收敛更快，学习效率更高，并且在同尺寸和跨尺寸设置中均比标准OPD取得更好的最终性能，在AIME-2025上提升了高达6.9个点。

## Abstract
On-Policy Distillation (OPD) improves the learning efficiency of standard reinforcement learning through dense, token-level supervision from teachers. In the standard KL objective of OPD, token-level losses are uniformly averaged, implying equal weights for all tokens. However, we discover that not all tokens are created equal: as student rollouts grow longer, they deviate further from the teacher's distribution, leading to degraded supervision quality at later positions. As a result, OPD using only the first 30% of tokens can perform comparably to using all tokens, whereas OPD using only the last 30% of tokens barely learns anything. In this work, we provide a principled understanding of this issue through the lens of constrained optimization. Based on these insights, we derive Importance-Weighted On-Policy Distillation (IW-OPD), in which the weight assigned to each token depends on the accumulated discrepancy between the student's and teacher's distributions, naturally upweighting earlier tokens and downweighting later ones with larger deviations. We show that IW-OPD converges significantly faster than OPD, with better learning efficiency, and achieves better final performance than standard OPD in both same-size and cross-scale settings, improving performance up to 6.9 points on AIME-2025.

## 2. 方法论

### 核心思想
- 将OPD视为一个**有有限预算的局部投影问题**：学生每次更新只能在KL散度预算ρ内移动，最优投影策略`q⋆`应对教师分布πT与学生当前分布πθ的似然比进行重加权。
- 从约束优化视角导出最优策略，再将其转化为一个可训练的重要性加权OPD目标（IW-OPD），自动上调教师兼容的早期词元权重，下调偏差大的后期词元权重。

### 关键技术细节
1. **约束优化框架**（公式7）：
   - 目标：最小化 `DKL(q∥πT)`，约束为 `DKL(q∥πθ) ≤ ρ`。
   - 闭式解（命题1）：`q⋆(y) = πθ(y) · r(y)α / Zα`，其中 `r(y)=πT(y)/πθ(y)`，α∈(0,1)由ρ决定。
2. **重要性加权目标**（命题2）：
   - 对`q⋆`优化KL散度等效于对OPD的每个词元损失施加权重 `˜rt = rt / Zα,t`（前缀似然比归一化）。

3. **稳定性技巧**（§4.2）：
   - **对数缩放**：将似然比转换为对数空间累积优势 `˜r_t^log = α ∑_{k<t} A_k^OPD`。

## 4. 主要结论与发现

1. **位置偏差明确存在**：OPD仅前30%词元即可持平全词元训练，仅后30%几乎无效；教师在长学生前缀上的正确率迅速下降。
2. **IW-OPD显著提升样本效率**：在训练早期（step 10）即超过标准OPD最终性能，例如教师30B→学生4B时AIME25从42.4提升到49.3。
3. **最终性能一致提升**：在全部实验设置中，IW-OPD均优于标准OPD，平均准确率提升1~6.9分，尤其在小学生（如0.6B）和大教师（如235B）时增益更大。
4. **效用随教师-学生差距增大而增大**：更弱的教师（4B）提升较小（+1.0平均），更强的教师（30B）提升更显著（+1.8平均），且学生越小相对增益越大。
5. **可与其他奖励设计正交**：结合ExOPD后IW-ExOPD进一步提升，说明前缀重要性加权是通用机制。

## 5. 优点

- **理论驱动**：从约束优化推导出加权形式，逻辑严密，为位置偏差提供原则性解释。
- **简单高效**：仅需在标准OPD基础上多计算累积绝对优势和归一化，无额外教师前向传播。
- **全面稳定技巧**：对数缩放、符号修正、归一化、插值等确保训练稳定，且在消融中验证了各组件必要性。
- **广泛适用**：在同尺寸、跨尺度、超大规模蒸馏中均有效，且与现有OPD变体兼容。
- **公平对比**：超参数与标准OPD保持一致，评估使用相同种子，结果可靠。

## 6. 不足与局限

- **收敛后权重非完全均匀**：`˜r_t`在收敛后仍近似1-t/T，残留轻微非均匀性，可能影响最终性能。
- **累积前缀差异是保守代理**：它不是精确的密度比校正，而是基于绝对优势和的启发式度量，可能不是最优选择。
- **实验规模限制**：最大学生为4B（表1/2）；虽然教师达235B，但学生仍较小。在更大学生（如30B+）上的验证未包含。
- **未评估对其他OPE变体（如GKD）的适用性**：仅测试了OPD和ExOPD，广义性待验证。
- **未分析计算开销**：仅定性说“无需额外教师评估”，但学生端计算累积操作的时间开销未量化。
- **长序列的稳定性**：最大响应长度16384 tokens，未讨论极端长序列下权重计算的数值稳定性。
