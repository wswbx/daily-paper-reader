## 摘要
强化学习通常通过轨迹的终端结果提升多轮智能体能力，这使得难以确定每个中间轮的信用分配。最近的在策略自我蒸馏方法通过自我教师将特权反馈转换为密集的token级监督，提供了一种有前景的替代方案。我们的研究源于将这种范式简单扩展到多轮设置时观察到的意外性能下降，我们将其归因于特权反馈（如成功轨迹或终端结果）与学生当前决策上下文之间缺乏对齐。我们提出HERO，一种基于 hindsight 增强的自我蒸馏框架，使用下一个环境观测作为局部对齐的反馈。在每次 rollout 之后，HERO对完成的交互进行反思，将每个观测转换为紧凑的turn级诊断，捕捉关于原始动作的可操作反馈，如其必要性、有效性或失败原因。在TauBench和WebShop上，HERO提高了任务成功率，并减少了不必要的回合，优于仅环境反馈的自我蒸馏和GRPO。它在有限的训练回合预算下特别有效，此时成功 rollout 很少，GRPO提供的奖励对比信号较弱。

## Abstract
Reinforcement learning typically improves multi-turn agent capabilities through the terminal outcome of the trajectories, which makes it difficult to determine credit assignments for each intermediate turns. Recent on-policy self-distillation methods offer a promising alternative by converting privileged feedback into dense token-level supervision through a self-teacher. Our study is motivated by the unexpected performance degradation observed when naively extending this paradigm to multi-turn settings, which we attribute to a lack of alignment between privileged feedback, such as successful trajectories or terminal outcomes, and the student's current decision context. We introduce HERO, a hindsight-enhanced self-distillation framework that uses next environment observations as locally aligned feedback. After each rollout, HERO reflects on the completed interaction to convert each observation into a compact turn-level diagnosis, that captures actionable feedback about the original action such as its necessity, validity or failure cause. On TauBench and WebShop, HERO improves task success and reduces unnecessary turns over environment-feedback-only self-distillation and GRPO. It is especially effective under limited training turn budgets, where successful rollouts are rare and GRPO provides weak reward-contrast signals.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：在多轮智能体任务（multi-turn agent tasks）中，传统强化学习方法（如PPO、GRPO）依赖轨迹的终端奖励来优化策略，导致**信用分配困难**——中间步骤的动作难以从稀疏的二元结果中获得有效反馈。近期提出的在策略自蒸馏方法（如SDPO、OPSD）虽能将终端奖励或成功示范转化为密集的 token 级监督，但简单将其扩展到多轮场景时，作者观察到**性能意外下降**。
- **根源分析**：这种下降源于**特权反馈与学生当前决策上下文之间的错位**。例如，将完整的成功轨迹作为教师的条件，教师可以看到未来动作和结果，而学生只能看到当前历史，这种信息不对称导致教师信号包含非因果捷径（non-causal shortcuts），从而产生误导性的 token 级监督。
- **背景意义**：多轮智能体在长序列交互中往往成功轨迹稀少，尤其是当训练阶段交互轮次预算严格时，GRPO 等 outcome-based RL 方法因缺乏奖励对比而失效。因此，寻找一种既密集又与局部决策上下文对齐的反馈信号成为关键。作者提出：最易获取且局部对齐的反馈信号是**每个动作后的下一个环境观测（next environment observation）**。

## 2. 方法论：HERO 框架

### 2.1 核心思想
HERO 通过**事后反思（hindsight reflection）**将每个 on-policy roll-out 中的环境观测转换为紧凑的 turn-level 诊断（hint），再以该诊断作为特权条件，驱动自我教师（self-teacher）对学生原始动作的 token 分布进行重新评估，从而产生密集且对齐的 token 级监督。

### 2.2 技术细节

- **三阶段流程**：
  1. **学生策略生成轨迹**：在标准因果交互历史下，学生策略 π_θ 逐轮采样动作，产生完整轨迹 τ = (x, y_1, o_1, ..., y_T, o_T)。
  2. **反思器生成 turn-level hints**：roll-out 结束后，反思器 R 观察完整轨迹 τ 和最终奖励 R(τ)，为每个 assistant turn t 输出结构化 hint h_t = (d_t, â_t)，其中 d_t 是自然语言诊断（如“使用了虚构的用户信息，应询问真实姓名”），â_t 是可选的修正动作。h_t 仅包含与该 turn 相关的 hindsight 信息，不暴露原始未来轨迹。
  3. **自我教师重新评估**：教师（使用当前策略 π_θ 的 EMA 副本）被赋予学生原有的决策上下文 H_t、环境观测 o_t、最终奖励 R(τ) 以及 hint h_t，构成特权上下文 \tilde{H}_t。教师对每个 token 位置计算目标分布 q_t^k = sg[π_θ(· | \tilde{H}_t, y_t^{<k})]，学生优化自身分布 p_t^k 以匹配 q_t^k。

- **损失函数**：对每个拥有非空 hint 的 turn t，计算所有 token 位置上的 Jensen-Shannon 散度，然后取平均。公式如下：
  ```markdown
  L_HERO(θ) = E_{τ∼π_θ} [ (1/|I(τ)|) Σ_{t∈I(τ)} (1/|y_t|) Σ_{k=1}^{|y_t|} D_JSD(p_t^k, q_t^k) ]
  ```
  其中 I(τ) 是 hint 非空的 turn 集合。

- **关键特性**：
  - **从失败轨迹中学习**：即使所有 roll-out 都失败（奖励为 0），只要反思器能生成有意义的 hint，教师仍能提供非零监督。这解决了 GRPO 在严格 turn 预算下奖励对比为零的瓶颈。
  - **无需外部教师**：反思器和教师均基于学生策略自身（或 EMA 副本），实现完全自蒸馏。

## 3. 实验设计

### 3.1 数据集与基准
- **主要基准**：
  - **TauBench-Retail**：多轮客户服务任务，使用结构化 API（查询订单、退货等），二进制奖励（成功/失败）。训练集 500 条，测试集 115 条。
  - **WebShop**：多轮网页购物任务，需导航产品页面、选择属性、下单。训练集 6219 条，测试集 691 条。奖励为连续值（0~1）。
- **额外评估**：TauBench-Airline（50 条测试集）作为**领域外（OOD）**基准，用于测试跨域泛化能力。

### 3.2 对比方法
- **Base**：无额外训练的指令微调模型。
- **Environment Feedback Only**：仅将原始环境反馈（如工具返回的错误信息）作为教师条件，无 hindsight 反思。
- **Full-Demo Privileged Teacher**：简单将完整成功轨迹作为每轮教师的特权上下文（类似 SDPO 的多轮扩展）。
- **GRPO**：基于组相对优势的强化学习。使用 8 个 roll-out 每组，学习率调优后选择 2×10⁻⁶。
- **HERO (ours)**：使用单次 roll-out (G=1)，学习率 2×10⁻⁷，EMA 教师更新率 0.001，JSD 损失 α=0.5，裁剪阈值 ε_min=0.4, ε_max=10。

## 6. 主要结论与发现

1. **HERO 显著提升成功率并减少冗余轮次**：在 Qwen3-4B 上，TauBench-Retail SR 从 GRPO 的 33.3% 提升至 34.7%，Airline 从 18.0% 提升至 19.5%，WebShop 从 65.2% 提升至 68.9%。同时平均轮次大幅降低（Retail 从 13.4 降至 9.6）。
2. **严格 turn 预算下 HERO 优于 GRPO**：当训练预算小于测试预算时，GRPO 因成功 roll-out 稀少而失效，HERO 仍能通过失败轨迹的反思持续改进。
3. **单 roll-out 训练有效**：HERO 在 G=1 时仍然有效，而 GRPO 在 G=1 时优势为零。
4. **全成功轨迹教师会损害性能**：Full-Demo 基线在所有设置下均低于 Base 模型，证实上下文错位的危害。
5. **反思比原始环境反馈更有效**：消融实验显示，仅 Reflection 已显著优于 Raw env feedback，加入环境反馈和最终奖励进一步提升。
6. **通用能力未退化**：MMLU、MMLU-Pro、IFEval 分数在训练前后基本不变。
7. **反思质量与教师性能相关**：使用 GPT-4o 作为外部反思器带来额外提升，但自反思已接近最优，暗示局部执行错误易于自动诊断。

## 7. 方法优点

- **简洁高效**：仅需单次 roll-out，因反思和教师 forward 计算的开销远小于多 roll-out 的交互成本。
- **本地对齐**：通过压缩 hindsight 为紧凑 hint，避免未来信息污染，使教师信号更精确。
- **免专家数据**：完全自蒸馏，不依赖外部教师或成功示范。
- **鲁棒性强**：能在成功轨迹稀少的场景下有效学习。
- **可迁移性**：跨域（零售→航空）泛化良好。

## 8. 不足与局限

- **依赖指令跟随能力**：反思器和教师均需模型正确理解提示并生成结构化输出。对弱指令微调模型（如基础模型）可能效果有限。
- **仅适合可事后诊断的错误**：对于复杂数学推理、深层步骤规划等，模型自身可能无法诊断根本原因（如逻辑谬误），反思器输出的 hint 质量下降。
- **计算开销**：虽然单步训练时间快于 GRPO，但每步仍需要额外一次教师 forward pass（相当于两倍推理）。在极端长序列下可能内存压力大。
- **实验覆盖有限**：仅测试了两个领域（零售、航空购物），未涵盖更多类型（如编程、对话、机器人控制）。也未与 process reward model 或 hierarchical RL 等方法对比。
- **反思器失败模式**：附录 E 指出存在 hindsight leakage（引用未来的信息）、recency bias（归因于最新轮次）、over-confident corrections（提出不支持的动作）等错误。虽然大部分 hint 正确，但错误 hint 可能引入噪声。
- **通用能力保留验证不充分**：仅使用了 MMLU、MMLU-Pro、IFEval，未测试更广泛的 NLP 任务（如翻译、摘要），存在过拟合风险。
