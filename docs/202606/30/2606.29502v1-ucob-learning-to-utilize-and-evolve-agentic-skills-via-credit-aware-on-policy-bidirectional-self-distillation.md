## 摘要
技能记忆可以通过将过去经验作为文本指导来改善智能体强化学习，但检索到的技能并非 oracle：它们可能在一种状态下有帮助，而在另一种状态下却误导相同的策略。这使得常见的特权教师假设变得脆弱，即技能条件的提示可以被视为无技能提示的固定教师。我们提出UCOB，一个通过信用感知的在策略双向自蒸馏来学习利用和演化智能体技能的框架。UCOB将技能条件和无技能提示视为同一模型的两个在策略上下文视图，比较它们在同一任务和锚定状态下的剩余回报，并使用更高回报的视图作为局部教师。这种局部信用信号内化了有用的技能条件行为，纠正了误导性的技能使用，并指导任务/状态技能记忆更新、效用感知检索和反思自我训练。在包括ALFWorld、WebShop和Search-QA的智能体任务上的实验表明，UCOB在不同模型规模上优于无技能RL、技能记忆基线和自蒸馏方法，在ALFWorld和WebShop上比最先进的基线分别高出23.5和18.0个百分点。消融和分析进一步验证了其核心机制和效率。

## Abstract
Skill memories can improve agentic reinforcement learning by reusing past experience as textual guidance, but retrieved skills are not oracular: they may help in one state while misleading the same policy in another. This makes the common privileged-teacher assumption fragile, namely that a skill-conditioned prompt can be treated as a fixed teacher for the no-skill prompt. We introduce UCOB, a framework for learning to utilize and evolve agentic skills via credit-aware on-policy bidirectional self-distillation. UCOB treats skill-conditioned and no-skill prompts as two on-policy context views of the same model, compares their return-to-go within the same task and anchor state, and uses the higher-return view as the local teacher. This local credit signal internalizes useful skill-conditioned behavior, corrects misleading skill usage, and guides task/state skill memory updates, utility-aware retrieval, and reflection self-training. Experiments on agentic tasks, including ALFWorld, WebShop, and Search-QA, show that UCOB outperforms skill-free RL, skill-memory baselines, and self-distillation methods across model scales, with up to 23.5 and 18.0 point gains over SOTA baselines on ALFWorld and WebShop. Ablations and analyses further validate its core mechanisms and efficiency.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在智能体强化学习中，技能记忆（skill memory）虽然可以复用过去经验，但检索到的技能并非永远有益——它们可能在某个状态下帮助策略，在另一个状态下却误导策略。现有方法（如SDAR）通常将技能条件提示视为无技能提示的固定教师（privileged teacher），但这一假设不可靠：技能条件视图并不总是优于无技能视图，即使让技能条件视图也参与在线策略rollout仍不能保证其权威性。
- **整体含义**：智能体需要学会“何时信任技能、何时纠正技能”，即技能利用应是一个信用分配问题（credit assignment），而非固定方向的蒸馏。论文引入UCOB框架，通过信用感知的在线双向自蒸馏，让技能条件和无技能两个视图在同一任务和锚定状态下比较剩余回报，高回报视图成为局部教师，从而实现有用技能内化、误导技能纠正，并驱动技能记忆的演化。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：
  - 将技能条件提示（skill-conditioned prompt）和无技能提示（no-skill prompt）视为同一在线策略模型的两个上下文视图，在训练时让它们都参与环境交互（混合rollout），然后根据同一任务和锚定状态（anchor state）下的剩余回报（return-to-go）决定教师方向：哪一视图局部回报高，哪一视图就成为另一视图的教师。
  - 这种“信用感知的双向自蒸馏”（Credit-Aware Bidirectional Self-Distillation, CBSD）同时支持有用技能的蒸馏和误导技能的纠正，并进一步更新技能记忆效用、优化技能检索和反思式技能写作，形成策略学习与技能演化的闭环。

- **关键技术细节**：
  1. **双级技能记忆与UCB检索**：维护任务级和状态级两个技能池，在线扩展。检索时使用UCB分数平衡效用与探索。
  2. **混合技能/无技能Rollout**：每批次中一半轨迹使用技能条件提示，一半使用无技能提示，两者均受在线RL损失优化。
  3. **锚定状态分组**：按任务和锚定状态将不同视图的轨迹记录分组，得到具有相同上下文的可比集合。
  4. **CBSD（信用感知双向自蒸馏）**：
     - 在每个锚定状态组内，选择最高剩余回报的记录作为信用参考（credited reference），其分支记为c*。
     - 对于分支相反的记录，形成教师-目标对，仅保留回报差 > ϵ<sub>CBSD</sub> 的对。
     - 在参考前缀上计算每个token的Top-K分布支持，并将参考分布（stop-gradient）蒸馏到目标视图分布，通过KL散度损失。
     - 损失中用置信门控（confidence gate）和回报差加权（gap weight）调控强度。
     - 方向自动决定：若技能视图获胜，则技能→无技能；若无技能视图获胜，则无技能→技能。
  5. **技能记忆演化**：
     - 利用CBSD中产生的信用证据更新技能效用（EMA更新）。
     - 利用效用驱动的优势值训练反思式技能写作器（reflection self-training），采用PPO风格的目标。
  6. **整体训练目标**：L = L<sub>RL</sub> + λ<sub>CBSD</sub>L<sub>CBSD</sub> + λ<sub>refl</sub>L<sub>refl</sub> + β<sub>KL</sub>L<sub>KL</sub>。

- **理论视角**：论文给出了一个局部策略改进的解释（Proposition 1）：在正确估计分支序的前提下，将低回报分支向高回报分支移动一小步，可保证局部advantage surrogate提高，且性能差下界中包含正的ηδ<sub>x</sub>项，从而解释CBSD的有效性。
