## 摘要
符号回归旨在从数据中揭示明确的科学定律。近期方法利用大语言模型引导基于背景文本的变异，这比随机遗传编程更具方向性。然而，精确的符号恢复需要同时具备语义引导和显式结构，以便通过有效的符号表示进行领域信息搜索。当前的大语言模型驱动系统仍然是结构盲的：它们在黑箱候选之间进行选择，缺乏局部变异的显式机制，并依赖于脆弱的系数拟合，这可能低估正确的骨架。我们提出FunctionEvolve，一个利用表达式树组织整个搜索的进化框架：结构摘要促进多样化的父代选择，局部树编辑保留有用的子表达式，而结构感知的拟合分解、约束和简化系数，以实现更可靠的评分。它仅使用基本函数族，没有额外的领域特定规则限制泛化能力。在LLM-SRBench的129任务合成子集上，使用Claude Opus 4.6的FunctionEvolve恢复了107个精确形式，达到82.9%的SA@50，是相同骨干基线的4.5倍，以及55.8%的SA@1，是此前最强已发表top-1结果的3.6倍。消融实验表明，结构可见搜索是可靠恢复的核心，大语言模型引导的改进和结构感知的系数优化作为关键的提议和评分机制。我们还对基准进行了审计，表明其材料科学子集中的共线性产生了可识别性问题。

## Abstract
Symbolic regression aims to uncover explicit scientific laws from data. Recent methods use LLMs to guide mutation from background text, which is more directed than random genetic programming. However, exact symbolic recovery requires both semantic guidance and explicit structure, so that domain-informed search are carried out through valid symbolic representation. Current LLM-driven systems remain structure-blind: they select among opaque candidates, lack explicit mechanisms for local mutation, and rely on brittle coefficient fitting that can undervalue correct skeletons. We propose FunctionEvolve, an evolutionary framework using expression trees to organize the whole search: structural summaries promote diverse parent selection, local tree edits preserve useful subexpressions, and structure-aware fitting decomposes, constrains, and simplifies coefficients for more reliable scoring. It uses only elementary function families, without additional domain-specific rules limiting generalization. On the 129-task synthetic subset of LLM-SRBench, FunctionEvolve with \emph{Claude Opus 4.6} recovers 107 exact forms, reaching 82.9% SA@50, 4.5x above same-backbone baselines, and 55.8% SA@1, 3.6x above the strongest previously published top-1 result. Ablations show that structure-visible search is central to reliable recovery, with LLM-guided refinements and structure-aware coefficient optimization serving as essential proposal and scoring mechanisms. We also audit the benchmark and show that collinearity in its materials-science subset creates identifiability issues.

- **核心问题**：如何在LLM驱动框架中显式利用表达式结构（AST），使搜索同时具备语义引导和结构可见性，从而可靠恢复精确符号形式。
- **整体含义**：LLM驱动的符号回归要取得进展，不能仅靠语义，必须让结构在“选择→变异→拟合”各环节中发挥主动作用。

## 2. 论文提出的方法论
### 2.1 核心思想
- 以**表达式树（AST）**为中心组织整个进化搜索流程，使结构信息在父代选择、局部变异和系数拟合中可见且可操作。
- 融合**确定性规则变异**（保证局部编辑的系统性）和**LLM引导的上下文相关变异**（利用领域知识进行非模板化调整），同时通过**结构感知系数优化**提升评分可靠性。

### 2.2 关键技术细节
- **Generator（生成器）**：利用LLM从任务上下文和领域知识中合成初始表达式种子，避免从无结构的随机池开始搜索。
- **Selector（选择器）**：每一轮进化中，提取进化树的摘要（包括AST结构、参数数量、深度、算子计数、训练NMSE和拟合参数），让LLM据此挑选有前景的父代节点，兼顾低误差、简单性和结构多样性，同时避免过度重复已有分支。
- **Mutator（变异器）**：对每个选中父代执行三类操作：
  - **规则添加**：通过加、乘、除、一元包装等操作附加固定基本函数库（线性、三角函数、幂、指数、对数、有理分式等）；
  - **规则删除**：修剪或展开AST子树以测试冗余部分；
  - **LLM引导变异**：使用父代结构、拟合参数、规则生成的候选、搜索历史及领域知识，提出非模板化局部改进（ADD保留父代并附着新材料；SUBST替换有问题的子树）。
- **Optimizer（优化器）**：结构感知的系数拟合管道：
  - **变量投影**：分离线性与非线性参数，用最小二乘求解线性部分；
  - **全局探索**：对非线性子空间使用CMA-ES、差分进化等；
  - **局部精调**：L-BFGS-B细化；
  - **参数快照**：将指数等结构性参数快照到附近整数或有理数（仅当重拟合后目标不恶化时接受）；
  - **符号简化**：合并冗余参数、简化恒等式（如exp(0)、log(1)），然后重新拟合。

### 2.3 算法流程（文字描述）
1. 由Generator基于任务上下文生成领域知识和初始种子表达式；
2. 将种子表达式解析为AST，进行规范化、去重，并通过Optimizer拟合系数和评分，存入进化树；
3. 循环迭代（最多30轮）：
   - Selector基于进化树摘要选出5个父代；
   - Mutator对每个父代应用规则变异和LLM引导变异，产生多个候选；
   - 候选经规范化、去重、有效性和退化检查（过度拟合、简化等）后，由Optimizer拟合评分；
   - 结果加入进化树，标记成熟节点（训练NMSE低于阈值）；
   - 若成熟节点达到50个则提前终止；
4. 最后按训练NMSE返回排序的表达式。

- **结构感知优化器关键**：替换为L-BFGS后SA从107降至53，优化器基准显示结构感知优化器在真实骨架变体上的成功率远高于通用优化器（98.4% vs ~70-80%）。
- **LLM引导变异和规则变异互补**：两者均不可少，去除LLM Mutator或AST Mutator均导致显著下降。
- **噪声敏感**：1%噪声下SA@50降至54，5%噪声降至40，说明需要更鲁棒的评分机制。
- **基准缺陷**：材料科学子集存在严重输入变量共线性（T≈273+500ϵ，R²≈1），导致关键机制无法识别，Arrhenius因子变化极小，结构不同表达式也能达到极低NMSE。非材料科学失败案例中多数也存在高相关性变量对。
- **AI-Feynman全恢复**：在120任务上SA@1=120/120，但首次出现集中在第0轮（LLM种子），反映经典公式可能已被预训练记忆。

## 7. 优点
- **结构可见的全流程设计**：将AST结构显式融入选择、变异、拟合，不是孤立于某一步，而是作为组织搜索的骨架。
- **LLM与确定性规则的有效融合**：规则保证局部编辑的系统性和可靠性，LLM提供上下文感知的灵活改进，两者互补而非替代。
- **结构感知系数优化器**：通过变量投影、参数快照、符号简化等技术，显著提高了正确骨架的评分可靠性，减少了因拟合失败导致的误判。
- **无领域特定规则**：使用通用基本函数族和代数模板，保持低归纳偏置，泛化能力强（可在物理、化学、生物、材料多个领域取得好成绩）。
- **资源效率高**：平均LLM调用次数远低于基线，且多数评估可并行化，实际壁钟时间可控。
- **对基准的深刻审计**：揭示了LLM-SRBench中的共线性问题，对后续基准设计有指导意义。
- **实验严谨性**：LLM判别可靠性审计、消融覆盖全面、多骨干验证、复杂度感知后处理分析。

## 8. 不足与局限
- **噪声鲁棒性不足**：在观测噪声下恢复率大幅下降，表明当前框架缺乏不确定性感知评分机制。
- **材料科学子集性能弱**：仅恢复15/25 SA@50和6/25 SA@1，虽然部分归因于基准共线性，但也暴露方法在依赖数据多样性发现唯一结构时的局限性。
- **SA@50与SA@1的差距**：许多正确表达式出现在top-50但非top-1，说明训练NMSE排名仍不能可靠区分正确与过拟合替代表达式，复杂度后处理虽能改善但尚未完全解决。
- **依赖高级LLM**：最佳结果需要Claude Opus 4.6等前沿模型；在较弱模型（如Llama-3.1-8B）上SA@1仅23，且需要JSON格式遵循能力强，弱模型可能产生更多无效输出。
- **未覆盖复杂场景**：论文未处理动态系统、无闭式解方程、更大候选变量集合等情况，适用范围有待进一步验证。
- **自定义基准审计可能引入主观偏差**：虽然共线性分析明确，但其他未见领域的结构可识别性问题未被系统检查。
- **实际应用限制**：符号回归在实验科学中常面临高噪声、变量多重共线性、小样本等挑战，论文的噪声实验仅覆盖1%和5%水平，真实场景可能更复杂。
