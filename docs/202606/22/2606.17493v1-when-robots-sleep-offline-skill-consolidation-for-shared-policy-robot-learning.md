## 摘要
长期部署中学习的机器人必须在不丢失使早期技能可重用的共享策略结构的情况下添加新技能。我们研究顺序机器人技能学习，其中先前的轨迹和任务损失可能不可用，且部署的策略必须保持单一共享控制器，没有特定任务头、路由或适配器。我们识别出技能耦合崩溃，一种故障模式，其中单个技能成功保持非平凡，但相关技能间的可靠性恶化。我们提出沉睡机器人，一个醒睡框架，在清醒时学习每个新技能，在睡眠时使用紧凑的冰冻技能记忆离线巩固共享策略：用于强化学习的冰冻评论家与无序状态缓冲区，以及用于模仿学习的冰冻演员快照与无序观察缓冲区。在睡眠期间，这些记忆定义可微的代理目标，其梯度通过纳什讨价还价结合，具有自适应锚定和局部兴奋性以稳定巩固。在Meta-World MT5上，沉睡机器人相对于最强的非神谕基线提高了64%的平均成功率和2倍的成对可靠性，在SurgicAI上，相对于持续模仿基线提高了平均成功率和向后转移，同时在成对可靠性上保持竞争力。

## Abstract
Robots that learn over long deployments must add new skills without losing the shared policy structure that makes earlier skills reusable. We study sequential robot skill learning, where previous trajectories and task losses may be unavailable, and the deployed policy must remain a single shared controller without task-specific heads, routing, or adapters. We identify skill-coupling collapse, a failure mode in which individual skill success remains non-trivial while reliability among related skills deteriorates. We propose Sleeping Robots, a wake-sleep framework that learns each new skill during wake and consolidates the shared policy offline during sleep using compact frozen skill memories: frozen critics with unordered state buffers for reinforcement learning and frozen actor snapshots with unordered observation buffers for imitation learning. During sleep, these memories define differentiable surrogate objectives whose gradients are combined through Nash bargaining, with adaptive anchoring and local excitability for stable consolidation. On Meta-World MT5, Sleeping Robots improves average success by 64 % and pairwise reliability by x 2.0 over the strongest non-oracle baseline, and on SurgicAI it improves average success and backward transfer relative to continual imitation baselines while remaining competitive on pairwise reliability.

# 论文总结：When Robots Sleep: Offline Skill Consolidation for Shared-Policy Robot Learning

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：机器人在长期部署中需要顺序学习新技能，但必须保持单一的共享策略（shared policy），而不能依赖任务特定的头、路由或适配器。现有持续学习方法主要关注单个任务的保留（防止灾难性遗忘），但忽略了共享策略中**技能之间的耦合可靠性**——即单个技能成功率高，但相关技能组合在一起时可靠性却大幅下降。作者将这种失效模式称为**技能耦合崩塌（skill-coupling collapse）**。
- **整体含义**：提出“沉睡机器人”（Sleeping Robots）框架，通过模仿生物睡眠的离线巩固机制，在“清醒”阶段学习新技能，在“睡眠”阶段利用紧凑的冻结技能记忆（frozen skill memories）离线整合共享策略，从而缓解技能耦合崩塌，提升多技能共享策略的协同可靠性。

## 2. 论文提出的方法论

- **核心思想**：分离在线获取（wake）与离线巩固（sleep）。在清醒阶段，使用适合该领域的算法（RL或模仿学习）学习当前技能，并将其存储为紧凑的冻结内存；在睡眠阶段，所有先前技能的冻结内存共同定义可微代理目标，通过纳什讨价还价（Nash bargaining）合并梯度，并结合自适应锚定和局部兴奋性进行稳定巩固。
- **关键技术细节**：
  - **冻结技能记忆**：
    - 对于强化学习（RL）：冻结的评论家（critic） + 无序状态缓冲区 + 归一化器快照。
    - 对于模仿学习（IL）：冻结的演员（actor）快照 + 无序观测缓冲区。
    - 不存储完整轨迹、奖励或动作，仅保留必要信息用于睡眠梯度生成。
  - **睡眠目标函数**：
    - RL：通过冻结评论家对当前策略在存储状态上的Q值取负作为目标。
    - IL：通过冻结演员与当前策略在存储观测上的动作输出差异的L2距离作为目标。
  - **纳什讨价还价梯度协调**：对每个技能的梯度进行L2归一化，通过求解一个对数乘积最大化问题，得到凸权重α⋆，从而形成协商后的梯度方向g⋆，避免单一技能主导。
  - **自适应睡眠锚定**：若当前策略参数与先前醒结束检查点距离小于阈值，则增加一个L2正则项拉向巩固后的检查点，防止过度偏移。
  - **局部兴奋性（local excitability）**：仅用于前馈RL策略的隐藏神经元，通过局部活动统计而非反向传播更新增益系数，以稳定训练。
- **算法流程**（文字说明）：
  1. 对每个技能k，先执行清醒训练（RL或IL），保存醒结束参数θ_wake_k和冻结记忆M_k。
  2. 当k≥2时进入睡眠阶段：计算所有存储记忆的梯度，归一化后通过Frank-Wolfe迭代求解纳什权重，得到协商梯度g⋆。
  3. 若满足锚定条件，添加锚定项；使用Adam优化器更新策略参数。
  4. 更新局部兴奋性变量（仅RL）。
  5. 循环直到睡眠目标收敛或达到最大迭代次数。

## 3. 实验设计

- **数据集/场景**：
  - **Meta-World MT5**：五个模拟Sawyer操作任务（到达、开门、开抽屉、关窗、按按钮），状态空间39维，动作空间4维。使用SAC（强化学习）策略，冻结评论家记忆。
  - **SurgicAI**：基于AMBF模拟器的达芬奇缝合任务，五个子技能（接近、放置、插入、重抓、拔出），使用视觉条件ACT（模仿学习）策略，冻结演员记忆。观测包括640×480 RGB图像和低维状态。
- **Benchmark**：顺序学习五个技能，每个技能训练后评估所有已学技能，报告**平均最终成功率（AFSR）**、**成对可靠性得分（PRS）**、**向后转移（BWT）** 和**协同保持指数（SPI）**。
- **对比方法**：
  - **Meta-World MT5**：EWC、A-GEM、DER、CLEAR、Reset & Distill (R&D)、Progress & Compress (P&C)、Nash-MTL、PCGrad、CompoNet。所有方法使用相同SAC骨干网络和训练预算。
  - **SurgicAI**：顺序BC、EWC、LwF、M2Distill、SR Wake-Only（本方法去除睡眠）、以及神谕MT-Joint（联合训练所有技能）。

## 6. 论文的主要结论与发现

- **主要发现**：持续学习不应仅评估单独任务保留。在MT5上，许多基线保留部分单个技能成功但成对可靠性急剧下降，证实了技能耦合崩塌。沉睡机器人通过离线巩固有效缓解这一失效，在MT5上AFSR相对最强非神谕基线提升64%，PRS提升2倍，SPI远超基线。在SurgicAI上，在保持竞争力的条件下取得最佳AFSR和BWT。
- **消融重要结论**：清醒单独训练（无睡眠）性能最差；纳什讨价还价优于简单平均梯度；移除锚定或兴奋性会降低整体平衡性能。完整组件可获得最佳平均指标。
- **鲁棒性**：逆序和8技能扩展仍能保持显著优势，表明结果不依赖特定顺序或长度。
