## 摘要
基于可验证奖励的强化学习（RLVR）在训练大语言模型完成推理任务方面取得了显著进展，但代表性方法如GRPO对所有token分配统一信用，在常规token上浪费梯度，而对关键推理步骤的信用分配不足。现有的token级信用分配方法需要超出模型自身rollout的资源。GRPO变体依赖于过程奖励模型或真实答案。知识蒸馏通过逐token散度分配信用，但需要外部教师（在线策略蒸馏）或特权信息（在线策略自蒸馏）。然而，这些依赖限制了在纯RLVR场景中的适用性。我们观察到，将模型以其自身已验证轨迹为条件会产生原始分布与条件分布之间的可测量逐token KL散度，并证明当存在多个已验证轨迹时，从由已验证轨迹构建的自教师进行蒸馏会导致不可行的加权平均解。我们提出SC-GRPO（自条件化GRPO），它利用前述KL散度作为GRPO梯度的乘性权重。在涵盖数学、代码和智能体任务的五个基准测试上，SC-GRPO相比GRPO平均提升8.1%，相比DAPO平均提升5.9%，且具有更强的分布外性能。此外，SC-GRPO达到了优于在线策略蒸馏（OPD）的性能。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) has driven substantial progress in training LLMs for reasoning tasks, but representative methods such as GRPO assign uniform credit across all tokens, wasting gradient on routine tokens while under-crediting pivotal reasoning steps. Existing token-level credit assignment methods require resources beyond the model's own rollouts. GRPO variants rely on process reward models or ground-truth answers. Knowledge distillation assigns credit through per-token divergence but requires external teachers (On-Policy Distillation) or privileged information (On-Policy Self Distillation). However, these dependencies limit applicability in the pure RLVR setting. We observe that conditioning the model on its own verified trajectories induces a measurable per-token KL divergence between the original and conditioned distributions, and prove that distilling from a self-teacher constructed by verified trajectories leads to infeasible weighted-average solutions when multiple verified trajectories exist. We propose SC-GRPO (Self-Conditioned GRPO), which uses KL divergence mentioned before as a multiplicative weight on GRPO gradients. Across five benchmarks spanning math, code, and agentic tasks, SC-GRPO consistently outperforms 8.1% over GRPO and 5.9% over DAPO with stronger OOD performance. Moreover, SC-GRPO achieves higher performance than OPD.

### 1. 论文的核心问题与整体含义（研究动机和背景）

当前基于可验证奖励的强化学习（RLVR）方法（如 GRPO）在训练大语言模型推理任务时，对生成的所有 token 分配**相同的序列级优势**，导致：
- 在常规 token（如标点、模板代码）上浪费梯度；
- 对关键的推理步骤（如算法选择、逻辑分支）信用分配不足。

已有 token 级信用分配方法（如过程奖励模型 PRM、在线策略蒸馏 OPD）依赖外部教师模型、真实答案或额外过程注释，在**纯 RLVR 场景**中不可行——仅有一个二值验证器可用。论文旨在利用模型**自身的已验证轨迹**（即自己生成并通过验证的正确解），构建无外部依赖的 token 级信用分配机制。

### 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想：**
SC-GRPO 通过将模型**以一条自身已验证轨迹为条件**（self-conditioned teacher），测量条件化分布与原始分布之间的**逐 token KL 散度**，并将该 KL 值作为**乘性权重**调整 GRPO 梯度——奖励决定更新方向，KL 决定每个 token 上的梯度强度。

**关键技术细节：**

- **自条件化教师构建**：对于一个 rollout oi，随机从组内正确轨迹集合 C(x) 中选取一条 τ≠oi，将 τ 放入教师 prompt 的系统提示中；教师与学生共享同一模型参数（教师前向传播不更新梯度）。
- **逐 token KL 散度计算**：在 student 的前缀 oi,<t 上，计算教师分布 eπθ(·|x, τ, oi,<t) 与学生分布 πθ(·|x, oi,<t) 之间的**前向 KL 散度** Di,t。
- **KL 加权函数**：将 Di,t 映射为权重 f(Di,t) = Di,t / (Di,t + c)，其中 c = max(P75(Dact), 10⁻⁴)。P75 是当前微批次中所有 token KL 值的 75% 分位数，用于抑制低 KL 的“常规 token”，保留高 KL 的“关键 token”。
- **组路由策略**：
  - **部分正确组**（2 ≤ nc < G，nc 为组内正确数）：每个 rollout 选取一条不同正确轨迹作为教师，计算 KL 权重后作用于 GRPO 优势。
  - **全错组**（nc = 0）：随机选一条 rollout 作为参考，计算其余 rollout 与该参考条件化教师的 KL 权重，平均得到多样性分数 si，归一化后作为伪优势（乘以弱系数 α=0.1 ），鼓励探索。

### 6. 论文的主要结论与发现

1. **SC-GRPO 在所有五个基准上显著优于基线**：Avg@8 相对 GRPO 提升 8.1%，相对 DAPO 提升 5.9%；Pass@8 提升更显著（相对 DAPO 提升 8.92%）。
2. **来自外部演示的 OPSD 不可靠**：即使使用强大外部模型（DeepSeekv4-Pro）或 Oracle 收集足够正确解，OPSD 性能仍远低于 RL 基线，甚至退化为基础模型水平。
3. **自条件化 KL 需作为乘性权重而非加法损失**：加法蒸馏损失（无论前向/反向/双向）均无法超越 GRPO，且多数变体低于 GRPO。
4. **组路由策略关键**：仅对部分正确组（2≤nc<G）和全错组（nc=0）应用 KL 加权，避免单正确或全正确组引起熵坍缩或噪声。
5. **自适应阈值 P75 有效**：自动分离高信息 token 与低信息 token，无需人工调参。
6. **OOD 泛化性强**：LCB 训练的 SC-GRPO 在 Codeforces 上保持 5.2% 相对提升，与域内提升幅度一致，表明改进来自更好的信用分配而非过拟合。

### 7. 优点

1. **完全自洽、无外部依赖**：仅利用模型自身已验证轨迹，无需 PRM、外部教师、真实答案等额外资源。
2. **梯度调制而非蒸馏**：KL 仅调整梯度强度，不改变更新方向，避免了蒸馏目标平均化导致的不可行问题。
3. **轻量高效**：仅增加一次教师前向传播，端到端时间开销仅 2%~13%。
4. **理论分析与实证相结合**：附录 A 严格推导了直接 OPSD 在 RLVR 中失败的原因（平均化目标、丢弃分歧信息、继承教师噪声）。
5. **设计原则清晰**：组路由、自适应阈值、弱多样性系数均有消融验证，设计选择有据可依。
6. **稳定性强**：REINFORCE++ 在长程智能体任务中完全崩溃（WebShop 奖励降至 0），SC-GRPO 在所有任务上稳定提升。

### 8. 不足与局限

1. **模型规模有限**：实验仅限于 Qwen3-8B 及类似大小的模型，未验证在更大模型（如 70B、405B）或更长序列（>12K token）上的有效性。
2. **未探索扩展思维模式**：所有实验使用“thinking disabled”的标准推理模式，未测试链式思维、多轮优化等结构化输出。
3. **多样性信号仅对全错组有效**：当组内无正确轨迹时，只能依靠弱多样性信号（α=0.1），可能在某些任务上探索效率不足。
