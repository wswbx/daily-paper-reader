## 摘要
技能增强的强化学习通过存储从过去经验中获取的可重用程序性知识来改进语言智能体。现有方法通常使用强大的语言模型来分析轨迹、生成技能，并在在线训练期间更新可检索的技能库。然而，这些方法很少在存储和复用新生成的技能之前评估其有用性。我们发现这种假设并不可靠：即使由专有前沿大语言模型生成的技能也表现出高度混合的效用，许多技能几乎没有益处甚至降低性能。一旦此类技能进入技能库，其影响难以识别，因为后续的轨迹反馈存在延迟，并且通常反映多个检索到的技能的组合效应，而非单个技能的边际贡献。我们提出了一种用于预存储技能验证的在线强化学习框架。该框架评估候选技能是否提供了超出当前任务已检索技能的有用信息。它利用标准的轨迹预算，在同一任务和检索上下文下形成两个匹配组：基于当前检索技能的基础轨迹，以及基于相同技能加上从基础轨迹中归纳出的一个候选技能的技能增强轨迹。这两组之间的奖励差距估计了候选技能的上下文相关边际效用，从而使框架能够在不增加轨迹开销的情况下，促进有用技能同时过滤无效或有害技能。该框架进一步利用这种边际效用信号来训练策略本身作为技能生成器，减少对专有模型重复调用的依赖。随着策略的演化，学得的技能生成似然度可作为上下文相关的评分，用于检索时的重新排序和过时技能的剪枝。

## Abstract
Skill-augmented reinforcement learning improves language agents by storing reusable procedural knowledge acquired from past experience. Existing methods typically use strong language models to analyze trajectories, generate skills, and update a retrievable skill bank during online training. However, they rarely assess whether a newly generated skill is useful before it is stored and reused. We find that this assumption is unreliable: even skills generated by proprietary frontier LLMs exhibit highly mixed utility, with many providing little benefit or even degrading performance. Once such skills enter the bank, their effects are difficult to identify, because subsequent rollout feedback is delayed and usually reflects the combined effect of multiple retrieved skills rather than the marginal contribution of any individual skill. We propose an online reinforcement learning framework for pre-storage skill validation. The framework estimates whether a candidate skill contributes useful information beyond the skills already retrieved for the current task. It uses the standard rollout budget to form two matched groups under the same task and retrieval context: base rollouts conditioned on the currently retrieved skills, and skill-augmented rollouts conditioned on the same skills plus one candidate skill induced from the base trajectories. The reward gap between these two groups estimates the candidate skill's context-dependent marginal utility, enabling the framework to promote useful skills while filtering ineffective or harmful ones without additional rollout overhead. The framework further uses this marginal-utility signal to train the policy itself as a skill generator, reducing reliance on repeated calls to proprietary models. The learned skill-generation likelihood serves as a context-dependent score for retrieval-time reranking and outdated-skill pruning as the policy evolves.

## 1. 核心问题与整体含义（研究动机与背景）

现有技能增强型强化学习方法（如 SkillRL、Skill0、D2Skill）通常依赖强大的闭源语言模型（如 GPT-5.4）从历史轨迹中生成新技能，并直接存入可检索的技能库。然而，这些方法**缺乏对生成技能有用性的预存储验证**，导致：

- 即使由前沿 LLM 生成的技能，其效用也高度混杂：少量技能带来提升，大量技能效用近乎零甚至有害（论文第 3 节实验证实）。
- 一旦低质量技能进入技能库，后续轨迹反馈是延迟的，且反映的是多个检索技能的组合效果，无法归因于单个技能的边际贡献。
- 随着策略演化，部分技能会过时或冗余，但现有方法难以识别和剪枝。

**核心挑战**：
1. 如何不增加额外轨迹成本来估计新生成技能的边际效用；
2. 如何基于当前检索上下文计算技能的上下文相关贡献；
3. 如何减少对昂贵闭源 LLM 的依赖，同时保证技能生成质量。

## 2. 提出的方法论：SAPO 框架

### 核心思想
SAPO（Skill-Augmented Policy Optimization）是一个在线强化学习框架，将标准轨迹预算拆分为**匹配的两组**（基础组与技能增强组），利用奖励差距估计候选技能的边际效用，进而用于预存储过滤、策略生成器训练、技能维护与检索重排序。

### 关键技术细节

1. **技能归纳单元**：从单个查询（K=1）或一组语义相似的查询（K>1）中归纳一个候选技能。
2. **在线解卷与技能生成**：
   - 对每个查询 \(x_{i,j}\)，检索已有技能 \(S_{i,j}\)，采样 **基础轨迹** \(Y_{i,j}^{\text{base}}\)。
   - 基于基础轨迹和任务描述，策略生成一个候选技能 \(\hat{s}_i\)。
   - 在相同上下文下添加 \(\hat{s}_i\)，采样 **技能增强轨迹** \(Y_{i,j}^{\text{skill}}\)。
3. **边际效用估计**：
   - 提示内效用：\(u(x_{i,j}, \hat{s}_i) = \frac{1}{|Y^{\text{skill}}|} \sum r - \frac{1}{|Y^{\text{base}}|} \sum r\)，衡量添加候选技能后的奖励提升。
   - 跨提示效用：对归纳单元内所有查询的提示内效用取平均，得到 \(U_{\hat{s}_i}\)。
4. **技能银行更新**：
   - 临时银行存储候选技能与效用。
   - 定期进行 **技能提升**：筛选出效用为正、排名前 ρ（如20%）且与长期银行中技能不重复（相似度 < γ）的技能，加入长期银行。
5. **策略作为技能生成器与评分器**：
   - **生成器训练**：使用非对称效用加权目标（W-REINFORCE）训练策略的生成似然，正效用增强、负效用强抑制。
   - **评分函数**：定义为策略生成技能的平均对数似然，用于维护时评估过时技能、检索时上下文重排序。
   - **知识蒸馏**：将完整输入模式（含基础轨迹）的分布蒸馏到简洁输入模式（不含轨迹），以便高效推理。

### 算法流程（文字描述）

1. 初始化策略参数、长期/临时技能银行。
2. 对于每个训练步：
   - 采样一批归纳单元（每组 K 个查询）。
   - 每个查询：检索技能 → 采样基础轨迹。
   - 从各组归纳单元生成候选技能。
   - 每个查询：采样技能增强轨迹，计算提示内效用。
   - 聚合跨提示效用，存储到临时银行。
   - 使用 GRPO 优化策略（基于所有收集轨迹）。
   - 每 T_prom 步：执行生成器训练、蒸馏、技能提升/删除。

## 6. 主要结论与发现

1. **现有方法直接注入未验证技能会引入低质量技能**，阻碍策略学习。
2. **SAPO 通过匹配两组轨迹的奖励差距估计边际效用**，在不增加额外交互开销的前提下过滤有害技能。
3. **该效用信号可以训练策略自身成为更好的技能生成器**，逐渐达到甚至超越闭源模型（GPT-5.4）的生成质量。
4. **策略的生成似然分数可用作上下文相关评分**，用于检索时重排序和过时技能剪枝。
5. **SAPO 在 ALFWorld、WebShop 和搜索 QA 上均优于所有先前技能增强 RL 方法**，同时避免了对闭源 API 的重复依赖。

## 7. 优点（亮点）

- **预存储验证机制**：首次提出在技能进入银行前评估其边际效用，直接避免污染。
- **无额外轨迹开销**：将标准轨迹预算拆分为匹配组，自然产生效用信号。
- **策略与技能协同演化**：不仅优化策略，还同时训练策略生成技能，降低对强模型依赖。
- **上下文相关评分**：利用策略的生成似然进行检索重排序，考虑了当前检索上下文。
- **实验充分、对比严谨**：涵盖多个环境、多种基线、消融和跨骨干验证。

## 8. 不足与局限

- **超参数敏感性**：K、ρ、γ 等关键超参数（如归纳单元大小 K=4）虽已分析，但未探讨联合影响，其他参数（银行容量、蒸馏频率）的敏感性未报告。
- **技能生成质量依赖基础轨迹**：若基础轨迹本身质量低或信息不足，则生成有效技能困难（论文承认在早期阶段效用较低）。
- **泛化性有限**：仅测试了文本交互任务（家庭、购物、问答），未在物理模拟、代码生成或连续动作空间环境中验证。
- **计算成本**：虽然减少了闭源 API 调用，但训练过程中需同时运行两组 rollouts（基础+增强），且增加生成器训练和蒸馏步骤，总训练耗时可能高于仅做 RL 的方法（未量化对比）。

- **仅使用内部奖励**：对于搜索 QA 等任务，奖励仅基于答案正确性，未利用过程监督信号。
