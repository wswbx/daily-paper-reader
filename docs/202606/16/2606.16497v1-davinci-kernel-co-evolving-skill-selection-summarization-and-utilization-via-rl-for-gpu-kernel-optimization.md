## 摘要
GPU内核优化代表了一种范式，其中功能正确性被假定，而执行效率是目标。我们提出了daVinci-kernel，一个通过动态进化的技能库将技能发现与技能利用相结合的强化学习框架。daVinci-kernel联合训练共享一个LLM主干网络的三个智能体：技能选择智能体通过BM25和LLM重排序检索相关技术，策略智能体基于所选技能生成多轮CUDA/Triton内核，以及技能总结智能体将成功的轨迹提炼为可复用的技能。候选技能仅在基于执行的验证确认可复现的速度提升后才被添加。三个智能体共享一个LLM主干网络，通过对多样性筛选后的数据进行结构化SFT冷启动初始化，然后通过多轮REINFORCE和每个智能体的优势估计进行端到端联合优化。在KernelBench上，daVinci-kernel-14B在Fast$_1$阈值下，Level 1、Level 2和Level 3分别达到37.2%、70.6%和32.2%，优于之前最强的强化学习训练模型Dr.Kernel-14B。

## Abstract
GPU kernel optimization represents a paradigm where functional correctness is assumed and execution efficiency is the objective. We present daVinci-kernel, a reinforcement learning framework that couples skill discovery with skill exploitation through a dynamically evolving skill library. daVinci-kernel jointly trains three agents sharing one LLM backbone: a Skill Selection Agent that retrieves relevant techniques via BM25 and LLM reranking, a Policy Agent that generates multi-turn CUDA/Triton kernels conditioned on selected skills, and a Skill Summary Agent that distills successful rollouts into reusable skills. Candidate skills are added only after execution-based verification confirms reproducible speedups. All three agents share a single LLM backbone, are initialized via a structured SFT cold start on diversity-filtered data, and are then jointly optimized end-to-end with multi-turn REINFORCE and per-agent advantage estimation. On KernelBench, daVinci-kernel-14B achieves 37.2%, 70.6%, and 32.2% on Level 1, Level 2, and Level 3 under the Fast$_1$ threshold, outperforming the strongest prior RL-trained model, Dr.Kernel-14B.

## 2. 论文提出的方法论：核心思想、关键技术细节

*   **核心思想**：技能-策略协同进化（Skill-Policy Co-Evolution）。框架通过一个动态进化的技能库，将技能发现（从成功经验中总结）与技能利用（通过检索和注入指导策略）耦合在一个强化学习循环中。随着策略能力的提升，有用的技能库边界也会从简单技能向更复杂、更特定于任务的技能转移。
*   **关键技术细节**：
    *   **三智能体架构**：框架包含三个共享同一LLM主干网络的智能体，通过强化学习端到端联合优化：
        1.  **技能选择智能体（Skill Selection Agent）**：在策略执行任务前，从技能库中检索最相关的技能。采用两阶段流程：先通过BM25（词汇检索）快速预过滤出Top-20候选技能，再由LLM根据任务描述、技能名称和描述进行重排序，最终选择至多3个技能。
        2.  **策略智能体（Policy Agent）**：接收任务和选定的技能上下文，通过多轮对话与环境交互，生成优化的CUDA/Triton内核。
        3.  **技能总结智能体（Skill Summary Agent）**：当策略智能体产生一个成功的轨迹（满足速度提升的绝对和相对阈值）时，对该轨迹进行分析，将其核心优化技巧提炼为可复用的新技能。新技能需经过**执行验证**（在原任务上重新运行，确保有可复现的速度提升）才能被正式加入技能库，防止无效或退化技能。
    *   **SFT冷启动**：在RL训练前，使用来自Dr. Kernel的种子数据，通过GPT-5.4离线构造三个智能体的监督微调数据。
        *   **多样性过滤**：为了防止技能生成陷入模式坍塌（生成过多通用、浅显的技能），对SFT数据进行了聚类下采样，剔除冗余和通用的技能模式，保证技能库的多样性。
    *   **联合强化学习**：在RL阶段，采用多轮REINFORCE Leave-One-Out (TRLOO) 算法进行训练。
        *   **损失函数**：最终损失由三部分构成：策略损失、选择损失、总结损失，并带有各自的权重。

            *   **总结优势**：以验证后的速度提升作为奖励，在对应同一任务的s个并行总结调用间进行LOO估计，鼓励生成验证速度提升更高的技能。
        *   **技能库更新**：每个训练步骤只将经过验证的最优技能原子化地添加到技能库中，保持库的增长保守而有效。
