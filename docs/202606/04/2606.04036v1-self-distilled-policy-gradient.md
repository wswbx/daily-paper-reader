## 摘要
在策略自蒸馏（语言模型基于特权上下文来监督自身生成）为稀疏奖励强化学习提供了一种有前景的密集监督来源。实际上，它可实例化为一种辅助的全词汇学生-教师反向KL散度损失。因此，我们提出SDPG，一种自蒸馏策略梯度框架，结合了分组相对验证器优势、归一化标准差、精确的全词汇在策略自蒸馏，以及参考策略KL正则化。实验上，SDPG相较于RLVR和自蒸馏基线提升了稳定性和性能。代码开源在https://github.com/lauyikfung/SDPG。

## Abstract
On-policy self-distillation, where a language model conditions on privileged context to supervise its own generations, is a promising source of dense supervision for sparse-reward reinforcement learning. Actually, it can be instantiated as an auxiliary full-vocabulary student-to-teacher reverse Kullback-Leibler divergence loss. We therefore propose SDPG, a self-distilled policy-gradient framework that combines group-relative verifier advantages with normalized standard deviation, exact full-vocabulary on-policy self-distillation, as well as reference-policy KL regularization. Empirically, SDPG improves stability and performance over RLVR and self-distillation baselines. The code is available at https://github.com/lauyikfung/SDPG.

# 总结

## 1. 核心问题与整体含义
- **研究动机**：在大型语言模型（LLM）的推理任务（如数学、代码）中，基于可验证奖励的强化学习（RLVR）存在**稀疏序列级奖励**和**训练初期负优势不稳定**的问题。纯在线策略自蒸馏虽然能提供密集的 token 级信号，但缺乏全局正确性判别，可能强化局部合理但全局错误的轨迹。
- **整体含义**：作者提出**SDPG（Self-Distilled Policy Gradient）** 框架，融合 RLVR 的二元结果验证与在线策略自蒸馏的密集监督，并加入参考策略 KL 正则化，以提升训练的**稳定性**和**性能**。

## 2. 方法论
- **核心思想**：在策略优化中同时利用两种监督信号：
  1. 来自验证器的稀疏二元结果信号；
  2. 来自特权上下文（privileged context）的密集全词汇蒸馏信号。
- **关键技术细节**：
  - **RLVR 损失**：使用分组相对优势（Group Relative Advantage）代替原始奖励，采用 REINFORCE 风格的梯度（无重要性采样剪裁）。
  - **全词汇在线自蒸馏损失**：在每个采样前缀上计算学生分布 \(p_t\) 与停梯度的教师分布 \(q_t\) 之间的**反向 KL 散度** \(D_{\text{KL}}(p_t \| \text{SG}[q_t])\)。作者证明该损失的梯度等价于一个以**中心化对数比率**为优势的策略梯度更新（命题 3.1），但仍采用显式全词汇 KL 以提高精度。
  - **参考策略 KL 正则化**：使用**未归一化 KL（UKL）** 代替标准 KL，并推导出针对前向 KL 和反向 KL 的两种变体（UFKL 和 URKL），从而避免期望梯度偏差。
  - **稳定器**：
    - **正优势门控**（Positive Advantage Gating）：仅在分组优势为正的轨迹上应用蒸馏损失，防止错误轨迹上的蒸馏冲突。
    - **β 调度器**（Warmup-Decay）：蒸馏系数先线性升温，再线性衰减，避免早期噪声和后期过度约束。
- **算法流程**（Algorithm 1）：
  - 对每个 prompt，采样 G 个回答，计算二元验证奖励和分组优势。
  - 对每个回答的每个 token，计算学生分布、教师分布和参考分布。
  - 构建总损失 \(L_{\text{SDPG}} = L_{\text{out}} + \beta(k) L_{\text{OPD}}^+ + \alpha L_K\)，并优化。

- **模型**：主要实验基于 **Qwen3-4B**；额外实验使用 **Qwen3-1.7B**。
- **评估基准**：

## 6. 主要结论与发现
- **性能领先**：SDPG-URKL 和 SDPG-UFKL 在三个基准测试的最终（Last）和最佳（Best）精度上均**超过 GRPO 和 RLSD**。例如，在 AIME24 上 SDPG-UFKL 达到 0.408（Best），而 GRPO 仅 0.316。
- **更快收敛**：SDPG 在训练前 50 步即拉开差距，且能与 GRPO 达到相同高奖励早几百步。
- **熵稳定性**：SDPG-UFKL 保持较高 actor 熵，而 RLSD 的熵在 250 步后骤降（模式崩溃），这归功于正优势门控和 β 调度。
- **消融作用**：移除全词汇蒸馏项（β=0）导致早期精度优势消失；移除 KL 正则化（α=0）导致响应长度严重缩短，说明两者互补。
