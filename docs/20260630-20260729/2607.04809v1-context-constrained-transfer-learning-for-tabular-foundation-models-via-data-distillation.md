## 摘要
表格基础模型（TFMs）通过上下文学习作为黑盒推理引擎展示了强大的经验性能。然而，它们在迁移学习中的应用受到两个障碍的限制：严格的上下文大小限制和对源任务与目标任务之间分布偏移的敏感性。直接混合异构源数据可能导致负迁移。为了解决这些挑战，我们提出了基于锚定与蒸馏的上下文约束迁移学习（TL-ANDI），一种针对TFMs的后验感知蒸馏框架。TL-ANDI通过解决一个预算受限的最优传输问题来构建紧凑的源上下文，该问题的成本同时衡量目标协变量覆盖率和后验兼容性。然后，选定的锚点样本配备局部蒸馏标签，并结合使用目标数据的残差校准步骤。

## Abstract
Tabular Foundation Models (TFMs) have demonstrated strong empirical performance as black-box inference engines through in-context learning. However, their use in transfer learning is limited by two obstacles: strict context-size constraints and sensitivity to distribution shifts between source and target tasks. Directly pooling heterogeneous source data can therefore lead to negative transfer. To address these challenges, we propose Context-Constrained Transfer Learning via ANchoring and DIstillation (TL-ANDI), a posterior-aware distillation framework for TFMs. TL-ANDI constructs a compact source context by solving a budget-constrained optimal transport problem whose cost jointly measures target covariate coverage and posterior compatibility. The selected anchor samples are then equipped with locally distilled labels and combined with a residual calibration step using target data.

## 2. 论文提出的方法论

### 核心思想
- 将源数据的蒸馏视为一个**后验感知的预算约束最优运输问题**：从大量源样本中选择最多 \(n_{\max}\) 个锚点（anchors），使得运输代价最小，代价函数同时包含协变量距离项（促进覆盖测试协变量）和后验差异项（惩罚与目标任务条件均值不匹配的源区域）。
- 对选中的锚点进行**局部核蒸馏**，用邻域内源标签的加权平滑估计替换原始噪声标签，降低方差。
- 通过**残差校准**（两步法：先用源上下文预测，再用目标数据预测残差）适应目标任务，最后用验证集选择最优超参数，并保证不差于仅用目标数据的预测器。

### 关键技术细节
1. **后验感知 OT 锚点选择**（Stage 1）：
   - 局部蒸馏源均值：\(\tilde{y}_i^{(h)} = \frac{\sum_{r} K_h(x_r^{src} - x_i^{src}) y_r^{src}}{\sum_{r} K_h(x_r^{src} - x_i^{src})}\)，其中 \(K_h\) 为核函数。
   - 估计后验差异得分：\(\hat{\Delta}_i^{(h)} = \tilde{y}_i^{(h)} - \hat{f}^{(tar)}(x_i^{src})\)，\(\hat{f}^{(tar)}\) 为目标仅预测器。
   - 运输代价：\(\hat{c}_{ji}^{(\lambda,h)} = \|x_j^{test} - x_i^{src}\|_2^2 + \lambda \{\hat{\Delta}_i^{(h)}\}^2\)。
   - 求解预算约束 OT：\(\hat{S}_{\lambda,h} \in \arg\min_{S\subseteq[n_{src}], |S|\le n_{\max}} \frac{1}{n_{test}}\sum_{j=1}^{n_{test}}\min_{i\in S} \hat{c}_{ji}^{(\lambda,h)}\)。采用贪心算法迭代选择使运输代价下降最大的源点。
2. **局部标签蒸馏**（Stage 2）：用平滑伪标签 \(\tilde{y}_i^{(h)}\) 替换原始标签，构造蒸馏后的源上下文 \(\tilde{D}_{\lambda,h}^{(src)} = \{(x_i^{src}, \tilde{y}_i^{(h)}) : i \in \hat{S}_{\lambda,h}\}\)。
3. **残差校准与验证选择**（Stage 3）：
   - 将目标数据分为校准集（calibration）和验证集（validation）。
   - 对每组超参数 \((h,\lambda)\)，用蒸馏后的源上下文运行“香草迁移学习”（Vanilla-TL，Algorithm 1）：先用源预测，再用目标残差学习残差偏置，组合得到候选预测器。
   - 验证集上从候选集（含目标仅预测器）中选出误差最小的，再在全体目标数据上重拟合，最终对测试集预测。

### 算法流程（文字说明）
- **Algorithm 1 (Vanilla-TL)**：
  - 输入：源数据、目标数据、测试协变量。
  - ① 用源数据作为上下文，预测目标与测试协变量，得到源预测 \(\hat{f}^{(src)}\)。
  - ② 计算目标残差 \(\hat{z}^{(tar)} = y^{(tar)} - \hat{f}^{(src)}(X^{(tar)})\)；以目标特征与残差作为新上下文，预测测试残差 \(\hat{u}^{(test)}\)。
  - ③ 最终预测 = 源预测 + 残差预测。
- **Algorithm 2 (TL-ANDI)**：
  - 拆分目标数据为 calibration/validation，训练目标仅预测器。
  - 对每个 \((h,\lambda)\) 组合：①计算蒸馏标签；②计算后验差异得分；③贪心选锚点；④构建蒸馏源上下文；⑤在 calibration 集上执行 Algorithm 1 得到候选预测器。
  - 在 validation 集上选最优预测器（含目标仅预测器），重拟合后给出测试预测。

## 6. 论文的主要结论与发现

1. **TL-ANDI 在异质源场景下显著优于随机采样**：当源数据包含不相关的子种群时，TL-RAND 出现严重负迁移（MSE 高于 Target-only），而 TL-ANDI 通过 OT 锚点选择有效滤除非信息样本，MSE 远低于 Target-only。
2. **标签蒸馏在不同情境下效果不同**：
   - 同质源下蒸馏贡献更大（尤其在预算小时），因为噪声被平滑。
   - 异质源下锚点选择起主导作用，蒸馏进一步降低剩余噪声。
3. **无负迁移保证**：通过验证集包含 Target-only 预测器，TL-ANDI 在实践中从未显著差于 Target-only（且通常优于或接近）。
4. **分类任务同样有效**：在二分类模拟与真实糖尿病数据上，TL-ANDI 优于 Target-only、TL-RAND 和 TabPFN-kNN，表明后验感知选择对分类有意义。
5. **真实数据验证**：在房价预测（回归）和糖尿病检测（分类）上，TL-ANDI 在所有目标域上均取得最低预测误差。
