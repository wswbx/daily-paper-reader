## 摘要
数据驱动的故障前动态安全评估（DSA）利用机器学习快速评估电力系统在可信故障下的动态风险。现有方法面临两个局限性。首先，它们需要大量标注数据库进行训练，并且针对潜在冗长的可信故障列表中的每个故障，都需要单独训练、调优和维护一个模型。其次，训练后的模型对未见过的故障泛化能力差。本文通过使用一种表格基础模型（TFM）来解决这些局限性，该模型通过上下文学习评估稳定性，无需重新训练或超参数优化。单个TFM可以同时评估多个故障，消除了每个分类器需要一个模型的需求。我们还描述了何时使用电气距离坐标（EDC）作为连续特征能使TFM泛化到未见过的故障，以及何时不能，并展示了少量标注样本如何可靠地改善泛化。通过在IEEE 68节点系统上的综合案例研究，我们表明单个TFM在每故障仅120个标注样本的情况下，平均宏F1分数达到约90%，比通常假设的样本量少约两个数量级，且无需任何模型重新训练或超参数调优。对于新的/未见过的故障，我们证明仅使用该新故障的10个标注样本结合EDC编码，就能匹配最佳的可实现迁移学习oracle模型，而该oracle模型需要完全标注的数据且在实践中不可部署。总体而言，这项初步研究为开发和部署电力系统运行的基础模型铺平了道路，并可能应用于多个运行任务。

## Abstract
Data-driven pre-fault dynamic security assessment (DSA) rapidly evaluates the dynamic risk of credible contingencies on a power system using machine learning. Existing approaches face two limitations. First, they require a large labelled database for training, with a separate model trained, tuned, and maintained for each contingency in a potentially long list of credible contingencies. Second, the trained models generalize poorly to unseen contingencies. This work addresses the limitations by using a tabular foundation model (TFM) that assesses stability through in-context learning, requiring no retraining or hyperparameter optimization. A single TFM can assess many contingencies at once, removing the need for one model per classifier. We also characterize when the use of electrical distance coordinates (EDC) as continuous features enables generalization of TFM to unseen contingencies and when they do not, demonstrating how a few labelled samples can reliably improve generalization. Through comprehensive case studies on the IEEE 68-bus system, we show that a single TFM attains an average Macro F1 score of about 90% with only 120 labelled samples per contingency, roughly two orders of magnitude fewer than conventionally assumed, without any model retraining or hyperparameter tuning. For new/unseen contingencies, we show that using just 10 labelled samples of the new contingency with EDC encoding matches the best achievable transfer learning oracle model, which requires fully labelled data and is not deployable in practice. Overall, this initial study paves the way towards developing and deploying foundation models for power system operations, with possible applications across multiple operational tasks.

## 论文核心问题与整体含义（研究动机和背景）

- **研究问题**：现有的数据驱动预故障动态安全评估（DSA）面临两大瓶颈：  
  1) **大标注数据需求**：通常需要为每个可信事故（contingency）独立训练一个机器学习分类器，且要耗费大量时域仿真（TDS）生成标注样本（数百万级别）。  
  2) **泛化能力差**：训练好的模型难以推广到未见过的故障/拓扑变化，导致实际部署困难。

- **背景意义**：随着可再生能源渗透率提高，电力系统运行的不确定性和运行极限的逼近使DSA至关重要。传统时域仿真计算昂贵，在线应用受限。虽然已有多种机器学习改进方案（如迁移学习、多标签学习、在线学习等），但它们仍依赖大量样本或无法处理全新故障。本文尝试引入**表格基础模型（Tabular Foundation Model, TFM）**，从根本上缓解上述问题，为电力系统基础模型应用开辟新方向。

## 方法论

- **核心思想**：采用预训练好的表格基础模型（具体为**TabPFN**），通过**上下文学习（In-Context Learning, ICL）**直接进行稳定性预测，无需任何梯度更新或超参数调优。模型在前向推理时，将少量带标签的样本作为“上下文”输入，即可对新查询样本输出后验概率 `P(Y_test | X_test, X_train, Y_train)`。

- **关键技术细节**：
  - **工作流程**（如图3所示）：
    - 离线阶段：对每个或所有可信事故，通过TDS生成少量标注样本作为上下文。
    - 在线阶段：对于已知故障，TFM直接利用其对应上下文预测新运行条件的标签；对于多个故障，可将所有故障的标注数据合并为单一上下文（配合故障编码）实现多事故同时评估。
    - 对于**未见过的故障**，有两种策略：
      1) **零样本**：使用**电气距离坐标（EDC）**编码故障位置作为连续特征，代替离散编码，使模型能通过电气邻近性插值。
      2) **少样本**：生成少量（例如10个）新故障的标注样本加入上下文，并采用**修改的EDC（mod-EDC）**编码，该编码在原始EDC基础上加上**故障清除前后的电气距离差异**（反映加速/减速能力的变化），增强了区分度。
  - **EDC和mod-EDC的定义**：
    - EDC：基于阻抗矩阵计算每个母线的8维坐标，使得欧氏距离近似电气距离。
    - mod-EDC：`M_k = [EDC_pre_k || Q_k]`，其中 `Q_k = EDC_pre_k - EDC_post_k`，即清除前与清除后电气坐标之差，表征拓扑变化程度。

- **无需公式**，但核心在于贝叶斯推断：TFM近似后验预测分布，等价于在上下文中执行贝叶斯推理。

## 实验设计

- **数据集/场景**：
  - 测试系统：**IEEE 68节点系统**（16机，68母线）。
  - 事故集：**22个**三相母线短路故障（N-1清除），每个故障生成120,000个运行条件（OC）样本，稳定/不稳定比例从9%到99%不等，包含严重类别不平衡。
  - 特征：每个OC由272维稳态量（有功、无功、电压幅值、相角）表示。

- **Benchmark与对比方法**：
  - 基线模型：XGBoost、多层感知器（MLP）、决策树（DT）、支持向量机（SVM-RBF）——每个按标准流程训练+超参数调优。
  - 多事故基线：**MDSA-S**（多标签学习）[18]。
  - 泛化基线：**联合域适应（JDA）**迁移学习[17]，选择最佳源事故（JDA-best，理论上限）以及基于EDC/mod-EDC选择源事故的JDA-EDC/JDA-mod-EDC。
  - 评估指标：平衡准确率（Balanced Accuracy）、宏F1（Macro F1）、特异性（Specificity）、精确率（Precision）。

- **充分性**：实验覆盖了不同样本量、不同事故难度（从平衡到极度不平衡）、不同编码方式，还进行了消融（对比零样本 vs 少样本）和迁移学习对比，多数实验独立重复4次，统计可信。但仅局限于一个68节点系统，未在更大规模或不同拓扑上验证。

## 主要结论与发现

- **样本高效**：TFM仅用**每事故120个标注样本**即可达到约90%平均宏F1，比传统假设少了两个数量级；在12个样本的极端稀缺情况下仍显著优于所有基线。
- **单模型多事故**：TFM作为一个单模型，可同时评估全部22个事故，其宏F1比多标签基线MDSA-S高出约9个百分点（94.6% vs 86.0%），尤其在类别不平衡严重的故障上鲁棒性更强。
- **泛化能力**：
  - 零样本下，EDC编码优于独热编码，但受限于同位置不同故障行为差异。
  - 少样本下（仅10个新故障标注样本），**mod-EDC编码**使TFM达到与理论上限的JDA-best相同的平衡准确率（88%），且无需重新训练。
  - TFM+10（10样本+mod-EDC）在宏F1上甚至超越JDA-best（87% vs 84%），且是实际可部署方案。

## 优点

1. **彻底消除训练与调参**：TFM无需梯度下降或交叉验证，直接将原始数据作为上下文，部署简便。
2. **样本效率极强**：以很少的TDS样本（低至十余个）即可实现实用级精度，大幅降低离线仿真成本。
3. **单模型多事故**：避免了为上千个事故各自训练分类器的模型冗余。
4. **鲁棒性**：对严重类别不平衡的故障表现稳健（如稳定比例仅1%的故障，特异性仍保持在较高水平）。
5. **泛化策略灵活**：结合EDC或mod-EDC编码，零样本和少样本均可行事，并能匹配或超越最佳迁移学习上限。
6. **计算快速**：推理时间可控，尤其在小样本下显著快于需调参的基线。

## 不足与局限

1. **系统规模限制**：仅在IEEE 68节点系统测试，未验证更大电网（如数百节点）的可行性；且TabPFN底层Transformer架构受限于最大100k样本和2000特征，对大规模系统可能面临内存或速度瓶颈。
2. **特征维度压力**：272维特征在更大系统中会剧增，需考虑降维或特征选择。
3. **对泛化的理解仍不完整**：EDC编码在零样本下失败的情况（同母线不同故障行为）未完全解决，仅靠mod-EDC在少样本时才有效。
4. **依赖清除线路信息**：mod-EDC需要知道故障清除后的拓扑，这在某些实时场景中可能不可用或延迟。
5. **预测仍有不确定性**：模型不能保证100%准确，需要操作员进一步校验，属于辅助工具。
6. **实验覆盖局限**：未测试不同故障清除时间、更复杂或多重故障、动态拓扑变化等场景；未与最新的深度学习方法（如GNN、Transformer时序模型）比较。
7. **可解释性未深入**：虽然TFM有潜在解释能力（如注意力权重），但论文未探讨如何向操作员解释预测。
8. **资源消耗不对称**：TFM依赖GPU，而基线可在CPU完成；对于缺乏GPU的电力系统运营中心可能有部署门槛。
