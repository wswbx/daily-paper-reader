## 摘要
重复 Transformer 层可以在不增加参数的情况下提升语言模型性能。然而，增加的计算深度会提高训练期间的前向与反向计算成本。训练此类模型需要选择反向窗口，以控制最后若干层重复在反向传播中保留梯度的数量。较长的窗口会提高逐 token 学习效率，但会增加每次更新的成本；较短的窗口则降低每次更新成本，但会牺牲逐 token 效率。要理解哪种窗口表现更好，需要考察不同的训练预算。已有工作在不同计算预算下比较反向窗口。当训练预算增加时，尚不清楚同一窗口是否仍能保持最佳表现。我们测量了两个窗口的相对性能随训练预算增长而发生的变化。我们的方法通过在相同数据上训练两个窗口来隔离逐 token 效率，并在每个预算下以约相等的训练时间比较完整训练方案。结果表明，随着预算增长，较短窗口会失去其大部分优势。控制实验显示，两种收益在更大预算下都会下降，其中扩展训练带来的收益下降幅度更大。反向窗口的比较取决于可用预算，并且随着预算增长，测试候选中最优的窗口可能发生变化。

## Abstract
Repeating transformer layers can improve language model performance without adding parameters. However, the added computational depth increases both forward and backward computation costs during training. Training such models requires choosing a backward window that controls how many final layer repetitions retain gradients during backpropagation. Longer windows improve per-token learning efficiency but increase per-update cost, while shorter windows reduce per-update cost but sacrifice per-token efficiency. Understanding which window performs better requires examining different training budgets. Prior work compares backward windows across computational budgets. When training budgets increase, it remains unclear whether the same window continues to perform best. We measure how the relative performance of two windows shifts as training budgets grow. Our method isolates per-token efficiency by training both windows on identical data, and compares complete training recipes at approximately equal training time at each budget. Results show that shorter windows lose much of their advantage as budgets grow. Controlled experiments show that both benefits decrease at larger budgets, with a greater decline in the benefit of extended training. Backward window comparisons depend on the available budget, and the preferred window among the tested candidates can change as the budget grows.

# 论文总结：Deeper Backpropagation or More Updates? Training Looped Language Models Across Budgets

## 1. 核心问题与整体含义

- **背景**：循环语言模型（looped LM）通过重复使用同一组 Transformer 层来增加“计算深度”，在不增加参数的情况下提升性能（Universal Transformers、Huginn、Parcae 等）。但重复前向迭代会同时抬高训练的前向与反向成本。
- **关键权衡**：训练时可选择**反向窗口（backward window）** k，即只对最后 k 次循环迭代保留梯度（截断反向传播），更早的迭代只做前向、不建图。
  - 窗口长 → 每个 token 的学习效率高（per-token efficiency），但每次更新更贵；
  - 窗口短 → 每次更新便宜，可在固定训练时间内做更多更新（extended training）。
- **研究缺口**：已有工作（Parcae 固定 token 数比较窗口；Schwethelm et al. 在多预算下研究截断并节省算力去换更多 token）没有回答：**当训练预算增大时，原本最优的窗口是否仍然最优？**
- **整体含义**：反向窗口的选择不是一次性、与预算无关的超参数；它应由目标训练预算与资源约束共同决定。论文通过“等 token”与“等时间”两类配对比较，把“每 token 效率”和“扩展训练收益”两个因素拆开，测量它们在预算增长时的相对衰减速度。

## 2. 方法论

### 2.1 核心思想
- 在**同一随机种子、同一数据前缀、同一前向深度抽样、同一推理深度**下，配对训练不同反向窗口的完整训练方案，分别在：
  1. **等 token 比较**：两窗口训练相同数据量 → 隔离 per-token efficiency；
  2. **等时间比较**：短窗口用节省的反向计算时间去增加更新次数（并配以适配更长更新数的完整学习率/权重衰减日程）→ 衡量组合收益；
  3. **等 token 控制端点**：补出短窗口在长 horizon 的等 token 端点，从而把组合收益分解为两个可加成分。

### 2.2 模型与窗口机制
- 采用 Parcae 架构：Prelude（2 个 block）产生表示 e；Core（2 个共享 block）对循环状态迭代并在每步注入 e；Coda（2 个 block）+ 预测头输出 logits。
- 每个序列采样前向深度 \(T_i=\max(1,\mathrm{Poisson}(16))\)；窗口 k 保留最后 \(\min(k,T_i)\) 次活跃迭代的梯度；在保留窗口边界处对循环状态做 stop-gradient，但保留的 e 注入仍把梯度传回 Prelude。
- 批内实现（Algorithm 1）：取 \(T_{\max}=\max_i T_i\)，右对齐活跃迭代，保留窗口起点 \(b=T_{\max}-\min(k,T_{\max})\)；\(r<b\) 的迭代仅前向、被 mask 掉。
- 主比较为 K4（4 次）与 K8（8 次）；另有 K1/K2/K6/FULL 作为有限候选网格。

### 2.3 时间匹配与更新数确定
- 实测每次更新成本 \(c_k\)（多次计时、双向方法顺序、剔除前 20 次更新），按
  \[
  N_k=\text{round-half-up}\left(N_{\text{ref}}\,c_{\text{ref}}/c_k\right)
  \]
  给短窗口分配更新数，使两者训练时间近似相等（实测时间比 0.9985–1.0074，偏差 −0.270%～+1.380%）。
- 预算层级：1×（K8 4,096 / K4+ 4,986）、2×（8,192 / 9,972）、4×（16,384 / 19,944）；388M 配置为 4,096/5,024 与 16,384/20,095。K4+ 表示“扩展后的四迭代训练”。

### 2.4 收益分解公式（文字说明）
- 记 \(G_s(N)=L_{4,s}(N)-L_{8,s}(N)\)：等 token 下 K8 相对 K4 的 per-token 效率优势；
- \(R_s(N)=L_{4,s}(N)-L_{4,s}(N^+)\)：把 K4 延长到等时间 horizon \(N^+\) 带来的扩展训练收益；
- 则等时间差 \(C_s=G_s-R_s\)，预算变化 \(\Delta C_s=\Delta G_s-\Delta R_s\)。
- 负 C 表示短窗口（K4+）占优；正 \(\Delta C\) 表示优势收缩（不必然是反转）。每个端点都用**从零开始、为自身 horizon 定制的完整日程**，不能用长跑的中途 checkpoint 代替等 token 控制。

### 2.5 统计推断
- 测试损失：对连续 65,536/131,072/262,144 target 的块做 20,000 次共享配对 bootstrap，报告边际 95% 区间。
- 下游：按恢复的“源簇”（CORE 64,067 簇、LAMBADA 5,151 段落簇）做共享重采样；LAMBADA 另做精确 McNemar + Holm 校正（仅限 6 个旧配对）。
- 明确区分“训练种子变异”与“条件于 checkpoint 的评估块/源簇不确定性”。
