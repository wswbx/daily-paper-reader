## 摘要
循环式语言模型通过重复应用共享计算来提升推理和知识操作能力。现有系统通常重复整个层堆栈，尽管混合器和稠密前馈网络（FFN）执行不同操作且具有不同开销。我们提出一个更窄的问题：应当循环什么？我们将循环视为状态更新的重复复合，并认为当一次应用暴露出一个新的跨位置影响方向、且该方向在任务读出时仍可观测时，这次应用是有价值的。迭代传输秩（Iterative Transport Rank, ITR）描述累积影响轨迹；边际 ITR 描述由连续应用所贡献的非冗余影响。这一视角促成了 MixerLoop，它重复每个 Gated DeltaNet 混合器，而将其稠密 FFN 仅应用一次。我们在相同数据、初始化和架构下，在 15M 和 110M 参数规模上比较了 MixerLoop、无循环和全块循环。一个有限上下文关闭干预测试后续混合器应用是否在最终语言模型读出处产生独特、不可忽略且有益的变化。MixerLoop 在 15M 参数下于聚合 CORE 上超过 FullLoop，并在 110M 参数下保留其 CORE 提升的 41.5%，同时将循环骨干投影 FLOPs 降低 45.9%。这些结果表明，无需重复执行稠密 FFN 也能保留循环深度的收益。

## Abstract
Looped language models improve reasoning and knowledge manipulation by applying shared computation repeatedly. Existing systems usually repeat an entire layer stack, although a mixer and a dense feed-forward network (FFN) perform different operations and have different costs. We ask a narrower question: what should loop? We view recurrence as repeated composition of a state update and argue that an application is valuable when it exposes a new cross-position influence direction that remains observable at the task readout. Iterative Transport Rank (ITR) describes the cumulative influence trajectory; marginal ITR describes the nonredundant influence contributed by successive applications. This view motivates MixerLoop, which repeats each Gated DeltaNet mixer while applying its dense FFN once. We compare MixerLoop with no recurrence and full-block recurrence at 15M and 110M parameters under the same data, initialization, and architecture. A finite context-off intervention tests whether later mixer applications produce distinct, non-negligible, and beneficial changes at the final language-model readout. MixerLoop surpasses FullLoop on aggregate CORE at 15M and retains 41.5% of its CORE improvement at 110M while reducing recurrent-backbone projection FLOPs by 45.9%. These results show that the benefits of recurrent depth can be retained without repeatedly executing the dense FFN.

## 1. 核心问题与研究动机

- **背景**：循环式（looped）语言模型通过权重共享的重复计算来增加“有效深度”，而不增加唯一参数量。Universal Transformer、Huginn、Ouro、LT2、MELT 等均属此类，已被证明能提升推理与知识操作能力。
- **现有做法的盲点**：绝大多数系统把**整个 Transformer 块**（token mixer + 稠密 FFN）作为循环单元整体重复，默认“循环什么”无需讨论。但 mixer 与 FFN 执行的操作性质不同、开销差异巨大——文中指出稠密 FFN 占每层投影 FLOPs 的 **61.2–61.3%**。
- **已有最接近的工作不足**：SGT 只循环高熵 softmax 注意力头、FFN 只跑一次，但其判据绑定于单步 softmax 注意力分布，无法解释 LT2 这类**有状态线性 mixer** 反复施加所获得的收益。
- **本文要问的更窄问题**：*what should loop?* 即在一个块内部，哪个算子值得获得额外的循环步数，以及如何度量其**边际贡献**。
- **理论视角**：把循环视为“状态更新的重复复合”；一次循环应用有价值，当且仅当它暴露出**新的跨位置影响方向**，且该方向在**任务读出（readout）层面仍可观测**。

## 2. 方法论

### 2.1 核心思想：MixerLoop 架构

- 以 **Gated DeltaNet (GDN)** 为骨干，仅改变循环发生的边界：**只循环 mixer，FFN 只执行一次**。
- 记号：$A_i$ 为第 $i$ 个物理层的残差 token mixer，$F_i$ 为稠密 FFN。
  - NoLoop：$h=(F_L\circ A_L\circ\cdots\circ F_1\circ A_1)(h_0)$
  - FullLoop：$(F_L\circ A_L\circ\cdots\circ F_1\circ A_1)^T(h_0)$
  - **MixerLoop**：$(F_L\circ A_L^{T})\circ\cdots\circ(F_1\circ A_1^{T})(h_0)$
- 关键细节：同一物理层内 $T$ 次 $A_i$ 共享参数，不同物理层仍保留各自的 mixer/FFN 权重；虽然参数复用，但每次施加接收上一轮输出的隐序列，**重新计算输入相关的 key、value、decay gate 与 delta-rule 更新**，因此产生新的记忆写入/擦除/读取序列，而非重复同一计算。

### 2.2 计算量分析（投影 FLOPs）

- $C_{\text{NoLoop}}=L(C_A+C_F)+C_H$；$C_{\text{MixerLoop}}=L(TC_A+C_F)+C_H$；$C_{\text{FullLoop}}=TL(C_A+C_F)+C_H$。
- 循环骨干内相对成本：$\dfrac{TC_A+C_F}{T(C_A+C_F)}$，在 $T=4$ 时为 **0.541**，即保留 FullLoop 骨干投影 FLOPs 的 54.1%、**降低 45.9%**。
- 因 LM head 只执行一次，端到端节省降为 15M 的 **33.9%** 与 110M 的 **43.0%**（32K 词表 head 在 15M 占比更大）。

### 2.3 度量工具：Iterative Transport Rank（ITR）与边际 ITR

- **有限上下文关闭（context-off）干预**：对每层 $\ell$ 构造 GDN mixer 的“去上下文”对照版本——保留输入投影、门控、归一化、残差与 token 内非线性，但**逐 token 独立处理**，因果卷积历史与循环状态在 token 间重置；因此只移除跨位置计算。
- **策略 $r\in\{0,\dots,T\}$**：前 $r$ 次出现使用原生上下文 mixer，其余 $T-r$ 次使用 context-off 版本；$r=0$ 完全移除该层上下文混合，$r=T$ 精确还原原模型。
- **分布表示**：用逐元素平方根 $s_{\ell,r}=\sqrt{p_{\ell,r}(\cdot\mid x_{\le t})}$，使欧氏距离正比于 Hellinger 距离，避免选择隐状态基。
- **累积轨迹**：$a_r=\mathrm{vec}_{\ell,x,t}[s_{\ell,r}-s_{\ell,0}]$；归一化 $z_r=a_r/\|a_r\|_2$，Gram 矩阵 $K_{rs}=z_r^\top z_s$，定义
  $$\mathrm{ITR}_T=\frac{\mathrm{tr}(K)^2}{\mathrm{tr}(K^2)}\in[1,T]$$
  即参与率秩（participation ratio rank）。接近 1 表示各次恢复沿共享方向移动预测；越大表示轨迹越多样。
- **边际 ITR**：$d_r=a_r-a_{r-1}$（$a_0=0$），$\Pi_{r-1}$ 为投影到 $\mathrm{span}\{d_1,\dots,d_{r-1}\}$ 的正交投影，
  $$\mathrm{mITR}_r=\frac{\|d_r-\Pi_{r-1}d_r\|_2^2}{\|d_r\|_2^2}\in[0,1]$$
  度量当前预测更新中**无法由先前各次更新表达**的比例（$mITR_1=1$，$d_r=0$ 时为 0）。
- **配套两项量**：平方 Hellinger 效应 $H^2_{\ell,r}=\tfrac12\|s_{\ell,r}-s_{\ell,r-1}\|_2^2$（幅度），以及真值 log 概率变化 $g_{\ell,r}=\log p_{\ell,r}(y)-\log p_{\ell,r-1}(y)$（方向是否有益）。
- 四者分工：ITR 看累积多样性、mITR 看新颖性、$H^2$ 看幅度、$\Delta\log p$ 看是否有用；共同检验“后续 mixer 应用是否产生**独特、不可忽略且有益**的读出变化”。
