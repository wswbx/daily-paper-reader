## 摘要
循环语言模型在预测每个词元之前，会对其隐藏状态重复应用同一个模块。遍历次数即其循环深度。增加该深度使模型在相同参数下为每个词元提供更多计算。共享模块能否从其在更大深度下作出的预测中学习？遵循先前工作，我们用共享循环模块改造预训练的 OLMo-2-1B，并在不同循环深度上继续中期训练。在四遍模型中，额外遍数主要在一遍后已排名较高的词元之间重新分配概率。我们使用更大深度下生成的续写，仅通过单遍训练共享模块，不使用参考答案或正确性过滤。我们将此称为迁移偏好回写。回写在大多数任务上进一步提高单遍和多遍准确率。在其目标深度上，更新后的模型在所有六个数学推理基准上优于在中期训练数据和词元预算上匹配的非循环对照模型，任务平均相对准确率增益最高达 46.2%。在四遍推理时，在带输入注入的模型中，单遍训练在相同目标上优于全深度训练。这一优势在无注入的匹配模型中消失。在 GSM8K 上，仅在第二至第四遍使用更新后的模块即可恢复几乎全部四遍增益，表明在一次遍历中学到的更新可以改进同一模块的后续应用。

## Abstract
A looped language model repeatedly applies the same block to its hidden state before predicting each token. The number of passes is its recurrent depth. Increasing this depth gives the model more computation per token with the same parameters. Can the shared block learn from the predictions it makes at greater depth? Following prior work, we retrofit pretrained OLMo-2-1B with a shared recurrent block and continue mid-training over varying recurrent depths. In the four-pass model, additional passes mainly redistribute probability among tokens that already rank highly after one pass. We use the continuations generated at greater depth to train only the shared block through a single pass, without reference answers or correctness filtering. We call this transfer preference write-back. Write-back further improves one-pass and multi-pass accuracy on most tasks. At their target depths, the updated models outperform a non-recurrent control matched for mid-training data and token budget on all six mathematical reasoning benchmarks, with a mean relative gain in accuracy of up to 46.2% across tasks. At four-pass inference, one-pass training outperforms full-depth training on the same targets in the model with input injection. This advantage disappears in the matched model without injection. On GSM8K, using the updated block only on passes two through four recovers nearly the entire four-pass gain, showing that an update learned in one pass can improve later applications of the same block.

# 论文总结：从循环中学习——在循环语言模型中内化深度诱导的偏好

## 1. 核心问题与研究动机

- **背景**：循环语言模型（Looped LM）在预测每个词元前，会对隐藏状态重复应用同一个共享块，遍历次数即“循环深度”。理论上，增加深度可在不增加参数的前提下提升每词元计算量，在推理服务（参数共享、深度批处理、KV 缓存复用）和潜在测试时计算方面都有吸引力。
- **核心问题**：已有工作表明循环模型可通过深度训练获益，但**额外遍历究竟改变了预测的什么**尚不清楚——它可能是新的中间计算、对已形成预测状态的精炼，或两者的混合。进一步地，**共享块能否从自己在更大深度下做出的预测中学习？**
- **整体含义**：论文将“深度诱导的预测偏好变化”转化为监督信号，提出**迁移偏好回写（preference write-back）**，探索循环计算如何被发展，以及如何被后续改进，连接了循环架构设计与持续学习两个议题。

## 2. 方法论

### 2.1 循环语言模型架构
- 将 OLMo-2-1B（16 个 Transformer 块，宽度 2048）改造为三部分：**输入栈 P**（块 1–7）、**共享循环核 Fθ**（块 8–11，约 268M 参数）、**输出栈 C**（块 12–16），总参数 1.49B。
- 深度 r 的执行：`s_i = Fθ(A_ψ([s_{i−1}; e]))`，其中 `e = P(x_{1:n})` 为输入栈输出，`[·;·]` 为隐藏维拼接，`A_ψ` 为无偏置线性注入投影（输入注入）。最终 `p_r(·|x) = softmax(W[C(s_r)]_n)`。
- 输入/输出栈各只应用一次；共享核在每遍重复使用相同参数。
- 中期训练：在 Dolmino 数据上继续因果语言建模，每步从 Poisson-lognormal 分布采样深度，均值按 1−√ 课程从 1 逐步升至目标均值深度 m（4/8/32）；深度 8/32 模型仅对最后 8 遍反向传播以控制梯度路径长度。

### 2.2 递归诱导偏好作为监督
- **诊断发现**：在固定深度 4 生成轨迹上，用同一输出栈对每个中间状态解码。715,596 个生成位置上，top-1 在四遍中保持不变的比例为 **95.6%**；当最终 top-1 改变时，**99.4%** 的最终选择已在一遍 top-5 内。额外遍历主要是在“头部候选”间重新分配概率，偶尔改变选择。
- **构造监督**：冻结更新前模型，以教师深度 rT 对每个 prompt 做贪心解码，得到完整续写 `ŷ`，形成数据集 `D_{rT} = {(x^(j), ŷ^(j))}`。**不使用参考答案、不做正确性过滤**，保留推理与最终答案的完整轨迹。

### 2.3 偏好回写（Preference Write-back）
- **核心思想**：解耦三种深度角色——**教师深度 rT**（暴露行为的深度）、**训练深度 rL**（学习该行为所经过的计算路径）、**推理深度 rE**（复用更新后算子的深度）。三者作用于同一共享循环核。
- **目标函数**：固定其余参数 φ（含注入投影 A_ψ），仅优化 θ：
  `L_{rL}(θ) = −(1/ΣT_j) Σ_j Σ_t log p_{rL}(ŷ_t^(j) | x^(j), ŷ_<t^(j); θ, φ)`
  即 completion-only 下一词交叉熵，无教师概率蒸馏项。
- **流程**（Algorithm 1）：① 冻结模型在 rT 深度贪心生成目标；② 仅共享核通过 rL 遍执行、AdamW 优化；③ 更新后的核 `F_{θ1}` 在任意推理深度的每一遍复用。
- 默认设置：rT = 平均深度，rL = 1，更新 268M/1.49B（18%）参数。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **非数学能力（17 个 OLMES 任务）**：知识（MMLU、MMLU-Pro）、考试（AGIEval 3-shot/1-shot）、常识（CommonsenseQA、HellaSwag、PIQA、WinoGrande）、科学 QA（ARC-C、ARC-E、OpenBookQA）、阅读（CoQA、SQuAD、DROP）、开放 QA（Jeopardy、NQ、TriviaQA）。
- **训练问题池**：OpenMathInstruct-2 的 augmented_gsm8k 部分（10k/30k/50k，含 curated 子集）或 GSM8K 训练集（7,473 题）；做过与测试集的近重复筛查。

- **充分性评价**：整体实验覆盖较充分，消融维度系统，结论有多模型与多深度支撑。**不足**：核心结论主要建立在单一 1B 模型家族（OLMo-2）与数学推理任务上；跨模型验证仅用 1,024 题 GSM8K 子集，规模较小；无注入对照与主模型并非同一循环配方，部分对比存在混杂因素（作者亦承认）。

## 6. 主要结论与发现

- **循环深度的作用是“精炼偏好”而非“挖掘新候选”**：额外遍历主要在首遍头部候选间重分配概率，top-1 稳定性 95.6%，最终 token 99.4% 已在首遍 top-5 内；重排序主要发生在第 2 遍（占 93%）。
- **写回有效**：平均深度 4 模型 GSM8K 从 56.18%→62.70%、GSM1K 51.12%→54.36%；18 组比较中 15 组提升；最终模型相对非循环对照的平均逐任务相对增益达 **34.9%–46.2%**，六个数学基准全部超过对照。
- **更深教师提供更好监督**：四遍教师优于一遍教师（GSM8K 62.70% vs 59.29%）；平均深度 32 模型用 8 遍教师（62.85%）甚至优于 32 遍教师（62.09%），说明教师深度可与推理深度分离选择。
- **单遍学习优于全深度学习（在带输入注入的模型中）**：GSM8K 62.70% vs 56.86%；但该优势在**无注入**模型中消失甚至反转（54.74% vs 54.81%，GSM1K 上全深度更优），说明优势依赖循环配方。
- **浅层学到的更新在后续遍仍有效**：仅在 pass 2–4 使用新块达 62.47%，恢复全更新增益（6.52 点）的约 97%；仅用 pass 1 几乎无增益（+0.07）。
- **梯度诊断解释机制**：四遍损失对首遍状态的梯度仅为一遍梯度的 7.3% 范数、余弦相似度 0.009；四遍训练中第 1/4 遍分别贡献 5.4%/59.1% 的参数梯度范数。
- **能力保留**：17 项 OLMES 平均分变化 <0.2 个百分点，最终模型相对对照仍有 5.6–7.1% 平均相对增益。
- **跨模型可迁移**：固定输入注入的 Retro-OLMo、Retro-LLaMA、Huginn 在深层推理上均提升；LoopUS 单遍准确率超过其原始八遍；Ouro（无重复注入）单遍提升但四遍略降。

## 7. 优点

- **概念清晰**：将教师深度、训练深度、推理深度三者解耦，把“深度诱导的瞬态行为”转化为“共享算子的持久更新”，视角新颖且表述严谨。
- **监督信号简洁**：无需参考答案、无需正确性过滤、无需教师概率蒸馏，仅用模型自身深层贪心续写即可，工程成本低。
- **诊断扎实**：先用中间读出量化“额外遍历改变了什么”，再据此设计方法，形成“观察→方法”的闭环；梯度分析进一步解释训练深度差异。
- **实验控制严格**：匹配数据、词元预算、FLOPs 上限、bootstrap 置信区间、开发/测试分离、近重复筛查，对比方法覆盖主流蒸馏与自训练路线。
- **泛化验证**：在 5 个公开循环模型上复现，并区分有无输入注入的配方差异，增强了结论的可信度与边界意识。
- **效率优势**：单遍训练比全深度训练更省时省内存，且效果更好（注入设定下），具备实用价值。

## 8. 不足与局限

- **模型与任务覆盖有限**：主实验基于单一 OLMo-2-1B 家族，任务集中于小学数学推理；跨模型验证仅 1,024 题 GSM8K，统计功效有限，对更大模型、代码/通用推理的适用性未知。
- **配方依赖性强**：单遍训练优于全深度训练的优势在无输入注入时消失，说明结论并非普适；不同循环架构（如 gated 更新的 LoopUS、无重复注入的 Ouro）表现不一致，Ouro 深层推理反而下降。
- **机制解释仍不完整**：为何单遍学习能改进后续遍、为何无注入时优势反转，论文仅给出梯度层面的相关性证据，缺乏更深入的理论刻画。
- **算力信息不完整**：未报告 GPU 数量与总训练时长，复现成本难以精确估计。
- **数据污染风险控制**：虽做了近重复筛查，但训练池与评测集同源（GSM8K 训练题、OpenMath 的 GSM8K 衍生数据），仍存在分布重叠的潜在偏差。
- **教师轨迹质量**：不做正确性过滤意味着监督信号可能包含错误推理；论文未量化错误轨迹比例及其对更新的影响。
- **应用限制**：方法依赖已有的循环中期训练检查点，对普通 Transformer 不直接适用；教师深度需额外深层推理开销。
