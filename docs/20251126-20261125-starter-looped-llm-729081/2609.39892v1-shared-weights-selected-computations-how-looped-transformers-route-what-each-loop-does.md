## 摘要
循环 Transformer 重复应用同一组 Transformer 层，从而形成一种用于潜在计算的循环架构。它们在迭代推理和长度泛化任务上的强劲表现提示了一种有吸引力的解释：循环机制可能提供一种归纳偏置，使模型能够在不同循环之间复用已学习到的算法。然而，仅有权重共享并不意味着每个循环都执行相同的操作。这引出了一个基本问题：每个循环是否真的在重复相同的计算？如果不是，又是什么将共享参数路由到不同操作？我们以图游走作为测试案例来研究这一问题。在模型的原生轨迹中，解码预测可以前进不同数量的图步，或停留在已到达的目标上，这表明循环进展不必遵循固定的“一循环一步”模式。随后我们表明，通过修改进入循环时的隐藏状态，可以引导一个冻结的循环转向不同的状态转移：一个学习到的线性层 $J$ 在不改变共享 Transformer 层的情况下选择所需的转移。为了检验这种引导如何起作用，我们使用激活修补，并发现注意力模式能够恢复其效果并切换所选择的转移。在五对匹配的图模型中，改变主干训练期间的中间监督会改变 $J$ 能够诱导的转移。这表明 $J$ 选择的是主干已学习到的计算，而不是创造新的算法。总之，这些结果表明隐藏状态可以控制共享计算，而注意力路由是其中的一条因果通路。

## Abstract
Looped Transformers repeatedly apply the same set of Transformer layers, giving them a recurrent architecture for latent computation. Their strong performance on iterative reasoning and length-generalization tasks suggests an appealing explanation: recurrence may provide an inductive bias that lets the model reuse a learned algorithm across loops. However, weight sharing alone does not imply that every loop performs the same operation. This raises a basic question: is each loop actually repeating the same computation, and if not, what routes the shared parameters to different operations?   We study this question using graph walks as a test case. In the model's native trajectories, decoded predictions can advance by different numbers of graph steps or remain at a reached target, showing that recurrent progress need not follow a fixed one-loop-one-step pattern. We then show that a frozen loop can be steered toward different transitions by modifying its entering hidden state: a learned linear layer $J$ selects the desired transition without changing the shared Transformer layers.   To test how this steering works, we use activation patching and find that attention patterns can recover its effects and switch the selected transition. Across five matched pairs of graph models, changing intermediate supervision during backbone training changes which transitions $J$ can induce. This suggests that $J$ selects computations learned by the backbone rather than creating new algorithms. Together, these results show that the hidden state can control shared computation, with attention routing as a causal pathway.

# 《共享权重，选择计算：循环 Transformer 如何路由每个循环所执行的操作》中文总结

## 一、核心问题与研究动机

- **背景**：循环 Transformer（Looped Transformer）反复复用同一组 Transformer 层，形成一种“潜空间循环计算”架构。已有工作表明，它在迭代推理、学习型算法、长度泛化以及测试时潜计算扩展等任务上表现优异，这容易被解释为：循环结构提供了“跨循环复用同一学习算法”的归纳偏置。
- **核心质疑**：权重共享并不等于每个循环执行相同操作。因为进入共享层的隐藏状态在每个循环都在变化，同一网络实际上被施加在不同内部状态上；并且如果只监督最终答案，中间轨迹在训练目标下是欠定的。
- **基本问题**：每个循环是否真的在重复同一计算？如果不是，是什么把共享参数路由到不同操作？
- **研究意义**：这关系到循环深度的归纳偏置本质、额外循环何时提供有用计算、以及循环式测试时计算能否被控制。作者以**图游走（graph walk）** 作为可控测试场景来回答该问题。

## 二、方法论

- **总体思路**：分三步——“观察现象 → 施加控制 → 追踪机制 → 检验依赖性”。
  1. **现象层**：在模型原生轨迹上读取中间循环的解码预测，检验是否遵循“一循环一步”。
  2. **控制层**：冻结主干，只在循环边界插入一个线性层 $J$，通过改变进入状态来选择下一转移。
  3. **机制层**：用激活修补（activation patching）检验注意力模式是否是因果通路。
  4. **依赖性检验**：改变主干训练时的中间监督，观察 $J$ 能诱导哪些转移。

- **状态引导公式**：原模型为 $h_{t+1}=F(h_t)$；引导版本为
  $$h_{t+1}=F(J(h_t))$$
  其中 $F$ 为共享 Transformer 块，$J$ 逐 token 独立作用。

- **$J$ 的参数化**：图任务中 $J(h)=h(D+AB)+b$，含学习到的对角项 $D$、秩 48 的低秩项 $AB$ 与偏置 $b$，共 25,088 个参数。逐 token、线性、低秩的约束确保 $J$ 自身不能跨 token 聚合图信息，跨位置的信息整合必须由冻结的 $F$ 完成。

- **注意力修补的三类干预**（记 $\alpha$ 为注意力模式、$V$ 为 value）：
  - **模式修补 vs 输出修补**：$z_{\text{pattern}}=\alpha_1V_2$，$z_{\text{output}}=\alpha_1V_1$，用于分离“读哪里”与“读到的内容”。
  - **引导模式移植**：$z_{J\to 0}=\alpha_JV_0$，$z_{0\to J}=\alpha_0V_J$，检验模式是否携带引导效应。
  - **目标切换修补**：$z_{\text{two}\to\text{one}}=\alpha_{\text{two}}V_{\text{one}}$，反向同理，检验模式是否决定预测哪个目标。

- **监督对比设计**：匹配的“仅最终监督”与“逐步监督”两种目标：
  $$\mathcal{L}_{\text{final}}=\ell_8,\qquad \mathcal{L}_{\text{stepwise}}=\ell_8+\frac{1}{7}\sum_{t=1}^{7}\ell_t$$
  用于检验 $J$ 的可控范围是否受主干已学算法限制。

## 三、实验设计

- **主要场景与基准**：
  - **图游走**：十节点置换图，输入给出边表、起点与深度 $d=8$，目标为 $f_G^8(s)$；仅监督最终答案。模型 D8L8（8 循环）与 D8L6（6 循环），共享两层 Transformer，隐藏维 256、4 头、MLP 1024。
  - **Ouro-2.6B 字母传递（letter-walk）**：文本化的十人循环传递规则，问 $k$ 步后谁持有信件；主干在 1–4 步上用 4 循环微调，冻结后训练稠密仿射层（4,196,352 参数）覆盖 1–8 步。
  - **Ouro 反义词消去（antonym cancellation）**：每步删除最左相邻反义词对，回答第 $k$ 步被删除的词对。
  - **附录扩展**：parity 长度外推、八节点图延续、Qwen3-8B（36 层全栈共享、8 循环）上的五类数值/日历任务、合成知识图谱关系复合。

- **对比条件**：
  - 无 $J$ vs $J_{\text{one}}$ vs $J_{\text{two}}$；不同映射组合顺序（one–one、one–two、two–one、two–two）；1–8 次连续控制调用。
  - 模式修补 vs 输出修补 vs 仅 value、无关图模式、错误循环模式、对照头等消融。
  - final-only 与 stepwise 两种监督的**五对匹配主干**（相同初始化、相同训练 token 流、相同更新预算）。

- **评测方式**：使用训练中排除的留出图与新采样图，报告图级 bootstrap 置信区间或 Wilson 区间；要求 current/next 读出正确等资格筛选，并声明不按预测正确性筛选主指标。

## 六、主要结论与发现

- **现象：一循环 ≠ 一步**。同一模型内不同轨迹可每循环前进 1 步、2 步，或停滞在已到达目标；D8L6 出现不规则速度（如种子 6 的增量序列为 2,2,1,1,1）。权重共享不保证同一算法。
- **控制：进入状态可选择下一转移**。冻结主干时，$J_{\text{one}}$ 把一跳准确率从 48.2% 提升到 99.6%，$J_{\text{two}}$ 达到 98.2% 的两跳准确率，且在未见图上泛化。
- **组合有代价**：one–one 达 93.6%、two–one 74.5%、one–two 65.3%、two–two 68.1%；顺序影响精度；第 8 次调用时混合序列仅约 10.1%。
- **机制：注意力路由是因果通路**。
  - 模式修补产生“重路由答案”（D8L6 77.8%、Ouro 71.1%），输出修补产生“原运行答案”（80.9%、93.8%），说明模式决定“读哪里”、value 决定“读到什么”。
  - 把引导模式移入未引导运行，准确率 39.2%→61.6%；反向 99.7%→68.1%；Ouro 248/256 vs 全引导 251/256。
  - 一跳/两跳模式互换可切换预测目标（0.1%→65.9%；0.5%→78.5%）；恢复选定头输出修复 74.0%（D8L6）与 249/249（Ouro）的错误，对照头仅 0.5%/0。
- **依赖性：$J$ 只能选择主干已学到的计算**。五对匹配模型中，stepwise 主干一跳 100%、两跳 13.2%；final-only 主干一跳 66.5%、两跳 50.5%（五对中两跳均更高）。Ouro 反义词任务上，final-only+$J$ 在深度 5–8 达 98.0%，stepwise+$J$ 仅 7.8%。
- **总体观点**：共享块是“可复用的执行器”，不断演化的隐藏状态决定它被路由到哪种计算；注意力路由是实现路径。长程循环推理不仅需要可复用计算，还需要能持续兼容这种路由的状态。

## 七、优点

- **问题提得准**：把“权重共享 ⇒ 计算重复”这一隐含假设显式化为可检验命题，并用反例（原生轨迹速度不一）直接推翻。
- **“控制”而非仅“观察”**：用冻结主干 + 线性探针式 $J$ 做干预，把相关性观察升级为可控因果实验；$J$ 的低秩、逐 token 约束设计巧妙，排除了 $J$ 自行完成图聚合的可能。
- **机制定位清晰**：模式/输出修补的对照设计能干净地区分“路由”与“内容”，并用目标切换与头输出恢复构成多重证据链。
- **监督对照严格**：五对匹配主干共享初始化与数据流，使“可控性依赖主干已学算法”的结论具有较强说服力。
- **跨模型验证**：从玩具图任务延伸到 Ouro-2.6B 语言任务、Qwen3-8B 与合成 KG，增强了外部效度。
- **诚实报告边界**：附录主动报告深度外推失败、组合退化、选择偏差、图排除未核实等负面/限制结果。

## 八、不足与局限

- **任务规模偏小、偏合成**：核心证据来自十节点环图与规则化文本任务，真实大规模推理任务的适用性未知；Qwen/KG 实验仅在附录，深度有限。
- **主干与映射样本有限**：机制分析只用 3 个**挑选过的**主干、每个目标 2 次映射拟合；Ouro 仅一个 checkpoint 与一个映射，缺乏跨种子复现。
- **$J$ 家族受限**：结论只针对“逐 token 线性/低秩仿射”这一干预族，不能推广到其他状态干预方式（作者亦承认）。
- **长程控制明显退化**：超过 2 个循环后精度快速下降，第 8 次调用仅约 10%；parity 在长度 >500 时带 $J$ 反而更差（36.40% vs 47.55%），图延续从 97.42%（9–16 循环）跌至 35.11%（17–32 循环）。
- **读出解释的固有风险**：结论基于解码读出而非内部状态直接测量；“Hold/零位移”并不代表隐藏状态未做计算，作者已提示这一点。
- **数据隔离存在不确定性**：Ouro 无可靠图排除清单，广样本图延续评测未核对训练排除；可能带来轻微泄漏风险。
- **算力与成本未报告**：无法评估训练开销、可扩展性与复现门槛。
- **应用限制**：作者声明未评估引导模型在下游部署中的安全性；方法目前是分析工具，而非可直接用于提升长程推理的工程方案。
