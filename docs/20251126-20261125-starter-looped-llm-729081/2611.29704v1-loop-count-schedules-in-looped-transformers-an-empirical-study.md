## 摘要
循环 Transformer 多次应用一个共享权重的层块，以重复计算换取参数。我们使用一组受控的 4600 万至 1.1 亿参数模型，在 2B token 上训练，并在每次循环传递中使用可学习残差门，采用三种调度：R 固定为 2、R 从 {1,...,6} 均匀采样、以及 R 从 {2,3,4} 采样，研究训练期间循环迭代次数 R 的调度如何决定每一次额外传递是充当完整层还是微小修正。我们发现采样范围的下界是决定性选择。如果采样范围包含 R=1，使得某些训练步只运行该层块一次并在该单次传递上计算损失，则门值塌缩至 0.1-0.5，每次额外传递都变成对第一次传递的小修正；如果范围从 R=2 开始，使得每个训练步至少运行该层块两次，则门值保持在 0.6-0.9，每次传递都保持完整层的强度，同时模型仍可在从 2 到最大训练值两倍的任意 R 下运行，验证损失与其最佳值相差仅几百分之一 nat。{2, 3, 4} 调度给出了最佳循环模型，为 2.909 nat，而参数匹配的普通模型为 2.951 nat；当以其训练深度的两倍运行时，仅退化 0.038 nat。我们进一步表明，在固定 R 下，残差流的方向在超过训练深度后几何收敛，而损失发散，这细化了近期关于静态深度训练不收敛的发现；并且在后续传递中复用第一次传递的键和值，在所有情形下会带来 0.01-0.03 nat 的代价，同时使逐 token 迭代一致收缩，并将推理缓存减半。在相同参数下，循环可恢复真实深度所提供收益的大约三分之一。代码、训练权重和逐 token 轨迹均已发布。

## Abstract
Looped transformers apply one block of layers several times with shared weights, trading parameters for repeated computation. We study how the schedule of the loop iteration count R during training determines whether each extra pass acts as a full layer or as a small correction, using a controlled ladder of 46M-110M-parameter models trained on 2B tokens with learned residual gates on every loop pass and three schedules: R fixed to 2, R sampled uniformly from {1,...,6}, and R sampled from {2,3,4}. We find that the lower bound of the sampling range is the decisive choice. If the sampled range includes R=1, so that some training steps run the block only once and compute the loss on that single pass, the gates collapse to 0.1-0.5 and each additional pass becomes a small correction to the first; if the range starts at R=2, so that every training step runs the block at least twice, the gates stay at 0.6-0.9 and each pass keeps the strength of a full layer, while the model can still be run at any R from 2 up to twice the largest trained value with validation loss within a few hundredths of a nat of its best. The {2, 3, 4} schedule gives the best looped model, 2.909 nats against 2.951 for the parameter-matched plain model, and degrades by only 0.038 nats when run at twice its trained depth. We further show that under a fixed R the direction of the residual stream converges geometrically beyond the trained depth while the loss diverges, which refines a recent finding that static-depth training does not converge, and that reusing the first pass's keys and values on later passes costs 0.01-0.03 nats in every regime while making the per-token iteration uniformly contractive and halving the inference cache. The loop recovers about a third of what real depth provides at equal parameters. The code, trained weights, and per-token traces are released.

## 1. 核心问题与整体含义

- **研究背景**：循环 Transformer 通过共享同一组层块的权重、重复执行多次来“以计算换参数”，近年被用于参数高效、自适应计算和潜在推理。现有大模型配方常在训练时采样循环次数 \(R\)，但“采样”本身为何重要、哪个属性决定额外循环的作用，仍缺少受控分析。
- **核心问题**：训练时循环次数 \(R\) 的调度，如何决定每一次额外 pass 是“一个完整层”还是“对第一次 pass 的小修正”？这种差异能否与收敛性、KV 缓存复用等性质分离？
- **整体含义**：论文发现决定性因素不是“是否采样 \(R\)”，而是**采样区间的下界**。若训练中可能出现 \(R=1\)，模型被迫在单次 pass 内完成主要计算，后续 pass 退化为小幅修正；若下界为 2，每次 pass 都保持完整层强度，且模型仍可在较宽 \(R\) 范围内稳定运行。这为循环模型训练配方提供了一个简单但关键的“一开关”建议。

## 2. 方法论

- **核心思想**：构建受控的普通/循环 Transformer 阶梯，在每次循环 pass 上加入可学习残差门，用门值直接观察额外 pass 做了多少工作；只改变 \(R\) 调度和 KV 策略，其他训练条件保持一致。
- **模型结构**：
  - 标准 pre-norm decoder-only Transformer：RMSNorm、RoPE 多头注意力、QK-norm、SwiGLU FFN，词嵌入与输出投影共享。
  - 第一次 pass 不加门，等价于普通块；第 2 至 \(R\) 次 pass 使用共享权重和门控残差更新：
    - \(x \leftarrow x + \alpha_{\text{attn}}\,\text{Attn}(\text{Norm}_1(x))\)
    - \(x \leftarrow x + \alpha_{\text{ff}}\,\text{FFN}(\text{Norm}_2(x))\)
  - 门参数 \(\alpha=\sigma(\theta)\in(0,1)\)，初始化为 0.5，不参与 weight decay；门接近 1 表示该 pass 近似完整层，接近 0 表示近似跳过。
- **三种循环次数调度**：
  - 固定 \(R=2\)：每个训练前向都恰好跑两次。
  - \(R\sim\{1,\dots,6\}\)：均匀采样，均值 3.5；部分训练步只跑一次并在单次输出上算损失。
  - \(R\sim\{2,3,4\}\)：均匀采样，均值 3；每个训练步至少跑两次。
  - \(R\) 按 micro-batch 独立采样，梯度累积使优化步看到多个深度的平均梯度；所有块共用同一个 \(R\)，无 step embedding、无输入注入、无截断反传。
- **前向静态 KV**：第一次 pass 计算 K/V，后续 pass 复用，仅重新计算 query。这样后续注意力输出是固定 value 向量的凸组合，推理缓存减半；与“训练后把最后 pass 的 KV 反向共享”的后向共享相对。
- **收敛度量**：
  - 方向变化：\(\delta_i=1-\cos(s_i,s_{i-1})\)，其中 \(s_i\) 为第 \(i\) 次 pass 后的残差向量。
  - 相对步长：\(\text{rel}_i=\|s_i-s_{i-1}\|_2/\|s_{i-1}\|_2\)，包含范数变化。
  - 输出空间：相邻 pass 的 next-token 分布 KL，\(\text{KL}(p_i\|p_{i-1})\)。
  - 对 token 取中位数以缓解重尾分布。

## 3. 实验设计

- **数据**：2.0B token 混合语料，来源为 FineWeb-Edu（通用文本）、codeparrot-clean 的 Python 部分（代码）、FineMath-4+（数学）；训练比例 80% 文本、10% 代码、10% 数学。
- **分词与序列**：训练 32k BPE tokenizer；每域留出 1M token 作为验证集；训练序列长度 1024，共约一遍 2B token。
- **模型规模**：
  - 隐藏维度 768、12 头、SwiGLU 内维 2048。
  - 每块约 7.1M 参数，绑定嵌入约 25.2M。
  - 非嵌入参数：21.2M（3 块）、42.5M（6 块）、85.0M（12 块）；总参数约 46.4M、67.6M、110.1M。
  - 循环模型只额外增加每块两个门标量。
- **训练设置**：AdamW，峰值学习率 \(6\times10^{-4}\)，2k 步 warmup + cosine 衰减至 10%，weight decay 0.1，梯度裁剪 1.0；每优化步 32,768 token，训练 61k 步，约 2B token；每 2k 步验证并保存 checkpoint。
- **对比对象**：
  - 普通模型：plain_3、plain_6、plain_12。
  - 循环 3 块模型：固定 \(R=2\) 与 \(R\sim\{1,\dots,6\}\)，各含 fresh KV 与 static KV。
  - 循环 6 块模型：三种调度 × fresh/static KV，共 6 个循环运行。
  - 共 13 个 run；其中 6 块 headline 的 4 个 run（plain_6 与三种 fresh-KV 循环模型）用 seed 43 重复。
- **评测 benchmark**：不是下游任务，而是三个域 held-out 验证损失按训练比例加权得到的语言建模验证损失；每个模型在 \(R\in\{1,\dots,6,8\}\) 下无重训评估，并记录门值、逐 token 轨迹、吞吐和峰值显存。

## 6. 主要结论与发现

- **采样区间下界是决定性开关**：
  - 固定 \(R=2\)：深层块门值接近 1，第二次 pass 近似完整层；在 \(R=2\) 时优于参数匹配普通模型 0.032 nat，但超出训练深度后损失明显变差且 seed 间不稳定。
  - \(R\sim\{1,\dots,6\}\)：门值塌缩到 0.1–0.5，额外 pass 变成小修正；损失在 \(R=2\) 到 8 很平，但总增益最多约 0.09 nat。
  - \(R\sim\{2,3,4\}\)：门值保持 0.6–0.9，额外 pass 保持完整层强度；最佳循环模型为 **2.909 nat（R=3）**，优于普通 6 层模型的 2.951；在 \(R=8\) 仅退化 0.038 nat。
- **门值是可解释观测器**：门值直接反映额外 pass 的工作强度；去掉 \(R=1\) 后，门值剖面恢复到接近固定 \(R=2\) 的形态。
- **固定深度循环“方向收敛但损失发散”**：固定 \(R=2\) 时，残差流方向变化 \(\delta_i\) 几何收缩，但范数每 pass 约增长 9%，相对步长停在 0.12–0.20；由于 pre-norm 只读方向，隐藏状态在方向上收敛，但收敛到输出投影未见过的状态，导致损失上升。这细化了“静态深度不收敛”的近期发现。
- **前向静态 KV 代价小且改变动力学**：在所有情形下仅增加 0.01–0.03 nat 损失，训练吞吐提升 2%–8%，推理缓存减半；使逐 token 迭代一致收缩，减少过度迭代损害，但牺牲 token 间读取彼此精炼状态的能力。
- **循环相对真实深度的收益有限**：等参数下，3 块循环恢复普通 6 块约 35% 的差距，6 块循环恢复普通 12 块约 24%；等 FLOPs 下，普通模型在语言建模损失上约优 0.10 nat。

## 8. 局限与需要谨慎解读之处

- **规模有限**：主体模型为 46M–110M 总参数、2B token，属于“受控机理研究”而非大模型验证；门值塌缩、下界效应和 static-KV 的代价在更大模型、更长训练、更多数据上是否同样成立，仍需验证。
- **统计功效不足**：多数配置为单 seed，headline 对比仅部分双 seed；固定 \(R=2\) 在 \(R=6\) 时两个 seed 的损失差异很大，说明超出训练深度后的行为本身高方差。当前效应量（约 0.01–0.1 nat）虽方向一致，但不宜据此做强断言。
- **评测面较窄**：主要指标是三个域 held-out 损失按训练比例加权，没有下游推理、代码生成、数学解题或长上下文任务；因此“循环在测试时扩展是否带来推理能力收益”没有被直接检验。语言建模损失平缓也不等于下游性能同样平缓。
- **调度空间覆盖有限**：只比较固定 \(R=2\)、\(R\sim\{1,\dots,6\}\)、\(R\sim\{2,3,4\}\) 三种调度，尚不能区分“下界”与“均值/方差/分布形状”的独立贡献；例如下界为 2 但均值更高、或下界为 1 但 \(R=1\) 概率极低的调度，可能给出不同结论。
- **门控机制本身可能改变结论**：门初始化 0.5、不参与 weight decay、每块两个标量等设计会影响优化路径；若改用其他残差缩放、LayerScale 或随机深度，门值剖面与“下界开关”效应可能部分变化。
- **static-KV 证据偏弱**：其损失代价多为单 run 比较，且“逐 token 迭代一致收缩”的解释基于观测相关性；在不同注意力结构、分组查询注意力或长序列下，前向 KV 共享的收益/损害可能不同。
- **理论解释仍是现象学**：方向收敛而范数增长导致输出分布漂移的解释有说服力，但未给出形式化收敛保证；pre-norm 下方向与范数的分离、输出投影未见状态等机制仍可进一步理论化。
- **资源与吞吐结论的普适性有限**：吞吐提升 2%–8%、缓存减半是在特定实现、序列长度 1024、单卡 RTX 5080 上测得，实际系统收益取决于 kernel、批大小与推理框架。

## 9. 对后续研究与实践的启发

- **训练配方**：若目标是让每次循环都保持“完整层”强度，应避免训练中出现 \(R=1\)，并让采样下界至少为 2；若目标是获得对 \(R\) 更鲁棒的小修正式循环，则可保留 \(R=1\)，但需接受额外 pass 的工作强度被压低。
- **诊断优先**：在扩大循环模型前，可先用可学习门值做低成本“体检”，判断额外 pass 是完整层还是微调；门值塌缩往往早于最终损失给出信号。
- **外推评估应多 seed**：固定深度循环在超出训练 \(R\) 后的不稳定性较强，报告测试时扩展收益时应至少多 seed、并同时报告方差，而非只看最佳点。
- **KV 策略需按目标选择**：若追求推理缓存减半与吞吐，前向 static-KV 是低代价选项；若任务依赖 token 间多轮读取彼此精炼状态，则 fresh-KV 可能更合适，需用下游任务而非仅损失来判断。
- **后续实验方向**：更大参数/ token 规模、多 seed、下游推理任务、不同 \(R\) 分布（控制下界、均值、方差）、不同门参数化与残差缩放、与 MoE/循环推理/测试时自适应结合，以及针对“方向收敛—范数漂移”的形式化分析。

## 10. 总体评价

论文以一个非常小、非常清晰的干预——训练时 \(R\) 的采样下界——解释了循环 Transformer 中“额外 pass 是完整层还是小修正”的分化，并把门值、残差动力学、KV 策略和损失联系起来。其最强贡献不是宣称循环模型全面优于普通模型，而是给出了一个可操作、可解释的训练开关，以及一套可复用的诊断方法。受限于模型规模、seed 数量和评测范围，结论应视为“受控小规模下的强机制证据”，而非大规模定论；但就问题切口、实验控制和工程启示而言，这是一项扎实且值得跟进的工作。
