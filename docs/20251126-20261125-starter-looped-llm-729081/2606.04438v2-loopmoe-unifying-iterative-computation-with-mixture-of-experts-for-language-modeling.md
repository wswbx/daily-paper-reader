## 摘要
混合专家（MoE）与循环架构沿两条正交的轴扩展模型规模，即参数容量与有效深度。然而，主流循环架构依赖稠密骨干网络，将参数数量与每 token 的 FLOPs 耦合在一起，使得在匹配预算下无法单独考察迭代计算的作用。为此，我们提出 LoopMoE，一种循环 MoE 语言模型，通过两项设计将稀疏路由与迭代式权重共享计算相结合。第一项是 IterAdaLN，它通过一个同时以迭代索引和每 token 隐藏状态为条件的调制信号，解决权重共享带来的对称性问题。第二项是一种容量平衡策略，可恢复经过良好调优的非循环参考模型中注意力层与 FFN 的活跃参数比例。这些设计共同实现了首次在总参数、每 token FLOPs 和活跃子层比例完全相同的条件下，对循环 MoE 与 Vanilla MoE 进行严格受控的正面比较评估。在九个下游基准上，LoopMoE 相对于其匹配的 vanilla MoE 的平均提升从 3B 规模下的 1 分以上增长到 9B 规模下约 3 分。这些结果为“迭代稀疏计算的优势可能随规模增强”提供了初步证据，使 LoopMoE 成为可扩展循环语言模型的一个有前景的架构。

## Abstract
Mixture-of-Experts (MoE) and looped architectures scale models along two orthogonal axes, namely parameter capacity and effective depth. However, mainstream looped architectures rely on dense backbones that couple parameter count with per-token FLOPs, which makes it impossible to isolate the effect of iterative computation under matched budgets. To this end, we present LoopMoE, a looped MoE language model that integrates sparse routing with iterative weight-shared computation through two designs. The first is IterAdaLN, which resolves weight-sharing symmetry via a modulation signal jointly conditioned on the iteration index and the per-token hidden state. The second is a capacity-balancing strategy that recovers the attention-to-FFN active parameter ratio of well-tuned non-looped references. Together, these designs enable the first strictly controlled, head-to-head evaluation of a looped MoE against a Vanilla MoE under identical total parameters, per-token FLOPs, and active sublayer ratios. Across nine downstream benchmarks, LoopMoE's average improvement over its matched vanilla MoE increases from over 1 point at the 3B scale to approximately 3 points at the 9B scale. These results provide initial evidence that the benefits of iterative sparse computation may strengthen with scale, positioning LoopMoE as a promising architecture for scalable looped language models.

## 1. 核心问题与研究动机

- **背景两条正交扩展轴**：MoE 通过稀疏激活解耦“总参数量”与“每 token 计算量”，沿**参数容量**轴扩展；循环/权重共享架构（block-recurrent）通过重复执行同一组层，沿**有效深度**轴扩展而不增加参数。
- **核心矛盾**：主流循环架构（Universal Transformer、ALBERT、Hyperloop、Ouro 等）均建立在**稠密骨干**之上，参数量与每 token FLOPs 被紧紧耦合。因此无法在“总参数、每 token FLOPs 同时对齐”的受控条件下，单独隔离出“迭代计算”本身的贡献。
- **理论出路与两个新难题**：MoE 天然解耦 N 与 F，是理论上可行的解法；但把循环直接嫁接到 MoE 上会引入：
  - **表征层面**：跨迭代权重共享带来结构对称性，模型难以逐步演化 token 状态；
  - **结构层面**：注意力参数在各迭代被均匀复用，而 token 每步路由到不同专家，导致“活跃注意力/FFN 参数比 ρ”严重偏离调优良好的非循环基线的工作点 ρ⋆，注意力相对欠参数化。
- **整体含义**：本文试图建立一个**严格受控的实验平台**，首次在总参数、每 token FLOPs、活跃子层比例三者同时匹配的条件下，正面对比“循环 MoE”与“Vanilla MoE”，从而把架构贡献从参数/计算膨胀中剥离出来。

## 2. 方法论

### 2.1 总体架构：Sandwich-Loop 骨干

- 层组织为三段：非共享 **prefix**（Lp）→ 共享 **loop block**（Lb，执行 K 次）→ 非共享 **suffix**（Ls）。有效深度 D = Lp + K·Lb + Ls，唯一层数 U = Lp + Lb + Ls。
- 单层结构沿用 DeepSeek-V3 风格：MLA 注意力 + 细粒度 MoE，第一个 post-embedding 层用稠密 FFN；每个子层采用 sandwich normalization（前置归一化 + 输出端额外 RMSNorm 后再残差相加）。
- **关键改动：移除 prefix 重注入**。既有 sandwich-loop 模型在每步把 h_pre 加性重注入，导致首迭代 h₀ 定义不清、常量 h_pre 主导残差流、抑制迭代间差异。本文改为纯递归：
  - h₀ = h_pre；h_k = f_body(h_{k−1}; c_{k,t})，k = 1…K
  - 由此 **IterAdaLN 成为唯一的“逐迭代差异化”通路**。

### 2.2 IterAdaLN（破解权重共享对称性）

- **动机**：DiT 式“仅以迭代索引为条件”的 AdaLN 对图像生成够用（扩散时间步是真正的全局条件），但对语言序列存在**空间瓶颈**——同一迭代内所有位置被施加相同仿射调制，而自然语言在句法标记、功能词、语义实体上的更新需求高度异质。
- **双流条件构造**（对注意力分支与 MoE 分支分别构造）：
  - 迭代流：迭代索引 k 经固定正弦编码 PE(k) + 小型可学习 MLP，得 v_k；
  - token 流：对当前 token 状态做线性投影（注意力分支用 h_{k−1,t}，MoE 分支用注意力更新后的中间态 m_{k,t}）；
  - 两流按广播加法融合：c^attn = Linear_attn(h_{k−1,t}) + MLP_iter(PE(k))，c^moe = Linear_moe(m_{k,t}) + MLP_iter(PE(k))。
- **归一化替换**：以无仿射的 RMSNorm 为基础，用条件生成的 (γ, β) 替代静态可学习缩放：
  - IterAdaLN(h; c) = (1 + γ(c)) ⊙ h / sqrt(E[h²] + ε) + β(c)
- **零初始化调制 MLP**：两个独立 MLP₀ 分别输出 (γ^attn, β^attn, α) 与 (γ^moe, β^moe)，输出投影零初始化 → 初始时 γ=β=α=0，K 步循环从“近似恒等变换”起步，差异化在优化中逐渐涌现。
- **残差门控 α 的非对称放置**：α 只作用于注意力分支。理由（附录 A.3）：MoE 输出是路由加权求和，α·MoE = Σ(α·w_i)·E_i，门控会被吸收进路由权重，不增加表征能力，反而扰动负载均衡损失与 expert-bias 更新所标定的路由权重；MLA 无类似的 token 条件重加权机制，故门控在此是严格互补的。
- **逐层更新式**（顺序复合）：
  - m_{k,t} = h_{k−1,t} + α_{k,t} · A(IterAdaLN(h_{k−1,t}; γ^attn, β^attn))
  - h_{k,t} = m_{k,t} + MoE(IterAdaLN(m_{k,t}; γ^moe, β^moe))

### 2.3 容量平衡策略

- **问题量化**：A_attn 随 K 保持常数，而 A_ffn 随 K 累积但**次线性**增长（后续迭代选中已激活专家的概率上升，边际贡献递减），故 ρ_loop 单调下降并远低于 ρ⋆。
- **两步流程**：
  1. **测量**：实验刻画 top-k 路由下 token 在 K 次迭代中期望激活的唯一专家数 a，得到 A_ffn(K) 的次线性曲线；以 Vanilla MoE 的 (ρ⋆, N⋆, F⋆) 为目标工作点。
  2. **重平衡 + 容量恢复**：扩大 MLA 的 Q/KV LoRA 秩以提升 A_attn，同时缩小每个专家的隐层维度以降低 A_ffn（top-k 不变，故 F 不变、N 下降）；再利用 MoE 对 N/F 的解耦，通过**扩大路由专家池数量**把 N 恢复到 N⋆。
- 效果（表 7）：3B 下 Q LoRA 384→512、KV 512→640、专家数 64→136、FFN 隐层 896→864；9B 下 768→896、512→640、64→136、1280→1216。

## 6. 主要结果

- **与匹配基线对比（核心主张）**：在总参数、每 token FLOPs、活跃子层比例、token 数全部对齐的条件下，LoopMoE 在多数基准上优于 Vanilla MoE，增益主要集中在**多步推理类**任务（BBH、GSM8K、MATH），而在知识密集型单跳任务（TriviaQA、MMLU）上差距较小甚至持平。这一分布形态与“迭代计算补充的是串行计算深度、而非参数化知识容量”的解释一致，也是本文最有说服力的证据形态。
- **BBH 子任务分解**：增益在需要多跳组合、状态跟踪、符号操作的任务上更明显，在单步事实检索类子任务上接近零。这为“循环带来的是算法性/串行深度”提供了任务层面的细粒度佐证，而不仅是聚合分数的提升。
- **跨迭代路由动力学**：router 输入的迭代间余弦相似度随 k 递减、专家激活 Jaccard 随 k 下降，说明循环块内部确实发生了**表征与专家选择的逐步分化**，而非简单地重复同一函数——这直接回应了“权重共享导致对称性、迭代无效”的担忧，也间接验证了 IterAdaLN 的作用。
- **IterAdaLN 调制量统计**：(γ, β, α) 的幅值随训练上升并随迭代索引呈现系统性差异，说明模型自发学会了按迭代差异化调制；零初始化使训练早期近似恒等，避免了深层循环的优化不稳定。
- **效率**：Loop Base 吞吐最高（86.2 TFLOP/s/GPU），LoopMoE 为 81.8，Vanilla MoE 为 66.0——即在相近甚至更优的训练吞吐下取得更好效果，说明收益并非用算力换来的。解码侧因参数量与 FLOPs 对齐，单请求延迟与 Vanilla MoE 同量级，未出现循环架构常见的推理开销爆炸。

## 7. 结论与贡献定位

- 本文的核心贡献不是“提出一个更强的模型”，而是**建立一个可证伪的受控比较框架**：把循环 MoE 与 Vanilla MoE 放到同一 (N, F, ρ) 工作点上，从而首次把“迭代计算”的边际收益从参数与计算膨胀中分离出来。
- 两项技术组件具有独立价值：（i）IterAdaLN 用 token 流 + 迭代流的双流条件破解权重共享对称性，并给出 α 只作用于注意力的机理性论证；（ii）容量平衡流程（测量 a → 提注意力秩 / 降专家隐层 → 扩专家池恢复 N）是对“循环使 ρ 漂移”这一结构性副作用的一般性修正方案，可迁移到其他循环-MoE 组合。

## 9. 启示

- 对 MoE 与循环架构的交叉研究，**“对齐工作点”应成为默认实验纪律**：不同时匹配 N、F 与活跃子层比例，任何“循环更好/更差”的结论都不可靠。
- 权重共享架构的性能瓶颈往往不在“共享”本身，而在**共享破坏了原本调优好的参数配比**；本文的 ρ 漂移分析提示，许多文献中循环架构的欠佳表现可能部分是配比失衡而非架构缺陷。
- 逐迭代条件化的正确粒度是 **token 级 × 迭代级**，而非仅迭代级；这对扩散式/递归式语言模型的 conditioning 设计有直接借鉴意义。
- 残差门控在 MoE 分支上“被路由权重吸收”的论证，是一个可推广的架构设计原则：**任何位于路由加权求和之外的逐 token 标量门控，在 MoE 分支上都是冗余的**。
