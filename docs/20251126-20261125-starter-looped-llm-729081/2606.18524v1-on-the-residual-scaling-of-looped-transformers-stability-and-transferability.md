## 摘要
循环（权重共享）Transformer 将共享残差块应用 N 次（h ← h + ε f(h)，每一步使用相同的 f），从而在不增加参数的情况下提高有效深度。先前的深度缩放分析针对深度为 L 的残差网络给出 ε = 1/√L。我们表明，这对循环架构并不充分：权重共享使残差更新在迭代之间相关，因而需要更强的缩放 ε = 1/N。对于多层块（L 个唯一层循环 N 次），我们推导出一种因子化参数化 ε = λ/(N√L)，它将两种增长来源分开：1/N 控制层内循环相关性，而 1/√L 控制层间方差。一个关键推论是，最优学习率仅取决于唯一层数 L，而不取决于循环次数 N，从而能够在不重新调参的情况下将超参数从小 N 直接迁移到大 N。在循环 Transformer 上的实验证实，在不同循环次数下，1/N 缩放比 1/√N 缩放更能改善可训练性并获得更优损失。

## Abstract
Looped (weight-tied) Transformers apply a shared residual block $N$ times ($h \leftarrow h + \varepsilon\,f(h)$, same $f$ at each step), increasing effective depth without adding parameters. Prior depth-scaling analyses prescribe $\varepsilon = 1/\!\sqrt{L}$ for depth-$L$ residual networks. We show that this is insufficient for looped architectures: weight sharing makes residual updates correlated across iterations, requiring the stronger scaling $\varepsilon = 1/N$. For multi-layer blocks ($L$ unique layers looped $N$ times), we derive a factored parameterization $\varepsilon = λ/(N\!\sqrt{L})$ that separates the two sources of growth: $1/N$ controls the within-layer loop correlation, and $1/\!\sqrt{L}$ controls the across-layer variance. A key consequence is that the optimal learning rate depends only on the number of unique layers $L$, not on the loop count $N$, enabling direct hyperparameter transfer from small to large $N$ without retuning. Experiments on looped Transformers confirm that $1/N$ scaling improves trainability and yields better loss than $1/\!\sqrt{N}$ scaling across loop counts.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：循环（权重共享）Transformer 将同一个残差块重复应用 N 次（`h ← h + ε f(h)`），在不增加参数量的前提下提升有效深度，已被 Universal Transformers、ALBERT 以及近期用于算法推理、潜在计算的循环模型采用。
- **核心问题**：随着循环次数 N 增大，训练常出现隐藏状态爆炸、对学习率高度敏感等不稳定现象。已有的深度缩放分析（针对深度为 L 的非共享残差网络）规定 `ε = 1/√L`，但这一准则是否适用于权重共享的循环架构尚未得到验证。
- **核心发现**：`1/√N` 缩放对循环模型**不充分**。原因是权重共享使不同迭代的残差更新高度相关，残差流范数从随机游走式的 `Θ(√N)` 增长恶化为线性式的 `Θ(N)` 增长，因此需要更强的 `ε = 1/N` 缩放。
- **整体含义**：该工作将深度缩放框架扩展到权重共享架构，指出标准独立性假设在参数复用下失效，并推导出修正后的缩放规则，使循环次数成为一个可稳定调节、且超参数可迁移的实用缩放轴。

## 2. 方法论：核心思想与关键技术细节

### 2.1 单层共享权重的分析（第 3 节）

- **模型抽象**：`h_{n+1} = h_n + ε W φ(h_n)`，其中 `ε = N^{-α}`，W 为共享的 i.i.d. 高斯矩阵，φ 为 ReLU。
- **展开分析**：`h_N = h_0 + ε Σ r_n`，平方范数分解为交叉项 `B_N = O(εN)` 与二次项 `C_N = ε²/d ‖Σ r_n‖²`。
- **关键机制**：由于 W 共享，可提取 `Σ r_n = W Σ u_n`。ReLU 的非负性把 `Σ u_n` 限制在非负正交锥 `C+` 内，激活值**构造性累积**（constructive accumulation），使得 `‖Σ r_n‖² = Θ(N²)`，而非非共享网络中的 `Θ(N)`。
- **定理 1**：在非退化激活质量、有界激活尺度、正锥增益三个假设下，`d^{-1}‖Σ r_n‖² = Θ(N²)`，残差流范数有界要求 `εN = O(1)`，即 `α ≥ 1`，故需 `ε = 1/N`。
- **定理 2（学习率缩放）**：在更新尺度、稳定激活、`εN = O(1)` 假设下，单步输出扰动满足 `d^{-1/2}‖Δh_N‖ = O(ηεN)`，故 `ηεN = O(1)` 充分。当 `α = 1` 时 `η = Θ(1)`，即**最优学习率与 N 无关**，实现超参数迁移。

### 2.2 多层块扩展（第 4 节）

- **模型**：L 个不同层各被复用 N 次，`h_{n,ℓ+1} = h_{n,ℓ} + ε W_ℓ φ(h_{n,ℓ})`。
- **两种方差来源**：层内循环相关（贡献 `Θ(N²)`）与层间随机游走（贡献 `Θ(L)`）。
- **因子化参数化**：`ε = λ/(N√L)`，其中 `1/N` 消除层内二次增长，`1/√L` 控制层间随机游走，λ 为可调 O(1) 常数。
- **定理 3（非正式）/ 定理 6（正式）**：在分支范数非退化、单层替换稳定性（一层只能通过总残差强度 `εN` 影响其他层）假设下，`ε = λ/(N√L)` 使残差流范数仅由 λ 决定，与 N、L 均无关；未缩放时总分支方差为 `Θ(LN²)`。
- **学习率法则**：`η ≲ 1/(λ√L)`，**只依赖唯一层数 L，不依赖循环次数 N**（命题 7 给出线性化最大更新界及相干条件下的紧致性）。

### 2.3 实用缩放配方（表 1）

- 残差分支：`× λ N^{-1} m_L^{-1/2}`（`m_L = L/L_ref`）
- 循环堆叠学习率：`η_0 m_L^{-1/2}`
- 嵌入 / 反嵌入学习率：`η_0`（不随深度缩放）

## 6. 主要结论与发现

- **线性缩放稳定前向传播**：`1/√N` 无法控制循环网络的残差流范数（可爆炸），`ε=1/N` 使其在 N=1–64 范围内保持有界且近似不变；非共享深堆叠则 `1/√L` 即足够。
- **机制验证**：非共享堆叠的增量余弦相似度近零（随机游走），循环网络的增量呈稠密正相关（构造性累积），与定理 1 一致。
- **学习率迁移**：线性缩放下最优学习率跨 N 近似不变（η ∝ N⁰）；sqrt 缩放下最优值随 N 漂移。
- **性能提升**：N=8 时线性缩放比 sqrt 缩放最低损失低 0.025 nats。
- **联合迁移**：`ε = λ/(N√L)` 使单一基础学习率在 L ∈ {12,24,48} 与 N ∈ {1,2,4,8} 的所有组合上近似最优，验证循环轴与深度轴的解耦。
- **训练后机制持续**：全训练后循环步增量相关性减弱但仍为正（早/中期步集中在 0.3–0.6），仅末尾步接近零或略负；不同 N 的最终残差流范数收敛到相近值。
