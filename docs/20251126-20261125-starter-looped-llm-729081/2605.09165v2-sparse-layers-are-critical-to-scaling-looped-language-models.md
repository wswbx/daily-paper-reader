## 摘要
循环语言模型通过深度重复一组 Transformer 层，从而降低内存成本，并在循环边界提供自然的提前退出点。然而，循环模型的可扩展性不如具有独立层的标准 Transformer。我们比较了标准 Transformer 与专家混合（Mixture-of-Experts, MoE）Transformer 在有循环和无循环情况下的表现，并得到两个主要结果。首先，我们发现 Looped-MoE 模型比标准基线具有更好的可扩展性，而稠密循环模型则不然。我们将此归因于循环之间的路由分歧：在 Looped-MoE 模型中，每次经过相同的共享层时会激活不同的专家，从而在不增加参数的情况下恢复表达能力。我们的第二个发现是，与标准模型相比，循环模型在提前退出方面具有更好的计算-质量权衡。由于每个循环都以产生最终输出的相同层结束，循环边界是更优的退出点，这一点已由这些点上更早的输出收敛所证实。总之，我们为扩展循环模型提供了一个明确方向：带有提前退出的 Looped-MoE 模型不仅能够在大规模下击败标准 Transformer，还能在质量下降极小的情况下显著节省内存和推理成本。

## Abstract
Looped language models repeat a set of transformer layers through depth, reducing memory costs and providing natural early-exit points at loop boundaries. However, looped models do not scale as favorably as standard transformers with unique layers. We compare standard and Mixture-of-Experts (MoE) transformers, with and without looping, and find two main results. First, we find Looped-MoE models scale better than the standard baseline while dense looped models do not. We trace this to routing divergence between loops: in Looped-MoE models, different experts are activated on each pass through the same shared layers, recovering expressivity without additional parameters. Our second finding is that looped models have better compute-quality trade-offs with early exits than standard models. Because each loop ends with the same layers that produce the final output, loop boundaries are superior exit points, as confirmed by earlier output convergence at these points. In sum, we provide a clear direction for scaling looped models: a Looped-MoE model with early exits can not only beat standard transformers at scale, but also enable significant memory and inference savings with minimal degradation in quality.

## 1. 核心问题与研究背景

- **背景**：大语言模型（LM）参数规模巨大，存储昂贵、推理缓慢。其根本架构限制在于：参数按顺序堆叠，**每个参数在一次前向推理中仅被使用一次**。
- **思路来源**：通过"计算深度"复用参数（Universal Transformer、LoopLM、循环深度模型等）可降低存储成本，并在循环边界提供天然的提前退出点。
- **核心矛盾**：已有研究发现，在**同等训练计算量（isoFLOP）**下，循环模型的表现**不如**使用独立层的标准 Transformer。
- **本文要回答的问题**：循环模型扩展性差的瓶颈在哪里？是否是稠密 FFN（对所有 token 施加相同操作、循环时不变性被放大）导致表达能力受限？稀疏 MoE 层能否通过输入相关的路由恢复表达能力？
- **整体含义**：若能用稀疏专家修复循环模型的扩展性缺陷，就能同时获得**更少存储 + 更优推理计算-质量权衡**，为低成本 LM 提供一条实用路径。

## 2. 方法论

### 2.1 核心思想
在标准循环 Transformer 中，将**稠密 SwiGLU FFN 替换为 top-k 稀疏 MoE 层**，使同一物理层在不同循环轮次对同一 token 激活不同专家子网络，从而在不增加参数的情况下恢复权重绑定损失的表达能力；同时利用循环边界作为高质量早退出点。

### 2.2 架构与关键设计
- **共同骨干**：decoder-only Transformer，多头自注意力（RoPE）、SwiGLU FFN、pre-RMSNorm（无可学习增益）、残差流。
- **层循环**：L 个唯一层重复 R 次，有效深度 L×R；缩放研究采用 L=8、R=2，与 16 层非循环模型有效深度对齐。
- **MoE 路由**：token-choice top-k 路由，$h(x)=W_{router}x$，取 top-k 专家并按 softmax 归一化加权求和：
  $$y=\sum_{i\in T}p_i(x)\,\text{FFN}_i(x)$$
  采用 **k=2 / E=8**（参考 Mixtral）。
- **辅助损失**：负载均衡损失 $L_{LB}$（鼓励专家均匀分配）+ router z-loss $L_{RZ}$（惩罚大 logit 以稳定训练），防止专家坍缩。

### 2.3 µP 参数化（降低缩放研究成本）
- 使用 Maximal Update Parameterization，在 $d_{base}=128$ 小宽度上调优学习率并迁移到大宽度。
- 初始化方差与学习率按 $w_{ratio}=d_{model}/d_{base}$ 反向缩放；将标准 µP 扩展到 unembedding、router、expert 权重；**不使用额外的前向乘子**（与部分先前工作不同）。
- 循环层无需额外修改（权重绑定层接收多位置梯度但尺度不变）。
- 通过 µP 迁移测试验证：最优学习率在不同宽度（128–1024）下最多仅 0.8% 损失差异。

### 2.4 FLOPs 核算
- 采用 $C=6ND$ 近似，其中 **N 使用 $N_{active}$**（单次前向实际使用的参数，含重复层与 k 个活跃专家），而非 $N_{unique}$（存储参数）。
- 四种架构在匹配 token 数下 $N_{active}$ 相同，因此计算预算可比。

### 2.5 早退出机制
- 训练无关的**熵准则**：在每个候选退出点将隐状态投影到词表，若输出分布熵低于阈值 τ 则退出，未使用的深度计为节省 FLOPs。
- 循环模型**仅允许在循环边界退出**；非循环模型可在任意中间层退出。
- 扫描 τ 得到"计算节省 vs 困惑度"的 Pareto 前沿。

### 2.6 分析工具
- **专家路由重叠分析**：统计同一 token 在两次循环中 top-k 专家集合的完全重叠 / 部分重叠 / 完全不重叠比例。
- **JSD 收敛分析**：计算各有效层输出分布与最终层分布的 Jensen-Shannon 散度，归一化到 [0,1]，JSD<0.5 视为"已收敛"。

## 3. 实验设计

### 3.1 数据集与训练配置
- **预训练数据**：FineWeb-Edu 的 10B token 样本；GPT-2 tokenizer（V=50,257）。
- **优化器**：AdamW（β₁=0.9, β₂=0.999, ε=1e-8, 独立权重衰减 1e-4）。
- **学习率调度**：Warmup-Stable-Decay（WSD）+ sqrt-decay cooldown 至峰值 5%，最后 10% 步执行；峰值学习率由 µP 从 d_base=128 迁移。

### 3.2 对比方法与实验设置

| Base | 稠密 | 16 | 否 |

| MoE | 稀疏 | 16 | 否 |

## 6. 主要结论与发现

### 6.1 缩放定律
- **Looped-MoE 缩放优于 Base**（α=0.077 vs 0.076，均与 Kaplan 等 0.076 一致），而**稠密 Looped 严格劣于 Base**。
- 总体排序（相同计算下测试损失）：**MoE > Looped-MoE > Base > Looped**。
- 结论：**稀疏专家修复了循环模型的缩放缺陷**，稠密 FFN 确实是循环架构的表达能力瓶颈。

### 6.2 下游性能
- 在 1e18 FLOPs 下，Looped-MoE Core 9 平均分 **39.6**，超过 Base（38.7），且存储参数更少（216M vs 246M）。
- Looped 最低（37.4），与缩放缺陷一致。
- 意外发现：MoE 测试损失最好但下游最低（36.4）；作者推测是每 token 单次仅访问 k=2 专家，而 Looped-MoE 因路由分歧在每个物理层累计访问 3–4 个不同专家，知识覆盖更广。

### 6.3 路由分歧机制
- 在 Looped-MoE 中，同一 token 第二次经过同一物理层时，**25–53% 的 token 获得完全不重叠的专家集合**，仅 4–14% 完全一致；多数 token 恰好共享一个专家。
- **第 7 层是例外**（37% 完全一致、仅 3% 零重叠），推测其承担循环边界前稳定 embedding 的结构性角色。
- 这证明共享层可在不同循环轮次实现**深度唯一的计算**。

### 6.4 早退出优势
- 循环模型在循环边界处**更早收敛**：第一轮循环结束时多数 token 已接近最终输出分布（JSD 分析），原因是循环边界处的层正是训练时负责产生最终输出的层。
- 在节省 10% FLOPs 时困惑度：Looped **50.2**、Looped-MoE **51.0**、Base **55.4**、MoE **75.7**。
- **稀疏本身不带来早退出优势**（MoE 退化最快），优势来自循环结构。
- **更多循环带来更好权衡**：Looped-MoE 2×8 在节省 10% FLOPs 时困惑度仅 **42.0**，严格优于 4×4 与 8×2；即使循环模型被限制只能在少量循环边界退出，仍优于拥有 15 个自由退出层的非循环 MoE。

### 6.5 实用建议
用 top-k MoE 层替换循环 LM 中的稠密 FFN：所得 Looped-MoE 在相同计算下优于标准稠密 LM、同精度下存储更少、并可通过循环边界早退出进一步节省推理计算。

## 7. 优点

- **问题定位精准**：将"循环模型扩展性差"这一现象归因到稠密 FFN 的表达能力瓶颈，并通过受控实验（分别消融循环与稀疏）验证，逻辑链条完整。

- **µP 工程贡献**：将 µP 扩展到 router、expert、unembedding，并验证仅需初始化方差与逐层学习率两种机制即可迁移，降低了缩放研究成本。

- **实用性强**：结论直接给出可操作的架构建议，并同时考虑存储与推理两个维度的成本。
