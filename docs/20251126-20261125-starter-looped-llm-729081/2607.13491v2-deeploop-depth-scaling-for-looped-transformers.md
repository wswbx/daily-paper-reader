## 摘要
循环 Transformer 通过多轮应用紧凑的物理块堆栈来扩展顺序计算，在不增加存储参数的情况下增加展开深度。这种复用改变了残差缩放问题：在非共享 Transformer 中，每个残差分支接收并应用自己的参数更新；而在循环 Transformer 中，一个共享更新聚合来自重复访问的梯度，并在下一次线性化前向传播中由这些相同访问读回。我们通过由访问对齐系数 κ_R 控制的一阶扰动界来形式化这种绑定深度效应。该界在访问去相关时恢复 DeepNorm 指数，但在保守对齐情形下，当循环次数在固定物理深度下增长时，它要求指数从 1/4 增加到 1/2。由此得到的方法 DeepLoop 保持 Post-LN DeepNorm 架构，并对展开深度 N 设置 α=(2N)^{1/2} 和 β=(8N)^{-1/2}。在 GPT-2 small 和 GPT-2 medium 规模的 GPT 风格循环语言模型上，当没有物理块被重复访问时 DeepLoop 是中性的，而一旦循环深度被激活，它可改善验证损失和下游准确率。这些结果表明，稳定的循环深度需要能够考虑参数访问而不只是名义层数的残差缩放规则。

## Abstract
Looped Transformers scale sequential computation by applying a compact stack of physical blocks for multiple rounds, increasing unrolled depth without increasing stored parameters. This reuse changes the residual-scaling problem: in an untied Transformer, each residual branch receives and applies its own parameter update, whereas in a looped Transformer one shared update aggregates gradients from repeated visits and is read back by those same visits in the next linearized forward pass. We formalize this tied-depth effect through a first-order perturbation bound controlled by a visit-alignment coefficient $κ_R$. The bound recovers the DeepNorm exponent when visits decorrelate, but in the conservative aligned regime it requires the exponent to increase from $1/4$ to $1/2$ as loop count grows at fixed physical depth. The resulting method, \textbf{DeepLoop}, keeps the Post-LN DeepNorm architecture and sets $α=(2N)^{1/2}$ and $β=(8N)^{-1/2}$ for unrolled depth $N$. On GPT-style looped language models at GPT-2 small and GPT-2 medium scale, DeepLoop is neutral when no physical block is revisited and improves validation loss and downstream accuracy once recurrent depth is activated. These results show that stable recurrent depth requires residual scaling rules that account for parameter visits, not only nominal layer count.

## 1. 核心问题与整体含义（研究动机与背景）

- **深度是提升 Transformer 表达能力的可靠途径，但标准架构中深度与参数量同步增长**：每增加一层就要新增一套注意力与 FFN 权重。
- **循环 Transformer 解耦这两个轴**：用 K 个物理块循环 R 轮，展开深度 N = K·R，而参数只存 K 个块。这与 Universal Transformer、ALBERT、Subformer 以及近期的循环深度/测试时计算模型一脉相承。
- **核心矛盾：权重共享改变了残差缩放问题**。DeepNorm 等残差缩放分析都建立在"深度不共享"（untied）假设上：每个展开子层拥有独立参数、贡献一次独立更新。但在循环模型中，同一物理子层被访问 R 次，其优化器更新会**聚合所有轮次的梯度**，随后这一共享更新又被**所有这些访问在下一轮线性化前向中读回**——形成"多次写入、多次读出"的双重聚合路径。
- **效应大小取决于访问对齐程度**：若各轮梯度/敏感度近似正交（去相关），循环模型行为接近 untied 深度；若高度相干，共享更新可能额外获得因子 R。
- **整体含义**：稳定的循环深度需要**考虑参数访问次数**的残差缩放规则，而不仅仅是名义层数。这为循环 Transformer 的深度扩展与共享参数训练提供了理论依据。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
引入**访问对齐系数 κ_R**，将"绑定深度"（tied-depth）效应形式化为一个受 κ_R 控制的一阶扰动界，并据此推导循环感知的残差缩放指数阈值。

### 2.2 模型设定
- 循环 Post-LN 三明治块：
  x_{i+1} = Norm( α·x_i + f_j(Norm(x_i); φ_j) )
  其中 j = (k, s) 为物理子层（k∈{1..K}，s∈{attn, ffn}），i = (r, j) 为其第 r 次展开访问。
- 物理残差子层数 J = 2K，展开访问数 M = J·R = 2KR = 2N。
- 内层归一化（branch-input Norm）在单位 RMS 流上等价于恒等映射（引理 A.2 证明其不放大敏感性因子，对分析"惰性"）。
- β 是**逐矩阵初始化增益**（作用于 DeepNorm 指定的残差分支矩阵），不是每次访问的运行时乘子。

### 2.3 关键推导链条
1. **假设 3.1（DeepNorm 尺度局部敏感性）**：每次访问的输出敏感性与有效更新范数均为 O(β/α)。
2. **Untied 界**：∥ΔF∥ ≤ C′·M·(β/α)²，稳定性条件 M(β/α)² = O(1)。DeepNorm 取 α=(2N)^{1/4}, β=(8N)^{-1/4}，满足 M(β/α)² = 1/2。
3. **Tied 双求和扰动**：
   ΔF_tied = −η Σ_j (Σ_r U_{r,j})(Σ_t G_{t,j}) + O(η²)
   ——更新由 R 次访问写入、再由 R 次访问读出。
4. **定义访问对齐系数**：
   κ_R := max_j ∥Σ_r U_{r,j}∥·∥Σ_t G_{t,j}∥ / [R·C_U·C_G·(β/α)²]，满足 0 ≤ κ_R ≤ R。
   正交访问 → κ_R = O(1)；完全对齐 → κ_R = Θ(R)。
5. **Tied 界**：∥ΔF∥ ≤ C″·M·κ_R·(β/α)²，稳定性条件 **M·κ_R·(β/α)² = O(1)**。
6. **命题 3.2（指数阈值）**：对缩放族 α=(cN)^p, β=(dN)^{-p}，若 κ_R = Θ(R^γ)，则条件成立当且仅当 **p ≥ (1+γ)/4**。
   - γ=0（去相关）→ p ≥ 1/4，恢复 DeepNorm；
   - γ=1（对齐，固定物理深度）→ **p ≥ 1/2**。
