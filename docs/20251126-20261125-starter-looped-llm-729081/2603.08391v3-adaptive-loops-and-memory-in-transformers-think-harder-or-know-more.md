## 摘要
思维链（CoT）提示使语言模型具备推理能力，但要求显式 verbalization 中间步骤。循环Transformer通过在隐藏状态中迭代精炼表示提供了另一种方案。这种参数效率是有代价的，因为循环模型缺乏更深模型那种每层使用独立权重的存储容量。在本工作中，我们研究了同时具备自适应逐层循环和门控记忆库的Transformer模型：前者中每个Transformer块通过学到的停止机制学习迭代其隐藏状态，后者提供额外的学习存储。我们发现，循环主要有利于数学推理，而相比参数和FLOP匹配的模型，记忆库有助于恢复常识任务上的性能。结合这两种机制得到的模型在数学基准上优于层数为其三倍的等FLOP基线。对模型内部结构的分析揭示了层特化：早期层学习尽量少循环并少量访问记忆，而后期层则两者都更频繁地使用。

## Abstract
Chain-of-thought (CoT) prompting enables reasoning in language models but requires explicit verbalization of intermediate steps. Looped transformers offer an alternative by iteratively refining representations within hidden states. This parameter efficiency comes at a cost, as looped models lack the storage capacity of deeper models which use unique weights per layer. In this work, we investigate transformer models that feature both adaptive per-layer looping, where each transformer block learns to iterate its hidden state via a learned halting mechanism, and gated memory banks, that provide additional learned storage. We find that looping primarily benefits mathematical reasoning, while memory banks help recover performance on commonsense tasks compared to parameter and FLOP matched models. Combining both mechanisms yields a model that outperforms an iso-FLOP baseline, with three times the number of layers, across math benchmarks. Analysis of model internals reveals layer specialization: early layers learn to loop minimally and access memory sparingly, while later layers do both more heavily.

## 1. 核心问题与研究动机

- **背景**：思维链（CoT）提示通过显式生成中间步骤提升推理，但每步都需生成 token，成本高；隐式推理（在隐藏状态中完成多步计算）成为替代方向，其中"循环 Transformer"通过重复应用同一 Transformer 块，以共享权重获得更大有效深度，参数效率高。
- **核心矛盾**：循环模型用 N 次迭代换取有效深度，却只有 1/N 的独立参数，存储容量先天不足。已有分析指出，循环带来的收益来自"知识操纵"（多跳推理），而非"知识存储"，其每参数记忆容量与标准 Transformer 相当。
- **研究问题**：能否用可学习的记忆库（memory banks）补回循环模型缺失的容量？即模型应当"想得更深"（更多循环/计算），还是"知道更多"（更大存储）？两者是否存在功能分工？

## 2. 方法论

### 2.1 自适应逐层循环（Adaptive Looping）

- **核心思想**：每个 Transformer 块可迭代最多 `N_max` 次，由学习到的停机路由器决定每步停止概率，最终输出为各步隐状态的加权组合（PonderNet 风格）。
- **停机路由器**：第 t 步停止概率 `p_t = σ(W_h·[h^(t); t/N_max] + b_h)`，其中 `t/N_max` 为归一化步嵌入；某步恰好停止的概率为 `p_halt^(t) = p_t · Π_{i<t}(1-p_i)`。
- **输出聚合**：`h_out = Σ_{t=1}^{N_max} p_halt^(t) · h^(t)`。
- **可学习循环缩放（训练稳定性关键）**：每步更新为 `h^(t) = h^(t-1) + softplus(α_t)·f_θ(LN(h^(t-1)))`，`α_t` 初始化为 −7.0，使循环初始近似恒等映射，模型逐步学会"何时、以多大幅度"介入。

### 2.2 门控记忆库（Gated Memory Banks）

- **局部（逐层）记忆**：每层独立维护 `(K_ℓ, V_ℓ) ∈ R^{M_L×D}`（M_L=1024 槽），存储该深度特有的中间计算/知识。
- **全局（共享）记忆**：单一 `(K_G, V_G) ∈ R^{M_G×D}`（M_G=512 槽），跨所有层共享，存储通用知识。
- **检索方式**：带 QK-normalization 的缩放点积注意力，`m = softmax(LN_q(h)·LN_k(K)^T / √D)·V`。
- **与 KV-cache 的区别**：记忆库是静态可学习参数，训练时反向传播优化、推理时固定，不随输入动态增长。
- **输入依赖门控**：`g = σ(W_g·h + b_g)`，`h_memory = h + g_L⊙W_L·m_local + g_G⊙W_G·m_global`；避免"强制使用记忆"损害仅靠循环即可完成的任务。论文比较门偏置初始化 `b_g ∈ {−3, 0, 3}`（初始门激活约 0.05 / 0.5 / 0.95）。

### 2.3 训练目标

- `L = L_CE + λ·ñ`，其中 `ñ` 为归一化期望循环步数（映射到 [0,1]）。**主要实验设 λ = 0**（无 ponder 惩罚），因此循环利用模式完全由下一词预测损失自发驱动。

## 6. 主要结论与发现

- **循环主要提升数学推理**：Loop-3 数学 BPB 由 2.163 降至 1.687（−22%），最大增益在 Precalculus（−31%）与 Intermediate Algebra（−26%）；常识准确率 0.501 vs 0.477、BPB 0.813 vs 0.859 亦小幅改善。
- **循环收益递减**：Loop-7 仅比 Loop-3 好约 1.7%，常识表现反而略降；说明额外迭代利于算法性计算，不利于依赖存储知识的任务。
- **循环优于单纯加层（数学）**：Loop-3 数学 BPB 1.687 优于 36 层 IsoFLOP 的 1.801（6.4% 优势），尽管层数仅为其 1/3。
- **记忆库补足常识容量**：三种门初始化均优于 IsoPar-M；相比无记忆 Loop-3，数学再提升 4.2%、常识准确率提升 2%；但 IsoFLOP-M 在常识上仍更强，记忆只是"缩小差距"而非全面反超。
- **层特化**：早期层少循环、少访问记忆；后期层两者都用得更多——与"早期层处理局部句法、后期层处理复杂语义/推理"的认知一致。
- **自发相变**：在 λ=0 下，各循环配置的期望循环步数均在验证交叉熵降至约 3.27±0.59 时开始快速上升，说明模型在获得足够语言能力后才开始利用迭代精炼。
- **循环与记忆互补而非替代**：循环更多的层记忆门激活也更高（局部门 0.42±0.13，全局门 0.30±0.03 更均匀）。
- **总体判断**：存在"知识操纵（循环）"与"知识容量（记忆/独立参数）"的功能解离，两者需结合才能兼顾数学与常识。
