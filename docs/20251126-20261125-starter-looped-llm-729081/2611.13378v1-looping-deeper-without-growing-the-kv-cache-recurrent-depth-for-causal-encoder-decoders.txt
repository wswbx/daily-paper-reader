# ABSTRACT 

Looped language models deepen computation without adding parameters, yet caching full-context key–value (KV) states across layers and rounds severely bounds serving batch size. We design a looped causal encoder–decoder (CED) that achieves recurrent depth with zero round-wise KV growth, addressing where and how to loop an asymmetric stack in which only sparse encoder layers generate global KV. We find that recurrence must be placed in the encoder to iteratively refine global KV representations rather than re-reading static decoder projections, which both drives language-modeling gains and preserves long-context scaling. Furthermore, training the encoder loop under stochastic recurrence depth induces a fixed-point equilibrium where every round losslessly shares the last round’s KV cache. Compounding cross-layer and cross-round KV sharing, the resulting Looped CED 

matches an unlooped CED’s minimal memory footprint and recovers 86–93% of a looped Transformer’s gain with 1/6 of its global KV. To test serving at production scale, we loop the 552B-parameter DeepSeek-V4.1-Flash for 8 rounds on one 4×GB200 node: with per-layer and per-round KV the loop cannot fit a single 128K-token request, whereas Looped CED holds 36 .8× less KV per token, fits 38 such requests (as many as the unlooped model), and serves 3.6× higher throughput on 8K-token prompts. 

# 1 INTRODUCTION 

Looped language models scale compute without scaling pa-rameters by repeatedly applying a weight-tied layer block across recurrent rounds (Dehghani et al., 2019; Saunshi et al., 2025; Prairie et al., 2026a; Geiping et al., 2025; Zhu et al., 2025). Yet in production serving, memory capacity and decode throughput are bottlenecked not by parameter count alone, but by the resident KV cache per request (Kwon et al., 2023; Zadouri et al., 2025). To shrink this KV foot-print, recent system-co-designed architectures replace ho-mogeneous full-context layers with asymmetric KV rout-ing (Brandon et al., 2024; Sun et al., 2024; DeepSeek-AI, 2026). Most notably, the causal encoder–decoder (CED) in DeepSeek-V4.1-Flash (DeepSeek-AI, 2026) equips ev-ery layer with bounded sliding-window attention (SWA) while restricting full-context ( global ) KV generation to a few encoder layers; all decoder layers share a single global KV projected once from the final encoder output, allowing prompt prefill to bypass the decoder entirely. Our goal is to combine recurrent looping with a CED to match the modeling quality and long-range scaling of a looped dense Transformer while preserving CED’s serving

Causal encoder–decoder (CED). Introduced in DeepSeek-V4.1-Flash (DeepSeek-AI, 2026), a CED partitions an L-layer stack into an encoder followed by a decoder. To bound local attention memory, every layer maintains its own sliding-window attention (SWA) cache over the most recent w tokens. and a single shared decoder KV entry linearly projected once at the encoder–decoder boundary from the normalized final encoder output. Any layer equipped with global attention jointly attends to its own local SWA cache and its designated global KV source—either the most recent encoder source preceding that layer, or the shared boundary projection—within a single unified softmax. Crucially, because all global KV entries are fully determined by the encoder output, prompt prefill only needs to execute the encoder layers, bypassing the decoder entirely. 

# 3 LOOPING A CAUSAL 

# ENCODER –D ECODER 

Unlike a homogeneous dense Transformer—where every layer generates and consumes full-context KV, making loop depth a purely representational choice—layer depth in a CED is directly coupled to both global KV routing and 

prefill execution (§2). Combining recurrence with a CED therefore requires jointly resolving two questions: where in the asymmetric stack to place the recurrent core (§3.1), and 

how to train and cache recurrent states so that multi-round iteration does not inflate resident KV memory (§3.2). 

3.1 Where to Loop: Architectural Placement and Serving Asymmetry 

Because a weight-tied recurrent block cannot straddle the encoder–decoder boundary without breaking the single-projection invariant that enables decoder-free prefill, the CED topology naturally partitions loop placement into two regimes (Figure 1a): 

Encoder loop (Iterative Global KV Refinement). The recurrent core resides entirely within the encoder and en-compasses at least one global KV source layer. Across the 

T rounds, the core iteratively refines both its local sliding-window representations and the encoder’s global KV source. Because the final encoder representation—and by exten-sion the projected decoder global KV—depends on the last round, prompt prefill must run all T encoder rounds. 

Decoder loop (Static-Context Iterative Readout). The recurrent core resides entirely within the decoder, down-stream of the boundary projection. Here, all global KV entries—both in the encoder and at the boundary—are final-ized before the loop begins. Each recurrent round refines its local SWA states while repeatedly querying a static global KV cache. Because the decoder is skipped during prefill, this placement leaves prefill compute unchanged relative to an unlooped CED, apart from the last w prompt tokens, which run the decoder to fill its SWA caches. 

Compute and execution asymmetry. In a CED, represen-tational role and system execution move in lockstep. During autoregressive decoding, every token traverses the full net-work, so looping a block of layers for T rounds adds the exact same number of single-layer passes per token in either placement. During prompt prefill, however, a decoder loop executes only the unlooped encoder, whereas an encoder loop must execute all T rounds of its recurrent core before projecting the boundary KV. In our 12-layer experimental configuration with a 6-layer encoder, a 4-layer recurrent core, and T =8 rounds (Fig. 1a), an unlooped CED requires 6 layer passes per prompt token (plus the boundary projection), halving the 12 passes of an unlooped dense baseline. Looping the decoder preserves this lightweight 6-pass prefill, whereas looping the encoder expands prefill to 34 layer passes per token; during decode, both placements expand execution from 12 to 40 passes. The two placements also differ in KV footprint. Decoder layers produce no global KV, so a decoder loop keeps the unlooped CED’s 8 KB of global KV per token (150M models, bf16) even if every round caches its own KV; an encoder loop rewrites its global KV source in every round, so per-round caching grows the global KV to 36 KB per token. Thus, comparing encoder and decoder loops directly tests whether high-quality recurrence requires actively refining the global KV source at the cost of prefill compute, or whether iterating over a fixed global context during decode suffices. 

3.2 How to Loop: Fixed-Point Training and Last-Round KV Caching 

Even when a loop improves modeling quality, naively caching distinct keys and values across all T rounds mul-tiplies the resident KV footprint of every looped layer by 

T , negating CED’s memory advantage. Eliminating this factor requires bridging a fundamental discrepancy between parallel training and memory-efficient inference. 

Per-round training vs. last-round inference. During training, sequences are processed in parallel across tokens by unrolling the recurrent core: at round r, each layer inside the core attends to the round-r keys and values of preceding tokens, which we term per-round KV . Caching all T trajec-tories during serving would require T copies of the core’s global and SWA caches: for the 150M encoder loop at T =8 ,the global KV per token grows from 8 KB to 36 KB (§3.1; Fig. 1b, hatched bars). To avoid this overhead, at inference we apply last-round KV (or terminal KV sharing (Huang et al., 2026b; Prairie et al., 2026b)): once a token completes all T rounds, we retain only its last-round KV states—both the global KV from the core’s source layer and the local SWA KV of every looped layer—and discard all intermedi-ate rounds. When a subsequent token executes any round 

r, it attends to its own round-r state for the current step alongside the cached last-round KV for all past tokens. Looping Deeper Without Growing the KV Cache 

Fixed-point convergence under stochastic depth. Sub-stituting last-round KV for intermediate-round KV at in-ference avoids distribution shift only if the recurrent core converges toward a contractive fixed point across rounds, so that both the local SWA representations and the global KV source stabilize in late rounds. Unlike a deterministic fixed-depth unroll—which allows the core to learn round-specific feature transformations that diverge across rounds—we sam-ple a stochastic recurrence depth per training sequence from a Poisson distribution with mean 8 (clipped to at least 1,backpropagating gradients through the final 4 rounds) while executing a deterministic 8 rounds at inference (Table 8). Exposing the coda and downstream layers to recurrent states across variable depths pressures the core to settle rapidly into a depth-invariant equilibrium (Huang et al., 2026b; Prairie et al., 2026b). When this equilibrium holds (§5.4), Looped CED retains the exact same resident KV footprint per token as an unlooped CED (8 KB of global KV per token at 150M, against 36 KB with per-round caching). 

# 4 EXPERIMENTAL SETUP 

Architectures and model scales. We instantiate DeepSeek-V4.1-Flash’s asymmetric CED topology across an L=12 -layer stack (Figure 1a), split evenly into an encoder (layers 0–5) and a decoder (layers 6–11). Every layer maintains a local SWA cache over a w=128 -token window. In the encoder, layers 0–1 use SWA only, while layer 2 serves as the sole encoder global KV source, read by layers 3–5. At the boundary, layer 6 projects the shared decoder global KV from the encoder output, read by layers 7–11. All global-reading layers merge local SWA and global KV in a single softmax (§2). Each token thus stores only two global KV entries—one from the encoder and one from the decoder. To isolate CED’s cross-layer KV topology, we use standard multi-head attention and dense FFNs without intra-layer KV compression (e.g., GQA or MLA) or MoE modules. Our dense Transformer baseline uses the exact same dimensions but equips every layer with full-causal KV and no SWA, caching 6 × more global KV per token than CED. Fixing this 12-layer layout, we scale hidden dimensions across d ∈ { 768 , 1024 , 1536 }, yielding approximately 90M, 150M, and 340M non-embedding parameters over a 2048-token context (adding a loop introduces ∼1% parameters for input injection; full architectural specifications are in Appendix E). 

Compared configurations and ablations. At each scale, we compare an unlooped baseline against a 4-layer recur-rent loop ( T =8 rounds) placed at layers 2–5 for both CED (encoder loop ) and the dense model, alongside a CED de-coder loop at layers 7–10. At 90M and 150M, we also train a dense model looped at the middle third (layers 4–7) to match Parcae’s default placement (Prairie et al., 2026a). Finally, two 150M CED ablations isolate our core mech-anisms: (i) a fixed-depth encoder loop trained with a de-terministic 8-round unroll to test whether cross-round KV sharing requires stochastic-depth training (§5.4); and (ii) a 

YOCO-U variant (Sun et al., 2026) that loops layers 2–5 within an SWA-only encoder (making layer 6 the sole global KV source), testing whether the loop itself must recompute global KV (§5.3). 

Training and evaluation. Models are trained from scratch on FineWeb-Edu (Penedo et al., 2024) using Muon (Liu et al., 2025) and AdamW under a unified learning-rate sched-ule (Appendix E). Standard runs allocate ∼40 tokens per non-embedding parameter (3.4B, 6.0B, and 13.6B tokens for 90M, 150M, and 340M). To evaluate extended scaling, we also train the 150M models for 29.6B tokens, match-ing the budget of 370M Parcae (Prairie et al., 2026a), our 150M configuration (Parcae counts embeddings). Within each scale and budget, all runs see identical data orders, matching parameter counts and training tokens rather than FLOPs. We report upstream bits per byte (BPB) on FineWeb-Edu val-idation and downstream zero/few-shot accuracy on DCLM CORE and CORE-Extended (Li et al., 2024). Furthermore, because dependencies beyond CED’s 128-token SWA win-dow rely exclusively on global KV—and standard FineWeb-Edu documents are too short to span our 2048-token con-text (median 617 tokens)—we evaluate position-wise BPB across contiguous 2048-token chunks drawn from three long-document corpora: PG19 (Rae et al., 2020), FinePDFs (≥ 4,096 tokens) (Kydl´ ıˇ cek et al., 2025), and GovReport (≥ 2,048 tokens) (Huang et al., 2021) (protocol details in Appendix H).

5.2 Quality Parity with Looped Dense Transformers at 1/6 Global KV 

When matched for parameter count, loop position (layers 2–5), training tokens, and recurrence depth, our looped CED matches the validation BPB of the looped dense Trans-former within 0.001 at all three scales while retaining only one-sixth of the resident global KV (Table 1, Figure 2). In the unlooped regime, CED slightly outperforms the dense baseline across all three scales; adding the encoder loop am-plifies CED capability nearly as strongly as looping benefits the dense stack, capturing 89%, 86%, and 93% of the dense loop gain at 90M, 150M, and 340M (the slight difference in relative gain likely reflects that the dense loop iteratively refines four full-KV layers whereas the CED encoder loop refines a single global-KV source alongside local SWA). We also benchmark against Parcae’s default middle-third loop placement (layers 4–7) (Prairie et al., 2026a). In a dense Transformer, looping layers 4–7 slightly underper-forms looping layers 2–5 at both 90M and 150M; we there-fore use layers 2–5 as our primary dense baseline and in-clude layers 4–7 as a literature reference. Over our extended 29.6B-token training horizon—where the dense reference is looped at layers 4–7—the CED encoder loop finishes ahead by a margin matching this placement offset (Table 2), con-firming that quality parity between looped CED and looped dense models persists across training scales.

Why looping local SWA alone fails at long range (CED vs. YOCO-U). Given that looping the lower half of the network is essential (§5.1), a natural question is whether the looped encoder even needs a global KV source, or whether iterating purely over local SWA layers suffices—the archi-tectural choice made by YOCO-U (Sun et al., 2026). On aggregate validation BPB (Table 1), our YOCO-U-style ablation (which loops layers 2–5 inside an SWA-only en-coder, deferring all global KV generation to layer 6) appears highly competitive, recovering 97% of the CED encoder loop’s average gain. Position-wise evaluation on long documents, however, ex-poses what this short-context average hides (Figure 3c). Within the 128-token SWA window, the YOCO-U loop per-forms slightly better than CED. Beyond the SWA window, however, YOCO-U degrades progressively relative to the dense and CED encoder loops with every doubling of con-text length across every corpus; by the end of the training context (1,024–2,048 tokens), it forfeits 30% of the long-range gain achieved by the CED encoder loop, with the deficit continuing to widen. The CED decoder loop suffers a symmetric failure mode from the opposite side: because its rounds repeatedly query a frozen global KV projection, it falls further behind the dense loop as context grows (Fig-ure 3c), and still does after 5× longer training. Together, these ablations establish a core design principle: for recur-rent computation to scale across long contexts, the looped block must actively recompute a global KV source. A copy test isolates this mechanism: each sample’s first 1,024 to-kens are repeated verbatim, so every copied token must be retrieved through global KV (Figure 10 in Appendix H). At 90M and 150M, unlooped CED recalls worse than unlooped dense (+0.106 and +0.014 BPB on the copied half). In stark contrast, training the exact same CED encoder loop with a determin-istic fixed depth ( T =8 ) causes last-round KV sharing to fail catastrophically (and degrades baseline per-round stability; preliminary experiments on shallower 6-layer, 45M CED models exhibit the exact same dichotomy). Appendix D traces this behavior directly to the recurrent core’s dynamical trajectory. Under stochastic-depth training, the CED encoder state contracts geometrically toward a fixed point across late rounds—stabilizing both its local SWA keys/values and its global KV source (§3.2)—such that unrolling up to 4× more rounds at test time leaves BPB virtually unchanged. Conversely, deterministic fixed-depth models (trained with truncated backpropagation through the final 4 of 8 rounds) fail to contract and instead enter a limit cycle of period 4, rendering last-round KV states incompatible with early rounds (Huang et al., 2026b; Prairie et al., 2026b). While Prairie et al. (2026b) find that Parcae models from 770M (about our 340M) can require a brief post-training phase to share KV losslessly, stochastic depth alone suffices across all scales studied here, and our serving analysis in §6 assumes that lossless last-round KV caching is maintained at production scale. 

5.5 Extended Training Horizon and Downstream Generalization 

Finally, Table 2 evaluates whether the upstream BPB advan-tages of looping the CED encoder translate into downstream task accuracy over an extended 29.6B-token training horizon (∼200 tokens per non-embedding parameter). Looping the CED encoder substantially boosts downstream performance over the unlooped CED baseline, improving DCLM CORE by +2.54 points (95% paired bootstrap CI [+1.4, +3.6]) and CORE-Extended by +1.22 points. Notably, while absolute scores across studies reflect differences in tokenizer and data ordering, the magnitude of our encoder loop’s downstream gain matches that reported by Prairie et al. (2026a) for 370M looped dense models at the identical token budget (+2.54 points on CORE and +1.04 on CORE-Extended). Compared against our own looped dense reference—which caches 6×

as much global KV—the CED encoder loop leads on val-idation BPB (0.8124 vs. 0.8178) and remains statistically indistinguishable on CORE under paired item-bootstrap test-ing ( −1.0 points, 95% CI [ −2.0, +0.0]). Moreover, across our standard-budget width sweep against the stronger L2–5 dense loop, the modest downstream gap at 90M and 150M shrinks with model width and becomes statistically indistin-guishable from zero at 340M. Comparing the two CED loop placements on CORE fur-ther underscores the role of scale and context length. At standard token budgets, the decoder loop significantly trails the encoder loop across every model size, with its deficit widening to −3.4 points (95% CI [ −4.5, −2.4]) at 340M. While extending training to 29.6B tokens allows the 150M decoder loop to narrow this gap on CORE (21.56 vs. 21.63), this convergence is confined to short-prompt zero/few-shot items that largely fit within or near the 128-token local SWA window—leaving the decoder loop’s large deficits in valida-tion BPB (0.8295 vs. 0.8124), long-document scaling (§5.3), and long-range in-context recall (Appendix H) unchanged.

Eliminating the KV capacity wall in single-turn and long-context serving. In a large MoE model, high serving throughput requires batching many concurrent requests to amortize expert weight streaming across tokens. As shown in Figure 4(a,b) and Table 4, the baseline with per-layer and per-round KV quickly exhausts HBM on standard 8K/1K prompts and cannot fit even a single 128K-context request at T = 8 (OOM ). Sharing KV across layers (CED with per-round KV) raises this concurrency ceiling, but per-round KV growth still caps the decode batch size. Adding cross-round KV sharing (Looped CED) makes the KV footprint invariant to recurrence depth, raising peak preemption-free through-put on 8K/1K to 3.1×–3.6× that of the baseline ( 5.0× on ShareGPT), boosting HBM-saturated decode throughput by up to 2.8× over per-round CED (Table 14), and scaling to 38 concurrent 128K requests ( 16 .5× higher throughput than the baseline at T = 4 ). Only a small fraction of this gain comes from compute: at low concurrency where no KV pool is full, the baseline is only ∼ 14% slower (since its prefill runs all layers on every prompt token and every layer keeps its own KV cache and indexer); the rest comes from KV capacity. At matched per-user interactivity tar-gets, the throughput advantage is much larger than this raw compute gap because the faster model reaches a given per-user speed at higher concurrency (Figure 5a,b). # 7 RELATED WORK 

Recurrent-depth models and cross-round KV sharing. 

Building on early weight-tied and equilibrium networks (De-hghani et al., 2019; Lan et al., 2020; Bai et al., 2019), mod-ern prelude–core–coda language models and their routed or adapted variants scale reasoning and sample efficiency via recurrent depth (Saunshi et al., 2025; Geiping et al., 2025; Prairie et al., 2026a; Zhu et al., 2025; Schwethelm et al., 2026a; Csord´ as et al., 2024; Bae et al., 2025a;b). To avoid linear KV growth across rounds, prior work either bounds and compresses cross-round caches (Geiping et al., 2025; Bae et al., 2025b; Wu et al., 2025; Conchello Vendrell et al., 2026; O’Neill & Reid, 2026) or reuses only the last round’s KV—which collapses fixed-depth models (O’Neill & Reid, 2026; Schwethelm et al., 2026b; Huang et al., 2026b) but is lossless when stochastic-depth training induces a contrac-tive fixed point (Prairie et al., 2026a; Huang et al., 2026b; Prairie et al., 2026b). We extend it to asymmetric SWA and global-KV stacks. 

Asymmetric KV topologies and loop placement. Be-yond head sharing, latent compression, and local win-dows (Shazeer, 2019; Ainslie et al., 2023; DeepSeek-AI, 2024; Zadouri et al., 2025; Beltagy et al., 2020; Xiao et al., 2024), cross-layer KV sharing and hierarchical sparse at-tention restrict global KV generation to a few or single layers (Brandon et al., 2024; Sun et al., 2024; Hu et al., 2025; Leng et al., 2026), culminating in CED’s split be-tween sparse encoder global-KV sources and a single pro-jected decoder KV (DeepSeek-AI, 2026). Whereas prior recurrent cross-layer designs loop downstream of a frozen prelude KV or only over local SWA layers under fixed depth (Capps, 2026; Sun et al., 2026), we show that preserv-ing long-context quality requires recomputing a global KV source inside a stochastically trained encoder loop.

Asym-Loop (Liang et al., 2026) loops a CED-style decoder over fixed per-layer encoder KV, but each decoder layer recom-putes a full-length local KV in every round, so its cache grows with the number of rounds unless that KV is shared. # 8 LIMITATIONS 

While our production serving benchmarks evaluate a fron-tier MoE architecture (DeepSeek-V4.1-Flash, with a 552B-parameter backbone), our controlled pretraining quality ab-lations are conducted on dense models up to 340M parame-ters within a 2048-token context. Pretraining a frontier-scale looped CED MoE end-to-end—potentially incorporating lightweight post-training alignment (Prairie et al., 2026b) to guarantee fixed-point convergence at extreme scale—and evaluating on broader long-context reasoning benchmarks remain important next steps. Our serving results measure cost, not quality: the looped DeepSeek-V4.1-Flash runs with dummy or original weights that were not trained to loop, so lossless last-round KV at this scale is assumed from our smaller models (§5.4). Per-round KV is emulated by capping the KV pool, and every run uses a single GB200 tray or H200 node rather than disaggregated or large expert-parallel deployments. Finally, because the encoder loop runs every round over the prompt, it costs more per request than a decoder loop on prompt-heavy workloads (Appendix B), and this premium grows with larger decode batches. 

# 9 CONCLUSION 

This work introduces Looped CED and establishes how to combine cross-layer KV consolidation (CED) with recurrent-depth computation (Looped Transformers) so that looping deeper does not inflate KV memory. First , resolving where to loop, we show that recurrence must be placed in the CED encoder so that each round actively refines a global KV source, matching looped dense Transformers in vali-dation BPB and long-document scaling while avoiding the long-range degradation of decoder or local-window loops. 

Second , resolving how to loop, we demonstrate that training with stochastic recurrence depth drives the recurrent encoder toward a contractive fixed point, enabling lossless cross-round KV sharing with zero additional KV memory over an unlooped model. Third , in production serving on 4×GB200 and 8 × H200 nodes with DeepSeek-V4.1-Flash, these dual savings shrink resident KV memory by 36 .8× over loops with per-layer and per-round KV ( 5.2× from cross-round sharing alone at T = 8 ), delivering 3.1×–16 .5× higher throughput across standard and 128K long-context work-loads while cutting multi-turn agent TTFT by 13 .6×–29 .7×Looping Deeper Without Growing the KV Cache 

against per-round KV.

# A CONCURRENT WORK 

The works below appeared on arXiv in September and Oc-tober 2026, while this paper was being finished. Section 7 contrasts the closest of them with Looped CED in brief; here we describe each in more detail. We have not compared against them experimentally. The fixed-point analyses of Huang et al. (2026b) and BeNice! (Prairie et al., 2026b), which we build on throughout, appeared in the same period. 

Looped encoder–decoders. AsymLoop (Liang et al., 2026) builds on the CED of DeepSeek-V4.1-Flash and loops the decoder. A causal encoder runs once and projects a global KV for each decoder layer, which stays fixed across rounds; each layer of a weight-tied decoder reads it together with a full-length local KV recomputed from the decoder’s state in every round. From 60M to 1B parameters it im-proves on looping the whole stack, but it is not compared with an encoder loop. AsymLoop does not discuss caching for decoding, but its decoder has a full-length KV of its own, recomputed every round, so its cache grows with the number of rounds unless that KV is shared across rounds. Our decoder, like that of DeepSeek-V4.1-Flash, keeps only sliding-window KV of its own: in our CED, a loop recom-putes global KV every round only if it sits in the encoder and contains a global-KV source. RLT (Zhang et al., 2026) also pairs a parallel causal encoder, whose output is pro-jected into a global KV that the decoder layers read, with a decoder that keeps sliding-window KV, but it recurs across tokens rather than across depth: each token’s decoder input merges the final decoder state of the previous token. It is evaluated on algorithmic tasks, and its decoder processes prompt tokens one after another. Our loops repeat layers within each token and keep prefill parallel across tokens. 

Sharing KV across rounds. LPT (Monea et al., 2026) pretrains looped models in which only the first round writes a full-length cache; later rounds read it together with a short window of their own KV. From 150M to 1B parameters this sharing improves quality over a looped model that caches every round. We share the last round’s KV instead. Both policies cache the looped layers’ KV once instead of once per round (LPT adds a short window per round), and both compose with the reduction across layers that CED provides. In a CED, however, the choice does not change prefill: the decoder’s global KV is projected from the encoder output of the final round, so an encoder loop runs every round on prompt tokens whichever round’s KV the later rounds read. The LSTM-style looped transformer of Kirsch (2026) shares one cache across its whole recurrent core: every core block reads the KV that the last core block writes in the final round, and a consistency loss late in training narrows the gap between parallel training and recursive decoding. In an ablation, a cache producer placed before the loop gives higher loss than this late producer at equal training tokens but lower loss at equal training compute; the author does not conclude that either placement is better in general. 

Compressing the caches of pretrained looped models. 

HLA (Chen et al., 2026) adds a compact cache to pretrained Ouro models while keeping their weights frozen: exact KV for a window of recent tokens, and one latent per older token that every loop reads directly. The cache per token shrinks by an order of magnitude. Like LLA (O’Neill & Reid, 2026), HLA finds that reusing the last loop’s KV in Ouro is unsafe for long generations, consistent with Ouro’s states not reaching a fixed point (Huang et al., 2026b). 

Shared global KV with local history. Xian (2026) stud-ies a non-looped decoder in which a lower stack produces one global KV that every upper layer reads, through one softmax, together with its own sliding-window KV, the same split as in a CED decoder. It proves that prefill can rebuild the complete local caches exactly while each upper layer processes only a suffix of the prompt that shrinks with depth. Our estimate of exact SWA replay in §6 already shrinks the replayed suffix pass by pass in this way; the proof also lets queries and feed-forward layers run on a suffix shorter than the one used for keys and values, which would lower that estimate slightly.

# C EVALUATION PROTOCOL 

Validation BPB. We tokenize the FineWeb-Edu valida-tion split into one token stream and cut it into consecutive samples of 2048 tokens, the training context; a sample may span document boundaries. Every model is scored on all Looping Deeper Without Growing the KV Cache 

2829 samples, about 5.8M tokens. BPB is the total negative log-likelihood of the predicted tokens in bits, divided by their total number of UTF-8 bytes, so it does not depend on the tokenizer. Looped models run 8 rounds. During training we evaluated only the first 512 samples (128 for the 29.6B-token runs; BPB train in Table 2); on the first 512 samples, every model’s BPB is within 0.001 of its value on all samples, and no ranking of models changes. 

Last-round KV. Last-round KV cannot be scored in one parallel pass, because a token’s last-round KV exists only after that token has run all its rounds. We therefore decode every sample token by token with teacher forcing, in fp32, as Prairie et al. (2026b) do for shared-KV perplexity. With per-round KV, the parallel pass gives the same result as token-by-token decoding, which we check in our tests. The deployment protocol of §5.4 instead prefills a prompt in one parallel pass and decodes only the answer. With last-round KV the prompt keeps only its tokens’ final-round KV, which every round of the answer reads; Figure 6 shows that this loses nothing at any prompt length. For the CED encoder loop we also decode all 2829 samples of the validation split and bootstrap the paired difference over samples: last-round minus per-round KV is −0.00018 [ −0.00021, −0.00015] at 90M, −0.00015 [ −0.00018, −0.00012] at 150M, 0.00000 [−0.00003, +0.00004] at 340M, and −0.00018 [ −0.00021,

# D FIXED -POINT ANALYSIS 

We run each loop for up to 32 rounds and track ρr, the relative change of the core state between rounds, as Prairie et al. (2026b) do. With random rounds, ρr shrinks by a factor of about 0.61 per round, from 13% at round 4 to 1.7% at the 8 rounds we deploy and 0.014% at round 32: the core contracts to a fixed point. Between rounds 7 and 8, layer 2’s global KV changes by only 3%, which is why every round can read the last round’s. From round 8 to 32, BPB stays within 0.0003 of its 8-round value, so running more rounds than trained is safe. The same holds after 29.6B tokens (ρ8 = 1 .8% ), for the decoder loop ( 0.62% ) and for the 45M CED ( 2.7% ). With a fixed number of rounds, ρr never falls below 30% after round 8, and layer 2’s KV changes by 31% per round. In-context recall. To test recall directly, we take the first 1,024 tokens of each PG19 test sample and of 512 arXiv documents from the Proof-Pile-2 test split (Azerbayev et al., 2024), and repeat them verbatim at positions 1,024–2,047. Each copied token lies 1,024 tokens after its source, far beyond the SWA window, so only global KV can retrieve it. Figure 10 shows BPB on the repeated half. Unlooped CED recalls worse than unlooped dense (+0.106 and +0.014); the encoder loop removes this deficit ( −0.160 and −0.084 against unlooped CED), whereas the decoder loop barely changes recall ( −0.014 and +0.005). The YOCO-U style loop, whose only global KV comes from layer 6, recalls worst of the looped models (+0.105 and +0.108 against the dense loop). The differences shrink with scale: at 340M, all five models lie between 0.357 and 0.388 BPB. The CED encoder loop recalls better than the dense loop at 90M and 150M ( −0.017 and −0.026 BPB), trails it by +0.006 [+0.005, +0.007] at 340M, and recalls better than the L4–7 dense loop of Table 2 after 29.6B tokens ( −0.012). Across the three sizes and both token budgets, it thus recalls within 0.03 BPB of the dense loop while caching one-sixth of its global KV.
