## 摘要
循环 Transformer 通过重复应用共享层来增加有效深度，提供了一种在不增加参数量的情况下扩展计算的方法。然而，全栈循环将上下文构建与迭代状态细化置于同一循环计算中，未显式区分二者的作用。我们提出非对称循环 Transformer（AsymLoop），将单遍上下文编码与循环状态细化分离。单遍因果编码器生成层特定的全局键值（KV）缓存，这些缓存在迭代过程中保持固定；而权重共享的循环解码器从其演化状态中生成局部 KV。在单一 softmax 下对两种来源进行联合注意力，使每次更新能够将持久上下文信息与当前中间状态相整合。在训练方面，我们对编码器和解码器采用重尾引导的逐层学习率方法。在 FineWeb-Edu 上跨四种模型规模（从 60M 到 1B）的实验表明，在有效深度和训练 token 预算匹配的情况下，AsymLoop 相比 Full Loop 始终具有更低的验证困惑度和更高的平均下游准确率。在 1B 规模下，AsymLoop 将七个常识推理基准上的平均零样本准确率从 49.58% 提升至 50.85%。进一步的实验将这些优势扩展到更长的训练预算、OLMo 风格的主干网络以及稀疏专家混合模型。这些结果支持将非对称上下文编码与状态细化作为循环语言模型的一种有效设计。

## Abstract
Looped Transformers increase effective depth by repeatedly applying shared layers, offering a way to scale computation without increasing parameter count. However, full-stack looping places context construction and iterative state refinement within the same recurrent computation, without explicitly distinguishing their roles. We introduce the Asymmetric Looped Transformer (AsymLoop), which separates single-pass context encoding from recurrent state refinement. A single-pass causal encoder produces layer-specific Global key-value (KV) caches that remain fixed across iterations, while a weight-tied recurrent decoder generates Local KV from its evolving state. Joint attention over both sources under a single softmax allows each update to integrate persistent contextual information with the current intermediate state. For training, we apply a heavy-tail-guided layerwise learning-rate method to the encoder and decoder. Experiments on FineWeb-Edu across four model scales, from 60M to 1B, show consistently lower validation perplexity and higher average downstream accuracy than Full Loop under matched effective depth and training token budgets. At 1B, AsymLoop improves average zero-shot accuracy across seven commonsense reasoning benchmarks from 49.58% to 50.85%. Further experiments extend these benefits to longer training budgets, an OLMo-style backbone, and sparse mixture-of-experts models. These results support asymmetric context encoding and state refinement as an effective design for recurrent language models.

# AsymLoop 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：循环 Transformer（Looped Transformer）通过反复应用共享层来增加"有效深度"，从而在不增加参数量的前提下扩展计算量；近期工作还表明循环深度可在测试时提供额外计算以提升推理能力。
- **核心问题**：主流做法"全栈循环"（Full Loop）把**上下文构建**与**迭代状态精炼**放在同一个递归计算中，没有显式区分两者角色。而已有分析表明，不同深度层承担不同计算职责（输入上下文化、特征精炼、预测形成），循环模型内部也存在多个前馈式处理阶段反复出现。
- **已有部分循环方案的不足**：只"选择循环哪些层"并不能决定非循环部分与循环部分**如何交换信息**。作者认为应依据二者的不同计算角色做更广义的**非对称设计**。
- **整体含义**：提出把"一次性上下文编码"与"权重共享的迭代状态细化"解耦，并用联合注意力连接，作为循环语言模型的一种新组织范式。

## 2. 方法论

### 2.1 总体架构
- 将 L 个物理层拆为 **E 个编码器层 + D 个解码器层**，实验中取 E = D = L/2。
- **编码器**：标准因果 Transformer 块（架构不变），只前向一次，输出上下文表示 H_E（N×d）。
- **解码器**：权重共享（weight-tied），跨 K 次迭代复用同一组 D 层参数；第 1 次迭代输入为 H_E，之后每次输入为上一轮解码器输出。
- 最终状态 Z_D^(K) 用于下一 token 预测，全流程端到端训练。

### 2.2 全局 KV（Global KV）与局部 KV（Local KV）
- 每个解码器层有**独立投影矩阵**，把 H_E 映射为该层专属的 Global K/V；这些缓存在一次前向的所有 K 次迭代中**保持固定**，充当"上下文锚点"。
- 每次迭代中，解码器层把当前（RMSNorm 后的）隐状态投影为 Query 与 Local K/V，因此 Local KV 随迭代演化。
- 注意力前对 Q 及两类 K 均施加 **QKNorm + RoPE**。

### 2.3 单 softmax 联合注意力
- 将 Global K 与 Local K 沿**键位置轴拼接**，Query 在同一个 softmax 内同时对两源分配注意力，并共用同一因果掩码（位置 i 只能看 j ≤ i）：
  - A = softmax( [Q·K_globᵀ | Q·K_locᵀ] / √d_h + [M | M] ) · [V_glob ; V_loc]
- 之后接标准输出投影、残差与 SwiGLU FFN。这样每次更新同时整合"持久上下文"与"当前中间状态"。

### 2.4 训练：谱系逐层学习率（ALRS）
- 采用 He et al. (2026) 的**重尾自正则（HT-SR）引导逐层学习率**：对每个权重矩阵取平方奇异值最大的那一半构成尾部 T_m，用幂律密度 p(λ) ∝ λ^(-α) 估计指数
  - α_m = 1 + |T_m| / Σ_{λ∈T_m} log(λ/λ_min)
- 按分配规则把指数映射为 [1, 5] 区间的学习率乘子：
  - η_target = η_base(u) · [1 + 4·(α_m − α_min)/(α_max − α_min)]
- 输入嵌入与输出头取上限乘子，归一化参数保持基础调度；前 20% 训练内每 100 步刷新一次分配（50 步线性过渡），之后固定乘子、基础余弦调度继续。
- 编码器参数每次前向只用一次，解码器参数被复用 K 次并累积梯度，这一差异正是允许二者学习率不同的动机；实测解码器 FFN 平均学习率约为编码器的 **1.5 倍**（属规则的自然结果而非人为设定）。

## 6. 主要结论与发现

- **一致优于基线**：四个规模上验证损失/困惑度均低于 Dense 与同有效深度的 Full Loop；135M 与 350M 上困惑度分别改善 **0.98** 与 **0.30**。
- **下游增益随规模增长**：相对 Full Loop 的平均准确率优势从 60M 的 **0.13** 个百分点增至 1B 的 **1.27** 个百分点；1B 零样本 49.58% → **50.85%**，五样本 50.05% → **51.45%**；350M 五样本平均超 Full Loop **2.15** 个百分点。
- **深度可扩展**：K 从 1 增到 5 困惑度持续下降（350M：12.20 → 11.92），且每个深度匹配点都优于对应基线。
- **Global KV 的作用随循环加深而增大**：CE 增益 0.022（K=1）→ 0.045（K=5），说明"固定上下文锚点"对多次迭代尤为重要；且优于把等量参数用于加宽 FFN，也优于加性注入编码器输出。
- **外推有效**：5× Chinchilla 预算下 350M 五样本 46.67% → **47.41%**；OLMo 主干困惑度相对降 **14.8%**；MoE 135M 困惑度降 **4.5%**；GSM8K SFT 后 11.75% vs Full Loop 10.24%（相对 Dense +31.43%）。
- **算力效率**：虽比原始 Full Loop 多 9.38%–15.23% 前向 FLOPs，但 K=1 的 AsymLoop 在 60M/135M/350M 上准确率高于 K=2 或 K=3 的 Full Loop 且训练 FLOPs 更少；在匹配每步 FLOPs 时仍优于加宽 Full Loop（135M：2.74947 vs 2.78983）。
- **优化侧观察**：ALRS 相比均匀 LR 降约 1 点困惑度，优于静态解码器学习率加成；ALRS 下权重归一化稳定秩普遍更低（谱能量更集中于主奇异方向）。

## 7. 优点

- **问题分解清晰且有依据**：把"角色分工"从直觉提升为可检验的架构原则（一次性编码 vs 迭代精炼），并用深度分析佐证。
- **架构简洁、代价可控**：编码器只跑一次，Global KV 每层仅一套投影，额外开销 9%–15%，却换来一致的性能提升，工程上易实现。
- **联合注意力设计优雅**：单一 softmax 内同时竞争 Global 与 Local 注意力，无需额外的门控或融合模块，且天然兼容因果掩码与 RoPE/QKNorm。
- **实验控制严谨**：有效深度匹配、token 匹配、参数匹配、解析 + 实测 FLOPs 双匹配、多种子验证，明显强于多数同类循环模型论文。
- **泛化验证多样**：OLMo 主干、MoE、长预算、SFT 四条外推线，说明结论不局限于单一配置。
- **机制性分析到位**：Global KV 增益随 K 单调上升、ALRS 的编解码学习率比与谱结构变化，提供了"为什么有效"的线索。

## 8. 局限与可质疑之处

- **架构增益与优化增益的耦合未完全解耦**：AsymLoop 主结果均使用 ALRS，虽然作者在 Full Loop 上对比了 ALRS 与均匀 LR，但未在全部规模上给出"AsymLoop + 均匀 LR"的完整曲线，因此"结构贡献"与"学习率分配贡献"的相对权重仍不够透明。
- **单种子主实验**：1B 与 350M 的主表基本依赖 seed 6198，仅在 135M 上做了三种子验证；对于 0.1–1 个百分点量级的下游差异（如 60M 的 0.13），缺乏方差信息会使显著性判断偏弱。
- **超参未做敏感性扫描**：E:D 的 1:1 划分、K 的取值、Global KV 的投影维度等关键设计点均固定，未给出"若改为 1:2 或 2:1 会怎样"的证据，读者难以判断该方法对分层比例是否鲁棒。
- **数据与任务域单一**：预训练仅 FineWeb-Edu（英文教育网页），下游以常识推理为主，SFT 仅 GSM8K 一项；对多语言、代码、长上下文等场景的适用性未知。
- **理论解释偏经验性**：对"为何 Global KV 随 K 增益上升"给出的是注意力锚点直觉与 CE 数值，未提供如梯度流、表示相似度或有效秩随迭代演化的定量分析（ALRS 部分有谱分析，但架构部分较弱）。
- **FLOPs 与墙钟的差距**：论文以矩阵 FLOPs 为主要效率口径，虽在 8×H100 上做了实测校验，但未系统报告吞吐（tokens/s）、通信开销与显存峰值随 K 的变化，实际部署收益可能小于 FLOPs 数字所示。
- **与同期循环/深度递归工作的横向比较有限**：对比基线集中在 Dense、Full Loop 及其加宽/参数匹配变体，未与 Huginn、Geiping 式循环、或其他"部分层循环"方案直接同表比较。

## 9. 启示与可借鉴点

- **"角色分离"是可复用的设计语言**：把网络拆成"一次性上下文化"与"共享权重的迭代精炼"两部分，这一思路可迁移到扩散式语言模型、检索增强模型（外部上下文天然适合做 Global KV）以及多模态融合（图像编码一次、文本迭代解码）。
- **Global/Local 双源单 softmax 注意力**是一种低成本的"持久记忆 + 工作记忆"实现：无需额外门控模块，天然兼容因果掩码、RoPE 与 QKNorm，工程落地门槛低。
- **按参数复用次数分配学习率**（ALRS）是一条独立于架构的优化经验：被复用 K 次的解码器参数获得更高学习率，且该比值由谱指数规则自动涌现（约 1.5×）而非手工设定，这一"由结构推导超参"的范式值得在权重共享类模型中推广。
- **实验设计的严谨性值得学习**：有效深度匹配 + token 匹配 + 参数匹配 + 解析与实测 FLOPs 双匹配，并刻意让基线在 FLOPs 上"略微占优"，是回应"不公平比较"质疑的范式做法。
- **机制验证优先于总体指标**：专门做"Global KV 增益随 K 单调上升"与"上下文访问方式四选一"的对照，把"为什么有效"从叙事变成可测命题。

## 10. 总体评价

该论文针对循环 Transformer 中"上下文构建与迭代精炼被混在同一递归过程"这一被忽视的结构问题，提出了一个简洁、代价可控且易于实现的非对称方案：编码器一次性编码、解码器权重共享迭代、二者通过单 softmax 联合注意力以 Global/Local 双源 KV 连接，并配套一个由谱指数自动推导的逐层学习率规则。实验在 60M–1B 四个规模、三种循环深度、多种消融与四条外推线（长预算、跨主干、MoE、SFT）上给出了一致的正向结果，控制变量（有效深度、token、参数、FLOPs）做得比同类工作更严格，机制性分析也提供了初步的"为什么有效"证据。

主要不足在于：架构与优化两项贡献未完全解耦、主实验单种子、关键超参（E:D 比例）缺少敏感性分析、数据与任务域偏窄，以及效率评估以 FLOPs 为主而缺少吞吐/显存系统报告。总体而言，这是一篇**问题定位清晰、设计优雅、实验扎实度高于同类平均水平**的工作，其"角色分离 + 双源注意力 + 按复用次数分配学习率"的三件套具有较强的可迁移性；若后续补齐多种子方差、分层比例消融与更广域的验证，结论的说服力会进一步增强。
