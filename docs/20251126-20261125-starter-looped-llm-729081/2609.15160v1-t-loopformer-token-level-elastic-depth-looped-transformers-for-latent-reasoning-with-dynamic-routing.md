## 摘要
循环 Transformer 最近通过在多次迭代中复用一组共享参数，在推理和语言任务中均展现出强劲性能，在实现参数效率的同时不牺牲表示能力。此外，循环 Transformer 直接在潜在空间中进行推理（潜在推理），以减少推理过程中消耗的 token 数量，从而获得更好的样本效率。然而，这些模型通常对每个 token 统一施加固定的递归深度，导致计算分配次优，并错失显著的效率提升空间。在本工作中，我们为循环 Transformer 提出动态 token 选择路由，使每个 token 能够根据其隐藏状态自适应地确定自身的循环迭代次数。我们使用动态路由器决定一个 token 应继续递归还是提前退出，使简单 token 绕过不必要的计算，而困难 token 获得更深层处理。为确保这种自适应机制不会损害解码效率，我们进一步引入按递归划分的 KV 缓存，为每个递归循环维护独立的键值缓存。该设计确保不同深度的 token 仅关注其对应的缓存状态，有效消除已退出 token 的冗余计算，并实现快速自回归解码。大量实验表明，T-LoopFormer 在相同参数下，在 PPL 和 10 个零样本推理任务上达到 SOTA 性能，甚至超越了使用 24 倍 FLOPs 的基础模型，并且我们的模型能够达到最低的推理延迟，这验证了 token 选择路由器和按递归 KV 缓存的有效性。代码：https://github.com/YuMingQian1234/T-LoopFormer。

## Abstract
Looped Transformers have recently demonstrated strong performance in both reasoning and language tasks by reusing a shared set of parameters across multiple iterations, achieving parameter efficiency without sacrificing representational power. Besides, looped Transformers perform inference directly in the latent space (latent reasoning) to reduce the number of tokens consumed during inference, thereby achieving improved sample efficiency. However, these models typically apply a fixed recursion depth uniformly to every token, leading to suboptimal compute allocation and leaving significant efficiency gains on the table. In this work, we propose \textbf{dynamic token-choice routing} for looped transformers, enabling each token to adaptively determine its own number of loop iterations based on its hidden state. We use a dynamic router to decide whether a token should continue recursing or exit early, allowing simple tokens to bypass unnecessary computation while hard tokens receive deeper processing. To ensure that this adaptive mechanism does not compromise decoding efficiency, we further introduce recursion-wise KV caching, which maintains an independent key-value cache for each recursion loop. This design ensures that tokens at different depths only attend to their corresponding cached states, effectively eliminating redundant computations for exited tokens and enabling fast autoregressive decoding. Extensive experiments show that T-LoopFormer reaches the sota performance under the same parameters on PPL and 10 zero-shot reasoning tasks, even surpassing the base model at 24x FLOPs and our model could reach the lowest inference latency, which validate the effectiveness of token-choice router and recursion-wise KV cache. ## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：循环 Transformer（looped / recurrent Transformer）通过多次迭代复用同一组共享参数，在参数效率与有效深度之间取得平衡，近期在语言建模与算法推理任务上表现突出。同时，这类模型在推理时直接在**潜在空间**中进行推理（latent reasoning），减少显式 CoT 所消耗的 token 数，从而提升样本效率。
- **核心问题**：现有循环 Transformer（包括 TMLT、LoopFormer 等弹性深度方法）在训练与推理时对**所有 token 施加统一的固定递归深度**。这种"一刀切"策略忽视 token 之间的难度差异：
  - 简单 token 被迫进行与困难 token 相同的计算，造成算力与内存浪费；
  - 序列级潜在推理导致推理吞吐下降、响应延迟升高；
  - 现有方法缺乏**token 级**的弹性深度控制。
- **整体含义**：作者希望将"弹性深度"从序列级下推到 **token 级**，让每个 token 根据自身隐藏状态自适应决定循环次数，并配套设计高效的缓存与压缩机制，从而在保持参数效率的同时实现更优的算力分配与更低的解码延迟。

## 2. 方法论

### 2.1 整体架构

- 基于 **LoopFormer** 的 decoder-only 循环 Transformer：共享的 $J$ 层 Transformer 堆栈 $\Phi_J(\cdot)$ 被迭代 $L$ 次；位置编码一次性加入。
- 采用**长-短轨迹对齐**训练：用户指定训练循环数 $L$ 与步长调度 $\Delta_L$，满足 $\sum_{i=1}^{L}\Delta_i=1$；每个循环 $i$ 以累计时间 $c_{i-1}$ 与步长 $\Delta_i$ 为条件。
- 条件信号经正弦-余弦频率嵌入 + 小型 MLP 得到 $e_i = e_c + e_\Delta$，再通过 AdaLN 式调制映射为两个 RMSNorm 的缩放 $(\gamma_1,\gamma_2)$ 与残差门控 $(\alpha_1,\alpha_2)$。

### 2.2 训练目标

$$\mathcal{L} = \mathcal{L}_L + \lambda_1 \mathcal{L}_S + \lambda_2 \mathcal{L}_{\text{align}}$$

- $\mathcal{L}_L$：最长轨迹（$L$ 次）的下一 token 预测损失；
- $\mathcal{L}_S$：每个 batch 采样 shortcut 长度 $S \sim U\{1,\dots,L-1\}$ 及其步长调度后的损失；
- $\mathcal{L}_{\text{align}}$：长-短轨迹对齐损失；实验中 $\lambda_1=\lambda_2=0.1$。

### 2.3 动态 Token 选择路由（核心创新）

- 使用**两层 MLP** 作为轻量路由器 $f_\theta:\mathbb{R}^d\to\mathbb{R}^M$，输入为 token 的**初始隐藏状态** $h^{(0)}_\tau$，输出递归深度分布：
  $$\pi_\tau = \text{softmax}(f_\theta(h^{(0)}_\tau)) \in \mathbb{R}^M$$
- 计算累计概率 $p^{(i)}_\tau = \sum_{\ell=i}^{M}\pi_{\tau,\ell}$，token 在第 $i$ 个循环保持活跃当且仅当 $p^{(i)}_\tau > 0.5$（默认阈值 0.5）。
- 因 $p^{(i)}_\tau$ 随 $i$ 单调不增，活跃集天然嵌套：$\mathcal{A}_1 \supseteq \mathcal{A}_2 \supseteq \cdots \supseteq \mathcal{A}_M$，且 $\mathcal{A}_1$ 为全序列。
- 每个 token 的自适应深度：$m_\tau = \max\{i: \tau\in\mathcal{A}_i\}$；token 一旦退出即永久停用，其隐藏状态保留最后一次循环结果并直接送入 LM Head。

### 2.4 Gather–Scatter 训练加速

- 每轮循环只对活跃 token 做紧凑化：$\tilde{H}^{(i)} = \text{Gather}(H^{(i-1)}, \mathcal{A}_i)$，共享块只在 $\tilde{H}^{(i)}$ 上运算，计算量正比于存活 token 数而非序列长度。
- 更新后按索引散射回原位置：
  $$H^{(i)}_\tau = \begin{cases}\text{Block}(\tilde{H}^{(i)})_{\sigma_i(\tau)} + H^{(i-1)}_\tau, & \tau\in\mathcal{A}_i\\ H^{(i-1)}_\tau, & \tau\notin\mathcal{A}_i\end{cases}$$
- 散射保留原始坐标，确保下一轮可重新 gather 不同的活跃集、损失对齐正确、梯度可回传。

### 2.5 按递归划分的 KV 缓存（Recursion-wise KV Cache）

- 为每个 token 分配 $M$ 个独立 KV 缓存（对应 $M$ 个循环），只保留活跃 token 的 KV：
  $$K^{(i,j)}_{<t} = \{k^{(i,j)}_\tau\}_{\tau<t,\,m_\tau\ge i},\quad V^{(i,j)}_{<t} = \{v^{(i,j)}_\tau\}_{\tau<t,\,m_\tau\ge i}$$
- 注意力只查询同一循环 $i$ 的缓存，并用有效性掩码 $\mu^{(i)}_\tau = \mathbb{1}[m_\tau \ge i]$ 排除已退出 token 的零槽位。
- 推理时 gather 索引排序保持因果顺序，并用原始位置映射 $\rho^{(i)}=\text{sort}(\mathcal{A}_i)$ 将新 K/V 写回原序列位置。
- 单 token 解码时退化为"早退出"：token 一旦离开活跃集，递归立即终止，缓存更新退化为尾部拼接。

- **效率**：
  - TPOT 最低（**0.197 ms/token**），甚至低于非循环 Base（0.202），比 LoopFormer（0.441）快约 **2.24×**；
