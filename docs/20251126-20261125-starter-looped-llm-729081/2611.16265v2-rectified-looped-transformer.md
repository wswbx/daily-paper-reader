## 摘要
循环 Transformer 通过重复应用共享块来增加有效深度，为语言建模提供了一种参数高效的方法。然而，现有大多数工作直接将每个循环的输出作为下一个循环的输入复用，这可能在循环加深时导致隐藏状态尺度增长和扰动放大。我们提出校正循环 Transformer（RLT），它使用受基于流的建模启发的插值调度来重新设计循环之间的反馈。在每个循环中，RLT 通过在当前状态与其预测之间进行线性插值来形成下一个输入。这种插值将状态变化分布到各个循环中，促使从初始输入到最终输出的轨迹更加平滑。理论分析证明，在适当假设下，RLT 能使状态幅度在各循环间保持一致有界，并降低最坏情况下的扰动放大。我们在语言建模语料库和下游基准上评估 RLT。在训练和推理深度匹配时，RLT 始终比标准循环 Transformer 获得更低的困惑度，同时对输入扰动和推理深度变化表现出更强的鲁棒性。与理论结果一致，潜在轨迹分析表明 RLT 在各循环间保持更稳定的隐藏状态范数，这也促进了基于外推的解码策略。值得注意的是，RLT 无需额外的可训练参数或额外的循环块评估即可实现这些增益，从而为循环 Transformer 提供了一种简单却更稳定的反馈机制。

## Abstract
Looped Transformers increase effective depth by repeatedly applying a shared block, offering a parameter-efficient approach to language modeling. However, most existing works directly reuse each loop's output as the next's input, which can lead to hidden-state scale growth and perturbation amplification as recurrence deepens. We propose Rectified Looped Transformer (RLT), which redesigns feedback between loops using an interpolation schedule inspired by flow-based modeling. At each loop, RLT forms the next input by linearly interpolating between the current state and its prediction. Such interpolation distributes state changes across loops, encouraging a smoother trajectory from the initial input to the final output. Theoretical analysis proves that, under appropriate assumptions, RLT keeps state magnitudes uniformly bounded across loops and reduces the worst-case perturbation amplification. We evaluate RLT on language modeling corpora and downstream benchmarks. At matched training and inference depths, RLT consistently achieves lower perplexity than a standard looped Transformer, while exhibiting greater robustness to input perturbations and variance in inference depth. Consistent with the theoretical results, latent trajectory analysis shows that RLT maintains more stable hidden-state norms across loops, which also facilitates extrapolation-based decoding strategies. Notably, RLT achieves these gains without requiring additional trainable parameters or extra recurrent block evaluations, thus providing a simple yet more stable feedback mechanism for looped Transformers.

### 1. 核心问题与整体含义

- **研究背景**：循环 Transformer（Looped Transformer）通过反复应用同一组共享层来增加“有效深度”，在不增加物理参数量的情况下提升语言模型能力，是参数高效扩展的一条重要路线。
- **核心问题**：现有循环语言模型多采用“直接反馈”（Standard Looped Transformer, SLT），即把上一循环的网络输出直接作为下一循环输入。随着循环加深，这种更新方式可能造成隐状态尺度增长、扰动放大，并对推理循环数高度敏感。
- **整体含义**：论文把“循环间状态反馈方式”视为循环 Transformer 的关键设计维度，提出用受 rectified flow 启发的线性插值来重新组织反馈，从而在不增加可训练参数、不增加循环块前向计算的情况下，改善语言建模性能与循环稳定性。

### 2. 方法论：Rectified Looped Transformer（RLT）

- **核心思想**：将每次循环的网络输出视为“终点预测”，不直接用其完全替换当前状态，而是在当前输入状态与预测端点之间做线性插值，把剩余位移按剩余循环数分摊到后续循环。
- **基本循环形式**：
  - 共享块输出：\(h_{k+1}=F_\theta(x_k,t_k)\)；
  - 反馈更新：\(x_{k+1}=(1-\eta_k)x_k+\eta_k h_{k+1}\)，其中 \(0\le\eta_k\le1\)；
  - SLT 取 \(\eta_k=1\)，即直接反馈；
  - RLT 取 \(\eta_k=\frac{\Delta t}{1-t_k}=\frac{1}{K-k}\)，其中 \(K\) 为总循环数，\(t_k=k/K\)，\(\Delta t=1/K\)。
- **调度特征**：反馈权重从 \(\eta_0=1/K\) 逐步增至 \(\eta_{K-1}=1\)，形成从初始状态到最终预测的平滑插值轨迹；每个循环重新估计端点，并把剩余位移分摊到剩余步骤。
- **训练与推理**：共享 Transformer 堆叠通过 AdaLN 风格接收时间步与步长条件；每个循环输出都通过共享 readout 计算交叉熵，采用 uniform all-step supervision；推理使用最终隐藏输出 \(h_K\) 解码。
- **理论分析**：
  - 在残差满足 \(\|F_\theta(x,t)-x\|\le M(1-t)^\alpha\) 等假设下，证明 RLT 的输入状态与隐藏输出范数随循环深度一致有界；
  - 对 SLT，状态范数上界可随 \(K\) 增长；对 RLT，上界与 \(K\) 无关；
  - 在 Lipschitz 条件下，SLT 的初始扰动最坏放大上界为指数级 \(L^K\)，RLT 降为多项式级 \(K^{L-1}\)；
  - 在非扩张网络与固定点存在条件下，RLT 对应 Krasnosel’skii–Mann 型迭代，固定点残差随 \(K\) 衰减。

### 6. 主要结论与发现

- **语言建模**：在匹配训练与推理深度时，RLT 在三个语料、三个深度上均取得更低困惑度。例如 \(K=4\) 时，Pile/FWE/OWT 的 PPL 分别降低约 4.2%、5.5%、5.2%。
- **下游表现**：整体平均准确率与 SLT 可比，部分深度和任务上有提升；但并非所有设置都优于 SLT，例如 \(K=8\) 时平均准确率略低，说明优势主要体现在困惑度和稳定性而非全面下游提升。
- **循环稳定性**：SLT 的隐藏状态尺度随循环明显累积；第 8 次循环相对第一层输出的平均 RMS 比约为 5.08，而 RLT 为 0.65，符合理论上有界性分析。
- **扰动鲁棒性**：RLT 对初始输入扰动和循环内扰动均更稳健；例如输出扰动 \(\rho=0.5\) 时，Pile 交叉熵增加为 0.61 nats/token（RLT）对 2.86（SLT）。
- **推理深度鲁棒性**：少循环时 RLT 明显优于 SLT；\(K_{\text{test}}=2\) 时 PPL 降低约 35.9%/48.2%/47.1%，平均下游准确率从 39.24% 提升到 40.76%。多循环时 SLT 性能快速退化，而 RLT 更平稳；\(K_{\text{test}}=32\) 时 PPL 为 17.72 对 57.72，平均准确率为 42.88% 对 38.05%。
- **量化与解码**：RLT 在 W8A16/W4A16/W8A8 下保持困惑度优势；更稳定的表示尺度也有利于对比解码和循环内 guidance。
- **潜空间轨迹**：PCA 显示 RLT 在不同推理预算下更集中于匹配深度端点，SLT 则少循环“达不到”、多循环“漂移过头”。

### 7. 优点

- **方法极简**：仅用逐元素线性插值改变反馈，不增加可训练参数，也不增加循环块前向次数，易于集成到现有循环 Transformer。
- **理论支撑清晰**：给出状态范数有界、扰动放大从指数级降到多项式级、固定点残差衰减等分析，与实验中的尺度稳定现象相互印证。
- **实验维度丰富**：覆盖匹配深度、少/多循环外推、输入与循环扰动、量化、对比解码、guidance 和 PCA 轨迹分析，诊断性较强。
- **对照设置较公平**：SLT 与 RLT 共享架构、权重初始化、数据顺序和训练预算，便于归因于反馈规则本身。
- **实际意义明确**：对循环语言模型的推理深度弹性、数值稳定性和量化部署均有潜在价值。

### 8. 不足与局限

- **模型规模有限**：主实验为 278M 参数、6.88B tokens，未验证更大模型、更长训练或万亿 token 预训练下的可扩展性。
- **基线覆盖不足**：主要与 SLT 对比，缺少与 ELR、TAPS、Fixed-Point Reasoners 等已有反馈控制/阻尼方法的直接比较。

- 径向条件、非扩张性、固定点存在性等假设在实际 Transformer 中难以先验保证；理论结果更多是对“反馈规则为何更稳定”的解释性刻画，尚未给出端到端训练收敛性、泛化误差或下游性能的理论保证。

- **调度依赖总循环数**：\(\eta_k=1/(K-k)\) 需要知道总预算 \(K\)，训练与推理预算变化时需相应调整时间条件；虽然外推实验显示较好多循环鲁棒性，但并非对任意 \(K\) 都无需重新校准。
- **量化结论为模拟结果**：W8A16/W4A16/W8A8 实验基于模拟量化，尚未验证真实硬件内核、实际延迟、吞吐和端到端部署收益。
- **任务覆盖偏向语言建模与常识/阅读理解**：缺少数学推理、代码、长上下文检索、多语言等场景；对循环深度真正有用的复杂推理任务验证不足。
- **机制分析仍以现象为主**：RMS 尺度、PCA 轨迹和扰动实验支持稳定性解释，但未深入拆解各循环学到了什么、端点预测误差如何传播，以及 RLT 与固定点迭代之间的更细粒度对应关系。

### 9. 总体评价与可借鉴点

总体而言，论文抓住了一个简洁而关键的设计变量：循环 Transformer 不应把每次循环输出直接当作下一状态，而应在“当前状态—预测端点”之间按剩余预算做插值。RLT 以极低的方法复杂度换取了更稳定的状态尺度、更强的扰动鲁棒性和更好的推理深度弹性，理论分析与诊断实验之间形成了较好的闭环。其最大价值在于提示循环语言模型的设计不仅要关注“循环多少次”，还要关注“循环间如何反馈”。

但当前证据仍属于中等规模验证：278M 参数、约 6.88B tokens、主要对照 SLT、缺少多种子统计和真实量化部署。若要将 RLT 作为通用循环语言模型组件，后续需要补充更大规模与更长训练、多随机种子、与 ELR/TAPS/Fixed-Point Reasoners 等反馈控制方法的直接比较，以及在数学、代码和长上下文任务上的验证。同时，应进一步分析训练开销、推理预算自适应调度和真实硬件量化收益。综合来看，这是一项方法简单、分析扎实、实验诊断丰富但规模与基线覆盖仍可扩展的工作，适合作为循环 Transformer 稳定性与推理深度弹性研究的重要基线。
