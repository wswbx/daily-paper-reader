## 摘要
LLM 架构研究通常旨在在固定计算/延迟预算下最大化模型质量。然而，许多感兴趣的应用（如边缘与端侧部署）还进一步受到模型内存占用的约束，因此推动了面向语言建模的参数高效架构。本文描述了一种简单架构，可提升 LLM 的参数效率。我们的架构以循环 Transformer 作为核心原语，其在深度方向复用 Transformer 层，因此比普通（深度匹配的）Transformer 更具参数效率。我们将循环 Transformer 组织为三个块——起始块、中间块和结束块——其中每个块本身由多个 Transformer 层组成，并且仅中间块在深度方向被循环应用。我们使用超连接（hyper-connections，Xie 等，2026）增强循环中间块，其将残差流扩展为矩阵值残差流。超连接仅在每次循环之后应用，因此只增加极少的参数和计算成本。在不同模型规模下，我们发现，与深度匹配的 Transformer 和 mHC Transformer 基线相比，我们的超连接循环 Transformer（Hyperloop Transformer）尽管使用的参数约少 50%，仍能表现良好。这一性能在训练后权重量化后仍得以保持，从而使 Hyperloop Transformer 成为面向内存高效语言建模的有吸引力架构。

## Abstract
LLM architecture research generally aims to maximize model quality subject to fixed compute/latency budgets. However, many applications of interest such as edge and on-device deployment are further constrained by the model's memory footprint, thus motivating parameter-efficient architectures for language modeling. This paper describes a simple architecture that improves the parameter-efficiency of LLMs. Our architecture makes use of looped Transformers as a core primitive, which reuse Transformer layers across depth and are thus more parameter-efficient than ordinary (depth-matched) Transformers. We organize the looped Transformer into three blocks--begin, middle, and end blocks--where each block itself consists of multiple Transformer layers, and only the middle block is applied recurrently across depth. We augment the looped middle block with hyper-connections (Xie et al., 2026), which expand the residual stream into matrix-valued residual streams. Hyper-connections are applied only after each loop, and therefore add minimal new parameters and compute cost. Across various model scales, we find that our Hyper-Connected Looped Transformer (Hyperloop Transformer) is able to perform well compared to depth-matched Transformer and mHC Transformer baselines despite using approximately 50% fewer parameters. This performance persists through post-training weight quantization, thus positioning Hyperloop Transformers as an attractive architecture for memory-efficient language modeling.

## 2. 方法论：Hyperloop Transformer

- **核心思想**：采用“middle-cycle”循环策略，将 Transformer 分为 begin、middle、end 三个块，仅 middle 块跨深度循环；在循环层级引入 hyper-connections，将残差流扩展为矩阵值多流残差，从而提升循环模型的表达灵活性与参数效率。
- **整体流程**：
  - 输入经过 begin block 得到 \(X_{\text{begin}}\in\mathbb{R}^{T\times C}\)。
  - 将其复制 \(n\) 份，得到 \(Y^{(0)}\in\mathbb{R}^{T\times n\times C}\)，作为并行残差流。
  - 对 middle block 进行 \(L\) 次循环；每次循环前后通过输入相关的 \(H^{\text{pre}}\)、\(H^{\text{post}}\) 读写 C 维子层输入/输出，并通过 \(H^{\text{res}}\) 在并行流之间混合。
  - 循环结束后，将 \(Y^{(L)}\) 在 \(n\) 个流上平均，得到 \(X_{\text{end}}\in\mathbb{R}^{T\times C}\)，送入 end block。
- **关键公式**：循环递推为  
  \[
  y_t^{(l+1)}=H^{\text{res}}_{l,t}y_t^{(l)}
  +H^{\text{post}}_{l,t}\left(F(H^{\text{pre}}_{l,t}y_t^{(l)})+e_l\right)
  \]
  其中 \(F\) 为 middle block，\(e_l\) 为 loop position embedding。
- **与原始 mHC 的差异**：
  - **简化 \(H^{\text{res}}\)**：不使用 Sinkhorn 归一化的稠密双随机矩阵，而采用对角矩阵  
    \[
    H^{\text{res}}_{l,t}=\operatorname{diag}\left(\sigma(\alpha^{\text{res}}_l(W^{\text{res}}_l z_t^{(l)})+b^{\text{res}}_l)\right)
    \]
    参数与计算更少，文中称性能足够甚至更好。
  - **加入 loop position embedding**：将架构视为以矩阵隐藏状态为状态的“深度方向 RNN”，每次循环有输入信号。
  - **仅在循环层级应用 hyper-connections**：每个 loop 后应用一次，而非每个 attention/MLP 子层后应用，因此额外参数与计算极小。
- **参数灵活性**：不同循环迭代可有各自的 \(W^\tau_l,b^\tau_l,\alpha^\tau_l,e_l\)，使循环块在每次迭代中略有变化；相比严格参数共享的普通循环 Transformer 更灵活，但新增参数很少。

## 6. 主要结论与发现

- Hyperloop Transformer 在三个规模上均优于深度匹配 vanilla Transformer、mHC 和普通 Looped Transformer 的困惑度，且参数约少 50%；下游任务平均准确率也总体最高。
- 普通 Looped Transformer 困惑度常落后于非循环基线，但在部分下游任务上可超过 vanilla，复现了文献中“循环模型任务表现较好但 PPL 较弱”的现象。
- Hyperloop 仅比普通 Looped 多约 150–300K 参数，却能显著改善 PPL 和任务表现。
- INT4 GPTQ 量化后，普通循环模型对量化更敏感；hyper-connections 可缓解退化，Hyperloop 在 weight-only 量化下仍保持优势。
- 训练吞吐：Hyperloop 与 Transformer/Looped 接近，额外开销很小；朴素实现的 mHC 有明显减速。
- 消融显示：
  - 循环次数增加有递减收益，Hyperloop 始终优于 Looped；
  - 固定深度下缩小 middle 并增加循环可进一步提高参数效率，但有小幅性能损失；
  - 并行流数量 \(n\) 增大收益递减，\(n=4\) 已合理；
  - **每个 loop 后应用一次 HC 最佳**，并非越密越好；
  - 对角 \(H^{\text{res}}\) 优于 identity 和 Sinkhorn；
  - LoRA 允许跨循环参数变化有轻微帮助，但远不如 Hyperloop 参数高效。
- 分析表明 Hyperloop 跨循环的层表示相似度更低，说明 HC 使循环层表示更灵活；logit lens 显示循环模型更贴近词汇空间，Hyperloop 更强，可能有利于 early-exit 推理。

## 7. 优点

- **方法简洁**：仅在 middle 循环块、循环层级加入轻量 hyper-connections，不改变 attention/MLP 主体，易于实现。
- **参数与计算开销极小**：loop-level HC + 对角 \(H^{\text{res}}\)，无需 Sinkhorn 和特殊 kernel，训练吞吐接近普通 Transformer。
- **参数效率显著**：在约 50% 参数下匹配/超过深度匹配基线，直接面向内存受限部署。
- **量化友好**：针对循环层修改 GPTQ Hessian 聚合方式，验证 INT4 后仍保持优势，实用性强。
- **实验较系统**：多规模、多基线、量化、过训练、结构消融、表示分析结合，结论有层次。
- **分析有启发性**：用 cosine similarity 和 logit lens 解释 HC 为何有效，并指出 early-exit 潜力。
