Abstract
A looped language model repeatedly applies the same block to its hidden state before predicting each token. The
number of passes is its recurrent depth. Increasing this depth gives the model more computation per token with the
same parameters. Can the shared block learn from the predictions it makes at greater depth? Following prior work, we
retrofit pretrained OLMo-2-1B with a shared recurrent block and continue mid-training over varying recurrent depths.
In the four-pass model, additional passes mainly redistribute probability among tokens that already rank highly after
one pass. We use the continuations generated at greater depth to train only the shared block through a single pass,
without reference answers or correctness filtering. We call this transfer preference write-back. Write-back further
improves one-pass and multi-pass accuracy on most tasks. At their target depths, the updated models outperform a
non-recurrent control matched for mid-training data and token budget on all six mathematical reasoning benchmarks,
with a mean relative gain in accuracy of up to 46.2% across tasks. At four-pass inference, one-pass training outperforms
full-depth training on the same targets in the model with input injection. This advantage disappears in the matched
model without injection. On GSM8K, using the updated block only on passes two through four recovers nearly the
entire four-pass gain, showing that an update learned in one pass can improve later applications of the same block.

Introduction
Looped Transformer language models scale inference-time computation by reapplying recurrent blocks before emitting
each token, decoupling computation depth from layer depth (Dehghani et al., 2019; Saunshi et al., 2025; Geiping
et al., 2025). This makes recurrent depth attractive both for serving—via parameter sharing, depth-wise batching, and
KV-cache reuse (Lan et al., 2020; Bae et al., 2025a,b; Geiping et al., 2025)—and for latent test-time computation,
where the model iterates in hidden-state space before emitting a token (Geiping et al., 2025; McLeish et al., 2026;
Koishekenov et al., 2025; Zhu et al., 2025). Empirically, such models can improve with additional recurrent depth and,
in some settings, rival language models several times larger (Saunshi et al., 2025; Geiping et al., 2025; Zhu et al., 2025).
These gains, however, do not follow from weight sharing alone. Although reapplying a shared block makes additional
depth available, the model must learn to use it across repeated passes. Recent work has therefore developed recurrent
architectures and depth-training strategies toward this goal (Geiping et al., 2025; McLeish et al., 2026; Koishekenov
et al., 2025). Building on these approaches, we retrofit a pretrained language model with recurrence and adapt it through
continued mid-training over varying execution depths. Yet developing a model that benefits from additional recurrence
leaves a further question: what do these additional passes actually change in its predictions?
Recurrent models can learn genuine iterative computation in controlled settings, including repeated algorithmic
operations and computing intermediate results in one recurrent pass that are used in subsequent passes (Schwarzschild
et al., 2021; Bansal et al., 2022; Saunshi et al., 2025; Jolicoeur-Martineau, 2025; Kohli et al., 2026; Huang et al.,
2026). But these results do not determine the role of additional passes in pretrained language models retrofitted with
recurrence (Bae et al., 2025a; McLeish et al., 2026; Koishekenov et al., 2025): improvements with depth may reflect
new intermediate computation, refinement of an already-formed predictive state, or a combination of the two.
We therefore examine how the next-token distribution changes with recurrent depth. Our intermediate readouts show
that additional recurrence primarily redistributes probability among tokens that already rank highly after shallow
execution. The leading token often gains probability, while changes in the relative ordering of nearby candidates can
also alter which token the model favors. These changes in preference can shape the continuation the model produces

and the context of subsequent predictions. This observation connects to recent results on simple self-distillation, where
changes in a model’s own predictive distribution can provide useful training signal (Zhang et al., 2026). Here, deeper
recurrent execution itself produces these preference changes, suggesting that the resulting behavior could guide further
learning of the shared recurrent operator without an additional correctness signal.
This paper tests this possibility by using trajectories generated at deeper recurrent depth as supervision for the same
model, while training only the shared recurrent block through a shallower execution. We refer to this process as
preference write-back. We take the shared recurrent operator as the object of improvement, with its subsequent repeated
use as a central consideration. Shallow execution provides a path for learning the update, while its value is assessed
through subsequent applications of the same operator.
Specifically, we make the following contributions. We show that additional recurrence refines predictive preferences
among plausible continuations (Section 2.2), and turn this depth-induced behavior into supervision without reference
answers or filtering (Section 2.3). By separating teacher, training and inference depth, we find that learning from deeper
behavior improves recurrent inference, with single-pass learning outperforming full-depth learning on the same targets
in our input-injected models (Section 3.2). We further show that the shallow-learned update remains useful when the
shared operator is applied at later recurrent passes (Section 3.3). Controlled comparisons reveal that the advantage of
shallow learning depends on the recurrent recipe, connecting how recurrent computation is developed to how it can
subsequently be improved (Section 3.4). We also examine the source of supervision and its transfer across question
pools (Section 3.5), together with the retention of capabilities beyond mathematical reasoning (Section 3.6).
2
Learning from recurrence
2.1
Looped language models and repeated computation across depth
A shared computation across depth.
Looped language models increase execution depth by repeatedly applying the
same recurrent core to an evolving latent state. We develop this shared computation through recurrent mid-training,
then seek to improve the same core using behavior revealed by deeper execution.
Input-conditioned recurrent computation.
We retrofit the OLMo-2 1B stage-1 checkpoint (Team OLMo et al.,
2025) into a non-recurrent input stack P, a shared recurrent core Fθ, and a non-recurrent output stack C, following
prior recurrent architectures (Geiping et al., 2025) and prior retrofits of pretrained models (McLeish et al., 2026). The
input and output stacks are termed the prelude and coda in prior work. We assign the first seven Transformer blocks
to P, the middle four to Fθ, and the final five to C, following the partition used for this model family (Koishekenov
et al., 2025). This partition places recurrence in a middle region where the angular changes between consecutive hidden
representations have stabilized, retaining separate input and output transformations.
Let x1:n ∈Vn be a prefix of n tokens from vocabulary V. The input stack, including token embeddings, produces
e = P(x1:n) ∈Rn×d, where d is the model width. Starting from an initial state s0 ∈Rn×d, an execution of depth r
computes

core Fθ : Rn×d →Rn×d and the position-wise linear projection Aψ : R2d →Rd reuse the same parameters θ and ψ at
every pass. This input injection makes the same representation e available throughout the evolution of the recurrent
state. After the final pass, the output stack C : Rn×d →Rn×d and language-model head W ∈R|V|×d produce the
next-token distribution pr(· | x1:n) = softmax(W[C(sr)]n), where [·]n ∈Rd selects the final-position representation.
The input and output stacks are each applied once.

We adapt the pretrained parameters to recurrent execution through continued
causal language-model training on the Dolmino mixture (Team OLMo et al., 2025). During this stage, the execution
depth is sampled once per training step from a Poisson-lognormal depth distribution, following prior recurrent-depth

We call m the model’s mean depth, using target values of 4, 8, and 32. Mean depth characterizes the recurrent-

different numbers of passes. Initialization and curriculum details are provided in Appendix C, and Appendix A shows
that recurrence already improves accuracy during mid-training. The resulting checkpoint supplies both the model to be
updated and the deeper executions from which we construct supervision.

2.3
Writing preferences back into the shared recurrent core
Once deeper behavior has been converted into supervision, the remaining problem is to turn a transient effect of
additional computation into a persistent change in the computation itself. In a weight-tied model, this means writing
the behavior back into the shared operator that produced it and that subsequent recurrence will reuse. Crucially, the
execution that reveals the behavior need not be the execution through which the operator learns it. We refer to this
transfer from depth-induced behavior into reusable computation as preference write-back (Figure 2 and Algorithm 1 in
Appendix C.3).
Decoupling behavior exposure from incorporation.
Preference write-back separates the source of supervision
from the computation through which that supervision is learned. The teacher depth rT specifies the execution whose
behavior is retained as supervision, while the training depth rL specifies the recurrent computation through which that
supervision acts on the shared operator. For a fixed target set DrT, changing rL leaves both the behavioral target and
the shared parameterization unchanged. Only the computational path connecting that target to the shared parameters
changes. Behavior exposed at one depth can thus be learned through another execution of the same operator.

but is not updated. Given DrT, we initialize θ = θ0 and optimize the recurrent core through an execution of depth rL
using completion-only next-token likelihood.

Reusing the written-back computation.
After optimization, the updated core Fθ1 becomes the recurrent operator
used at every subsequent pass, while the remaining parameters ϕ remain unchanged. At inference depth rE, the model
repeatedly applies Fθ1 as the recurrent state evolves. This reuse follows from weight sharing. Whether an update
learned through shallow execution remains useful on states reached later in recurrence is a separate empirical question.
Preference write-back thus separates the depth that exposes behavior from the depth used to learn it and the depth at
which the updated computation is reused. These roles are indexed by teacher depth rT, training depth rL, and inference
depth rE, respectively, while all three operate on the same shared recurrent computation. We therefore assess the update
through its repeated use at inference, not only through the execution used to learn it.
3
Preference write-back in looped language models
Experimental setup.
We study looped language models obtained by continuing mid-training an OLMo-2-1B base
model toward mean recurrent depths of 4, 8, and 32. Unless otherwise stated, self-distillation follows the recipe
introduced in Section 2. Each model generates greedy trajectories at its standard deeper execution depth, without
correctness filtering, and only the shared recurrent block is updated through one recurrent pass. We compare the looped
checkpoints with a non-looped control trained on the same data and 50B mid-training tokens. We evaluate each looped
model before and after write-back at one pass and at its standard inference depth, focusing on mathematical reasoning
under greedy decoding. Architecture, training, and evaluation details are given in Section 2 and Appendix C.
3.1
Learning from deeper recurrence improves recurrent inference
The looped checkpoints already benefit from additional recurrence before write-back. At their mean depths, all
three outperform the non-looped control on each of the six mathematical reasoning benchmarks, with mean per-task
relative gains of 26.5–39.9% (Table 1). On GSM8K, the mean-depth-4 checkpoint improves from 40.86% after one
pass to 56.18% after four passes.
Learning from its own four-pass continuations raises one-pass accuracy to 48.52% and four-pass accuracy to 62.70%.
The updated model continues to benefit from additional recurrence, gaining 14.18 points from one to four passes.
Across the three models, write-back increases accuracy in 15 of the 18 model–benchmark comparisons at their mean
depths, including all six for the mean-depth-4 model. GSM8K, GSM1K, GSM-Symbolic, and ASDiv improve at all
three mean depths. The final models achieve mean per-task relative gains of 34.9–46.2% over the non-looped control.
Additional recurrence supplies supervision beyond one-pass self-training. On the mean-depth-4 model, we use the
same question pool, one-pass learning, and four-pass inference, varying only the teacher depth (Table 7). Four-pass
teacher continuations yield 62.70% on GSM8K and 54.36% on GSM1K, compared with 59.29% and 51.95% from
one-pass teacher continuations.
Write-back further improves the looped checkpoint under a common learning budget. We compare gold-answer
SFT, SSD-style self-training (Zhang et al., 2026), and distillation on a common random subset of 1,024 GSM8K
training questions (Table 2). Both starting checkpoints share the pretrained initialization, mid-training data, data
order, and 50B-token budget. The primary comparisons use a common cap of approximately 1.575 × 1016 estimated
matrix-multiplication FLOPs for trajectory generation, teacher scoring, and student training. Sequence KD (Kim and
Rush, 2016) learns from the same four-pass continuations as write-back and gives the best non-looped scores of 47.46%
on GSM8K and 40.83% on GSM1K. The looped checkpoint already reaches 56.18% and 51.12% at four-pass inference.
On the looped checkpoint, DistiLLM-2 (Ko et al., 2025), GKD (Agarwal et al., 2024), and EOPD (Jin et al., 2026) use
the same original four-pass teacher as write-back. Write-back achieves the highest four-pass accuracy on both tasks
among the tested updates, at 60.50% and 51.54%. Its GSM8K gain of 4.32 points is more than twice the 2.12-point
gain of DistiLLM-2, the strongest tested KD alternative on this task.

3.3
Shallow-learned updates remain useful in later recurrence
Does an update learned through one pass improve later applications of the same shared operator? In the
mean-depth-4 model, we choose at each of four recurrent passes whether to use the original or self-distilled shared
block, while keeping the rest of the model fixed (Table 3). Using the updated block only on the first pass gives 56.25%
GSM8K accuracy, close to the original model’s 56.18%. Keeping the original block on pass 1 and using the updated
block on passes 2–4 reaches 62.47%, compared with 62.70% when the update is used throughout. The later-pass

Recurrent recipes shape subsequent learning
The advantage of shallow learning depends on the recurrent recipe. We compare mean-depth-4 models with and
without input injection, starting from the same pretrained checkpoint and following matched mid-training procedures

3.5
Sources of depth-induced supervision
Useful supervision can emerge before the model reaches its standard inference depth. We compare teacher
trajectories generated at different depths while keeping one-pass learning and deeper inference fixed (Table 7). For the
mean-depth-32 model, learning from eight-pass trajectories raises 32-pass GSM8K accuracy from 57.01% to 62.85%,
compared with 62.09% from 32-pass trajectories. Across the three benchmarks, the corresponding mean per-task
relative gains are 2.3% and 2.6%. Teacher depth can therefore be chosen separately from inference depth.
On the same 10,000 OpenMath questions, greedy continuations give higher accuracy than truncated sampling on
all three evaluated tasks, including 62.62% versus 60.50% on GSM8K (Table 7). Learning from either GSM8K or
OpenMath question pools also improves GSM8K and GSM1K in the mean-depth-4 model. At a fixed pool size of
10,000 questions, selecting questions for broader coverage raises SVAMP accuracy from 61.20% with random selection
to 63.90%, with both pools improving GSM8K.

Write-back retains the overall non-mathematical performance of the looped checkpoints. We evaluate 17 OLMES

4
Related Work
Recurrent depth and looped language models.
Weight sharing across depth dates back to Universal Transformers
(Dehghani et al., 2019) and ALBERT (Lan et al., 2020). Looped Transformers can emulate iterative algorithms
(Giannou et al., 2023) and approach the reasoning ability of deeper models (Saunshi et al., 2025). Recent work
pre-trains recurrent-depth language models at scale (Geiping et al., 2025; Zhu et al., 2025), converts pretrained models
into looped form (Bae et al., 2025a; McLeish et al., 2026; Koishekenov et al., 2025), and adapts the number of passes to
each token (Bae et al., 2025b) or to a compute budget (Jeddi et al., 2026). Building on these approaches, we develop
looped language models through recurrent mid-training and study how the predictive behavior revealed by additional
passes can inform subsequent training.
Self-distillation and model-generated supervision.
Extra inference-time computation can improve reasoning (Snell
et al., 2025). Several lines of work use model predictions as supervision, including sequence-level distillation (Kim
and Rush, 2016) and born-again self-distillation (Furlanello et al., 2018). Related work internalizes chain-of-thought
into latent reasoning (Hao et al., 2025; Shen et al., 2025) and trains on a model’s own generations, often filtered for
correctness or consistency (Zelikman et al., 2022; Huang et al., 2023; Singh et al., 2024) and sometimes without any
filter (Zhang et al., 2026; Agarwal et al., 2025). We use sequence-level self-distillation on the model’s own deeper
continuations to update only the shared recurrent core.
Supervision across depth and training through partial computation.
Intermediate depths are often supervised
directly through losses on hidden layers (Lee et al., 2015), deep-to-shallow self-distillation (Zhang et al., 2019) or
early-exit losses (Elhoushi et al., 2024). Weight-tied iterative models are often trained through part of their computation.
Implicit models use implicit or approximate gradients, including approximations based on a single operator application
(Bai et al., 2019; Geng et al., 2021; Fung et al., 2022). Recurrent networks that extrapolate to more iterations
(Schwarzschild et al., 2021) have been trained by backpropagating through a random suffix (Bansal et al., 2022).
Recurrent-depth language models also truncate backpropagation (Geiping et al., 2025), as in truncated backpropagation
through time (Williams and Peng, 1990). Preference write-back separates the forward depth used for learning from
the depths used to generate supervision and to run inference. Our pass-wise intervention shows that an update learned
through one pass remains useful at later recurrent passes. Controlled comparisons further show that the advantage of
single-pass learning over full-depth learning depends on the recurrent recipe.
5
Conclusion
Once a model has learned to benefit from recurrent depth, its own deeper executions can provide supervision for further
learning. Our analysis shows how additional recurrence refines predictive preferences among already plausible tokens,
and preference write-back demonstrates how the model can learn from these changes to improve its reasoning. An
important finding is that an update learned through a single application of the shared recurrent operator can improve
its subsequent applications. Using the updated core only at later passes recovers nearly the full gain in our four-pass
GSM8K experiment. The advantage of shallow learning over full-depth learning also varies with the recurrent recipe,
linking the development of recurrent computation to its subsequent improvement. More broadly, these findings open up
the question of how the behavior that emerges as recurrent computation develops can guide its continued learning.

Recurrence primarily reweights the top of the distribution
Reading out along a depth-4 trajectory.
We analyze the mean-depth-4 Looped LM of Table 1. During an ordinary
greedy generation at depth 4, we additionally decode the state sk after each pass k = 1, . . . , 4 with the same output
stack and language-model head, giving the intermediate readouts
qk(· | x, ˆy<t) = softmax(W[C(sk)]n) ,
k = 1, . . . , 4.
The readouts are diagnostic only: each decodes from a copy of the output-stack cache, none feeds back into the
recurrence, and tokens are selected from q4 alone, so the generation is exactly the ordinary depth-4 generation. Because
every qk is conditioned on the depth-4 trajectory, and its output stack attends to the depth-4 states of earlier positions,
it describes an intermediate state of that execution and differs in general from pk, the distribution of an independent
execution of depth k (Section 2.1). Figure 5 summarizes how the readouts change from pass to pass.
Recurrence primarily reshapes the head of the distribution.
Additional passes mainly reshape the relative
probabilities of candidates already near the top after the first pass, rather than promote previously low-ranked candidates.
The effect varies in magnitude: at many positions the probabilities change while the ordering is preserved, at others
nearby candidates are reordered, and only occasionally does the top-1 prediction change.
We apply this diagnostic to all 7,473 GSM8K training problems under greedy depth-4 generation, yielding 715,596
generated-token positions. (a) The top-1 prediction is stable at most positions: it is the same at all four passes at 95.6%

From readout to supervision.
Within the four-pass generation, additional passes mainly redistribute probability
among tokens that already rank highly in the first-pass readout of that same trajectory. Greedy decoding at the deeper
execution turns this preference into a complete continuation, and these continuations are the self-distillation targets of
Section 2.2.
Relation to layer-wise readouts.
Decoding intermediate states with the model’s own output head is a common
probe of residual networks, whose layers refine a prediction iteratively (Jastrz˛ebski et al., 2018): feed-forward updates
promote candidate tokens in vocabulary space (Geva et al., 2022), late layers sharpen the next-token distribution (Lad
et al., 2025), and intermediate predictions can be more accurate than final ones (Halawi et al., 2024). In a looped model
every pass shares one state space and one operator, so the same output stack reads out each pass directly, without learned
per-layer probes.
C
Implementation details
This appendix gives the implementation behind Sections 2 and 3: the looped architecture (Appendix C.1), the mid-
training that produces each Looped LM (Appendix C.2), the self-distillation recipe (Appendix C.3), and the evaluation
protocol (Appendix C.4).
Notation in the tables.
The tables name the three depths of Section 2.3 directly: Teacher is the teacher depth rT,
Training is the training depth rL, and the Depth 1 and Mean depth columns give the inference depth rE. The mean
depth m is the target of the depth curriculum during mid-training (Appendix C.2), and it is also the inference depth at
which each Looped LM is used.
C.1
Architecture
Partition of OLMo-2 1B.
OLMo-2 1B has 16 Transformer blocks of width d = 2048 with 16 attention heads (Team
OLMo et al., 2025); its released configuration specifies a SwiGLU feed-forward layer of width 8,192 and a vocabulary
of 100,352 tokens. The input stack P consists of blocks 1–7, the shared recurrent core Fθ, called the shared recurrent
block in Section 3, of blocks 8–11, and the output stack C of blocks 12–16. Fθ is a single module invoked once per
recurrent pass, so an execution of depth r applies the same 268,468,224 parameters r times; the complete model has
1.49B parameters.
Input injection and the initial state.
The injection projection Aψ is one bias-free linear map from R2d to Rd, applied
at each position, with no gate, normalization or activation. The same input-stack output e is concatenated with the
recurrent state at every pass. During training, the initial state s0 is drawn from a truncated normal distribution with
standard deviation 0.0087. At evaluation, s0 is drawn with a seed derived from the prompt tokens, so executions of
different depth on the same prompt start from the same state.
Model without input injection.
The model without input injection in Table 5 removes both the concatenation and the
separate initial state:
s0 = e,
si = Fθ(si−1),
i = 1, . . . , r.
It is therefore a different recurrence rather than injection with a zeroed projection. Its partition, output stack and
mid-training procedure match those of the injected mean-depth-4 model.

C.2
Mid-training of the Looped LMs
Common setup.
Every Looped LM and the non-looped control start from the OLMo-2 1B stage-1 checkpoint and
continue causal language-model training on the Dolmino mixture (Team OLMo et al., 2025) for up to 50B tokens, with
context length 4,096, a global batch of 2,097,152 tokens (512 sequences), the same data order, BF16 precision and
fully sharded data parallelism. Table 9 lists the optimizer and the gradient path of each model. All models use a peak
learning rate of 7.4 × 10−5, decayed linearly to zero over 23,842 steps without warmup, β = (0.9, 0.95), weight decay
0.033, gradient clipping at norm 1.0 and a z-loss coefficient of 10−5. Muon updates the matrix parameters with its
learning rate rescaled to the update scale of AdamW, and AdamW updates the embeddings, normalization parameters
and language-model head.
Depth sampling and curriculum.

lognormal distribution of Geiping et al. (2025), with log-normal scale σ = 0.5 and parameterized by the current
curriculum mean µt of Section 2.1. Over the first 75% of the T training steps, µt rises from 1 to the target mean depth
m along a one-minus-square-root schedule, and it is held at m afterwards:

Non-looped control.
The non-looped control of Tables 1 and 8 is trained with the same data and setup, but with a

C.3
Self-distillation
Teacher trajectories.
The teacher is the frozen Looped LM before the update. For each training question it generates
one continuation at teacher depth rT by greedy decoding, using the fixed eight-shot chain-of-thought prompt of OLMES
for GSM8K (Gu et al., 2025; Team OLMo et al., 2025) and at most 512 new tokens. Generation ends at the first stop
string or end-of-sequence token. The generated token ids, including the stop token, are the target without further editing;
a continuation that reaches the token limit is kept as generated. Targets are generated once and reused in every epoch,
and the reference answer of the training question is never used. The sampled targets in Table 7 apply temperature
T = 0.7 and then top-k truncation with k = 10 at each step.
Objective and updated parameters.
A training sequence is the eight-shot prompt followed by the target continuation.
The loss is the completion-only next-token cross-entropy of Section 2.3, normalized by the total number of target tokens
in the batch; no distillation term on the teacher probabilities is added. Only the 32 parameter tensors of Fθ are updated.
The embeddings, input stack, injection projection Aψ, output stack and language-model head are frozen, leaving 18%
of the parameters trainable.

Setup.

D.3
Pass-wise block replacement
The intervention of Table 3 executes the mean-depth-4 Looped LM for four passes and chooses, for each pass, either
the original shared block or the block of the self-distilled model of Table 1. All other parameters are shared by the two
models; only the 32 tensors of the recurrent block differ. Each pattern is a complete execution: generation and the cache
are rebuilt under that pattern, so the comparison locates where the updated block is needed rather than splitting the gain
into additive per-pass contributions. On eight check examples, the two pure patterns reproduce ordinary inference of the
two models exactly, in generated tokens, next-token logits and cache contents.
Table 13 gives the record of the four patterns on GSM8K. Using the updated block on passes 2–4 recovers 97% of the
gain obtained by using it throughout. Using it only on the first pass corrected 39 answers and introduced 38 errors, for a
net gain of one correct answer out of 1,319.
