## 摘要
循环语言模型无需增加参数即可加深计算，但在各层与各轮中缓存全上下文键值（KV）状态会严重限制服务批大小。我们设计了一种循环因果编码器-解码器（CED），在轮次间 KV 零增长的情况下实现循环深度，解决了在仅由稀疏编码器层生成全局 KV 的非对称堆栈中应在何处以及如何循环的问题。我们发现，循环必须放在编码器中，以迭代细化全局 KV 表示，而不是重复读取静态解码器投影；这既能带来语言建模收益，又能保持长上下文扩展性。此外，在随机循环深度下训练编码器循环，会诱导出一种不动点均衡，使每一轮都无损地共享上一轮的 KV 缓存。通过叠加跨层与跨轮 KV 共享，所得 Looped CED 与未循环 CED 的最小内存占用相当，并在仅使用循环 Transformer 全局 KV 的 1/6 的情况下，恢复了其 86–93% 的收益。为测试生产规模下的服务，我们在单个 4xGB200 节点上将 552B 参数的 DeepSeek-V4.1-Flash 循环 8 轮：若使用逐层与逐轮 KV，该循环甚至无法容纳单个 128K token 请求；而 Looped CED 每 token 持有的 KV 少 36.8 倍，可容纳 38 个此类请求（与未循环模型一样多），并在 8K token 提示上提供 3.6 倍更高的吞吐量。

## Abstract
Looped language models deepen computation without adding parameters, yet caching full-context key-value (KV) states across layers and rounds severely bounds serving batch size. We design a looped causal encoder-decoder (CED) that achieves recurrent depth with zero round-wise KV growth, addressing where and how to loop an asymmetric stack in which only sparse encoder layers generate global KV. We find that recurrence must be placed in the encoder to iteratively refine global KV representations rather than re-reading static decoder projections, which both drives language-modeling gains and preserves long-context scaling. Furthermore, training the encoder loop under stochastic recurrence depth induces a fixed-point equilibrium where every round losslessly shares the last round's KV cache. Compounding cross-layer and cross-round KV sharing, the resulting Looped CED matches an unlooped CED's minimal memory footprint and recovers 86-93% of a looped Transformer's gain with 1/6 of its global KV. To test serving at production scale, we loop the 552B-parameter DeepSeek-V4.1-Flash for 8 rounds on one 4xGB200 node: with per-layer and per-round KV the loop cannot fit a single 128K-token request, whereas Looped CED holds 36.8x less KV per token, fits 38 such requests (as many as the unlooped model), and serves 3.6x higher throughput on 8K-token prompts.

- **研究动机**：循环语言模型通过重复应用权重共享层块来“加深计算而不增加参数”，但推理时若为每一层、每一轮都缓存全上下文 KV，KV 显存会随层数和循环轮数增长，严重限制服务批大小与长上下文吞吐。
- **具体问题**：因果编码器–解码器（CED）是一种非对称 KV 拓扑：每层保留局部滑动窗口注意力（SWA），只有少量编码器层生成全局 KV，解码器共享一个由编码器末端投影出的全局 KV。把循环深度引入 CED 时，需要回答两个问题：
  1. **在哪里循环**：循环应放在编码器还是解码器？对建模能力、prefill 和 decode 成本有何影响？
  2. **如何循环与缓存**：如何训练和缓存，使多轮循环不增加常驻 KV，同时不损失质量？
- **整体含义**：论文试图把“循环深度”与“KV 缓存增长”解耦，在保留 CED 跨层 KV 共享和服务效率的同时，获得接近循环 dense Transformer 的建模收益与长上下文扩展能力。

## 2. 方法论

- **总体架构：Looped CED**
  - 采用 prelude–recurrent core–coda 的“三明治”结构：非循环前奏 \(P\)、权重共享循环核心 \(R\)、非循环尾段 \(C\)。
  - 在 12 层实验配置中：编码器为第 0–5 层，解码器为第 6–11 层；每层维护 128 token 的 SWA 缓存。
  - 编码器第 2 层是唯一编码器全局 KV 源，供第 3–5 层读取；第 6 层从编码器最终输出投影出共享解码器全局 KV，供第 7–11 层读取。
  - 循环核心为第 2–5 层，共 4 层，训练和推理默认 \(T=8\) 轮。

- **循环位置设计**
  - **编码器循环**：循环核位于编码器内并包含全局 KV 源层。每轮迭代细化局部 SWA 表示和编码器全局 KV，最终边界投影也随最后一轮更新。代价是 prompt prefill 必须执行全部 \(T\) 轮编码器循环。
  - **解码器循环**：循环核位于边界投影之后，全局 KV 在循环开始前已固定，每轮只反复读取静态全局 KV 并更新局部 SWA。prefill 可跳过解码器，计算便宜，但循环无法重构全局表示。

- **门控输入注入**
  - 每轮将输入嵌入经 RMSNorm 后注入循环状态：
    \[
    R(h_{r-1},e)=f\big(\bar A\odot h_{r-1}+\Delta\odot(B\tilde e)\big)
    \]
    其中 \(\tilde e=\mathrm{RMSNorm}(e)\)，\(\bar A=\exp(\Delta\odot A)\)，\(\Delta\) 为学习步长，\(A\) 为衰减参数，\(B\) 为输入投影。
  - 该设计用于稳定循环动态并保持 token 级输入 grounding。

- **随机循环深度训练与不动点**
  - 每条训练序列从 Poisson(8) 采样循环轮数，至少为 1；只对最后 4 轮反传梯度；推理时固定执行 8 轮。
  - 随机深度使循环核在后期轮次收敛到收缩不动点，使局部 SWA KV 和全局 KV 源在后期稳定。

- **最后轮 KV 缓存**
  - 推理时不为每个 token 保留所有 \(T\) 轮的 KV，而是只保留该 token 完成全部轮次后的“最后一轮”全局 KV 和 SWA KV。
  - 后续 token 在任意轮次都读取历史 token 的最后轮 KV。若不动点成立，该替换近似无损。
  - 与 CED 原有的跨层 KV 共享叠加后，形成“跨层 + 跨轮”双重共享。

- **长上下文评估方法**
  - 提出 offset-averaged long-document BPB：在 PG19、FinePDFs、GovReport 的长文档上按位置评估 BPB，并对同一文档多个偏移取平均，以探测超出 128-token SWA 窗口后对全局 KV 的依赖。
  - 另设“复制测试”：将前 1,024 token 原样复制到后 1,024 token，迫使模型通过全局 KV 检索远距离信息。
