## 摘要
我们提出 Dory1.0-4B，一个具有弹性深度的 40 亿参数循环（潜在循环）语言模型：单个检查点可服务于不同的推理计算预算。Dory1.0-4B 构建在归一化 Transformer（nGPT）主干上，采用交错滑动窗口与全注意力层，组织为输入块、共享循环块和输出块。推理时，循环块可被应用可变次数。我们在 6 万亿 token 上预训练 Dory1.0-4B。前 4.5 万亿 token 以 NVFP4 训练，随后通过额外预训练将上下文长度扩展至 256K token。接着，我们使用监督微调（SFT）和可验证奖励强化学习（RLVR）对模型进行后训练，并采用难度感知的循环课程，将更难提示路由到更深循环。增加循环次数可提升准确率，在编码、智能体和长上下文基准上收益最大。在 12 个基准上平均而言，使用两个或更多循环时，Dory1.0-4B 优于 Qwen3.5-9B、Gemma 4 12B 和 Gemma 4 26B-A4B 等更大模型。循环还使 Dory1.0-4B 在智能体基准上更具 token 效率：使用四个循环时，其生成的 token 数比使用一个循环少 1.3–2.5 倍，因为额外计算花在潜在空间而非更长输出上。为减少循环期间的内存占用，Dory1.0-4B 仅缓存最后一个循环的键和值，从而在任意循环次数下其 KV 缓存占用与非循环模型相同，同时保留大部分准确率收益。我们开源了 BF16、MXFP8、NVFP4 和 GGUF 量化检查点。

## Abstract
We introduce Dory1.0-4B, a 4-billion-parameter looped (latent-recurrent) language model with elastic depth: a single checkpoint serves different inference compute budgets. Dory1.0-4B is built on a normalized Transformer (nGPT) backbone with interleaved sliding-window and full-attention layers, organized into an input block, a shared recurrent block, and an output block. At inference, the recurrent block can be applied a variable number of times. We pre-trained Dory1.0-4B on 6 trillion tokens. The first 4.5 trillion tokens were trained in NVFP4, and additional pre-training then extended the context length to 256K tokens. Next, we post-trained the model using Supervised Fine-Tuning (SFT) and Reinforcement Learning with Verifiable Rewards (RLVR), with a difficulty-aware loop curriculum that routes harder prompts to deeper loops. Increasing the loop count improves accuracy, with the largest gains on coding, agentic, and long-context benchmarks. With two or more loops, Dory1.0-4B outperforms larger models such as Qwen3.5-9B, Gemma 4 12B, and Gemma 4 26B-A4B on average across 12 benchmarks. Looping also makes Dory1.0-4B more token-efficient on agentic benchmarks: with four loops, it generates 1.3-2.5x fewer tokens than with one loop, as the extra computation is spent in latent space rather than on longer outputs. To reduce memory during looping, Dory1.0-4B caches keys and values only from the last loop, keeping its KV-cache footprint equal to that of a non-looped model at any loop count while retaining most of the accuracy gains. We open-source the BF16, MXFP8, NVFP4, and GGUF quantized checkpoints.

## 1. 核心问题与研究动机

- **背景**：当前 LLM 的测试时计算扩展（test-time compute scaling）主要消耗在 **token 空间**——生成更长的推理链，导致延迟、KV 缓存占用和服务成本随每个生成 token 线性增长。
- **核心问题**：能否在不增加参数量的前提下，为单一模型提供一条**互补的计算扩展轴**，让推理算力花在潜在空间而非更长的输出上？
- **整体含义**：作者提出 **Dory1.0-4B**，一个 40 亿参数的**循环（latent-recurrent）语言模型**，具备**弹性深度**——同一检查点可通过改变共享循环块的执行次数 𝑘 来适配不同推理计算预算，无需重训或换模型。这是 Nemotron Labs 家族首个开源的循环语言模型，面向推理与智能体任务做完整后训练。

## 2. 方法论

### 2.1 核心思想
- 将 72 层物理层划分为三段：**16 层输入块**（运行一次，产生固定表示 𝑢）、**40 层共享循环块**（运行 𝑘 次，权重与 nGPT 残差率全部共享）、**16 层输出块**（运行一次）。
- 有效前向深度为 **32 + 40𝑘**，𝑘=1 时为 72 层，𝑘=4 时达 192 层物理层应用。
- 循环边界变换（无额外学习适配器、无外层残差加法）：

  - 𝑠₀ = 𝑥（𝑥 为输入块输出）
  - 𝑢ₜ = 𝑁(𝑠ₜ₋₁ + 𝑥)，每轮把固定输入 𝑥 重新注入
  - 𝑠ₜ = 𝑁(𝐹_θ(𝑢ₜ))，𝑡 = 1,…,𝑘
  - 最终状态 𝑠ₖ 送入输出块与 LM head

  其中 𝑁 为逐 token 的 L2 归一化，𝐹_θ 为共享循环块。

### 2.2 架构细节（nGPT 主干）
- 保留 nGPT 的**残差混合更新规则**：每个子层输出与归一化残差流按学习到的逐通道权重 𝑎=|𝛼̂| 混合后再归一化。
- 额外对**门控注意力的拼接输出**（输出投影前）和 **SwiGLU 激活**（下投影前）做 L2 归一化，并用融合 Triton kernel 实现。
- 残差率、QK scale、logit scale 的原始参数初始化为 0.0177（而非 1/√d），初始有效残差率为 0.05；logit scale 为 𝑠𝑧/𝜎₀，𝜎₀=0.0177。
- **注意力**：GQA，16 个 query head、4 个 KV 组；输入相关的 **sigmoid 注意力输出门**；RoPE 作用于全部 Q/K 维度。
- **层间模式**：3:1 的滑动窗口注意力（SWA，窗口 𝑊=1024，RoPE base θ_S=10⁴）与全注意力（θ_F=10⁷）交错；共 36 个纯 MLP 层、27 个 SWA 层、9 个全注意力层。

### 2.3 训练流程
- **NVFP4 预训练**：Megatron-LM + Transformer Engine 的 NVFP4 block-scaling 配方，E2M1 4-bit 操作数用于支持的线性层矩阵乘，权重保持 BF16、优化器主权重/Adam 矩/梯度累积为 FP32；端到端较 BF16 加速约 **20%**。首尾解码层不豁免 NVFP4。使用 Nemotron 3 Ultra 的两阶段数据课程（多样性优先 → 质量优先），序列长度从 8,192 增至 32,768，全局 batch 从 768 降至 192（保持每步 6,291,456 token）。
- **循环引入（BF16 续训）**：从 NVFP4 检查点正常重启（保留优化器、调度器、RNG、数据位置），续训约 1.465T token 至 6T；循环数从 {1,2,3,4} 均匀采样，采样在优化器步与 microbatch 索引上确定并跨数据并行副本共享；另设 **0.1 的 rank 级覆盖比例**，轮换部分副本强制单循环，提供额外单循环信号。
- **截断反传（TBPTL）**：深度为 1，仅最后一次循环调用及输入/输出块可训练；仅在最终采样调用后计算下一 token 交叉熵，无中间出口或辅助损失。
- **长上下文扩展**：序列长度从 32,768 扩至 262,144，额外约 300B token（总计约 6.3T）；全注意力 RoPE base 从 5×10⁵ 提至 10⁷，SWA 保持 10⁴/窗口 1024；重置优化器/调度器/RNG，恒定学习率 10⁻⁵ 无 warmup，47,683 步。
- **SFT**：9 个 epoch，打包 262,144 token 序列，全局 batch 128，恒定学习率 10⁻⁵，保留随机循环采样（{1,2,3,4} 均匀 + 0.1 单循环覆盖），TBPTL 深度 1；混合 thinking（`<think>…</think>`）与非 thinking（空 think 块）数据，损失仅作用于 assistant token。
- **RLVR**：200 步异步 GRPO（NeMo RL），23 个单步环境；每步 384 个 prompt × 16 响应 = 6,144 rollouts；学习率 4×10⁻⁶，BF16；rollout 温度 1.0、top-p 1.0、65,536 token 上下文；按 𝑘=1,2,3,4 设 4:1:1:1 的 prompt 配额，同一 GRPO 组内 16 条 rollout 共享同一循环数。
- **难度感知循环课程**：先用 SFT 检查点以单循环对候选 prompt 做 8 次采样并打分，保留平均奖励严格在 (0,1) 之间的 prompt，记录其通过率作为难度代理。路由分数：

  - 𝑠ᵢ = 𝛼·𝑞ᵢ + (1−𝛼)·𝑢ᵢ，𝑢ᵢ∼Uniform(0,1)

  其中 𝑞ᵢ 为批内中点分位数（并列值同分位），𝛼=0.3；分数越低越优先填入更深循环槽位。𝛼=1 时完全按难度排序，𝛼=0 时为满足配额约束的均匀随机分配。
- **最后循环 KV 缓存**：每个循环注意力层只维护一份缓存，每轮覆盖；查询对已缓存 token 使用最后循环的 KV、对当前步 token 使用当前循环 KV，使任意 𝑘 下 KV 内存等于单循环模型。
- **量化**：MXFP8 用 PTQ；NVFP4 与 Q5_K_M 用 QAD（全词表前向 KL，温度 1，教师为对应 BF16 检查点，学生为 PTQ 版本，每步按当前权重重算量化 scale，保留循环采样与 TBPTL）。

## 6. 主要结论与贡献

- **弹性深度可用**：同一检查点在𝑘=1→8 范围内均可运行，性能总体随𝑘 增大而提升（尤其数学、代码与需要多步推理的任务），说明循环块确实提供了 token 空间之外的互补计算轴；𝑘=1 时仍保持可用的基础能力，使“按预算选深度”在部署上可行。
- **效率优势可落地**：
  - **KV 缓存**：最后循环缓存策略使任意𝑘 下的 KV 内存与单循环模型持平，避免了深度增加带来的显存线性膨胀，这是弹性深度能实际服务的关键工程点。
  - **自推测解码**：以浅循环起草、深循环验证，可在不换模型的前提下获得 prefill+decode 加速，形成“精度–延迟”可调旋钮。
  - **量化**：MXFP8-PTQ 与 NVFP4/Q5_K_M-QAD 在多数基准上接近 BF16，配合 DGX Spark 的实测加速，支撑端侧/边缘部署叙事。
- **训练配方贡献**：NVFP4 block-scaling 预训练带来约 20% 端到端加速且首尾层不豁免，配合 BF16 续训引入循环、长上下文扩展到 262,144、SFT 混合 thinking/非 thinking 数据、GRPO + 难度感知循环课程，构成一套可复现的“循环 LM 后训练流水线”。
- **开源意义**：作为 Nemotron Labs 首个开源的循环语言模型，其价值不仅在分数，更在于公开了循环边界变换、残差归一化细节、循环采样与 TBPTL 等实现要点，为该方向提供可复现基线。

## 7. 局限与未来方向（基于论文信息的推断）

- **架构层面**：循环块权重与残差率全共享，可能限制不同深度所需的表示分化；未来可探索部分共享、深度条件化调制（如按𝑘 注入轻量嵌入）或中间循环的辅助出口。
- **训练层面**：TBPTL 深度 1 是明显的简化，加深截断深度或引入循环一致性/中间层蒸馏损失，可能进一步释放深循环收益。
- **评测层面**：缺少同预算密集基线、缺少长上下文与多轮智能体场景下的量化与 KV 策略联合评估；难度感知课程仅在小规模早期检查点上消融，其在大规模 RL 下的稳定性待验证。
- **部署层面**：弹性深度需要服务端按请求动态选择𝑘，涉及批内不同𝑘 的调度与吞吐权衡（论文未讨论混合𝑘 批处理的开销），这是实际落地的开放问题。

## 8. 总体评价

论文问题意识清晰：把“测试时计算”从 token 长度转向潜在深度，是对当前推理模型扩展范式的一个有意义补充。方法上工程完成度高——循环边界变换设计简洁（无额外适配器）、最后循环 KV 缓存巧妙解决了显存瓶颈、NVFP4 预训练与 QAD 量化形成了完整的效率链条。实验覆盖从基座到后训练、从精度到延迟/内存/量化的多维证据，弹性深度在𝑘=1–8 上的单调趋势具有说服力。

主要短板在于**归因强度**：缺乏同参数量、同 token 预算的密集模型对照，TBPTL 深度 1 与仅 200 步 RL 使“循环架构本身贡献多少”难以完全剥离；部分基线为自报分数，横向比较的严格性有限。总体而言，这是一篇以系统与工程贡献为主、实证较扎实但因果归因偏弱的模型报告型论文，其开源实现对该方向的后续研究具有较高参考价值。
