## 摘要
循环 Transformer 通过跨循环复用共享层来提升表达能力，但代价是效率。要推进其表达能力与效率的前沿，需要重新思考连接相邻循环的核心机制：在 Transformer 的循环之间应传递什么？我们提出循环混合 Transformer（Mixture-of-Loops Transformer，MoLT），其循环混合注意力（Mixture-of-Loops Attention，MoLA）使用键和值（KV）作为记忆，以在深度和循环之间进行选择性复用。在循环残差（loop residual）下，MoLT-R 保留残差流，并跨循环读取局部 KV 以提升表达能力。在循环 KV（loop KV）下，MoLT-KV 则从嵌入重新开始，并在较早位置读取当前循环的局部 KV 与前一循环的记忆 KV，以提升效率。MoLT-KV 消除了同位置跨循环依赖，并结合用于并行训练的循环强制（loop forcing），解锁了超越训练循环范围的单次遍历循环混合（Mixture-of-Loops，MoL）解码。为平衡效率与质量，我们引入 U 形 MoLT（U-MoLT），它将记忆构建与预测读出分离，并在不改变预测的情况下跳过未使用的解码器遍历。在 400B token 预训练中，U-MoLT 在 700M/1.5B 稠密模型和 3B MoE 模型上均优于 OLMo3，在 700M 上实现 1.7 倍的验证交叉熵（CE）token 效率，同时将 3B MoE 的 10 领域困惑度改善 0.75，并将 10 任务准确率提升 2.1 个百分点。在 Qwen3.5-0.8B-Base 的 100B token 继续预训练中，我们的 U-MoLT 适配在全部 11 个领域上相较匹配基线降低了 CE，并具有 1.4 倍的平均 token 效率。在推理时，采用 MoL-Hybrid-2 的 U-MoLT 在 S 尺寸（约 113M）模型上与未循环的 OLMo3 延迟相当，分别为 996.6 ms 与 1,000.6 ms。代码见 https://github.com/hustvl/MoLT

## Abstract
Looped Transformers boost expressivity by reusing shared layers across loops, yet at the cost of efficiency. Pushing their expressivity-efficiency frontier requires rethinking the core mechanism connecting adjacent loops: What should be passed as a Transformer loops? We introduce Mixture-of-Loops Transformer (MoLT), whose Mixture-of-Loops Attention (MoLA) uses keys and values (KV) as memory for selective reuse across depths and loops. Under loop residual, MoLT-R retains the residual stream and reads local KV across loops for expressivity. Under loop KV, MoLT-KV instead restarts from embeddings and reads current-loop local KV with preceding-loop memory KV at earlier positions for efficiency. MoLT-KV eliminates same-position cross-loop dependence and, paired with loop forcing for parallel training, unlocks single-traversal Mixture-of-Loops (MoL) decoding beyond the training loop horizon. To balance efficiency and quality, we introduce U-shaped MoLT (U-MoLT), which separates memory construction from prediction readout and skips unused decoder traversals without changing predictions. In 400B-token pretraining, U-MoLT outperforms OLMo3 across 700M/1.5B dense and 3B MoE models, achieving 1.7x validation cross-entropy (CE) token efficiency at 700M while improving 3B MoE 10-domain perplexity by 0.75 and 10-task accuracy by 2.1 percentage points. In 100B-token continued pretraining of Qwen3.5-0.8B-Base, our U-MoLT adaptation lowers CE on all 11 domains over the matched baseline with 1.4x mean token efficiency. At inference, U-MoLT with MoL-Hybrid-2 matches non-looped OLMo3 latency at 996.6 vs. 1,000.6 ms on S-size (~113M) models. Code is available at https://github.com/hustvl/MoLT

# 《Mixture-of-Loops Transformer》论文结构化总结

## 1. 核心问题与整体含义

- **研究背景**：循环 Transformer（Looped Transformer）通过跨循环复用共享层参数来提升表达能力，近期在架构设计中受到广泛关注，但代价是推理效率下降。
- **核心问题**：推进循环模型的“表达性—效率”前沿，需要重新思考连接相邻循环的核心机制——**一个 Transformer 在循环之间到底应该传递什么？**
- **标准答案的瓶颈**：主流做法是 **loop residual（循环残差）**，即把每个循环的输出直接送入下一循环。该选择同时制约表达性与效率：
  - 反复将计算压缩进单一残差流会导致**信息稀释与表示退化**；
  - 每个 token 依赖自身前一循环的输出，迫使推理**逐循环串行执行**，无法并行或跳过。
- **论文主张**：不应只依赖残差流，而应把**已计算的键值（KV）作为记忆**，在深度与循环之间进行选择性复用。由此提出 **Mixture-of-Loops Transformer（MoLT）** 家族。

## 2. 方法论

### 2.1 核心思想
- 提出 **Mixture-of-Loops Attention（MoLA）**：每个查询在同一 softmax 分布中联合读取**序列 KV**（沿 token 位置）与**深度 KV**（同 token 位置、不同层/循环的局部 KV），实现跨深度、跨循环的选择性记忆复用。
- 通过两种反馈接口（loop residual / loop KV）与一种编码器—解码器拆分，形成三个变体。

### 2.2 三个变体与关键技术细节

- **MoLT-R（loop residual，追求表达性）**
  - 保留残差流：第 1 循环输入为嵌入 `e(x_t)`，后续循环输入为前一循环归一化输出 `z_{r-1,t}`。
  - 序列 KV 为当前层输入在 `j ≤ t` 的局部 KV；深度 KV 包括当前循环更早层的局部 KV（`D^<ℓ_cur`）与**前一循环所有层的局部 KV**（`D_prev`，同位置 `t`）。
  - 参数量不增加，但推理需固定 N 循环串行执行，保留 N 份序列 KV 缓存。

- **MoLT-KV（loop KV，追求效率）**
  - **嵌入重启**：每个循环都从 `e(x_t)` 重新开始，不再传递残差状态。
  - 序列 KV 改为**前一循环输出 `z_{r-1}` 在严格前缀 `j < t` 上的记忆 KV**（每层独立投影），排除同位置 `j = t`，从而**消除同位置跨循环依赖**。
  - 深度 KV 仅来自当前循环 `k ≤ ℓ`（含自身 KV），提供同位置注意力通路。
  - 第 1 循环用当前循环序列 KV 在 `j < t` 替代记忆 KV。

- **U-MoLT（U 形，平衡效率与质量）**
  - 将堆栈拆为 **MoLT Encoder（L_E 层，loop KV 构建记忆）** 与 **MoLT Decoder（L_D 层，cross-only 因果读出）**。
  - 解码器从原始编码器输出 `Y^{r,0}=X^{r,L_E}` 开始，通过**每层独立的 decoder KV 投影**读取归一化编码器输出 `z^r`（`j ≤ t`）。
  - 解码器位于反馈路径之外，因此可在不影响预测的前提下**跳过中间循环与非最终提示位置的解码器遍历**（Proposition 2）。

### 2.3 训练与解码算法流程

- **多循环监督目标**：所有循环共享同一真值序列，损失为各循环交叉熵的加权和：
  `L = Σ_{r=1}^{N} α_r L_r`，其中 `α_r = w_r / Σ_k w_k`，`L_r = -1/|Ω| Σ_t log p^r_θ(x_{t+1} | x_{≤t})`。
- **Loop Forcing（循环强制）**：对 MoLT-KV / U-MoLT，每个反馈循环并行地以前一循环的**严格前缀记忆 KV** 为条件训练，而非顺序解码的前缀；把 T 步串行训练变为 N 次并行遍历，类比 teacher forcing。支持开放或截断跨循环梯度。
- **三种解码调度**：
  - **Fixed-loop decoding**：每个新 token 依次跑完 N 个循环，需 N 次遍历。
  - **MoL decoding**：从空缓存逐 token 处理，每次遍历从 `e(x_t)` 出发，联合读取缓存前缀记忆 KV 与当前循环局部 KV，并追加新记忆 KV；**单次遍历**即可，且可超出训练循环数。
  - **MoL-Hybrid decoding**：用 k 循环（k=1 或 2）**并行预填充**初始化提示记忆 KV，随后每步采用 MoL 单次遍历更新，兼顾提示并行与解码效率。
- **理论保证**：严格三角递推 `z^r_t = F_t(x_t, z^{r-1}_{<t})`；Proposition 1 证明有限前缀稳定（位置 t 在 `r ≥ t+2` 时达到唯一稳定解）；Corollary 1/2 给出空缓存 MoL 解码与提示条件 MoL-Hybrid 解码的等价性。

## 6. 主要结论与发现

- **质量全面优于非循环基线**：U-MoLT 在 700M、1.5B、3B MoE 三个规模上均降低 10 域困惑度并提升 10 任务准确率。
  - 700M：平均准确率 56.6% → 59.1%（+2.5pp），平均 PPL 15.64 → 14.86；MoLT-R 达 59.2% / 14.84。
  - 1.5B：准确率 +1.4pp，PPL 13.86 → 13.15。
  - 3B MoE：准确率 +2.1pp（60.1 → 62.2），PPL 13.99 → 13.24（−0.75）。
- **Token 效率显著提升**：700M/400B 配对实验中，U-MoLT 在 **232.8B tokens** 即达到 OLMo3 的 400B 验证 CE，**1.7× token 效率**；训练 CE 上为 1.5×；逐域加速 1.4–2.1×。
- **跨架构继续预训练有效**：Qwen3.5-0.8B-Base 上，U-MoLT-CT1 在全部 11 域降低 CE（均值 2.496 → 2.480），达到基线最终 CE 仅需 66.3–78.3B tokens，平均 **1.4× token 效率**，仅增加 0.42% 参数。
- **解码效率接近非循环模型**：MoL-Hybrid 解码将固定 2-loop 延迟降低 32–50%；4,096 token 提示 + 64 步解码下，U-MoLT + MoL-Hybrid-2 为 **996.6 ms**，与 OLMo3 的 **1,000.6 ms** 相当。
- **单次遍历不损失质量**：MoL 与 MoL-Hybrid 相对固定 2-loop 的 ∆CE 在 −0.0005 至 +0.0014 之间，∆PPL 在 −0.012 至 +0.039 之间。
-

- **深度 KV 是主要收益来源**：消融显示，收益并非单纯来自“多算几遍”，而主要来自**跨循环复用已计算的 KV**；仅保留 loop residual 而不引入深度 KV 时，提升明显更小。深度 KV 的来源（当前循环更早层 vs. 前一循环全部层）对质量有实质影响，说明“传什么”比“传不传”更关键。
- **MoLA 的放置方式影响效率—质量权衡**：dense 与 sparse 两种放置在不同规模下表现不同；sparse 放置更接近“按需读取记忆”，在参数量与 FLOPs 增量受控时仍能保留大部分收益，但并非在所有设定下都严格占优。
- **循环损失权重需适度**：1:1、1:2、1:4 三组消融中，过度强调后期循环会损害早期循环的表示质量；文中报告的较优区间表明多循环监督应保持各循环损失的相对平衡，而非简单加大深循环权重。
- **U-MoLT 的“解码器可跳过”具有实际价值**：由于解码器位于反馈路径之外，中间循环与非最终提示位置的解码器遍历可在不改变最终预测的前提下省略（Proposition 2），这使 U-MoLT 在保持循环表达能力的同时具备结构性的推理剪枝空间。
- **循环带来的有效深度收益存在饱和迹象**：作者将 MoLT-R 随有效深度增长的优势称为“初步观察”，说明循环数增加并非无条件线性提升；在固定 token 预算下，超过一定循环数后收益递减，需与训练成本、显存占用共同权衡。
- **理论性质支撑了解码等价性**：严格三角递推保证位置 t 的表示只依赖 `x_t` 与前一循环的严格前缀；Proposition 1 的有限前缀稳定性与 Corollary 1/2 的等价性，为“空缓存 MoL 解码”和“提示条件 MoL-Hybrid 解码”提供了形式化依据，而不仅是经验性加速。

## 7. 局限性与可改进方向

- **训练成本与显存开销上升**：700M 规模的算力账目显示，MoLT 的理论训练 FLOPs 约为 baseline 的 2.01×，峰值活跃显存由 43.6 GiB 升至 58.4 GiB。虽然 token 效率提升可部分抵消该成本，但在固定算力预算下是否“净划算”仍取决于具体规模与任务。
- **算力披露不完整**：1.5B 稠密、3B MoE、S-size 消融与 Qwen 100B 继续预训练均未完整报告 GPU 数量、总 GPU-hours 与墙钟时间，限制了跨规模成本—收益的精确比较与复现预算评估。
- **部分结论为初步观察**：MoLT-R 的深度缩放优势、混合骨干上的行为差异等，作者自身措辞较为谨慎；这些结论需要更多随机种子、更多规模点与更长训练预算来确认稳健性。
- **架构依赖性**：在纯注意力 OLMo3 骨干上，U-MoLT 的 cross-only 解码器设计结论较清晰；但在 Qwen 混合骨干（含 GDN 等非纯注意力组件）上并非严格 cross-only，说明方法的最优形态可能随骨干结构变化，通用性仍需验证。
- **长上下文与缓存管理**：MoL 解码依赖前缀记忆 KV 缓存的追加与读取；在极长上下文、多轮对话或高并发场景下，缓存容量、淘汰策略与内存带宽可能成为新的瓶颈，文中主要验证了 4,096 上下文与单 batch 延迟。
- **理论假设较强**：有限前缀稳定性与解码等价性建立在严格因果、固定循环语义与有限前缀递推之上；对非因果任务、变长循环或训练—推理循环数不一致的情形，理论保证的适用范围需进一步界定。
- **公平性上的细微差异**：700M 配对实验使用了与主表不同的数据切分，绝对 CE 不可直接跨表比较；不同调度共享同一 checkpoint 虽有利于隔离解码影响，但也意味着解码结论不能直接推广到不同训练配方。

## 8. 启示与实践建议

- **设计层面**：把“循环间传递什么”作为独立设计维度，而非默认残差流；KV 作为可选择性读取的记忆，为表达性与并行解码提供了一条不同于“加深网络/增加循环”的路径。
- **工程层面**：若追求训练质量上限，可优先考虑 MoLT-R；若追求推理延迟接近非循环模型，U-MoLT + MoL-Hybrid 是更实用的组合；MoL 单次遍历在报告的质量损失范围内可作为默认快速解码方案。
- **评测层面**：论文同时报告下游准确率、多域困惑度与 teacher-forced 解码质量，并用配对实验衡量 token 效率，这种“质量—效率—成本”三维报告方式值得借鉴；后续工作应补齐各规模算力账目并增加种子方差。

## 9. 总体评价

- **贡献定位**：论文将循环 Transformer 的核心问题从“是否循环”转向“循环间传递何种记忆”，提出 MoLA 与 MoLT 家族，在概念上简洁、在实现上可落地，并给出理论性质与多规模实证，属于架构机制层面的实质性推进。
- **证据强度**：消融覆盖面广、对比条件控制较好，700M 配对 token 效率实验与 4,096 token 解码延迟实验尤其有说服力；但多规模算力披露不足、部分结论为初步观察、混合骨干上的行为差异，使结论的普适性仍需外部复现验证。
- **总体判断**：MoLT 在“表达性—效率”前沿上提供了有竞争力的新基线，其最大价值可能不在于单一最优变体，而在于揭示了**深度 KV 复用**这一可迁移的设计原则；后续若能在更大规模、更长上下文与更多骨干类型上补齐成本与稳健性证据，该方法有望成为循环架构的默认选项之一。
